# Section brief — `programs` (Xterra treadmill wave X1)

Read `$S/briefs-x1/COMMON.md` first. Your section facet is `section: programs`.

Yours: the owner's manuals' program chapters — Programs, Preset Programs (every
program by name, its profile, segments, levels and defaults; rebuild the profile
tables), Manual, Interval, Hill, Fat Burn, Cardio, User / Custom programs, HR /
target heart-rate programs (each is its own card), fitness tests, Heart Rate
Exertion (the zone table and the 220-minus-age rule), the WS200/WS300 program
set. Service manuals print little here — zero from a book is a correct result;
prove it and say so. Then act as second reader for `console`: report (do not
card) anything on the console pages that looks wrong.

Not yours: how the console reads a pulse (grips, chest strap pairing) → console;
program-related error messages → errors.

Program tables are the place ghost text and flattened images hide: many program
profile pages are pictures — read the OCR supplement and, where a segment figure
matters, the render. A program printed identically in several books is one card
with `applies_to` listing them; a profile whose figures differ is its own card
with the distinguishing value in the title.
