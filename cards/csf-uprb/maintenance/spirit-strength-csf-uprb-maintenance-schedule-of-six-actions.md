**The CSF-UPRB prints six action rows and no lubrication group at all.** Every other Spirit
strength machine in the range has something to lubricate; this one has nothing.

| Action | Daily | Weekly | Monthly | Bi-Monthly |
|---|:---:|:---:|:---:|:---:|
| **Cleaning** | | | | |
| Upholstery | ✔ | | | |
| Handgrips | ✔ | | | |
| Main Frame | | ✔ | | |
| **Inspect** | | | | |
| Handgrips | | | ✔ | |
| Upholstery | | | ✔ | |
| Main Frame | | | | ✔ |

That is the whole table. The table box closes after *Inspect: Main Frame*.

## Seven rows the rest of the range has and this book does not

**Clean: Guide Rod. Inspect: Belt / Cables. Inspect: Fasteners. Inspect: Labels. Inspect: Pulleys.
Lubricate: Guide Rods.** And no *Lubricate* group heading.

**This is a real absence, checked on the rendered page and not inferred from the extraction.** It is
the answer to "how often do I lubricate my Spirit bench?" — the manual asks for no lubrication of
any kind, and names no lubricant anywhere in the book. The word *lubricate* does not occur in it.

## What the book still requires, on other pages

The table is not the whole obligation. The same manual prints, on its facility precautions page:

- *Inspect all cables and belts and connections prior to use. DO NOT use if any components are
  worn, frayed or damaged.*
- *Perform regular maintenance checks on the equipment. Also pay close attention to all areas most
  susceptible to wear, including (but not limited to) cables, pulleys, belts and grips.*

and on its SAFEGUARDS page:

- *Cables and belts pose an extreme liability if used when frayed. Always replace any cable or belt
  at first sign of wear.*

**So the machine has no scheduled cable inspection but does have a pre-use one.** Both statements
are in the same book and neither cancels the other; see
`spirit-strength-maintenance-replace-a-frayed-cable-at-first-sign-of-wear`. Those two pages are
boilerplate carried across the whole range and mention parts a bench may not have — say what the
page says, and read the machine in front of you.

## Its safety page also states a different limit from the rest

Where the other CSF books print a **user weight limit**, this one prints **Max Loading Capacity:
600 lb**. That is a safety figure, not a maintenance one, and it is answered from the safety cards.
