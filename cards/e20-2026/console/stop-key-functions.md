**The Stop button has several functions.**

- **Press once during a program: pauses the program for 5 minutes.** To resume, **press the Start key**.
- **Press twice during a workout: the program ends and a Workout Summary is displayed.**
- **Hold down for 3 seconds: the console performs a complete Reset.**
- **During data entry for a program: Previous Screen.** Each press goes back one step in the programming.

**The 5 minute pause is a setting, not a fixed rule.** The service menu item **F07 PAUSE MODE** can be turned off so the console **pauses indefinitely** instead; see `e20-2026-pause-mode-setting`. Neither passage in the manual mentions the other.
