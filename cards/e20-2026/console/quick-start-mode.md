**This is the quickest way to start a workout.** After the console powers up, **press the Start key**. That initiates Quick Start mode.

- **The time counts up from zero.**
- **The resistance level is adjusted manually with the Level UP/DOWN buttons.**

Resistance changes are not instant - see `e20-2026-resistance-change-timing`.

Quick Start is not the same as skipping the setup screens inside a program. Pressing Start at a program's data-entry screen runs that program on its **default settings**; see `e20-2026-program-key-and-default-settings`.
