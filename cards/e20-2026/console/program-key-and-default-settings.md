**Press the Program key to select a program and begin customizing the settings.**

**If you want to work out without entering new settings, just press the Start key.** That bypasses the programming of data and takes you directly to the start of your workout. **If you start a program without changing the settings, the default settings will be used.**

While you are entering data, the **Stop key** steps back one screen; see `e20-2026-stop-key-functions`.
