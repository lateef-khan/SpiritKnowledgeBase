The console drawing is labelled with five callouts:

- **Tablet holder**
- **Program buttons**
- **Level buttons**
- **USB charger**
- **Speaker**

**The key-by-key description is missing from this extraction.** The manual's console pages carry the labelled photograph and the button legends as images; pages 13 to 15 produced no text at all, so the only console parts this manual can be quoted for are the five callouts above. The named keys that appear elsewhere in the text are **Start, Stop, Enter, Program, Manual and Level UP/DOWN**, and the display windows named are the **Message Window**, the **Time Window** and the **Distance Window**.
