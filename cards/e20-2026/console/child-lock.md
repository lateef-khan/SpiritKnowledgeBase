**This is F09 CHILD LOCK in the engineering menu, not F03 units, not F04 sleep mode and not F07 pause mode.**

**F09 CHILD LOCK - 1: OFF, 0: ON.** It locks the keypad so no unauthorized use of the machine is allowed.

**When the child lock is enabled the console will not allow the keypad to operate unless you press and hold the Start and Enter buttons for 3 seconds to unlock the console.**

A keypad that ignores every press is worth checking against this setting before calling it a fault; see `e20-2026-console-key-pressure`.
