**Do not use excessive pressure on console control keys.** They are precision set to function properly with **little finger pressure**. **If you feel the buttons are not functioning properly with normal pressure, contact your SOLE dealer.**

Before calling, the service menu has a **Key Test (F00)** that reports whether each key is working; see `e20-2026-engineering-mode`.

If the keypad ignores every press, check whether the **child lock** is on - it blocks the keypad until Start and Enter are held for 3 seconds. See `e20-2026-child-lock`.
