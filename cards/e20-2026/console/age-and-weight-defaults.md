**Age and Weight default settings change when you enter a new number, so the last Age and Weight entered are saved as the new defaults.**

If you enter Age and Weight the first time you use the elliptical, **you will not have to enter them every time you work out** unless either has changed, or **someone else enters a different Age and Weight**.

The console keeps one set of values. This manual describes no separate user profiles.
