**DO NOT SHIP ANY UNIT TO OUR FACTORY WITHOUT A RETURN AUTHORIZATION NUMBER. All units arriving without a return authorization number will be refused.**

The owner is responsible for **adequate packaging** and for **all transportation costs both ways**, and SOLE is not responsible for shipping damage; see `e20-2026-how-to-get-warranty-service`.

The manual does not say how the return authorization number is issued, beyond the service contacts on the same page.
