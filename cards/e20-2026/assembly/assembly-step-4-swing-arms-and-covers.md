Hardware for this step: **#137, #110, #114, #103**. See `e20-2026-assembly-hardware-pack`.

- Install **Swing Arm (L) (15)** on Lower Handle Bar (L), then secure **three Button Head Socket Bolt (103) through three Curved Washer (137)** using the **Allen Wrench Head Screw Wrench (144)**. Do the same for **Swing Arm (R) (16)**.
- Install **Console Mast Cover (L) (87)** on Chain Cover (L), and **Console Mast Cover (R) (88)** on Chain Cover (R), then combine them and secure **three Sheet Metal Screw (114)** using the **Phillips Head Screw Driver (142)**.
- Install **Slide Wheel Cover (L) (62)** and **Slide Wheel Cover (R) (63)** on Pedal Arm (L) and Pedal Arm (R), and secure **four Phillips Head Screw (110)** with the Phillips Head Screw Driver (142).
- Install the **Rear Bar Cover (60)** on the Rail Connecting Tube (10), then secure **two Phillips Head Screw** with the Phillips Head Screw Driver (142).

**These four bullets are printed unnumbered**, unlike steps 1 to 3. Work them in the printed order.

**The part descriptions here disagree with the hardware checklist on page 6.** The checklist calls **#137** a *5/16" × 15m/m Button Head Socket Bolt*, while this step calls it a **Curved Washer**; the checklist calls **#114** an *M5 × 10m/m Phillips Head Screw* and supplies four, while this step calls it a **Sheet Metal Screw** and uses three. Neither passage corrects the other.
