1. **Press the Program key, then press the Enter key.**
2. **Adjust the Age setting** with the Level UP/DOWN keys, then press Enter.
3. **Enter your Weight** with the Level UP/DOWN keys, then press Enter to continue.
4. **Set the Time** and press Enter to continue.
5. **Adjust the Max Level.** This is **the peak exertion level you will experience during the program (the highest colored segment/box of the program profile)**. Adjust it and press Enter.
6. **Press the Start key to begin the workout.** The **Stop key** goes back one level, or screen, to modify the settings.
7. **Level UP / DOWN changes the resistance at any time during the program.**
8. **When the program ends the Message Window shows a summary of your workout**, displayed for a short time before the console returns to the start-up display.

**This manual never lists the programs.** Page 21 refers to **"any of the nine different programs"**, but the pages carrying the program names and their profile charts produced no text in this extraction, so the nine cannot be named from this source.
