| Reason | Solve |
|---|---|
| Control board are broken | Replace with new Control board |
| Generator brake resistance voltage wire shedding | Please re-install wire |
| Driver IC broken | Replace the new console |

Note the split: the manual blames the **control board** for the first cause but the **console** for
the third, because the driver IC it names sits in the console.

This machine brakes with a generator and an induction brake rather than a tension motor, so the
tension-motor tests written for the CVC800 climber do not apply here.
