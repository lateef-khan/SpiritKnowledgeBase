You create the desired resistance levels for each of the **20 segments** of the program using the
keyboard on the screen. You may change these levels at any time during the workout.

1. Select the **Custom** program, then press **Enter** to begin customising it with your personal
   data - or press **Start** to begin with the default settings.
2. The window shows the corresponding level profile. Use the on-screen interface to achieve the
   workout profile you want, then press **Next** to save and continue.
3. The following screens ask for the desired **Time**, the user **Age**, and **Weight**. Use the
   default values or adjust as needed. Press **Start** to begin.

**No name is stored.** The button-console CE800, CE850 and CES880 manuals all have a name-entry step
for the Custom program; this one does not, and it does not offer to delete a stored program.
