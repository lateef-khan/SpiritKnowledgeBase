Security in engineering mode sets a lock that trips at an accumulated mileage.

The screen carries **Lock Mode** (ON / OFF), **Set Lock Accumulate Mileage** (shown at 100),
**Set Lock Password to Activate**, **Confirm Set Lock Password to Activate**, and a numeric keypad
with Enter and backspace.

The instructions, word for word:

1. Set a four-digit number password and the number of kilometers you want to lock.
2. Can use the set password to unlock or use the password **2222** to unlock.

So **2222 is a master unlock code** on this console, not just a fallback the manual mentions in
passing.

The mileage is in **kilometres** here. The bike in the same console family sets the same lock in
**miles**, with a stated range of 100 to 9999. This manual prints no range at all - 100 is only the
value shown in the screenshot.
