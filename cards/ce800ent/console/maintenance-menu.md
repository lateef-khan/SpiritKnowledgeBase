**This is where Wi-Fi and Ethernet are set up.** Reach it from engineering mode, then Maintenance.
The screen lists seven buttons, in this order:

| Button | What the manual says it is for |
|---|---|
| Default Language Setup | Set the default language |
| WiFi Setup | Wi-Fi connection |
| Etherent Setup | Ethernet connection - the button really is printed "Etherent" |
| BT Setup | Enable the Bluetooth function |
| Update App(USB) | Update APP, a USB manual update |
| Update OS | Reserved |
| System & Apps | Update APPS, the internet function of the APPs |

That is the whole of it. **The manual gives no steps inside any of these seven screens** - no SSID
entry sequence, no static-IP fields, no update file name, no Bluetooth pairing procedure. The bike
in the same console family documents its Wi-Fi and Ethernet screens in detail; this manual does not.

"Update OS (reserved)" means the button exists but is not in use.
