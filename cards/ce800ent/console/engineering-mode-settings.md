The **Engineering Mode** entry of the setting page holds four settings.

| Setting | What it does |
|---|---|
| Units | Choice of **KM or Mile**. |
| Beep Mode | Turns off the beep of the button - no beeping sound is heard. |
| Sleep Mode | **Default OFF.** Set ON and the console sleeps after **30 minutes** with no operation. Press any key to wake it. |
| Pause Mode | **On** allows 5 minutes of pause. **Off** makes the console pause indefinitely. |

Note which way round Pause Mode works: turning it **off** is what stops the console resetting after
five minutes.

The manual calls the console "the electronic watch" in the Sleep Mode line; that is the source's own
term for the console throughout the Dyaco manuals.
