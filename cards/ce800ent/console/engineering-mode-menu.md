Reach it by clicking the Home icon at the top centre of the main page **ten times**. The setting page
then offers **six sub-menu modes**, printed word for word as:

| Item | Description |
|---|---|
| Engineering Mode | Set the unit, Sleep mode |
| Security | Set Lock Accumulate mileage. |
| Diagnostics | The Error Diagnostics |
| Machine Information | Set Machine Type, GS Mode, Touch sound, Sleep Mode, Safety Mode, Zero mileage. |
| Maintenance | Set default language, Wi-Fi, Ethernet, Bluetooth, USB update, update OS. |
| A / V Source Setup | Set audio/visual source. |

Two of these descriptions do not match the screens they open.

- **Machine Information** promises Machine Type, GS Mode, Touch sound, Sleep Mode, Safety Mode and
  Zero mileage. The screen itself offers Machine Type, RPM Detection, Safety Lock and Zeroing, plus
  read-only distance, hours and three version numbers. So **GS Mode and Touch sound are not on it at
  all**, and Sleep Mode is on the Engineering Mode screen instead. "Safety Mode" is presumably the
  Safety Lock control and "Zero mileage" the Zeroing button.
- **Engineering Mode** promises only unit and sleep mode; the screen also carries Beep Mode and
  Pause Mode.

The bike in the same console family has **seven** entries, not six, and has no A/V Source Setup.
