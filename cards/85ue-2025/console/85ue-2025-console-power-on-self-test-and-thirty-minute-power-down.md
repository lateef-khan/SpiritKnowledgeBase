**"When initially powering on the console please wait a few minutes for internal
self-test."** A slow start on this machine is normal and is not a fault. The console then goes to the
**start-up display, which is the login method page**, and *"you may now begin to use the machine
after choosing the login method"* (`85ue-2025-console-login-by-qr-code-nfc-or-pin`).

**A few minutes, not a few seconds.** Every LED Spirit console runs its self-test in seconds; this
one is a touchscreen booting an operating system, and its own manual says so. **Do not treat a
minute-long blank screen on this machine as a dead console.**

**"The console will automatically power down after 30 minutes of inactivity. Press any function key
to wake the console up again."** The function keys are the **+/-**, **START & PAUSE** and **ENTER**
keys under the screen (`85ue-2025-console-function-keys-and-the-four-viewing-modes`).

**"Always turn off the main power switch when the machine is not in use."** The switch is call-out S
on the front of the machine, beside the power socket, **not on the console**
(`85ue-2025-console-ten-inch-touch-panel-on-a-360-degree-articulating-arm`).

**The machine has a built-in universal power supply.** *"You can plug the 8.5UE into any A.C. power
source from 100 to 240 volts, 50 to 60 Hz. The A.C. input is located in the front of the 8.5UE. The
input module has an input connector for the line cord, a power switch and a 5 amp fuse."* **The
5 amp fuse is in that module**, and it is the only fuse the manual names.

**Faults arrive as a message, not a code.** *"If there is an issue, the console will show an error
message along with a possible solution. Follow the message to resolve the issue."* **The manual
prints no error code list anywhere in its 64 pages.**

**There is no software version screen on the boot display.** This paragraph prints no version number
and no odometer reading.

**Thirty minutes matches the 8.5S stepper, and neither is twenty.** The 7.0S, 7.5S and MS300 power
down after **20** minutes
(`spirit-rehab-stepper-console-power-up-and-the-twenty-minute-auto-power-down`). **Check which
machine before quoting a figure.**
