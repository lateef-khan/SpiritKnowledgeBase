**The overview page labels five things in the status bar and two buttons at the foot of the
screen:**

| Call-out | What it points at |
|---|---|
| **Log Out** | Left-hand icon |
| **Settings** | The gear icon |
| **Bluetooth Device** | The Bluetooth icon |
| **WiFi Connection** | The Wi-Fi icon |
| **Heart Rate Sensor Connection** | The heart rate icon |
| **Press Timer to start the Timer program** | The **Timer** button |
| **Press Start to begin the exercise session** | The **Start** button |

**The body of the screen is a swipeable carousel.** *"Swiping from left to right to see more and then
select the wanted item to start."* The home screen page repeats the same instruction and adds one
label the overview page does not: **User name**, showing who is signed in
(`85ue-2025-console-login-by-qr-code-nfc-or-pin`).

**Two ways to begin from this screen, and they are not the same.** **Start** begins the exercise
session as **Quick Start**; **Timer** starts the **Timer program**. **The manual explains Timer
nowhere else** - it labels the button and never says what the program does, how long it runs, or how
it is set. **Do not describe the Timer program to a customer; this book does not.**

**Every icon on this bar is a status indicator as well as a control.** The Bluetooth, Wi-Fi and heart
rate icons show what the console is connected to
(`85ue-2025-console-wifi-ble-ftms-and-ant-plus`).

**The 8.5S stepper's equivalent page carries a defect this one does not.** That book's screenshot was
photographed with a **Factory Mode** toast still on screen and its heart rate leader line lands on
the toast's dismiss button (`85s-2025-console-screen-overview-prints-a-factory-mode-banner`).
**Neither fault is on the 8.5UE page** - its five call-outs land on five icons. **The 8.5S card's
warning about that drawing does not apply here.**

**No physical key is drawn on this page.** The three function keys under the screen are described in
the operation chapter, not here (`85ue-2025-console-function-keys-and-the-four-viewing-modes`).
