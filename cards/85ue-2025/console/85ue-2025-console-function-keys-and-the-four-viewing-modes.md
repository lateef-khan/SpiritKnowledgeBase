**Three function keys, and the manual lists them in one line:**

| Key | What it does |
|---|---|
| **+ / -** (Plus / Minus) | **Adjust resistance level** |
| **START & PAUSE** | **One touch start (quick start); temporarily pauses exercise and touch start to resume** |
| **ENTER** | **Confirm each setting** |

**Everything else is on the glass.** *"All information required for operation is explained on screen.
The detailed directions on how to program the various functions will be shown on each screen of the
console display."*

**Quick Start needs a login first.** *"After the console powers up **and user is logged in** just
press the Start key to begin; this will initiate the Quick Start mode. In Quick Start the time will
count up from zero, all workout data will start to accrue and the workload may be adjusted manually
by sliding to desired number or by pressing the Up and Down keys"*
(`85ue-2025-console-login-by-qr-code-nfc-or-pin`). **Two ways to set the workload - drag the slider
on screen, or use the keys.**

**Settings holds six things**, in the manual's own list: **Beacon feature setting, language, time &
date, WiFi, Standby or Pause mode, and units of measurement.**

**The workout screen has four modes and one icon steps between them.** *"You may also switch the mode
between Status, Diagram, Symmetry, and Controls by pressing the icon."*

| Mode | What it does |
|---|---|
| **Status** | *"View the value of the current parameters"* |
| **Diagram** | *"Display the selected parameter progress chart"* |
| **Symmetry** | The left / right arm power comparison |
| **Controls** | *"Adjust the parameter"* |

**Select the parameter to display on the screen first**, then press Diagram or Controls for it.
**During the programs you can scroll through the data in the display.**

**Close Up Mode** is a separate toggle that *"changes the appearance of the screen"* - **the manual
says no more than that** and does not say what it enlarges.

**Pausing and finishing.** **Press STOP to pause or stop the exercise**; the pause screen offers
**Resume** to continue the session and **Finish** to end it. **STOP is on the screen; START & PAUSE
is the physical key** - both are described, and the manual never says whether they are the same
control.

**The 8.5S recumbent stepper prints the same screens** and its card holds the same list
(`85s-2025-console-settings-and-the-four-workout-views`); that is a **climber** card. **The 8.5S-Fit
is a different, 15.6" console laid out differently**
(`85s-fit-2026-console-workout-views-and-finishing-with-two-stop-presses`) - do not answer one from
the other.
