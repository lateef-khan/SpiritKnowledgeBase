**Five items, four of them the same sentence: check the screws regularly and tighten any that are loose.** No
interval beyond "regularly", no torque, no screw size.

| Item | As printed |
|---|---|
| 3.1 Pedal | "check the screws regularly for any loosening, and if any are loose, please tighten them" (figure 3.1.1) |
| 3.2 Circular ring | the same screw check (figure 3.2.1), **and**: "check the smoothness of the Circular Ring when it rotates. If it is too loose or too tight, simply tighten or loosen the screws accordingly (Left and Right are the same method)" (figure 3.2.2) |
| 3.3 Rail assembly | the same screw check (figure 3.3.1) |
| 3.4 Console O-ring | "check whether the Rotating Structure Assembly moves smoothly." Loosen the **four screws** on the console mast, **pull out the rotating structure assembly**, disconnect the **three connections**, and the **O-ring** can be removed (figures 3.4.1-3.4.4) |
| 3.5 Seat carriage | the same screw check (figure 3.5.1) |

**"Pedal" on this machine means the foot rest plate**, as its owner's manual calls the part; the ergometer is
arm-cranked and the circular ring of 3.2 is the hand crank's ring, whose bearing preload is set by the same
screws that hold it - too loose or too tight, adjust the screws, both sides alike.

The console O-ring step is the same four moves the 8.5R recumbent prints
(`85r-2025-maintenance-preventive-check-console-mast-bolts-and-rotating-structure-o-ring`); neither book says
what to do with the O-ring once reached beyond replacing it.

Where the intervals are: the owner's manual's schedule checks the handles for tightness and wear **monthly** and
inspects the crank arm with handles for loosening **weekly / daily**
(`85ue-2025-maintenance-machine-care-schedule`). A machine that wobbles is 7.1
(`85ue-2025-maintenance-wobble-four-adjustment-feet-and-screws`).
