*"The Steep Ramp Test is used to determine and optimize the training intensity in adults and **does
not require respiratory gas analysis measurements**. **User needs to maintain above 60 RPM as long as
possible as the resistance keeps increasing.** The test should be supervised by the therapist."*

Setup is two values, and the screen names their units:

| Setting | Unit |
|---|---|
| **Power Increment** | **watts** |
| **Stage Duration** | **seconds** |

While the test runs the screen shows the **current watt**, the **current speed in RPM**, the **stage
number**, and a prompt to keep the speed up. **A button aborts the test.**

**The test ends when the RPM drops below 60.**

*Two figures on the page disagree, and both are recorded as printed. The body text and the on-screen
coaching prompt say **60 rpm** - "Endure the longest time possible at pedaling speed over 60 rpm" -
while the warning prompt in the same screenshot reads **"Speed is below 65 rpm. Speed up or finish"**.
Which threshold the console actually uses is not stated. **These prompts are only in the picture**;
the page's text layer carries none of them, so the 65 never appears in the extracted text at all.*

**This test is not in the 8.5S stepper book, nor in any other Spirit manual carded so far.** The
Conconi Test on the facing page is a different test with a different purpose - anaerobic threshold
from heart rate, not training intensity from a ramp - and the Conconi page's screenshot is
confusingly a Steep Ramp Test screen; see
`85ue-2025-programs-conconi-test-for-the-anaerobic-threshold`.
