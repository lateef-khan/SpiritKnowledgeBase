*"The Power Distribution mode will measure the pedaling power through the cycle range and displays
the workload measurements on the screen. The screen will show a graph, workload value and **power
distribution index** indicating the upper limbs power distribution so the user has visual feedback to
improve the involved limb's strength."*

**Power Distribution answers a different question from Symmetry.** Symmetry compares the left arm
against the right; Power Distribution shows where in the crank revolution the power is produced. See
`85ue-2025-programs-symmetry-index-between-left-and-right-arm-power`.

**It is listed as one of the thirteen programs on the Programs Setup page**, but the manual describes
it on the *Finishing Your Workout* page, beside the exercise summary rather than among the program
setups.

**The manual states no scale for the power distribution index, no target value and no setup steps.**
The paragraph above is everything it prints.

*The page also states what the exercise summary does: "When the program ends, either by the set time
reaching zero or ending the program by pressing STOP at any time and then pressing Finish to end, a
summary is shown on the screen. The summary provides detailed data for the amount of time the user
exercised."*
