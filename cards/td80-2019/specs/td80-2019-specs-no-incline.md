**The TD80-2019 desk treadmill has no incline.** Its book prints no incline keys, no incline range and no elevation step anywhere: the console photograph shows MUTE, STRIDE LENGTH, FAST / MEDIUM / SLOW direct keys and DISPLAY / START / ENTER / STOP / SLOW / FAST keys only; START OPERATION adjusts speed with the SPEED keys alone; calibration sets minimum and maximum speed with no elevation step.

The only "elevation" in the book is the power-cord boilerplate ("Route the power cord away from any moving part of the treadmill including the elevation mechanism"), shared word for word with the incline-bearing books. The Xterra walking treadmill is likewise flat (`ws200-2023-specs-no-incline`).
