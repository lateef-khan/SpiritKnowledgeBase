**DIRECT SPEED KEYS**: 3 presets, **1 kph/1 mph, 2 kph/2 mph, 3 kph/3 mph** - press one at any time to start the treadmill, which adjusts to that speed by itself.

**OPERATION (MANUAL)**: 1. Fit the key, press any button to wake up. 2. Press **START**: a **3-second countdown with a short beep** runs first, then adjust with SPEED up/down anytime. 3. Press **ENTER** to view speed, time, distance, calories or **scan** (rotates every 5 seconds). 4. **STOP** (or pull the key) stops; **START** resumes with all previous data kept. 5. After training, **DISPLAY** shows the accumulated speed/time/distance/calories; START begins again.

**SETTING STRIDE LENGTH (S.L.)**: feeds the step count. Pick from height or measure toe-to-toe in cm; adjustable **30-99 cm** to taste. Chart: 155 cm (5')-38, 160 (5'3")-40, 165 (5'5")-43, 170 (5'7")-45, 175 (5'9")-46, 180 (5'11")-47, 185 (6')-49, 190 (6'2")-50, 195 (6'5")-52.
