**The only A2 calibration that checks the wheel size and has no grade-return step.**

1. Remove the safety key.
2. Press and hold **Start and Fast**, replace the safety key, then press **Enter**.
3. Set **miles or km** and check the **wheel size** with the **Fast/Slow key**, then press Enter.
4. Minimum speed (if needed): **0.8 kph / 0.5 mph**. Press Enter.
5. Maximum speed (if needed): **6.0 kph / 4.0 mph** (maximum speed; the line ends there).
6. Press **Start**. The process is automatic; the speed starts up without warning, so do not stand on the belt.

The book continues with speed-sensor alignment if calibration does not pass (maintenance/errors territory). No engineering or maintenance menu is printed anywhere in this book.
