**Pause differs from every other book**: STOP once slows the belt to a stop and holds Time/Distance/Calorie; after **five minutes** the display resets to start-up. START resumes with **speed only** (there is no incline). A **second** STOP ends the program (no summary is printed); a **third** resets the console. No 3-second hold reset is printed.

**TO TURN OFF AUDIBLE BEEP**: press the **MUTE button, top left of the console** (no Key Tone menu exists).

| Window | Range |
|---|---|
| SCAN | each parameter shows **5 seconds** in turn |
| SPEED | **0.8-6.0 KPH (0.5-4.0 MPH)** |
| TIME | **00:00 to 99:59** |
| STEP | **0 to 9999** steps |
| DISTANCE | **0.00 to 99.99** km (miles) |
| CALORIES | max **999.9** (rough guide only, not medical) |

**ENTER**: sets countdown parameters; with the belt stopped, **hold 3 seconds to reset all accumulated data**; confirms stride length. **START**: begins training. **STOP**: stops training. **FAST/SLOW**: **0.1 KPH (0.1 MPH)** per press. **STRIDE LENGTH**: one-step length, **30-99 cm**. **DISPLAY**: shows time, distance and other info. **SAFETY KEY**: powers the computer; pulling it shuts everything down.
