The Calories program counts down to a calorie target you set. **It is the only program on this
machine whose duration the console works out for you.**

1. Press the **Calories** key, then **Enter**. The display prompts you through the programming.
2. The Message Center blinks your **Age (default is 35)**. Level Up/Down adjusts, then Enter.
3. It blinks your **Body Weight (default is 100)**. Adjust, then Enter.
4. It displays "Use Level Up or Down keys to adjust Calorie burn" - **default is 300**. Adjust, then
   Enter.
5. It blinks the preset **average pedal RPM - default is 50**. Adjust, then Enter.
6. It blinks the preset **top resistance of the selected program - default is Level 5**. Adjust, then
   Enter. Each program has resistance changes throughout; this caps the highest the program can reach.
7. It displays the **Program Time**, a value calculated from what you entered in steps 3-6. Press
   **Start** to accept it, or **Enter** to go back to steps 4-6 and change the data, which
   recalculates the Program Time.

How the workout then runs:

- Pressing Start begins a **3:00 warm up** - 1:00 @ Level 1, 1:00 @ Level 2, 1:00 @ Level 3 - or press
  **Enter** again to bypass it.
- **Both the Calorie and Time windows count down to 0.** If the Time expires before the calories reach
  0, the Time window begins accumulating time until the Calories reach 0.
- After the program ends there is a **3:00 cool down** - 1:00 @ Level 3, 1:00 @ Level 2, 1:00 @ Level
  1 - or press **Enter** to end the workout.

*The manual contradicts itself on the body weight default. Step 3 of this program prints **100**;
step 3 of the Fusion program in the same manual prints **150 lbs**. Both are printed as shown.*

**This is not the treadmill Calorie program.** The Spirit XT485 and XT685 version asks for a top
speed and a top incline and warms up at 1, 2 and 3 mph - see
`xt-2015-programs-calorie-program-setup-xt485-xt685`. **The XE395 2023 and XE795 2023 replaced this
with a Target Calories program** that simply counts a calorie total down, with none of the above.

**The XE795 2018 printing (printed page 23) prints these seven steps and every figure above** - age
35, body weight 100, calorie burn 300, average pedal RPM 50, top resistance Level 5, the 3:00 warm up
at Levels 1, 2 and 3 and the 3:00 cool down at Levels 3, 2 and 1. It carries the same body-weight
contradiction with its own Fusion page, which prints 150 lbs.
