1. Under normal use the console screen will display. If there is no display, first check the **power adapter** to make sure it is in the correct position. Check all connectors, including those in the console, on the controller and the wire harness, are connected properly.
2. Check that all the wires are inserted firmly and securely into the console.
3. Remove the console cover and the left and right chain covers. Check that all wires are inserted in the correct positions and check whether any wires are broken.

**This manual has no fuse replacement section.** Where the 2019 Sole elliptical manuals send you to a 5A fuse on the motor controller, this one names the transformer instead: the tension motor voltage test step 5 says to check the transformer and replace it if there is no output.
