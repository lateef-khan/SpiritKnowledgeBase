**This is E1, not E2 (tension motor). This machine has only two error codes.**

Definition: all screens are off and outputs stop when the EEPROM is damaged or malfunctions. The display message shows **"E-1"**.

Troubleshooting: **replace the upper controller.** The manual gives no other step for E1.

The error table prints the meaning as "EEPROM failure", and prints the code as **E1** while the section heading and the definition print it as **E-1**.

**There is no E3 on this machine.** The error code table lists only E1 and E2, and the table of contents lists only 8.1 and 8.2. The 2019 Sole ellipticals all carry an E3 for the incline or stride VR; this machine has no incline or stride motor.
