1. First remove chain covers (R) and (L).
2. Use a **10 m/m wrench** to release the **M6 x 6T nyloc nut** on the **M6 x 45L eye bolt**.
3. Use a **#12 open end combination spanner wrench** to remove the **hex head bolt 5/16" x 3/4"** and **flat washer 5/16" x 23 x 1.5T** securing the right swing arm assembly.
4. Remove the **5/16" x 3/4" hex head bolt** and **5/16" x 23 x 3T flat washer** which fix the pedal assembly set and the swing axis.
5. Separate the base of the swing axis and the pedal assembly set, then remove the handle bar axle.
6. Use a **12mm wrench** to remove the **5/16" x 3/4" hex head bolt** and **8.5 x 26 x 2T flat washer** which fix the handle bar assembly set and the main frame, then separate them.
7. Reassemble in the reverse order. **When replacing the swing axis, the plane must be connected with the U-slot gap plane in alignment before the screw is locked.**

Note the source's cross reference: step 1 says "Refer to step 11.2" but the side case procedure in this manual is section 9-2. There is no section 11.2.
