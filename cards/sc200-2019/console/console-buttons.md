The program buttons are Manual, Hill, Fat Burn, Cardio, Strength, HIIT, 2User and 2HR. There is a separate Fan key for the cooling fan.

**READY MODE**
- STOP: pressing STOP for 3 seconds restarts the console.
- START: starts the machine.
- LEVEL UP / LEVEL DOWN: non-functional.
- DISPLAY: non-functional.
- FAN: controls fan ON/OFF.
- ENTER: enters parameter setting, and confirms or modifies a parameter.
- **BLUETOOTH: toggles between Bluetooth APP mode and hand pulse mode.**

**RUN MODE**
- STOP: press once to stop; **press twice to finish sport mode; press three times to return to standby mode**.
- START: pause mode. **Press START within 5 minutes to return to sport mode.**
- ENTER: non-functional.
- LEVEL UP / LEVEL DOWN: each press changes level by 1.
- FAN: controls fan ON/OFF.
- DISPLAY: switches the exercise data during a workout. If the information shown is the latest data, pressing DISPLAY lights the SCAN icon and the message window auto displays every four seconds on a recycle.
- BLUETOOTH: non-functional.

Note the source wording: the READY and RUN mode descriptions say "start bike" and "stop bike", carried over from the Sole bike manual.
