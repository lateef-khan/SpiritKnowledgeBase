**IDLE MODE** - after entering the age, the message window shows MANUAL flashing, indicating the program currently selected; other information is shown as the initial value.

**DISPLAY MODE** - with the setting "ON" the console will not enter sleep mode unless the power is turned off. With no RPM input in idle mode the console enters sleep mode after **30 minutes** without a key press. In display mode the LCD shows nothing and the backlight is off; press any key to wake it. Resistance in sleep mode: Incline = 1, fan off. (The manual prints "Incline = 1" even though this machine has no incline.)

**CHILD LOCK MODE** - pre-set is CHILD LOCK OFF; set it in Engineering Mode. The message window shows "CONSOLE LOCKED", then "CHILD LOCK-ON PRESS START AND ENTER TO ENABLE OPERATION". Turn it off by **pressing START and ENTER for more than two seconds**.

**EXERCISE MODE (QUICK START)** - from idle, press START to enter manual mode. Age and weight are preset values, time counts up from 00:00, all countable data counts up from 0 and resistance counts up from 1.

**PAUSE MODE** - press STOP. Exercise parameters are recorded, the window shows "PAUSE", the upper window shows the recorded parameters and **resistance returns to LEVEL 1**. The tension motor returns to its previous level when START is pressed.

**END MODE** - the console sounds **three short beeps, eight times**, when the program finishes. The dot matrix shows "STOP" and the message window shows the end-of-motion message. Pressing START at that point starts another workout with the previous settings. When the end display has finished, the system enters idle mode.

**BLUETOOTH MODE** - when the console connects to the app, **"BLE APP" lights up** in the console. When the workout summary data is uploaded, **SYNC is lit**.

**RESET MODE** - in idle, hold STOP for **more than three seconds**. All screens are cleared, the console restarts and goes to the user selection.
