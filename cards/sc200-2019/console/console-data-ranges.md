| Reading | Display range | Work range | Notes |
|---|---|---|---|
| SPM | 0 to 99.9 | 0~99.9 | the manual describes it as "the current speed in mile per minute" |
| TIME | 0:00 to 99:99 | 0:00 to 99:59 | count down setup range 10:00 to 99:00; when TIME is set the timer counts down to zero |
| TOTAL STEPS | 0 to 99999 | 0 to 99999 | "the current distance in steps" |
| CALORIES | 0.0 to 999.9 | 0.0 to 999.9 | cumulative |
| RESISTANCE LEVEL | 0 to 99.9 | 1 to 20 | current level position |
| PULSE | 0 to 999 | 40 to 220 BPM | hand pulse or chest belt receiver |

**Note on SPM.** The manual defines it as "speed in mile per minute". On a climber SPM normally means steps per minute, and the same table already has TOTAL STEPS in steps. The definition is reproduced exactly as printed; treat the unit as unconfirmed.

There is no incline, stride, distance in miles or laps reading on this console.
