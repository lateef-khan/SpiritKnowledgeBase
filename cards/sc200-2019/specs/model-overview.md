The manual's cover code is **XS110B-YS007**. Section 1 is titled "XS110B-YS007 Outlines".

**The manual describes this machine as a climber.** Section 3 reads "CONSOLE: Interface that controls all functions of the Climber", the block diagram page is headed "CLIMBER Configuration" and the wiring diagram is headed "CLIMBER CIRCUIT DIAGRAM". The troubleshooting matrix rows also say climber.

**But sections 7 and 4 call it a bike.** The whole of section 7, Product Safety Instructions, is written about "your bike", and the READY MODE and RUN MODE button descriptions say "Pressing START button to start bike" and "press STOP button to stop bike". These are the fixed phrases carried over from the Sole bike manual. Nothing in the manual describes a bike seat or pedals of a bike.

The machine has a console with a **7.5" LCD display**, a **tension motor** that changes brake resistance, a speed sensor, a flywheel with a drive belt and idler wheel, connecting arms, linked assemblies, a curved rail tube and a crank arm. There is no incline motor and no incline or stride adjustment; **the manual carries no calibration procedure.**

The parts drawings name: console assembly, console holder assembly, console mast and mast covers, handle bar covers, chain covers L and R, pedals L and R, rear shroud, slide wheel cover, stabilizer covers; console mast, left and right upper handgrips, drive pulley, crank arm, idler wheel assembly, curved rail tube, flywheel, connecting arms L and R, main frame, rear stabilizer with handle and linked assemblies L and R.
