**This is the menu as the XU878 service manual prints it. The owner's manual prints a different one
for the same machine** - see the end of this card.

**Press and hold Start, Stop and Enter for about 5 seconds.** The Message Window displays
**"Engineering Mode"**. Press **Enter** to open the menu; the **Level ▲/▼** keys move through it.

| Item | What the manual says |
|---|---|
| **A. Key Test** | Test all the keys to make sure they are functioning |
| **B. Display Test** | Automatically tests all LCD's |
| **C. Functions** | Press Enter to access settings, use Level ▲/▼ keys to scroll |
| **D. Security** | Locks the keypad so no unauthorized use of the machine is allowed. **When the child lock is enabled, the console will not allow the keypad to operate unless you press and hold the Start and Enter buttons for 3 seconds to unlock the console.** |

**Inside Functions, in the printed order:**

1. **Sleep Mode** - "Turn off to have the console power down automatically after **30 minutes** of
   inactivity"
2. **Pause Mode** - turn on to allow **5 minutes** of pause, turn off to have the console pause
   indefinitely
3. **ODO Reset** - resets the odometer
4. **Units** - choose from English or Metric display readings
5. **BEEP MODE** - ON/OFF
6. **DA TEST** - for testing the DA function
7. **ELLIPTICAL / BIKE** - no description printed

**The owner's manual for this bike prints a different menu.** It lists Key Test, Security,
Functions and Display Test in that order, a **20-minute** sleep, and a Security lock opened by
pressing **Level Up then Enter** rather than holding Start and Enter
(`ce800-2013-console-engineering-mode-elliptical-or-bike`). The seven Functions entries are the same
seven settings in a different order, and the service manual gives Security a description the owner's
manual does not. **Nothing in either document resolves the 20 or 30 minutes**; read the console.

**The Sleep Mode line says "turn off" to power down**, the reverse of what the setting's name
suggests. The 2016 XBR25 and XBU55 service manuals print the same setting the other way round -
turn on to power down (`spirit-xbr-2016-console-maintenance-menu-20-minute-sleep-described-motor-test-and-safety`)
- and nothing in this book's software-spec chapter, which has no sleep paragraph, settles it.

**The three-second Start-and-Enter unlock is printed twice in this book**, here and in the Child
Lock Mode paragraph of the software spec, which times it at two seconds. Same keys, two figures.
