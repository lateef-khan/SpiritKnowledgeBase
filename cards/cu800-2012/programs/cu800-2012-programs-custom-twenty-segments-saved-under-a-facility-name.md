The Custom Program builds and saves a workout, and can be **personalised with your facility name**.

1. Press the **Custom** key. The message window shows a welcome message - or the name you previously
   saved. Press **Enter** to begin programming.
2. The window shows `Name - A` if no name is stored, or `Name - <saved name>` with the first letter
   blinking. Up and Down change the letter, Enter accepts it and moves on. Press **Stop** to keep an
   existing name, or to finish entering a new one.
3. Enter your **Age**, then Enter.
4. Enter your **Weight**, then Enter.
5. Enter the **Time**, then Enter.
6. Enter the **Max Level** - the peak exertion level - then Enter.
7. The first column blinks. Set the level for the first segment, then Enter.
8. Each next segment starts at the level of the one before. Repeat until **all twenty segments**
   have been set.
9. Press **Enter to save**. The window says **"New program saved"** and offers to start or modify
   the program. Stop exits to the start-up screen.
10. **Up or Down during a Custom workout affects only the current column.** When the profile moves to
    the next column it returns to the preset work level. This is the opposite of a preset program,
    where Up or Down shifts the whole profile.
11. During the **User 1 or User 2** program you may scroll the data with the adjacent Display key,
    switch the matrix between profile and quarter-mile track with the other Display key, use the
    heart rate monitoring features, and switch to heart rate **Auto-Pilot** mode.

**Any preset workout can be saved as a custom program**, but the manual names two different keys for
it. The Manual program's step 8 says to press the **Custom** key; the HRC program's step 10 says to
press a **User** key. Both scans print it that way.

**The manual calls the same feature three names** - "Custom", "Custom User Defined Programs" and
"User 1 / User 2" - without saying whether there are one or two storage slots or how a User key maps
to the Custom key. Both scans of the manual print it the same way.

**The later LED 800 consoles store twenty-four segments and cap the name at seven characters** - see
`spirit-bike-programs-custom-twenty-four-segments-and-a-seven-character-name`.
