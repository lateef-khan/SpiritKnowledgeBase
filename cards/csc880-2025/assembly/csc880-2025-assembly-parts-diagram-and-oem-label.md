Eleven call-outs, as printed:

| Letter | Part |
|---|---|
| A | Console |
| B | Pulse Sensors |
| C | Accessory Pocket |
| D | Safety Key |
| E | Handlebars |
| F | Console Mast |
| G | Main Frame |
| H | Steps |
| I | Step Up |
| J | **Leveler** |
| K | Safety-Stop Sensor |

## The page carries an untranslated OEM model line

Printed above the heading, in the top left corner of the page:

```
CLE450S-3A1楼梯机
```

**楼梯机 is Chinese for "stair machine".** `CLE450S-3A1` is the original equipment
manufacturer's model number for this machine; it appears nowhere else in the manual, and
the book never explains it. Spirit's own name for the machine, CSC880, is on the cover
and in the title of every other chapter.

**This is a source defect, not a second model.** Do not treat CLE450S-3A1 as a Spirit
model id, and do not report it to a customer as their machine's model number. It is a
line the translator missed on one page.

## Callout J is the only place the word Leveler appears in the book

No step of the four-step build fits a leveller, no page says how many there are, where
they sit, what size wrench turns one or how to adjust it. **The whole 44-page manual
never says how to level the machine**, and never says how to move it either. That is
true of every Spirit stair climber manual in the repository. See
[the absence card](../../csc900-2024/assembly/csc900-2024-assembly-no-levelling-or-moving-instruction.md).

## Callout D is a safety key, and the CSC900 has a tether cord

The CSC900 stair climbers describe a **safety tether cord** with a clip that fastens to
your clothing. This diagram labels a **Safety Key**. The two are not the same part and
the CSC880 book prints no tether-cord instructions.

## What the diagram does not label

No transport wheel, no power inlet and no water bottle holder. The power input location
is drawn on the QUICK START page instead, five pages later.
