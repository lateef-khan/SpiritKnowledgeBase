**The owner's manual has the bolt sizes; this page has the cable identities.** Nothing here names a fastener.

**Install the columns.** (1) Install the columns in the positions shown. (2) Connect the wiring harnesses.
(3) Organize the harness to prevent wire jamming - *when installing the column, pull the communication cable
upward at the same time* so it is not trapped. (4) Install the bottom fixing bolts.

**Install the handrails.** (1) Insert the upper end of the handrail into the hole on the frame. (2) Insert the
small handrails at the top into the holes at the same time, align the bolt holes and secure the bolts.
(3) Install the fixing bolts at the bottom of the handrail. (4) After securing the bottom bolts, tighten the
bolts on top. (5) Install the other side the same way.

**Install the console.** (1) Thread the wiring harness through the hole at the rear of the console. (2) Align the
fixed holes on the console with the mounting holes on the frame and install the bolts. (3) Connect the wiring
harness. (4) Organize the harness and secure it to the clip. (4, again in the book) Push down from the top to
install the back cover of the console. (5) Secure the back cover screws.

**The five console cables**, as the photographs label them:

| Cable | Where |
|---|---|
| Handle pulse cable | left side of the console board |
| Right handle cable | **white** |
| Left handle cable | **red** |
| Communication cable | **5PIN** |
| Emergency stop switch cable | **4PIN** |

The console numbers its steps 1, 2, 3, 4, 4, 5. The page is photographs with drawn captions; the OCR
supplement has only fragments, so the sequence above was read from a render. The owner's-manual build (four
steps with M10 and M8 sizes) is the other card; the unboxing that precedes this page is on its own card.
