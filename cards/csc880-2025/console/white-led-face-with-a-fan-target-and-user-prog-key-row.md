**White, not Blue.** The drawing's top call-out reads **"Premium, ultra-bright White LED
display"**. Every CSC900 printing - 2019, 2021 and 2024 - calls the same call-out **Blue**
(`csc900-2024-console-screen-overview`). It is the quickest way to tell the two consoles apart in a
photograph.

**The drawing labels the same five things the CSC900 drawing does:**

| Call-out | What the manual says about it |
|---|---|
| **Premium, ultra-bright White LED display** | The four data windows across the top |
| **Large LED Matrix window** | "to track workout progress" |
| **Program Direct Keys** | Down the left of the keypad |
| **Resistance level display window** | Its own window |
| **Workout Results Key** | Below the program keys |

**What this drawing adds is a labelled key row**, printed under the resistance level window and
repeated on printed p. 16 and p. 18:

**`RESULTS` · `FAN` · `LEVEL` · `TARGET` · `USER PROG`**

**That is the first Spirit stair climber drawing to name a FAN key.** The fan itself is described in
the same words in all four books (`csc900-2024-console-two-speed-fan`), but only this one shows you
where the button is. **TARGET** and **USER PROG** are labelled here and explained nowhere in the
console chapter.

**The manual never says what the Workout Results Key does** - the same silence as in every CSC900
printing.

**The drawing names no USB port, no water bottle holder, no tether socket and no heart rate grip**,
although the book describes a safety tether cord, hand pulse sensors and Safety-Stop Sensors
elsewhere. **Do not read a port onto this console that the book never names.**

**The program key legends on the drawing read FAT BURNING, HILL, CHALLENGE and INTERVAL**, read from
the OCR of the flattened page; the CSC900-2021 drawing prints FITNESS TESTS, FAT BURNING, TRAINING,
ROLLING HILLS, CHALLENGE and INTERVAL. Which programs each machine has is a programs question, not a
console one.
