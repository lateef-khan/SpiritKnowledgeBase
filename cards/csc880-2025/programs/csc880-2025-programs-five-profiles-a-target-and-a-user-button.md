**Eight program keys.** Six sit in the **Program Direct Keys** block - FITNESS TEST, FAT BURNING,
TRAINING, ROLLING HILL, CHALLENGE and INTERVAL - and two more, TARGET and USER PROG, sit on the
bottom row beside RESULTS, FAN and the LEVEL rocker.

- **FITNESS TEST** - **the manual describes no test of any kind.** See below.
- **FAT BURNING** - keeps the user at low to moderate intensity for a prolonged workout. Aerobic
  endurance.
- **TRAINING** - gradually ramps intensity up to a level for steady state exercise. Aerobic
  endurance.
- **ROLLING HILL** - segments of medium and medium-high intervals. Aerobic capacity.
- **CHALLENGE** - a prolonged gradual warm-up, then sustained training at higher intensity.
  Introduces anaerobic training within an aerobic workout.
- **INTERVAL** - high intensity anaerobic sprints alternating with low intensity recovery. Anaerobic
  capacity.
- **TARGET** - Target Training, with Time, Vertical Distance or Calories as the goal.
- **USER PROG** - build your own across all 24 segments of the dot matrix display.

**The FITNESS TEST key sits in the top-left corner of the Program Direct Keys block, where the
CSC900's five profile keys begin, and the manual says nothing whatever about it.** A loose search of
the whole book for "WFI", "CPAT", "VO2", "fitness test" and "protocol" returns **zero hits of each**;
the contents page runs `Programs 22` straight to `Machine Care 31`; and every printed page from 21 to
30 was checked for native word count, so no fitness-test chapter is hidden behind a flat image. The
key exists on the overlay; the documentation for it does not. **Do not answer a CSC880 fitness-test
question from the CSC900's WFI or CPAT card** - see `csc900-2024-programs-wfi-stairclimber-protocol`
and `csc900-2024-programs-cpat-stairclimber-protocol`. Those figures belong to a different console
and no CSC880 source confirms them.

The five profile descriptions are word for word the CSC900's. The setup, the Target ranges and the User
Program are the CSC900's too - see
`csc900-2024-programs-preset-setup-defaults-of-age-thirty-five-and-thirty-minutes`,
`csc900-2024-programs-target-training-goals-and-ranges` and
`csc900-2024-programs-user-program-of-twenty-four-segments`.

**What this machine does not have:**

- **No printed WFI or CPAT protocol**, despite the FITNESS TEST key - see above.
- **No Manual program and no HIIT.**
- **No heart rate control program**, although the manual says there is one - see
  `csc880-2025-programs-heart-rate-control-program-named-but-not-present`.

*The key strip was read from a 200 dpi render of the console overview page (printed p. 20, PDF p.
22), which is a flat illustration: `pdftotext` returns 34 words from that page - the four callout
labels and the caution text - and **no key names at all**. The extraction alone would have made this
look like a five-profile console with no fitness test. The keys are labelled **ROLLING HILL**
(singular) on the overlay and **ROLLING HILLS** in the program chapter; both are recorded as
printed.*

Unlike all three CSC900 printings, **this manual does print a heart rate training page and an RPE
scale** - see `csc880-2025-programs-target-zone-of-111-to-157-beats` and
`ct900-rate-of-perceived-exertion-rpe`.
