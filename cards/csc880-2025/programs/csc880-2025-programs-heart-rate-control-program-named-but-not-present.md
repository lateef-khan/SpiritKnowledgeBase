**No. The console has eight program keys and none of them is a heart rate program.** The keys are
FITNESS TEST, FAT BURNING, TRAINING, ROLLING HILL, CHALLENGE, INTERVAL, TARGET and USER PROG - see
`csc880-2025-programs-five-profiles-a-target-and-a-user-button`.

**Two sentences in the manual say otherwise, and both are carried-over boilerplate:**

- Printed page 21, Programming the Console: *"Your Age is also necessary during the Heart Rate
  control program to ensure the correct settings are in the program for your Age. Otherwise the work
  settings could be too high or low for you."*
- Printed page 29, Heart Rate Exertion: *"With all Heart Rate program you may use the heart rate
  monitor feature without using the Heart Rate program. This function can be used during manual mode
  or during any of the nine different programs."*

**This console has no manual mode either, and eight keys rather than nine programs.** Both
sentences appear word for word in Spirit stepper and elliptical manuals for machines that do have a
Heart Rate program key, and they were not edited when the page was reused here. The eighth key,
FITNESS TEST, is undocumented in its own right - see
`csc880-2025-programs-five-profiles-a-target-and-a-user-button`.

What the age entry actually does on this machine is drive the calorie and heart-rate-percentage
readouts. Entering it is still worth doing; it just does not select a program.

*The console key strip was read from a 300 dpi render of the console overview page, which is a
photograph. `pdftotext` returns only the callout labels from it, so the key list cannot be confirmed
from the extraction alone.*
