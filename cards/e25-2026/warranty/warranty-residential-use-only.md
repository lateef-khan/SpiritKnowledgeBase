**This elliptical is intended for residential use only and is warranted for that application. Any other application voids this warranty in its entirety.**

The exclusions restate it: **product use in any environment other than a residential setting** is not covered. The warranty preamble adds that it "applies only to products in ordinary household use".

The manual draws no distinction between commercial, light-commercial and institutional use - anything that is not a residential setting is outside the warranty.
