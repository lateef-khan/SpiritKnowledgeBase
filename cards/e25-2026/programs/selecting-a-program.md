1. Use the **Program key** to select the program (P1~6, U1~2, H1~2).
2. Press the **Enter key** to select a program and begin customizing the settings.
3. To work out **without** entering new settings, just press the **Start key**. This bypasses the programming of data and takes you directly to the start of the workout.

**If you start a program without changing the settings, the default settings are used.**

While entering data, the **Stop key** is a Previous Screen function and steps back one level of the programming screen each time it is pressed.
