After the startup self-test the dot matrix display appears in the **Time and Distance windows**, and the program numbers **P1/P2/P3/P4/P5/P6/U1/U2/H1/H2** are displayed in the **Incline window**. Press the Program key to move through them.

| Program | What it is |
|---|---|
| P1 | Manual - you control the workload, not the computer |
| P2 | Hill |
| P3 | Fat Burn |
| P4 | Cardio |
| P5 | Strength |
| P6 | Interval |
| U1, U2 | Custom user defined programs you build and save |
| H1, H2 | Heart rate programs; H1 defaults to 60%, H2 to 80% of maximum heart rate |

Quick Start is not in this list: pressing Start straight after power up begins a Quick Start workout with the time counting up from zero.

**The manual's own program count is inconsistent.** Ten program slots are listed here and on page 15, and page 20 correctly calls P2 to P6 "five different programs", but page 23 says the heart rate monitor feature can be used "during manual mode or during any of the **nine** different programs". No winner is picked; the printed program list on page 15 names ten slots.
