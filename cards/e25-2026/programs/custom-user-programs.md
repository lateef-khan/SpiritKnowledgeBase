The two customizable User programs let you build and save your own workout.

1. Select the User program (**U1** or **U2**) and press **Enter**. If a program has already been saved to that slot it is displayed and you are ready to begin. If not, **LEVEL and INCLINE display 1**.
2. The Time window asks for your **Age**. Enter it with the **Level +/-** keys, then press **Enter**.
3. You are asked for your **Weight**. Adjust it with the **Level +/-** keys, then press **Enter**.
4. Next is **Time**. Adjust it with the **Level +/-** keys and press **Enter**.
5. You are asked to set the **level for the first segment**. The Distance window displays **[1-18] segments**. Press **Level +/-** and then **Enter** to move to the next segment. Repeat until **all eighteen segments** are set, then press **Enter** to move on to the incline.
6. Set the **incline for the first segment**, following the same procedure as the level profile. Press **Start** to begin the workout.
7. Press **Level +/-** at any time during the program to raise or lower the level.
8. Press **Incline +/-** at any time during the program to raise or lower the incline. **This affects only the incline of the current segment.** When the program moves to the next segment the incline returns to the set segment number.
9. Each press of the **Display** button shows the next set of information.
10. When the program ends the Message window shows a **summary of your workout**, displayed for a short time before the console returns to the start-up display.
