The cover reads **E25(2026)** and the factory code is **SE668SA-SE052**. The circuit diagram sheet is headed "SE668SA-SE052 ELLIPICAL CIRCUIT DIAGRAM" (the word ELLIPTICAL is misspelled on that sheet) and names the console **SE668SA**.

This is the Sole E25 of model year 2026. **No Spirit database SKU has been matched to this manual**, so do not quote a six digit model number for it.

Section 3 lists four electrical assemblies:

| Part | What it does |
|---|---|
| Console | Interface that controls all functions of the elliptical. Contains key controls and an **LED** display. |
| Main Controller | Carries the DC power supply for the console, the incline driver and the tension motor driver. Links the console so it outputs the appropriate voltages for the tension motor. |
| Tension Motor | Increases or decreases the resistance level of the brake. |
| Incline Motor | An AC motor. The user controls variable elevation from the console through the main controller. |
