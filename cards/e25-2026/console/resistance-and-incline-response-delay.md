This is normal behaviour, not a fault.

**Changes in resistance and incline do not occur immediately.** Set the desired resistance level on the computer console and release the adjustment key. **The computer will obey the command gradually.**

If the incline never reaches the commanded position, or the display and the ramp disagree, that is a different problem - see the incline cards.
