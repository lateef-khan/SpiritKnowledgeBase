**START key.** The quickest way to start a workout. After the console powers up, press Start to begin; this is Start key mode. Time counts up from zero. Resistance level and incline are adjusted by hand with the **Level +/-** and **Incline +/-** buttons.

**STOP key.** It has several jobs.

- Pressed **once** during a program it **pauses for 5 minutes**. Press Start to resume.
- Pressed **twice** during a workout the program ends and a **Workout Summary** is displayed.
- **Held for 3 seconds** the console performs a complete **Reset**.
- During data entry for a program it is **Previous Screen**, stepping back one stage each press.

**DISPLAY/ENTER key.** Each press shows the next set of information.

- **Display combo 1** - Time, Distance, INCLINE, Level.
- **Display combo 2** - PACE, WATT, Calories, PULSE.
- In **Data Scan** mode the displayed information changes **every 4 seconds** in the Message Window.

**Other keys named on the button drawing.** PROGRAM key, MODE / ENTER key, the CONTROL keys, and the **Fan key**, which switches the cooling fan on or off.
