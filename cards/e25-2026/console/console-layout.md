The control panel drawing labels these items. The four display windows are shared, each one carrying two readouts:

| Window | Shows |
|---|---|
| Upper left | Time, PACE |
| Upper right | Distance, WATT |
| Lower left | Incline, Calories |
| Lower right | Level, Pulse |

Also labelled on the panel: a **cooling fan**, a separate **fan power switch**, the **Program** key, the **Display/Enter** key, a **speaker**, and a **tablet holder** above the console.

The drawing's leader lines did not survive the text extraction, so the labels above are given in the order printed. Which physical spot each label points to is not recoverable from the text; the pairing of readouts per window is printed as text and is reliable.

What each key does is on the console keys card; the Type-C charging port on the console has its own card.
