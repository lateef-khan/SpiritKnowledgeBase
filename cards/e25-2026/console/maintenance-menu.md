Press and hold **Start, Stop and Enter together for 3 seconds**. The time window displays **[F1]**. Press the **Program key** to move through F1 to F13, and press **Enter** to open an item.

| Item | Name | What it does |
|---|---|---|
| F1 | Key Test | Tests all the keys to make sure they are functioning. |
| F2 | Display Test | Automatically tests all LEDs. |
| F3 | ODO Reset | Resets the odometer. |
| F4 | Units | English (Imperial) or Metric. **0: Metric / 1: English**. |
| F5 | Sleep Mode | Console powers down automatically after 15 minutes of inactivity. 0: OFF / 1: ON. |
| F6 | Pause Mode | On allows 5 minutes of pause; off pauses indefinitely. 0: OFF / 1: ON. |
| F7 | Key Tone | Beep when a key is pressed. 0: OFF / 1: ON. |
| F8 | Grade Return | Incline returns to home position when pause is pressed. 0: OFF / 1: ON. |
| F9 | Factory Set | - |
| F10 | Light Mode | Adjusts display brightness. |
| F11 | Motor Test | Continually runs the tensioning gear motor. |
| F12 | Manual | Allows stepping of the gear motor. |
| F13 | Security | Locks the keypad. With the child lock enabled the keypad will not operate unless you **press and hold Start and Enter for 3 seconds**. |
| End | Exit | Leaves the maintenance menu. |

The console software also built the maintenance menu to change readings from English to Metric and to silence the key beep; those are F4 and F7.
