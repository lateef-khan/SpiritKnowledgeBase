If there is a problem with the incline, try running the calibration.

**Press the Start key and the FAN key at the same time and hold them down for 3 seconds.** The incline calibration starts and runs automatically.

If the problem persists, contact the service department.

Calibration is the step the E3 troubleshooting tables and the troubleshooting matrix both send you back to.

**This key combination changed.** The 2019 E25 used the Incline UP key and the Start key held for 5 seconds. On this machine it is Start plus Fan for 3 seconds.
