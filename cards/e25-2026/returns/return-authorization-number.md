**DO NOT SHIP ANY UNIT TO THE FACTORY WITHOUT A RETURN AUTHORIZATION NUMBER. All units arriving without a return authorization number will be refused.**

The owner is responsible for adequate packaging on return and for transportation costs in both directions, and SOLE is not responsible for damage that occurs during shipping.

The manual also asks you, twice, to **call SOLE first before returning the product to any retailer**, or if you need any assistance with assembly or technical support.
