**This is the SR400's E-2, an owner-level cable check. It is not the SR500's E2 motor error (cable-tensioner communication, all functions stopped) and not the SR550's E2 gear-motor failure (motor does not move on Level Up/Down).** Same code letters, different books, different depth: the SR400 book prints one line and no motor diagnosis.

The book's Remark 1 under Recovery Mode, quoted whole: "If console display E-2, pls check if cables were well connected or damaged."

That is the entire E-2 remedy the book prints. It names no part, no voltage test and no reset sequence. The two neighbouring remarks on the same page (RF battery pairing time, power-saving mode) are console behaviour, not error remedies.
