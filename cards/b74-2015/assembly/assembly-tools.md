| Item | Tool |
|---|---|
| #43 | Combination 5mm Allen Wrench & Phillips Head Screw Driver |
| #79 | 13/15mm Wrench |
| #87 | L Allen Wrench |
| #106 | 14/15mm Wrench |

**The R72 half of the same manual ships a different set** (#140, #141, #142) and re-uses some of these numbers for hardware: in the R72 checklist **#87 is a 5/16" flat washer**, not the L Allen wrench. Never carry a B74 item number into the R72 section.

**Tool item numbers are not shared between models.** The same `#` is a different part on another Sole bike, so use the list printed in your own machine's manual.
