After the console prompts for the **Workout Intensity Level** (L1 to L6, "determined by how much
water you've filled the tank with", default L6) and ENTER, it enters Standby. UP/DOWN scroll the
selection, **ENTER "accesses the different workout programs"**, START/STOP starts and stops, RESET
returns to the main menu (hold to reset values), and RECOVERY runs the fitness test (a console
function).

The Programs pages list **six** menu items:

| Menu item | What it does | Card |
|---|---|---|
| **QUICK START** | press START/STOP to train; ENTER switches between values. "The program profile displays **16 columns, each equal to 100 meters**" | this card |
| **STANDARD** | five presets: 2000m, 5000m, 10000m, 30:00, 500m/1:00 | standard presets card |
| **TARGET SINGLE** | one target: time, distance, calories or a heart rate | target single card |
| **TARGET INTERVALS** | a training time, distance or both, then a rest time | target intervals card |
| **CUSTOM** | four fixed interval modes | custom modes card |
| **RACE** | you against the computer at a fixed pace per 500 m | race card (shared with the ERG550W and ERG600W) |

There is no Manual mode in the list, no preset profile beyond the Standard distances and times, no
user-built program, no fat burn, cardio or strength profile, no watt program and no Heart Rate
Exertion page - the book has no such page at all; grep for *exertion*, *Borg* and *220* returns
nothing. The functions page nevertheless describes setting a pulse target "In Manual Mode" - a
paragraph carried over from the ERG600W book; see the target single card.

**The ERG600W and ERG550W consoles have only MANUAL and RACE**, and the ERG800W has a different
ten-program set - see `not_to_be_confused_with`.
