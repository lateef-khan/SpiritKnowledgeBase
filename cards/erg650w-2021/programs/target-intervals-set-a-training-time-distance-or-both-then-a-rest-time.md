Choose **Target Interval**, press ENTER to confirm, and choose one of three values to set an
interval target for:

| Selection | Steps as printed |
|---|---|
| **Interval Time** | Using the Arrow Keys, set a training time. Press ENTER and set a rest time. Press Start to begin the workout. |
| **Interval Distance** | Using the Arrow Keys, set a training distance. Press ENTER and set a rest time. Press Start to begin the workout. |
| **Interval Variable** | Using the Arrow Keys, set a training time, then press ENTER to confirm and set a training distance. Press ENTER and set a rest time. Press Start to begin the workout. |

The book prints no range, step or default for the work or rest values on this page and does not say
how many repeats run. For fixed work/rest/repeat combinations use the **Custom** menu instead - see
`see_also`.

**Other consoles set intervals in other ways**: the ERG800W and ERG750W take a work time, a rest time
and a cycle count in seconds; the ERG600W and ERG550W have no interval program.
