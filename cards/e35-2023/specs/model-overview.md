The cover reads **E35(2023)**, **SE678S-SE039**, "Elliptical Trainer". That factory code is the manual's own name for the machine.

This is the Sole E35 of model year 2023. The Spirit database SKU is **535022**.

What the manual says the machine is made of:

- **Console** - the interface that controls all functions. It holds key controls and a **TFT LCD touch panel**.
- **Controller** - the circuit board holding the DC power supply for the console, the incline driver and the tension motor driver.
- **Gear motor** - increases and decreases the resistance level of the brake.
- **Incline motor** - an AC motor the user drives from the console to change elevation.

Two PDFs of this manual exist, a factory issue and a SOLE-branded one. Their extracted text is identical, so the knowledge base carries one source.

The 2023 E25 manual describes a keypad and LCD console instead, and prints numbered E-codes. Do not carry an answer between them.
