Press the **gear icon** above the screen while in IDLE MODE. The manual's sentence says there are 8 sub-menu modes and then lists ten; both are printed as shown.

| Item | What it does | Default |
|---|---|---|
| **1) Unit System** | Toggles Metric/Imperial. Four sub-items: Distance (mi/km), Speed (mph or km/h), Height (ft, in/cm), Weight (lb/kg). | Imperial |
| **2) Speed Display** | RPM shows the RPM value; MPH and KM/H show speed per hour. | RPM |
| **3) Sleep Mode** | OFF: the screen never turns off. ON: no operation on the IDLE MODE page for **15 minutes** turns the screen off; any key wakes it. RETAIL: the display shows the RETAIL video full screen. | RETAIL |
| **4) Screen Brightness** | Slider, left darker and right brighter. | 85% |
| **5) Date & Time** | Press ">" to enter. AM/PM or 24-hour, slide up and down to adjust, then **Save**. | - |
| **6) Wi-Fi** | Turn Wi-Fi on and the system scans. Pick the network, enter the password. If it connects, pressing Training returns to the Settings page. If not, the device only shows **"Saved"** and does not connect. | - |
| **7) Language** | Japanese, English, Spanish, Simplified Chinese, German, French, Traditional Chinese, Russian. | English |
| **8) Software** | Main program update. See the update card. | - |
| **9) Media Apps** | Third-party media and mirroring app updates. See the update card. | - |
| **10) Passcode** | ON requires a passcode when creating a new user account and at login. OFF disables the feature. | - |

**Sleep Mode is set in two places.** It is here on the settings page and again in Engineer Mode's FUNCTION page. Both use the same OFF / ON / RETAIL choices and the same 15-minute idle timer.

To reach engineer mode, **press 10 times on the word "Settings"** while on the Settings page.
