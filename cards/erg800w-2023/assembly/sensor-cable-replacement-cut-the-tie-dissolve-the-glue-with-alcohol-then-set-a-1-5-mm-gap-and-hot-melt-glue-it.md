1. With a Phillips screwdriver remove the **M4 x 12 Screw (J7)** and **M4 x 19 Screw (J8)** from both the **End Cover (A4)** and the **End Cover (A5)**.
2. Cut the cable tie (red arrow in the photo).
3. Using alcohol, remove the adhesive securing the sensor (blue arrow).
4. Disconnect the sensor cable connector (yellow arrow). Install the new sensor with its cable and secure it to the sensor mount.
5. **Adjust the gap between the sensor and the flywheel pulley to 1.5 mm.** Slowly pull the running belt to make sure the sensor does not interfere with the magnet. Once the position is right, **apply hot-melt glue** to secure it.
6. Reassemble in reverse.

The sensor wire is N5 (6 x 25 x 150 mm) reading the six Ø6 x 5 magnets (A50) in the pulley. The TZ-8145 troubleshooting table at the back of the book allows the gap up to "less than 6 mm" for a working sensor; 1.5 mm is the setting figure.
