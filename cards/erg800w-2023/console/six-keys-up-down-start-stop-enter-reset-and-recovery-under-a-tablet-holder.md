**The face:** a **tablet holder** on top, one wide **LCD window** - WATTS / AVG, CALORIES / HOUR, TIME/500M / AVG, TIME and SPM across the top row; METERS, a dot-matrix race track lettered C and Y, PULSE and STROKES across the bottom - and a strip of six **program buttons**: RECOVERY, RESET, ENTER, START/STOP, DOWN, UP. The service manual's Electronic System page shows the same face.

| Key | As printed |
|---|---|
| **UP** | "Press to increase the input value / Under Standby mode, press to select program." |
| **DOWN** | "Press to decrease the input value / Under Standby mode, press to select program." |
| **START/STOP** | "Press to start the training. Once the training start, **press to stop the training. Press again to continue the training.**" - a pause and resume |
| **ENTER** | "Press to confirm or select each training mode. Once the training start, **press to check different exercising data.**" |
| **RESET** | "Press it to restart the console." (Held 3 seconds it returns the console to Standby - [standby card](standby-at-power-on-or-reset-held-3-seconds-and-quick-start-by-pulling-the-handle.md).) |
| **RECOVERY** | "Press to start the RECOVERY function during the training." ([recovery card](recovery-counts-down-60-seconds-shows-rec-fail-and-grades-from-very-good-to-very-poor.md)) |

The readouts and their ranges are on [the data card](data-ranges-meters-to-99999-watts-to-9999-and-pulse-40-to-240.md); the programs UP and DOWN select in Standby are programs cards. The console angle, the console tube and the smart-phone stand adjust (assembly Figure 10), and the console comes off its steel tube with one M6 x 75 screw and a ribbon-cable connector (service manual) - both assembly cards. The console is powered by the adaptor (K) that plugs in at assembly Figure 12; there are no batteries.
