| Data | Description | Unit | Range |
|---|---|---|---|
| TIME | Time | Second | 00:00 ~ 99:59 |
| TIME/500M | Time to finish 500 m | Second | 00:00 ~ 99:59 |
| TIME/500M AVG | Average time to finish 500 m | Second | 00:00 ~ 99:59 |
| METERS | Rowing distance | Meter | 0 ~ 99999 |
| STROKES | Total strokes | None | 0 ~ 9999 |
| SPM | Strokes per minute | None | 0 ~ 99 |
| PULSE | Heart rate per minute | None | 40 ~ 240 |
| WATTS | Power | Watt | 0 ~ 9999 |
| WATT AVG | Average power | Watt | 0 ~ 9999 |
| CALORIES | Consumed energy | Calories | 0 ~ 9999 |
| CALORIES/HOUR | Consumed energy per hour | Calories | 0 ~ 9999 |

Distance is in metres only; the book prints no units setting. This is the only Xterra rower console that prints an **average** 500 m time and an **average** watts beside the live figures, and calories per hour. ENTER steps through these readings during a row ([key card](six-keys-up-down-start-stop-enter-reset-and-recovery-under-a-tablet-holder.md)); PULSE comes only from a chest belt ([heart-rate card](heart-rate-from-a-5-3-khz-or-bluetooth-chest-belt-not-included.md)). The older water rowers' ranges (distance to 99900 m, strokes 0 to 9990) are on [the ERG550W family card](../../shared/console/xterra-ergw-console-readouts-time-500m-distance-to-99900-m-strokes-and-watts.md).
