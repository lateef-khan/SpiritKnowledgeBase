**This is the ERG800W console with a tablet holder, program buttons and an LCD window - not the
Spirit water rower console with one button per target** (see `not_to_be_confused_with`).

The console is in **Standby Mode** when it is powered on or after RESET is pressed for 3 seconds.

**QUICK START** - in Standby Mode, press START/STOP **or pull the handle** to begin ("QUCK START"
as printed).

**Ten programs**, selected by pressing UP or DOWN in Standby until the training mode shows the
name, then ENTER, then UP/DOWN to set each value, ENTER, and START/STOP. The book gives each
program its own page, in this order:

| Program | What you set | Card |
|---|---|---|
| TIME PROGRAM | target time | count-down programs card |
| METERS PROGRAM | target meters | count-down programs card |
| CALORIES PROGRAM | target calories | count-down programs card |
| STROKES PROGRAM | target strokes | count-down programs card |
| INTERVAL 20/10 PROGRAM | number of cycles | fixed intervals card |
| INTERVAL 20/30 PROGRAM | number of cycles | fixed intervals card |
| INTERVAL CUST PROGRAM | work time, rest time, cycles | custom interval card |
| SPM PROGRAM | target strokes per minute | stroke-rate card |
| RACE PROGRAM | the computer's pace and the distance | race card |
| TARGET HR PROGRAM | target heart rate and zone; chest strap required | target heart rate card |

During training, **ENTER** cycles through the exercising data, **START/STOP** stops and pressing it
again continues, and **RECOVERY** starts the heart rate recovery test (a console function, sold-
separately chest strap required).

The book's contents page lists "Programs" at printed page 40; Standby, Quick Start and the TIME
program sit on the Function Buttons page just before it (printed 39), and the chapter runs to
printed 48. The book also prints a Heart Rate Exertion page and a perceived-exertion page after
the chest-strap pages - see `see_also`.
