1. In Standby Mode press UP/DOWN until the training mode turns into **INT CUST PROGRAM**.
2. Press ENTER, then UP/DOWN to adjust the **WORK TIME** of each cycle. **Default 20 seconds, each
   step 1 second, adjustable 05 ~ 599.**
3. Press ENTER, then UP/DOWN to adjust the **REST TIME** of each cycle. **Default 10 seconds, each
   step 1 second, adjustable 05 ~ 599.**
4. Press ENTER, then UP/DOWN to adjust the **CYCLE**. **Default 10, each step 1, adjustable 01 ~ 99.**
5. Press ENTER, then START to start the training.

Each CYCLE includes the WORK TIME and the REST TIME you set up, and the CYCLE counts down during
the training. The flow diagram reads *SELECT INT CUST PROGRAM - SELECT WORK TIME - SELECT REST
TIME - SELECT TARGET CYCLE*, each value confirmed with ENTER, then START/STOP.

The book numbers the rest-time default as its own step ("4. Default is 10 Seconds..."), so the page
counts eight steps; the sequence above is what they say.

**Other consoles' custom intervals have other limits**: the ERG750W allows 10 to 120 seconds in
10-second steps, the ERG700 defaults to 10/10 in 1-second steps for ten cycles - see `see_also`.
