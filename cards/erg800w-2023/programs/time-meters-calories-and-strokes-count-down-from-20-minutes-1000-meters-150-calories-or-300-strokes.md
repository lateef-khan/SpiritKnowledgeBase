All four work the same way. In Standby Mode press UP/DOWN until the training mode shows the program
name, press ENTER, press UP/DOWN to set the target, press ENTER, then press START to start the
training. **The chosen value counts down during the training.**

| Program | Default | Each step | Adjustable range |
|---|---|---|---|
| TIME PROGRAM | **20:00** | **01:00** | **05:00 ~ 99:00** |
| METERS PROGRAM | **1000** meters | **100** meters | **100 ~ 9900** meters |
| CALORIES PROGRAM | **150** Cals | **10** Cals | **10 ~ 990** Cals |
| STROKES PROGRAM | **300** | **10** | **10 ~ 990** |

Every value is set with UP/DOWN and confirmed with ENTER: the flow diagram under each program reads
*SELECT <program> - PRESS UP/DOWN - PRESS ENTER - SELECT TARGET - PRESS UP/DOWN - PRESS ENTER -
PRESS START/STOP*.

**Slips as printed:** the METERS page's flow diagram is captioned "SELECT TIME PROGRAM" although it
sets meters, and the STROKES page spells "Ajdustable range". The data table on the console page
gives the displayed ranges as TIME 00:00 ~ 99:59, METERS 0 ~ 99999, STROKES 0 ~ 9999 and CALORIES
0 ~ 9999 - the targets above are narrower than what the display can show.

**The ERG750W, ERG650W, ERG600W and ERG550W set targets differently** - other consoles, other
ranges; see `see_also`. The Spirit water rowers print no default at all for their targets - see
`not_to_be_confused_with`.
