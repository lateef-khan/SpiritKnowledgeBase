The console illustration says **"Six programs offer a variety of work-outs"**, and the Preset Programs page says **"The treadmill has five different programs... These five programs have factory preset work level profiles"**:

| Program | Type |
|---|---|
| Manual / Quick Start | You set speed and incline yourself |
| Hill | Preset pyramid profile |
| Fat Burn | Preset sustained-effort profile |
| Cardio | Preset profile with fluctuations |
| Strength | Preset build-and-hold profile |
| Interval | Preset high/low intensity profile |

**There are no heart rate programs and no user programs on this machine.** The manual has no HR1 or HR2 key, no Heart Rate Programs chapter, no chest strap chapter and no User 1 / User 2 program.

**Two leftover sentences in this manual say otherwise and are wrong for the XT185.** Page 20 prints "You may not use the Pulse Grip feature while in Heart Rate Programs", and page 21 prints "Entering your Age is necessary during the Heart Rate programs". Both are boilerplate carried over from the larger models; this console has no such program to enter.
