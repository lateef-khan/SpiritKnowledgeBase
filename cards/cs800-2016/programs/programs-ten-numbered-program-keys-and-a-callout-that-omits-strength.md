**This is the 2016 CS800, the Dyaco XS200-SS003 book, not the 2020 CS800.** The 2020 machine's
owner's manual reaches every program through one **Program** button and describes each profile;
this book does neither - see
`spirit-stepper-programs-the-program-count-the-manual-claims-changes-with-the-printing`.

The Function Button Locations page is a photograph of the console with three callouts. The
**PROGRAM BUTTONS** callout reads *"(Manual, Hill, Fat Burn, Cardio, Interval, Custom 1&2, HR1&2)"*
- **nine names**. The console in the photograph carries **ten program keys**, each printed with a
digit so that the same keys double as a number pad during data entry:

| Key | Program | Key | Program |
|---|---|---|---|
| 1 | MANUAL | 6 | INTERVAL |
| 2 | HILL | 7 | CUSTOM 1 |
| 3 | FAT BURN | 8 | CUSTOM 2 |
| 4 | CARDIO | 9 | HR 1 |
| 5 | STRENGTH | 0 | HR 2 |

**STRENGTH is key 5 on the console and is missing from the callout.** The key legend is a picture,
not text; it was read from a render of the page, and the ten names above are as printed on the keys.

**The operation text names a different keypad.** Under Exercise Mode (Quick Start) the same book
says: *"You could chose the program by pressing the key: MANUAL, PROGRAM, HRC. And then, press START
key to start the workout. All parameter will be the preset value."* Three key names - MANUAL,
PROGRAM, HRC - that match neither the ten keys in the photograph nor the callout. The book never
reconciles the two; which keypad a given machine carries cannot be settled from it. Recorded as
printed.

**What the book does not print.** No page describes any program: no profile pictures, no Max
Level, no heart-rate percentage for HR 1 or HR 2, no custom-program setup. Its only other program
sentences are the idle-mode line *"Each program profile will be displayed on the MESSAGE WINDOW and
hold display 5 seconds"* and the Quick Start line that pressing START in idle enters Manual mode
with age and weight at their preset values, time counting up from 00:00 and resistance from 1.
The words *Hill*, *Fat Burn*, *Custom* and *HRC* occur nowhere else in the book.

The console pictured also carries a DISPLAY key with TRACK and PROFILE indicators, an **HR %**
scale from 50 to 90, SCAN, ENTER between the RESISTANCE LEVEL minus and plus keys, START, STOP and
FAN. Those keys and the console's display ranges belong to its console cards, not here.

**Do not answer this machine from the XS895 key list**, which also has ten keys but replaces
Custom 1 and Custom 2 with User 1 and User 2 - see
`xs895-programs-ten-programs-including-two-heart-rate-keys`.
