**READY MODE** (before Start):

| Key | What it does |
|---|---|
| STOP | Non-function |
| START | Starts the machine: "there will be 3 second final count down on window display, then machine starts running. In MANUAL, bike starts at MIN LEVEL" |
| LEVEL UP / DOWN | Non-functional until a setting has been entered |
| FAN | Fan on or off |
| ENTER | Enters parameter setting, and confirms or modifies each setting. The spec adds "confirm the every setting by pressing START key no pressing ENTER key" - Start accepts the settings and begins |

**RUN MODE** (during a workout):

| Key | What it does |
|---|---|
| STOP | Stops the machine |
| START, ENTER | Non-functional |
| LEVEL UP / DOWN | Raises or lowers the level by 1 |
| FAN | Fan on or off |
| **DISPLAY** | Switches the exercise data. If the display already shows the latest data, pressing it lights the **SCAN ICON** in the message window and the display cycles automatically **every four seconds**: "CYCLE MODE WILL FIRST DISPLAY `SEG TIME XX:XX` AND THEN DISPLAY" `Dist XXXX`, `PACE XX.X` |

**Three readings in the scan, and a Display key to start it.** The 2016 ellipticals scan SPEED, WATT,
LAPS, TIME and MAX LV on the **Enter** key
(`spirit-xe-2016-console-keys-in-ready-and-run-mode-enter-scans-every-four-seconds`); the CU800-2012
bike scans a longer list on its own Display key
(`cu800-2012-console-keys-in-ready-and-run-mode-and-the-display-key-data-scan`). This stepper's list is
segment time, distance and pace, and nothing else is printed.

**"Bike starts at MIN LEVEL" and "press STOP button to stop bike"** - the key tables call the machine a
bike throughout; it is the spec's leftover wording, on a stepper whose every other page says
climber or stepper.

**No Incline row**, because the machine has no ramp; and no Scan key in the tables, though the
photograph shows one
(`cs800-2016-console-face-blue-matrix-with-ten-numbered-program-keys-a-display-key-a-fan-key-and-control-keys`).
**The 2020 CS800 has four LED data windows and two Scan buttons instead**
(`spirit-stepper-console-led-data-windows-steps-and-vertical-distance`); do not answer one from the other.
