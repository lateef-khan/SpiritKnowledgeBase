**The Display Windows page carries one call-out, "Matrix Display"**, over a photograph of the console;
the Function Button Locations page names the **PROGRAM BUTTONS**, the **CONTROL KEYS** and a **Fan
Key** ("Cooling fan switch on or off").

**The legend under PROGRAM BUTTONS lists nine programs**: Manual, Hill, Fat Burn, Cardio, Interval,
Custom 1&2, HR1&2. **The photograph shows ten numbered keys**, five down each side of the matrix:

| Left of the matrix | Right of the matrix |
|---|---|
| **1** MANUAL | **6** INTERVAL |
| **2** HILL | **7** CUSTOM 1 |
| **3** FAT BURN | **8** CUSTOM 2 |
| **4** CARDIO | **9** HR 1 |
| **5** STRENGTH | **0** HR 2 |

**The legend omits Strength**, the fifth key on the left; the key is on the console. Which programs
the machine runs is a programs question.

**Above the first program key sits a DISPLAY key** with TRACK and PROFILE indicators beside it; it is
the key the Run-mode page uses to scan the message window
(`cs800-2016-console-keys-in-ready-and-run-mode-and-the-display-key-scan-of-seg-time-dist-and-pace`).
The matrix in the photograph is **blue** and shows `1/4 MI`, with an **HR %** scale of 50 to 90 under
it; the **message window** below is a single red line reading `TIME 1:09 DIST 0.00`.

**The control keys in the photograph are SCAN, the RESISTANCE LEVEL pair with ENTER between them,
FAN, and a green START and a red STOP.** The book names FAN, START, STOP, LEVEL UP, LEVEL DOWN,
ENTER and DISPLAY in its key tables; SCAN is drawn and never described.

**This is the blue-matrix, one-message-window console of the CE850-2016 and CU800-2012**
(`spirit-ce-console-blue-led-console-face`), not the 2020 CS800's face with four LED data windows and
two Scan buttons (`spirit-ce-console-led-console-face`). The 2016 XE ellipticals carry an LCD with a
muscle figure instead (`spirit-xe-2016-console-face-7-5-inch-lcd-with-6-or-10-program-buttons`).
**No USB port, no C-SAFE port and no water bottle holder is labelled** on either page.
