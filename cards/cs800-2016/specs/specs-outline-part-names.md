The book's cover and headings call this machine **XS200-SS003**; a Chinese caption (電子錶, *console*)
survives beside the first label. Names only - **no item numbers, part numbers or quantities**.

**Drawing 1 - covers, twelve labels**

| Left column | Right column |
|---|---|
| Console Mast Cover (L) | Console Assembly |
| Chain Cover (L) | Console Mast Cover (R) |
| Pedal (L) | Handle Bar Cover (R) |
| Pedal (R) | Chain Cover (R) |
| Stabilizer Cover (L) | Rear Shroud |
| | Slide Wheel Cover (R) |
| | Stabilizer Cover (L) |

**Stabilizer Cover (L) is printed twice**, once on each side of the drawing; the right-hand one
points at the right stabilizer cover and is a labelling slip.

**Drawing 2 - structure, thirteen labels**

| Left column | Right column |
|---|---|
| Console Mast | Console Holder Assembly |
| Left Handgrip (Upper) | Drive Pulley |
| Curved Rail Tube | Handle Bar Cover (R) |
| Connecting Arm (L) | Crank Arm |
| Connecting Arm (R) | Idler Wheel Assembly |
| Rear Stabilizer with handle | Flywheel |
| | Main Frame |

The 2020-version CS800 book redraws both pages with different names - *Rail Tube* for the Curved
Rail Tube, *Swing Assembly* and *Linked Assembly (R)*, *Rear Side Case* for the Rear Shroud, and
*Left/Right Slider Cover* (`cs800-2021-specs-outline-part-names`).
