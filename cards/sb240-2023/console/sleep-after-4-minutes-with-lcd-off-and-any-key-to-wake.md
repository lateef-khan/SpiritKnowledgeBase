"**WAKE-UP FUNCTION.** The monitor will enter SLEEP mode (LCD off) when there is no signal input and no key has been pressed for 4 minutes. Press any key to start the monitor."

The book does not say whether the workout values survive the sleep. The console is powered from the wall adapter, so a blank LCD is this timer before it is anything else.
