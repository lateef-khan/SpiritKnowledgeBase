The Console Screen Overview labels a **Phone Ledge**, the **LCD Window** and the **Program Buttons**. "There are 6 button keys":

| Key | As printed |
|---|---|
| START/STOP | **Quick Start:** starts the computer without selecting a program - manual workout only, time counts up from zero. In exercise mode it stops; in stop mode it starts |
| UP | Increases resistance during exercise; in setting mode increases Time, Distance, Calories, Age and selects Gender and Program |
| DOWN | Decreases resistance; in setting mode decreases the same values |
| ENTER | Accepts the current entry in setting mode; **at stop mode, holding it over two seconds resets all values to zero or default**; when setting the clock, accepts the hour or minute |
| BODY FAT | Enter HEIGHT, WEIGHT, GENDER and AGE to measure body fat ratio (the P24 program on the Programs cards) |
| PULSE RECOVERY | Starts the recovery test ([recovery card](../../shared/console/xterra-console-recovery-grades-from-outstanding-to-poor.md)) |

**Program select and setting:** UP/DOWN chooses the program, ENTER confirms; in Manual, UP/DOWN sets TIME, DISTANCE, CALORIES and PULSE; START/STOP starts; at a target the computer beeps and stops, and START/STOP continues toward the next target. The ENTER text mentions "setting the clock", but the book prints no clock procedure. The readouts are on [the readouts card](readouts-time-distance-rpm-watt-speed-calories-pulse-age-and-distance-bar.md); the four-minute sleep on [the sleep card](sleep-after-4-minutes-with-lcd-off-and-any-key-to-wake.md).
