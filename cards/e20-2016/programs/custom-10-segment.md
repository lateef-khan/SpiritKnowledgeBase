**Ten segments — the shortest custom profile in any B book.** 1. Select U1/U2 with the USER1/USER2 keys, Enter; if empty 'A' blinks — Level UP/DOWN pick letters ('B' up, 'Z' down), Enter per letter, Stop finishes (max 7 characters). 2. A stored program offers Run Program? Yes/No; No asks to delete — deleting is required to build anew. 3-5. Enter Age, Weight, Time; the Time step flows into the first blinking column. 6. Build the level profile to all ten segments. 7. Start begins and saves, Enter modifies, Stop exits. Level UP/DOWN adjust mid-program; Enter scrolls data in 2016 wording; a summary ends the session. The E20-2020 has no custom programs at all.
