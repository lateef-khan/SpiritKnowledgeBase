**This list starts with the stroke itself, and no other book in the range does.** The ERG600W's version of the same question starts at the batteries and adds a sensor gap instead (`erg600w-2021-errors-console-shows-no-data-batteries-wires-magnets-sensor-gap-5-mm`).

The service manual's answer, in its order. The question is printed as *The console without data* and the answer opens *When there is no display, check as below*:

1. Check if you pull a complete stroke, **at least 1 M from the front strap wheel**. The console sets this regulation to protect children playing with the rowing machine; it is not a guide to correct operation.
2. Check if the batteries have enough power. If not, change new battery to try.
3. Check if the wires are connected properly. If not, try to connect all the wires again.
4. Check if the **two magnets** are right in the mesh belt wheel. If not, press a new magnet on the hole of the mesh belt wheel.
5. Check if the wires have breakage. If yes, change new wire.
6. If all is OK, change a new console.

**Step 1 is a design rule, not a fault.** The console ignores a pull shorter than a metre from the front strap wheel so that a child tugging the handle does not start it; the page's photo shows a tape measure laid along the strap. A customer who rows short strokes and sees nothing count is seeing that rule, and the fix is a longer stroke. The magnets are the two the sensor counts on the mesh belt wheel; the photo rings them both.

The owner's manual describes the same fault from the customer's side in three rows - sensor wire, replace sensor wire, replace monitor (`xterra-rower-errors-no-count-or-distance-sensor-wire-then-monitor`) - and prints neither the stroke rule nor the magnets. A console that shows nothing at all is a shorter question on the same page: batteries, then a new console (`xterra-rower-errors-monitor-does-not-display-install-batteries-then-computer-wires`).

The Spirit CRW800H2O service manual answers this question with the ERG600W's list, not this one (`crw800h2o-console-shows-no-data`).
