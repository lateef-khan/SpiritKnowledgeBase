| Quick key row | Values |
|---|---|
| Speed | 2, 3, 4, 5, 7, 9, 12 |
| Incline | 1, 3, 5, 7, 9, 12, 15 |

Pressing one in RUN mode takes the machine straight to that speed or incline.

There are also **UP and DOWN incline keys and FAST and SLOW speed keys on the handrails**, separate from the quick key rows.

**Source wording.** Both quick key rows are introduced as "5 preset buttons", but seven values are listed on each row. The values are what the machine does; the count of five is a slip in the manual. This manual prints no metric equivalents for the speed quick keys.
