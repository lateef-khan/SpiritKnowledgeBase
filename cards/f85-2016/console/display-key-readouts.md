Pressing DISPLAY during a workout switches the exercise data shown in the message window between:

- `LAP XXX`
- `VERTICAL XXXX M` (the unit is metres)
- `SEGMENT TIME X:XX` — this line is not shown in HRC mode
- `MAX SPEED XX.X`

Before a workout, once a program has been chosen, the same key shows the speed or incline profile in the dot matrix.
