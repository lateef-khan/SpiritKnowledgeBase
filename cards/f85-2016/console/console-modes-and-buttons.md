**The four window display modes**

| Mode | What it means |
|---|---|
| OFF | The safety key is not in the console. Every window is blank. |
| READY | The treadmill is on and the safety key is inserted. The message window shows the program profile name and cycle. Press START to run in Manual. |
| SLEEP | Pressing any button returns the console to READY. |
| RUN | Pressing STOP, or removing the safety key, stops the treadmill instantly and drops it into OFF. |

**READY mode**

| Button | Behaviour |
|---|---|
| SAFETY KEY | Fit it in the right position to power the computer on. Pulling it away shuts the computer down automatically. |
| STOP | No function. |
| START | Starts the treadmill after a 3 second countdown on the window display. In MANUAL it starts at MIN SPEED; in a PROGRAM it starts at the program's preset value. |
| ENTER | Changes each function. MANUAL sets time. A preset PROGRAM sets time and speed. Heart Rate Control 1 to 2 sets time, age and heart rate value. User Program 1 to 2 sets time, speed and incline. |
| FAST, SLOW, UP, DOWN | Non functional until the user enters a setting. |
| FAN | Turns the cooling fan on and off. |
| DISPLAY | After a program has been chosen, shows the speed or incline profile in the dot matrix. |

**RUN mode**

| Button | Behaviour |
|---|---|
| SAFETY KEY | Pulling it away shuts the computer down automatically. |
| STOP | Stops the treadmill. |
| START and ENTER | Non functional. |
| FAST | Increases speed by 0.1 kph (0.1 mph) per press. Held down, it runs up to MAX SPEED quickly. |
| SLOW | Decreases speed by 0.1 kph (0.1 mph) per press. Held down, it runs down to MIN SPEED quickly. |
| UP | Raises the incline by 1 per press. **The RUN mode page gives the maximum incline position as 12.** |
| DOWN | Lowers the incline by 1 per press, to a minimum of 0. |
| FAN | Turns the fan on and off (optional). |

**Watch the incline limit.** The operation table earlier in the same manual gives the incline working range and preset value as 0 to 15, and the incline quick keys reach 15. The RUN mode page above says 12. Both numbers are printed in this one manual.
