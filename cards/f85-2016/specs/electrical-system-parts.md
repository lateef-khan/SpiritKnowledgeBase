| Part | What it does |
|---|---|
| Safety key | Fits on the console and activates all functions. With no safety key the console cannot be controlled. |
| Console | The interface that controls all functions of the treadmill. Made up of key controls and the display. |
| Main controller (also called the lower controller or driver board) | Carries the DC power supply for the console, the incline driver and the DC motor driver. It links the console to the motors and outputs the voltages that run them. |
| Treadmill motor | A variable speed DC motor. |
| Incline motor | An AC motor. The user sets the elevation from the console, through the main controller. |

**A wording clash inside the manual.** Section 3 describes the console as "key controls and LCD display", while section 4 labels the same console a **10.1" TFT PANNEL**. It is one console; the two pages name the panel differently.
