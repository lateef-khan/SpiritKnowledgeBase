The platform ships in a normal version and a CE version. Quoting the manual:

> Besides normal version, ST535 treadmill is with a CE version. Both versions are with exactly the same in functions and outlines except that the power input is 110AC for normal version versus 230VAC for CE version and an additional Filter Choke circuit is added for CE version as shown in the circuit diagram on next page.

| | Normal version | CE version |
|---|---|---|
| Power input | 110AC | 230VAC |
| Filter choke circuit | no | yes |
| Functions and outlines | identical | identical |

**The rest of the manual is not consistent with this note.** The safety and grounding sections call the machine a nominal **220 volt** product with a 10 amp outlet, and bracket the 120Vac system as 110 volt, 15 amp. The special note says 110AC and 230VAC. Treat 220 and 230 as the same high voltage build when reading those pages.
