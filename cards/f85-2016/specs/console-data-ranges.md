| Window | Display range | Working range | Step |
|---|---|---|---|
| SPEED | 0.0 to 99.9 | 1.0 to 18.0 kmph (0.5 to 12.0 mph) | 0.1 km/h or mph |
| INCLINE | 0 to 99 | 0 to 15 (preset value 0 to 15) | 1 |
| TIME | 0:00 to 99:99 | 0:00 to 99:59 | count down setup 10:00 to 99:00 |
| LAPS | 0 to 99 | 0 to 99 | |
| DISTANCE | 0.00 to 99.9 | 0.00 to 99.9 | |
| CALORIES | 0.0 to 999 | 0.0 to 999 | |
| PULSE | 0 to 999 | 50 to 200 BPM | |

- TIME counts up by default. Setting a time makes it count down, and it counts to zero.
- In RUN mode, pressing STOP saves the time value; entering RUN mode again continues counting up from it.
- PULSE reads from the hand grips or from a receiver. Using the receiver needs a chest belt. If no signal arrives for **8 seconds** the window falls back to 0.

**Two incline limits are printed in this manual.** This table says the working range is 0 to 15 and the incline quick keys go to 15, but the RUN MODE page says "the maximum incline position is 12" for the UP button. Both numbers are in the same manual.
