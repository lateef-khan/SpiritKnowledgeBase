**TT8 2023 ST738-YT066, DC drive motor.**

**Speed quick keys — 7 presets: 2/3/4/5/7/9/12 in miles, 3/6/9/12/15/18/22 in kilometres.**

**Incline quick keys — 7 presets: -4/-2/2/4/6/9/12.**

The values are the same in ready mode and in run mode.

Note that the incline quick keys reach **-4 and -2**, below the incline work range of 0 to 15 printed in the
display function table of this same manual.
