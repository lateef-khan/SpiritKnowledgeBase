**TT8 2023 ST738-YT066, DC drive motor.**

**GR Mode (Grade Return). Default: ON. Setting: ON/OFF.**

If the incline does not return to zero while GR MODE is OFF, switch it to ON, go back to Setting, and the
incline should return to zero.

**With GR Mode ON, the incline should be at zero when:**

- the treadmill is powered on,
- the user pauses the machine during a workout,
- the workout ends and the display is on the SUMMARY page,
- the display is on the HOME page,
- the SAFETY KEY is plugged back in.

**Unplugging the SAFETY KEY does not return the incline to zero** even with GR Mode ON.

**With GR Mode OFF:** the incline should not be at zero at power on, should stay at the current level when
the user pauses, should not be at zero on the SUMMARY page, and should be at zero or at the current set
level when START is pressed. Unplugging and re-plugging the SAFETY KEY does not move it to the basic
level.
