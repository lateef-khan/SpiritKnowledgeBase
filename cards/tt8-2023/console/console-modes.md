**TT8 2023 ST738-YT066, DC drive motor.**

| Mode | What it means |
|---|---|
| OFF | The safety key is not in the console. All windows appear blank. |
| READY | The treadmill is ON and the safety key is inserted. The message window shows the program profile name and cycle. Press the **START button** or the touch panel **"START WORKOUT"** to run in Manual Mode. |
| SLEEP | Pressing any button takes the console back to READY Mode. |
| RUN | Pressing STOP or pulling the safety key stops the treadmill instantly and returns it to OFF Mode. |

Whether removing the safety key blanks the screen is a setting — see the Sleep Mode and Display Mode
cards.
