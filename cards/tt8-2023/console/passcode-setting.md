**TT8 2023 ST738-YT066, DC drive motor.**

With the feature turned **ON**, press the **">"** button to reach the **Enter Old Passcode** page.

1. Enter the correct old passcode.
2. Create a new passcode.
3. Re-enter the new passcode to confirm; the console then returns to the Settings page.

If the passcode is entered incorrectly the system prompts **"Wrong passcode. Please try again."**

The manual documents no recovery path for a forgotten passcode.
