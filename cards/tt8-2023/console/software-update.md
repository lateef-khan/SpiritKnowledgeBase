**TT8 2023 ST738-YT066, DC drive motor.**

**A yellow dot on the gear icon of the IDLE MODE page means the main program has an update waiting.**

1. Go to the Settings page. If an update is detected the **Update** button lights up.
2. Click Update to start. The version number changes when the update completes.
3. If the software is current, the page shows **"Up to date"**.

**Do not interrupt the power supply during the update.** Doing so could damage the system and stop it
working properly in the future.
