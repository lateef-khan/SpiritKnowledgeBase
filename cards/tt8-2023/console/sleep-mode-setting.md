**TT8 2023 ST738-YT066, DC drive motor.**

Sleep Mode changes what removing the SAFETY KEY does. **Default: OFF.**

- **Sleep Mode OFF**: removing the SAFETY KEY does **not** turn the screen off, and there is no Sleep Mode
  at all.
- **Sleep Mode ON**: removing the SAFETY KEY turns the screen off and activates Sleep Mode. With no
  operation on the IDLE MODE page for **15 minutes** the device enters Sleep Mode by itself. **The device
  cannot enter Sleep Mode without the SAFETY KEY inserted.** Any key wakes it.

This is a different setting from **Display Mode** in engineering mode, which controls a **30 minute**
power-down. Both exist on this machine.
