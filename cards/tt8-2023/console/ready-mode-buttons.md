**TT8 2023 ST738-YT066, DC drive motor.**

- **Safety Key**: insert it in the right position to power on the console. Pulling it away shuts the console
  down automatically.
- **Stop Key**: no function.
- **Start Key**: starts the treadmill. There is a **3 second countdown** on the window display, then the
  machine starts running — at MIN SPEED in MANUAL, or at the program preset value in a PROGRAM.
- **Touch panel**: changes each function. MANUAL sets time. Pre-set PROGRAM and Fitness tests set time and
  speed. Heart Rate Control 1~2 sets time, age and heart rate value. User Program 1~2 sets time, speed and
  incline.
- **Speed quick keys**: 7 preset buttons — **2/3/4/5/7/9/12 MI (3/6/9/12/15/18/22 KM)**.
- **Incline quick keys**: 7 preset buttons — **-4/-2/2/4/6/9/12**.
- **Fan key**: turns the fan on and off.
- **Display key**: non-function in ready mode.
