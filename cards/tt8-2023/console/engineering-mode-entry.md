**TT8 2023 ST738-YT066, DC drive motor.**

**Press 10 times on the word "Settings" while you are on the Settings page.**

Engineering mode lists six main functions:

1. Engineering Mode
2. Diagnostics
3. Machine Information
4. Maintenance
5. Lube Setup
6. Key Test

This replaces the START + STOP + ENTER key combination used on the older button consoles.
