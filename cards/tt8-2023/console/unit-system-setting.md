**TT8 2023 ST738-YT066, DC drive motor.**

On the settings page, the Unit System button **toggles between Metric and Imperial. The default setting is
Imperial.**

Four sub-items follow:

| Item | Units |
|---|---|
| Distance | mi / km |
| Speed | mph / km/h |
| Height | ft, in / cm |
| Weight | lb / kg |
