**TT8 2023 ST738-YT066, DC drive motor.**

**Child Lock is OFF by default.** The setting range is ON/OFF. After switching it to ON you must **reset the
device or re-plug the safety key** for the setting to take effect. The DM window in IDLE MODE then shows
**"Console Locked"**.

**To unlock: press and hold both the START and STOP buttons for 3 seconds**, which returns the console to
IDLE MODE.

The manual states the unlock gesture three different ways, so expect the on-screen prompt to disagree with
the text:

- Settings section: "press and hold both the START & STOP buttons for 3 seconds".
- Engineering Mode / Machine Information: "press START & STOP key within 3 seconds".
- The message the display itself shows: **"Press Start and Display to enable operation"**.

Two of the three say START and STOP; the on-screen prompt names Start and Display.
