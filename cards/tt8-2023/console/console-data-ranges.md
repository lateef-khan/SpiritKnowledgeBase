**TT8 2023 ST738-YT066, DC drive motor.**

**SPEED** — display range **1.0 to 22.0 km MAX**, or for miles **0.5 to 12.0 MAX**. Work range **1.0~22.0
km/h (0.5 ~ 12.0 mph)**, adjusted in 0.1 km/h (mph) steps.

**INCLINE** — the window shows the incline position from 0 to 15. Work range **0 to 15**, preset value 0 to
15, changed by 1 per press.

**TIME** — count up by default; setting a time makes it count down. Display range 0:00:00 to 9:99:99, work
range 00:00 to 9:99:59, count-down setup range 10:00 to 99:00.

**DISTANCE** — display and work range 0.00 to 99.9, in kilometres or miles.

**CALORIES** — display and work range 0 to 999.

**PULSE** — display range 0 to 999, work range **50 to 200 BPM**. In RUN Mode, with no signal for **8
seconds** the value drops to 0.

Two things in this table do not line up with the rest of the manual, and both are printed as they stand
here: the INCLINE display range is given as the single character "0" while the work range is 0 to 15, and
the incline **work range of 0 to 15 excludes the -4 and -2 values that the incline quick keys offer**.
There is no LAPS window on this console.
