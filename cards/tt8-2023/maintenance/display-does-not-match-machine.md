**TT8 2023 ST738-YT066, DC drive motor.**

| Symptom | Reason | Solve |
|---|---|---|
| The speed of the belt does not match the console display | The controller is not calibrated, or the parameters of the controller are incorrect | Execute the calibration procedure; replace the controller |
| The incline position does not match the console | The controller is not calibrated | Calibrate the console |

Note the wording: for the speed mismatch this manual blames the **controller's** calibration and parameters,
where the 2016 and 2019 TT8 manuals blame the console.

If the incline window shows **E3** rather than a wrong number it is a fault code, not calibration drift.
