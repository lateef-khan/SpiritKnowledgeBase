Steps four (pedals) and five (console and transmitter) have no hardware table.

## The handlebar bolt is not the one in the 2021 book

The 2021 printing of the same machine calls for **BOLT (36), 5/16" x 3/4"** in step
three - a different item number and a different length. Every other row above is
identical in both books. Check which printing you have before ordering; see
[the 2021 card](../../xic600-2021/assembly/xic600-2021-assembly-hardware-kit.md).

## This page prints the step-three instruction twice

PDF page 11 of the 2018 book carries a leftover text block headed "STEP 3 Handlebar and
Drink Holder" above the hardware panel, saying the same thing in different words. Both
copies name bolt **(88)** at **5/16" x 15mm**, so they agree. The 2021 printing drops
the stray block.
