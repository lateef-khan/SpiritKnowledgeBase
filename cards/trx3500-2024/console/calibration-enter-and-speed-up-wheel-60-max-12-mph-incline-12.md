Remove the safety key. Press and hold down the **Enter** and **Speed Up** buttons and replace the safety key; the console enters Calibration mode. **DO NOT STAND ON THE BELT DURING CALIBRATION.** The console displays the software version number; press Enter for the next item.

1. Set the wheel diameter to **60**. Press Enter.
2. Set kilometers or miles. Press Enter.
3. Set the minimum speed of **0.5**. Press Enter.
4. Set the maximum speed of **12**. Press Enter.
5. Set the maximum incline value of **12**, then press the Start/Stop key to confirm. The console enters the calibration display automatically.
6. Press the **START/STOP** key to start the calibration. It returns to the standby screen automatically when complete.

The shared Dyaco GT90C/GT90D service manual prints the same procedure with two extras: the message window rolls "A0464 VER (soft version) FACTORY SETTING PRESS ENTER" on entry, and a **GRADE RETURN ON/OFF** prompt comes before the unit step — ON returns a raised incline to zero automatically at the next power-on, OFF leaves it raised until Start is pressed. It writes the speeds as 1 km (0.5 mi) and 18 km (12 mi). The TRX4500 book sets the incline maximum to 15 ([TRX4500 card](../../trx4500-2024/console/calibration-enter-and-speed-up-wheel-60-max-12-mph-incline-15.md)). Sleep, lube reset and child lock are in a separate engineering mode ([engineering card](../../shared/console/xterra-trx-console-engineering-mode-program-and-speed-keys-sleep-lube-child-lock.md)).
