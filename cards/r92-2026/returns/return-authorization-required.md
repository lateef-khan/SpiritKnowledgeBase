**DO NOT SHIP ANY UNIT TO OUR FACTORY WITHOUT A RETURN AUTHORIZATION NUMBER. All units arriving without a return authorization number will be refused.**

If a unit does go back:

- **All transportation costs, both to our factory and upon return to the owner, are the responsibility of the owner.**
- **The owner is responsible for adequate packaging upon return to SOLE.**
- **SOLE is not responsible for damages that occur during shipping.**
- **Make all freight damage claims with the appropriate freight carrier**, not with SOLE.

**Before returning the product to any retailer**, or for any assistance with assembly or technical support, **the manual asks you to call 866-780-7653 first**. That notice is printed twice, on the front matter and again after the warranty.

**The manual describes no consumer return window, no refund and no restocking fee.** Everything it says about sending a machine back sits inside the warranty service process; a change-of-mind return is a retailer matter this manual does not cover.
