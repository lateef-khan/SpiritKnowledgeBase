**This is the quickest way to start a workout.**

1. **After the console powers up, press the Start key.** This initiates **Quick Start mode**.
2. **In Quick Start the time counts up from zero.**
3. **Adjust the resistance level manually with the Level + and Level - buttons.**

Quick Start asks for nothing - no age, no weight, no time.

**Quick Start is not the same as the manual program.** The manual program is a program you select with the Program key and it walks you through age, weight and time first. Pressing Start from a selected program also skips the setup and uses the stored defaults; see the program setup card.
