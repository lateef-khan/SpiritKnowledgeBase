**These are the F menu items of the service menu, not the P, U and H workout programs.** F1 is Key Test; P1 is the manual workout program. They are selected in different ways and have nothing to do with each other.

**To open the menu: press and hold the Start, Stop and Enter keys together and keep holding for 3 seconds.** The time window displays **F1**. **Press the Program key to move through the menu, and the Enter key to access an item.**

| Item | What it does |
|---|---|
| **F1** | **Key Test** - test all the keys to make sure they are functioning |
| **F2** | **Display Test** - automatically tests all LEDs |
| **F3** | **ODO Reset** - resets the odometer |
| **F4** | **Units** - English (Imperial) or Metric display readings. **0: Metric / 1: English** |
| **F5** | **Sleep Mode** - turn off to have the console power down automatically after **15 minutes** of inactivity. **0: OFF / 1: ON** |
| **F6** | **Pause Mode** - turn on to allow **5 minutes** of pause; turn off to have the console pause indefinitely. **0: OFF / 1: ON** |
| **F7** | **Key Tone** - turn the key press beep on or off. **0: OFF / 1: ON** |
| **F9** | **Factory Set** |
| **F10** | **Light Mode** - allows adjustment of display brightness |
| **F11** | **Motor Test** - continually runs the tensioning gear motor |
| **F12** | **Manual** - allows stepping of the gear motor |
| **F13** | **Security** - keypad lock, on its own card |
| **End** | **Exit** - leaves the maintenance menu |

**The menu says it runs F1 to F13, but F8 is not printed.** There is no F8 entry in this manual, and it does not say whether F8 exists and was omitted or does not exist. Expect a gap when stepping through with the Program key.

**F5 is printed contradicting itself.** A setting called Sleep Mode offers "0: OFF / 1: ON", and then the description says it is **turning it off** that makes the console power down after 15 minutes. Reading it either way makes one half of the line wrong, and the manual does not resolve which setting actually produces the 15 minute power down.

**F9 Factory Set has no description at all** - the manual does not say what it changes or resets. Do not run it on a customer machine on the strength of this page.
