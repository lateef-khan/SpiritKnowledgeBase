**The SOLE+ App syncs your workout data with one of the fitness cloud sites Sole supports:**

- **Apple Health**
- **Google Health Connect**
- **Strava**
- **MapMyFitness**

The page adds **"with more to come"**, so the list is explicitly open ended and is not a guarantee for any service not named above.

**The data goes out through the app over Bluetooth, not through the console's charging port.** The Type-C port on the console is stated elsewhere in this manual to be for charging only - you cannot save workout data to it.

**The page describes no export from the machine itself.** There is no file, no memory stick and no account on the console; the app is the only route off the bike, and it has to be paired first.
