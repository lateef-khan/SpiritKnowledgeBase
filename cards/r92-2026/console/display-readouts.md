**Each time the DISPLAY/ENTER button is pressed, the next set of information appears.**

**Display combo 1:** **Time**, **Distance**, **RPM**, **Level**.

**Display combo 2:** **PACE**, **WATT**, **Calories**, **PULSE**.

**Data Scan mode:** the displayed information **changes every 4 seconds** in the Message Window.

Eight values in total, in two groups of four, on one Display/Enter key.

**The manual prints an indicator icon before each value name**, showing which lamp lights up for which window. **Those icons are pictures and did not survive the text extraction**, so this card can give the order of the values but not which lamp marks which one. The reading order above is the printed order.

The manual defines none of these values, gives no accuracy statement for calories or watts, and gives no display ranges.
