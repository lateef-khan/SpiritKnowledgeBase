**These are the two custom user programs U1 and U2 - not the presets P2 to P6, and not the heart rate programs H1 and H2.**

**The customizable User programs let you build and save your own workout.** There are two slots.

1. **Select the User program and press Enter.** **If you have already saved a program to that slot it is displayed and you are ready to begin.** If not, **LEVEL displays 1**.
2. **The Time window asks you to enter your Age.** Use the **Level + / -** keys, then press **Enter**.
3. **You are asked to enter your Weight.** Use the **Level + / -** keys, then press **Enter**.
4. **Next is Time.** Use the **Level + / -** keys and press **Enter**.
5. **Now set the level for each segment of the workout.** **The Distance window displays segments 1 to 18.** **Press the Level + / - keys to set the level, then press Enter to move to the next segment.** **Repeat until all eighteen segments have been set.**
6. **Press the Start key to begin.**
7. **Press the Level + / - keys at any time during the program to change the level.**
8. **Each time the Display button is pressed, the next set of information appears.**
9. **When the program ends the Message window shows a summary of your workout**, for a short time, then the console returns to the startup display.

**A saved program comes back the next time you select the slot** - that is what distinguishes these from the presets. **The manual does not say how to clear or overwrite a saved slot**, and does not say whether changing the level with Level + / - during a workout is saved back into the slot.
