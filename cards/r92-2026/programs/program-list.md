**These are the workout programs, not the F menu of the service software.** F1 to F13 are diagnostic items and are reached a different way.

**Ten programs are displayed in the RPM window on the startup display:**

**P1 / P2 / P3 / P4 / P5 / P6 / U1 / U2 / H1 / H2**

Page 13 writes the same set as **P1~6, U1~2, H1~2**, selected with the **Program key**.

| Group | Count | What they are |
|---|---|---|
| **P1** | 1 | The manual program - you control the workload, not the computer |
| **P2 to P6** | 5 | Preset workouts, each an eighteen segment level profile |
| **U1, U2** | 2 | Custom user defined programs you build and save |
| **H1, H2** | 2 | Heart rate programs, which control resistance automatically |

**The heart rate section counts them as "the nine different programs"** plus manual mode - the same ten, with P1 counted as manual mode rather than as a program.

Each group is set up slightly differently and has its own card.
