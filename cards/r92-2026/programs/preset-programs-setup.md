**These are the preset workouts P2 to P6 - not the manual program P1, not the user programs U1 and U2, and not the heart rate programs H1 and H2.**

1. **Press the Program key to select a preset program and press the Enter key to get in.**
2. **The Time window asks you to enter your Age.** Adjust with the **Level + / -** keys, then press **Enter**.
3. **You are asked to enter your Weight.** Adjust with the **Level + / -** keys, then press **Enter**.
4. **Next is Time.** Adjust it and press **Enter**.
5. **Press the Start key to begin.** You can also **press the Stop key to go back one level of the programming screen** and change a setting.
6. **Press the Level + / - keys at any time during the program to increase or decrease the resistance.**
7. **Each time the Display button is pressed, the next set of information appears.**
8. **When the program ends the Message window shows a summary of your workout**, for a short time, then the console returns to the startup display.

The setup is the same as the manual program. **The difference is what happens once you start: a preset workout drives the resistance through an eighteen segment profile** instead of leaving it where you put it. The five profiles are on their own card.
