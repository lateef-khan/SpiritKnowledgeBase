**This is P1, the manual program - not the preset workouts P2 to P6, not the user programs U1 and U2, and not the heart rate programs H1 and H2.** It is also not the F menu of the service software.

**The manual program works as the name implies: you control the workload yourself, not the computer.**

1. **Select the manual program and press the Enter key.**
2. **The Time window asks you to enter your Age.** Adjust it with the **Level + / -** keys, then press **Enter** to accept the number and move on.
3. **You are asked to enter your Weight.** Adjust with the **Level + / -** keys, then press **Enter**.
4. **Next is Time.** Adjust the length of time, then press **Enter**.
5. **Press the Start key to begin.** You can also **press the Stop key to go back one level of the programming screen** and change a setting.
6. **The program starts at level one.** This is the easiest level and **it is a good idea to stay at level one for a while to warm up**. **Level + increases the workload, Level - decreases it**, at any time.
7. **Each time the Display button is pressed, the next set of information appears.**
8. **When the program ends the Message window shows a summary of your workout.** The summary is displayed for a short time, then the console returns to the startup display.

**Step 4's wording is damaged in this manual:** it reads "You may adjust the length of Time by pressing the keys", with the key names missing. Every other setting on this page uses the Level + / - keys.

If you do not want to enter age, weight and time at all, press Start instead of Enter and the stored defaults are used.
