**These are the two heart rate programs H1 and H2 - not the manual program P1, not the presets P2 to P6, and not the user programs U1 and U2.**

**Both operate the same way. The only difference is the default target: one defaults to 60% of maximum heart rate and the other to 80%.** In the printed order, **H1 is set to 60% and H2 is set to 80%**.

**A heart rate monitor is required.** **The Pulse window displays Err if there is no pulse input after the Start key is pressed** - see the error card.

1. **Press the Program key to select a heart rate program and press the Enter key to get in.**
2. **The Time window asks you to enter your Age.** Use the **Level + / -** keys, then press **Enter**.
3. **You are asked to enter your Weight.** Use the **Level + / -** keys, then press **Enter**.
4. **Next is Time.** Adjust and press **Enter**.
5. **Now adjust your Target Heart Rate** - the heart rate you will strive to reach and maintain during the program. Adjust it and press **Enter**.
6. **Press the Start key to begin.**
7. **Press the Level + / - keys at any time during the program to increase or decrease the workload. This changes your Target Heart Rate**, not the resistance directly.
8. **Each time the Display button is pressed, the next set of information appears.**
9. **When the program ends, press Start to run the same program again, or Stop to exit.** These programs do not return to the startup display on their own the way the other programs do.

**This page contradicts itself about going back a step.** Step 6 as printed says "You can also go back and modify your settings by pressing the **Enter** key", and the note immediately after it says "At any time during the editing of Data you can press the **Stop** key to go back one level, or screen". **Every other program in this manual uses Stop to go back one level.** The manual picks no winner and neither does this card.

**Age drives the target.** The console calculates maximum heart rate from the age you entered, and age is a saved default that whoever used the machine last may have changed.
