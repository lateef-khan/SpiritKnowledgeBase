1. **Use the Program key to select the program** (P1~6, U1~2, H1~2).
2. **Press the Enter key to select a program and begin customizing the settings.**
3. **If you want to work out without entering new settings, just press the Start key.** This **bypasses the programming of data and takes you directly to the start of your workout**.
4. **If you start a program without changing the settings, the default settings will be used.**

**Going back:** during setup, **press the Stop key to go back one level of the programming screen**. That is how the manual programs P1 and P2 to P6 describe it.

**The heart rate programs describe going back differently and contradict themselves in the same paragraph.** See the heart rate program card.

**Age and weight are not per workout.** What you enter becomes the new default; see the defaults card.
