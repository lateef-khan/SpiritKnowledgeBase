The hardware is bagged per assembly step. Numbers in parentheses are assembly-drawing item numbers.

**Hardware Step 1**

| Item | Description | Qty |
| --- | --- | --- |
| #171 | 3/8" x 19 x 1.5T Flat Washer | 6 pcs |
| #166 | 5/16" x 20 x 1.5T Flat Washer | 4 pcs |
| #128 | 3/8" x 1-1/2" Hex Head Bolt | 2 pcs |
| #175 | 3/8" x 2T Split Washer | 4 pc |
| #140 | M5 x 10mm Phillips Head Screw | 6 pcs |
| #158 | 3/8" x 7T Nylon Nut | 2 pcs |
| #176 | 5/16" x 1.5T Split Washer | 4 pcs |
| #177 | 5/16" Star Washer | 4 pcs |
| #129 | 3/8" x 3/4" Socket Head Cap Bolt | 4 pcs |
| #124 | 5/16" x 2-1/4" Hex Head Bolt | 4 pcs |

The E25 book draws #129 as a button-head socket cap bolt and the step-1 text fits it with the L Allen wrench. The E55-2019 book prints the same size and count but draws and labels #129 a Hex Head Bolt while its step text still says socket cap; this card follows the E25 drawing, which agrees with its own step text.

**Hardware Step 2**

| Item | Description | Qty |
| --- | --- | --- |
| #65 | Switch Wire Cap | 2 pcs |
| #120 | 5/16" x 18 x 15L Hex Head Bolt | 2 pcs |
| #190 | Wave Washer | 2 pcs |
| #167 | 5/16" x 23 x 1.5T Flat Washer | 2 pcs |

The checklist calls #167 a Nyloc Nut, but the step-2 text fits "two Flat Washers (167)" onto the bolts and the printed dimensions are washer dimensions. This card follows the step text.
