1. Press and hold **Start, Stop and Enter together** until the display shows **"Engineering mode"** (it may say maintenance menu, depending on version). Press Enter.
2. Scroll the menu with the Speed ▲/▼ keys. Use Stop to return to the previous menu selection.

| Item | What it does |
|---|---|
| A. Key Test | Tests all the keys to make sure they are functioning |
| B. Display Test | Tests all the display functions |
| C. Functions | Press Enter to access settings, scroll with Speed ▲/▼ |
| C. I. Display Mode | Turn **off** to have the console power down automatically after 30 minutes of inactivity |
| C. II. Pause Mode | Turn **on** to allow 5 minutes of pause, **off** to have the console pause indefinitely |
| C. III. Maintenance | Reset lube message and odometer readings |
| C. IV. Units | Choose English or Metric display readings |
| C. V. Key Tone | Turns the key beep on or off |
| D. Security | Child lock for the keypad |
| E. Exit | Leave the menu |

The E0 section describes a second way in: remove the safety key, press STOP + START + ENTER and insert the safety key at the same time. Under Functions there is a **DISPLAY MODE** on/off setting that decides whether the display goes dark or shows E0 when the safety key is pulled.
