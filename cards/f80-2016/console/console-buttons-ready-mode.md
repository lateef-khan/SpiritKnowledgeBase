- **SAFETY KEY** - fit it in the right position to power on the computer. Pulling it away shuts the computer down automatically.
- **STOP** - no function.
- **START** - starts the treadmill. There is a **3 second count down** on the window display, then the machine starts running. In MANUAL it starts at MIN SPEED; in PROGRAM it starts at the program preset value.
- **ENTER** - changes each function. MANUAL sets the time. A preset PROGRAM sets time and speed. Heart Rate Control 1~2 sets time, age and the heart rate value. User Program 1~2 sets time, speed and incline.
- **FAST, SLOW, UP, DOWN** - non-functional until a setting has been entered.
- **SPEED RAPID** - 5 preset buttons for rapid speed: 2，3，4，5，7，9，12
- **INCLINE RAPID** - 5preset buttons for rapid incline: 1，3，5，7，9，12，15
- **FAN** - turns the fan on or off.
- **DISPLAY KEY** - after choosing a program, pressing this key shows the speed or incline profile in the dot matrix.
- **ENTER KEY** - before running a program, this button sets the personal profile (for example age).

The console drawing labels **Incline quick keys 1 / 3 / 5 / 7 / 9 / 12 / 15** and **Speed quick keys 2 / 3 / 4 / 5 / 7 / 9 / 12**, and a second pair of key blocks labelled "Incline Quick Keys - Incline UP & DOWN" and "Speed Quick Keys - Speed FAST & SLOW".

**The two rapid-button lines are printed exactly as quoted above.** They say "5 preset buttons" but then list **seven** values each, and the console drawing on the previous page labels seven incline quick keys and seven speed quick keys. There are seven quick keys of each kind.
