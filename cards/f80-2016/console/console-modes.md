- **OFF Mode** - the safety key is not in the console and all windows will appear blank.
- **READY Mode** - the treadmill is on and the safety key is in the console. The message window shows the program profile name and cycle. Press START to start the treadmill in Manual Mode.
- **SLEEP Mode** - pressing any button returns the treadmill to READY Mode.
- **RUN Mode** - pressing STOP and removing the safety key stops the treadmill instantly and returns it to OFF Mode.
