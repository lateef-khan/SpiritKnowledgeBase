- **SAFETY KEY** - pulling it away shuts the computer down automatically.
- **STOP** - stops the treadmill.
- **START** and **ENTER** - non-functional.
- **FAST** - each press increases speed by 0.1 KPH (0.1 mph). Held down, the speed climbs quickly to MAX SPEED.
- **SLOW** - each press decreases speed by 0.1 KPH (0.1 mph). Held down, the speed falls quickly to MIN SPEED.
- **UP** - each press raises the incline by 1. The maximum incline position is **12**.
- **DOWN** - each press lowers the incline by 1. The minimum incline position is 0.
- **SPEED RAPID** - speed will set to 2, 3, 4, 5, 7, 9, 12 quickly.
- **INCLINE RAPID** - incline will set to 1, 3, 5, 7, 9, 12, 15 quickly.
- **FAN** - turns the fan on or off.

**DISPLAY KEY** selects the SPEED or INCLINE profile while a program is being chosen. During a workout it switches the exercise data in the message window; after the switch the system scans and displays automatically **every four seconds**:

- PACE XX:XX
- VERTICAL XXXX M (unit: meter)
- SEG TIME X:XX (not shown in HRC mode)
- SPEED XX.X MAX XX.X (actual speed and max speed)
- DATA SCAN

During DATA SCAN the system scans and displays automatically every four seconds.
