**Size: 144 x 74 x 120 cm. Weight: 80 kg.** Printed once, in that order, as a single line under the
last assembly drawing; there is no specification page, no inch equivalent and no indication of which
figure is length, width or height beyond the order given. Read it as length x width x height.

**This is the only dimension or weight any 4.0R book prints.** The 2025 Spirit owner's manual for the
same recumbent has no specification of any kind
(`spirit-med-bike-specs-which-owners-manuals-print-a-specification-page`), and the service manual
adds none. The Dyaco PT book is undated and carries no revision stamp; the PDF is from February 2016.

The upright 4.0 U's line is 108 x 55 x 136 cm and 60.5 kg (`40u-pt-specs-size-and-weight`). No
shipping weight or carton size is printed in either.
