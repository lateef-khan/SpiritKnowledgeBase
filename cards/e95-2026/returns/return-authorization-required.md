> **DO NOT SHIP ANY UNIT TO OUR FACTORY WITHOUT A RETURN AUTHORIZATION NUMBER. All units arriving without a return authorization number will be refused.**

Three related conditions sit in the same paragraph:

- **All transportation costs, both to the factory and upon return to the owner, are the responsibility of the owner.**
- **The owner is responsible for adequate packaging** upon return to SOLE.
- **SOLE is not responsible for damages that occur during shipping**; make all freight damage claims with the appropriate freight carrier.

The manual does not say who issues the return authorization number; the service steps route every request through the selling dealer, the online service request form, or **866-780-7653**.
