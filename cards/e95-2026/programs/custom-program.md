**Custom is a program with fully customizable resistance and incline patterns.**

1. On the program setup page, press **"Add Pattern"** to enter edit mode.
2. **Connect dots to map your load throughout the program**, from **easiest on the bottom to hardest on the top**.
3. **Each segment's duration depends on the selected total time** - you can set the total time right before start.

How the two axes behave is different, and the manual is explicit about it:

- **Resistance values are relative.** The maximum can be changed before each workout, and **all the segments will be adjusted proportionally**.
- **Incline values are absolute** and can be set directly.
- **The incline pattern is optional.**

A custom program can be kept for reuse by saving it as a **template**.
