The XE150 console has **12 preset programs**. There are no per-program keys: after power up or
reset, press the Up/Down keys to highlight the **Program icon**, then press **Mode** to enter program
mode.

The display shows **P1** for two seconds, then changes to the P1 program profile. Keep pressing
Up/Down to scroll through the 12 programs. When you see one you want, press **Mode** to enter. At
that point you may press **Start** to begin with the default settings, or customise it:

1. Press **Up** to raise the work level; the profile grows on screen. Press **Mode** when it is where
   you want it, or press Mode straight away to bypass this step.
2. The **Time** window blinks. Set the workout time with Up/Down, then Mode.
3. The **Distance** window blinks. Set a distance to count down if you want one, then Mode.
4. The **Calorie** window blinks. Set it the same way, then Mode.
5. The **Pulse** window blinks. **Entering a Pulse number sets an alarm** that beeps when your heart
   rate reaches that number, to tell you that you have reached your target.

Press **Start** to begin. You may also press Start at any point during programming; **any data not
programmed at that point counts up from zero.**

When the program ends there is a series of audible beeps. Press **Start** to restart the program or
**Reset** to return to the start-up screen.

**The manual names none of the twelve and prints no profile table for them**, so this KB holds no
list of what P1 to P12 do.

**The XE350 and XE550 in the same manual are different machines here.** They have per-program keys
and **five** named presets - Hill, Fat Burn, Cardio, Strength and Interval - set up a different way.
Do not answer "12 programs" for an XE350 or XE550.
