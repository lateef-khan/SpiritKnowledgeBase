The User mode lets you build and save your own custom program.

1. Press **Up** or **Down** until the **User icon** at the top of the display is blinking, then press
   **Mode**.
2. The **first column** of the profile blinks. Use Up/Down to set the work level, then press Mode.
3. The **second column** blinks. Repeat.
4. Carry on until all the columns are set to your liking.

**All the settings are then saved as a custom program.** The manual gives no save keystroke, no
program name, and **does not say how many columns there are** - so this KB does not hold a segment
count for the XE150.

**The XE350 and XE550 in the same manual have two User programs instead**, each with a name and
twenty segments - see `spirit-xe-programs-user-one-and-user-two-store-twenty-segments`.
