**This console has no program keys and no number pad.** Everything is chosen from a **row of icons
along the top of the display** using **Up**, **Down** and **Mode**.

- **Highlight an icon with the Up/Down keys, then press Mode to enter it.** The icons named in the
  manual are **Manual**, **Program**, **User**, **Target HR** and an **age** icon inside Target HR.
- **Inside a mode, whatever is blinking is what you are setting.** Adjust it with Up/Down, then press
  **Mode** to accept and move on. The order in Manual is profile work level, then Time, then
  Distance, then Calories, then Watts.
- **Press Start at any point to begin.** Anything not yet set counts up from zero.
- **Press Reset to return to the start-up screen.**

**Quick Start needs nothing but Start.** After the console powers up, press **Start** and the Time
counts up from zero with the workload on the Up/Down buttons.

**Preset programs are numbered, not named.** There are **12**, reached through the **Program** icon:
the display shows **P1** for two seconds then the P1 profile, and Up/Down scrolls through all twelve.

**When a program ends there is a series of audible beeps.** Press **Start** to run it again or
**Reset** to go back to the start-up screen.

**Do not use the XE350 and XE550 instructions on this machine.** Those two share the rest of this
manual and work completely differently - one key per program, a numeric key pad, an Enter key, a
Display key and a Stop/Reset with a five-minute pause. None of that exists here. See
`spirit-ce-console-program-key-previews-the-profile` and
`spirit-ce-console-stop-button-press-once-twice-hold` for what those two do instead.

**The manual prints no console drawing text for this machine.** Its control-panel illustration on
p. 16 carries no call-out labels that survive extraction, so **no key layout should be quoted beyond
the keys named in the text above**: Start, Reset, Mode, Up, Down and Recovery.
