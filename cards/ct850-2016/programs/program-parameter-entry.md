Press **ENTER** in READY mode to change each function. What you can set depends on the program:

| Program | What you can set |
|---|---|
| MANUAL | Time |
| Pre-set PROGRAM | Time and speed |
| Control (heart rate control) | Time, age and the value of heart rate |
| User Program 1~2 | Time, speed and incline |

Press **ENTER** to confirm each setting and **START** to finish setting and begin. Pressing the
**DISPLAY** key while selecting a program chooses whether the profile shown is SPEED or INCLINE.

**This manual prints no list of program names, no profile chart and no fitness tests.** It names only
the four types above. Anything more specific would have to come from the owner's manual, not from
this service manual.
