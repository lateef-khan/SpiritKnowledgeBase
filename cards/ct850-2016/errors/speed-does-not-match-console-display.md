| Condition | Reason | Solve |
|---|---|---|
| The speed of the belt doesn't match console display | Console is not calibrated | Calibrate the console |

**The CT850 2020 manual does not print this row.** It keeps only the matching incline row.

The incline equivalent, which both manuals print, is
`ct850-2016-incline-position-does-not-match-console`. A treadmill that reaches only about 7 mph while
showing more is a supply problem, not a calibration problem: `ct850-2016-only-reaches-7-mph`.
