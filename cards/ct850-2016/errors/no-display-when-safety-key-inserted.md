Eight causes, in the order the manual lists them.

| Reason | Solve |
|---|---|
| Haven't switch ON/OFF switch | Switch the AC switch |
| Insert the Safe key on wrong position | Insert the safe key on right position |
| 12 PIN Computer connector not plugged in properly | Please check the wire and connect again |
| 12 PIN computer cable is broken | Replace 12 PIN computer cable |
| Fuse on controller is blown | Replace fuse or controller |
| Varistor on controller is blown | Replace varistor or controller |
| Safety device is broken (open) | Replace safety key device |
| Other components are faulty | Replace console |

This machine uses a **12-pin** computer cable between console and controller. The CT850 2020 manual
prints the same row but names a plain `console connector` and `console cable` instead:
`ct850-2020-no-display-when-safety-key-inserted`.
