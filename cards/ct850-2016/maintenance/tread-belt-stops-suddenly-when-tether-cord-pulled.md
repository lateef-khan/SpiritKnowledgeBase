| Problem | Solution/cause |
|---|---|
| Tread-belt stops quickly/suddenly when tether cord is pulled | High belt/deck friction. |

That one line is the whole answer this manual gives.

A belt that stops dead instead of coasting is being dragged by the deck. The same cause — high
belt/deck friction — is what this manual gives for the treadmill tripping its own onboard breaker
(`ct850-2016-trips-onboard-10-amp-circuit`), so treat the two symptoms as one problem. Clean the
belt and deck first (`ct850-2016-tread-belt-and-deck-cleaning`), then check tension
(`ct850-2016-tread-belt-tension-adjustment`).

**This row is printed only in the 2016 manual.** The CT850 2020 diagnosis guide (section 8-6) does
not contain it. It is not evidence that the 2020 machine behaves differently, only that the 2020
document is silent.

This is a friction symptom, not a safety-key fault. If the machine keeps running with the key out,
or will not run with it in, those are different rows —
`ct850-2016-does-not-stop-after-safety-key-removed` and
`ct850-2016-no-display-when-safety-key-inserted`.
