| Key | Behaviour in RUN mode |
|---|---|
| SAFETY KEY | Pull it away and the computer shuts down automatically. |
| STOP | Stops the treadmill. |
| START | Non-functional. |
| ENTER | Non-functional. |
| FAST | Each press increases speed by **0.1 kph (0.1 mph)**. Held down, speed rises quickly to MAX SPEED. |
| SLOW | Each press decreases speed by 0.1 kph (0.1 mph). Held down, speed falls quickly to MIN SPEED. |
| UP | Each press raises the incline position by 1. |
| DOWN | Each press lowers the incline position by 1; the minimum is 0. |
| SPEED / INCLINE QUICK | Preset buttons for rapid speed and incline. |
| FAN | Turns the fan on and off. |
| DISPLAY | Switches the exercise data shown in the message window. |

After a DISPLAY press the system scans and displays automatically **every four seconds**, cycling:

```
PROGRAM NAME
LAPS   XX
VERT       XXX FT   (metric units show "KM")
SEG TIME XX:XX      (not shown in HRC MODE)
MAX SPEED  XX:XX    (not shown in HRC or MANUAL MODE)
```

**The UP key description says "the maximum incline position is 12".** The Function table earlier in
the same manual gives the incline work range and preset range as 0 to 15, and the calibration
procedure sets maximum elevation to 15. The 12 here does not agree with the rest of the manual.

The FAST and SLOW step is printed as "0.1kph(0.1mph)" - the same number for both units, which cannot
be true of both. The Function table gives the step as 0.1 mph.
