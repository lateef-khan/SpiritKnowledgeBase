**This Functions list has six entries; the CT850-2020 owner's manual prints the same menu with
five.** The 2020 manual has no **Units** entry between Maintenance and GS Mode
(`ct900-engineering-mode-menu` covers that machine). The sleep figure here is **30 minutes**, where
the CT800 menu with a Units entry prints 20 (`spirit-ct800-console-engineering-mode-menu-with-units`).

The console has built in maintenance/diagnostic software. It will, for example, change the console
settings from English to Metric and turn off the beeping of the speaker when a button is pressed.

**To enter: press and hold the Start, Stop and Enter buttons, then insert the safety button.** Keep
holding the buttons down for about 5 seconds until the Message Center displays **Engineering Mode
Menu**, then press **Enter**.

| Item | What it does |
|---|---|
| 1. Key Test | Test all the buttons to make sure they are functioning |
| 2. Display Test | Tests all the display functions |
| 3. Security | Allows the keypad to be locked to prevent unauthorized use |
| 4. Functions | Press Enter to access settings, Up arrow to scroll |
| 5. Security | Sets the Child Lock function |

Under **Functions**:

| Setting | What it does |
|---|---|
| a. Sleep Mode | Turn on to have the console power down automatically after **30 minutes** of inactivity |
| b. Pause Mode | Turn on to allow 5 minutes of pause, turn off to have the console pause indefinitely |
| c. Maintenance | Reset maintenance reminder message and odometer readings |
| d. Units | Sets the display to readout in Imperial (miles, pounds, feet, etc.) or Metric (kilometers, kilograms, meters, etc.) display measurements |
| e. GS Mode | Returns the elevation to lowest setting when pause is pressed |
| f. Beep Mode | Turns the speaker (beep sound) on or off |

**Security is printed twice**, as item 3 and again as item 5. Item 5 gives the Child Lock, which
locks out the keypad until a pre-determined key sequence is pressed: **key sequence = Incline UP
held down together until unlocked.** The manual prints it exactly that way; it names one key where
"held down together" implies two, and nothing else in the manual resolves what the second key is.

**This is not the menu the CT850-2016 service manual describes.** That manual enters engineering
mode with SPEED and ENTER and the safety key, and lists the items in a different order:
`ct850-2016-engineering-mode-menu`. The two documents describe the same machine and disagree about
the entry gesture, so read both before you go looking for the menu.

**Calibration is not in this menu.** It has its own entry gesture and its own "Factory settings"
prompt: `ct850-2016-console-calibration-minimum-speed-0-5`.
