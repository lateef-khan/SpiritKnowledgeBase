**To enter:** remove the safety key, press **SPEED** and **ENTER** at the same time, then return the
safety key until **"ENGINEERING MODE"** is displayed. Press **ENTER** again.

Scroll with the **UP/DOWN or FAST/SLOW** keys. **ENTER** runs the selected item. **STOP** returns to
the previous menu selection, and from the top level exits to idle mode.

| Menu item | What it does |
|---|---|
| 1) Key Test | Press each key to verify it is working. Press ENTER to run. |
| 2) Display test | Lights all LED lights. Press ENTER to run. |
| 3) Functions | Press ENTER to open the sub-menu below. |
| 4) Security | Sets the Child Lock function. |
| 5) | Press STOP to exit and return to idle mode. |

Under **Functions**:

| Setting | What it does |
|---|---|
| Sleep | Turns sleep mode on or off. When off, the display is always lit. |
| Pause | Turns pause mode on or off. When on, Pause lasts **5 minutes**. |
| Maintenance | Resets the odometer reading. |
| Units | Sets the display to English or Metric readings. |
| Grade Return (GS Mode) | Returns the elevation to the lowest setting when pause is pressed. |
| Beep | Turns the speaker (beep sound) on or off. |

**Child Lock:** it locks out the keypad until a pre-determined key sequence is pressed. When Child
Lock is on, at power on and before idle mode the message window displays **"CONSOLE LOCKED"**; press
numeric key **0** and **Enter** at the same time to unlock the console and return to idle mode.

Engineering mode is **not** where calibration lives. Calibration has its own entry sequence -
INCLINE + SPEED with the safety key - and its own menu headed "Factory settings".
