The manual labels five areas.

| Call-out | What it is |
|---|---|
| DISPLAY | The LED display panel, called "LED Display" on the Display Windows page |
| PROGRAM BUTTONS | The grid of keys under the display |
| CONTROL KEYS | The keypad in the middle of the handlebar: START, UP, FAST, DOWN, SLOW, STOP |
| Fan Key | "Cooling fan switch on or off" |
| Speed / Incline quick keys | The preset keys for rapid speed and incline |

The safety key hangs from the middle of the handlebar keypad, below START.

The LED panel holds a dot-matrix profile window, a row of small data windows above three larger
numeric windows, and a bar graph column. Only the three large windows - **INCLINE**, **TIME** and
**SPEED** - are legible in the 300 dpi render; the small window labels are not. The readings the
console shows, from the Function text in the same section, are SPEED, INCLINE, TIME, LAPS, DISTANCE,
CALORIES and PULSE.

**Do not use the page headed "LCD Layout".** It is a photograph of the bare display board
(DYACO ST8100-U01-C / S5600 V1.2), not a drawing of the console face, and it carries no labels.
