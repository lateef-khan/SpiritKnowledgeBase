| Mode | What it means |
|---|---|
| OFF | The SAFETY KEY is not on the console. All windows are blank. |
| READY | Power is on and the SAFETY KEY is in. The message window shows the program profile name and cycle. Press START to start the treadmill in Manual Mode. |
| SLEEP | Press any button and the treadmill enters READY Mode. |
| RUN | Pressing STOP **and** removing the SAFETY KEY stops the treadmill instantly and it enters OFF Mode. |

A blank display with the safety key fitted is a fault, not OFF mode.

**Twelve more service manuals print these same four modes**, so this card now covers the CT800-2016,
the XT185, XT285, XT385 and XT485 of 2015, the XT185, XT285, XT385, XT485 and XT685 of 2023, and the
XT485ENT and XT685ENT touchscreens. The wording differs in one place only:

- **OFF mode.** The CT800-2016, the XT385-2015, the XT485-2015 and the XT485ENT say "all windows
  will appear blank". The XT185-2015, the XT285-2015 and the five 2023 XT books say only that the
  treadmill enters OFF Mode. **The XT685ENT says the
  window shows "PLEASE REPLACE THE SAFETY KEY"** - on that touchscreen OFF mode is a message, not a
  blank screen, and its READY mode "will show programs name for choosing and quick start for tap to
  begin workout" rather than a program profile name and cycle.

The LED consoles' SLEEP mode time-out is a setting in engineering mode - Display Mode or Sleep Mode
depending on the book (`xt-2015-console-engineering-functions-key-tone`,
`xt-2023-console-engineering-functions`); the XT685ENT's is a three-position switch on its Settings
page (`xt685ent-2023-console-settings-page-ten-items-with-a-retail-sleep-mode`).
