| Mode | What it means |
|---|---|
| OFF | The SAFETY KEY is not on the console. All windows are blank. |
| READY | Power is on and the SAFETY KEY is in. The message window shows the program profile name and cycle. Press START to start the treadmill in Manual Mode. |
| SLEEP | Press any button and the treadmill enters READY Mode. |
| RUN | Pressing STOP **and** removing the SAFETY KEY stops the treadmill instantly and it enters OFF Mode. |

A blank display with the safety key fitted is a fault, not OFF mode.
