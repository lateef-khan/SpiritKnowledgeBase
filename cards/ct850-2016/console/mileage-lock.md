**To set it:**

1. Remove the safety key, press and hold numeric keys **1, 2 and 3** together, then return the
   safety key to enter the setting function.
2. The message window displays **"LOCK SETTING = ON/OFF"**.
3. Press FAST / SLOW / UP / DOWN to set On or Off, then press **ENTER**.
4. Off returns to idle mode. On continues to the code setting procedure.
5. The message window displays `PASSWORD= ＊＊＊＊`. Use the numeric keys to set a **4-digit**
   security code. Press ENTER.
6. Enter the code again to confirm. Press ENTER.
7. The message window shows **"MILEAGE XXX Km"**. Use UP/DOWN or FAST/SLOW to set the required
   mileage, then press ENTER. The window shows **"Lock Setting OK"** and returns to idle mode.

**To unlock:** press and hold numeric keys **1, 2 and 3** together to enter the unlocking function.

The mileage is set in **kilometres**. The manual gives no allowed range for the mileage value and no
master password for a forgotten code - unlike the Child Lock in engineering mode, which is cleared
with 0 + Enter, and unlike the touchscreen consoles in this family, which accept 2222.
