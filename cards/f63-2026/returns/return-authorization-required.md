**DO NOT SHIP ANY UNIT TO THE FACTORY WITHOUT A RETURN AUTHORIZATION NUMBER. All units arriving without a return authorization number will be refused.**

If a unit does go back:

- **All transportation costs, both to the factory and on return to the owner, are the responsibility of the owner.**
- **The owner is responsible for adequate packaging** on return to SOLE.
- **SOLE is not responsible for damage that occurs during shipping.**
- **Make all freight damage claims with the appropriate freight carrier.**

Before returning the product to a retailer, or for any assistance with assembly or technical support, the manual asks you to **call 866-780-7653 first**. That line is printed on both the front and back covers.

The steps that come before a return are on `f63-2026-how-to-get-warranty-service`.
