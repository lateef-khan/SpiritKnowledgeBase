The console is telling you the **safety key is not in position**.

Printed exactly as it appears in the manual:

> If the console displays SAFE. Please replace the key to Operate", put the Safety key back to continue using the treadmill.

(The stray closing quotation mark is in the printed text.)

**Put the safety key back on the console to continue.**

This is different from a console that shows **nothing at all** with the key fitted; that is a fault. See `f63-2026-no-display-with-safety-key`.

How the key and tether are meant to be used is on `f63-2026-safety-tether-cord`.
