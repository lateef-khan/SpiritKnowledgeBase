1. **Press the Program keys** to view the programs, then press **Display/Enter** to select one. The presets are **P2-Hill, P3-Fat Burn, P4-Cardio, P5-Strength, P6-Interval**. Or just press Start to begin using the preset values.
2. The **incline window displays Age**. Adjust with the speed knob key, then press Display/Enter.
3. The **incline window then displays your body weight**. Adjust, then press Display/Enter.
4. The **time window then displays the total workout time desired**. Adjust, then press Display/Enter.
5. **The speed window displays the preset max speed of the selected program.** Adjust with the speed knob key, then press Display/Enter. Each program has various speed changes throughout; **this lets you limit the highest speed the program will reach at its peak.**
6. **Press Start to begin.** The program begins with a **3 minute warm-up**. **To bypass the warm-up and go directly to the beginning of the program, press Start again.**

**You may press Start at any time during the programming** to start with the information you have already entered.

The max speed cap (step 5) and the 3 minute warm-up (step 6) are the two things this page adds over the manual program setup.

The per-segment speed and incline of each preset are on their own cards, starting at `f63-2026-hill-program-profile`.
