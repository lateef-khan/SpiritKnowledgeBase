1. **Press the Program keys** to view the programs on the screen, then press **Display/Enter** to select the program you want. **Or just press Start** to begin using the preset program values for age, weight and other program specific information.
2. If Display/Enter was pressed, the **incline window displays Age**. Adjust it with the **speed knob key**, then press Display/Enter.
3. The **incline window then displays your body weight**. **Entering the correct body weight affects the calorie count.** Adjust with the speed knob key, then press Display/Enter.
4. The **time window then displays the total workout time desired**. Adjust with the speed knob key, then press Display/Enter.
5. **Press Start to begin the program.**

**You may press Start at any time during the programming** to start the program with the information you have already entered.

The console shows the manual program as **P1**.
