1. **Attach the safety key** to wake the display up, if it is not already on.
2. **Press the Start key to begin belt movement.** Use the **speed knob button** to adjust to the desired speed. You may also use the **speed keys 3, 6, 9, 12**.
3. To slow the tread belt down, use the speed knob, or press the speed adjust keys 3 through 12.
4. To stop the tread belt, **press the Stop key or pull away the safety key.**

Speed and incline do not change instantly: set the value on the console and release the adjustment key, and the computer obeys the command gradually.

The service manual card `f63-2026-console-buttons-run-mode` covers what every key does while the belt is moving, including the 3 second countdown before the belt starts.
