| Readout | Display range | Working range |
|---|---|---|
| SPEED | 0.0 to 99.9 | **0.5~12 Mile**. Each press of FAST or SLOW changes it by 0.1 km/h (mph) |
| INCLINE | 0 to 99.9 | **0 to 15**. Preset value 0 to 15. Each press of UP or DOWN changes it by 1 |
| TIME | 0:00 to 99:99 | 0:00 to 99:59. Count down setup range 10:00 to 99:00 |
| PACE | 99.99 | 0.00 to 99.59. With no speed it shows 0.00 |
| DISTANCE | 0.00 to 99.99 | 0.00 to 99.9 |
| CALORIES | 0.0 to 9999 | 0.0 to 999 |
| PULSE | 0 to 999 | **60 to 200 BPM** |
| LAPS | 0 to 999 | 0 to 99 |

**PACE** is new on this console: it calculates how long it takes to walk a kilometre or a mile, as a time.

Time counts up by default; if the user sets a time it counts down.

Pulse comes **from a receiver, with a chest belt worn**. **If the treadmill has no pulse signal for 3 seconds the displayed value becomes 0**, which is shorter than the 8 seconds used on earlier models.

**The manual gives no kilometre working range for speed**, only the 0.5 to 12 mile figure.
