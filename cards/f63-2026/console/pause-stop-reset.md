| Action | What happens |
|---|---|
| **Stop pressed once** while running | Pause. The tread belt decelerates slowly to a stop and **the incline goes to zero percent**. Time, distance and calorie readings hold. **After 5 minutes the display resets and returns to the start up screen.** |
| **Start pressed while paused** | The workout resumes. **Speed and incline return to their previous settings.** |
| **Stop pressed a second time** | The program ends and a **workout summary** is displayed. |
| **Stop pressed a third time** | The console returns to the **idle mode (start up) screen**. |
| **Stop held down for more than 3 seconds** | The **console resets**. |

The 5 minute pause timeout is configurable: the engineering mode menu has a **Pause Mode** item - on allows 5 minutes of pause, off lets the console pause indefinitely. See `f63-2026-engineering-mode`.
