The program function has **9 programs**: Manual, Hill, Fat Burn, Cardio, Strength, **HIIT**, Interval, User x2 and HRC x2. It also has USER1 and USER2.

**What the LED display shows for each**

| Program | LED shows |
|---|---|
| Manual | P1 |
| Hill | P2 |
| Fat Burn | P3 |
| Cardio | P4 |
| Strength | P5 |
| Interval | P6 |
| User x2 | U1 ~ U2 |
| HRC x2 | H1 ~ H2 |

Choose one by turning the rotary switch PROGRAM key, confirm every setting with ENTER, then press START.

**HIIT is new on this model** and is counted in the nine, but the LED code table above does not list a code for it.
