The calorie window **displays the cumulative calories burned at any given time during your workout.**

**Note: this is only a rough guide used for comparison of different exercise sessions, which cannot be used for medical purposes.**

The programming pages state the same limit in more detail: **no exercise machine can give you an exact calorie count**, because too many factors determine calorie burn for a particular person. Even someone of the exact same body weight, age and height may burn very differently. **The calorie display is to be used as a reference only, to monitor improvement from workout to workout.**

**Entering the correct body weight during programming affects the calorie count.** See `f63-2026-manual-program-setup`.
