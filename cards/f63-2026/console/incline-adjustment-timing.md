**Incline may be adjusted anytime after belt movement.** It is not adjusted before the belt starts.

- Use the **incline knob** to adjust.
- For a more rapid increase or decrease, select the desired key **0, 5, 10 or 15** on the left hand side of the console.
- **The incline window indicates the incline position as adjustments are made.**

**Changes do not occur immediately.** Set the desired value and release the adjustment key; the computer obeys the command gradually.

Pressing Stop once sends the incline to zero percent; see `f63-2026-pause-stop-reset`. An incline that will not move at all and shows an error code is a different problem; see `f63-2026-e3-error-code`.
