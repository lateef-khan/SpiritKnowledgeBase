In RUN MODE:

- **SAFETY KEY** - pull it away and the computer shuts down automatically.
- **STOP button** - stops the treadmill.
- **START** and **ENTER** - non-functional.
- **Rotary Switch FAST/SLOW** - changes speed by 0.1 KPH (0.1 mph) per press. Held down, the speed runs quickly to MAX SPEED.
- **Rotary Switch UP/DOWN** - changes the incline position by 1 per press. **The maximum incline position is 15 and the minimum is 0.**
- **SPEED RAPID** - **4** preset buttons: **3, 6, 9, 12 MI**.
- **INCLINE RAPID** - **4** preset buttons: **0, 5, 10, 15**.
- **FAN button** - turns the fan on and off.
- **PROGRAM KEY** - non-functional.

The 4 speed and 4 incline quick keys are fewer than the 7 each used on the earlier F63.
