In READY MODE:

- **SAFETY KEY** - fit it in the right position to power on the computer. Pull it away and the computer shuts down automatically.
- **STOP button** - no function.
- **START button** - starts the treadmill. There is a **3 second countdown** on the window display, then the machine starts running. In MANUAL it starts at MIN SPEED; in a PROGRAM it starts at the program preset value.
- **ENTER button** - changes each function. MANUAL sets time. A pre-set PROGRAM sets time and speed. Heart Rate Control 1~2 sets time, age and the heart rate value. User Program 1~2 sets time, speed and incline. It also swaps and polls the incline and speed profile display.
- **Rotary Switch FAST/SLOW** and **Rotary Switch UP/DOWN** - non-functional unless the user has entered a setting.
- **SPEED RAPID** and **INCLINE RAPID** - non-functional in this mode.
- **FAN button** - turns the fan on and off.
- **PROGRAM KEY** - turn the rotary switch to choose, confirm every setting with ENTER, then press START.

The console also has an **NFC reader** and a **USB Type-C** socket.
