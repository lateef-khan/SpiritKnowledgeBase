**This is E1, not E2 (tension motor). This machine has no E3.**

Definition: all screens are off and outputs stop when the EEPROM is damaged or malfunctions. The display message shows **"E-1"**.

Troubleshooting: **replace the upper controller.** The manual gives no other step for E1.

The error table prints the meaning as "EEPROM failure", and writes the code as **E1** while the section heading and the definition write it as **E-1**.

**The error table on this machine lists only E1 and E2.** The 2016 Sole elliptical manuals add E3 for the incline VR; this machine has no incline motor and no E3.
