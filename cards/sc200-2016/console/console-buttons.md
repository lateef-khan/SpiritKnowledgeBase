The program buttons are MANUAL, HILL, FAT BURN, CARDIO, INTERVAL, USER 1 & 2 and HR1 & 2.

**READY MODE**
- STOP: non-function.
- START: starts the machine after a 3 second countdown on the window display. In MANUAL it starts at MIN LEVEL.
- LEVEL UP / LEVEL DOWN: non-functional if the user has not entered a setting.
- FAN: controls fan ON/OFF.
- ENTER: enters parameter setting, and confirms or modifies a parameter.

**RUN MODE**
- STOP: stops the machine.
- START and ENTER: non-functional.
- LEVEL UP / LEVEL DOWN: each press changes level by 1.
- FAN: controls fan ON/OFF.
- DISPLAY: switches the exercise data. If the information shown is the latest data, pressing DISPLAY lights the SCAN icon and the message window auto displays every four seconds on a cycle. The cycle first shows **SEG TIME XX:XX**, then **FLOORS XXXX**, **FPM XX.X** and **L XX MAX LV XX** (program mode only).

**There are no incline or stride keys on this console**, and no DISPLAY key entry in READY MODE. The source writes the START and STOP descriptions about "the bike".
