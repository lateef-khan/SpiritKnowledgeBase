**IDLE MODE** - each program profile is displayed on the message window and held for **5 seconds**, cycling the program profile at the same time. The heart rate bar LED stands lit. The 7-segment data window shows **SPM = 60, CALORIES = 681, TIME = 30:00, PULSE = 125**.

**DISPLAY MODE** - pre-set is DISPLAY ON (disabled); set it in Engineering Mode. With the setting "ON" the console will not enter sleep mode unless the power is turned off. With no SPM input in idle mode the console enters sleep mode after **30 minutes** without a key press. In display mode the LCD shows nothing and the backlight is off; press any key to wake it. **Resistance in sleep mode: Incline = 1, fan off.** (The source names an incline; this machine has none.)

**CHILD LOCK MODE** - pre-set is CHILD LOCK OFF; set it in Engineering Mode. The message window shows "CONSOLE LOCKED", then "CHILD LOCK-ON PRESS START AND ENTER TO ENABLE OPERATION". Turn it off by **pressing START and ENTER for more than two seconds**. All keys are dead while child lock is active.

**EXERCISE MODE (QUICK START)** - from idle, press START to enter manual mode. Age and weight are preset values, time counts up from 00:00, all countable data counts up from 0 and resistance counts up from 1. Programs are chosen with **MANUAL, PROGRAM and HRC**, then START.

**PAUSE MODE** - press STOP. Exercise parameters are recorded and the window shows "PAUSE"; after 5 seconds the message window shows "PRESS START TO RESUME OR STOP TO END". It returns to idle after **five minutes** with no key press. The resistance level should return to 1, and the tension motor returns to the pre-pause level when START is pressed.

**END MODE** - the message window shows "WORKOUT SUMMARY" and displays workout data for 3 minutes, cycling every three seconds through **AVG LEVEL XX, FLOORS XXX, AVG FPM XX.X**; level and stride show average values and calories and time show totals. The system enters idle mode after **3 minutes** with no key press.

**RESET MODE** - in idle, hold STOP for **more than three seconds**. You must leave console lock mode first.
