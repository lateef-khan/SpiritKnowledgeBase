The *Remarks* under Computer Operation are the whole of this book's troubleshooting:

1. Computer requires two "AA" batteries.
2. The computer will turn on automatically by pressing any key or when you start pedaling.
3. The computer will turn off automatically if no signal is detected for around four minutes.
4. **If computer is illegible or partial segments appear, remove batteries and wait 15 seconds to
   re-install.** Removing the batteries will reset all values to zero.

The remedy is a power reset, not a part: pull both AA cells, count fifteen seconds, refit them. Expect the
odometer and every other stored value to read zero afterwards - the book says so on the previous page too
(*All the values will reset to ZERO automatically when change the batteries*). A screen that is simply dark
on an idle machine has switched itself off under remark 3.

The EU100 book has no troubleshooting section and prints no error code
(`xterra-errors-owner-manual-has-no-troubleshooting-section-and-no-error-code-table`).
