**Buttons.** MODE - select the function (the key text lists "Scan, Time, Count, Calories and Total Count", a stray line from another console; the functions the page then describes are Time, Speed, Distance, Calories, Odometer and Pulse, and the card follows those). SET - set the values of time, count and calories. RESET - reset the function value to zero; hold 2 seconds to reset everything except the odometer. All values reset to zero when the batteries are changed.

| Function | As printed |
|---|---|
| Scan | Each function in sequence every 6 seconds: Time - Speed - Distance - Calories - Odometer - Pulse |
| Time | Elapsed time up to 99:00; counts down from a preset to 00:00 |
| Speed | Current speed "up to 999 MILE" |
| Distance | Up to 999 miles; counts down from a preset to 0.0 |
| Calories | Up to 999 cal; counts down from a preset to 0.0 - a rough guide, not for medical purposes |
| Odometer | Total distance up to 9999 miles |
| Pulse | Current heart rate in BPM; **both hands must hold the gripped pulse** |

**Presetting a value.** Press MODE until the function shows, press SET until the number you want shows, press MODE to accept; hold MODE a few seconds to zero everything except ODO. The computer counts down from the preset once you exercise and **beeps when the preset is reached** - press any button to stop the beep and it counts up from there. With several presets, each sounds its alarm in turn as it is reached.

**Remarks.** The computer takes **two "AA" batteries**; it turns on with any key or when you pedal and off after about four minutes without a signal ([auto-off card](../../shared/console/xterra-console-battery-console-wakes-on-pedalling-and-sleeps-after-4-minutes.md)). **If the display is illegible or shows partial segments, remove the batteries, wait 15 seconds and reinstall them** - removing them resets all values to zero.
