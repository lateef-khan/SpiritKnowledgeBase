**Yes, the stride is powered and the console drives it. No, the manual never says
how long it is.**

The XE895-2018 owner's manual is the only Spirit residential elliptical or E-Glide
manual in which the word *stride* appears at all - eight times in the text layer
and seven more in the flat images of the program pages - and every one of them is
the adjustment mechanism:

| Where | What it says |
|---|---|
| p. 14, assembly | The upper handle wire is labelled **RESISTANCE/STRIDE**, red, item 62 |
| p. 26, Custom User 1 and User 2 | After you have set a resistance level for all twenty segments, "you are asked to adjust the stride Level ... for the first segment", then the same for all twenty |
| pp. 27-28, preset programs | Each of the five presets prints **two** profile pictures - a Work Profile and a **Stride Profile** |
| p. 36, Engineering Mode | **Stride Calibration**: hold Start, Level up and Stop together for 5 seconds and it runs automatically |

## What the manual does not state

- **No stride length**, in inches or centimetres, at either end of the travel.
- **No shortest and longest setting**, and no fixed length.
- **No count of stride levels**, and no step size. The resistance scale is stated -
  20 levels - but nothing anywhere attaches a number to the stride scale.
- **No stride up or down key.** The custom-program steps set stride levels with the
  Level Up/Down keys during setup. The console call-out drawing on p. 17 shows one
  row of keys - FAN, START, LEVEL - and +, STOP, ENTER and a music-note key - with
  no stride key and no incline key on the console face, and no passage describes
  changing the stride mid-workout.

There is no specification table in this book to supply any of it - see
`spirit-xe-specs-no-specification-table`. Get a stride length from Spirit Fitness
or the product spec sheet and say the owner's manual does not print one.

## Do not answer this with the CE850's 18 to 24 inches

`spirit-ce850-specs-stride-length-18-to-24-inches` is the only Spirit elliptical
card that carries a stride length, and it is a **commercial CE850** figure from a
different machine with a different mechanism. Quoting it for an XE895 invents a
number this book never printed.

## The book is an edit of the XE395 book, and two places were missed

The XE895's stride occupies exactly the places the XE395's powered incline occupies
in its own book - the handle wiring, the per-segment program setup, the second
profile picture and the calibration routine. Two places were not changed over:

- **p. 12, assembly.** The upper handle wire is labelled **RESISTANCE/ INCLINE
  (White/Red)** two pages before the same wire is labelled RESISTANCE/STRIDE on
  p. 14.
- **p. 17, the console drawing.** The readout window beside LEVEL is labelled
  **INCLINE**. The drawing is the XE395's artwork reused unchanged - the XE395-2018
  book prints the identical console picture on its own p. 18, down to the same key
  row - and the XE895 text never once describes an incline readout.

Both are flat images or native labels in the drawing, not OCR artefacts; the
console page was rendered at 300 dpi and read to confirm it.

**Nothing else in the book gives the XE895 an incline** - no incline key, no incline
rail, no incline profile in any program, no Incline on/off step in program setup and
no Incline Calibration. Treat the two leftovers as artwork errors, and do not tell a
customer the XE895 has an incline. Equally, **do not tell them the LEVEL window
reads out a stride**: the book never says what, if anything, displays the stride
level during a workout. See `spirit-xe-specs-which-machines-have-a-power-incline`.
