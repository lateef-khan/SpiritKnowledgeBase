**If there is a problem with the stride, try running a calibration test.**

1. Press the **Start key, Level up key and Stop key at the same time**.
2. **Hold them down for 5 seconds.** The stride calibration then **starts and runs
   automatically**.
3. **If the problem persists, contact the service department.**

That is the whole paragraph as printed. **The manual prints no message, no code, no pass or fail
result and no duration**, and it does not say whether the machine must be stationary or being
pedalled.

**Three keys, and no Enter.** The CE850 2016 commercial elliptical prints a stride calibration
that reads almost the same but takes **Start and Level Up only, then Enter** - see
`ce850-2016-console-stride-calibration`. Two different key combinations for two different
machines; do not carry one across to the other.

**This machine has an adjustable stride and no incline.** The XE395 2018 book prints the same
three-key hold for its **incline** instead, on a machine with a powered incline rail and no
stride adjustment - see `xe395-2018-errors-incline-calibration-three-key-hold`.

**Watch the assembly wiring label on this manual.** Assembly step 5 names the handle wire
`RESISTANCE/ INCLINE (White/Red) (61/62)` while the callout list for the same two wires on the
facing page reads `RESISTANCE/STRIDE`. The machine has no incline, so `INCLINE` there is a
copy-and-paste defect in the source, not a second subsystem.

**No other XE895 manual exists on disk**, and no later Spirit residential elliptical printing
carries a stride calibration: the word `calibration` does not appear in the XE195 2021, XE295
2021, XG400 2021, XE795 2021 February, XE795 2021 November, XE395ENT 2021, XE395 2023 or XE795
2023 books, nor in the XE795 2018, XE195 2019, XE295 2019 or XG400 2019 printings carded in this
same wave.

The machine still prints **no error code and no troubleshooting chapter** - see
`spirit-xe-errors-no-error-codes-printed`. The word `error` does not appear in this manual once.

**The XE895 2016 service manual (XE895-SE022) prints a different hold for the same subsystem** - *Press the Stride key and the Start key at the same time. Hold them down for 5 seconds and the Stride calibration will start and run automatically* - two keys, Stride and Start, with no Stop and no Level. The CE850 2016 book, of which the XE895 2016 is the residential printing, says the same; the CE850 (2020) writes it *STRIDE up key and the START key*. So the three-key hold on this card is the 2018 owner's manual's, and the two-key hold is the 2016 service manuals' (`xe895-2016` is a separate id from `xe895-2018`). Those books also print the message the calibration answers, `STRIDE ERR` with `E3` in the stride window: `spirit-ce850-2016-errors-stride-err-stride-window-e3`.
