**This machine's User program builds two profiles, not one: twenty resistance segments and then
twenty stride segments.** There are **two** customisable User programs, **User 1 and User 2**, which
operate identically. You can build one from scratch or **save any preset program you complete as a
custom program**, and you can personalise either by adding your name.

1. Press the **User 1** or **User 2** key. The Message Center shows a welcome message, carrying your
   name if a program is already saved. Press **Enter** to begin programming.
2. If a program is already saved it is displayed and you are ready to begin. If not, you may enter a
   username: the letter **"A"** blinks, the Up button switches to "B" and the Down button switches to
   "Z". Press Enter for each letter. **Maximum 7 characters.** Press **Stop** when finished.
3. If a program is already stored, pressing Start or Enter at the welcome message prompts
   **"Run Program?"** - Level Up/Down chooses Yes or No. Choosing No then asks whether to delete the
   stored program. **You must delete the current program to build a new one.**
4. Enter your **Age**, then Enter.
5. Enter your **Weight** - Level Up/Down or the numeric key pad - then Enter.
6. Set the **Time**, then Enter.
7. Set the **Max Resistance Level** of the program, then Enter.
8. The first column blinks (`SEGMENT > 1`). Set its resistance with the **Level Up** key, then Enter.
9. The next segment starts at the previous segment's level. Repeat until **all twenty segments** have
   been set.
10. **You are now asked to adjust the stride Level.** The first column blinks again (`SEGMENT > 1`);
    set the stride level for that segment with the **Level Up/Down** keys, then Enter.
11. The next segment starts at the previous segment's stride level. Repeat until **all twenty
    segments** have been set.
12. Press **Enter** to save. The Message Center says **"PROG SAVED"** and offers to Start or modify
    the program. **Stop** exits to the start-up screen.

**There is no Max Stride Level step**, although there is a Max Resistance Level step. Setting up a
*preset* program on this machine asks for a Max Resistance Level and nothing about stride at all -
see `spirit-ce-programs-preset-setup-steps`.

**The manual never says what a stride level means** - no length, no level count, no step size - and
never says how to change the stride during a workout. See
`xe895-2018-specs-powered-stride-set-per-segment-with-no-length-printed`.

**This is not the XE395's second profile.** The XE395 2010 and XE395 2018 build twenty resistance
segments and then twenty **incline** segments; the XE895 has no incline and the XE395s have no
stride. See `xe395-2010-programs-custom-user-resistance-then-incline`.

**The XE295, XG400 and XE795 build the resistance profile only** and stop there - see
`spirit-xe-2021-programs-custom-user-programs-cap-the-name-at-seven-characters`. **The XE195 has no
custom program at all.**
