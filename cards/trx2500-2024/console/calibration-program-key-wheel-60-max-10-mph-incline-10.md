First remove the Safety Key, hold down the **Program** key and at the same time replace the safety key. The console enters Calibration mode. **DO NOT STAND ON THE BELT DURING CALIBRATION.**

1. Set the wheel diameter to **60**. Press Enter to confirm and move to the next item.
2. Set kilometers or miles. Press Enter.
3. Set the minimum speed of **0.5**. Press Enter.
4. Set the maximum speed of **10**. Press Enter.
5. Set the maximum incline value of **10**, then press Enter. The console automatically enters the calibration display.
6. Press the **START/STOP** key to start the calibration. It returns to the standby screen automatically when calibration is complete.

The Dyaco GT90B-NT022 service manual prints the same six steps with the speeds written as 1 km (0.5 mi) and 16 km (10 mi). Sleep mode lives in a separate engineering mode ([engineering card](engineering-mode-enter-and-speed-keys-sleep-mode.md)); the TRX3500 and TRX4500 enter calibration with a different combination ([TRX3500 card](../../trx3500-2024/console/calibration-enter-and-speed-up-wheel-60-max-12-mph-incline-12.md)).
