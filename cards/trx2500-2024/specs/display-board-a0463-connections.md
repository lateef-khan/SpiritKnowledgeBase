The board photographed is silkscreened **A0463 V11**, dated **2017-6-8**, with an "EW" logo. Its sticker reads
**Part Number: A001010420 / Description: INC-A0463A0 / ProgrammingNumber: CT80_A0463_S505_... .hex / Speed: 16KM**
(the middle of the program name is too small to read with certainty). Fourteen callouts:

| Callout | Where on the board |
|---|---|
| Safety key wires socket | white socket, left edge, upper |
| Main Control wires Socket | black 5-pin header, left edge, middle |
| Key board wires Socket | long white socket, lower left |
| Incline Handrail keys socket | black socket, bottom left corner |
| Speed Handrail keys socket | blue socket, bottom centre-left (silkscreen SPEED) |
| Speaker | beside the keyboard socket, below the pin row |
| Hand Pulse Module | daughter board at the bottom centre with a round sensor can |
| Hand Pulse Socket | two white sockets, right edge, lower |
| Bluetooth board wires socket | white socket, top edge, left of centre |
| Fan power wires socket | white socket, top edge, centre |
| AMP power wires socket | red socket, top edge, right of centre |
| Wireless Pulse Socket | white socket, top edge, right (silkscreen WP) |
| MAIN IC | chip left of centre |
| Display IC | chip right of centre |

Section 6.1's "PCB Board Top" and "PCB Board Bottom" are uncaptioned photographs of the same board. The TRX3500 and
TRX4500 boards add an MP3 audio input socket and carry different part numbers; they are on their own card.
