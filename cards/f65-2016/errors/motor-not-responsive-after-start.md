1. If the belt moves but stops after a short time and the display shows **"LS1/LOW SPEED"**, run a calibration.
2. If you press start, the belt never moves and the display then shows **LS1/LOW SPEED**, contact service.

**This manual names the code LS1/LOW SPEED and points at "section 8.2 on Error Message: LS1/LOW SPEED". There is no such section in this manual** - section 8.2 is E1, and no LS code appears anywhere else. The equivalent F80 manual prints E1 in this row instead. Treat the symptom as the E1 no-RPM-signal path.
