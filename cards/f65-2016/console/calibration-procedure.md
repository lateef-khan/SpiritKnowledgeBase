1. Remove the safety key.
2. Press and hold **Start and Speed ▲** and replace the safety key at the same time. Keep holding until the window displays **"Factory settings"**, then press ENTER.
3. Set the display to Metric or English (miles vs kilometers) with the **incline▲/▼** key, then press ENTER. (The maximum speed value is displayed in the speed window, and the maximum elevation value is displayed in the incline window.)
4. **Grade return - On.** This lets the incline return to zero when STOP is pressed. EU standards require it to be **off** for sale in Europe.
5. Press START to begin the calibration.

**The process is automatic and the belt starts up without warning, so do not stand on the belt.**
