**Any class, collection or program can be labeled as a Favorite.**

- To "like" a program, **open the program setup page and tap the "ribbon" icon in the upper left corner of the screen.**
- **Up to 12 favorite programs will appear on the Home page** for easier access.
- Manage previously labeled programs on the **Favorites page**, reached from the Home page or the user Profile page.
- **To remove the label, un-tap the "ribbon" icon.**

Favorites and **Templates** are different things. A favorite is a bookmark on an existing program; a template stores a program together with a set of parameters you chose, and the console holds up to 12 of those separately.
