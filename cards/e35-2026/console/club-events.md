Access community challenges from the **"Club" tab in the bottom navigation bar**. Events there are **created by other members of the SOLE community**.

**To view all available events, your profile must be linked to your SOLE+ account.**

Two event formats:

| Format | How it works |
| --- | --- |
| **Shared goals** | Challenges with a **predefined target score**, which must be achieved within a limited time period to complete the challenge. |
| **Rankings** | Competitions in which users try to **earn the highest score possible** within a limited time period, to defeat as many competitors as possible. |

**The score can be represented by one of the following focus parameters: calories, distance, active time and workout count.**

- **Press the "filter" icon in the upper menu** and filter items by format, duration and focus parameter.
- **Join private events with "Join via ID".** Enter the event ID shared with you by the creator and you automatically become a participant.
- **Create your own challenge with the + icon** in the upper menu: choose event format, focus parameter, set dates, event name and an optional description. **Your event can be private or public.**

Joining an event carries a data-sharing consent; that is a separate rule with its own card.
