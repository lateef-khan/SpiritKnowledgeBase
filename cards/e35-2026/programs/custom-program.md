**Custom is a program with fully customizable resistance and incline patterns.**

1. On the program setup page, **press "Add Pattern" to enter edit mode.**
2. **Connect dots to map your load throughout the program, from easiest at the bottom to hardest at the top.**
3. **Each segment's duration depends on the selected total time** - you can set the total time right before start.

How the two axes behave is not the same:

- **Resistance values are relative.** The maximum can be changed before each workout and **all the segments are adjusted proportionally.**
- **Incline values are absolute and can be set directly.**
- **The incline pattern is optional.**

A profile holds a custom program with an adjustable intensity pattern of its own, so this is one of the things you lose by working as a guest.
