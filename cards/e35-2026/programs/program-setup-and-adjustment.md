Access preset programs from the **"Programs" tab of the bottom navigation bar**. **Tap on any program card to open the Program Setup page**, where you can learn more about the program and set the properties of your workout.

**To adjust workout parameters you can:**

- **drag the ruler**;
- **tap the + and - buttons**;
- **tap on the number to open a numpad and input the value directly.**

For the preset pattern programs, the two properties that matter are **Total Time** and **Max Resistance**: together they define the duration and overall intensity of the workout.

The setup page is also where the **"ribbon" icon** marks a program as a favorite.
