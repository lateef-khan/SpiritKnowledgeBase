These are the callout numbers on the exploded view drawing. The drawing is a
picture with bare numbers on it and no text, so the table below is the only
readable form of it.

**132 rows are printed.** The item numbers that appear are 1-29, 31-72, 75, 94, 101-109, 111-140, 142-148, 150-156, 158-163. Any number outside that run is **not printed in this manual at all** - 30, 73, 74, 76, 77, 78, 79, 80, 81, 82, 83, 84, 85, 86, 87, 88, 89, 90, 91, 92, 93, 95, 96, 97, 98, 99, 100, 110, 141, 149, 157 are absent, not a missing page.

**This is the 2024 CT800 list. It is not the 2020 CT800 list, and it is not the
CT850-2024 list.** All three run to 129-132 items with the same numbering scheme,
so a number looks valid against any of them.

## What changed from the 2020 CT800 list

The 2024 list carries the same 132 item numbers as `ct800-2020-specs-parts-list`,
in the same order, with **four substantive changes** and one notation change:

| Item | CT800-2020 | CT800-2024 |
|---|---|---|
| 119 | M8 x 1.25 x 40 mm socket head cap bolt, **qty 4** | same bolt, **qty 6** |
| 122 | M8 x 1.25 x 95 mm **socket head cap bolt**, qty 8 | M8 x 1.25 x 95 mm **button head socket bolt**, qty 8 |
| 131 | M3 x **50 mm** Phillips head screw, qty 4 | M3 x **40 mm** Phillips head screw, qty 4 |
| 139 | 5 x **20 mm** tapping screw, qty 25 | 5 x **19 mm** tapping screw, qty 25 |

Every other row is the same part at the same quantity. **The 2024 book writes
lengths `40mm` where the 2020 book wrote `40m/m`**; that is a typography change,
not a part change, and it is left as printed in each card.

## What tells this list apart from the CT850-2024 list

The CT800 is the DC-drive machine and the CT850 the AC-drive machine, and the
lists say so:

- **Only the CT800-2024 list has item 42 Hall Sensor Rack, item 43 Hall Sensor,
  item 54 DC digital control and item 69 1300 mm Sensor W/Cable.**
- **Only the CT850-2024 list has item 73 Inverter Plate and item 74 Inverter**,
  plus a second ground wire at 76 and a socket head cap bolt at 110.
- Four shared numbers carry different values - see `ct850-2024-specs-parts-list`.

**Items 50 and 51 are printed identically**, both `400mm_Handpulse Wire (Upper)`
quantity 1, so this list cannot tell the two upper handpulse wires apart. The
2020 list had the same pair.

**No motor rating, roller size, deck size or belt size is printed for any of
these parts.** Item 55 is `Drive Motor` and item 66 `Incline Motor`, each with no
horsepower or wattage; items 15, 16, 17 and 18 - front roller, rear roller,
running deck and running belt - carry no dimensions. See
`spirit-ct800-specs-no-specification-table`.

**Item 112 is printed `3/8" x UCN16 x 2"` and item 118 `3/8" x UCN16 x 2"`, while
item 154 is printed `3/8" x UNC16 x 1-1/4"`.** UCN and UNC are the same thread
callout spelled two ways in the one list.

**The exploded view drawing is a flat image dated `20230719`** at its foot - a
year before the manual. The number is legible only from a 300 dpi render; two
independent OCR passes agree on it. The drawing itself carries bare callout
numbers and no text, so the table below is the only readable form of it.

garbled and **is not the source of any figure on this card**. Where the two
