| | Imperial | Metric |
|---|---|---|
| Maximum usage dimensions of the machine | approx. **74 in L x 38 in W** | approx. **1876 mm L x 970 mm W** |
| Area required for safe operation | at least **87 in L x 43 in W** | **2200 mm L x 1100 mm W** |
| Free space in front, for access and passage | at least **12 in** | at least **300 mm** |

The manual prints both unit systems, on facing pages, and they agree with each
other to within rounding. It calls the first row "maximum usage dimensions",
meaning the space the machine sweeps while someone is on it, not a carton size.

**This is the only Spirit commercial elliptical owner's manual of the ten that
prints any dimension.** The CE800, CE800ENT, CE850, CE900 and CES880 books state
no assembled dimensions elsewhere, and none of the ten states a machine weight -
see `spirit-ce-specs-no-specification-table`. Do not carry these figures onto
another model.

**No height is given.** The manual states length and width only, so the ceiling
clearance a suspension elliptical needs is not answerable from this book.
