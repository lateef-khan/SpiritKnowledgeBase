The drawing is headed **PARTS OF YOUR ELLIPTICAL** and its labels are lettered A to L:

| Letter | Part |
|---|---|
| A | LCD Screen |
| B | Adjustable Fan |
| C | Hand Pulse Grips |
| D | Upper Handlebar |
| E | Direct Access Key |
| F | Accessory Tray |
| G | Shroud |
| H | Stationary Handrail |
| I | Internal Flywheel |
| J | Pedal |
| K | Transport Wheels |
| L | Levelers |

## These are not the names the build uses

The assembly steps call the same parts by different words, and the two vocabularies do
not meet anywhere in the manual:

| Diagram says | The build says |
|---|---|
| Upper Handlebar (D) | Upper Handrail (53, 54) |
| Stationary Handrail (H) | Stationary Handrail (48, 49) |
| Levelers (L) | Leveler (28) and Basic Leveler (52) |
| Shroud (G) | not named in any step |
| Accessory Tray (F) | not named in any step |

**Neither the shroud nor the accessory tray is fitted by any of the fifteen steps**,
and neither is on the illustrated assembly-parts page. Both arrive attached.

**F, the accessory tray, is the only thing on this machine that holds a drink.** It is
not the console-mast clamp-and-holder that the CE800 and CE850 fit, and not the CE900's
cup holder. See
[the bottle holder card](../../shared/assembly/spirit-ce-assembly-water-bottle-holder.md).

**E, the Direct Access Key**, is a console control, not a physical key; the console
chapter is where it is explained.

The whole-machine drawing shares its page with a **WARNING** panel, so the two run
together in the extracted text. The twelve labels above are the whole of the list.
