The console has built-in maintenance/diagnostic software - it can switch the display between English
and Metric, and turn off the key beep, among other things.

**Hold down Start, Stop and Enter, keep holding them, and then power the machine on.** The Message
Window displays `MAINTENANCE MODE MENU -PRESS ENTER`. Press **Enter** to open the menu.

**This is the only Spirit elliptical whose manual says to hold the keys down *before* power-on.**
The CE800, CE850 and CE900 manuals have you hold the keys while the machine is already running.

Navigate with the **Level Up/Down** keys. **Press Enter to jump to the previous mode setting.**

- **A. Key Test** - test all the keys to make sure they are functioning
- **B. Display Test** - automatically tests all LEDs
- **C. Function** - press Enter to access settings, use Level Up/Down to scroll
  1. **Units** - press Enter to select **ENGLISH** or **METRIC**
  2. **Pause Mode** - on allows 5 minutes of pause; off makes the console pause indefinitely
  3. **Odometer Reset**
  4. **Beep Mode** - turns off the speaker so no beeping sound is heard
- **D. Service** - factory testing
  1. **PWM Test**
  2. **Sensor Test**
- **E. Exit** - exit to idle mode

**There is no Sleep mode entry and no protocol choice**, and the manual prints no inactivity timeout
for this machine anywhere.
