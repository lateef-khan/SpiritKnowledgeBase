| Error Code | Definition | Troubleshooting |
|---|---|---|
| EEPROM | When the EEPROM is damaged or there is a problem with access, all windows will be turned off, all outputs will stop, and Window will show "EEPROM ERROR". | The EEPROM is abnormal, please replace the Display Board directly. |

**The fix is the display board, and the manual offers no check before it.**

**The CE900 2025 elliptical prints the same message and names a different part** - the *upper
controller*. Do not carry one answer to the other machine:
`ce900-2025-errors-eeprom-error-replace-upper-controller`.

The CU900ENT bike prints the message as `EEPROM ERR` and gives no fix at all:
`cu900ent-eeprom-err`.

The other coded message this manual prints is `E5`:
`ces880-2025-errors-e5-console-to-controller-connection`.
