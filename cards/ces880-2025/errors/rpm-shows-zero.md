**Condition: `RPM shows "0"`. Cause: the console doesn't receive any signal from the Sensor Wire.**

1. Verify the gap between the **Sensor and the Magnet is 2mm**.
2. Check all the wire plugs are connected firmly, correctly and are not damaged.
3. The Sensor Wire is broken, replace with the Sensor Wire.
4. Controller Malfunction, replace with the Controller.
5. Console Malfunction, replace with the Console.

**2 mm is the only figure printed for this machine.** No other Spirit elliptical manual in this set
prints a sensor gap, so do not carry a figure from another machine here.

A console that shows nothing at all, rather than a zero, is a different row:
`ces880-2025-errors-lcd-screen-does-not-display-anything`.
