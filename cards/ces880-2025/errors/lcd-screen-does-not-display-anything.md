The condition is printed as `LCD Screen does not display anything`.

| Reason | Solve |
|---|---|
| Wires connection | Check all the wire plugs are connected firmly, correctly and are not damaged |
| Console display is broken | Replace with the Console |
| Controller is broken | Replace with the Controller |
| Generator is broken | Replace with the Generator |

**Work the list in order.** The generator is on it because this machine has no mains supply to the
console - if the generator produces nothing, the console never lights.

A screen that lights but is faint or partly lit is the row above:
`ces880-2025-errors-lcd-not-bright-incomplete-or-imperfect`. Missing segments on a *powered*
display are a separate Spirit row again, written for the CT850 2016 and CVC800:
`spirit-lcd-displays-dim-or-incomplete`.
