The manual's cover code is **SE565S-SE016**. Section 1 is titled "SE565S-SE016 Outlines" and the table of contents calls it the "SE565S Elliptical". The circuit diagram page is also headed SE565S-SE016, so the code is consistent throughout.

This is the Sole E25 of model year 2016. The Spirit database SKU taken for it is **525116**, named "SOLE E25 2016".

The machine has a console with a **6.5" LCD display**, a main controller (DC power supply, incline driver and tension motor driver), a **tension motor** that changes brake resistance, and a **115 volt AC incline motor**.

The parts drawings name: console, console chin cover (rear), handle bar cover, console mast cover, pedal arm covers L and R, round disk and round disk cover, side case (L), pedal, connecting arm cover (R), incline cover, inclinable rail cover, rear bar cover, middle stabilizer cover, incline bottom cover and slide wheel cover; swing arms L and R, console mast, console holder assembly, pedal arms L and R, main frame, connecting arms L and R, drive pulley, bushing housing (pedal arm), cross bar, rear rail assembly, wheel assembly, flywheel, inclinable rail assembly and incline motor.
