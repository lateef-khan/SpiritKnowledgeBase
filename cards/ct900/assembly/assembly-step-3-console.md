1. Wires should be away from the console mounting bracket.
2. Install the **CONSOLE (54)** using 4 **BOLTS (68)**.
3. Connect wiring harness to **CONSOLE (54)**.
4. Attach **CONSOLE BRACKET COVER (49)** to **MAIN PANEL** using 4 **BOLTS (68)**.

## Hardware for step 3

| Part | Type | Description | Qty |
|---|---|---|---|
| 68 | BOLT | M5XP0.8X12L | 8 |

**The CT900ENT manual misprints this bolt.** Its step-three table calls item 68
`M5x8x12mm`, while its own step-four table calls the same item `M5x.8x12mm` and the
CT900 parts list gives **M5 x P0.8 x 12mm**. It is an M5 x 0.8 pitch screw; the
manual contradicts itself, not the machine.
