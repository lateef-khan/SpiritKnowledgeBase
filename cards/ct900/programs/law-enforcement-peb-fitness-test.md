A timed 1.5 mile run. You control the speed manually. Maximum time allowed to pass the test:

| Age | Male | Female |
|---|---|---|
| 20-24 | 10:43 | 13:36 |
| 25-29 | 11:05 | 13:43 |
| 30-34 | 11:26 | 13:43 |
| 35-39 | 11:47 | 14:37 |
| 40-44 | 12:28 | 15:12 |
| 45-49 | 13:07 | 16:02 |
| 50-54 | 13:49 | 17:02 |
| 55-59 | 14:48 | 17:37 |
| 60+ | 15:07 | 17:37 |

For more detailed information, visit: https://www.fletc.gov/peb-scores-age-and-gender
