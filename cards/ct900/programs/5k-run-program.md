This program automatically sets a 5K distance as your goal. The track display will show one loop that is the equivalent of 5 kilometers and the Distance window will also show 5K to start. When the program begins the Distance will count down; once it reaches zero the program ends.

*Please note that the Speed readout is in MPH if the console is not set to Metric.
