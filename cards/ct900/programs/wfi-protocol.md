**This is the WFI test, not the Gerkin protocol** (they use the same stage chart, but WFI scores it differently).

The WFI test is a modified Gerkin protocol. The actual test is the same as the [Gerkin chart](gerkin-protocol.md), but the score is calculated differently. The manual does not state the WFI scoring formula itself, only that it differs from Gerkin's.

For the before/during/after procedure (shared with Gerkin), see [Gerkin/WFI test procedure](gerkin-wfi-test-procedure.md).
