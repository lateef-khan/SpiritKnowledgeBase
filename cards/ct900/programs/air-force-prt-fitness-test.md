A timed 1.5 mile run. You control the speed manually. Maximum time allowed to pass the test:

| Age | Male | Female |
|---|---|---|
| <20 | 12:36 | 16:22 |
| 20-30 | 14:00 | 16:57 |
| 40-49 | 14:52 | 18:14 |
| 50-59 | 16:22 | 19:42 |
| 60+ | 18:14 | 22:28 |

For more information visit: http://bit.ly/SF-AirForce

Note: the source table skips the 30-39 age bracket - it jumps from "20-30" directly to "40-49," exactly as printed.
