## This is an 18-item table, not the 7-task one

The CT900 prints the table above - **Item** against **Weekly / Monthly / Quarterly / Biannually /
Annually**. The CT900ENT prints a different table entirely - seven tasks against a **How To** column
and **Daily / Weekly / Monthly / Semi-Annually** (`ct900ent-general-maintenance-schedule`), as do the
CT800 and CT850 manuals (`spirit-ct800-maintenance-schedule-tasks`). Neither answers for the other.

Page 36 of `spirit-treadmill-ct900-owners-manual` also carries a copy of that *seven*-task table,
laid over the CT900's own text as part of a duplicated *GENERAL MAINTENANCE* block from the 2026
4.0T/7.0T/8.0T manuals (see `ct900-belt-deck-cleaning`). It is not a CT900 table - the CT900's own
schedule is on page 38 and is the one above.

The **CTSBS900** prints this same 18-item table verbatim (`ctsbs900-maintenance-schedule`), with
"Slat Belt Sled Treadmill" substituted in the unplug line.

## The four 2024 New Black Units treadmills print this table

The **CT800 2024**, **CT850 2024**, **CT800ENT 2024** and **CT850ENT 2024** print the eighteen rows
above in the same order with the same marks in the same columns, under
*MACHINE CARE - CONTINUED - SCHEDULE* and the same *UNPLUG TREADMILL BEFORE PERFORMING ANY
MAINTENANCE* line. Every cell was placed from a 300 dpi render, because on all four the table is a
flattened image: `pdftotext` returns 96 words from that page - the heading and the unplug line -
and none of the table.

**The 2024 reissue changed which table these machines carry.** The CT800 2012/2016, CT850 2018,
CT800ENT 2022 and CT850ENT 2022 print the *seven*-task Task / How To table
(`spirit-ct800-maintenance-schedule-tasks`), as does the CT900ENT
(`ct900ent-general-maintenance-schedule`). Their 2024 replacements print the eighteen-row table
above instead. Do not answer a 2024 machine from the seven-task card, or the reverse.

**A hidden copy of the old seven-task table is still in the 2024 PDFs.** Each of these four pages
carries an invisible second text layer holding the earlier Task / How To table, complete with
interval marks, laid over the printed page. It is not printed and no reader sees it; anything read
out of a 2024 text layer rather than a render will silently mix the two tables.

**None of the four lists a lubrication task**, which agrees with the deck instruction on
`spirit-2026t-maintenance-deck-takes-no-lubricant`.
