The console diagram in the manual labels the following areas:

- **Fan** - top of console
- **Scan Button for LED Windows** - cycles the LED data display windows
- **LED Data Display Windows** - shows Watts, Time Elapsed, Calories, Distance, METS, Time Remaining, Calories/Hour, Pace
- **Direct Access Speed Buttons** - jump straight to a specific speed
- **Dot Matrix Message Center** - see [Dot Matrix Message Center](dot-matrix-message-center.md)
- **Up, Down, Program Controls**
- **Tablet Friendly reading rack**
- **Incline display / Speed display** - numeric LED windows
- **Numeric keypad (1-9, 0, dot, Enter, Clear)** - for typing exact values
- **Water bottle holder and cargo compartment** - for buttons, phone, or MP3 player
- **Start, Stop, Speed, and Incline controls** - physical buttons below the display: **INCLINE +/-**, **START**, **ENTER**, **STOP**, **SPEED +/-**
- **Safety Key** - slot between Start and Enter buttons; the console will not operate without it - see [safety tether cord and safety key](../safety/safety-tether-cord-and-key.md)
- **Contact Heart Rate Grips** - the two handlebar grips used to read pulse

For a diagram of the physical treadmill body (frame, uprights, motor cover, etc. rather than the console face), see [treadmill parts diagram](../assembly/treadmill-parts-diagram-labels.md).
