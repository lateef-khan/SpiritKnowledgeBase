**This is E34 (CONSOLE EE ER), distinct from E7 (EEPROM WR ERR / write error) and E16 (EEPROM RD ERR / read error), which are generic-inverter-table-only codes with no stated fix.**

**Description**: The console EEPROM error.

**Solution**: Replace the console.

This is one of the few E-codes in this manual with an actual stated description and fix, rather than a generic pointer to the inverter driver's own table.
