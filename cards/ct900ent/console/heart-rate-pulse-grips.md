The **Pulse (Heart Rate)** value on the screen shows the current value of heart beats per minute. You must use both left and right stainless steel sensors to pick up your pulse. Pulse values are displayed anytime the computer is receiving a **Grip pulse** signal. You may use the Grip pulse feature while in Heart Rate Control.

The CT900ENT will also pick up wireless heart rate transmitters that are **Polar compatible**.

For the full Heart Rate Control program that uses this pulse data to automatically adjust incline, see [Heart Rate Control program](../programs/heart-rate-control-program.md).

Note: the hand pulse sensors are not medical devices — see [general safety warnings](../safety/general-safety-warnings.md).
