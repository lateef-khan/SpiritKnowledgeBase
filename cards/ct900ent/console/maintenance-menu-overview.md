Reached via the [Settings menu](settings-menu-access.md) > Maintenance.

- **Default Language Setup** allows you to select the main language that will be shown when the console is turned on. You are able to select the language in the Home menu, but once the user finishes using the machine the console will return to this default language.
- **Software Update Manager** is used to install new versions of the application software.
- **Internet Manager** allows you to modify the internet sites that are shown in the Internet menu — see [Internet site manager](internet-site-manager.md).
- **WiFi/Ethernet Setup** is for selecting a WiFi signal or Ethernet addresses — see [WiFi/Ethernet setup](wifi-ethernet-setup.md).
- **Machine Setup** allows you to select whether the Csafe port is used for Csafe or CAB TV Tuner. This menu also allows you to set the screen brightness.
- **FTP Settings** is the Spirit FTP site address where Error logs and remote troubleshooting can be managed.
