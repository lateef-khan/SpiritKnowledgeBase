Security in engineering mode sets a lock that trips at an accumulated distance.

| Control | What it does |
|---|---|
| LOCK MODE | The distance locking function. When the distance reaches the set value, the display and buttons lock and cannot be used. |
| SET LOCK ACCUMULATE MILEAGE | The DISTANCE value, **100 to 9999 Miles**. |
| Password | The password used to unlock DISTANCE. |

**To unlock: press and hold UP for 3 seconds.** "This is an unlock function once only." **If the
password is forgotten, the default password 2222 unlocks the DISTANCE.**

The distance is in **miles** here. The CT800ENT-2022 sets the same lock in **kilometres** with a
range of 100 to 990 (`spirit-ct800ent-console-security-mileage-lock-100-to-990-km`); the CU900ENT
bike prints this screen word for word in miles (`cu900ent-security-distance-lock`). All three accept
2222.

The child lock under Machine Information is a different lock with the same three-second UP release
(`ct900ent-console-machine-information-machine-type-gs-mode-child-lock`).
