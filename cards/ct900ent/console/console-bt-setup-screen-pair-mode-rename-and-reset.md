**BT Setup is the seventh entry of the Settings list in engineering mode.** Its buttons:

| Button | What it does |
|---|---|
| (version field) | Shows the version of the Bluetooth module |
| Clear | Clears all messages on the window |
| Pair Mode | The window displays "Enter pairing mode" and waits for a Bluetooth connection |
| Deleted Pair | The window displays "OK" and disconnects the Bluetooth connection |
| Reset | The window displays "Bluetooth device is power on" and Bluetooth turns on again |
| Rename BT Device | Modifies the name of the Bluetooth connection; press it again to enter the new name |
| (volume) | Headphone volume control |

**Pairing procedure:**

1. Press **Pair Mode**. The window shows "Enter pairing mode".
2. On the phone or tablet, turn Bluetooth on and search for devices. The display shows
   **"ENT console"**. Select it. Both the phone and the console start the coding request; confirm on
   both and pairing completes.

The manual gives no PIN and no timeout, and does not say whether the link carries audio, heart rate
or both.

**The owner's manual pairs from the home screen instead**, through the BT icon at the bottom left,
where the phone sees the console as **A2DP** and the audio plays through the headphone port
(`ct900ent-bluetooth-pairing`). Neither document mentions the other. The CU900ENT bike prints this
same screen (`cu900ent-bluetooth-pairing`).
