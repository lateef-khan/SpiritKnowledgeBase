**Calibration on this console is a button on the Engineering Mode screen, and it calibrates the
incline only.** The manual's words: *"Press 'Calibration' button to start calibrating. It calibrates
incline motor only. There is no calibration for the tread belt. (When calibration is completed,
calibration window disappears)."* No LED-console routine - no safety key gesture, no belt run - applies
here.

The screen's controls, as printed:

| Control | What it does |
|---|---|
| WHEEL SIZE | Shown on the screen; the manual gives it no description and no value |
| BEEP MODE | ON / OFF for beep sound mode |
| SLEEP MODE | ON / OFF. "The display always lights when turns off. When there is no action for **30 minutes** after turning on the power, it enters sleep mode." |
| MAX INCLINE | To set max. incline level at **15** |
| UNITS | English / Metric mode switching |
| MAX SPEED | **12 for English mode, 20 for Metric** |
| MIN SPEED | **0.5 for English mode, 0.8 for Metric** |
| Calibration | Incline calibration, as above |

**The owner's manual never opens this screen** - it says the Settings menu's Engineering Mode entry
is for the service manual (`ct900ent-settings-menu-access`). Its console chapter does print the 30
minute sleep (`ct900ent-sleep-mode-auto-shutoff`), which agrees with this screen.

**The CU900ENT bike prints the same screen with WHEEL SIZE reading NA and no speed or incline
fields** (`cu900ent-engineering-mode-settings`). The CT800ENT-2022 treadmill's Engineering Mode screen
is a calibration page with a wheel size of 2.98 and no beep or sleep switch
(`spirit-ct800ent-console-engineering-mode-speed-and-incline-defaults-wheel-2-98`). The LED CT900
calibrates the belt as well as the incline (`ct900-calibration-procedure`).
