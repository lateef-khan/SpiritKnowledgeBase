When the **Internet button** on the Home page is pressed, you are directed to the Internet interface.

There are **6 basic internet sites** to choose from. You may change or add other sites through the Maintenance program — see [Adding or removing internet sites](internet-site-manager.md) for how those site icons are configured.

**Note:** An internet cable connection or WiFi connection is required — see [WiFi and Ethernet network setup](wifi-ethernet-setup.md).

**The CR900ENT-2021 (p. 23) and CU900ENT (p. 21) bike owner's manuals print this section word for
word**, so this card covers those bikes as well and its product line is no longer treadmill-only.
Same **6 basic internet sites**, same pointer to the Maintenance program, same note that an internet
cable connection or WiFi connection is required.

**The CU900ENT service manual names the six** as "such as Face Book / You Tube etc." and adds that a
site is deleted by holding its button for 2 seconds:
`cu900ent-internet-manager-add-website`. No document prints the full list of six.
