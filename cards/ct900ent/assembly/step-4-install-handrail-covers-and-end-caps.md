This is the final assembly step. It covers both sides of the treadmill (left side is shown in the illustrations; the right side is installed the same way).

## Hardware for step 4

| Part | Type | Description | Qty |
|---|---|---|---|
| 68 | Screw | M5x.8x12mm | 4 |
| 69 | Screw | M5x.8x25mm | 2 |
| 75 | Flat Washer | 5.5x19x1.5 | 8 |
| 83 | Screw | 3.5x12mm | 18 |

## Steps

1. Attach LEFT OUTER HANDRAIL COVER (48) to MAIN PANEL using 2 SCREWS (83) and 2 FLAT WASHERS (75).
2. Attach LEFT INNER HANDRAIL COVER (47) to MAIN PANEL using 5 SCREWS (83).
3. Attach LEFT LOWER UPRIGHT COVER (40) to MAIN FRAME (1) using 2 SCREWS (83), 2 FLAT WASHERS (75), and 1 long SCREW (69).
4. Attach LEFT END CAP (42) to MAIN FRAME (1) using 2 SCREWS (68).
5. Repeat to install the right side covers (45, 46, 39, 41).
6. Reinstall the MOTOR COVER (37) using the bolts removed in [step 1](step-1-attach-uprights.md).
