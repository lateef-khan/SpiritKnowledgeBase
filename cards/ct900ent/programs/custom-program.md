You will create the desired speed and incline levels for each of the **20 segments** of the program using the pop-out keyboard on the screen. After the program has started, you still have the ability to change these levels whenever you desire.

**The CT800ENT owner's manual states the same twenty segments and the same on-screen keyboard**
(printed page 31), writing "the keyboard on the screen" rather than "pop-out keyboard" and "You may
change these levels at any time during the workout". It adds a three-step sequence the CT900ENT
manual does not print:

1. Select the Custom program then press **Enter** to begin customizing it with your personal data,
   or just press **Start** to begin with the default settings.
2. Adjust the **Speed and Incline profiles** using the on-screen interface. Press **Next** to save
   and continue.
3. The following screens ask for the desired **Time**, the user **Age** and **Weight**. Use the
   defaults or adjust as needed, then press **Start**.

The button-console CT800 generations build a Custom program segment by segment from the console
windows and never say how many segments it holds - see
`spirit-ct800-programs-custom-program-build`.

**The CT850ENT owner's manual states the same twenty segments, the same on-screen keyboard and the
same three-step sequence as the CT800ENT** (printed page 31).
