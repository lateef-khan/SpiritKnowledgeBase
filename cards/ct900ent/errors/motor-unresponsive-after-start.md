**Problem:** Motor is not responsive after pressing start.

**Cause / fix:** Reset power. If still unresponsive, contact service.

The 2026 4.0T prints the same remedy, worded "Reset power. If still no good contact
service."

**The CT800ENT 2024 and CT850ENT 2024 owner's manuals print this row word for word** - `Reset
power. If still no good contact service.` - with no code and no calibration step.

**Their non-ENT siblings in the same 2024 family answer the same row with the code `LS` and a
two-way split** on whether the belt moved at all: `ct850-2016-motor-not-responsive-after-start`.

**Four service manuals print the same one-line answer**, `Reset power. If still no good contact service.` - the CT800 2020, CT800ENT 2022, CT850ENT 2022 and 4.0T. For the CT800 2020 that contradicts its own owner's manual, which prints the `LS` two-way row (`ct850-2016-motor-not-responsive-after-start`); the CT800ENT 2022 and CT850ENT 2022 owner's manuals print the `LS` row as well. **The CT900ENT service manual prints the LS row, not this one**, so on that machine it is the service document and the owner's document that disagree, the other way round.
