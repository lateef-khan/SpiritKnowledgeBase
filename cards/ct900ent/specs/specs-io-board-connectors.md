The console's I/O board is drawn from underneath with these call-outs:

| Call-out | Pins printed |
|---|---|
| Key Board CONNECT | **24 PINS** |
| SYSTEM CABLE CONNECT | **8 PINS** |
| HDMI CONTACT | - |
| N.A. | - |
| GROUND | - |
| Internet CONNECT | - |
| Console Power CONNECT | - |
| TV CONNECT | - |
| C-safe CONNECT | - |

The 8-pin system cable is the same cable the error chapter calls the "8-PIN cable" and the troubleshooting
matrix the "8 PIN Computer connector". The CT1000ENT draws the same board with a **20-pin** keyboard
connector; do not carry the count across.
