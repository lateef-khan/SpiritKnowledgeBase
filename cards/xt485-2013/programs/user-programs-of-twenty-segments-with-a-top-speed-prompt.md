**Twenty segments, stated outright**, and a **top speed prompt** before the segments - two things the
2015 XT485 book does not print. The 2015 book also spells out entering the name letter by letter and a
re-scaled profile picture; this book does neither
(`xt-2015-programs-custom-user-program-xt485-xt685`).

1. Press the **User 1-2** key **once for User 1 or twice for User 2**, then Enter. The dot matrix shows
   a single row of segments at the bottom unless a program is already stored.
2. *"The customer can to set the user name on this step and fallow the directions in the message
   center."* *(printed as shown; no letter-by-letter procedure is given)*
3. The Message Center blinks an **Age** value - adjust, Enter.
4. It blinks a **bodyweight** value - enter yours, Enter.
5. The clock / Message Center flashes: adjust up from **30 minutes** if desired and press Enter.
   **This is a must to continue even if the time is not adjusted.**
6. It blinks the **preset top speed (3 mph or 3 kmph)** - Speed + or -, Enter. This limits the highest
   speed the program can reach.
7. The first column blinks: set the speed for the first segment with + or -, Enter; the second column
   blinks. **Repeat until all 20 segments have been programmed.** The first column blinks again for
   the incline pass - **program all 20 segments for incline** the same way.
8. Press **Start** to begin the workout **and save the program to memory**, or **Enter to go back one
   step** and reprogram.

The 2010 XT685 book also says twenty segments; the 2015 XT485 and XT685 books never give a count.
