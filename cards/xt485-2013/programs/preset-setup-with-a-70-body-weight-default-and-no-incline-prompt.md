**Two figures and one step set this book apart from the 2015 XT485.** The body weight default is
printed as **70#** where the 2015 book prints 150 lbs; the top speed prompt reads **3 mph or 3 kmph**
where the 2015 book prints 3 mph or 5.0 kmph; and **there is no top-incline step** - the 2015
console asks for one after the top speed (`xt-2015-programs-select-and-start-xt385-xt485-xt685`).

*"The treadmill offers nine factory preset-programs, two user defined programs and one Manual
program. Each preset program has a maximum speed level that is displayed when a desired workout is
chosen."*

1. Press the desired program key - **Hill, Fat Burn, Cardio, Strength or Interval**. The display
   prompts you through the programming, or press **Start** to begin with the default values.
2. If Enter was pressed, the Message Center blinks your **Age (default is 35)**. Use the + or - keys,
   then Enter. Age sets the heart rate bar graph and the Heart Rate programs.
3. The Message Center blinks your **Body Weight (default is 70#)**. Use the speed + or - keys, then
   Enter. *The calorie note follows here: no exercise machine can give an exact calorie count; the
   display is a reference for progress from workout to workout.*
4. The Message Center blinks **Time (default 30 minutes)**. Adjust or accept, then Enter. *You may
   press Start at any time during the programming to start the program.*
5. The Message Center blinks the **preset top speed of the selected program (3 mph or 3 kmph)**.
   Use the Speed + or - keys, then Enter; this limits the highest speed the program can reach.

Then press **Start**, or **Enter to go back one level** and change data - the 2015 book names Stop
for that.

**"70#" is what the page prints**, three times over in this chapter; whether it means 70 pounds or
is a stray metric default is not stated, and it is recorded as printed.
