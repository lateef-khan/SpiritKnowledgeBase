**Seven Functions, including a Motor Test and a Grade return, and no safety-key gesture.** The XT685
2010 menu has a Motor Test but no Grade return and no Sleep entry, is entered with the safety key and
calls its display test LCD Test (`xt685-2010-console-engineering-mode-menu`); the 2015 XT menu ends in
an Exit item and its Functions in a Beep (`xt-2015-console-engineering-mode-menu`,
`xt-2015-console-engineering-functions-beep`). Do not read one menu onto the other.

**To enter: press and hold the Start, Stop and Enter keys at the same time, until the display shows
"Engineering mode" - "it may say maintenance menu, depending on version" - then press Enter.** Scroll
with the **+ and -** keys; **Stop** returns to the previous menu selection.

| Item | What it does |
|---|---|
| A. Key Test | Tests that each key is functioning properly |
| B. Display test | Tests that the LCD display segments are all lighting properly |
| C. Functions | see below |
| D. Security | "Allows you to lock the keypad so the treadmill cannot be used. Press Enter to change setting (also called child lock)" |

Under **Functions**:

| # | Setting | What it does |
|---|---|---|
| I | **Sleep Mode** | "Allows you to turn off the sleep mode. Console will stay on all the time unless power is turned off." |
| II | **Pause Mode** | "When the console is paused during a program this will allow you to keep the console paused indefinitely instead of 5 minutes." |
| III | **Odometer reset** | Allows you to reset the odometer |
| IV | **Unit Metric** | "When enter is pressed allows you to change the settings for data to metric." |
| V | **Motor Test** | "For service personnel only when troubleshooting motor problems." |
| VI | **Beep** | Allows you to disable the speaker so there is no beeping |
| VII | **Grade return** | "When in Pause mode the incline will return to zero automatically." |

**The Sleep entry is a switch and prints no time.** The time is in the console chapter - **20
minutes** with no key operations (`xt485-2013-console-turning-the-treadmill-off-after-20-minutes`) -
not the 30 the 2015 books and the 2010 XT685 print.

**Security prints no unlock**, as the XT385/XT485/XT685-2015 owner's manuals do not
(`xt-2015-console-keypad-lock-security`); the 2015 service manuals' Start and Enter for 3 seconds is
not stated for this machine.

**There is no Maintenance or Reset Lube entry**, although the lubrication page says the console "has a
built in lubrication reminder indicator that lights every 180 hours of use"; nothing in this menu is
said to clear it. **Calibration is not in this menu** - it has its own Factory settings gesture
(`xt685-2010-console-calibration-wheel-size-3-01`), printed on the same page just above.
