The cover reads **E25(2023)**, **SE668S-SE038**, "Elliptical Trainer". That factory code is the manual's own name for the machine.

This is the Sole E25 of model year 2023. The Spirit database SKU is **525022**.

What the manual says the machine is made of:

- **Console** - the interface that controls all functions. It has a keypad and an **LCD display**, not a touch panel.
- **Controller** - the circuit board holding the DC power supply for the console, the incline driver and the tension motor driver.
- **Gear motor** - increases and decreases the resistance level of the brake.
- **Incline motor** - an AC motor the user drives from the console to change elevation.

The 2023 E35, E95, E95s and E98 manuals describe a TFT LCD touch panel console instead, and they print a different error code set. Do not carry an answer between them.
