| Mode | What it does |
|---|---|
| **IDLE** | Each program profile is displayed as a page change, 5 seconds per profile, one at a time, with the program name in the message window. The heartbeat bar lights bottom to top and the track circle lights bottom to middle. The data window shows RPM = 60, calories = 681, time = 30:00, distance = 12.0, pulse = 125. |
| **SLEEP** | Set on or off in Engineer mode. Off means the watch never sleeps unless power is turned off. On means it sleeps after **15 minutes** with no RPM input and no key press in idle mode. Press any key to wake it. |
| **Child lock** | Default off, set in engineer mode. With it on, power-up shows "Console locked" twice, flashes, then "Child lock-on. Press Start and Enter to enable operation." Hold both keys; after holding Enter for **3 seconds** the lock releases into idle mode. Until it is unlocked no key works. |
| **EXERCISE** | From idle, Start goes straight to manual mode: age and weight are preset, time counts from 00:00, all data from 0, resistance from level 1. Or press Program (Manual, Program, HRC) to pick a program, then Start. |
| **PAUSE** | Stop during exercise. Data is recorded and the main window shows "Pause". After 5 seconds it scrolls "Press Start to resume or Stop to end". No key for **5 minutes** returns to idle. Resistance returns to level 1; pressing Start again returns the pull wire motor to the stage it was at before the pause. |
| **END** | "End of Workout Summary". The message window alternates "AVG Level XX", "AVG SPD XX.X" and "AVG RPM XXX" every 3 seconds. Calories, time and distance windows show the workout totals. No key for **5 minutes** returns to idle. |
| **RESET** | In idle, hold Stop for **3 seconds** to reset and restart the system. All screens clear and it returns to idle. Child lock must be released first. |
