**IDLE mode**

| Key | Function |
|---|---|
| Stop | Non-function. |
| Start | Starts the elliptical after a **3 second** countdown on the window display. In MANUAL it starts at MIN LEVEL. |
| Level Up / Level Down | Non-functional unless the user has entered a setting. |
| Incline Up / Incline Down | Non-functional unless the user has entered a setting. |
| Fan | Turns the fan on and off. |
| Enter | Non-function, except that after choosing a program it modifies the setting. |
| Program | Selects a program to begin a workout. |
| Display | Non-function. |

**EXERCISE mode**

| Key | Function |
|---|---|
| Stop | Stops the elliptical. |
| Start | Non-function. |
| Level Up / Level Down | Each press changes the level by 1. |
| Incline Up / Incline Down | Each press changes the incline by 1. |
| Fan | Turns the fan on and off. |
| Enter | Non-function. |
| Program | Selects a program to begin a workout. |
| Display | Switches the displayed exercise data. Press again on the last data to start a scan that cycles every **4 seconds**: "LAPS XX", then "SPEED XX.X MPH", "SPEED XX.X RPM", "L XX MAX LV XX" (program mode only), "WATT XXX", "SEG TIME XX:XX". |
