If there is a problem with the incline, run the calibration.

1. Press the **Incline UP key and the Start key at the same time**.
2. Hold them down for **5 seconds**. The incline calibration starts and runs automatically.
3. If the problem persists, contact the service department.

The troubleshooting matrix gives the same answer in a shorter form for the E3 / INCLINE ERR symptom: turn the AC switch off and on again, then follow this calibration procedure.
