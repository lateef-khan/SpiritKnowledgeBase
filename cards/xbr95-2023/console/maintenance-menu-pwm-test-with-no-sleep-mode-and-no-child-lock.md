**This is the menu as the XBR95-2023 service manual prints it. The owner's manual for the same
machine prints a different one** - see the end of this card.

**Press and hold Start, Stop and Enter for about 5 seconds.** The Message Window displays
**"Engineering Mode"**. Press **Enter** to open the menu; the **Level ▲/▼** keys move through it.

| Item | What it does |
|---|---|
| **A. Key Test** | Test all the keys to make sure they are functioning |
| **B. Display Test** | Tests all the display functions |
| **C. Functions** | Press Enter to access settings, use Level ▲/▼ keys to scroll |
| **E. Exit** | There is no item D |

**Inside Functions, in the printed order:**

1. **ODO Reset** - resets the odometer
2. **Units** - English or Metric display measurements
3. **Pause Mode** - turn on to allow **5 minutes** of pause, turn off to pause indefinitely
4. **Beep** - turns off the speaker so no beeping sound is heard
5. **PWM test** - **tests the Brake resistance**

**No Sleep Mode, no Motor test, no Child Lock.** The XBR95-2023 owner's manual (p. 35) prints the
2023 family menu instead - a fifteen-minute Sleep Mode, a Motor test that runs the tensioning gear
motor, and a Child Lock item (`xe395-2023-console-engineering-mode-with-a-child-lock`). **The two
documents disagree about the same machine and neither mentions the other.** The service manual's
list fits the hardware it describes on its own pages - a generator brake and no tensioning motor -
and matches the XE795-2023 elliptical's PWM-test menu except that the XE795 keeps a Sleep Mode
(`xe795-2023-console-engineering-mode-with-a-pwm-test`). Read the console in front of you before
quoting either list.

**PWM test is this machine's name for the brake test.** The 2016, 2018 and 2021 XBR95 books call
the same entry DA Test (`xe795-2021-console-engineering-mode-with-a-da-test`).

**The XBR55-2023 and XBU55-2023 service manuals print the family menu**, with the Sleep Mode, the
Motor test and the Child Lock, agreeing with their owner's manuals; only the XBR95 splits.
