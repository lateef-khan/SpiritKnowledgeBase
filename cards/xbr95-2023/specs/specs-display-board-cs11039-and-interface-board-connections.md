**Display board**, marked **CS11039-02ES** on the diagram and **CS11039 Rev 1.3** on the
photographed silkscreen:

| Connector | Lead |
|---|---|
| **AJ1 / BJ1** | SPEAKER |
| **J3** | FAN |
| **J2** | HR HANDLEBAR |
| **J4** | USB CHARGER |
| **J9** | WIRELESS HEART RATE RECEIVER |
| **J1** | KEYS BOARD |
| **J12** | SYSTEM CABLE |

The socket names are the same as the XBR55/XBU55's CS11037 board, but the board number differs
and the XBR95's system cable runs to a controller, not to a motor.

**Interface board:** **JK7** SYSTEM CABLE, **JK6** HANDGRIP PLUSE SENSOR (spelt so), **JK5** LEVEL
THUMB SWITCH - the resistance buttons in the seat handles. No board number is printed for it.

No pin definitions are printed for any of these sockets, and this book has no console-to-board
pin list at all (the 2016 XBR95 book had a six-pin one).
