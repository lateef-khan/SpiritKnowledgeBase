**Power on.** Plug in the power supply; the computer powers on and displays all segments on the LCD for 2 seconds, then enters user data setting mode (Age, Gender, Height, Weight). The picture shows the user screen with AGE 25.

**Power save.** After **4 minutes** without pedalling or pulse input the console enters power-saving mode; press any key to bring the display back. The note on the body-fat page repeats it: when the user stops pedalling for 4 minutes the computer enters power save mode, and **all user settings and exercise data are stored** until the user starts again.

**Adaptor.** "This product requires a **9V, 1000mA** adaptor." **If the computer is acting abnormally, unplug the adaptor and plug it in again.** The keys and readouts are on [the keys card](seven-keys-and-readouts-with-time-to-99-59-distance-to-99-90-and-calories-to-990.md).
