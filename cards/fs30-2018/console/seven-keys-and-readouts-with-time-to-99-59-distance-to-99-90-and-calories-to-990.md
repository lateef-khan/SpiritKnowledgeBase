| Key | As printed |
|---|---|
| MODE | During setup, confirms/enters every exercise data setting and enters the program |
| RESET | Returns to the main function mode and resets all values to zero |
| START/STOP | Start or stop training |
| RECOVERY | Test heart rate recovery status ([recovery card](../../shared/console/xterra-console-recovery-grades-from-outstanding-to-poor.md)) |
| UP / DOWN | Select the training mode and adjust a value up or down |
| BODY FAT | Body fat measurement (the test itself, with its E-1 and E-4 readings, is on the Programs cards) |

| Readout | As printed |
|---|---|
| TIME | Counts up 00:00 to 99:59 in 1-second steps; with a preset, counts down from 1:00-99:00 in 1-minute steps |
| SPEED | 0.0 to 99.9 ML or KM |
| RPM | Current revolutions per minute |
| DISTANCE | Counts up 0.00 to 99.90 in 0.1 steps; with a preset, counts down |
| CALORIES | Counts up 0 to 990 by 1; with a preset, counts down in 10-cal steps |
| PULSE | Your pulse; set a target and the computer beeps when it is reached |
| WATT | Current power output |

Power-on, the 4-minute power save and the adaptor are on [the power card](power-on-user-data-9-v-adaptor-and-power-save-after-4-minutes.md). The arrow keys are printed as "5/6" in the extracted text where the page shows up/down triangles.
