1. Use the up/down arrows to select the workout program and press MODE to enter.
2. Use the arrows to preset the workout **TIME**.
3. Press **START/STOP** to start; the arrows adjust the load level.
4. Press START/STOP to pause; **RESET** returns to the main menu.

**The book never says how many preset programs there are or what they are called.** The
mode list on the console picture reads MANUAL / PROGRAM / USER / H.R. / WATT, the Program
mode page shows one screenshot labelled "PROGRAM", and no page prints profiles. Searched the
whole text for "program", "preset", "profile" and letter-spaced variants; the only OCR
supplements in the program chapter (p. 13, 14, 16) are the console screenshots read from a
render, and they hold no program list either.
