1. Use the up/down arrows to select the workout program; choose **User** and press MODE.
2. Press the arrows to set the load level of each **column**, and press MODE to enter it and
   move to the next column. **Total columns = 20.**
3. Hold the MODE key to finish or quit setting.
4. Use the arrows to preset the workout **TIME**.
5. Press **START/STOP** to start; the arrows adjust the load level.
6. Press START/STOP to pause; **RESET** returns to the main menu.
