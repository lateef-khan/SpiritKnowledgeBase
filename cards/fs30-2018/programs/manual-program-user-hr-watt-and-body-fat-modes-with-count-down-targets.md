After power-on and the user data (age, gender, height, weight), the console offers these
modes, each with its own card: **Manual**, **Program**, **User Program**, **H.R.**, **Watt**
and **Body Fat**, plus a post-workout **Recovery** test.

Count up and count down as printed:

| Function | Count up | Count down |
|---|---|---|
| Time | 00:00 to 99:59 in 1-second steps | from a preset of 1:00 to 99:00, set in 1-minute segments |
| Distance | 0.00 to 99.90 in 0.1 mile/km steps | from a preset of 0.00 to 99.90 in 0.1 steps |
| Calories | 0 to 990, 1 calorie steps | from a preset of 0 to 990 in 10-calorie steps |
| Pulse | displays your pulse; "User may set the target Pulse. The computer will beep to indicate the target has been reached" | |
| Watt | "Display current training Watt value (power output)" | |

Speed shows 0.0 to 99.9 and RPM the current cadence. The console needs a 9 V, 1000 mA
adaptor and enters power-save after 4 minutes without pedalling or pulse input, keeping the
user settings and exercise data.
