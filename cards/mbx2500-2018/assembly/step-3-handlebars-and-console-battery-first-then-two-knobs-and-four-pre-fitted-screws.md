Hardware step 3: pre-assembled on the computer, **#73 screws (4)**; **#19 L type quick release knob (1)**; **#22 ball type quick release knob (1)** (the pack list calls 22 a "Ball Type Knob").

1. **Follow the instructions on page 12 to insert the battery into the console** - before the console goes on the post.
2. Insert the handlebar post (17) into the main frame (16). Secure using the L type quick release knob (19).
3. Attach the handlebar (18) to the handlebar post (17). Secure using the ball type knob (22).
4. Attach the computer (72) onto the computer bracket and secure using the 4 screws (73) which are pre-assembled on the back of the computer (72). Attach the sensor wire (74) to the computer (72).

"Note: The handlebar post can be vertically adjustable and the handlebar can be horizontal adjusted after your cycle is fully assembled."
