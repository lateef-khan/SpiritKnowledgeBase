**Buttons.** **MODE/RESET** confirms all settings; hold 2 seconds to reset all function figures. **SET** sets the value of TIME, DISTANCE, CALORIES and PULSE; hold it to increase the value quickly (the computer must be in standby mode).

| Window | As printed |
|---|---|
| RPM | Pedalling rotations per minute |
| SPEED | Exercise speed |
| TIME | SET a target between 0:00 and 99:00 for count-down, or it counts up |
| DISTANCE | SET a target between 0:00 and 99:50 for count-down, or it counts up (the book prints distance in the time format) |
| CALORIES | SET a target between 0 and 9990 for count-down, or it counts up |
| PULSE | Displays your pulse; set a target and the console beeps when it is reached. **(Chest strap not included.)** |

The book prints no hand-pulse grips - the words do not appear - so the pulse window only ever shows a strap reading. The battery, sleep timer and target beep are on [the battery card](cr2032-battery-sleep-after-4-minutes-and-an-8-second-target-beep.md).
