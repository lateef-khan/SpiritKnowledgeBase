**The service manual prints this menu twice, under two names, and neither copy matches the owner's
manual's copy.** The owner's manual lists four items a to d with Security second and a Functions list
that gives Sleep Mode 20 minutes (`spirit-ct800-console-engineering-mode-menu-with-units`). The two
service-manual copies are below; read all three before you go looking for an entry.

**Copy 1 - "Maintenance menu" (p. 52).** Press and hold **Start, Stop and Enter** at the same time
until the display shows **"Engineering mode"** ("it may say maintenance menu, depending on version").
Press Enter. Scroll with the up and down keys; Stop returns to the previous menu.

| Item | What it does |
|---|---|
| 1) Key Test | Press each key to verify it is functioning correctly |
| 2) Display test | Lights all LED lights |
| 3) Functions | i. **Sleep** - on or off; when off the display is always lit. ii. **Pause** - on or off; when on, Pause lasts **5 minutes**. iii. **Maintenance** - reset odometer readings. iv. **Units** - English or Metric. v. **Grade Return (GS Mode)** - returns the elevation to the lowest setting when pause is pressed. vi. **Beep** - speaker on or off |
| 4) Security | Sets the Child Lock, which locks out the keypad until a pre-determined key sequence is pressed. **Key sequence = Start & Enter held down together until unlocked.** |

**Copy 2 - "Engineering Mode" (p. 69, in the repair procedures).** Remove the tether cord, press and
hold **START, ENTER and STOP**, replace the tether cord. The display shows **"ENGINEERING MODE MENU"**.
Press ENTER, then scroll with UP or DOWN through KEY TEST, DISPLAY TEST, FUNCTIONS and SECURITY -
and a **CALIBRATION** entry the first copy does not have:

| Sub-menu | What it holds |
|---|---|
| CALIBRATION | **Speed Calibration** - test the speed. **Incline Calibration** - test the incline. |
| KEY TEST | Press all buttons on the console. |
| DISPLAY TEST | Press ENTER; the console tests each segment or LED. Look for any burned out or not working. |
| FUNCTIONS | **Sleep Mode On/Off**, **Beep Sound On/Off**, **GS Mode On/Off**, **Units English/Metric** (ENTER changes each), **Maintenance** (press ON/OFF to change), **Lube Message Reset** (ENTER resets), **Odometer Message Reset** (ENTER resets). |
| SECURITY | The display shows **"CONSOLE LOCKED"** before idle mode. ENTER turns it on or off. **To unlock the display, press START and ENTER.** |

**What the three copies disagree on:**

- **Sleep time-out.** The owner's manual's menu says 20 minutes; neither service-manual copy prints a
  figure at all. The manuals' console chapter says 30 (`ct900ent-sleep-mode-auto-shutoff`).
- **What Maintenance resets.** Copy 1 says the odometer only; copy 2 lists a separate Lube Message
  Reset and an Odometer Message Reset; the owner's manual says "the lube reset message and odometer".
- **The unlock sequence.** Both service-manual copies say Start and Enter. The owner's manual says
  only that Security locks the keypad.
- **Calibration.** Copy 2 lists it as a sub-menu of engineering mode. Copy 1 and the owner's manual do
  not; their calibration has its own Start-and-Fast gesture
  (`ct800-2016-console-calibration-in-kph-with-potentiometer-readings-235-to-22`).

**The CT850-2016 service manual's menu is different again** - entered with SPEED and ENTER, unlocked
with numeric 0 and Enter: `ct850-2016-engineering-mode-menu`. The CT800-2016 has no numeric keys.
