**This is the second calibration routine in the same service manual, and it is not the same as the
first.** Section 8.3 holds Start and Fast, sets 0.8 and 20.0 kph, and prints one wheel size of 2.98
(`ct800-2016-console-calibration-in-kph-with-potentiometer-readings-235-to-22`). This copy, in the
dealer-style repair procedures at the back of the book, sets miles and gives the wheel size as a
range.

1. **Remove the tether cord.**
2. **Press and hold the START and FAST buttons. Replace the tether cord while holding the buttons.**
   The message window displays **"FACTORY SETTING"**; press ENTER to go into test mode.
3. Use the UP/DOWN button to change from **Km (metric) to M (English)**.
4. The **wheel size** is displayed in the **Distance window**. Use UP/DOWN to change it. **It should
   be set to 2.92~2.98.**
5. The **minimum speed** is displayed in the Distance window. Use UP/DOWN to change it. **It should be
   set to 0.5.**
6. The **maximum speed** is displayed in the Distance window. Use UP/DOWN to change it. **It should be
   set to 12.0.**
7. The **maximum elevation** is displayed in the Distance window. Use UP/DOWN to change it. **It
   should be set to 15.**
8. **Press START.** The unit auto-calibrates the speed and incline. **Do not stand on the belt during
   calibration.** The unit resets when it completes the calibration.

**Three CT800-2016 documents, three wheel-size statements**: 2.98 in section 8.3, 2.92~2.98 here, and
2.98 in the owner's manual (`spirit-ct800-console-calibration-with-grade-return`). Nothing in the
manual says why this copy allows a range. The speeds here (0.5 and 12.0) match the owner's manual and
are the mile versions of section 8.3's 0.8 and 20.0 kph.

This copy is the one the manual's Troubleshooting Guide means by "Run the calibration procedure
(procedure 1)" for an LS error, an incline that does not work, and a surging belt.
