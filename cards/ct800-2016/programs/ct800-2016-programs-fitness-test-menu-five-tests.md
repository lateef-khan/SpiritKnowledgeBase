When the **Fit-Test** button is pressed the dot matrix displays the **5 different tests available:
Army (PFT), Navy (PRT), Air Force (PRT), Marines (PFT), and Gerkin.** Use the arrow button to reach
the test you want and press **Enter**.

**There is no PEB or Coast Guard test on this console.** Those two arrive on the twelve-program
generation - see `spirit-ct800-programs-fitness-test-menu-seven-tests`.

The Programmable Features page of the same manual still describes the machine as having "a Gerkin
protocol based Fitness Test" as though Gerkin were the only one - see
`spirit-ct800-programs-program-lineup-five-presets`. The five-test list on this page is the fuller
statement.

For what the console asks for before the test starts, see
`spirit-ct800-programs-fitness-test-entry-weight-age-gender`.
