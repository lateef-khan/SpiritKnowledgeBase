**AC model: TT8 2016 ST925A-YT030, AC drive motor driven by an inverter. The DC drive motor TT8 2016 (ST925-YT021) is a different machine and this card does not apply to it.**

| Symptom | Reason | Solve |
|---|---|---|
| The speed of the belt does not match the console display | Console is not calibrated | Calibrate the console; replace the controller |
| The incline position does not match the console | Console is not calibrated | Calibrate the console; replace the incline motor |

If the incline window shows an error rather than a wrong number, it is a fault code, not a calibration
drift — read the error card for the code on screen.
