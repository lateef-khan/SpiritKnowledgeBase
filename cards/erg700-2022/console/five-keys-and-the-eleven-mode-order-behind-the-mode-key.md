**The face:** a blue-topped console with three windows above a dot matrix (STROKES/MIN, TIME, DISTANCE), four below it (HEARTRATE, CALORIES, WATT, LEVEL) and **five keys in a row: RESET, START/STOP, MODE, DOWN, UP.** Any valid key press beeps; in power-off mode any key turns the console on.

| Key | What it does |
|---|---|
| **MODE** | In idle mode each press steps to the next workout mode; stop when the matrix shows the pattern you want and the value to be set blinks once a second. In Manual it also stops the scan ([scan card](scan-alternates-the-wave-pattern-and-500m-time-every-5-seconds.md)). |
| **UP / DOWN** | In the setting mode of a target workout, count the parameter up or down one increment per press; during a workout, change the resistance level. |
| **START/STOP** | In idle mode enters Manual; in setting mode confirms the value shown and starts; during a workout ends it and every window stops counting. |
| **RESET** | In stopping mode switches back to idle; "the reset key button is valid only in stopping mode". Held **3 seconds** under any mode it "turns on the console again". |

**Mode order:** MANUAL » DISTANCE » TIME » CALORIES » 20/10 INTERVAL » 10/20 INTERVAL » CUSTOM INTERVAL » Fat Burn » Cardio » Strength » Game. **Manual is the default after power-on**, and the program name scrolls across the matrix from left to right. What each mode does is a programs question.

**Two lines in the book contradict the table.** The window page says "RESET: Press and hold this button for 2 seconds to reset all of the value to Zero" and "UP: Increase the setting value of the following functions. TIME, COUNT, DISTANCE, CALORIES, and PULSE" - the ERG500's key text, pasted in: this console has no COUNT or PULSE setting. The card follows the Key button Function page, which is written for this console and matches the Spirit and Sole twins word for word ([Spirit keys](../../crw800-2024/console/crw800-2024-console-button-functions.md), [Sole keys](../../sr500-2016/console/console-buttons.md)). There is no pause: START/STOP ends the workout. Waking and the 1-minute switch-off are on [the power card](wakes-on-any-key-or-a-stroke-beeps-2-seconds-and-turns-off-after-1-minute.md).
