| Window | What it reads | Range as printed |
|---|---|---|
| **Stroke/min** | S/M, the equivalent strokes per minute | not stated |
| **Time** | Elapsed, accumulated for each mode; the remaining time when counting down | 00:00 ~ 99:59 (minute:second) |
| **Distance** | Accumulated for each mode; the remaining distance when counting down | 0 ~ 9999, then the format **1X.XX** above 9999 |
| **Heart Rate** | With a signal the small dot at the lower right of the window blinks with the value; **with no signal the window shows nothing** | **40 ~ 220 bpm** |
| **Calories** | Calories burned - "based on built in estimates of the average user and may not reflect accuracy" ([calorie card](../../shared/console/xterra-treadmill-console-calorie-display-is-a-rough-guide.md)) | 0 ~ 999 |
| **Watts** | Watt value **for each stroke** | **0 ~ 2000**; above 999 a decimal stands for thousands - 1000 shows 1.00, 1240 as 1.24, 1250 as 1.25, 2000 as 2.00 |
| **Level** | Current resistance level; **levels 1 and 2 light the first dot, 3 and 4 the second, and so on** - sixteen levels on eight dots | 1 ~ 16 |

So "1.24" is 1240 watts, an empty heart-rate window is no strap, and two neighbouring levels look the same on the dots. The heart rate comes only from a chest strap sold separately ([strap card](../../shared/console/xterra-treadmill-console-wearing-the-chest-strap-and-its-2500-hour-battery.md)). The 500M/TIME reading is not a window but a state of the centre matrix ([scan card](scan-alternates-the-wave-pattern-and-500m-time-every-5-seconds.md)). Keys: [key card](five-keys-and-the-eleven-mode-order-behind-the-mode-key.md). The Spirit CRW800 / XRW600 and the Sole SR500 print this table word for word ([Spirit](../../crw800-2024/console/crw800-2024-console-window-functions.md), [Sole](../../sr500-2016/specs/console-data-ranges.md)).
