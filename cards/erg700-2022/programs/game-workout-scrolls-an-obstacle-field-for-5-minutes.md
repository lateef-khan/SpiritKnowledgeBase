Choose GAME workout mode with **MODE**, then press **Start/Stop** to begin. "Game mode is a bit
different from the other workout modes because it is an actual game!"

- **Three dots at the left side represent the user position**; the image **shifts one profile to
  the left per second** and continues to scroll.
- The user's position does not shift sideways. **The faster you row, the higher your position**;
  with no input it drops to the lowest. The height equals your stroke speed.
- **"Avoid obstacles by rowing faster and slower to move the user block up and down."**
- **The game counts down from 5 minutes and ends when time is up.**

The duration is fixed; it is the only timed mode on this console with no user setting. No score,
collision rule or win condition is printed.

**Same page on Spirit and Sole machines.** The Spirit XRW600 prints the obstacle goal in other words
and the CRW800 omits it; the Sole SR500 prints the same game - see `see_also`.
