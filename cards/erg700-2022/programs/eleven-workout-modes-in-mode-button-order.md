The screen shows a full display and the buzzer beeps for two seconds after turning on. **Pressing
Start goes directly to Manual workout mode**; pressing **MODE** in idle mode switches the workout mode
in this sequence:

**MANUAL - DISTANCE - TIME - CALORIES - 20/10 INTERVAL - 10/20 INTERVAL - CUSTOM INTERVAL - Fat Burn -
Cardio - Strength - Game**

**Eleven modes.** "The program name will scroll from left to right to tell the user what it is." The
default mode after turning on is Manual. In a target mode the matrix window shows the pattern and
the value to be set blinks each second; UP and DOWN change it by one increment per press; Start/Stop
confirms and starts, and pressed again ends the mode. Reset works only in stopping mode (hold 3
seconds to restart the console).

| Mode | Card |
|---|---|
| MANUAL | manual mode card |
| DISTANCE, TIME, CALORIES | count-down targets card |
| 20/10, 10/20, CUSTOM INTERVAL | interval modes card |
| Fat Burn, Cardio, Strength | timed profiles card |
| Game | game card |

**No heart rate program, no user program, no fitness test.** The console reads a pulse (40~220 bpm)
from a chest strap and the book carries a Heart Rate Monitoring page with the 220-minus-age formula,
but no mode targets a heart rate. The level runs **1~16**, shown as eight dots of two levels each.

**Same page on Spirit and Sole machines.** The Spirit CRW800 and XRW600 and the Sole SR500 rowers print this chapter word for word; those are other brands and other cards - see `see_also`.
