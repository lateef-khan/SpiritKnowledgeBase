**This is E1 on the rower - a console memory failure - not the E1 of the Xterra recumbent bikes (the monitor cannot read the gear motor) and not the treadmills' E1 (no speed signal).** Codes match across Xterra product lines by letter only.

The book, word for word:

> When the screen displays "E1" "RAM ERROR" message, it means that the system console EEPROM has failed, all functions are disabled. You will need to replace the console.

So the screen shows both the code and the words `RAM ERROR`, nothing on the console works, and the remedy is a new console. The book prints no test and no other part for this code.

**The ERG700 is the only rower or strength book in the Xterra range that prints an error code at all**; the other ten rower owner's manuals describe faults as symptoms only (`xterra-errors-rower-and-strength-books-print-no-error-codes-except-one-rower`). The other code on this page is E2, a cable-communication fault with a check list (`erg700-2022-errors-e2-cable-communication-abnormal-8-pin-cable-and-tension-motor`).

The same code, message and remedy are printed for the Spirit CRW800 and XRW600 rowers (`crw800-2024-errors-e1-console-eeprom-failure`) and the Sole SR500 (`sr500-2016-e1-eeprom-failure`) - the same Dyaco console family - but those cards are those brands' and this one is Xterra's.
