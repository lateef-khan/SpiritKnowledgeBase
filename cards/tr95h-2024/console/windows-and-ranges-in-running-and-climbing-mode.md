**Speed / incline range**

| Mode | Speed | Incline level |
|---|---|---|
| Running | 0.8 – 12 kph / 0.5 – 7.5 mph | 0 – 15 |
| Climbing | 0.8 – 6 kph / 0.5 – 3.7 mph | 15 – 40 |

**Function display**

| Window | Shows |
|---|---|
| PULSE | (A) heartbeat 0-200 bpm, (B) body type 1-5, (C) resting heart rate |
| CALORIES | (A) calories 10-999 kcal, (B) height 20-98 cm |
| STEP | (A) step count, (B) BMR |
| DISTANCE | (A) distance 0-99.9 mile, (B) FAT% |
| PROGRAM | (A) running mode 1-12, climbing mode 1-5; (B) BMI; (C) user profile U0-U3 |
| GENDER | Male / Female |
| INCLINE | (A) level 0-15 running, 15-40 climbing; (B) age 10-99 (default 30); (C) difficulty level 1-3 |
| TIME | 00:00 – 99:59 |
| SPEED | (A) running 0.8-12 kph, climbing 0.8-6 kph (0.5-7.5 / 0.5-3.7 mph); (B) weight 44-309 lb |
| Speed unit | KM or MILE — **default setting KM** |
| Dot matrix | 16 x 29 dots |

**Defaulted data:** gender male, age 30, height 67 in, weight 154 lb, time 30 minutes, resting heart rate 72 bpm, target distance 1.0 mile, target calories 10 kcal, target time 30 minutes.

The console overview labels the LCD window, direct incline buttons (a column of climbing levels 40, 35, 30, 25, 20 on the left), HR training programs (Max, Interval, Threshold, Marathon, Easy on the right), Incline ▲/▼, a Cooldown button, Climbing Mode, Start, Stop, Running Mode, Enter and Speed −/+ ([button card](button-functions-cooldown-modes-enter-lap-usb.md)). The book lists a KM/MILE unit but prints no procedure for changing it, and neither book for this machine prints an engineering or calibration mode ([absence card](no-engineering-or-calibration-mode-is-printed.md)).
