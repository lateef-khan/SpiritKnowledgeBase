| Button | What it does |
|---|---|
| **Direct Incline** | Quick incline selection for Climbing mode (the console prints levels 40, 35, 30, 25, 20). |
| **INCLINE ▲/▼** | Sets data; selects a preset program and level; adjusts incline; chooses U0-U3 to key in personal data. U0 keys in data without memory; U1, U2 and U3 remember three users. That data can be deleted by pressing and holding Enter for 3 seconds for re-input. |
| **COOL DOWN** | Lowers speed and incline instantly; pressing it again resumes the original program ([cool down card](cool-down-button-drops-speed-to-2-mph.md)). |
| **Climbing mode** | For climbing exercise. |
| **START** | Starts the machine, or wakes it from sleeping mode. |
| **STOP** | Stops the machine temporarily; **held for 3 seconds, the whole system is set to 0**. |
| **Running mode** | For running exercise. |
| **ENTER** | Confirms setting data. |
| **SPEED** | Sets data; selects a preset program and level; adjusts speed. |
| **Max, Interval, Threshold, Marathon, Easy** | Heart-rate training zones; Easy is the lowest, Max the highest. |
| **LAP** | Each dot is 8 meters (0.00497 miles); one lap is 400 meters (0.25 miles); 0-99 laps. |
| **USB PORT** | At the bottom left of the console, for charging tablets and cell phones. No rating is printed. |

The parts drawing also names remote speed buttons and remote incline buttons on the handlebars, and the hand pulse grips.
