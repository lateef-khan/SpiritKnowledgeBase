**IDLE MODE** - each program profile is displayed as a page change, resting 5 seconds on each. One profile shows at a time and the program name shows in the message window with it. The heart rate bar lights bottom to top and the track circle lights from the bottom to the middle. The data windows show sample values: RPM 60, calories 681, time 30:00, distance 12.0, pulse 125.

**SLEEP MODE** - set on or off in Engineer mode. With sleep mode **off** the console never sleeps unless the power is switched off. With it **on**, and no RPM input in idle mode, it sleeps after **15 minutes** with no key press. Press any key to wake it straight back to idle mode.

**CHILD LOCK MODE** - default is off, set it on or off in engineer mode. With child lock on, switch the power on and the main window shows "Console locked" twice, flashes, then shows "Child lock-on. Press Start and Enter to enable operation." Hold **both buttons at the same time**; after holding Enter for **3 seconds** the lock releases and the console enters idle mode. No key works while the lock is on.

**EXERCISE MODE** - from idle, press Start to enter manual mode directly. Age and weight are preset values, time counts from 00:00, all data counts from 0 and resistance starts at 1. Or press the Program key (Manual, Program, HRC), pick a program and press Start.

**PAUSE MODE** - press Stop during exercise. The parameters are recorded and the main window shows "Pause", with the recorded data in the upper window. After 5 seconds the message changes to a scrolling "Press Start to resume or Stop to end", which then repeats. With no key press for **5 minutes** it returns to idle mode. The resistance level drops to 1; press Start again and the pull wire motor returns to the stage it was on before the pause.

**END MODE** - the main window shows "End of Workout Summary" and steps through the workout information. The message window alternates "AVG Level XX", "AVG SPD XX.X" and "AVG RPM XXX" every 3 seconds, and the Calories, Time and Distance windows show the totals. With no key press it returns to idle mode after **5 minutes**.

**RESET MODE** - in idle mode, hold the Stop key for **3 seconds** to restart the system. Clear child lock first. Reset clears all screens and enters idle mode after restarting.

**The sleep timer is printed two different ways in this manual.** This section says 15 minutes. The Maintenance Menu on page 21 says the console powers down "after 30 minutes of inactivity", and it reverses the polarity: there, turning Sleep Mode **off** is what makes the console power down. Confirm with the technical department before quoting a figure.
