The Console Screen Overview labels a **Phone Ledge**, the **LCD Window** and the **Function Buttons**.

| Function | Range as printed |
|---|---|
| Auto Scan | Every 6 seconds |
| Time | 0:00 - 99:59 |
| Speed | 0.0 - **99.9** KM/H (MPH) |
| Distance | 0.00 - 999.9 KM (Miles) |
| Calories | 0.0 - 999.9 CAL |
| Odometer | 0.0 - 9999 KM (Miles) |
| Pulse | 40 - 240 BPM |

Battery type 2 AAA or UM4; operating temperature 0 to +40 C (32-104 F); storage -10 to +60 C (14-140 F).

**Buttons.** MODE - push down to select functions. **SET - sets time, distance, calories.** RESET - resets time, distance, calories. Unlike the FB160/FB360 console, SET is not said to set a pulse target ([FB160/FB360 card](../../shared/console/xterra-fb-console-mode-set-and-reset-keys-with-targets-and-speed-to-999-9.md)).

**SCAN.** Press MODE to select the TIME function; the left side of the monitor flashes SCAN and the monitor shows time, speed, distance, calorie, odometer and pulse every 6 seconds. To return to SCAN, press MODE to select TIME again in SCAN mode. PULSE RATE: press MODE until PULSE appears, then hold both contact pads ([pulse card](../../shared/console/xterra-console-hand-pulse-reads-after-6-to-7-seconds-and-runs-high-at-first.md)). A faint or blank display means replace the batteries; the monitor shuts off after 4 minutes without a signal ([auto-off card](../../shared/console/xterra-console-battery-console-wakes-on-pedalling-and-sleeps-after-4-minutes.md)).
