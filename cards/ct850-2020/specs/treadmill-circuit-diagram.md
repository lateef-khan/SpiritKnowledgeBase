The page is a flattened image; the values below are read off the 300 dpi render, not off the
extracted text.

| Item | As printed |
|---|---|
| Input power | 120V/60HZ, plug then in-line connector |
| Breaker | **RFMB 20A** |
| Ground wire | green/yellow |
| Line filter | GD20-FCC110A, 115/230V 20A, 50/60 HZ |
| AC motor | **KSP485**, three black wires |
| Heat-sink fan | AC, **115V~ 50/60HZ** |
| Inverter | **RM6T6-1003, AC100-120V 50/60Hz** |
| Incline motor | **JS25A**, 3-pin VR cable plus red / white / black wires and a ground |
| Ferrite coils | two "Coil 3", φ35x21x13L |

Harnesses: **6PIN-2PIN, 1100 mm** upper connection and **6PIN-2PIN, 2000 mm** bottom connection,
mated through a **9-pin male / 9-pin female** pair.

Inverter terminals shown: AC(N) and AC(L), CN3 and CN2 at the top, **CN4 to the 3-pin incline VR
cable**, **CN5 to the incline motor**, and U / V / W out to the AC motor.
Mains convention: **L = black wire, N = white wire.**

The 2016 CT850 manual prints a different diagram: a 12-pin console harness, a **KSP131** motor, an
**RM6T3-1003B** inverter and a **110V** heat-sink fan. Check which machine you have before you
order a part.
