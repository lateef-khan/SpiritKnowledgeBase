**This is E-06H, and it is not any other code printed with the same characters.** Sole's ST90 prints E-06H as a converter overvoltage and sends the technician to the braking resistor; this manual sends the technician to the wall supply instead.

| Field | Value |
|---|---|
| Code | E-06H |
| Cause, word for word | The inverter is overvoltage. |
| Solution, word for word | Check the AC input voltage is stable 100~120V. |

The whole printed table is on the card `ct850-2020-inverter-error-code-list`. The only tool section 8-2 asks for is a **multi-meter**.
