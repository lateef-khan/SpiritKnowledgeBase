**This is E-41H, and it is not any other code printed with the same characters.** `OLO` is the short form the inverter itself shows.

| Field | Value |
|---|---|
| Code | E-41H |
| Cause, word for word | OLO The system is overload. |
| Solution, word for word | 1. Check if the motor, driver belt, rollers, and running belt cause the motor stuck. 2. The running belt is worn need lubricate or replacement. |

The whole printed table is on the card `ct850-2020-inverter-error-code-list`. The only tool section 8-2 asks for is a **multi-meter**.

The running belt work this solution asks for is on `ct850-2016-running-deck-belt-and-cushion-replacement`.
