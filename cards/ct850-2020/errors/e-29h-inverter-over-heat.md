**This is E-29H, and it is not any other code printed with the same characters.** The manual prints exactly the same cause and the same three-step solution for E-09H, and it never says how the two differ. Sole's ST90 prints E-29H as a high temperature *alert* rather than an over-heat trip.

| Field | Value |
|---|---|
| Code | E-29H |
| Cause, word for word | The invertor is over heat. |
| Solution, word for word | 1. Check the fan of invertor. 2. Clean the invertor. 3. Is the ambient temperature too high? |

The whole printed table is on the card `ct850-2020-inverter-error-code-list`. The only tool section 8-2 asks for is a **multi-meter**.
