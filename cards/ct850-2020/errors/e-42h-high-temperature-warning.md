**This is E-42H, and it is not any other code printed with the same characters.** This is printed as a *warning*; E-09H and E-29H are printed as over heat. All three carry the same three-step solution.

| Field | Value |
|---|---|
| Code | E-42H |
| Cause, word for word | The warning of high temperature. |
| Solution, word for word | 1. Check the fan of invertor. 2. Clean the invertor. 3. Is the ambient temperature too high? |

The whole printed table is on the card `ct850-2020-inverter-error-code-list`. The only tool section 8-2 asks for is a **multi-meter**.
