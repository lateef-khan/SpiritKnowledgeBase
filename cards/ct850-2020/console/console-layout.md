The manual calls out these parts of the console.

| Call-out | Where it is |
|---|---|
| Scan Button for LED Windows | Left of the top LED row |
| LED Data Display Windows | Two rows across the top |
| Scan Button for Dot Matrix | Below the LED scan button |
| Direct Access Incline Buttons | Ladder of keys down the left edge, headed INCLINE |
| Dot Matrix Message Center | Centre panel |
| Direct Access Speed Buttons | Ladder of keys down the right edge, headed SPEED |
| Up, Down, Program Controls | ENTER and PROGRAM keys right of the dot matrix |
| Fan | Grille in the SPIRIT badge panel under the display |
| USB Charger | Right of the fan grille |
| Water bottle holder and cargo compartment | One each side, "for buttons, phone, or MP3 player" |
| Start, Stop, Speed, and Incline controls | Keypad in the middle of the handlebar |
| Safety Key | Round receptacle in the middle of that keypad |
| Contact Heart Rate Grips | The two handlebar grips |

The two LED rows are labelled **DISTANCE, CALORIES, PULSE, TIME ELAPSED** on top and
**WATTS, PACE, METS, TIME REMAINING** below. **INCLINE** and **SPEED** have their own numeric
windows under the dot matrix, and three indicator LEDs marked **TRACK**, **SPEED** and **INCLINE**
sit to the left of it.

The speed ladder is numbered 1 to 12, which matches the twelve Direct Access Speed Buttons named in
the quick start instructions. The incline ladder numbering is drawn too small to read reliably at
300 dpi, so it is not quoted here; the factory setting for maximum elevation is 15. The CT800-2020
manual states its own incline ladder in words, in the INCLINE section, not on the drawing - see
`ct850-2020-incline-adjustment`, which lists each machine's range.

**The CT800-2020 owner's manual prints the same thirteen call-outs on its p. 15**, in the same words
including "for buttons, phone, or MP3 player", so this card covers that machine. **Two things above
come from the CT850 drawing only** and are not printed in the CT800-2020 manual: the labels on the
two LED rows, and the INCLINE / SPEED / TRACK indicator arrangement. Do not quote those as
CT800-2020 statements.

**The other two CT800 consoles look nothing like this.** The 2012 and 2016 console has six call-outs
and no USB charger, scan buttons or direct access ladders
(`spirit-ct800-console-layout-blue-led-matrix-window`); the CT800ENT-2022 is a touchscreen
(`ct800ent-2022-console-layout`).
