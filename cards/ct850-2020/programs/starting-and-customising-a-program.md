1. Press the **Program** button to select a program, then press **Enter** to start customising it
   with your personal data - or just press **Start** to run it with the default settings.
2. The **Time** window blinks with the default value of **20 minutes**. Adjust with any of the
   Up/Down buttons, then press Enter.
3. The **Incline** window blinks a value: this is your **Age**. Adjust, press Enter.
4. The **Distance** window blinks a value: this is your **Bodyweight**. Entering it correctly
   affects the accuracy of the Kcal readout. Adjust, press Enter.
5. The **Speed** window blinks, showing the preset top speed of the program. Adjust, press Enter.
   Each program changes speed throughout; this limits the highest speed it will reach.
6. Press **Start** to begin, or **Stop** to return to the previous screen.
7. A **3 minute warm-up** begins, with the clock counting down from 3 minutes. Press Start to bypass
   it and go straight to the workout.

You may press **Start at any point** during programming to begin with only the settings you have
changed so far.

**5k Run, 10k Run, HR 1 & 2, Custom and Manual do not have a warm-up.**

Age is what the console uses to calculate your maximum heart rate for the heart rate bar graph.
