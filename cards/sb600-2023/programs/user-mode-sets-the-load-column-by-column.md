1. Press and hold **Reset** for 3 seconds, choose the User and confirm the data; or press
   Reset only.
2. Select **USER** with the Up/Down arrows and press **MODE**.
3. Select the load level of the first **column** and press MODE to confirm; MODE moves to the
   next column. "When done, press and hold MODE for 3 seconds to confirm."
4. Set **Time, Distance, Calories and Target Pulse**.
5. Press **Start**; the Up/Down arrows adjust the load during the workout.
6. Stop pauses; Reset returns to the main menu; holding Reset for 3 seconds enters standby.

The book does not say how many columns the profile has; its pictures show the sixteen-column
grid the presets use.
