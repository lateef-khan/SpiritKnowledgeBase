1. Press and hold the **Reset** button for 3 seconds, choose the User and confirm the user
   data; or press Reset only.
2. Select **MANUAL** with the Up/Down arrows and press **MODE** to confirm.
3. Select the **Load level** and press MODE to confirm.
4. Pre-set the values of **Time, Distance, Calories and Target Pulse** (figures 10-13 in
   the book), MODE after each.
5. Press **Start**. Adjust the load with the Up/Down arrows during the workout.
6. Press **Stop** to pause. Press Reset to go back to the chosen mode, or hold Reset for 3
   seconds to return to the main menu.

Load runs from 1 to 16.
