After confirming the user's data (User 0-4: sex, age 10-99, height 100-200 cm, weight
20-150 kg), press MODE and use the Up/Down arrows to choose the operation mode:

- **Manual**
- **Program** - twelve presets, selectable with the P1-P12 keys
- **Fitness** - a 12-minute test
- **Watt**
- **User Program**
- **HRC** - 55%, 75%, 90% or a target

Value ranges printed with the mode list:

| Item | Range |
|---|---|
| Speed | 0.0 - 99.9 |
| Distance | 0.00 - 99.95 |
| Calories | 0 - 990 |
| Pulse | 60 - 220 |
| RPM | 15 - 999 |
| Watt | 10 - 350 |
| Load | 1 - 16 |

Every mode starts the same way: press and hold Reset for 3 seconds (or press Reset), choose
the user and confirm the data, select the mode with the arrows and press MODE. Start begins
the workout; Stop pauses it; Reset returns to the main menu, and holding Reset for 3 seconds
enters standby. Each mode has its own card.
