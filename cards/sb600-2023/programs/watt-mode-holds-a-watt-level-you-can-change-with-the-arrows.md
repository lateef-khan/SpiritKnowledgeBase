1. Press and hold **Reset** for 3 seconds, choose the User and confirm the data; or press
   Reset only.
2. Select **WATT** with the Up/Down arrows and press **MODE**.
3. Select the **Watt level** and press MODE. The value range is 10 to 350.
4. Set **Time, Distance, Calories and Target Pulse**.
5. Press **Start**; "you can adjust the watt level by using the Up/Down Arrows".
6. Stop pauses; Reset returns to the main menu; holding Reset for 3 seconds enters standby.

The book does not print a default watt value or say how the load follows your cadence.
