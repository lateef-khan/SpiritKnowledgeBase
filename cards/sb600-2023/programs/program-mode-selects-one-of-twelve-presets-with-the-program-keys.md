1. Press and hold **Reset** for 3 seconds, choose the User and confirm the data; or press
   Reset only.
2. Select **PROGRAM** with the Up/Down arrows and press **MODE**. Press the Up/Down arrows to
   select program **1 to 12**, or press one of the **program keys** for quick selection (the
   Program button "quickly select[s] preferred pre-set programs (12 programs)").
3. Adjust the **Load level** as desired and press MODE.
4. Set **Time, Distance, Calories and Target Pulse**.
5. Press **Start**; the Up/Down arrows adjust the load during the workout.
6. Press **Stop** to pause. Reset returns to the main menu; holding Reset for 3 seconds
   enters standby.

The twelve profiles are on their own card; the book gives them numbers only, no names.
