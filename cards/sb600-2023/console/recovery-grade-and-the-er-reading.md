After exercising for a period, **keep holding the handgrips and press RECOVERY**. All functions stop except Time, which counts down from **00:60 to 00:00**; the screen then shows the recovery status as a value from **F1 to F6 - F1 the quickest ("best") recovery, F6 the slowest**. Keep exercising to improve it. Press RECOVERY again to return to the main menu.

**Note:** "If the heart rate is undetected or connected only intermittently, then the display will show **'ER' (Error)**" (Figure 48). ER is a failed recovery reading, not a machine fault code. The SB240 and FS3.0 print meanings for each grade ([card](../../shared/console/xterra-console-recovery-grades-from-outstanding-to-poor.md)).
