1. Connect the power supply to the monitor, or **press RESET for 3 seconds**: the LCD lights all segments with a long beep of 1 second and then shows **78.0** (Figures 1 and 2 - the value's meaning is not explained; it is not the software version, which the book never prints).
2. Press the Up/Down arrows to select **User 0 - 4** and press MODE to confirm (the figures show U-0 to U-4).
3. Preset the user's Sex, Age, Height and Weight with the arrows, MODE confirming each.

| Item | Range |
|---|---|
| Sex | Male / Female |
| Age | 10 - 99 |
| Height (cm) | 100 - 200 |
| Weight (kg) | 20 - 150 |

Every mode page then begins "Press and hold the Reset button for 3 seconds, choosing User and confirming the user data. Alternatively, press Reset only" - the short press keeps the current user. After the user, MODE opens the mode list (Manual, Program, Fitness, Watt, User Program, HRC); those are on the Programs cards. The buttons are on [the console card](usb-charging-port-twelve-program-keys-and-seven-function-buttons.md).
