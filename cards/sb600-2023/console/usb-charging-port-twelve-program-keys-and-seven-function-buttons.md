The Console Screen Overview labels the **LCD Window**, the **Program Buttons** (P1 to P12 in two rows, each with its profile) and a **USB Charging Port** on the right side of the console. The LCD windows read TIME, PULSE, SPEED, DISTANCE, WATT, CALORIES, an RPM/LOAD bar graph and a PROGRAM message line.

| Button | As printed |
|---|---|
| Start / Stop | Start or stop training |
| Recovery | Test the heart rate recovery status ([recovery card](recovery-grade-and-the-er-reading.md)) |
| Up arrow | Select the training mode or adjust a value up |
| Down arrow | Select the training mode or adjust a value down |
| Reset | In Stop mode, press to return to the main menu; **hold 3 seconds** to go back to standby and the user selection |
| Program | Quickly select a preset program (12 programs) |
| Mode | "To start workout" - in practice the confirm key: it confirms the user, the mode, the load level and each preset value |

Every mode page ends the same way: Stop pauses the workout; Reset goes back to the main menu; Reset held 3 seconds enters standby. Power-up and user setup are on [the powering-on card](powering-on-shows-78-0-then-users-0-to-4-with-sex-age-height-and-weight.md); the readout ranges on [the ranges card](readout-ranges-with-load-1-to-16-and-watt-10-to-350.md).
