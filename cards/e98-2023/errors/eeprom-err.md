**This is EEPROM ERR. It is not LWR not found and it is not LWR not match.**

Definition: **all screens are off and outputs stop when the EEPROM is damaged or malfunctions. The display message shows "EEPROM ERR".**

Troubleshooting: the EEPROM is abnormal, **replace the Display Board directly**. The manual gives no other step.

The error code list prints the meaning as "EEPROM failure".

**This console prints no numbered E-codes.** The error code list on this machine holds exactly three entries: EEPROM ERR, LWR not found and LWR not match. If a customer reports "E1" on this machine, they are quoting an older Sole console, not this one.
