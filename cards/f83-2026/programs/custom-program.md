**Custom is a program with fully customizable speed and incline patterns.**

1. On the program setup page, **press "Add Pattern" to enter edit mode**.
2. **Connect dots to map your load throughout the program** — easiest at the bottom, hardest at the top.
3. **Each segment's duration depends on the selected total time**, which you set right before the start.

- **Speed values are relative**; the maximum can be changed before each workout and **all segments adjust proportionally**.
- **Incline values are absolute and can be set directly. The incline pattern is optional.**

A custom program with an adjustable intensity pattern is one of the things a personal profile gives you over guest mode.
