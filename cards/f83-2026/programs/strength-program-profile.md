**Strength follows a preset speed and incline changing pattern.** The **Total Time** and **Max Speed** settings you choose before the start define the duration and the overall intensity.

**Speed values are a percentage of the max speed set before the start. Incline values are absolute.**

The printed chart heads 22 columns (Warm up, segments 1 to 20, Cool down) but every printed row carries 26 values, so the extraction cannot say which values belong to the warm-up and cool-down columns. The values below are reproduced in printed order and numbered by position only; no mapping to the numbered segments is inferred.

```

Speed    40 40 50 66 66 66 75 75 75 75 88 88 100 100 100 88 88 88 100 88 75 66 66 50 40 40
Incline   0  0  0  0  0  4  6  8 10 10  0  0   0   8   8 10  0  0   6  8  0  0  0  0  0  0
```
