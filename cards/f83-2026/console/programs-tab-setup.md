**Access the preset programs by selecting the "Programs" tab of the bottom navigation bar.**

**Tap on any program card to open the Program Setup page**, where you can learn more about the program and set the properties of your workout.

To adjust a workout parameter you can:

- **drag the ruler**;
- **tap the + and – buttons**;
- **tap on the number to open a numpad and type the value directly**.
