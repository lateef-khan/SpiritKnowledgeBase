**Any class, collection or program can be labelled as a Favorite.**

- **To "like" a program**, open the program setup page and **tap the ribbon icon in the upper left corner** of the screen.
- **Up to 12 favorite programs appear on the Home page** for easier access.
- Manage labelled programs on the **Favorites page**, reached from the Home page or the user Profile page.
- **To remove the label, un-tap the ribbon icon.**
