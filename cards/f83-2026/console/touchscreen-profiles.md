The first time the console is launched it prompts you to **enter as a guest or create a new profile**.

- **Tap + to create a new profile.**
- **A maximum of 9 profiles can be created.**
- **Each profile can be protected with a passcode.**

Setting up a profile is recommended: it lets the machine remember your **physical parameters, favourite programs and templates**, gives you your own **custom program with an adjustable intensity pattern**, and lets your **workout records synchronise with the SOLE+ mobile app**.

**In Guest mode you can set age and weight on the Home screen**, which helps the machine calculate the workout summary more accurately.
