**Yes.** When the TFT display is damaged and cannot be used:

1. **Unplug the connection cable of the TFT display.**
2. The **LED display then operates independently**.
3. **Start directly by pressing the START key**, or **select a program by pressing the PROGRAM key**.
4. Pressing Start runs the program **using the preset program values for age, weight and other program-specific information**.
