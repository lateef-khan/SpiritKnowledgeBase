Every message printed in this manual's error table, with the fault it stands for. Each has its own card.

| Message | Meaning |
| --- | --- |
| LUBE | Reminder to check lubrication under the walking deck |
| E01 | Over-current protection; treadmill overloaded, controller protection activated |
| E02 | Hall mistake |
| E03 | The hardware current is too large |
| E04 | Phase loss |
| E05 | Undervoltage |
| E06 | Overvoltage |
| E3 | Incline adjustment error |
| E22 | Error in communication between the LED electronic watch and the control board |
| E23 | TFT electronic watch has a communication error with the LED electronic watch |
| E31 | Overtemperature |
| ERROR | TFT electronic watch communication failure |

**No solution is printed for E31 in this manual.**

The manual introduces the table with: "Before contacting us for aid, please review the following information. It may save you both time and expense. **This list includes common problems that may not be covered under the treadmill's warranty.**"
