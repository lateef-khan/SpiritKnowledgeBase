**DO NOT SHIP ANY UNIT TO THE FACTORY WITHOUT A RETURN AUTHORIZATION NUMBER. All units arriving without a return authorization number will be refused.**

Related terms printed in the same step:

- **All transportation costs, both to the factory and on return to the owner, are the owner's responsibility.**
- **The owner is responsible for adequate packaging** on return to SOLE.
- **SOLE is not responsible for damage that occurs during shipping.** Make all freight damage claims with the appropriate freight carrier.
