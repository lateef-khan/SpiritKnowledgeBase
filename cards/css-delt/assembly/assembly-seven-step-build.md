**Seven steps in both printings. The 2026 revision changes the step 2 bolt and re-specifies step 4; steps 1, 3, 5, 6 and 7 are the same tables in both.** The books print a table per step and a drawing; there is no step text beyond the notes quoted below.

## Step 1 - door frame to main frame

| No. | Description | Spec | Qty |
|---|---|---|---|
| 001 | Doorframe | | 1 |
| 020 | Inner Hexagon Socket Head Bolt | M10*35 | 4 |
| 024 | Spring washer | M10 | 4 |
| 027 | Flat washer | Φ20*Φ10.5*2 | 4 |
| 040 | Main Frame | | 1 |

Notes: (1) the screws hardware (20, 24, 27) at the weight tower bottom are pre-installed - remove them, attach the frame onto the door frame, then fix the screws; (2) the powerline needs to be threaded through the holes before the door frame goes to the main frame, or the machine will have to be disassembled.

Notes (a page of their own): install the weight stacks, top weight stack and guide rod fixed plate in sequence; the upper pulley (210) is with magnets and the magnet side must face and interact with the sensor; after the weight stack is installed, lubricate the guide rods before attaching the shrouds. **Item 098 is an M10*30 socket cap screw here, in both printings** - the 2026 step 2 gives the same number to an M8*30. Eleven 20 lb plates and a 20 lb top plate is a 240 lb stack.

## Step 7 - shrouds

The eight-row shroud panel every weight-stack machine prints (002 upper shield, 003 shield fixed plate x 4, 007 front shield, 008 back shield, 015 M5*10 x 8, 018 M6*16 x 2, 022 M6 x 2, 025 Φ12*Φ6.4*1.6 x 2), with the note to connect the batteries and display from page 22 before installing the covers and to fit the front shroud (7), then the back shroud (8), then the upper shield (2). Both printings.

**Tools are not in the carton** - an Allen wrench set, a Phillips screwdriver and C-ring pliers are to be prepared - and the unpacking page still says the hardware is separated into four steps. No torque is printed anywhere.
