Hardware: **#65** 3/8" x 2-1/4" Hex Head Bolt (4 pcs), **#77** 3/8" x 19mm x 1.5T Flat Washer (6 pcs), **#84** 3/8" x 25mm x 2T Flat Washer (4 pcs), **#136** M5 x 15mm Phillips Head Screw (4 pcs), **#176** 3/8" x 3/4" Hex Head Bolt (6 pcs).

1. Install the Rear Stabilizer (7) onto the Main Frame (1) with the four Hex Head Bolts (65) and four Flat Washers (84), using the **12/14m/m Wrench (112)**.
2. Install the **Seat Carriage Cover (128)** onto the Seat Back Bracket (5) with the four Phillips Head Screws (136), by using the Phillips Head Screw Driver (114).
3. Install the Seat Back Bracket (5) onto the Seat Carriage (4) with the six Hex Head Bolts (**167**) and six Flat Washers (77), by using the **12/14m/m Wrench (112)**.

**The six bolts are called (167) in the instruction but #176 in the checklist** and in the hardware box printed beside this step. There is no item 167 anywhere in the checklist. The LCR 2013 instruction says 176; the 2011, 2019 and 2023 instructions say 167.

Part 128 is called the **Seat Carriage Cover** here; the LCR 2011 and 2013 manuals call the same part the **Seat Back Cover**.
