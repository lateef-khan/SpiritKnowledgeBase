The Training section's main screen offers **5 training modes: Start, Timer (Manual), Distance, Calories and Heart Rate.** In guest mode you set age and weight on this screen so the workout summary is more accurate.

Tap a program card to open its Program Setup page. Switch between programs with the arrow buttons at the top right. Adjust a parameter by dragging the ruler, tapping **+** and **-**, or tapping the number to open a numpad.

| Program | What it does |
|---|---|
| Timer (Manual) | A timed workout with the resistance level controlled by hand at any point during the workout. |
| Distance | Sets a target distance. The program ends when the target is reached. |
| Calories | Sets a target calorie count. The program ends when the target is reached. |
| Heart Rate | You use resistance to control your heart rate. Follow the resistance level recommendations to stay **within 5 bpm** of the target. **A heart rate monitor is required.** |

**Setting the heart rate target:** on the setup page, either set the target bpm directly, or select **60% or 80% of your age-predicted maximum heart rate** and let the machine calculate it. If you use the percentage option, make sure the machine knows your age, otherwise the calculation uses default values.

**The heart rate program ends when the time is up, or if your heart rate goes 20% higher than the target.**
