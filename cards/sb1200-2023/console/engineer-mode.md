**To open it:** go to the **Settings** page and **press 10 times on the word "Settings"**.

There are **4 pages** in Engineer Mode: **FUNCTION**, **SERVICE**, **FACTORY SETTING** and **CALIBRATION**.

The FUNCTION page holds:

1. **Beep** - whether there is a beep sound when a physical button is pressed.
2. **Software Update**
   - **COMMAND** - reserved, no function.
   - **OSOTA** - forcibly check whether the OS has updates available.
   - **USB** - update through the Console App from a USB flash drive.
3. **Machine Type** - switches the machine model. Covered in a separate card because of what it erases.
4. **Spin Bike Level Calibration** - runs the resistance system G-sensor calibration. Covered in a separate card.

**The manual lists the contents of the FUNCTION page only.** It names the SERVICE, FACTORY SETTING and CALIBRATION pages but does not say what is on them.
