**Machine Type** switches the console between machine models. It sits on the FUNCTION page of Engineer Mode.

**Changing it destroys data.** The manual states: "When switching machine models, all settings will be reset to default values, and all local accounts and records will be cleared and cannot be recovered."

Before changing it, make sure every profile that matters has been linked to a **SOLE+** account, because the history stored only on the console goes with the reset.
