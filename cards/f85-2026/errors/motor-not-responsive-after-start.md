**The manual's answer for this symptom is a single line, and it is damaged in print.** It reads, character for
character:

```
Check the problem handing based on theerror code repartd.
```

Read as intended, that is: check the problem handling based on the error code reported. **The row gives no other
step** — it defers entirely to the error message table on page 33.

So the procedure this manual actually supports is:

1. Read the code on the console.
2. Look that code up in the error message table.

If no code is displayed at all, this row offers nothing further; the display-does-not-light row is the other place
in the guide that covers a machine that will not run.
