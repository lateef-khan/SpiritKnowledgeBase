**The manual's cause is grounding.** As printed: "Treadmill may not be grounded. Static electricity is 'crashing'
the computer. Refer to Grounding Instructions on page 3."

So the fix is not a console fault — check the outlet:

1. Confirm the treadmill is plugged into a properly installed, properly grounded outlet.
2. Confirm no adapter is defeating the grounding pin. If a temporary adapter is in use, its green rigid earlug
   must be connected to a permanent ground and the adapter held in place by a metal screw.
3. If in doubt whether the outlet is grounded, have a qualified electrician check it.

The page 3 reference is correct — grounding instructions really are on page 3.
