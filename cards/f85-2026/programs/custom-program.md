**Custom is a program with fully customisable speed and incline patterns.**

1. On the program setup page, press **"Add Pattern"** to enter edit mode.
2. **Connect dots to map your load** throughout the program — **easiest at the bottom, hardest at the top**.
3. **Each segment's duration depends on the selected total time**, which you set right before the start.

- **Speed values are relative.** The maximum can be changed before each workout and **all segments adjust
  proportionally**.
- **Incline values are absolute** and can be set directly.
- **The incline pattern is optional.**

A custom program is one of the things a personal profile keeps for you; guests do not carry one between sessions.
It can also be saved as a template.
