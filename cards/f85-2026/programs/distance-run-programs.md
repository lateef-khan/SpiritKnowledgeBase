**5K Run and 10K Run automatically set a target distance** for the workout — **5 km and 10 km respectively**.

- On the program setup page the console **shows the estimated total time for the run based on the selected target
  speed**.
- **The program ends when the target distance is reached**, not when a clock runs out.

The manual describes no other distance targets and no way to enter a custom distance.
