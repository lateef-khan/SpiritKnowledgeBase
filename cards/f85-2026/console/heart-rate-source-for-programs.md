**Heart Rate programs are intended for wireless Bluetooth wearables only.** The manual prints this as a caution:
"Heart rate programming, caution! Heart Rate programs are intended for wireless Bluetooth wearables only. You must
receive a strong/steady value in the Heart Rate Window."

So before starting a heart rate program:

1. Pair a **Bluetooth heart rate wearable** with the console.
2. Confirm a **strong, steady value in the Heart Rate Window**.

**This qualifies what the Programs page says.** The Heart Rate program description on page 18 says only that "a
heart rate monitor is required for this program", without naming a type. This page narrows it to Bluetooth
wearables. Both statements are in this manual; the program card carries the other half.

The safety page separately warns that **the pulse sensors are not medical devices** and are only an aid to
tracking heart rate trends.
