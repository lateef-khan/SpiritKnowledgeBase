**Yes — this console has a documented fallback.**

When the TFT display is damaged and cannot be used, **unplug the connection cable of the TFT display and use the
LED display for operation**. The LED display then **operates independently**.

From the LED display you can:

- **Press the START key** to start directly, or
- **Press the PROGRAM key** to select a program for movement.
- Press Start to begin the program **using the preset program values for age, weight and other program specific
  information** — the LED display does not ask you for them.

**What you lose.** Everything on the touchscreen side: profiles, video classes, the touchscreen program setup
page, Club, Media and SOLE+ sync. The LED display normally only mirrors the TFT display's motion data, so this
independent mode is a fallback, not a second console.

An E23 fault is the communication error between the TFT and LED displays; a dead TFT that shows nothing at all is
the plain "ERROR" message. Both are on their own cards.
