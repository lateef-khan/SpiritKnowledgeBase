**This treadmill has a TFT touchscreen and a secondary LED display.** The manual states it plainly: "This
treadmill is equipped with not only TFT displays but also LED displays."

**During operation the LED display only mirrors the motion data of the TFT display.** Its four windows show:

| Window set | Values |
|---|---|
| Default | INCLINE, CALORIE, PACE, SPEED |
| After pressing DISPLAY/ENTER | LAPS, DISTANCE, TIME, PULSE |

**Pressing the DISPLAY/ENTER key switches between the two sets.**

If the TFT display fails, the LED display can be used on its own — that is a separate card.
