On the Home page, choose from a variety of **pre-installed Apps**, or use the **Mirroring function to cast content
from your smartphone directly to the console screen**.

Once content is playing, use the **bottom panel** for navigation and view settings. There are **three view
layouts**:

| Layout | What is shown |
|---|---|
| Full interface | Status bar, control panels, real-time stats |
| Partial interface | Status bar, real-time stats |
| Minimal interface | Full-screen content with all panels hidden |

**The manual does not name a single app.** It says "a variety of pre-installed Apps" and nothing more, so this
knowledge base has no list of which apps ship on this console, and no mirroring instructions beyond the word
"Mirroring".
