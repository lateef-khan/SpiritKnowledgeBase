| Part | What the manual says it does |
|---|---|
| Safety key | Fits on the console and activates all functions. Without it the console cannot be controlled. |
| Console | Interface that controls all functions of the treadmill. |
| Main controller (inverter) | Carries the AC power supply for the console, the incline driver and the AC motor driver. Includes the power supply, AC motor, incline motor, AC control board control circuit and incline control circuit. |
| AC motor | Changes to increase or decrease speed. |
| Incline motor | An AC motor. The user controls elevation from the console through the main controller. |

**Two lines in this section describe a machine that is not this one.** The main controller entry ends "...link the console to output appropriate voltages for DC control Board that controls the Treadmill functions", and the general information entry says the console "Contains Key controls and LCD Display". This machine has no DC control board - it has a Rhymebus AC inverter - and its console is a TFT touch screen, as section 4-2-3 and section 6-4 both say. Treat both lines as text carried over from a DC treadmill manual.
