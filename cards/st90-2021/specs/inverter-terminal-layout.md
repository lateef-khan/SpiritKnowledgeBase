The inverter in this machine carries the factory code **YT061**.

| Terminal | What lands on it |
|---|---|
| INCLINE AC | Incline motor power |
| INCLINE VR | Incline position sensor |
| key pad | Key pad |
| Brake | Brake |
| ESP | ESP |
| CONSOLE | RM6T6A, the console link |
| AC IN | N (white), L (black) |
| AC MOTOR | W (black), V (white), U (red) |

**The drive motor runs on three wires here, U, V and W**, not the two-wire M+/M- of a DC treadmill. Any instruction telling you to check "motor M+ or M-" belongs to a DC machine and not to this one.
