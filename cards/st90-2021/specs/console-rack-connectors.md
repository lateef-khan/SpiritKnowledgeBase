| Connector | Pins |
|---|---|
| KEYBOARD | 8 |
| KEYBOARD | 10 |
| RM6T6A control | 9 |
| Wired Network cable | 8 |
| SPEED KEY | 3 |
| HAND-RIGHT | 2 |
| RF board | 3 |
| SAFETY | 3 |
| HAND-LEFT | 2 |
| INCLINE KEY | 3 |

The rack also carries the **Transfer PCB board** and the connection point for the **TFT console cable**. The RM6T6A 9-pin control cable is the link down to the inverter's CONSOLE terminal, and it is the cable E-50H asks you to check.
