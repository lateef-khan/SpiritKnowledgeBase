| Connector | Pins |
|---|---|
| KEYBOARD | 8 |
| KEYBOARD | 10 |
| RF | 3 |
| SPEED KEY | 3 |
| INCLINE KEY | 3 |
| SPEAKER (left) | 2 |
| SPEAKER (right) | 2 |
| HAND-RIGHT | 2 |
| SAFETY | 3 |
| HAND-LEFT | 2 |

The transfer board carries the two speaker plugs; the console rack list does not. Everything else on it repeats a connector that is also on the console rack.
