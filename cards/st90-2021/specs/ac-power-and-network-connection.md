| Item | Detail |
|---|---|
| AC power cable | L (black), N (white) |
| AC power switch | On the frame beside the inlet |
| Wired Network Connect Seat | Takes the 8-pin Wired Network cable |

The main power switch is at the right, under the motor hood. The wired network cable runs from the connect seat up the upright to the console rack, where it lands on the 8-pin Wired Network connector.
