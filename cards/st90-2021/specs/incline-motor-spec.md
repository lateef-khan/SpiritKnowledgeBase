| Field | Value |
|---|---|
| Type | AC motor, 110 volt |
| Power wires | Four: red, black, white, green |
| Sensor | One 3-pin position sensor cable |

| Wire | Function |
|---|---|
| Red | UP. AC voltage here raises the incline. |
| Black | DOWN. AC voltage here lowers the incline. |
| White | COM, neutral. |
| Green | Ground. |

The 3-pin cable is the position sensor the manual elsewhere calls the incline **VR**. Both E-3H and E-52H name it.
