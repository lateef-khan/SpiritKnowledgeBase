| Field | Value |
|---|---|
| Sole model number (SKU) | not confirmed; see the ST90 model card, `st90-model-numbers` |
| Manual cover | `ST90 Service Manual`, no year and no factory code |
| Factory code inside the manual | YT061, printed in the heading of section 6-1 |

**The manual itself carries no model year.** The only identifier printed anywhere in it is `YT061`, in the section 6-1 heading `INVERTER Component Locations (YT061)`.

**"ST90 2020" and "ST90 2021" are one machine, not two.** Both names are in use for the same treadmill, and this knowledge base files it under both. Which of the two ST90 numbers in the customer-service table is this machine's has not been confirmed.

The next ST90, the 2023, is a different machine: factory code ST8910-YT067, with a different console, a lube reminder instead of a belt reminder and a 15 minute sleep timer instead of 30.
