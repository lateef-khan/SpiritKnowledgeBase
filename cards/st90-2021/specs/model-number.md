| Field | Value |
|---|---|
| Sole model number (SKU) | 590820 |
| Name in the Spirit `Models` table | SOLE ST90 2021 |
| Manual cover | `ST90 Service Manual`, no year and no factory code |
| Factory code inside the manual | YT061, printed in the heading of section 6-1 |

**The manual itself carries no model year.** The only identifier printed anywhere in it is `YT061`, in the section 6-1 heading `INVERTER Component Locations (YT061)`.

**"ST90 2020" and "ST90 2021" are one machine, not two.** There is a single SKU, 590820, and the database names it `SOLE ST90 2021`. The last two digits of a Sole SKU are usually the model year, and here they read `20`, which is where the name "2020" comes from. Both names are in use for the same treadmill.

The next ST90 is a different machine: SKU 590822, named `SOLE ST90 2023`, factory code ST8910-YT067, with a different console, a lube reminder instead of a belt reminder and a 15 minute sleep timer instead of 30.
