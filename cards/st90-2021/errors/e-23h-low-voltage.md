**This is E-23H on the AC inverter, and it is not any other code that starts with the same characters.** E-01H is printed with the same words, `Low voltage`, and is a different code. The manual gives no test that tells them apart.

| Field | Value |
|---|---|
| Code | E-23H |
| Description | Low voltage |

The manual's cause column, word for word:

> Low voltage, please check outlet voltage.
> Please check extension cord.

The whole printed table is on the card `st90-2021-inverter-error-code-list`. This machine runs a Rhymebus AC inverter, so it does not use the E1 to E8 code set of the DC digital controller fitted to the F63, F65, F80, F85, F89 and TT8.
