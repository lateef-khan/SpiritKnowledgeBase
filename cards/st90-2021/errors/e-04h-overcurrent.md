**This is E-04H on the AC inverter, and it is not any other code that starts with the same characters.** This is the code for something physically jammed. The two overload codes, E-0AH and E-0BH, are answered with lubrication and bearings instead.

| Field | Value |
|---|---|
| Code | E-04H |
| Description | Overcurrent |

The manual's cause column, word for word:

> Please check if motor, drive belt, roller, running belt are stuck.

The whole printed table is on the card `st90-2021-inverter-error-code-list`. This machine runs a Rhymebus AC inverter, so it does not use the E1 to E8 code set of the DC digital controller fitted to the F63, F65, F80, F85, F89 and TT8.
