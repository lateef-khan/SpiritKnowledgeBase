**This is the words `INCLINE ERR` in the incline window, not the code E-3H and not the code E-52H.** Those two are inverter codes with their own cards.

| Field | Value |
|---|---|
| Condition | INCLINE ERR, INCLINE window displays "INCLINE ERR" |
| Reason | Position sensor value of incline motor is wrong |

1. Turn off the AC switch and turn the power on again.
2. Calibrate the monitor.

The 2023 manual for this machine prints the same row twice with two different readings, `INCLINE ERR` in one copy and `E3` in the other. This manual prints only `INCLINE ERR`.
