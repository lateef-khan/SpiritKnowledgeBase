Yes. The machine has a wired network connect seat at the frame and an 8-pin wired network cable that runs up to the console rack.

**The manual says nothing about how to configure it.** Section 8-1-8 is one line: "Set the wired network." There is no address, DHCP or port detail anywhere in the manual.
