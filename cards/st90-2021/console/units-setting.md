Open **Unit** in the settings page and touch the icon to swap between **METRIC** and **IMPERIAL**. The default is IMPERIAL.

Four values follow the setting:

| Value | Unit |
|---|---|
| Distance | mi / Km |
| Speed | mph / Km/h |
| Height | ft, in / cm |
| Weight | lb / Kg |

There is a second units setting in engineering mode, which is the one the calibration uses.
