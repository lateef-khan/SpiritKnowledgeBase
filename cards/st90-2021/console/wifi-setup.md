1. Open **WIFI** in the settings page and turn it on. The console scans for hotspots around the treadmill on its own.
2. Touch the network name you want and enter the password.
3. If it joins, touch the back icon to return to the settings page.

**If it does not join, the screen shows the network as saved but not linked.** The state icon has two readings only, linked and unlinked.
