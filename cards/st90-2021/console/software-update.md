**The idle mode page tells you when there is something to install.** It shows `NEW SOFTWARE VERSION AVAILABLE!` above the Settings button for a system update, and `NEW APP UPDATE AVAILABLE!` for an app, Miracast or AirPlay update.

1. Open **Software** in the settings page.
2. If a system update exists, an **Update** button appears. Touch it. The version number changes when the update finishes.
3. If the software is already current, only a back button appears.

**Do not interrupt the power during an update.** The manual says the system may crash and not start again.

There is a second update path, from a USB stick, in the engineering menu's Maintenance page.
