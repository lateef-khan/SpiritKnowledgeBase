| Item | What it holds |
|---|---|
| Grade Return | Auto incline return to zero, on or off |
| Child Lock | On or off, default off |
| Beep Mode | Touch button beep, on or off, default on |
| Display Mode | Sleep and safety key screen behaviour, default on |
| Distance | Total workout distance, 0.00 to 9999 Km / Mile |
| Hour | Total workout time, 0.00 to 9999 hrs |
| SW Version | The APK version |
| FW Version | The firmware version |
| OS Version | The operating system version |
| Zeroing | Clears the total distance and time |

**Zeroing asks first.** Touching it puts up "Are you sure the parameter need to be reset?"; Yes clears the totals, No exits.

Beep Mode is about the touch screen specifically: with it on, touching an available button on the screen beeps.
