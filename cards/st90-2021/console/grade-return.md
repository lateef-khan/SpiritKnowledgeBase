**Grade Return** is a setting in the engineering menu's Machine Information page, not a fault.

**With it on**, the incline returns to zero when any of these happen:

- the treadmill is powered on
- the user presses pause during a workout
- the console is on the SUMMARY page
- the console is on the HOME page
- the safety key is taken off and put back

**With it off**, the incline stays where it is in all of those cases. It still returns to zero when the user starts a new workout.
