**Belt Setup** is a reminder to check the belt after a set number of hours. It is **off by default**, with the time set to 0. The range is **100 to 1000 hours**.

When the total workout time reaches the setting, the main page puts up:

> CHECK BELT PRESS START/STOP TO RESET CHECK MESSAGE

for about 3 seconds, then goes to the idle page.

**Clearing the message does not clear the odometer.** The total distance and time keep accumulating.

This is a belt *check* reminder, not the lube reminder the 2023 machine has; the 2023 console replaced this page with a Lube Setup page defaulting to 90 hours.
