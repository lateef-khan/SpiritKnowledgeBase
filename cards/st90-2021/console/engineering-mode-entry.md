From the **settings page**, touch the word **Settings** ten times. The engineering page opens.

It holds six functions:

1. Engineering Mode
2. Diagnostics
3. Machine Information
4. Maintenance
5. Belt Setup
6. Key Test

Touching the word **Settings** ten times again, from the engineering page, opens the developer options page.
