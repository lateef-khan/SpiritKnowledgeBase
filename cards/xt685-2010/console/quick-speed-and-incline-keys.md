**On this console the keys are labelled QUICK KEYS, and the manual calls them Quick Speed and Quick
Incline.** The 2015 XT consoles call the same control a **Select** key, and the 2023 consoles
replace it with direct preset buttons. Ask for the key by the name printed on the machine in front
of you.

1. Press either the **Quick Speed** or the **Quick Incline** button.
2. **Select 2 digits.**
3. **Press Enter.** The treadmill adjusts to that value automatically, so you do not have to press
   and hold a key until it reaches the value.

Values are entered in **.1 mph increments for speed** and **.5 level increments for incline**.

The manual prints these examples:

| Press | Result |
|---|---|
| Quick Incline, then 1, 0 | Incline Level 1.0 |
| Quick Incline, then 3, 5 | Incline Level 3.5 |
| Quick Speed, then 8, 0 | 8.0 mph or kmph |
| Quick Speed, then 0, 8 | 0.8 mph or kmph |

**The highest value this console will take is printed in this same paragraph, and it is not the
XT685-2015 figure.** The two books state different maxima for machines carrying the same model name,
so do not answer a 2010 machine from `xt-2015-specs-speed-and-incline-range-xt485-xt685`. The
figures themselves are a specification and live at
`xt-2015-specs-speed-and-incline-range-xt185-xt285`, whose sentence the 2010 XT685 manual prints
word for word.

**Quick Start names these keys too**, as the alternative to holding Speed or Incline down - see
`xt-2015-console-quick-start`.

**The XT485 2013 owner's manual prints this paragraph and the same four examples on its printed p. 13**, with the keys labelled QUICK KEYS on its console drawing, so this card covers that machine - with one wording change: it says "select either **1 or 2 digits**" where the 2010 XT685 says 2 digits, so 8 and Enter is offered as well as 8, 0 and Enter. **The ceiling it prints in the same paragraph is 9.9 mph or kmph and 9.5% incline** - "The maximum value you may input for speed is 9.9 mph or kmph and incline 9.5%" - which is the same sentence the 2010 book holds at `xt-2015-specs-speed-and-incline-range-xt185-xt285`; the calibration routine of the same 2013 book sets a maximum of 12.0 mph / 18.0 kmph, and nothing in it says how a speed above 9.9 is reached.
