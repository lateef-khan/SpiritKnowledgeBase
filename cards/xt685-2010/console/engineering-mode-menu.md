**This Functions list holds a Motor Test and an ODO Reset, and the display test is called LCD
Test.** The 2015 XT menu has neither, calls its display test Display Test, puts Security last and
ends with an Exit item: `xt-2015-console-engineering-mode-menu`. Do not read one menu onto the
other.

The console has built in maintenance/diagnostic software. It will, for example, change the console
settings from English to Metric and turn off the beeping of the speaker when a key is pressed.

**To enter: press and hold the Start, Stop and Enter keys, then insert the safety key.** Keep
holding the keys down until the Message Center displays **Engineering Mode Menu**, then press
**Enter**.

| Item | What it does |
|---|---|
| a. Key Test | Will allow you to test all the keys to make sure they are functioning |
| b. Security | Allows the keypad to be locked to prevent unauthorized use |
| c. Functions | Press Enter to access settings, Up arrow to scroll |
| d. LCD Test | Tests all the display functions |

Under **Functions**:

| Setting | What it does |
|---|---|
| Display Mode | **Turn off** to have the console power down automatically after **30 minutes** of inactivity; leave on to display all lights while the power is on |
| Motor Test | Press Enter to run the motor up and down in a continuous loop. The display shows the level setting and the position sensor reading. Press Stop to end the test |
| Beep | Turns off the speaker so no beeping sound is heard |
| Units | Sets the display to readout in English or Metric display measurements |
| ODO Reset | Resets the odometer |
| Pause Mode | Turn on to allow 5 minutes of pause, turn off to have the console pause indefinitely |

**The manual calls the Motor Test motor "the resistance motor"**, which is the wording of a bike or
elliptical manual; on this machine it is the incline motor that runs up and down and reports a
position sensor reading. The phrase is reproduced as printed.

**This manual and the XT685-2015 manual set Display Mode in opposite senses.** This one says turn it
**off** for the console to power down after 30 minutes, which agrees with the XT385-2015 and
XT485-2015 books; the XT685-2015 book says turn it **on**
(`xt-2015-console-engineering-functions-beep`). The 30 minute period is the same everywhere. Nothing
resolves the direction; test the machine.

**The manual contradicts itself about what is in Functions.** Its lubrication note tells you to
scroll Functions until a **"Reset Lube"** message appears and press Enter, but the Functions list
printed here has no Reset Lube and no Maintenance entry at all. Both are reproduced as printed. The
2015 XT and the CT800 menus do print a Maintenance entry that resets the lube message.

**Security is the keypad lock**, and this manual says no more about it than the one line above:
`xt-2015-console-keypad-lock-security`.

**Calibration is not in this menu.** It has its own entry gesture and its own "Factory settings"
prompt: `xt685-2010-console-calibration-wheel-size-3-01`.

The converted text mis-numbers the six Functions entries - it prints "ii" twice and then jumps to
"vii" - so the order above is the printed order, not the printed numbering.
