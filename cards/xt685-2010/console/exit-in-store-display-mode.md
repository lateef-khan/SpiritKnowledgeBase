**A new console comes configured in an in-store "Display Mode", where it stays powered on unless the
main power switch is turned off.** That is why a machine straight out of the box never goes to
sleep.

To exit display mode for normal operation:

1. **Press and hold the Stop, Enter and Handrail Control key for 5 seconds.** The display shows
   `Display mode - On`.
2. Use any of the **Program, Incline or Speed +** keys to change the setting to **Off**.
3. Press **Enter**.

The Handrail Control key is the handrail disable switch in the lower right of the console - see
`xt-2015-console-handrail-controls-and-disable-switch`.

**There is a second Display Mode setting, in the engineering mode Functions menu**, which is the one
that decides whether the console powers down after 30 minutes of inactivity:
`xt685-2010-console-engineering-mode-menu`. The manual gives them the same name and never says how
the two relate. This card is the ATTENTION block, the one reached with the three-key hold.

The 2015 XT manuals print no ATTENTION block and no in-store display mode, so nothing here is
claimed for those machines.

**The Sole bike consoles have the same in-store mode with a different third key** - Display rather
than Handrail Control - and are a different brand:
`sole-bike-display-mode-exit-with-level-up-key`.
