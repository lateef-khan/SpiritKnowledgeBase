The program buttons are Manual, Hill, Fat Burn, Strength, Interval, 2 User and 2HR. There is a separate Fan key for the cooling fan.

**READY MODE**
- STOP: non-function.
- START: starts the elliptical after a 3 second countdown on the window display. In MANUAL the elliptical starts at MIN LEVEL.
- LEVEL UP / LEVEL DOWN / STRIDE UP / STRIDE DOWN / DISPLAY: non-functional if the user has not entered a setting.
- FAN: controls fan ON/OFF.
- ENTER: enters parameter setting, and confirms or modifies a parameter.

**RUN MODE**
- STOP: stops the elliptical.
- START: non-functional.
- ENTER: changes the LEVEL and STRIDE profile.
- LEVEL UP / LEVEL DOWN: each press changes level by 1.
- STRIDE UP / STRIDE DOWN: each press changes position by 1; maximum stride position 20, minimum 1.
- FAN: controls fan ON/OFF.
- DISPLAY: press to display the exercise data for 5 seconds during a workout.
