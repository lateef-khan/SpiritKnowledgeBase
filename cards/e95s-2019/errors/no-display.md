1. Under normal use the console screen will display. If there is no display, first check the **AC adapter** to make sure it is in the correct position.
2. Check that all the wires are inserted firmly and securely into the console.
3. Remove the **AC adapter fuse** to check it for damage; replace it if damaged.
4. Remove the console cover and the left and right chain covers. Check that all wires are inserted in the correct positions and check whether any wires are broken.
