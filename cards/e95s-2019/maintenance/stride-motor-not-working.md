1. The incline motor, controller and gear motor are all electronic components. **Do not disassemble them if you are unfamiliar with these parts.**
2. When the motor is not functioning, check all the wires for a secure connection, and check whether the incline controller and power adaptor are damaged or broken. Replace damaged or broken parts.
3. **To return the motor, make sure it has been reset**, then turn the tubing clockwise to the end. Turn the same tubing counterclockwise **two and a half circles**, or set the centre distance between the two holes to **245 +/- 1 mm**.
4. If there is no resistance, first check whether the console is functioning normally. Next check the **gear motor cable**; if it is worn or damaged, remove the steel cable. Use a Phillips screwdriver to remove the **tapping screw 5x19** securing the gear motor cable and replace the cable with a new one.
