**This machine has a separate User 1 key and User 2 key, and its manual is the only one in the family that states a segment count: 18.** The XT485 and XT685 use a single User 1-2 key and print no segment count.

1. Select the **User 1** or **User 2** program key, then press **Enter**. The dot matrix display will have a single row of segments at the bottom, unless a program was previously stored.
2. If a program is stored under the button pressed, it is retrieved. If not, you have the option of programming in your first name. The message window displays and flashes the letter **"A"**. Press the **Speed +** key for "B", or the **Speed -** key for "Z". After selecting the appropriate letter, press Enter; "A" is displayed and blinking again. Repeat until all the letters of your first name are programmed (**7 characters maximum**). When your name is displayed, press **Stop** and it is stored under either User 1 or User 2.
3. The Message Center blinks an **Age** value. Adjust the age and press Enter.
4. The Message Center blinks a **bodyweight** value. Enter your bodyweight and press Enter.
5. The clock / Message Center flashes. Use the + / - keys to adjust up **from 30 minutes** if desired, then press Enter. **This is a must to continue even if time is not adjusted.**
6. The first column (segment) blinks. Using the + / - keys, adjust the speed level to your desired effort for the first segment, then press Enter. The second column blinks; repeat until **all 18 segments** have been programmed. The first column blinks again — this is the incline programming; repeat the process for **all 18 segments** of incline.
7. Press the **Start** button to begin the workout and also save the program to memory.
8. The profile picture is re-scaled to fit in the window, but the actual speed and incline settings remain the same as programmed.

**Note:** while in a User program, if you change the speed, all segment speeds from there on also change. If you increase your current speed 1 mph, the remaining segment speeds increase by 1 mph; if you decrease your current speed .5 mph, the remaining segment speeds decrease by .5 mph.
