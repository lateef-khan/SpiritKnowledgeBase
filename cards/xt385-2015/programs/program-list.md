The manual states: **"The XT385 offers seven factory preset-programs, two user defined programs and one Manual program."** The console illustration calls it **"Ten innovative programs"**, which is the same total.

| Program | Type |
|---|---|
| Manual / Quick Start | You set speed and incline yourself |
| Hill | Preset pyramid profile |
| Fat Burn | Preset sustained-effort profile |
| Cardio | Preset profile with fluctuations |
| Strength | Preset build-and-hold profile |
| Interval | Preset high/low intensity profile |
| HR1 | Heart rate program, 60% of maximum heart rate |
| HR2 | Heart rate program, 80% of maximum heart rate |
| User 1 | A profile you build and save |
| User 2 | A profile you build and save |

**This machine has no Calorie program and no Fusion program.** Those two are only on the XT485 and XT685 in this family.

Two counts in the manual disagree with each other. The Preset Programs page says "The treadmill has five different programs" and then describes only Hill, Fat Burn, Cardio, Strength and Interval; the Heart Rate chapter says the heart rate monitor can be used "during any of the nine different programs". Only the seven-plus-two-plus-one sentence above matches the ten-program console illustration.
