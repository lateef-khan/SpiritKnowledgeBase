1. **Press the Garmin logo in the status bar**, then the **Connect Device** button to run the
   pairing flow.
2. **Switch the Garmin device into pairing mode.**
3. **Select it on the console screen.**
4. **Input the pin code displayed on the device.**

**Garmin then becomes one of the three workout views**, alongside **Stats** and **Charts**, on the
right side of the workout screen
(`85s-fit-2026-console-workout-views-and-finishing-with-two-stop-presses`).

**This is the only Spirit machine in the range with a named watch integration.** No other Spirit
owner's manual mentions Garmin at all.

**The manual names no model, no minimum firmware and no list of supported devices**, and does not say
what data crosses the link or in which direction.

**It is a separate flow from the heart rate icon.** The status bar also carries a **Heart Rate** icon
for pairing "a heart rate measuring device", with no steps printed - do not send an owner through the
Garmin flow for a chest strap.
