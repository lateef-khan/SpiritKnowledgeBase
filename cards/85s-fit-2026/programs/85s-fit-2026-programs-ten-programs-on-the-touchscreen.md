Press **All Programs** on the home page for the full selection. The book then describes **ten**:

- **Timer** - *"The level of resistance is controlled by the user. Increase or decrease levels at any
  time during your workout."* Set a target workout time and adjust resistance manually.
- **Hill** - a triangle or pyramid type of gradual progression from approximately **10% of maximum
  effort** (the level you chose before starting) up to a maximum effort lasting **10% of the total
  workout time**, then a gradual regression back to approximately 10%.
- **Plateau** - *"A Plateau Program modifies training variables to re-stimulate physiological
  adaptation."* Main goals: break performance stagnation, introduce new training stimulus, improve
  recovery-stress balance, prevent overtraining. The program preview describes it as a quick rise to
  maximum intensity sustained for most of the workout.
- **HIIT**
- **Custom** - **you create the resistance level for each of the 20 segments** using the on-screen
  keyboard, and may change them at any time during the workout.
- **Steps** - set a target number of steps; the workout finishes automatically when it is reached.
- **Calories** - set a target calorie burn; the workout finishes automatically when it is reached.
- **Heart Rate**
- **METs**
- **Wingate Test**

Tapping a program opens **Preview Mode**, where you can slide left and right between programs of the
same category; tapping the card again opens the **Program Setup** page, where a value is changed by
dragging the scale, using the **+** and **-** buttons, or tapping the number for direct input.
**Different programs offer different parameters to adjust.** **Start This Program** begins it;
**Back** returns to program selection.

**There is no Manual program and no Facility program** on this machine, and no Symmetry program key
- unlike the 8.5S, which has all three plus Manual and a Facility name; see
`85s-2025-programs-eleven-programs-on-the-touchscreen`. The 8.5S-Fit's Custom holds **twenty**
segments where the dot matrix rehabilitation steppers' User programs hold twenty-four.

**Measured, not assumed:** the 8.5S and 8.5S-Fit program pages share only **12.5%** of their 8-word
phrases, well below the 56.9% the two books share overall.
