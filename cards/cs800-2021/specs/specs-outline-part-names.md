Names only - **no item numbers, part numbers or quantities**.

**Drawing 1 - covers, twelve labels**

| Left column | Right column |
|---|---|
| Console Mast Cover (R) | Console |
| Chain Cover (L) | Console Mast Cover (R) |
| Pedal (L) | Handle Bar Cover (R) |
| Pedal (R) | Chain Cover (R) |
| Left Slider Cover | Rear Side Case |
| Handgrip CapCover (L) & (R) | Right Slider Cover |

**Console Mast Cover (R) is printed twice.** The left-hand label points at the *left* mast cover
and should read (L); the drawing has no (L) label at all.

**Drawing 2 - structure, fifteen labels**

| Left column | Right column |
|---|---|
| Left Handgrip | Console Mast |
| Crank Arm Assembly | Right Handgrip |
| Rail Tube | Drive Pulley |
| Connecting Arm (L) | Swing Assembly |
| Connecting Arm (R) | Flywheel |
| Rear Stabilizer | Idler Wheel Assembly |
| | Main Frame |
| | Linked Assembly (R) |
| | Handgrip Connecting Tube |

The 2016 book names the same structure differently - *Curved Rail Tube*, *Crank Arm*, *Rear
Shroud*, *Slide Wheel Cover* (`cs800-2016-specs-outline-part-names`); the parts list with item
numbers is in the owner's manual (`cs800-2024-specs-parts-list`).
