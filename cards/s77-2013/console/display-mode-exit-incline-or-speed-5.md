The console ships in an in-store display mode where it stays powered unless the main power switch is off. To exit for normal operation: press and hold **Stop, Enter and Display** for **5 seconds**; the display shows 'Display mode - On'; use the **Incline 5 key or the Speed 5 key** to change the setting to **Off**, then press **Enter**. The only book in the wave with this key naming.
