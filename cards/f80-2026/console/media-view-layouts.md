Switch between three view layouts, depending on how much information you want while working out:

| Layout | What it shows |
|---|---|
| **Full interface** | Status bar, control panels, real-time stats |
| **Partial interface** | Status bar, real-time stats |
| **Minimal interface** | Full-screen content with all the panels hidden |

The same logic applies while watching video classes.
