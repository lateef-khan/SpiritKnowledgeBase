Access community challenges by selecting the **"Club" tab in the bottom navigation bar**. Here you find
events created by other members of the SOLE community. **To view all available events your profile must be
linked to your SOLE+ account.**

- **Shared goals** are challenges with a predefined target score, which must be achieved within a limited
  time period in order to complete the challenge.
- **Rankings** are competitions in which users try to earn the highest score possible within a limited time
  period, in order to defeat as many competitors as possible.
- The score can be represented by one of these **focus parameters**: **calories, distance, active time and
  workout count**.
- **Filter** events by format, duration and focus parameter using the "filter" icon in the upper menu.
- **Join private events with "Join via ID"** - enter the event ID shared with you by the event's creator and
  you automatically become a participant.
- **Create your own challenge** with the + icon in the upper menu: choose event format, focus parameter, set
  dates, event name and an optional description. Your event can be **private or public**.
