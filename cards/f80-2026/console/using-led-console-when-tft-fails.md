**When the TFT displays are damaged and cannot be used, you can unplug the connection cable of the TFT
displays and use the LED displays for operation.**

At this time:

- The **LED displays operate independently**.
- The machine **can be started directly by pressing the START key**, or you can **select a program by
  pressing the PROGRAM key**.
- **Press the Start key to begin the program using the preset program values for age, weight and other
  program specific information.**

The manual does not say where the TFT connection cable is, and does not say whether the touchscreen features
(profiles, video classes, Club, Media) have any LED equivalent - they do not appear in this fallback.
