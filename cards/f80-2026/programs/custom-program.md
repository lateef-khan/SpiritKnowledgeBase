**Custom is a program with fully customizable speed and incline patterns.**

1. On the program setup page, **press "Add Pattern" to enter edit mode**.
2. **Connect dots to map your load throughout the program, from easiest on the bottom to hardest on the
   top.**
3. **Each segment's duration depends on the selected total time** - you can set the total time right before
   the start.

- **Speed values are relative**, and the maximum can be changed before each workout; **all the segments will
  be adjusted proportionally**.
- **Incline values are absolute and can be set directly.**
- **The incline pattern is optional.**

A finished Custom workout can be saved as a Template so its settings are preserved.
