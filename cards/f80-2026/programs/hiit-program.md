**"HIIT is a customizable interval program where you can manually choose the duration and speed of the
sprint and rest intervals, as well as the total number of intervals."**

So HIIT gives you four settings: sprint duration, sprint speed, rest duration and rest speed, plus the
interval count.

**HIIT is not the same as the Interval program.** Interval is one of the five preset pattern programs and
follows a fixed chart; HIIT has no chart because you build the pattern yourself.
