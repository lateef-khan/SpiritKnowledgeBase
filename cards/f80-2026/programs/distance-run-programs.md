**5K Run and 10K Run automatically set a target distance for your workout - 5 km and 10 km respectively.**

- On the program setup page, **the console shows the estimated total time for this run based on the selected
  target speed**.
- **The program ends when the target distance is reached**, not when a timer runs out.

The manual prints the targets in kilometres for both programs, whatever display units the console is set to.
