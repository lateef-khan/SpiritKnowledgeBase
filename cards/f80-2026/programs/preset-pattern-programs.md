**Hill, Fatburn, Cardio, Strength and Interval follow preset speed and incline changing patterns.** The
**Total Time** and **Max Speed** settings define the duration and overall intensity of your workout.

**How to read the pattern values**

- **Speed values are a percentage of the Max Speed you set before the start.** If Max Speed was set to 10.0
  mph and the chart value is 20, that segment runs at 2.0 mph. A chart value of 100 means that segment runs
  at exactly the Max Speed you set.
- **Incline values are absolute.**

Because speed is proportional, changing Max Speed rescales the whole workout; changing Total Time changes
how long each segment lasts, not what it demands.

The segment-by-segment numbers for all five programs are on their own card.
