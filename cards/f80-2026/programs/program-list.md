Preset programs are reached through the **"Programs" tab of the bottom navigation bar**. Tap any program
card to open a **Program Setup page**, where you can learn more about the program and set the properties of
your workout.

**Programs**

| Program | What it is |
|---|---|
| Manual | Timed workout, speed and incline controlled manually at any time |
| Hill | Preset speed and incline pattern |
| Fatburn | Preset speed and incline pattern |
| Cardio | Preset speed and incline pattern |
| Strength | Preset speed and incline pattern |
| Interval | Preset speed and incline pattern |
| HIIT | Customisable sprint/rest intervals |
| 5K Run | Target distance 5 km |
| 10K Run | Target distance 10 km |
| Heart Rate | Incline controls heart rate to a target |
| Custom | Fully customisable speed and incline pattern |

**Fitness tests**, also on the Programs page: **Gerkin Protocol**, **Air Force**, **Army**, **Navy**,
**Coast Guard**, **PEB** and **Marine Corps**.

The additional tab menu at the top of the Programs page holds **Templates**.

**To adjust workout parameters you can drag the ruler, tap the + and - buttons, or tap on the number to open
a numpad and input the value directly.**
