**Problem:** motor is not responsive after pressing Start.

**Solution / cause, as printed:** "Check the problem handling based on the error code reported."

**That is the whole entry.** This manual answers a dead motor by sending you to whichever code the console
is showing, so read the display first and then use that code's card. The codes that can appear are LUBE,
E01, E02, E03, E04, E05, E06, E3, E22, E23, E31 and ERROR.

**If no code is showing at all**, this row gives you nothing further; the display-does-not-light row and the
assembly cable-pinch warning are the two other places in the manual that cover a machine that will not run.
