1. Select a program, then press **Enter** to begin customizing it with your personal data - or just
   press **Start** to begin the program with the default settings.
2. The **Time** window blinks with the default value of **20 minutes**. Adjust with any of the
   Up/Down buttons, then press **Enter**.
3. The **Incline** window now blinks a value indicating your **Age**. Entering the correct age
   affects the Heart Rate Bar Graph accuracy and is also needed for the HR programs. Adjust, then
   press Enter.
4. The **Distance** window now blinks a value indicating your **Bodyweight**. Entering your correct
   bodyweight affects the Calorie readout accuracy. Adjust, then press Enter.
5. The **Speed** window now blinks, showing the preset top speed of the selected program. Adjust,
   then press Enter. Each program has various speed changes throughout; this limits the highest
   speed the program will attain during your workout.
6. Press **Start** to begin your workout, or **Stop** to return to the previous screen.
7. A **three minute warm-up** begins, with the clock counting down from three minutes. Press Start
   to bypass it and go straight to the workout.

**You may press Start at any time during programming to begin with only the settings you have
modified at that point - except on the Calorie Program.** The Calorie program is the one program
this manual excludes from that shortcut, because the console has to work the program time out from
every value you enter; see `ct850-2018-programs-calorie-program-setup`.

**5K Run, 10K Run, HR 1, HR 2, Custom and Manual do not have a warm-up.**

**This manual does not name a Program button.** It says only "select a program". The twelve-program
CT850 generation of 2016 and 2020 names a Program button in the same step and does not print the
Calorie exception, because it has no Calorie program - see
`ct850-2020-starting-and-customising-a-program`.
