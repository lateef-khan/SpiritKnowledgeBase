**This console holds two custom programs, U1 and U2.** The 2016 and 2020 CT850 generation holds one
and never offers a choice - see `spirit-ct800-programs-custom-program-build`.

1. Select the **Custom** program. The Message Window shows **"PRESS ENTER TO MODIFY OR START TO
   BEGIN WORKOUT"**. Press **Enter** to set it up, or **Start** to begin the workout. When you press
   Enter the Dot Matrix Window shows **U1**, flashing, and the Message Window shows **"PRESS 1 OR 2
   TO SELECT THEN PRESS ENTER"**. Choose **U1** or **U2** with the 1 or 2 button, then press Enter.
   The Dot Matrix Display lights a single row of dots at the bottom unless there is a previously
   saved program.
2. The Message Window shows **"ADJUST TIME THEN PRESS ENTER"** with the Time window blinking. Use
   the Up/Down/Fast/Slow buttons or the numeric buttonpads to set the time, then press Enter. *This
   is a must to continue even if the time is not adjusted.*
3. The Message Window shows **"ADJUST AGE THEN PRESS ENTER"** and the Incline window blinks your
   age. Entering the correct age affects the Heart Rate Bar Graph accuracy. Adjust, press Enter.
4. The Message Window shows **"ADJUST BODY WEIGHT THEN PRESS ENTER"** and the Incline window blinks
   your bodyweight. Entering it correctly affects the calorie readout accuracy. Adjust, press Enter.
5. The Message Window shows **"ADJUST SPEED THEN PRESS ENTER"**. The first speed column (segment)
   blinks along with the Speed window. Set the speed for that segment with the Up/Down/Fast/Slow
   buttons, then press Enter. The second column then blinks. **The previous segment's value is
   carried over to the new segment.** Repeat until all segments have been programmed.
6. The Message Window shows **"ADJUST INCLINE THEN PRESS ENTER"**. The first column blinks again,
   and so does the Incline window. Set the incline for each segment the same way.
7. The Message Window shows **"PRESS START TO BEGIN WORKOUT OR ENTER TO MODIFY"**. Press **Start**
   to begin the workout **and save the program to memory**, or **Stop** to return to the previous
   screen.

**The manual never says how many segments a Custom program holds.** It says only "repeat the above
process until all segments have been programmed". Do not assume the twenty segments the touchscreen
consoles use.
