1. Press the **Calorie** button to initiate the program. The Message Window shows **"PRESS ENTER TO
   MODIFY."**
2. Press **Enter**. The Message Window shows **"ADJUST AGE THEN PRESS ENTER"** and the Incline
   window blinks. Set the age, press Enter.
3. The Message Window shows **"ADJUST BODY WEIGHT THEN PRESS ENTER"** and the **Incline** window
   blinks. Set the weight, press Enter.
4. The Message Window shows **"ADJUST TARGET CALORIE BURN THEN PRESS ENTER"** and the **Incline**
   window blinks. Set the calorie target, press Enter.
5. The Message Window shows **"ADJUST MAX. SPEED THEN PRESS ENTER"** and the **Speed** window
   blinks. Set the maximum speed, press Enter.
6. The Message Window shows **"ADJUST MAX. INCLINE THEN PRESS ENTER"** and the **Incline** window
   blinks. Set the maximum incline, press Enter. The Message Window then shows **"PROGRAM TIME"**:
   **the console works out for itself how long it will take to burn the calories you asked for** and
   shows that time in the Time window.
7. The Message Window shows **"PRESS START TO BEGIN WORKOUT OR ENTER TO MODIFY"**. Press **Start**
   to begin, or **Stop** to return to the previous screen.

**The Calorie program is the one program you may not start early.** On every other program you may
press Start part way through the setup to run with only the values you have changed so far; this
manual excludes the Calorie program from that, because the program time depends on all of them - see
`ct850-2018-programs-preset-setup-steps`.

**As printed, body weight, target calorie burn and maximum incline all blink in the same Incline
window on consecutive screens.** That is what the source says and it is preserved.

**The manual prints no default age, weight or calorie target for this program**, and no warm-up or
cool-down description. Do not assume the figures another Spirit console uses; the XT485 and XT685
Calorie program has its own defaults and its own warm-up, see
`xt-2015-programs-calorie-program-setup-xt485-xt685`.

For what the program actually does to speed and incline, see
`ct850-2018-programs-calorie-strength-speed-incline-chart`.
