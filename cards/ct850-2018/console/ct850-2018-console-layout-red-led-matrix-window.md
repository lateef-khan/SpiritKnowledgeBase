**The matrix window on this console is red.** The CT800 console whose drawing is otherwise labelled
the same way has a **blue**-LED matrix window:
`spirit-ct800-console-layout-blue-led-matrix-window`. The other CT850 LED console is a different
shape again, with scan buttons, direct access ladders and a USB charger:
`ct850-2020-console-layout`.

The drawing labels five things:

| Call-out | The manual's words |
|---|---|
| Fan | "Fan to keep you cool" |
| Heart Rate % Profile | The bar graph above the display |
| Contact Heart Rate Grips | The two handlebar grips |
| 20-Character Message Center | The text window |
| Large Red-LED Matrix Window | The dot matrix panel |

It also labels the storage: **"Convenient water bottle holder and cargo compartment for buttons,
phone, or MP3 player"**. The manual replaces the word "key" with "button" throughout, so it reads
"buttons" where it means keys.

**There is no USB charger, no scan button and no direct access ladder on this drawing**, and the
manual prints no numbered key map. It names a numeric buttonpad in its quick start and incline
instructions but does not draw it
(`ct850-2018-console-quick-start-numeric-buttonpad`).

The ports on the back of the console are not named beyond the C-SAFE pair
(`ct850-2020-c-safe-ports`).
