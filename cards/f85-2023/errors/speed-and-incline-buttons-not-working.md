The matrix gives one set of causes for both the FAST/SLOW speed buttons and the UP/DOWN incline buttons.

1. The connector between the SPEED CABLE and the CONSOLE is not connected properly. Connect the cables again.
2. The connector between the SPEED CABLE and the SPEED ADJUSTMENT SWITCH W/CABLE is not connected properly. Check
   the wire of the adjustment switch, and replace the cable if needed.
3. The button of the SPEED ADJUSTMENT SWITCH is broken. Replace the switch.
4. The connector of the SPEED CABLE or the SPEED ADJUSTMENT SWITCH W/CABLE is damaged.

**As printed**, the numbering in the solve column runs 1, 2, 2, 3 while the reason column runs 1 to 4. The pairing
above follows the order the manual prints.

Run the console key test first to find which buttons the console actually sees.
