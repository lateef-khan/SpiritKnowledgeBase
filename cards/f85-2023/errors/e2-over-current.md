**This is E2, over current. It is not E3 (incline VR voltage). On a Sole machine built before 2016 the
same over current fault is printed as E3.**

**Definition.** The controller detected that the operating current for the drive motor is above standard, so the
display lights up and shows E2. The controller is protecting itself and the drive motor from damage.

**Usual cause.** The running belt needs lubricating, or its bottom fibre is badly worn and needs replacing. A dry
or worn belt makes more friction against the running deck, so the controller has to supply more current to hold
the set speed.

1. Lubricate the bottom of the running belt as the owner's manual describes.
2. If that does not solve it, the belt is worn out. Replace the running belt; the drive motor current then returns
   to normal.
3. If E2 still appears after a new belt, either the controller or the drive motor is defective. **Replace the
   controller first**: the drive motor is a passive component and is less likely to be the cause.
