The cover reads **F85(2023)**, the factory code **ST278-YT071**, and calls the machine
a **ENT Treadmill**.

The console is key controls and a 15.6" TFT touch panel display. The display board runs **Android 10**.

The machine has a console, a main controller carrying the DC power supply, the incline driver and the DC motor
driver, a DC drive motor and an AC incline motor. It also has a **rear incline motor** on its own rear incline control board, which is what gives this machine decline.

**The manual never prints a six digit SKU.** It identifies the machine only by the name on the cover and the
factory code above.
