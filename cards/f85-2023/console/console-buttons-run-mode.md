| Button | Run Mode |
|---|---|
| Safety Key | Pulling it away shuts the computer down automatically. |
| Stop Key | Press STOP to stop the treadmill. |
| Start Key | Non-functional. |
| Speed quick keys | Sets speed to 2, 3, 4, 5, 7, 9, 12 MI (3, 6, 9, 12, 15, 18, 22 KM) |
| Incline quick keys | Sets incline to -4, -2, 2, 4, 6, 9, 12 |
| Fan key | Turns the fan ON and OFF (Optional). |
| Display key | Changes the three training diagrams, from Stats to Charts to Track. |
