1. Remove the slider adjustment following its instructions, then use an **M6 Allen wrench** to release the **socket head cap bolt M8 x 40L** which secures the fixing piece on the main frame.
2. **Plug in the power supply before removing the incline motor and use the console to set the program to 21".** If the gear motor is also coming out, set the resistance control to **max, level 20**, then cut off the power.
3. Use **two 17 wrenches** to release the incline set screws **(diameter 10 x 62L)**, **flat washer 3/8" x 19 x 1.5T**, **nylon nut M10 x 8T** and two **nylon washers diameter 24 x diameter 10 x 3T** from the moving range adjusting assembly.
4. Release the incline set screws **(diameter 10 x 40L)**, **flat washer 3/8" x 19 x 1.5T** and **nylon nut M10 x 8T** which fix the incline motor.
5. Use a Phillips head screwdriver to release the **four tapping screws (diameter 5 x 19L)** holding the circuit cover on the main frame.
6. Use diagonal pliers to cut the cable ties on the fixed wires. Use a Phillips head screwdriver to release the **tapping screw (diameter 5 x 19L)** from the incline motor, and unplug the wire running from the incline motor to the controller - **remember the wire position**. The incline motor wire can then be pulled out and the motor removed.
7. **Take the steel cable out before removing the gear motor.**
8. Use a Phillips head screwdriver to release the **two tapping screws (diameter 5 x 19L)** holding the gear motor. Pull out the connected wire, then remove the gear motor.
9. **Remember all the wire positions before releasing the controller.** Pull out all the wires and use a Phillips head screwdriver to remove the **two tapping screws (diameter 5 x 19L)** holding the control plate on the main frame.
10. To remove the spring, use **two 14 wrenches** to release the **hex head bolt 3/8 x 19L**, **washer 3/8" x 19 x 1.5T** and **nylon nut 3/8" x 7T** which fix the moving range adjusting assembly. The spring can then come out.
11. Use a **12mm wrench** to release the **hex head bolt 5/16" x 1/2"** and **washer 5/16" x 23 x 1.5T** fixed on the incline rotate axle **A diameter 17 x 108L**.
12. Pull the incline rotate axle diameter 17 x 108L out from the other side, then remove the moving range adjusting assembly.
13. Use a round bar smaller than diameter 17 to knock the **J4FM bushing** out.
14. Reassemble in the reverse order as disassembly.
15. When reassembling, the **incline rotate axle must be aligned with the notch plane**, then the screw fastened.
16. Reassemble the incline motor with the **two nylon washers diameter 24 x diameter 10 x 3T**.
17. With the incline motor and all the wires fastened, plug in the power supply and **use the console to set the program to 18"**, then fasten the **socket head cap bolt M8 x 40L** fixed on the spring. Fasten all the parts.

**Note the two different stride settings.** Step 2 sets the console to **21"** before removal; step 17 sets it to **18"** before the final bolt goes in. The manual gives no reason for the difference; both figures are printed.

Zeroing a replacement motor by rotation is described in section 10.6, not here. That figure is **245 +/- 1 mm**.
