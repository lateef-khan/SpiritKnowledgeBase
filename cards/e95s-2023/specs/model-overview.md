The cover reads **E95S(2023)**, **SE895B-SE041**, "ENT Elliptical Trainer". That factory code is the manual's own name for the machine. **ENT** is how the cover marks the entertainment console model.

This is the Sole E95s of model year 2023. The Spirit database SKU is **595622**.

What the manual says the machine is made of:

- **Console** - the interface that controls all functions. It holds key controls and a **TFT LCD touch panel**.
- **Controller** - the circuit board holding the DC power supply for the console, the incline driver and the tension motor driver.
- **Gear motor** - increases and decreases the resistance level of the brake.
- **Incline motor** - an AC motor. On this machine section 3 says the user controls **stride length** with it, not elevation.

**This machine adjusts stride, not incline.** The manual keeps the word "incline" for the motor, the wiring, the calibration and the error text, because the console software and the parts are shared with the incline machines. Read "incline" as "stride" throughout when working on this model.

This is the only manual in the 2023 elliptical set whose pages are numbered "N of 60" instead of "- N -".
