**Main program (Software).** On the Settings page, the Software button lights up when an update is needed. Press it to start. The version changes when the update completes. If the software is already current, the message **"Up to date"** is displayed.

**Media Apps.** The button lights up when a third-party media or mirroring app has an update. Go to Settings, then Media Apps, click ">" to enter the update list, then press the update button for the app you want.

**Do not interrupt the power supply during either update.** The manual says this could damage the system and prevent it from functioning properly in the future.

**The YouTube app is a web version and cannot be updated.**

Engineer Mode's FUNCTION page carries a third route under Software Update:

- **COMMAND** - reserved, no function.
- **OSOTA** - forcibly check whether the OS has updates available.
- **USB** - use a USB flash drive to update through the Console APP.
