**Press "Hello Guest" ten times** to reach the machine information, settings and service procedures.
It is a user name shown on the screen, not a key.

**The manual says two different things about where you press it.** The TOUCHSCREEN OPERATION page
(p. 19) says *"from the Home page"*; the ENGINEERING MODE MENU page (p. 47) says *"from the Login
page"*. Both are reproduced as printed and the manual does not resolve them.

**The menu has five groups:**

| Group | What it holds |
|---|---|
| **Machine Information** | Set Machine type, Zero Mileage |
| **Preferences** | Set the Beep mode, Sleep mode, etc. |
| **Machine Setup** | Set Default Language, WiFi, Units, Software, Firmware, App Manager |
| **Service** | Key Test, Information, PWM Test, Ethernet Setup, Error Code Log |
| **Customization** | Retail Mode Video |

**Preferences, in the manual's own words:**

1. **Beep Mode** - turn off the beep of a button, so no beeping sound is heard.
2. **Sleep Mode** - **the default is OFF**. Set ON and the console goes to sleep after **15 minutes**
   with no operation. **Press any key to wake it up.**
3. **Pause Mode** - on allows **5 minutes** of pause; off makes the console pause indefinitely.

**Machine Information** holds three things: **Machine Type** (choose the exercise equipment),
**odometer information**, and **Reset Odometer**, which clears all mileage.

**Machine Setup** sets the default Language, Wi-Fi, Units, **Software** (a USB manual update),
Firmware and **App Manager**, which updates the third-party apps.

**Error Code Log** records the error codes raised on the machine while running.

**Fifteen minutes, and only here.** Every other Spirit bike that prints a sleep figure says 20 or 30
minutes - `ce900-2025-console-engineering-mode-unit-type` says 20,
`ct900ent-sleep-mode-auto-shutoff` says 30. Do not carry any of those onto this machine.

**This is not the older ENT entry gesture.** The CR900ENT, CU900ENT, CE800ENT, CT800ENT-2022 and
CT850ENT-2022 consoles are opened by pressing the **Home** icon ten times, and their Settings list is
seven entries, not five: `spirit-ent-console-enter-engineering-mode`.
