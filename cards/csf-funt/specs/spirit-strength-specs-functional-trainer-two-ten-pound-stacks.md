**The manual prints no weight-stack rating**; this is reconstructed from the assembly hardware table,
which is the only place the plates are counted. See
`spirit-strength-specs-no-weight-stack-rating-printed`.

| No. | Description | Spec | Qty |
|---|---|---|---|
| 021 | `10LB Weight Stack` | | 32 |
| 022 | `10LB Counter Weight Stack Set` | | 2 |
| 023 | `17 Holes Shaft` | | 2 |
| 024 | `Select Pin` | | 2 |
| 010 | `Guide Rod` | φ20*1726 | 4 |
| 011 | `Guide Rod Fixing Plate` | | 2 |

**Two of everything, so the machine has two independent stacks** - two select pins, two selector
shafts, two pairs of guide rods. Thirty-two plates and two counterweight sets divide as **sixteen
plates plus one counterweight per side**, all of them 10 lb: **170 lb a side, 340 lb of iron in the
machine.**

**The seventeen-hole selector shaft confirms the count.** Seventeen pin positions against seventeen
10 lb pieces a side is a one-to-one match, and it is the only machine in the range whose manual
prints a hole count at all.

**What the customer feels is not necessarily 170 lb.** This is a cable machine, and the manual never
states the pulley ratio, so do not convert the stack figure into a resistance at the handle. The only
Spirit strength manual that publishes that conversion is the ST800FT, where selected weight is halved
at the handle - `spirit-strength-specs-effective-resistance-is-half-the-weight-selected`. **Do not
apply the ST800FT figures to this machine**; it is a different generation and its manual is silent.

Its guide rods are 1726 mm long, the only rod length printed anywhere in the range.
