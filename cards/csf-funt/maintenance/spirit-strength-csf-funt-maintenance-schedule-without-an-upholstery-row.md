**The CSF-FUNT prints twelve action rows, and neither of them is upholstery.** It is the only
machine of the thirty-nine whose schedule omits both upholstery rows.

## What is missing, and what that means

Against the twenty-two-machine single-station table
(`spirit-strength-maintenance-schedule-thirteen-actions-daily-to-bi-monthly`) this book **drops
Clean: Upholstery (daily) and Inspect: Upholstery (monthly)** and **adds Clean: Internal Tower
(bi-monthly)**.

**A functional trainer has no pad.** The omission reads as deliberate rather than as a printing
slip: the machine is a two-column cable crossover with no bench and no seat, and the two rows it
drops are the two that name a pad. **Do not add an upholstery interval to this machine from a
neighbouring card** — and if a customer's CSF-FUNT is fitted with an accessory bench, that bench is
not covered by this table at all.

## It carries the Internal Tower row but not the Add on Track row

The nine CSD machines print **both** extra rows. This machine prints only the Internal Tower
cleaning row; its *Lubricate* group has the single guide-rod line and stops there. See
`spirit-strength-maintenance-schedule-with-internal-tower-and-add-on-track`.

## Two other things this book alone does

- **It has no SAFEGUARDS page**, so it is the one CS machine of the thirty-six that does not print
  *"Cables and belts pose an extreme liability if used when frayed"* — see
  `spirit-strength-maintenance-replace-a-frayed-cable-at-first-sign-of-wear`, which names the other
  thirty-five.
- **Its weekly Belt / Cables inspection is still there**, so the machine is inside
  `spirit-strength-maintenance-cables-inspected-weekly-and-before-every-use` even though the
  replacement rule is not printed in its book.
