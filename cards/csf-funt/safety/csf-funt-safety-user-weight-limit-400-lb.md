**400 lb / 180 kg** — the highest user weight limit of any Spirit strength machine, 40 lb above the
CSS and CSD stations and 50 lb above the CSI i-Strength machines.

| Where | Printed as |
|---|---|
| Safety instructions, item 20 | `Max User Weight Limit: 400lb/180kg.` |
| Serial number decal | `MAX USER WEIGHT: 180KG / 400LB` |
| Specification table | `Max User Weight   400lb / 180kg` |

All three agree, which makes the CSF-FUNT unusual in this range: 180 kg is 397 lb, so the pair is
consistent to within three pounds and there is no decal-versus-manual conflict to resolve.

**The CSF-FUNT prints no separate load or stack limit**, and it is also the only one of the
thirty-six CSS, CSD, CSF and CSI manuals with **no SAFEGUARDS page** — its contents run from Safety
Guidelines on printed page 8 straight to Parts of Your Unit on page 10. So the second statement of
the weight limit that the other machines carry on that page does not exist here, and neither do the
inspection and operating-warning rules. Answer those from the facility precautions page instead.

The word *safeguards* does appear in the CSF-FUNT PDF, but only inside a layer of the file that is
not printed on any page.
