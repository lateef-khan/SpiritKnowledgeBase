**This routine has no "Factory settings" prompt and no Enter key: units are toggled with STOP, and
every value is confirmed with START.** The XT275 in the same dealer manual confirms with ENTER and
adds a grade return step (`xt275-2007-console-calibration-wheel-2-30-with-grade-return`); the
XT375, XT475 and XT675 open a "FACTORY SETTING" menu instead
(`spirit-xt-2007-console-calibration-factory-setting-wheel-2-810-or-3-060`).

1. **Remove the tether cord.**
2. **Press and hold the START and FAST buttons. Replace the tether cord while holding the buttons.**
   The display goes into test mode and **"SET" blinks in the middle of the screen**.
3. Use the **STOP** button to change from **Km (metric) to M (English)** in the Speed window.
4. The **wheel size** is displayed in the Speed window. Use FAST or SLOW to change it. **It should be
   set to 2.50.** Press START.
5. The **minimum speed** is displayed in the Speed window. Use FAST or SLOW to change it. **It should
   be set to 0.5.** Press START.
6. The **maximum speed** is displayed in the Speed window. Use FAST or SLOW to change it. **It should
   be set to 10.0.** The **maximum elevation** is displayed in the Incline window. Use UP or DOWN to
   change it. **It should be set to 15.**
7. **Press START.** The unit auto-calibrates the speed and then the incline. **Do not stand on the
   belt during calibration.** The unit resets when the calibration completes.

The manual's troubleshooting guide sends you here first for an "LS" error and for an incline that does
not work. It prints no adjustable range for any value and no separate speed-sensor step; speed sensor
adjustment is its Procedure 3.
