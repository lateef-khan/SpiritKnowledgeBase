Hardware: **#65** 3/8" x 2-1/4" Hex Head Bolt (4 pcs), **#77** 3/8" x 19 x 1.5T Flat Washer (6 pcs), **#84** 3/8" x 25 x 2T Flat Washer (4 pcs), **#136** M5 x 15mm Phillips Head Screw (4 pcs), **#176** 3/8" x 3/4" Hex Head Bolt (6 pcs).

1. Install the Rear Stabilizer (7) onto the Main Frame (1) with four Hex Head Bolts (65) and four Flat Washers (84), using the **12/14mm Wrench (112)**.
2. Install the **Seat Back Cover (128)** onto the Seat Back Bracket (5) with four Phillips Head Screws (136), using the Phillips Head Screw Driver (114).
3. Install the Seat Back Bracket (5) onto the Seat Carriage (4) with six Hex Head Bolts (**176**) and six Flat Washers (77), using the **12/14mm Wrench (112)**.

**This is the one LCR printing of this step with no item-number conflict.** The 2011 manual calls the Phillips screws #99 in its checklist and the six bolts (167) in the instruction; the 2016, 2019 and 2023 manuals all print (167) in the instruction against #176 in the checklist. Only the 2013 instruction says 176, matching its own checklist.

Part 128 is called the **Seat Back Cover** here; the LCR 2016 manual calls the same part the **Seat Carriage Cover**.
