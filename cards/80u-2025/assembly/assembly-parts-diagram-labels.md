Sixteen letters on a line drawing headed PARTS OF YOUR UPRIGHT BIKE:

| Letter | Part |
|---|---|
| A | 10" touch panel console |
| B | Vertical viewing angle adjustment |
| C | Console articulating arm horizontal adjustment |
| D | Ergonomic handlebar |
| E | Manual mechanical brake lever |
| F | Fore / aft seat adjustment |
| G | Seat height adjustment |
| H | Moving wheels |
| I | Adjustable Crank arm (optional) |
| J | Pedal straps |
| K | Leveling glides |
| L | Assisted grab bar |
| M | USB Type B Port; for Stress Testing & Data Transfer |
| N | UART Port; for Stress Testing |
| O | Power ON/OFF |
| P | Power socket |

**The longest key on any Spirit bike diagram**, and the only upright one to label two data ports, the power switch and socket, the moving wheels and the levelling glides. The 8.5R recumbent's key runs to U across two pages and adds the arm support, seat belt, seat carriage stops, wheelchair anchor and bottle holder. The optional adjustable crank arm (I) is drawn; the service manual's component drawing numbers twenty-two covers and parts of the same machine, differently.
