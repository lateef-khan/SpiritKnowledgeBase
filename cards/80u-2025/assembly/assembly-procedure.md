**Every step names its tools by item number, and the pedal step prints a torque.** Item numbers in parentheses are assembly-drawing numbers; each step's hardware table is on the hardware card.

## Step one - console mast, bottom covers, rear stabilizer

1. Attach the **console mast** onto the main frame with two bolts (145), split washers (146) and flat washers (124) **on each side (right, left and inner side)**; the bolts go **from the top to the bottom**, using the **6 mm Allen wrench (164)**.
2. Install two bolts (147), split washers (123) and flat washers (167) onto the console mast on the inner front side; the bolts go **horizontal**, using the **8 mm Allen wrench (165)**.
3. Install the **front and back bottom cover (61 and 62)** with two screws (140) onto the console mast, using the **Phillips screwdriver (159)**.
4. Install the **rear stabilizer (4)** onto the main frame with the two bolts (148) and split washers (149), using the **19 mm wrench (162)**.

## Step two - pedals and seat

1. There is an "L" stamped into the end of the threaded post of the left pedal and an "R" in the right.
2. Install the **left (12-L) and right (12-R) pedals** onto the crank arms using the **open wrench (161)**.
3. The left pedal has a reverse thread and will be screwed into the crank in the opposite rotation from normal threads.
4. Make sure to tighten the pedals as much as you possibly can. **Recommended force: 300 in-lb (34 Nm).**
5. Install the **seat** onto the seat post with the bolt (139), which goes through the **pin kit (11)**, and tighten it firmly using the **L Allen wrench (163)**.

*Note: it may be necessary to re-tighten the pedals if you feel a thumping during pedaling; a thumping or clicking is usually caused by the pedals not being tight enough.*

## Step three - handlebars and top covers

1. Attach the **left handlebar (3-1)** onto the console mast (2) with 4 bolts (151) and split washers (152), using the **5 mm L Allen wrench (160)**.
2. Do the same with the **right handlebar (3-2)** onto the console mast.
3. Install the **front and back top cover (59 and 60)** with 2 screws (140) onto the console mast, using the Phillips screwdriver (159).

## Step four - console on the articulating arm, bottle holder

1. Plug all the connectors (72, 74 and 89) from the top of the **console articulating arm** to the console back.
2. Install the **console (70)** on the console articulating arm (53) and attach the **leather cover (168)** on it with 2 bolts (153) to the top right and top left, using the Phillips screwdriver (159). Next, attach 2 bolts (153) at the bottom right and bottom left - **the leather cover should not be in between**.
3. Attach the **yellow cover (52)** and the leather cover (168) to the console articulating arm (53) with 2 screws (141), using the Phillips screwdriver (159).
4. Install the **drink bottle holder clamp (240)** with 2 bolts (153) to the console mast, and then the **drink bottle holder (241)** with 2 bolts (153) to the clamp.

**The seat bolt is printed as M3 x 10 mm** in step two's table - a 3 mm bolt for the seat, as printed. The 8.5R recumbent builds in seven steps on a different frame and shares only the console-and-leather-cover step and the pedal torque with this book. Plugging in, levelling and the seat adjustments are the setting-up page's cards.
