Hardware, each step: **#57 M8 x 50 carriage bolt (2), #58 8 x 16 x 1.5t flat washer (2), #59 M8 cap nut (2)**.

1. Install the front stabilizer tube (No. 11) onto the main frame and secure using 2 carriage bolts (No. 57), 2 flat washers (No. 58) and 2 cap nuts (No. 59).
2. Install the rear stabilizer tube (No. 12) onto the main frame and secure using 2 carriage bolts (No. 57), 2 flat washers (No. 58) and 2 cap nuts (No. 59).

The book does not say which tube carries transport wheels and has no moving paragraph; its levelling instruction ("adjust the 5 levelers") is in step 11.
