From the start interface you may:

- press **Start** for **Quick Start** - "press the +/- keys to adjust resistance (range
  1-24)";
- press **Mode** for the **target mode** (set time, distance, calories);
- press **Program** for the eight programs;
- press **Set** for the settings (buzzer, metric/imperial, brightness, sleep time).

**Target mode**: "some function values need to be preset (the function values will vary
depending on the selected sport mode). The preset function values are TIME, DISTANCE and
CALORIES. Note: Some programs do not allow adjustment of preset function values." Select the
icon, set the value with +/-, press START. When the target is reached the metrics for the
completed workout (time, distance, calories, average speed, average resistance, average
heart rate) are displayed.

| Function | Value | Default | Step | Description |
|---|---|---|---|---|
| Time | (5:00 - 99:00 to count down) | 00:00 | +/- 1:00 | At 0:00 time accumulates; set to 5:00-99:00 it counts down to 0 and the exercise ends |
| Distance | (0.5 - 99.00 to count down) | 0.00 | +/- 0.50 | At 0.00 distance accumulates; set to 0.5-99.00 it counts down to 0, prompts, then counts up |
| Calories | 0 - 9990 | 0.0 | +/- 10 | At 0 calories add up; set to 10-9990 they count down to 0, then count up |
| Watt | 0 - 850 | - | - | Power output from the current resistance and RPM |
| Pulse | 40 - 220 | 90 | +/- 1 | From the hand pulse grips or a connected Bluetooth heart monitor |

The table prints no setting range for Time or Distance in the Value column; the ranges above
come from its description column.

**Program mode**: press PROGRAM, touch the program, set the workout time with +/-, press
Start to set and Start again to begin. The eight programs are on their own card.

**No heart rate program and no user program.** The console interface pages, the button list
and the program pages name none, "heart rate" appears only for the pulse display and the
Bluetooth chest-strap pairing page, and no page in the book was found imaged rather than
set (the OCR supplements on p. 15, 16, 18, 19 and 23 are the interface screenshots).
