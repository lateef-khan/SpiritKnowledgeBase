**Quick start.** After powering on, press **START** to begin in quick-start mode. During exercise the +/- keys adjust resistance (**range 1-24**). Every function counts from the start, except the pulse, which shows only when a heart-beat signal is detected.

**Target mode (MODE).** Preset TIME, DISTANCE or CALORIES; select the icon, set the value with +/- and press START. Some programs do not allow the preset values to be adjusted. When the preset target is reached the console shows the completed workout - time, distance, calories, average speed, average resistance and average heart rate. STOP ends any workout and opens the same data review (MOTION DATA: total time, total distance, total calories, average speed, maximum level, average pulse).

| Function | Range | Default | Step | Behaviour |
|---|---|---|---|---|
| Time | 0:00 - 99:00 | 00:00 | +/- 1:00 | 0:00 counts up; 5:00-99:00 counts down and the exercise ends at 0 |
| Distance | 0.00 - 99.99 | 0.00 | +/- 0.50 | 0:00 counts up; 0.5-99.00 counts down to 0, prompts, then counts up |
| Calories | 0 - 9990 | 0.0 | +/- 10 | 0 counts up; 10-9990 counts down to 0, then counts up |
| Watt | 0 - 850 | - | - | Power output from the current resistance and RPM |
| Pulse | 40 - 220 | 90 | +/- 1 | From the hand pulse grips or a connected Bluetooth heart monitor |

**Program mode.** PROGRAM lists the eight programs; touch one, set the time with +/-, press Start to set and Start again to begin (the programs are on the Programs cards).
