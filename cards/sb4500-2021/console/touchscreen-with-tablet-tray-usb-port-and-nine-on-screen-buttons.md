The console page labels a **Tablet Tray** above the screen, the **Touchscreen Display**, and a **USB Port** below it (the book does not say what the port charges or carries). The standby screen reads "start by pressing the screen"; the console is otherwise all on-screen buttons.

| Button | As printed |
|---|---|
| MODE | Opens the mode selection interface (targets) |
| PROGRAM | Opens the program selection interface |
| START | Starts the workout |
| PAUSE | Pauses the workout |
| STOP | Ends the workout and opens the exercise data interface |
| SET | Opens the settings |
| back arrow | Returns to the previous interface |
| - | Decreases a value; during exercise, reduces the resistance |
| + | Increases a value; during exercise, increases the resistance |

The exercise interface shows CALORIES, DISTANCE (miles), TIME, RPM and PULSE across the top, WATT and SPEED (miles/h) dials, and a LEVEL number between - and +, with PAUSE and STOP. Boot, standby and the settings menu are on [the settings card](boot-beep-standby-and-settings-for-beep-units-brightness-8-and-sleep-5-minutes.md); quick start and targets on [the quick start card](quick-start-with-resistance-1-to-24-and-target-time-distance-and-calories.md).
