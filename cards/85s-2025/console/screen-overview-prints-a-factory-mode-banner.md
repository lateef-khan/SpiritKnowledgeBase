**The page labels five things in the status bar and two buttons at the foot of the screen:**

| Call-out | What it points at |
|---|---|
| **Log Out** | Left-most icon |
| **Settings** | The gear icon |
| **Bluetooth Device** | The Bluetooth icon |
| **WiFi Connection** | The Wi-Fi icon and the clock |
| **Heart Rate Sensor Connection** | *see below* |
| **Press Timer to start the Timer program** | The **Timer** button |
| **Press Start to begin the exercise session** | The **Start** button |

**The body of the screen is a Welcome carousel** with **Age, Height (cm) and Weight (kg)** pickers -
the screenshot shows 30, 165 and 75 - under the line *"To get more accurate results, please provide
your physical data."* **Swiping from left to right shows more, then select the wanted item to
start**; the next card in the carousel is **Pattern Programs**.

**Two defects on this page, both visible only in a render.**

- **The screenshot was taken with the machine still in Factory Mode.** A grey toast sits under the
  status bar reading **`Exit the Factory Mode once the testing is over.`** with an **X** to dismiss
  it. It is a factory test banner that was never cleared before the photograph was taken, and it is
  **not** a message an owner should expect to see.
- **The Heart Rate Sensor Connection leader line lands on that toast's X button**, not on a status
  bar icon. The heart-rate icon is the **third** icon in the bar, the waveform between the gear and
  the Bluetooth symbol. **Do not tell a caller the heart rate control is where this drawing points.**

**`pdftotext` returns 46 words from this page and a 300 dpi render returns far more**, so an
extraction alone shows neither the banner nor the mislabelled leader. The printed page is the fact
here; read the render.
