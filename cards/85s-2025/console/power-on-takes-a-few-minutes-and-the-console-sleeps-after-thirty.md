**"When initially powering on the console please wait a few minutes for internal
self-test."** A slow start is normal on this machine and is not a fault. The console then goes to the
**start-up display, which is the login method page**, and you may begin once a login method has been
chosen (`85s-2025-console-login-by-qr-code-nfc-or-pin`).

**A few minutes, not a few seconds.** Every LED Spirit console runs its self-test in seconds; this
one is a touchscreen booting an operating system, and its own manual says so. **Do not treat a
minute-long blank screen on this machine as a dead console.**

**The console automatically powers down after 30 minutes of inactivity. Press any function key to
wake it up again.**

**Thirty minutes, not twenty.** The 7.0S, 7.5S and MS300 power down after **20**
(`spirit-rehab-stepper-console-power-up-and-the-twenty-minute-auto-power-down`). **Always turn off
the main power switch when the machine is not in use**, which this book says and the CS800's sleep
paragraph explicitly does not.

**There is no software version screen.** This power-on paragraph prints no version number and no
odometer reading, unlike every other Spirit console; machine information is inside the settings, not
on the boot screen.

**The book adds one line about faults:** *"If there is an issue, the console will show an error
message along with a possible solution. Follow the message to resolve the issue."* It prints no error
code list anywhere.
