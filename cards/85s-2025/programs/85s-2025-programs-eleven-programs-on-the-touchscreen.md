The Programs Setup page lists **eleven**:

- **Manual** - you control the workload; set a workout mode and time, then adjust the level
  yourself.
- **Timer** - *"a quick set-up, large font, egg timer type display for patient warm-ups."* Set a
  target exercise time and press Start; **+** and **-** adjust the session time during the workout.
- **Hill** and **Plateau** - the two **Pattern** programs. *"Pattern programs are preset exercise
  programs that have been designed for a variety of goals. The initial built in level of difficulty
  is set to a relatively easy level. You may select the level before beginning."* Setup takes a
  level of difficulty, a workload type and a workout time, and **the unit of measurement can switch
  between RPM and deg/sec.**
- **HIIT**
- **Wingate Test**
- **Facility** - build and save a custom program under a facility name.
- **Heart Rate Target**
- **Calories Target**
- **METs Target**
- **Steps Target**

**A Care Plan section sits beside them on the home page** - *"Personalized programs created by your
therapist."*

**"When a program is selected you have the option of modifying the settings. If you want to begin
without entering new settings, just press the start key."** Skipping data entry uses the data from
the **set up menu**.

**This is not the 8.5S-Fit's program list.** That machine drops Manual and Facility, adds Custom and
Steps under different names, and there is no Timer-plus-Manual pair - see
`85s-fit-2026-programs-ten-programs-on-the-touchscreen`. It is not the dot matrix rehabilitation
stepper's list either: those machines have Cardio, Interval, Symmetry, two User keys and an HR key
and no Wingate test - see
`spirit-rehab-stepper-programs-ten-program-keys-including-an-hr-key-no-manual-describes`.

**Measured, not assumed:** compared as 8-word phrase shingles over the program pages, the 8.5S and
the 8.5S-Fit share only **12.5%**, and the 8.5S and the 7.5S only **13.0%**. These three books
describe three different program sets.
