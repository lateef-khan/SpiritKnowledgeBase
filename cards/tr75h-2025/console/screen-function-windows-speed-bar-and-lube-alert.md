**Windows** (read from the render of the screen-function page, which is printed as a picture):

| Window | Range or meaning |
|---|---|
| INCLINE / LEVEL | Running mode 0-15, hiking mode 15-40 |
| DISTANCE | 00.0-99.9 km (mile), looping display |
| PROGRAM | 0 for quick start or target mode; 1-12 preset running, 1-5 preset hiking; H1-H3 for heart-rate control; U1-U2 for user mode |
| TRAINING LEVEL | Three levels, shown L1-L3, looping |
| CALORIES | 000.0-999.9 kcal, looping |
| PULSE | 40-200; shows "0" when no heart rate is detected |
| SPEED | Running 0.8-12 kph (0.5-7.5 mile); hiking 0.8-6 kph (0.5-3.7 mile) |

**Speed bar.** The bar under the top windows is marked WARM UP, WALKING, JOGGING and RUNNING: warm up 0.5-1.9, walking 1.9-3.7, jogging 3.7-6.2, running 6.2-7.5 (the book writes "miles"; they are mph). With no movement only the white outline shows.

**LUBE alert.** When total usage reaches **112 miles** the word "LUBE" appears on the LCD after powering on. Pressing any key removes it temporarily, but it returns the next time the system is turned on. To reset the 112-mile reminder and clear the message, press **STOP + SPEED (−)** at the same time. The reset only works after the 112-mile threshold has been reached. The deck lubrication itself belongs to the Maintenance section.
