**Getting started.** Switch on the power; with the safety key inserted the console shows Standby Mode. (Without the key only the border lines show, the numbers read "--" and the dot matrix scrolls "INSERT SAFETY KEY".) The incline automatically returns to 0 if it is not already there. Press **RUN / HIKE** to choose RUNNING or HIKING mode, then **START/STOP** for Quick Start.

**Quick start mode (program code 0).**

1. Press RUN / HIKE to choose RUNNING or HIKING mode.
2. Press START/STOP. A countdown "5, 4, 3, 2, 1" with beeps plays, then the motor starts.
3. The belt starts at **0.5 mph**, at **incline level 0 for running** and **level 15 for hiking**.
4. The dot matrix shows a track animation, and TIME, DISTANCE and CALORIES count up.
5. Use **+ / −** to adjust speed and **▲ / ▼** to adjust incline.
6. Press RUN/HIKE to switch between RUNNING and HIKING mode while running.

In Running mode the dot matrix shows only the speed profile; in Hiking mode only the incline profile. The book's default settings are age 30, time 32 min, distance 1.0 km (mile) and calories 10 kcal. Speed and incline ranges per mode are on [the console features card](features-speed-and-incline-ranges-per-mode.md).
