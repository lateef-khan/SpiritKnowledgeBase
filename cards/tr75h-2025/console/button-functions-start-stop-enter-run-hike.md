| Button | What it does |
|---|---|
| **STOP/START** | Press to start the treadmill from standby mode. Press to pause while running. **Press and hold to return to standby mode and reset all data.** |
| **ENTER** | Confirms program settings and workout "tensions" (the book's word for levels). |
| **RUN/HIKE** | In standby, selects Running or Hiking mode; while running, switches between them. |
| **INCLINE +/−** | Raises or lowers the incline by 1 level while running. Before starting, selects the PROGRAM; in setting mode, selects the LEVEL; in data-setting mode, adjusts values. |
| **SPEED +/−** | Raises or lowers the speed by 0.1 mph while running. Before starting, selects the PROGRAM; in setting mode, selects the LEVEL; in data-setting mode, adjusts values. |

The console overview drawing shows, under the LCD, Incline ▲/▼, ENTER, START/STOP, RUN/HIKE and Speed −/+, with the program, quick-start and target-mode instructions printed on the console face itself. Neither book prints a USB port for this machine; the service manual's display-board socket list has a USB socket (4 pin) and a Bluetooth socket (4 pin), which the Specs section holds.
