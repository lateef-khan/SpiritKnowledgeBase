| Status | What the screen shows |
|---|---|
| **Power on** | All function and numeric icons light up (full display), then the console automatically enters Standby Mode. |
| **Safety key not inserted** | Only the border lines are displayed and all digits show "**--**". The buttons do not function in this mode. The quick-start page adds that the dot matrix scrolls "**INSERT SAFETY KEY**". |
| **Standby** (key inserted) | All icons show, numbers display "0", and the dot matrix shows a running track. The track animation moves counterclockwise; only the first section shows after the first lap. |
| **Mode** | The default mode is running. Press RUN/HIKE to switch; the display shows "RUN" or "HIKE". |

The status table itself is printed as a picture; this text is read from a 300 dpi render of the page, and the native text layer holds only the power-on sentence.
