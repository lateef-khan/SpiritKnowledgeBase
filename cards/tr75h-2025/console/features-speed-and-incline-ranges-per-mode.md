**Speed / incline range**

| Mode | Speed | Incline level |
|---|---|---|
| Running | 0.5 – 7.5 mph | 0 – 15 |
| Climbing (Hiking) | 0.5 – 3.7 mph | 15 – 40 |

**Programs**, as the page lists them: running mode has 12 presets with difficulty levels 1-3, 3 targets (time, distance, calories), HRR programs and a Fat program; climbing mode has 5 presets, 3 targets, HRR and Fat. The Programs section holds how they are run.

**Defaulted data:** gender male, age 30, height 5'7", weight 150 lb, time 30 minutes, resting heart rate 72 bpm, target distance 0.6 mile, target calories 10 kcal, target time 30 minutes.

**Function display**, as printed: PULSE window (heartbeat 0-200 bpm, body type 1-5, resting heart rate); CALORIES window (10-999 kcal, height 1'8"-8'2"); STEP window (step count, BMR); DISTANCE window (0-99.9 mile, FAT%); PROGRAM window (running mode 1-12, climbing mode 1-5, BMI, U0-U3); GENDER window (male/female).

**Contradictions inside this book.** This page is a near copy of the TR95H's, and it disagrees with the rest of the TR75H book: the console overview and the screen-function pages show PROGRAM, LEVEL, DIST., PULSE, CALORIE, INCLINE, TIME and SPEED windows and no STEP or GENDER window; the screen-function page says the PROGRAM window shows H1-H3 for heart-rate control and U1-U2 for user mode, not U0-U3; the pulse display range there is 40-200, not 0-200; the quick-start page's defaults are time 32 min, distance 1.0 and calories 10; and the HRR line gives climbing mode "0.5~6.2 mph" against the 3.7 mph maximum above it. The screen-function page and the button page describe the console the overview drawing shows ([screen function card](screen-function-windows-speed-bar-and-lube-alert.md)).
