1. In standby, press **RUN/HIKE** to choose running or hiking mode.
2. Press **+ / -** to select a preset program. The PROGRAM window shows **01 to 12** for
   Running mode and **01 to 05** for Hiking mode.
3. Press **ENTER** to confirm the selected program.

**Running mode**

4. The dot matrix scrolls "SELECT LEVEL".
5. Press + / - to choose the level (**L1 to L3**), then press ENTER.
6. The dot matrix scrolls "SELECT TIME".
7. Press + / - to set the time, then press ENTER.
8. Press **START/STOP** to begin.

**Hiking mode**

4. The dot matrix scrolls "SELECT TIME".
5. Press + / - to set the time, then press ENTER.
6. Press START/STOP to begin.

Levels 2 and 3 add **1.0 mph** per level to a Running program's speeds with no change to the
incline. The text layer of these pages also carries "0.6 miles per segment" lines that are
**not printed**; they are ghost text (1.0 km is 0.6 miles) and the printed 1.0 mph is carded.
