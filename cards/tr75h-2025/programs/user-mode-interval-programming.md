**To run a User program**

1. In standby, press **RUN/HIKE** to choose Running or Hiking mode.
2. Press **+ / -** to select USER mode; the selected **U1 or U2** flashes in the PROGRAM window.
3. Press **ENTER**; the dot matrix scrolls "SET TIME OR START".
4. Press + / - to adjust the time (default 32:00, range 10:00 to 99:00).
5. Press ENTER; the dot matrix scrolls "PRESS START".
6. Press **START** to begin with the selected USER data and time.

**To program the intervals** (USER INTERVAL Program Setting) - repeat steps 1 and 2, then:

3. **Press and hold ENTER for 3 seconds** to enter INTERVAL setting; the SPEED and INCLINE
   windows flash.
4. Press + / - to set the speed for the first interval (SPEED window); the dot matrix shows the
   speed profile.
5. Press the incline arrows to set the incline for the first interval (INCLINE window); the dot
   matrix does not show the speed profile while doing so.
6. Press ENTER to move to the next interval and repeat steps 4 and 5.
7. After the last interval, press ENTER; **a long beep confirms the data is saved**. Then
   proceed to the time setting.
8. "SET TIME OR START" - set the time with + / -.
9. Press ENTER; "PRESS START".
10. Press START/STOP to begin using the saved USER data and time.

The book does not print the number of intervals in a User program; the preset tables use 16.
