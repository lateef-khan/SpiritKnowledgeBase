The console has **Running** and **Hiking** modes, chosen with the **RUN/HIKE** button in
standby (and switchable while running). The Program window shows a **program code**:

| Code | Program |
|---|---|
| 0 | Quick Start, or Target mode (time, distance or calories) |
| 01 to 12 | Preset Running programs (12), each with training level **L1 to L3** |
| 01 to 05 | Preset Hiking programs (5), no level |
| H1 to H3 | Heart Rate Control |
| U1, U2 | User programs |

**Quick Start (code 0):** press RUN/HIKE, then START/STOP; a "5, 4, 3, 2, 1" countdown with
beeps plays, then the motor starts at **0.5 mph**, at **incline level 0 for running and 15
for hiking**. In Running mode the dot matrix shows only the speed profile; in Hiking mode only
the incline profile.

**Default setting, as printed on the Quick Start page:** Age 30, **Time 32 min**, Distance
1.0 km (Mile), Calories 10 kCal.

**A contradiction in the book.** The Console Features page (PDF p. 22) is a copy of the TR95H
page: it lists "HRR (E, M, T, A, I)", a "Fat" program, users U0 to U3, a 30-minute default
time and a 0.6-mile target distance. **None of those appear in this book's own program
pages**, which document the set above with a 32-minute default and a 1.0-mile target. The
program pages are treated as the authority for this console.

The presets are printed as numeric tables (four cards); Target mode, HRC, User mode and the
selection steps have their own cards.
