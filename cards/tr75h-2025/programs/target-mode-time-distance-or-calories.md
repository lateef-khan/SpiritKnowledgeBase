Target mode shares **program code 0** with Quick Start. In standby, press **+ / -** to select
the target; the dot matrix scrolls "TARGET TIME", "TARGET DISTANCE" or "TARGET CALORIES".

| Target | Default | Range |
|---|---|---|
| TIME | 32:00 | 10:00 to 99:00 |
| DISTANCE | 1 mile | 1.0 to 20.0 mile |
| CALORIES | 10.0 | 10.0 to 990.0 |

1. Press **ENTER**; the dot matrix scrolls "SET TIME OR START" (or "SET DISTANCE OR START",
   "SET CALORIES OR START").
2. Use + / - to adjust the value.
3. Press ENTER to confirm; the dot matrix shows "PRESS START". Press **START/STOP** to begin.
4. Press **RUN/HIKE** to switch between Running and Hiking mode.
5. The dot matrix shows the track animation and the target **counts down**; the other two
   quantities count up in their own windows.

The Console Features page of the same book lists a 30-minute time and 0.6-mile distance
default; those figures are copied from the TR95H book and this page's 32:00 and 1 mile are
taken as the console's own.
