**This is E5, not E6 (controller component fault) and not E0.**

**Definition**: poor communication between the console and the lower controller. Almost always the main control wire is bad, but the console board or the lower controller can also be at fault.

| Part | Troubleshooting |
|---|---|
| Lower controller board | Replace the main control wire. |
| Main control wires | Reinsert the main control wire. Replace the main control wire. |
| Display board | Replace the upper control board. |
