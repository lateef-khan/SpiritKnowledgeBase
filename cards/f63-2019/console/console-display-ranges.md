| Readout | Display range | Working range |
|---|---|---|
| SPEED | 0.0 to 99.9 | 1.0~20.0KM or 0.5~12Mile. Each press of FAST or SLOW changes it by 0.1 km/h (mph) |
| INCLINE | 0 to 99 | 0 to 15. Preset value 0 to 15. Each press of UP or DOWN changes it by 1 |
| TIME | 0:00 to 99:99 | 0:00 to 99:59. Count down setup range 10:00 to 99:00 |
| LAPS | 0 to 99 | 0 to 99 |
| DISTANCE | 0.00 to 99.9 | 0.00 to 99.9 |
| CALORIES | 0.0 to 999 | 0.0 to 999 |
| PULSE | 0 to 999 | 40 to 220 BPM |

Time counts up by default; if the user sets a time it counts down. When a time is set the count runs to zero. Pressing STOP in RUN Mode saves the time value, and re-entering RUN Mode continues counting from it.

Pulse comes from the hand grips or from a receiver, and the receiver needs a chest belt. **If the treadmill has no pulse signal for 8 seconds the displayed value becomes 0.**
