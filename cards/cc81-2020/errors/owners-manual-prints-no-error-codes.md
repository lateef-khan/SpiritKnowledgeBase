**The 2019 owner's book for this machine prints no numbered error code and no troubleshooting table.** Its contents run from operation through the Maintenance Menu in Console Software to the warranty. The "maintenance/diagnostic software" hits are the console menu (a console-section topic), not fault remedies.

E1 (EEPROM failure) and E2 (tension motor failure) exist for this machine, but only in the *service* manual — carded separately and linked here so a code quote lands on the right book.
