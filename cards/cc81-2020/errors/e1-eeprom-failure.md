**This is the climber E1, not the climber E2 (tension motor), and not the treadmill E1 or the bike E1.**

| Field | Value |
|---|---|
| Code | E1 |
| Cause, as printed | EEPROM failure |
| Definition | The memory IC of EEPROM is defective. |

**Fix:** the **display board requires replacement**. The manual gives no test and no other repair for this code.

The climber manual lists only two error codes, E1 and E2.
