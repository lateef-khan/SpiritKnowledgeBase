1. Pedal the machine.
2. Press and hold the **Start, Stop and Enter** keys together.
3. Keep holding for about **5 seconds**. The Message Center shows **Maintenance Mode**.
4. Press **Enter** to open the menu.

**The menu**

1. **Key Test** — tests every key.
2. **Display Test** — tests every display function.
3. **Function**
   - Units — English or Metric readout
   - Pause mode (have five minutes)
   - Odometer Reset — resets the odometer
   - Sleep mode
   - Beep sound — controls the beep
   - CAB Protocol or CSAFE Protocol
4. **Service**
   - Motor test
   - Csafe test
   - Sensor test — tests the speed sensor
5. **Exit**

**Note on the source.** The manual writes "pedal the elliptical" in this step. This is the climber service manual, so it means pedal this machine. The rest of the section is written for this console.
