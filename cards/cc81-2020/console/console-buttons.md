The console has six program buttons (**Manual, Hill, Fat Burn, Cardio, Strength, HIIT**) and a set of control keys.

**In idle**

| Key | What it does |
|---|---|
| STOP | Press and hold for more than 3 seconds to reset the console. |
| START | Starts a workout in MANUAL mode. |
| LEVEL +/- knob | **No function.** |
| ENTER | Enters the setting, and confirms the setting. |

**In a workout**

| Key | What it does |
|---|---|
| STOP | Once goes to pause. Twice ends the workout. Three times returns to idle. |
| START | Within 5 minutes of pausing, returns to the workout. |
| LEVEL +/- knob | Turn it to change the resistance level. |
| ENTER | **No function.** |

A knob that does nothing in idle is normal. It only works once a workout is running.
