**IDLE.** The main window shows the name of each program one after another, and the dot window shows that program's profile at the same time.

**QUICK START.** Press **START** in idle to go straight into MANUAL mode. Time counts up from 00:00, every other value counts from 0, and resistance starts at level 1. To pick a program instead, press one of the quick select keys (**MANUAL, HILL, FATBURN, CARDIO, STRENGTH, HIIT**) and then press START. The program runs on its default values.

**PAUSE.** Press **STOP** during a workout. Every window keeps its value and resistance drops to level 1. Press **START** to carry on, and resistance goes back to the level set before the pause.

**SLEEP.** After **30 minutes with no RPM and no pulse** the console sleeps. The LCD stops showing and the backlight goes off, resistance is set to level 1, and the fan is switched off. Press any key to wake it into idle.

**END.** The console beeps three times when the workout finishes. The main window shows **"WORKOUT SUMMARY"** and the workout values. Press START to run the same workout again. Press STOP to go back to idle.

**RESET.** In idle, press and hold **STOP for more than 3 seconds**. The console resets the system.

**One naming fault in the source.** The manual heads this section "4-2-4 DISPLAY MODE", but every line under it describes sleep mode. There is no separate display mode.
