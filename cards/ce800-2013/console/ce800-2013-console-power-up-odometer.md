**There is no mains cord.** The manual states these commercial elliptical trainers have a
**built-in generator** and do not need to be plugged into an AC outlet; start to pedal and the
console turns on automatically.

The self-test then runs in this order:

1. **All the lights turn on for a short time.**
2. When the lights go off, the dot matrix shows a **software version (i.e. VER 1.0)** and the
   Message Window shows an **odometer reading**.
3. The odometer reads **how many hours** the machine has been used and **how many virtual miles**
   it has gone. The manual prints the display as `ODO 123 MI 123 HRS`.
4. The odometer stays up for **only a few seconds**.
5. The console then goes to the start-up display: the dot matrix scrolls the program profiles and
   the Message Window scrolls the start-up message.

**`ODO 123 MI 123 HRS` is the manual's own example, not your machine's total.** Both 123s are
placeholders.

legible; nothing else on the page is.
