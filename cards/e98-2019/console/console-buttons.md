The program buttons are Manual, Hill, Fat Burn, Strength, Interval, 2 User and 2HR. There is a separate Fan key for the cooling fan.

**READY MODE**
- STOP: non-function.
- START: starts the elliptical after a 3 second countdown on the window display. In MANUAL the elliptical starts at MIN LEVEL.
- LEVEL UP / LEVEL DOWN / INCLINE UP / INCLINE DOWN / DISPLAY: non-functional if the user has not entered a setting.
- FAN: controls fan ON/OFF.
- ENTER: enters parameter setting. In workout mode ENTER changes the dot matrix display: LEVEL PROFILE -> INCLINE PROFILE -> SCAN (SCAN changes every 3 seconds).

**RUN MODE**
- STOP: stops the elliptical.
- START: non-functional.
- ENTER: switches between the LEVEL and INCLINE profile. **The source prints this line in untranslated Chinese ("切換 LEVEL 和 INCLINE PROFILE"); the meaning given here is the literal translation of that line and nothing more.**
- LEVEL UP / LEVEL DOWN: each press changes level by 1.
- INCLINE UP / INCLINE DOWN: each press changes position by 1; maximum incline position 20, minimum 1.
- FAN: controls fan ON/OFF.
- DISPLAY: press to display the exercise data for 5 seconds during a workout.
