Five tools are supplied:

| Item | Tool |
| --- | --- |
| #169 | 13/14mm Wrench (160mm) |
| #172 | 12/14mm Wrench (160mm) |
| #170 | Short Phillips Head Screwdriver |
| #171 | Phillips Head Screwdriver |
| #213 | L Allen Wrench |

The L Allen wrench is new against the 2011-2015 set; it fits the socket cap mast bolts of step 1.
