1. Use a Phillips head screwdriver to remove **swing arm joint cover B (left and right)**.
2. Use **12 and #13 open end wrenches** to release the **hex head bolt 5/16" x 1-1/4"**, **flat washer 5/16" x 20 x 1.5T** and **nut 5/16" x 9T** that secure the rod end bearing.
3. Use a **12mm open end wrench** to remove the **hex socket screw 5/16" x 15mm** and **flat washer 5/16" x 20**. Pull out the pedal carriage bolts to remove the pedal bar assembly.
4. Use a Phillips screwdriver to remove the **Phillips head screw M5x10mm** securing the pedal, and remove the pedal.

Note the nut size. This manual calls it a **5/16" x 9T** nut. The E25 manual of the same year prints **5/16" x 7T** for the same fastener in the same step, and the E35 and E98 manuals print 5/16" x 7T for the swing arm nut. Check the nut on the machine before ordering.
