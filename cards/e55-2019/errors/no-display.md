1. If there is no display, follow these steps for diagnosis.
2. Make sure power is plugged in properly and the **AC breaker is not activated**.
3. Make sure all connectors, including the cables for the console and AC power, are connected properly. Disassemble the console to check the cables inside it if necessary.
4. If all connections are fine, then check to determine if a cable is broken or the console or lower controller has failed.

If the machine still has no power, check the 5A fuse on the motor controller.
