1. Press and hold the **Start, Stop and Enter** keys at the same time until the display shows
   **"ENGINEERING MODE MENU PRESS ENTER"**. Some versions say maintenance menu. Press **Enter**.
2. Scroll with the **Speed up / down** keys. **Stop** returns to the previous menu selection.

| Menu | What it does |
|---|---|
| A. Key Test | Tests every key so you can confirm they work. |
| B. Display Test | Tests all the display functions. |
| C. Functions | Press Enter to reach the settings, scroll with Speed up / down. |
| C-I. Display Mode | **Turn it off** to have the console power down automatically after **30 minutes** of inactivity. |
| C-II. Pause Mode | **On** allows 5 minutes of pause. **Off** makes the console pause indefinitely. |
| C-III. Maintenance | Resets the lube message and the odometer readings. |
| C-IV. Units | English or Metric display readings. |
| C-V. Key Tone | Turns the key press beep on or off. |
| D. Security | Locks the keypad against unauthorised use. With the child lock enabled the keypad does nothing until you **press and hold Start and Enter for 3 seconds** to unlock the console. |
| E. Exit | Leaves the menu. |

**The manual gives two ways in.** Section 8.11 says to hold Start, Stop and Enter with the machine already on.
The E0 note in section 8.1 says to remove the safety key, press STOP, START and ENTER, and insert the safety key
at the same time. Both are printed in the same manual.

**Sleep timing.** The 30 minutes here is the manual's figure. The 2023 touchscreen manuals give 15 minutes for
their own Sleep Mode, and the company-wide sleep mode cards say 15 to 30 minutes.
