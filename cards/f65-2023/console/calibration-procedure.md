1. Remove the **Safety Key**.
2. Press and hold down the **Start** and **Speed up** buttons and at the same time replace the Safety Key.
   Keep holding Start and Speed up until the window displays **"Factory settings"**, then press **Enter**.
3. Set the display to **Metric or English** (Miles or Kilometers) with the incline up / down key, then press
   Enter. The maximum speed value shows in the speed window and the maximum elevation value shows in the incline
   window.
4. **Grade return - On.** This lets the incline return to zero when the Stop button is pressed. **For sale in
   Europe, EU standards require this to be off.**
5. Press the **Start** button to begin calibration. The process is automatic. **The speed starts up without
   warning, so do not stand on the belt.**
