| Button | Run Mode |
|---|---|
| Safety Key | Pulling it away shuts the computer down automatically. |
| Stop Key | Press STOP to stop the treadmill. |
| Start Key | Non-functional. |
| Enter Key | Non-functional. |
| Speed Fast Key | Each press adds 0.1 KPH (0.1 mph). Held down, the speed climbs quickly to MAX SPEED. |
| Speed Slow Key | Each press removes 0.1 KPH (0.1 mph). Held down, the speed falls quickly to MIN SPEED. |
| Incline Up Key | Each press raises the position by 1. Maximum incline position is 15. |
| Incline Down Key | Each press lowers the position by 1. Minimum incline position is 0. |
| Speed quick keys | Sets speed to 2, 3, 4, 5, 7, 9, 12 |
| Incline quick keys | Sets incline to 1, 3, 5, 7, 9, 12, 15 |
| Fan key | Turns the fan ON and OFF. |
| Display key | Selects the SPEED or INCLINE profile while choosing a program, and switches the exercise data on the message window during a workout. After the switch the system scans and displays automatically every four seconds: PROGRAM NAME LAPS XX, VERT XXX FT (M in metric), SEG TIME XX:XX (not shown in HRC mode) and MAX SPEED XX:XX (not shown in HRC or MANUAL mode). |
