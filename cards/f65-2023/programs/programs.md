Press the **PROGRAM keys (up / down arrows)** to choose one, confirm every setting with **ENTER**,
then press **START** to exercise.

The program function has **6 programs**: Manual, Hill, Fat Burn, Cardio, Strength and Interval.

It also has **USER1, USER2, TH60 PCT and THR80 PCT**.

**As printed.** The manual writes the third heart rate program as "TH60 PCT" and the fourth as "THR80 PCT". The
missing R in the first one is a typographical error in the source; both are target heart rate percentage programs.

In RUN mode the PROGRAM key is non-functional.
