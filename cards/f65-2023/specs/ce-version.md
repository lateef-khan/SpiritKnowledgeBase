Besides the normal version, the **ST168** treadmill has a **CE/GS version**.

Both versions are exactly the same in functions and outlines except that the power input is 110AC for the normal version versus 230VAC for the CEGS version, and an additional
**Filter Choke circuit** is added for the CEGS version, as shown in the circuit diagram.

**Watch the voltage figures in the rest of the manual.** The safety instructions describe a 220-volt, 10-amp
outlet with a bracketed note that the 120VAC electronic power system needs 110-volt, 15-amp. The grounding
instructions call it a nominal 220-volt circuit. Those pages are written for the CEGS machine first.
