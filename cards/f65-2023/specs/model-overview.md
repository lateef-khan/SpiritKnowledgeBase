The cover reads **F65(2023)**, the factory code **ST168-YT069**, and calls the machine
a **Treadmill**.

The console is an LCD display with physical keys, a speaker, a fan, hand pulse grips and the safety key.

The machine has a console, a main controller carrying the DC power supply, the incline driver and the DC motor
driver, a DC drive motor and an AC incline motor.

**The manual never prints a six digit SKU.** It identifies the machine only by the name on the cover and the
factory code above.
