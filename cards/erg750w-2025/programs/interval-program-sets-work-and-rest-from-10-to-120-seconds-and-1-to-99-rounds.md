1. **Hold the MODE button for 3 seconds.** You hear a prompt sound and enter the INTERVAL setting.
   Set the desired interval (work) time: **10-120 seconds in 10-second increments**.
2. Press MODE to light up **REST** and set the rest time: **10-120 seconds in 10-second increments**.
3. Press MODE again to adjust the **PULSE window** to the desired number of rounds ("number of
   movements"): **1-99 times**.

In INTERVAL mode the START status shows a heartbeat symbol and the REST window displays the
remaining rounds. **The sequence starts with a rest**: REST - START (Round 1) - REST - START
(Round 2), and so on.

- When the interval exercise is finished, a prompt sound is emitted and the console returns to
  normal mode.
- Press and hold RESET to return to normal mode at any time.
- The machine returns to normal mode after waking from sleep.
- If you stop during the exercise, "resistance will be paused for 4 seconds, and SPM will go to 0"
  (as printed; the resistance on a water rower is the tank knob, so this describes the display).

The book prints no default work or rest time. The console page's MODE entry says the same thing in
one line: "Hold the MODE button for 3 seconds to enter the INTERVAL setting".

**Other Xterra consoles use other limits**: the ERG800W's custom interval runs 5 to 599 seconds, the
ERG700's ten cycles with 1-second steps - see `see_also`.
