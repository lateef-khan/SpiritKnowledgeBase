The ERG160 console is one green LCD window with a legend strip - SCAN, TIME, COUNT, DISTANCE, CALORIES, SPM - and **one key, MODE**, under the XTERRA logo. The parts list calls the console **X-3508**.

| Function | Range as printed |
|---|---|
| SCAN | Every 6 seconds |
| TIME | 0:00 ~ 99:59 |
| COUNT | 0 ~ 9999 TIMES |
| TRIP DISTANCE | 0 ~ 9999 METER |
| CALORIES | 0 ~ 9999 CAL |
| SPM | 0 ~ 999 TIMES/MIN |

**MODE:** press to select a function; **press and hold two seconds to reset all functions to zero.** SCAN shows time, stroke count, distance, calories and strokes per minute in sequence, 6 seconds each. TIME, DISTANCE and CALORIES run from exercise start to end; COUNT is the total stroke count; STROKE/MIN (SPM) is "an automatic accumulation of strokes per minute". The calorie readout is an estimate for an average user, for comparison between workouts on this unit ([calorie card](../../shared/console/xterra-treadmill-console-calorie-display-is-a-rough-guide.md)).

**There is no pulse readout, no SET key and no target setting** on this console; the ERG180's two-key console adds both ([ERG180 card](../../erg180-2023/console/mode-and-set-keys-with-scan-every-6-seconds-and-pulse-60-to-240.md)). Distance is in metres only; the book prints no units setting. The same table also prints the battery type, 2 AA or UM 3 ([battery card](../../shared/console/xterra-erg-console-two-aa-batteries-and-where-they-go.md)), and an operating temperature of 0 to +40 C (32 to 104 F) and storage of -10 to +60 C (14 to 140 F). Waking, the STOP marker and the 2-minute shut-off are on [the auto-off card](../../shared/console/xterra-erg-console-wakes-on-rowing-or-mode-shows-stop-after-4-seconds-and-shuts-off-after-2-minutes.md). The single-key bike consoles of the same family are on [the SB120 card](../../shared/console/xterra-bike-console-single-mode-key-with-pulse-40-to-240-and-a-2-second-reset.md).
