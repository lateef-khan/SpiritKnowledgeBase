In READY MODE:

- **SAFETY KEY** - fit it in the right position to power on the computer. Pull it away and the computer shuts down automatically.
- **STOP** - no function.
- **START** - starts the treadmill. There is a **3 second countdown** on the window display, then the machine starts running. In MANUAL it starts at MIN SPEED; in a PROGRAM it starts at the program preset value.
- **CLEAR/SET** - changes each function. MANUAL sets time. A pre-set PROGRAM (**P1~P24**) sets time and speed. Heart Rate sets time, age and the heart rate value.
- **PROGRAM** - selects manual, random program and user HRC program.
- **FAST**, **SLOW**, **UP**, **DOWN** - non-functional unless the user has entered a setting.
- **SPEED RAPID** - 6 preset buttons: **1 kph (1 mph), 2, 4, 6, 8 and 10**.
- **INCLINE RAPID** - 6 preset buttons: **2, 4, 6, 8, 10 and 12**.
- **FAN** - turns the fan on and off.
