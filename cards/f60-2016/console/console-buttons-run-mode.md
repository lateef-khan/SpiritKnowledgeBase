In RUN MODE:

- **SAFETY KEY** - pull it away and the computer shuts down automatically.
- **STOP** - stops the treadmill.
- **START**, **SET** and **PROGRAM** - non-functional.
- **FAST** / **SLOW** - change speed by 0.1 kph (0.1 mph) per press. Held down, the speed runs quickly to MAX or MIN SPEED.
- **UP** / **DOWN** - change the incline position by **0.5** per press. **Maximum incline position 10, minimum 0.**
- **SPEED RAPID** - sets 1, 2, 4, 6, 8 or 10 kph (mph) quickly.
- **INCLINE RAPID** - sets position 2, 4, 6, 8, 10 or 12 quickly.
- **FAN** - turns the fan on and off.

**Note on the incline numbers**: the maximum incline in RUN MODE is given as 10, but the incline rapid keys include a 12, and the calibration screen offers an incline level of 10 or 12. Check which level the machine is calibrated to.
