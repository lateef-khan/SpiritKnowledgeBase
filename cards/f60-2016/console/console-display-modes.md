| Mode | What it means |
|---|---|
| OFF Mode | The user has not inserted the safety key on the console. **All windows appear OFF.** |
| READY Mode | The treadmill is ON and the safety key is inserted. Press START to start the treadmill in Manual Mode. |
| SLEEP Mode | Pressing any button takes the treadmill back to READY Mode. |
| RUN Mode | Pressing STOP, or removing the safety key, stops the treadmill instantly and puts it in OFF Mode. |

**Before operating**: the treadmill changes speed slowly, so it takes a little time to reach the speed you set. Check that the **emergency switches on both the left and right side are turned on**, and turn the switch round to check it is off. Check the safety key is fitted properly and the clip is on your clothing. If any of these is wrong the machine will not work.
