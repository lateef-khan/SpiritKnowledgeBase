Unlike every other A1 book, the F60-2016 sets **no 60/80 or 70/90 default**: the target is keyed in directly.

1. Choose the **HRC program**, then press **CLEAR/SET**.
2. Use the **FAST/SLOW keys to set the Target Heart Rate**, then press CLEAR/SET.
3. Use the **FAST/SLOW keys to set the workout Time**, then press **START**.

The zone page alongside still computes 220-minus-age with 50%-90% zone, 60% recommended for fat and 80% for the cardiovascular system (see `f63-2026-target-heart-rate-zone`), but those percentages are not wired into this HRC setup.
