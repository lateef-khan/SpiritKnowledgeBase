The F60-2016 console is nothing like the ten-program menu consoles: it has **24 pre-set programs and no user slots**. **Fourteen of them (P1-P14) change speed only with no incline changes**; the last ten **(P15-P24) change speed and incline**. The book names none of them and prints no profile chart.

**Starting a preset.** Press the **Program key** to choose P1-P24. Press **Clear/Set** to set the workout time, then **Start**.

**Custom targets (quick start only).** In Idle mode, press **Clear/Set**; each press blinks a different target. With the **Calories** target blinking, the Speed Up/Down keys set a calorie target, and **Start** begins with calories counting down to zero from it. Time and Distance targets work the same way. **This feature only works in the quick start mode and not in preset programs.**

The Heart Rate Control program takes a user-set target: see `f60-2016-programs-heart-rate-control`. (Note: this book's maintenance and warranty pages are branded FUEL Fitness, not Sole.)
