This console shows seven error messages. Each has its own card.

| Code | Explanation printed in the manual |
|---|---|
| E0 | Display board CPU did not receive the Safety device signal. |
| E1 | The console didn't receive speed feedback signal, E1 will be appeared, and doesn't operate treadmill. |
| ER | The console didn't receive Incline feedback signal, ER will be appeared at incline window, but the treadmill able be operate. |
| E2 | The lower controller enter into be over current protected. |
| E4 | The motor / lower controller volt is abnormal, or motor input volt input isn't inserted. |
| E5 | The Communication is bad. |
| E6 | The lower controller is fault. |

The only tool the manual asks for is a multi-meter.

**There is no E3 and no E7 on this machine.** The incline fault is shown as **ER** in the incline window, not as E3. There is also no E8. An **LS** message appears in the troubleshooting matrix but has no section of its own.
