The console illustration says **"Eight programs offer a variety of work-outs"**, and the Preset Programs page says **"The treadmill has five different programs... These five programs have factory preset work level profiles"**:

| Program | Type |
|---|---|
| Manual / Quick Start | You set speed and incline yourself |
| Hill | Preset pyramid profile |
| Fat Burn | Preset sustained-effort profile |
| Cardio | Preset profile with fluctuations |
| Strength | Preset build-and-hold profile |
| Interval | Preset high/low intensity profile |
| HR1 | Heart rate program, 60% of maximum heart rate |
| HR2 | Heart rate program, 80% of maximum heart rate |

**There are no user programs on this machine.** The manual has no User 1 / User 2 key and no Custom User Defined Programs section; those start at the XT385.

The Heart Rate chapter of this manual says the heart rate monitor feature "can be used during manual mode or during any of the 5 different programs", counting only the five presets.
