**The console is an option on this bike, and the book says so in its contents list:** item 4 of the
Q&A is headed **"Display Blank (with Console Option)"**. Nothing else in the seventeen pages
describes a console - no display windows, no keys, no batteries, no pairing procedure.

The outline and skeleton drawings name every visible part - seat cushion, tube insert, **brake
tension knob**, quick release, pulley cover, flywheel fender, chain covers, stabilizer end caps, pedal,
eye tube end cap, leather brake pad - and no console. **The rider's only control is the brake tension
knob.**

This is an absence that was checked three ways, not a gap in the extraction:

| Check | Result |
|---|---|
| Loose-word search for console, display, monitor, computer, battery, engineer | "console" 1 hit and "display" 2 hits, all in the Q&A item above; the rest 0 |
| Same search allowing spaces between the letters | the same |
| Every page's word count from the PDF | none of the 17 pages is under 25 words; the two rendered pages (2 and 8) add only drawing labels |

**What the optional console needs is named only in the Q&A:** power for the unit, a **speed sensor
and magnet** correctly installed, and a **transmitter** whose position may have to be moved for the
signal to be received. That answer is held with the error cards.

**The 2019 and 2020 SB700 books describe a console in full** - readouts, a speed-sensor pairing, a
timer and heart-rate zones (`sb700-2019-console-readouts`, `sole-spinner-speed-sensor-pairing`). **None of
it may be quoted for this machine**: the 2009 book is a parts-replacement manual for an earlier bike,
filed under XIC600 in the Spirit folder, and it never says which console the option is.
