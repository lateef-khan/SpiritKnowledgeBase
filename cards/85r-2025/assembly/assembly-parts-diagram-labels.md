Twenty-one letters on two line drawings headed PARTS OF YOUR RECUMBENT BIKE - A to P on the first page, Q to U on the second:

| Letter | Part |
|---|---|
| A | 10" touch panel console |
| B | Vertical viewing angle adjustment |
| C | Console articulating arm horizontal adjustment |
| D | Manual mechanical brake lever |
| E | Assisted grab bar |
| F | Arm support |
| G | Seat belt (optional) |
| H | Seat position Fore / aft seat adjustment |
| I | Seat angle adjustment |
| J | Seat swivel adjustment |
| K | Seat carriage stops with assisted grab bar |
| L | Wheelchair anchor |
| M | Adjustable Crank arm (optional) |
| N | Pedal straps |
| O | Moving wheels |
| P | Leveling glides |
| Q | USB Type B Port; for Stress Testing & Data Transfer |
| R | UART Port; for Stress Testing |
| S | Power ON/OFF |
| T | Power socket |
| U | Bottle holder |

**The longest key on any Spirit bike diagram.** It names the wheelchair anchor, the seat carriage stops and the removable-seat parts that the operating page describes ("roll the removable seat away to allow for direct wheelchair access"; "the wheelchair anchor design incorporates a strap that secures the wheelchair at the wheel or frame member") - **and the book prints no procedure for sliding the seat off or anchoring a wheelchair**; the two sentences on the operating page are all it says. The 7.5S rehabilitation stepper's manual does print that procedure, for its own frame. Two optional parts are drawn: the seat belt (G) and the adjustable crank arm (M).
