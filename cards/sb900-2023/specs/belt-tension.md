**180 lbs.** That is the only figure the manual gives, and it is stated once, in the idler wheel refit step. This manual has no belt slipping section, so there is no second printing to check it against.

To set it, use a **6 mm hex key** on the **hex screw M8 x 80L (65)**. **Clockwise increases** the belt tension, **counterclockwise loosens** it.

**The unit does not match the earlier SB900.** The SB900 2020 manual gives **1000 Newton** for the same machine family, in both of the two places it prints the figure. This manual gives 180 lbs, which is about 800 N, and gives no gauge type.

| Machine | Printed figure |
|---|---|
| SB900 2023, SB1200 2023 | 180 lbs |
| SB900 2020 | 1000 N |
| SB700 2020 | 700 to 750 N, and 1000 N in the belt slippage answer |
| SB700 2019 | 700 to 750 N |

**Confirm the unit with the technical department before setting a belt to it.** The SB1200 2023 manual prints the identical sentence.
