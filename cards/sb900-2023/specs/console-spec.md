| Value | Range |
|---|---|
| Cadence bar graphic | 0 ~ 199 rpm |
| RPM | 0 ~ 199 RPM |
| Speed | 0 ~ 99 KM/H |
| Pulse | 30 ~ 240 BPM (needs a chest belt) |
| Time, count down | 1 ~ 99 minutes |
| Time, count up | 00:01 ~ 99:59 |
| Protocol | BLE 4.0 |

This table is identical to the one in the SB700 2020 and SB900 2020 manuals. Unlike those manuals, this one does not name the console part number; the cover code is SB910-3268T.
