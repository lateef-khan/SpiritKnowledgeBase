This step needs no hardware from the assembly pack.

1. Install the Console Holder on the Handlebar (4) by using the **M3 L Allen Wrench**. Install the Console (26) on the Console Holder, and **rotate it 90 degrees clockwise** to fix it.

**The M3 L Allen wrench called for here is not in the ASSEMBLY TOOLS list** and has no item number anywhere in the manual. The listed tools are #100 14/15mm Wrench, #101 M5 Allen Wrench Head Screw Wrench, #102 M6 L Allen Wrench and #103 Short Phillips Head Screw Driver.

**The Console Holder has no item number either.** Only the Console (26) and the Handlebar (4) are numbered.

This is a twist-lock console, not a clamp-and-thumb-screw console like the SB700 and the SB900 up to 2021.
