| Item | Range |
|---|---|
| Cadence bar graphic | 0~199 RPM |
| RPM | 0 ~ 199 RPM |
| Speed | 0 ~ 99 KM/H |
| Pulse | 30 ~ 240 BPM (**needs a chest belt**) |
| Time, count down setting range | 99:59~00:01 |
| Time, count up setting range | 00:01~99:59 |
| Protocol | BLE4.0 |

**The count down range is written differently in the 2021 console manual**, which prints "Count down setting range 1~99 minutes" for the same line. The other rows are identical between the two manuals.

The console manual is published by Direction Technology and carries its own warranty, not SOLE's.
