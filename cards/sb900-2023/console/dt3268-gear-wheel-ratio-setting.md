1. In **DIST or KCAL** mode, press the **PAGE** key for **3 seconds** to enter setting mode.
2. Press the **MODE** key to select the ratio icon.
3. Press the **PAGE** key to set the gear wheel ratio.
4. Press **MODE** to enter the number. Hold it longer for the number to jump faster.

**How the number maps to the ratio, in the manual's own examples:**

| Ratio | Number to enter |
|---|---|
| 1:6 | 600 |
| 1:3.75 | 375 |

**This card is the procedure, not the value for this bike.** The console manual is a universal one and its examples are not this machine's ratio. The SB900 2023 service manual gives the machine's own figure — 1:3.25, entered as 325 — and warns that getting it wrong makes RPM and speed read inaccurately. Use that figure and this procedure together.
