**This is the speed sensor transmitter pairing, not the Smart Tension knob pairing.** The knob pairing is section 5.2 and uses a different key sequence.

1. Press and hold **MODE and PAGE together for 3 seconds** to enter setting mode.
2. Wake the speed sensor by **stepping on the bike**. The transmitter sends its signal to the console for the pair stage.
3. **A "0" on the LCD means the pairing worked.** **"Err" means it failed** - press **PAGE** and repeat the pair stage.
4. The console leaves the pairing stage on its own after **10 seconds** if a transmitter is already paired.

The SB700 2020 and SB900 2020 manuals print the same procedure and add that every bike is paired at the factory, so re-pairing is a commercial or maintenance job. This manual does not repeat that.
