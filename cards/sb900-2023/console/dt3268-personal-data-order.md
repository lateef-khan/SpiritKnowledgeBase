**Personal data setting follows straight after the target heart rate zone setting.** Press **PAGE** to go to the next item and **MODE** to adjust it.

The order is:

**Gender → Age → Weight → Weight unit**

Changing metric units to imperial units affects all displayed units: MPH/KPH, Lb./KG and ML/KM.

**This is not the order the 2020 and 2021 consoles use.** Those go gender, then weight unit, then weight, and they never ask for age at all. An age prompt on this console is expected; on those, it is not there to find.
