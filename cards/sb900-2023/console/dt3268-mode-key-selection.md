Press the **MODE** key to select the **TIME, POWER BALANCE, DIST, KCAL** display. Power balance is an option on the DT3268i variant only.

**The bike's own owner's manual prints a shorter list for the same key** — "Press 'MODE' key to select TIME, DIST, KCAL display" — with no Power balance. Both are printed for this machine; which one a given console shows depends on the variant and on whether a power meter pedal is paired.

**The troubleshooting page of the same manuals lists a third set** — SPEED (SPD), DISTANCE (DIST), TIME (TIME) and CLOCK (CLK) — for toggling with the MODE key. The manuals do not reconcile the three lists.
