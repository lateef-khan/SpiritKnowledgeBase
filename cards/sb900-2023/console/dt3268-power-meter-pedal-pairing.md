1. Install the power meter pedals correctly on the bike.
2. With the console in **DIST or KCAL** mode, hold the **PAGE** key for **3 seconds** to go into settings.
3. Inside settings, hold **MODE and PAGE at the same time** to go into pairing mode.
4. In pairing mode, **start riding** while pressing the **PAGE** key so the console catches the pedal's signal. **When the word "OK" appears the console has paired with the power meter pedal.**
5. After a successful pairing the console returns to the main page automatically.

The pedal types named are **LOOK/SPD**.

**Power balance only exists on the DT3268i console variant**, and the readout only appears once a power meter pedal is paired.
