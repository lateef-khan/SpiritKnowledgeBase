Press the **Settings icon 10 consecutive repetitions** to enter the Maintenance suite:

- **Engineering Mode** - tap **Calibration** to begin. Automatic; the speed starts up without warning, so do not stand on the belt.
- **Diagnostics** - 'Recorder the error code on machine during running' (the book's words).
- **Machine Information** - tap **Zeroing** to reset the odometer. Four modes to enable: **Grade return, Beep Mode, Display Mode and Child lock**.
- **Maintenance** - default language setup is a reserved function; **Update App (USB)** is the offline update path if Wi-Fi cannot update; **Update OS** is a reserved function.
- **Lube Setup** - tap **Zeroing** to reset the lube message; the lube message defaults to **90 hours**.
- **Key Test** - tests every key.

The visible Settings rows above it: **Units, WiFi, Date, Time, Software, Bluetooth, Media Apps, Display Mode** (auto power off after **30 minutes** of inactivity), **Display Brightness** (slider), **Child Lock** (hold the **Display button for 3 seconds** to unlock).
