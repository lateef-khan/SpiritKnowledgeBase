The program key gives **6 programs**:

- Manual
- Hill
- Fat burn
- Cardio
- Strength
- Interval

and also:

- **USER1** and **USER2** — user programs, where the user sets time, speed and incline.
- **TH60 PCT** and **THR80 PCT** — the two heart rate percentage programs.

**Heart Rate Control 1 to 2** lets the user set time, age and the heart rate value.

**To run one**: press the PROGRAM keys (▲/▼) to choose, confirm each setting with ENTER, then press START.

**Source wording.** The two heart rate programs are printed as "TH60 PCT" and "THR80 PCT" in the same sentence. The prefix is spelled two different ways for what is plainly one pair of programs, the 60 percent and 80 percent target heart rate workouts.
