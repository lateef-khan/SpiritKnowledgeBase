1. Press and hold **START**, **STOP** and **ENTER** at the same time until the display shows **"Engineering mode"**. Depending on the software version it may say **maintenance menu** instead. Press **ENTER**.
2. Scroll the menu with the Speed ▲/▼ keys. **STOP** returns to the previous menu selection.

| Item | What it does |
|---|---|
| A. KEY TEST | Tests every key to make sure it is working. |
| B. DISPLAY MODE | Tests all the display functions. |
| C. Functions | Press ENTER to reach the settings below, and scroll them with the Speed ▲/▼ keys. |
| C-I. Display Mode | Turn it **off** to have the console power down automatically after **30 minutes** of inactivity. |
| C-II. Pause Mode | Turn it **on** to allow 5 minutes of pause. Turn it **off** to have the console pause indefinitely. |
| C-III. Maintenance | Resets the lube message and the odometer readings. |
| C-IV. Units | Choose English or Metric display readings. |
| C-V. Key Tone | Turns the beep on key press on or off. |
| D. Security | Locks the keypad against unauthorised use. With the child lock enabled the keypad will not operate until **Start and Enter are held for 3 seconds**. |
| E. Exit | Leaves the menu. |

**Two different items are both called Display Mode.** Item **B** is a display self test. Item **C-I** is the 30 minute power down setting, and it is also the setting that decides whether the console shows E0 when the safety key is pulled. Choosing the wrong one is easy; they are on the same screen.
