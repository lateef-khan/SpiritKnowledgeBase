| Quick key row | English values | Metric values |
|---|---|---|
| Speed | 2, 3, 4, 5, 7, 9, 12 | 3, 6, 9, 12, 15, 18, 20 |
| Incline | 1, 3, 5, 7, 9, 12, 15 | same |

Pressing one in RUN mode takes the machine straight to that speed or incline. **There are seven buttons on each row.**

There are also **UP and DOWN incline keys and FAST and SLOW speed keys on the handrails**, separate from the quick key rows, on their own wiring to the display board.

**Source wording.** The READY mode page introduces both rows as "5 preset buttons" while listing seven values on each. The RUN mode page on the next page says "total 7 buttons" for each row. Seven is correct.

**Watch the top metric speed.** This manual gives the highest metric quick key as **20**, while the console's own working range is 1.0 to 22.0 KM. The 2021 ENT manual for the neighbouring build gives the highest metric quick key as 22.
