Pressing DISPLAY during a workout switches the exercise data shown in the message window. **After the switch the system scans and displays automatically every four seconds.**

- `PROGRAM NAME LAPS XX`
- `VERT XXX FT` — the metric units show `M`
- `SEG TIME XX:XX` — not shown in HRC mode
- `MAX SPEED XX:XX` — not shown in HRC mode or MANUAL mode

Before a workout, while selecting a program, the same key selects the **speed or incline profile** to show.
