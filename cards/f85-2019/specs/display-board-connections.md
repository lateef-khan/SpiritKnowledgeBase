The display board carries a **Main IC** and a separate **Multimedia processor IC**. Around them:

| Connection | Goes to |
|---|---|
| TFT-LCD display wire | The panel |
| USB wire | The USB port |
| Bluetooth module | On board |
| Bluetooth speaker wire | The speaker |
| Amplifier wire | The amplifier board |
| Wireless heart receiver | The chest belt receiver |
| Heart module | On board |
| FAN | The cooling fan |
| Safety key | The safety key switch |
| 6-pin main control wire | The driver board, socket JK90 |
| Handrail pulse | The hand pulse grips |
| Quick speed and incline key board | The console quick key rows |
| KEY BOARD | The main keypad |
| Quick incline handrail buttons | The handrail incline switch |
| Quick speed handrail buttons | The handrail speed switch |

The treadmill configuration block diagram also names **BULETOOTH** (Bluetooth) as part of the machine. The console has an **audio in** jack and an **earphone out** jack on the front panel.

**The amplifier board has its own wiring page**, section 6.3, separate from the display board.
