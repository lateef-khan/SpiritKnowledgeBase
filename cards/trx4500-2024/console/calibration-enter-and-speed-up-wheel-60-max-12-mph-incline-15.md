Remove the safety key. Press and hold down the **Enter** and **Speed Up** buttons and replace the safety key; the console enters Calibration mode. **DO NOT STAND ON THE BELT DURING CALIBRATION.** The console displays the software version number; press Enter for the next item.

1. Set the wheel diameter to **60**. Press Enter.
2. Set kilometers or miles. Press Enter.
3. Set the minimum speed of **0.5**. Press Enter.
4. Set the maximum speed of **12**. Press Enter.
5. Set the maximum incline value of **15**, then press the Start/Stop key to confirm. The console enters the calibration display automatically.
6. Press the **START/STOP** key to start the calibration. It returns to the standby screen automatically when complete.

**The service manual says 12, not 15.** The shared Dyaco GT90C/GT90D service manual — one book for the TRX3500 and TRX4500 — prints this procedure once with a maximum incline of **12**, and its Up-key description also stops at 12. The owner's manual for this machine has a 15 incline key and a "0-15% incline range" badge, so 15 is what its console accepts; the service manual's page names neither machine and reads as the TRX3500's. The service manual adds a GRADE RETURN prompt and the "A0464 VER ... FACTORY SETTING" message described on [the TRX3500 card](../../trx3500-2024/console/calibration-enter-and-speed-up-wheel-60-max-12-mph-incline-12.md).
