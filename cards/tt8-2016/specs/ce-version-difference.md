**DC model: TT8 2016 ST925-YT021, DC drive motor. The AC inverter TT8 2016 (ST925A-YT030) is a different machine and this card does not apply to it.**

Besides the normal version there is a **CE version**. Both versions are exactly the same in functions and
outlines except that:

- the power input is **110 AC for the normal version** versus **230 VAC for the CE version**, and
- an additional **filter choke circuit** is added for the CE version, shown in the circuit diagram.

The sentence itself is damaged: the heading says "Special Note on ST925 CE version" but the body sentence names the "ST535 treadmill". The machine this manual covers is the ST925.
