**This row prints a single branch with no code and no calibration pointer — not the two-way E1/LS rows its siblings print.**

> Motor is not responsive after pressing Start — 1. If you press Start and the belt never moves, contact service.

Every other stencil book splits this fault two ways (run calibration if the belt moved and stopped, contact service if it never moved) under E1, LS or Err. The F60-2020 book prints only the contact-service branch. Read from the render (folio F60 TREADMILL 26): the page shows one numbered item and the table is complete.

The service manual's E1 procedure (no RPM signal) is the deeper test path for this symptom: see `f60-2020-e1-error-code`.
