**This is E4, not E5 (communication) and not E1.**

**Definition**: motor power wires error. The code list calls it "Treadmill motor wires or volt possible abnormal".

**Cause**: the power wires of the motor are not inserted into the lower controller.

| Part | Troubleshooting |
|---|---|
| Lower controller | Insert the power wires of the motor. |
| Motor | Replace the motor. |
| Display board | Replace the upper control board. |
