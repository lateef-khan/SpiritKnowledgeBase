| Row | Values |
|---|---|
| Speed shortcut keys | **1-10** (press one to set the speed rapidly) |
| Incline shortcut keys | **1-10** (press one to set the incline rapidly) |

Step keys alongside them: **SPEED up** adds **0.1 mph** per press (hold 3 seconds for rapid increase, also adjusts program values); **SPEED down** mirrors it. **INCLINE up** adds **1 level** per press (hold 3 seconds for rapid increase, also adjusts program values); **INCLINE down** mirrors it. Incline runs **0 to 12**, speed **0.5 to 12.0 mph**.
