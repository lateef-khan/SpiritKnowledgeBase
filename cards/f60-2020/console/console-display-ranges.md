| Readout | Display range | Working range |
|---|---|---|
| SPEED | 00:0 to 99.9 KM/H (MPH) | **0.5 to 12.0 MPH (1 to 18 KM/H)**. Each press of FAST or SLOW changes it by 0.1 KM/H (MPH) |
| INCLINE | 000 to 999 | **0 to 12**. Preset value 0 to 12. Each press of UP or DOWN changes it by 1 |
| TIME | 00:00 to 99:99 | 00:00 to 99:59. Count up setup range 05:00 to 99:00 |
| DISTANCE | 00:0 to 99.9 | 0 to 99.9 |
| CALORIES | 000 to 999 | 000 to 999 |
| PULSE | 0 to 999 | **50 to 220** |

Time counts up by default; if the user sets a time it counts down. When a time is set the count runs to zero. Pressing STOP in RUN Mode saves the time value, and re-entering RUN Mode continues counting from it.

Pulse comes from the hand grips or from a receiver, and the receiver needs a chest belt. **If the treadmill has no pulse signal for 8 seconds the displayed value becomes "P".**
