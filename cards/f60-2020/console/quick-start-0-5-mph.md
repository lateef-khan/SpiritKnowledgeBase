After power-on with the safety key in place, press **START**: the treadmill starts at the **minimum speed of 0.5 mph**, time counts up from zero and all data accrues. Adjust speed with the **Fast/Slow buttons** and incline with the **Up/Down buttons** at any time. Program presets default to **30 minutes**; during a program the same keys (or the rapid keys) adjust speed and incline, and **STOP** or a pulled safety key ends it.
