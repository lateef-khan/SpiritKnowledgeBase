| Mode | What it means |
|---|---|
| OFF Mode | The treadmill is turned on but the user has not inserted the safety key. The console display shows idle mode status, but the console does not work. |
| READY Mode | The treadmill is turned on and the safety key is inserted. The message window shows **"press start for quick start or program button for setup"**. |
| RUN Mode | Pressing STOP, or removing the safety key, stops the treadmill instantly and puts it in OFF Mode. |

**Before operating**: the treadmill changes speed slowly, so it takes a little time to reach the speed you set. Check the emergency switch is inserted in the right position and the clip is on your clothing. If either is wrong the machine will not work.

The console carries a **USB port for charging only** and **Bluetooth**.
