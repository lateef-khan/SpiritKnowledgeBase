**STEP 1:** Program button to **USER 1 or USER 2**, Enter. **STEP 2:** SPEED keys adjust the time **up from 30 minutes** if desired, Enter. **STEP 3:** SPEED keys set the speed effort and INCLINE keys the incline effort, Enter — **repeat until all 20 segments are programmed**. **STEP 4:** Start begins the workout.

Unlike the menu-console user programs there is **no naming step and no save sentence**; speed and incline are entered together per segment rather than all-speeds-then-all-inclines.
