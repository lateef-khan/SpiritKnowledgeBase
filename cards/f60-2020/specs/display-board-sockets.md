The display board wire connection drawing labels these sockets:

- **AMP power wires socket**
- **Wireless Pulse socket**
- **Bluetooth board wires socket**
- **Safety key wires socket**
- **Main Control wires socket**
- **Fan power wires socket**
- **Hand Pulse Module** and **Hand Pulse socket**
- **(L), (M) and (R) Key board wires sockets**
- **Speed Handrail keys socket** and **Incline Handrail keys socket**
- Two **Speaker sockets**

The treadmill configuration diagram also shows a **USB port that only charges** and a **Bluetooth** module.
