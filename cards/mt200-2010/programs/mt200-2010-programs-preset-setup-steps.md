**The time defaults to 20 minutes on this generation of the MT200. The later generation defaults
to 30 minutes** - see `70t-2026-programs-preset-setup-steps`, which covers the 7.0T and the later
MT200. Everything else in the procedure is the same on both.

1. Select a program, then press the **enter** key to begin customising the program settings - or
   just press the **start** key to begin with the default settings. All data calculations use the
   patient information from the **Set Up** function (Set Up key at top left of console).
2. After selecting a program, press enter to set the **program time**. The Time window blinks with
   the **default value of 20 minutes**. Use any of the up/down keys to adjust the time, then press
   enter. *(You may press start at any time during the programming to begin with only the settings
   you have modified at that point.)*
3. The **Speed window** now blinks, showing the preset **top speed** of the selected program. Use
   the Up/Down keys to adjust, then press enter. Each program has various speed changes throughout;
   this lets you limit the highest speed the program will attain during your workout.
4. Now press the **Start** key to begin your workout.
5. **There will be a 3 minute warm-up to begin.** You can press the start button to bypass this and
   go straight to the workout. During the warm-up the clock counts down from 3 minutes.
