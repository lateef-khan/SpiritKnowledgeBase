Four tools, each given a letter the assembly steps then use:

| Letter | Tool |
|---|---|
| A | 4mm Allen Wrench |
| B | 5mm Allen Wrench |
| C | 13/17mm Combination Wrench |
| D | **M22 Wrench** |

**The lettering is the useful part.** This is the only indoor cycle manual in this
repository whose steps name the tool for each fastener: **D** turns the star pop-pin into
the frame, **C** tightens the console screw, the dumbbell-holder screws and the sensor
guard screw, and **A** the console bracket screws into the handlebar.

**Wrench D has no equivalent in the CIC800 carton.** The CIC800 ships the same 4mm, 5mm
and 13/17mm tools, unlettered, and no M22 - so a CIC800 kit cannot fit this machine's
pop-pin.

## The carton still does not hold the levelling wrench

Levelling asks for a **14mm wrench**; nothing here opens to 14. See
[that card](../../ct800-2016/assembly/ct800-2016-assembly-levelling-pads.md).
