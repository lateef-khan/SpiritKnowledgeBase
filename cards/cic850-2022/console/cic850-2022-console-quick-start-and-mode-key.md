**Waking it.** The console sits in **Power Saving Mode** with the display off. **Press the Page key**
and it goes to the **'QUICK Start' active state**. The manual prints the two states side by side.
Then just pedal - there is no program to choose.

**MODE SELECT.** Press the **MODE** key to select which of **TIME, DIST and KCAL** the shared bottom
window shows.

**The troubleshooting page widens both.** For "No Display on Console" it says press **any** key to
bring the console to Quick Start mode, and for "RPM or HR does not change" it says press the MODE key
repeatedly to toggle between **SPEED (SPD), DISTANCE (DIST), TIME (TIME) and CLOCK (CLK)** - four
values, not three. The console operation page names three. Treat MODE as cycling whatever the console
in front of you shows; the manual is inconsistent about how many that is.

**A blank display is normally this, not a fault.** Only if a key press does not wake it does the
manual send you to the batteries.

**This is not the XIC600's gesture.** That indoor cycle has no Page key; you wake it by holding
either of its two Easy-Touch keys.
