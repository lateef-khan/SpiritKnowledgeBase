1. Select **"More"** in the bottom right corner.
2. Select **Equipment management**.
3. Select **"+"** in the top right corner.
4. Select **exercise bike**.
5. Select **"sensor"** at the very bottom.
6. Select the machine you wish to connect - it appears as **`SPIRIT BIKE`**.
7. The successfully paired machine shows up on this page.
8. Go to **browse** and select a video you would like to play.
9. Select **Start**.
10. **Press start on the console when Kinomap asks you to start pedalling.**
11. **Enjoy the ride!**

**Step 10 is the one riders miss.** Kinomap prompts, and the console has to be woken and started as
well - press the Page key to bring it out of Power Saving Mode into Quick Start.

**`SPIRIT BIKE` is the advertised name.** This is the only place in the manual that prints it, and it
is the name to look for in any other app too.

**Pair the console to the phone first** with the smartphone key -
`cic850-2022-console-bluetooth-pairing-smartphone-key`.

**The manual closes the section with the general claim** that the console is compatible with most
virtual active apps available. Only Zwift and Kinomap get step-by-step pages.
