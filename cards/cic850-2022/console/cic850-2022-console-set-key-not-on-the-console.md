**The console has three keys - MODE, a smartphone button, and PAGE/RECORD.** The overview drawing on
printed page 24 labels all three, and the moulded console face reads MODE and PAGE. **No SET key is
drawn or moulded anywhere.**

**Four separate passages nonetheless tell you to press one:**

| Page | Instruction |
|---|---|
| 17 and 29 | "Hold both **MODE and SET** keys on the console for 3 seconds" to re-pair the speed transmitter |
| 17 and 29 | "Press the **SET key** to repeat the pairing steps again" after `Err` |
| 27 | "The user can go into TIMER setting from SPEED or DISTANCE Mode by press and hold **'SET' key** for 3 seconds" |
| 35 | "Press and Hold **'SET key'** repeatedly to clear past measured value or go into setting and exit" |

**Treat SET as the PAGE/RECORD key.** Every other procedure in the same manual reaches the same
places with **Page** - the timer setting is given on the same page 27 as "holding the **Page** button
down for 3 seconds", and resetting the measured values on page 27 is "press and hold the **Page** key
under the TIME Mode for 3 seconds". The SET wording is carried over from another console in the same
DT-3268 family and was not updated.

**This is a defect in the manual, not a missing part.** Do not send a customer looking for a fourth
button, and do not open the console to find it.

**Where it bites hardest** is the transmitter pairing procedure, because a rider who cannot find SET
concludes the console is faulty. Use MODE + PAGE/RECORD held together for 3 seconds.
