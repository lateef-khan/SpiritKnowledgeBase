1. Hold the **Page** button down for **3 seconds**.
2. Press **Page** again to continue.
3. Press the **Mode** button until the desired time is displayed.

**If you set nothing, the TIME counts up** from 00:00 to 99:59.

**If you did set a countdown**, the TIME counts down to zero, then **the display flashes and an alarm
sounds**, and the console **automatically starts counting up again from 00:01**. It does not stop the
ride.

**A second doorway into the same setting.** The manual adds: "The user can go into TIMER setting from
SPEED or DISTANCE Mode by press and hold 'SET' key for 3 seconds." That is the **Page/Record** key -
this console has no SET key. See `cic850-2022-console-set-key-not-on-the-console`.

**Published range:** count down **1 to 99 minutes**, count up **00:01 to 99:59**.

**Which window you start from matters.** Hold Page under DIST or KCAL and you get the personal data
and heart rate zone settings instead, and under TIME you get the reset.
