**The console is a DT-3268F.** The manual prints the part number twice:

- the parts list, **item 110 - `Console DT-3268F`**, quantity 1;
- the **HARDWARE FOR STEP 5** table, as `PART 110 / TYPE CONSOLE / DESCRIPTION
  DT-3268F`.

It is held on by **item 109, the console bracket**, secured with **item 137, an
M5 x 15L screw**, and it mounts on **item 107, the fixed base assembly**, with
**item 108, an L type knob**. Those four items are what a console replacement
actually touches.

**This is the only machine in the Spirit indoor cycle and air bike group whose
owner's manual names its console part number.** The XIC600, AB900, AB950 and
JB950 books never print one, and the CB900 and CIC800 have no console at all.

## The Bluetooth name drops the F

The Kinomap pairing walkthrough on printed p. 31 shows the bike appearing in the
app's sensor list as

```
DT-3268 9A1D7F
```

so what a customer sees when pairing is **DT-3268 followed by a six-character
suffix**, not `DT-3268F`. The suffix is per-machine; `9A1D7F` is the one in the
screenshot and is not a model identifier. The console pairs as an **FTMS**
exercise bike.

**That line is drawn into the screenshot and does not extract.** The text of the
page reads only "4. Select exercise bike"; the console name was recovered by
rendering printed p. 31 at 300 dpi.

## The same console family is fitted to Sole spin bikes, and those are different machines

Sole's SB700-2020, SB900-2020 and SB900-2023 use the **DT-3268** console and
publish a measuring-range table identical to the one the CIC850 prints - see
`sole-spinner-console-spec` and `sb900-2023-console-spec`. That makes a search on
"DT-3268" return Sole cards for a Spirit question and the reverse.

**A Sole card is not an answer for a CIC850, and this card is not an answer for
an SB900.** The console may be the same family, but the bike around it is not:
different frame, different parts list, different warranty. Order a console
against the machine's own book. Where the CIC850's own display ranges are needed,
take them from the `console` section card for this machine rather than from a
Sole card.

The manual never says who makes the DT-3268F, and never gives its panel
technology, size or firmware version.
