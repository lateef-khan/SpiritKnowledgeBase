**The program keys also function as a number key pad when you are in the
data-setup mode.** The number for each key is **shown below the program name**. If
you are entering new data such as time, age or weight, you can use these keys to
enter the numbers quickly.

In idle mode the same keys do something else: **pressing a program key previews
that program's profile.** To begin a program, press its program key and then the
enter key.
