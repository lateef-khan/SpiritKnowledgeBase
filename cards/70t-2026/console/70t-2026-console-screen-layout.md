The overview drawing labels six things:

- **Dot Matrix Display**
- **Tablet Friendly Reading Rack Holder**
- **Message Window**
- **Heart Rate % Profile**
- **Incline Buttons**
- **Speed Buttons**

**That is everything the drawing names.** It does not label the individual program
keys, the set up / fan key or the display keys, although those are described in
the text on the pages that follow.

**The 2025 printing of the 7.0T owner's manual draws the same console with the same six call-outs**, so this card covers the 70t-2025. Its render shows two differences from the 2026 drawing: the key at the top left is labelled **Set up** alone, not Set up / Fan - the 2025 book has no fan (`70t-2026-console-fan-key`) - and program key **2 is labelled Deck-lift** where the 2026 keypad differs. The rest is the same: Track, Speed and Grade LEDs beside the dot matrix, Grade, Distance and Speed windows, Pulse, Mets, Calories and Pace legends with Cadence, Left steplength right and Symmetry under them, a 50-90% heart rate profile, Incline / Decline / Zero percent keys, Forward / Reverse / Acceleration-Deceleration keys, a number pad 1-0 with Enter, Start and a Stop marked Hold to reset.
