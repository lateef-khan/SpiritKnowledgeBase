**To enter: press Start and Speed Fast while the console is in power up reset**,
then press enter. The sequence steps through, enter accepting each:

| Prompt | Default | Range |
|---|---|---|
| UNITS | ENGLISH | Any up/down arrow changes it to Metric |
| ADJUST MIN SPEED | 0.1 mph | up to 0.5 mph |
| ADJUST MAX SPEED | 10.0 mph | down to 3.0 mph |
| ADJUST REVERSE SPEED MAX | 3.0 mph | down to 1.0 mph, up to 5.0 mph |
| ADJUST BELT SPEED ACCELERATION TIME PER EACH 1.0 MPH | 0:03 seconds, shown in the Time window | 0:01 to 1:00 minute |
| ADJUST BELT SPEED DECELERATION TIME PER EACH 1.0 MPH | 0:03 seconds, shown in the Time window | 0:01 to 1:00 minute |
| Adjust Max Incline | 15 | down to 10 |
| Adjust Max Decline | 5 | up to 10 |

After the acceleration and deceleration steps the console prompts **"Press Enter
for Grade Calibration Or To Exit Hold Stop Key Until Reset."** Max Incline is set
with enter; **Max Decline is followed by Start to calibrate**. **If grade
calibration succeeds the MW shows "Passed" for 3 seconds, then exits to idle
mode.**

**The decline default disagrees with the display range.** The Basic Information
page prints a rear incline range of 0 to minus 10%, but the factory Max Decline
default is 5; see `70t-2026-console-data-windows`.

**Both MT200 manuals print the same entry sequence, the same eight prompts and the
same defaults and ranges** - the 2010 manual on its p. 40, the 2022 manual on its
p. 64. The same disagreement over the decline figure is printed in both MT200
manuals too.

**The MT200-2022 service manual prints the same entry sequence, the same eight prompts and the same
defaults and ranges** as the two owner's manuals, including the "Passed" message after a successful
grade calibration.
