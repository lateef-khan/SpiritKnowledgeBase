The **set up / Fan key** enters patient data and customises the settings. Press
set up, then use the **up/down arrows to scroll the menu** and the **enter key** to
select an option.

Under **Patient data**:

| Value | What the console uses it for |
|---|---|
| Age | Vo2 and heart rate programs |
| Gender | Vo2 program |
| Weight | METs and Calorie calculations, and the Vo2 program |
| Height | The Symmetry program |

**The same key also toggles the fan**; that behaviour is a separate fact, see
`70t-2026-console-fan-key`.
