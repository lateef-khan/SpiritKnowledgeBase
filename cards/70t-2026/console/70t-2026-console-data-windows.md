| Window | What it shows |
|---|---|
| Time | Program time remaining, or elapsed time in quick start mode |
| Incline grade | **Front incline range 0 to 15 %. Rear incline range 0 to minus 10%** |
| Distance | Miles or kilometers, selected in Maintenance mode |
| Speed | mph or kph. **Range from minus 3 mph (5 kph) to plus 10 mph (16 kph) in 0.1 increments** |

**True zero speed is provided by a mechanical brake whenever the motor is idle.**

The minus sign on speed means the belt is set to reverse; see
`70t-2026-console-forward-reverse-keys`. The minus sign on grade means decline;
see `70t-2026-console-incline-decline-zero-keys`.

**The displayed decline range and the factory decline limit disagree.** This page
prints a rear incline range of 0 to minus 10%, while the Factory settings sequence
sets a **max decline defaulting to 5, adjustable up to 10**; see
`70t-2026-console-factory-settings`.
