Below the message window is a **heart icon and a bar graph**.

- Wearing an optional heart rate chest belt transmitter **starts the Heart Icon
  blinking**. This may take a few seconds.
- The **message window displays your heart rate in beats per minute**.
- The **bar graph represents the percentage of maximum heart rate**. The console
  overview drawing labels it the **Heart Rate % Profile**.

**Enter the correct age in set up for the bar graph to be accurate**; see
`70t-2026-console-set-up-menu-patient-data`.

This page names only the chest belt as a source. **It does not say the hand grips
feed the graph**, and the manual prints no formula for the maximum it works from.

**Both MT200 manuals print this word for word** - the 2010 manual on its p. 14, the
2022 manual on its p. 24 - including the note that the correct age must be entered in
set up. The MT200 manuals also name only the chest belt as a source.
