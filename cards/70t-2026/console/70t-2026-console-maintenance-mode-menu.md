**To enter it: press and hold the start, stop and enter key at the same time**,
until the display shows "Maintenance menu", then **press the enter key**. Scroll
the menu with the **up and down keys**; **the stop key returns to the previous menu
selection**.

| Menu item | What it does |
|---|---|
| Key Test | Press each key to verify it is functioning correctly |
| Display test | Lights all LED lights |
| Functions | The sub-menu below |
| &nbsp;&nbsp;Sleep | Turns sleep mode on or off. **When off, display power is always on** |
| &nbsp;&nbsp;Pause | Turns pause mode on or off. **When on, pause lasts 30 minutes** |
| &nbsp;&nbsp;Odometer reset | Reset odometer readings |
| &nbsp;&nbsp;Units | Set display to English or metric readings |
| &nbsp;&nbsp;Grade Return (GS Mode) | Turns GS mode on or off. **Returns the elevation to the lowest setting when pause is pressed** |
| &nbsp;&nbsp;Beep | Turns the speaker (beep sound) on or off |
| &nbsp;&nbsp;Service Mode | The motor, brake, step-sensor and calibration routines - see `70t-2026-console-service-mode-tests` |

**Maintenance mode is not the Factory settings mode.** Factory settings are
reached by a different key combination during power-up reset and hold the speed
and grade limits; see `70t-2026-console-factory-settings`.

**The MT200 manuals give the same key combination and the same menu, but not the same
words on the screen.** Both say to **keep the three keys held down for about 5
seconds**, which the 7.0T manual does not state.

| Manual | What the message window then displays |
|---|---|
| MT200 2010, p. 39 | **"Engineering mode"** |
| MT200 2022, p. 61 | **"Maintenance mode"** |
| 7.0T 2026, p. 43 | "Maintenance menu" |

**Both MT200 manuals say outright that the menu "may be called Engineering mode,
depending on version"**, so the name on the screen is a software version difference
and not a different menu. Every item listed above is printed identically in both
MT200 manuals.
