- **In Idle mode the fan function is disabled by default.**
- **During any active program**, press the **Set Up / Fan button to toggle the fan
  on or off**.
- On completion of the program the machine **returns to Idle mode and shuts off the
  fan**.

So a fan that will not start is usually a machine sitting in Idle mode: start a
program first.
