**Forward**
Sets the belt direction to forward. **Forward is the default direction when the
machine is powered on and any time the console is in idle mode.** If the belt is
already set to reverse this key changes it to forward. If the belt is moving in
reverse when the key is pressed, **the belt slows to zero speed first**, then
forward speed changes are allowed.

**Reverse**
Sets the belt to reverse if it is currently set forward. **This function only
operates in quick start or manual mode.** If the belt is moving when the key is
pressed it **slows to zero speed first**, then reverse speed changes are allowed.
**The speed window shows a minus (-) sign** indicating the speed is set to
reverse.

The top reverse speed has its own factory default of 3.0 mph; see
`70t-2026-console-factory-settings`.
