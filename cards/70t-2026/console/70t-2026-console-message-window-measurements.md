The message window is the main display for programming instructions and for
measurements during a program. **The measurement data shown varies depending on the
program.** Measurements include:

| Measurement | What it is |
|---|---|
| Pulse | Heart rate in beats per minute, **from 0 to 240 bpm** |
| METs | Metabolic equivalent; activity values run **from 0.9 (sleeping) to 23 (running at 22.5 km/h)** |
| Calories | Kilocalories (kcal) burned during exercise |
| Pace | Minutes per mile (or kilometer) |
| Step cadence | Steps per minute average |
| Step length | Heel strike to heel strike, in inches or centimetres |
| Symmetry | The percentage of difference between the left and right step length |

**To the left of the message window is a display key that switches the data
shown.**

**Both MT200 manuals print the same seven measurements with the same figures** - the
2010 manual on its p. 14, the 2022 manual on its p. 23.
