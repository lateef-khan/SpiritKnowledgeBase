The symmetry program provides basic gait information and a feedback graph. It measures the **left and
right step length** and calculates the **symmetry index**. The message window displays the user's
**cadence**, left and right step length in **inches (or centimetres)** and the symmetry index.

The dot matrix shows a graph of step symmetry as visual feedback. If the user has a longer step length
with their left leg, the graph grows on the left of the dot matrix. In the manual's example the step
lengths are **26 vs. 15 inches**, left longer than right. If the step length were even, only two dots
would light at the bottom centre of the graphic screen.

**To run it:**
1. Press the **symmetry** key, then **enter**.
2. Enter the **time** (up/down keys or the numeric key pad), then enter.
3. Press **Start**. All data calculations use the patient information from the set up function.

During the program, press the **display** key to scroll the data. When the program ends - by the set
time reaching zero, or by pressing stop twice - a summary shows the **average cadence, step lengths and
average symmetry** for the amount of time the user walked. You may then press start to run it again,
stop to exit, or the facility key to save it as the facility program.

*Note: for some types of gait the left/right data can be displayed in reverse. If this happens, press
the symmetry program key to flip the display.*

The 8.0T has a Symmetry feature too, but there it is a screen mode rather than a program with its own
key.

Both MT200 owner's manuals print this program in the same words, including the 26 vs. 15 inch
example and the note about flipping the display - the 2010-generation manual on printed page
22, the 2022-generation manual on printed pages 34-35.
