The facility program lets you build and save a custom program. You can build your own, **or save any
other preset program you complete as a custom program**, and personalise it by adding your facility name.

1. Press the **facility** key. The message window shows a welcome message - or the name you gave a
   previously saved program. Press **Enter** to begin programming.
2. The message window shows `Name - A` if no name is saved, or the saved name with its first letter
   blinking. Use up/down to change a letter and enter to save it and move to the next. Press **stop**
   when the name is finished, or press stop straight away to keep the existing name.
3. Enter an **age** (up/down keys or the numeric key pad), then enter.
4. Enter a **weight**, then enter.
5. Enter the **time**, then enter.
6. Adjust the **max level** - the peak exertion level you will experience during the program - then enter.
7. The first column blinks: adjust the level for the first segment, then press enter to move to the
   next. Each new segment starts at the level of the one before. **Continue until all twenty-four
   segments have been set.**
8. Press enter to **save**. The message window says `New program saved`, then offers to start or modify
   the program. Pressing stop exits to the start up screen.

During the facility program you can scroll the data in the message window with the adjacent **Display**
key.

**Saving a workout you have just finished:** when any program ends, press the **facility** key and follow
the instructions in the message window to save it as the facility program.

Unlike the 4.0T's Custom program, this one asks for a single **level** per segment, not a separate speed
and grade.
