1. Select a program, then press **enter** to begin customising it - or just press **start** to begin with
   the default settings. All data calculations use the patient information from the **set up** function
   (set up key at top left of console).
2. Press enter to set the **program time**. The Time window blinks with the **default value of 30
   minutes**. Adjust with any of the up/down keys, then press enter. *(You may press start at any point
   during programming to begin with only the settings you have modified so far.)*
3. The **speed window** now blinks, showing the preset **top speed** of the selected program. Adjust with
   the up/down keys and press enter. Each program has various speed changes throughout; this limits the
   highest speed the program will reach during your workout.
4. Press **start** to begin your workout.

**There is a 3 minute warm-up to begin.** You can press the start button to bypass it and go straight to
the workout. During the warm-up the clock counts down from 3 minutes.
