**The 7.0T has two preset exercise programs**, designed for a variety of goals: **Plateau** and
**Interval**. The initial built-in level of difficulty for each is set to a relatively easy level; you
may adjust the level of difficulty (**max speed**) before beginning.

Besides these two, the console offers a **Manual** program, the **Facility** custom program and the
saved program behind the **user** key, a **Vo2** fitness test, a **Symmetry** program and the
**deck-lift** program.

**About the profile picture.** The profiles shown in the dot matrix are merely pictures of the whole
profile and do not change size when the speed keys are pressed. When setting up a program you enter the
maximum speed setting for the **peak** of the profile. During the program the speed levels change as the
profile progresses. Pressing the speed keys changes the **peak level of the program, not the current
segment speed**, so you may need to change the peak setting several times before the current segment
increases.
