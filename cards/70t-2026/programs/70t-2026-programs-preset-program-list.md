**These consoles have two preset exercise programs**, designed for a variety of goals: **Plateau**
and **Interval**. The initial built-in level of difficulty for each is set to a relatively easy
level; you may adjust the level of difficulty (**max speed**) before beginning.

Besides these two, the console offers a **Manual** program, the **Facility** custom program and the
program saved behind it, a **Vo2** fitness test, a **Symmetry** program and the **deck-lift**
program. On the 7.0T the saved program is reached with a **user** key; on the MT200 it is reached
with the **facility** key. The MT200 also has a **Quick Start** mode, which is a console card.

**About the profile picture.** The profiles shown in the dot matrix are merely pictures of the whole
profile and do not change size when the speed keys are pressed. When setting up a program you enter the
maximum speed setting for the **peak** of the profile. During the program the speed levels change as the
profile progresses. Pressing the speed keys changes the **peak level of the program, not the current
segment speed**, so you may need to change the peak setting several times before the current segment
increases.

Both MT200 owner's manuals print the same two presets and the same paragraph about the profile
picture - the 2010-generation manual on printed page 16, the 2022-generation manual on printed
pages 27-28. **Their printed segment values are not the same as the 7.0T's**: see
`spirit-mt200-programs-preset-speed-incline-chart`.
