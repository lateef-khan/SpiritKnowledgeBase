**This is the 7.0T E31 (Fan) - not E18 (IGBT O-Heat), not E19 (Ambient Temp), not the CT900 E31 (COMM TIMEOUT) and not Sole E31 (overtemperature).**

| Field | Value |
|---|---|
| Code | E31 |
| Name, as printed | Fan |

**The one cause or remedy the table lists under it:** Drive Fan Bad

The table prints nothing else for this code - no description, no test procedure and no part number. The wording above is the manual's own, abbreviated as it prints it.
