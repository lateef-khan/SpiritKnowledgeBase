**This is the 7.0T E29 (I Signl Stop) - not E21 (In Sig Lost), not E32 (Analog In) and not the CT900 E29 (Incorrect Data).**

| Field | Value |
|---|---|
| Code | E29 |
| Name, as printed | I Signl Stop |

**The one cause or remedy the table lists under it:** Reset Power

The table prints nothing else for this code - no description, no test procedure and no part number. The wording above is the manual's own, abbreviated as it prints it.

**Ambiguous:** the fourth printed column opens with a further `Bad Drive` line that has no code heading above it, and E29 is the last code in the third column, so that line is most likely E29's second remedy - but the column break makes it impossible to prove from the text alone, and it is not listed above. The fragment in printed order:

```
E29 I Signl Stop      <- column 3, second-to-last row
Reset Power           <- column 3, last row
Bad Drive             <- column 4, first row, no code heading
```
