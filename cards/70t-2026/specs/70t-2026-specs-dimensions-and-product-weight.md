| Spec | Value |

| Length | 94.8" |
| Width | 48.7" |
| Height | 57.5" |
| Product Weight | 496 Lbs. |

The page prints inches and pounds only - it gives no metric equivalent for any of
them, and it gives **no running deck or belt size, no folded dimensions and no
shipping weight**.

**Where these figures came from.** The whole Specifications page is a flattened
image in this PDF, so a text extraction of the manual returns only the Power line
and the certifications list. Every figure above was read off the rendered page.

The 8.0T of the same 2026 line is a different and much larger machine - 213.3 cm
(84") long and 252.5 kgs (556.7 lbs) - and the 4.0T manual prints no dimensions
at all.
