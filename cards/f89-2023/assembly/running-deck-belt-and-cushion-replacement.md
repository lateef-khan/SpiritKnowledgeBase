**The cylinder has to come off first.**

1. Fold the treadmill. Unmount the **cylinder** with an L-Allen wrench and a **12mm open-end wrench**.
2. Remove the **foot rails** with a screwdriver.
3. Remove the **8 running deck locking screws**, then take off the running deck. The running deck, running belt
   and cushions can now be replaced. Reverse the steps to install them.
4. **Adjust the running belt tension and centre it.**

A worn belt or deck is the usual cause of an **E2** over current fault, so replace both when the deck is scored.
