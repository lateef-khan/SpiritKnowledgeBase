Lube Setup reminds the user to lube the deck. **The default time is 90 hours** and the setting range is
**90~200 hours**. The total using hour shows at the upper right of the display.

- When the total using hour reaches the setting, powering the machine on shows **"LUBE DECK PRESS STOP TO RESET
  LUBE MESSAGE"** for 3 seconds, then the message closes and the console goes to IDLE MODE.
- Once the display reaches IDLE MODE the message does not appear again until the next setting hours are reached.
- **Press STOP** to clear the message. Or enter **Lube Setup and hit "Zeroing"**; the display asks "Are you sure
  the lube parameter needs to be reset?" and Yes resets the total using hour.
- **The total using hour and distance are not cleared by the message.** They keep accumulating.
- If the total using hour has not reached the setting and the user resets anyway, the accumulated using hour
  resets to zero.
