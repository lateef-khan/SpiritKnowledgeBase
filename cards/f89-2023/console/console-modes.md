| Mode | What it means |
|---|---|
| OFF Mode | The SAFETY KEY is not inserted in the console. All windows appear blank. |
| READY Mode | The treadmill is ON and the SAFETY KEY is inserted. The message window shows the program profile name and cycle. Press START, or "START WORKOUT" on the touch panel, to start the treadmill in Manual Mode. |
| SLEEP Mode | Pressing any button takes the treadmill into READY Mode. |
| RUN Mode | Pressing STOP and removing the SAFETY KEY stops the treadmill instantly and enters OFF Mode. |
