| Button | Ready Mode |
|---|---|
| Safety Key | Insert the safety key in the right position to power on the console. Pulling it away shuts the console down automatically. |
| Stop Key | Non-function. |
| Start Key | Press START to start the treadmill. There is a 3 second final countdown on the window display, then the machine starts running. In MANUAL it starts at MIN SPEED; in PROGRAM it starts at the program preset value. |
| Touch panel | Changes each function. MANUAL sets time. Pre-set PROGRAM and Fitness tests set time and speed. Heart Rate Control 1~2 sets time, age and the heart rate value. User Program 1~2 sets time, speed and incline. |
| Speed quick keys | 7 preset buttons for rapid speed: 2, 3, 4, 5, 7, 9, 12 MI (3, 6, 9, 12, 15, 18, 22 KM) |
| Incline quick keys | 7 preset buttons for rapid incline: -4, -2, 2, 4, 6, 9, 12 |
| Fan key | Turns the fan ON and OFF. |
| Display key | Non-function. |
