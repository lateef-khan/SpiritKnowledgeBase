**Child Lock is OFF by default.** The setting range is ON/OFF.

1. Set Child Lock to **ON** in Settings.
2. **Reset the device or re-plug the safety key** to make the setting take effect.
3. The DM window in IDLE MODE then displays **"Console Locked"**.
4. To unlock, **press and hold both the START and STOP buttons for 3 seconds**, and the console enters IDLE MODE.

**The manual states the unlock two ways.** Section 4.5 says press and hold START and STOP for 3 seconds. The
engineering mode section says the display shows "Press Start and Display to enable operation" at the bottom, and
that the user can press START and STOP within 3 seconds. Hold START and STOP; that is the instruction both
sections agree on.
