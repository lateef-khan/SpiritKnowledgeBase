**This manual prints `#311008418` twice, on two consecutive pages, for two different labels.**

| Printed page | Page heading | Line printed |
|---|---|---|
| 17 | START WORKOUT | Placard Part number **#311008418** |
| 18 | REPETITION AND TIME COUNTER | Placard Part number **#311008418** |

On the other twenty-one books that print a number there, the second of those lines reads
**Counter Placard part number #311010581** - the counter label, which is the same part on every
machine in the range. Here the exercise placard's number has been repeated onto the counter page and
the word *Counter* dropped from the label.

**So this book does not tell you the counter placard number for this machine.** `#311008418` is the
LATERAL RAISE workout placard - and note that the CSS-LATP lat pulldown book prints the *same*
`#311008418` for its own workout placard, so the number is already doing double duty before it
reaches the counter page.

If someone needs the label beside the REPS and TIME windows, `#311010581` is what every other book in
the range calls it; this manual is not evidence that the lateral raise uses a different one, only
that its counter page was copied wrong. Say that rather than quoting `#311008418` back as the counter
placard.
