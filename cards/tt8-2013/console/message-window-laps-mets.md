The Message Window first shows the program name. Each **Display** press steps on: **Laps, Verticle, MET's, Segment Time, Max Speed (in mph), and Data Scan mode** – no Pace and no Incline entries, unlike the F63/F65/F80/S77 order. In Data Scan mode the shown information changes every **4 seconds**.
