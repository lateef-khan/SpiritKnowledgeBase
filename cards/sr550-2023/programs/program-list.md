Press **"All Programs"** on the home screen. Inside, the tabs across the top switch between **All Programs**, **Templates** and **Favorites**.

Tap any program card to open its **Program Setup** page, where you can read about the program, set the properties of your workout, or keep browsing with the arrow buttons in the upper right corner. To adjust a workout parameter you can **drag the ruler, tap the + and - buttons, or tap the number to open a numpad** and type the value.

| Program | What it does |
|---|---|
| Manual (Timer) | A timed workout with the resistance level controlled manually at any time during the workout. |
| Distance | Sets a target distance. The program ends once the target has been reached. |
| Calories | Sets a target calorie count. The program ends once the target has been reached. |
| Fatburn | Follows a preset resistance level changing pattern. Set Total Time before start. |
| Cardio | Follows a preset resistance level changing pattern. Set Total Time before start. |
| Strength | Follows a preset resistance level changing pattern. Set Total Time before start. |
| Game | A fixed 5-minute program. |
| Custom | A fully customisable intensity pattern over 20 segments. |
| HIIT | Short bursts of high intensity followed by rest periods, fully customisable. |

Start a program with the **"Start This Program"** button on the screen, or with the physical **START** key on the machine.
