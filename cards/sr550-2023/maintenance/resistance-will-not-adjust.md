First test the **Controller Assembly (36)** - the handle unit with the resistance buttons - and the **Console Assembly (43)** separately, to see which one is at fault. If both are faulty, work through all three solutions.

**Solution 1, the Controller Assembly (36).**

1. Follow the instruction manual, or the message on the sticker, to calibrate the **RF module**.
2. If there is still no resistance, remove the **3.5 x 12L Sheet Metal Screw (112) x1pc** from the **Battery Cover (36~3)** and check whether the Controller Assembly (36) has power. If not, replace it directly.
3. If it has power, remove the **3.5 x 12L Sheet Metal Screw (112) x2pcs** from the Controller Assembly (36) and check the connection of the **Resistance Button W/Cable + Faceplate (36~4)** and the **RF Module (35)**.
4. Or take the **3.5 x 12L Sheet Metal Screw (112) x4pcs** out of the console, open the cover and check the cable connections on the **Console Bottom Cover (43~2)**. A spare RF Module (35) makes this much quicker.

**Solution 2, the Console Assembly (43).** Release the 3.5 x 12L Sheet Metal Screw (112) x4pcs from the Console (43) and check the **PCB board (43~4)** and the **500mm Computer Cable (Upper)**. Release the **Chain Cover (R) (72)** and check the **Gear Motor (35)** and the **500mm Computer Cable (Lower) (45)**.

**Solution 3, the mechanism.** Release the Chain Cover (R) (72) and check the **Drive Belt (24)** and **Flywheel (23)**, then the connections between the **Gear Motor (35)**, the **Steel Cable (66)** and the flywheel.

- **Gear Motor (35)** - listen for noise while it works. If there is noise, run the Steel Cable (66) to its maximum. If there is no noise, replace the Gear Motor (35) directly.
- **Flywheel (23)** - check whether the steel cable is broken or the flywheel is stuck.

**The manual numbers the RF module and the gear motor the same.** Part (35) is called the RF Module in the controller steps and the Gear Motor everywhere else.
