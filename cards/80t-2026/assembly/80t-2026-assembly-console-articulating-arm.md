The console hangs on a **360 degree swivel articulating arm**. It lets a
clinician operate the console from any position around the machine and set a
suitable viewing distance for the patient. A separate tilted view angle
adjustment covers a wide range of user heights.

**How stiffly it swivels is set during assembly, not afterwards.** The arm is
mounted on the console mast with **5 socket set screws (209)**, M5 x 5L, turned
with the **3mm Allen Wrench (220)**:

- **Do not firmly tighten the socket set screws.**
- If the swivel arm feels too tight, **loosen a quarter circle at each
  adjustment** and work towards a proper swivel function.

The parts diagram names the two movements separately: **B** is the vertical
viewing angle adjustment and **C** the console articulating arm horizontal
adjustment.

Neither the 4.0T nor the 7.0T has this arm. Their consoles are bolted to a fixed
console frame.
