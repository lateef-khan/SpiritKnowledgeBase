| Label | Part |
|---|---|
| A | 10" touch panel console |
| B | Vertical viewing angle adjustment |
| C | Console articulating arm horizontal adjustment |
| D | Safety tether cord |
| E | Hand grips |
| F | Bottle holder |
| G | Adjustable handrails |
| H | Handrail adjustment (horizontal) |
| I | Handrail adjustment (vertical) |
| J | Rear step |
| K | Rear incline |
| L | Front incline |
| M | Exercise area (22"x60"; 56x152.5cm) |
| N | USB Type B Port; for Stress Testing & Data Transfer |
| O | UART Port ; for Stress Testing |
| P | Power ON/OFF |
| Q | Power socket |

**These letters are this machine's letters only.** The 7.0T diagram stops at J
and means different parts by the same letters - its C is the Safety Key, its D
the adjustable handrails, its H the rear step. The 4.0T diagram also stops at J
and differs again.
