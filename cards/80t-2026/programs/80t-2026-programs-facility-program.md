The Facility program lets you build and save a custom program. **You can build your own, or save any
other preset program you complete as a custom program.** It can be personalised further by adding your
facility name.

On the touch screen:
- Change the **max speed**, **max grade** or **total time**.
- Click to **create the profile**. Once created, the profile is shown in place.
- **Touch a segment** to create or modify it.
- Click **Save** after creating the profile.
- Click **Start** to run the program.

**The manual gives no segment count for this program.** The 4.0T's Custom program and the 7.0T's
Facility program each use twenty-four segments; the 8.0T manual does not state a number, so none is
recorded here.
