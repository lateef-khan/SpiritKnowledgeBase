The Program Setup menu lists **twenty** programs, in this printed order:

- Manual
- Timer
- Lift
- Hill
- Plateau
- HIIT
- Facility
- Heart Rate Target
- Calories Target
- METs Target
- Distance Target
- Steps Target
- Vertical Target
- Fitness Test
- Naughton Protocol
- Modified Naughton
- Bruce Protocol
- Balke-Ware Protocol
- Astrand Rhyming Test
- Conconi Test

The single **Fitness Test** entry opens ten test protocols of its own. Hill and Plateau are described
together as the "pattern programs". Swipe the home screen from left to right to see more items and
select the one you want.
