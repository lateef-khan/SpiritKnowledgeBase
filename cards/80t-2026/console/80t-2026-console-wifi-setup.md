1. **Select preferred language, then click Next.**
2. **Turn WiFi on.**
3. **Choose preferred WiFi network, then click Next.**
4. **Enter the password for the WiFi network, then click Connect.**

WiFi can be changed later from the Settings menu; see
`80t-2026-console-settings-menu`.

**WiFi matters beyond the setup wizard.** Without a WiFi connection the console
signs users in as a guest in offline status; see
`80t-2026-console-user-login-methods`.

**The 4.0T and 7.0T have no WiFi.** Neither manual mentions it anywhere.
