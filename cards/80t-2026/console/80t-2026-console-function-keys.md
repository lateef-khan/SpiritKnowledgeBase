| Key | What it does |
|---|---|
| **+ / -** (Plus/Minus) | Adjust speed level |
| **^ / v** (Up/Down) | Adjust incline/decline % grade level |
| **START & PAUSE** | One touch start (quick start); temporarily pauses exercise, and touch start to resume |
| **ENTER** | Confirm each setting |

**Those four are all the hard keys this manual names.** Everything else is done on
the touch screen.
