**There is a thin protective sheet of clear plastic on the overlay of the console
that should be removed before use.**

The console itself is a **Touch Screen Display**: all information required for
operation is explained on screen, and the detailed directions for programming the
various functions are shown on each screen of the console display.

The console UI is shared across the MED 8 series - the manual names the **8.0T,
8.0U, 8.5R, 8.5S and 8.5UE**. Only the 8.0T is a model in this knowledge base.
