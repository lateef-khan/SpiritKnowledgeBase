The console is a **10" touch panel**. The overview drawing labels these on the home
screen:

| Label | Where |
|---|---|
| Settings | Top of the screen |
| Log Out | Top left |
| Bluetooth Device | Top right area |
| WiFi Connection | Top right |
| Heart Rate Sensor Connection | Right side |
| User name | Shown on the home screen |

Three shortcuts are called out on the drawing:

- **Press Lift** to start the deck lift program.
- **Press Timer** to start the Timer program.
- **Press Start** to begin the exercise session.

**Swipe from left to right to see more**, then select the wanted item to start.
