**On the Home Screen, tap the Wi-Fi icon once, then tap the clock in the status bar six times.**
"Maintenance Mode is intended for troubleshooting purposes." The screenshot marks the two targets with
arrows at the top right of the Welcome page - the Age, Height and Weight wheels with the Lift, Timer and
Start buttons.

**What the menu holds, as the book draws its tree:**

| Top level | Second level | Third level |
|---|---|---|
| **Odometer** | | |
| **Software** | Android Version, Firmware Version, LCB Version, Console APP Version | |
| **Service** | Machine Type | Treadmill, Upright Bike, Recumbent Bike, Recumbent Stepper, UBE, Rehab UBE |
| | Communication | |
| | NFC Sensor | |
| | Keypad Test | **Grade Increase, Grade Decrease, Start/Stop, Enter, Speed Down, Speed Up** |
| | Error Log | |
| | Beacon Test | White, Blue, Green, Yellow, Red Color |
| | **Drive Motor** | Rotational Speed, Electric Current, Belt Speed Setting |
| | **Incline Motor** | Front Motor D/A, Rear Motor D/A, Calibration |
| | **Step Sensor** | |
| | **Brake** | ON/OFF Setting |
| **Lock Facility Program** | ON / OFF Setting | |

"The full name of LCB is Lower Control Board."

**Odometer** - "Indicates the total belt operation time and accumulated running distance." On this
machine the belt wording is literal.

**Lock Facility Program** - "When set to ON, the speed and incline profiles of the Facility program
cannot be modified."

**Software** is where firmware, LCB and console-app updates run
(`80t-2026-console-firmware-lcb-and-console-app-update-from-a-usb-root-or-over-wifi`). **Service**
holds the tests, including the incline calibration and the brake release
(`80t-2026-console-service-tab-drive-motor-incline-motor-calibration-step-sensor-and-brake-release`).

**The owner's manual never mentions maintenance mode**; its Settings menu is the owner's menu
(`80t-2026-console-settings-menu`). Do not hold Start, Stop and Enter on this console - that is the
LED treadmills' gesture (`70t-2026-console-maintenance-mode-menu`, `40t-2026-console-maintenance-mode-menu`).
The MED 8 bikes and stepper share the app and the gesture, with crank tests where this tree has motor
tests (`spirit-med-80-bike-console-maintenance-mode-on-the-wifi-icon-once-and-the-clock-six-times`,
`85s-2025-console-maintenance-mode-on-the-wifi-icon-once-and-the-clock-six-times`).
