**When initially powering on the console, wait a few minutes for the internal
self-test.** The console then goes to the start up display, which is the **login
method page**. You may begin to use the machine after choosing the login method.

**No software version, odometer or hours reading is printed for this start-up.**
The 7.0T shows all three during its self-test; this manual does not claim the same
for this machine.

If there is an issue, the console shows an error message along with a possible
solution.
