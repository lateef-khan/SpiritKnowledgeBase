During a program you can **scroll through the data in the display**, and **switch
the mode between Status, Diagram, Symmetry and Controls by pressing the icon**.

| Mode | What it does |
|---|---|
| **Status** | View the value of the current parameters |
| **Diagram** | Display the selected parameter on a progress chart |
| **Symmetry** | The step-length view, see `80t-2026-console-symmetry-screen` |
| **Controls** | Adjust the parameter |

Select the parameter to display on the screen, then press Diagram to chart it or
Controls to adjust it.

**Turn on Close Up Mode to change the appearance of the screen.**

**Press STOP to pause or stop the exercise**; see
`80t-2026-console-pause-and-summary`.
