**This is the 8.0T inverter code `oun`, row 45 of the 48-row table** - not `ouA`, `oud`, `ocn` on the same table, and not the same letters on any other Spirit treadmill (see the links below). It is an inverter (drive) fault, and it is printed only in the service manual - the owner's manual has no code list (`80t-2026-errors-console-shows-message-with-solution`).

| Category | Error Code | Cause | Solution |
|---|---|---|---|
| Inverter | 45. oun | Overvoltage during constant speed operation | Check the load on transmission components related to the drive belt operation. |

`ouA` (acceleration) checks the motor insulation and `oud` (deceleration) goes straight to a new inverter; only `oun` checks the transmission load.

The whole table, with the fourteen codes the book marks *Not applicable to this model*, is `80t-2026-errors-inverter-error-code-table-48-rows`.
