**This is the 8.0T inverter code `ct3E`, row 18 of the 48-row table** - not `ct1E`, `ct2E` on the same table, and not the same letters on any other Spirit treadmill (see the links below). It is an inverter (drive) fault, and it is printed only in the service manual - the owner's manual has no code list (`80t-2026-errors-console-shows-message-with-solution`).

| Category | Error Code | Cause | Solution |
|---|---|---|---|
| Inverter | 18. ct3E | Loose wiring at the inverter output or internal circuit abnormality | Check for loose connections between the inverter output and the motor terminals. Replace the inverter if necessary. |

`ct1E`, `ct2E` and `ct3E` print the same cause and the same solution; only the code differs. The book does not say what separates the three.

The whole table, with the fourteen codes the book marks *Not applicable to this model*, is `80t-2026-errors-inverter-error-code-table-48-rows`.
