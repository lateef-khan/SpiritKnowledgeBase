**This is the 8.0T inverter code `Hoc1`, row 09 of the 48-row table** - not `Hoc3`, `Hou` on the same table, and not the same letters on any other Spirit treadmill (see the links below). It is an inverter (drive) fault, and it is printed only in the service manual - the owner's manual has no code list (`80t-2026-errors-console-shows-message-with-solution`).

| Category | Error Code | Cause | Solution |
|---|---|---|---|
| Inverter | 09. Hoc1 | Inverter output short circuit, loose wiring, or poor grounding | Check for loose connections between the inverter output and the motor terminals. |
| Inverter | 09. Hoc1 | Sudden overload on transmission components | Check the load on transmission components related to the drive belt operation. |

**Two causes on one row**, one electrical and one mechanical, each with its own check. `Hoc2` is printed on the next row as *Not applicable to this model*.

The whole table, with the fourteen codes the book marks *Not applicable to this model*, is `80t-2026-errors-inverter-error-code-table-48-rows`.
