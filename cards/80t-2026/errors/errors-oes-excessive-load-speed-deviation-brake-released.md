**This is the 8.0T inverter code `oES`, row 29 of the 48-row table** - not `oS`, `Pgo` on the same table, and not the same letters on any other Spirit treadmill (see the links below). It is an inverter (drive) fault, and it is printed only in the service manual - the owner's manual has no code list (`80t-2026-errors-console-shows-message-with-solution`).

| Category | Error Code | Cause | Solution |
|---|---|---|---|
| Inverter | 29. oES | Excessive load caused significant speed deviation | Check whether the electromagnetic brake on the motor is released during operation (refer to the troubleshooting section for details). Check the load on transmission components related to the drive belt operation. |

**The first check is the same brake question the `Pgo` procedure asks** - whether the electromagnetic brake on the motor is released during operation - and the book points at that section rather than repeating it. A brake that stays on is a load the motor cannot overcome; the second check is the drive-belt transmission.

The whole table, with the fourteen codes the book marks *Not applicable to this model*, is `80t-2026-errors-inverter-error-code-table-48-rows`.
