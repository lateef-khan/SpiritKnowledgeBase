**This is the 8.0T inverter code `oud`, row 44 of the 48-row table** - not `ouA`, `oun`, `ocd` on the same table, and not the same letters on any other Spirit treadmill (see the links below). It is an inverter (drive) fault, and it is printed only in the service manual - the owner's manual has no code list (`80t-2026-errors-console-shows-message-with-solution`).

| Category | Error Code | Cause | Solution |
|---|---|---|---|
| Inverter | 44. oud | Overvoltage during deceleration | Replace the inverter. |

`ouA` (acceleration) checks the motor insulation and `oun` (constant speed) the transmission load; only `oud` goes straight to a new inverter.

The whole table, with the fourteen codes the book marks *Not applicable to this model*, is `80t-2026-errors-inverter-error-code-table-48-rows`.
