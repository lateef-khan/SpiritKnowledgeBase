**This is the 8.0T inverter code `oL`, row 06 of the 48-row table** - not `oL1`, `oL2`, `LL` on the same table, and not the same letters on any other Spirit treadmill (see the links below). It is an inverter (drive) fault, and it is printed only in the service manual - the owner's manual has no code list (`80t-2026-errors-console-shows-message-with-solution`).

| Category | Error Code | Cause | Solution |
|---|---|---|---|
| Inverter | 06. oL | Prolonged overload operation | Inspect transmission components for any abnormalities, such as damage or wear on the running deck surface. |

The three `oL` codes all end at the same inspection - transmission components, and damage or wear on the running deck surface. The book separates them by what the inverter measured: `oL` prolonged overload, `oL1` the motor under overload for an extended period, `oL2` motor over-torque.

The whole table, with the fourteen codes the book marks *Not applicable to this model*, is `80t-2026-errors-inverter-error-code-table-48-rows`.
