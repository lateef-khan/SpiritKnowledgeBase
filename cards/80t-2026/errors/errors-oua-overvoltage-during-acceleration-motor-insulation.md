**This is the 8.0T inverter code `ouA`, row 43 of the 48-row table** - not `oud`, `oun`, `ocA`, `Hou` on the same table, and not the same letters on any other Spirit treadmill (see the links below). It is an inverter (drive) fault, and it is printed only in the service manual - the owner's manual has no code list (`80t-2026-errors-console-shows-message-with-solution`).

| Category | Error Code | Cause | Solution |
|---|---|---|---|
| Inverter | 43. ouA | Overvoltage during acceleration | Check motor insulation condition. |

**The only row whose solution is the motor insulation.** `oud` (deceleration) goes straight to a new inverter and `oun` (constant speed) to the transmission load; the three overvoltage codes do not share a remedy.

The whole table, with the fourteen codes the book marks *Not applicable to this model*, is `80t-2026-errors-inverter-error-code-table-48-rows`.
