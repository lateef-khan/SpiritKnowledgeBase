**This is the 8.0T inverter code `EPE0`, row 41 of the 48-row table** - not `EPE1`, `ErP0` on the same table, and not the same letters on any other Spirit treadmill (see the links below). It is an inverter (drive) fault, and it is printed only in the service manual - the owner's manual has no code list (`80t-2026-errors-console-shows-message-with-solution`).

| Category | Error Code | Cause | Solution |
|---|---|---|---|
| Inverter | 41. EPE0 | EEPROM read error | Replace the inverter. |

`ErP0`, three rows of the same family up the table, is printed as *EEPROM error* with the same fix; the book does not say how the two differ.

The whole table, with the fourteen codes the book marks *Not applicable to this model*, is `80t-2026-errors-inverter-error-code-table-48-rows`.
