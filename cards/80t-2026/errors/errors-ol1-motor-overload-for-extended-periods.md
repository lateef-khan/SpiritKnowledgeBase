**This is the 8.0T inverter code `oL1`, row 07 of the 48-row table** - not `oL`, `oL2` on the same table, and not the same letters on any other Spirit treadmill (see the links below). It is an inverter (drive) fault, and it is printed only in the service manual - the owner's manual has no code list (`80t-2026-errors-console-shows-message-with-solution`).

| Category | Error Code | Cause | Solution |
|---|---|---|---|
| Inverter | 07. oL1 | Motor operated under overload for extended periods | Inspect transmission components for any abnormalities, such as damage or wear on the running deck surface. |

It shares its remedy word for word with `oL` and `oL2`. On the CTSBS900 treadmill `oL1` is an *inverter* overload, a different fault (`ctsbs900-ol1-inverter-overload`); do not read that book here.

The whole table, with the fourteen codes the book marks *Not applicable to this model*, is `80t-2026-errors-inverter-error-code-table-48-rows`.
