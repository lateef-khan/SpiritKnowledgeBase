The checklist splits this by what the belt does:

| What happens | What to do |
|---|---|
| The belt moves but stops after a short time, and the display shows `E1` | Run a calibration - see the E1 card |
| You press start and the belt never moves, then the display shows `E1` | Contact service |

**The manual gives no other start-up fault table for this machine.** The troubleshooting procedure matrix that would cover a dead start with no error code is section 8.10, and in this manual that section is images only with no readable text. The earlier ST725 manual's matrix does carry those rows: motor M+ or M- wire not connected, motor broken, or the controller latched off and cleared by a power cycle at the ON/OFF switch.
