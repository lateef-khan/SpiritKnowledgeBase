| Field | Value |
|---|---|
| Sole model number (SKU) | 577818 |
| Name in the Spirit `Models` table | SOLE S77 2019 |
| Manual cover | `ST728 Treadmill Service Manual` |

**The manual never says "S77".** It is written throughout as the **ST728**, which is the Dyaco factory code. The Sole name and the SKU come from the Spirit database, not from the manual, and the manual carries no model year anywhere.

**The last two digits of the SKU are not the model year here.** `577818` ends in `18` while the database names the row `SOLE S77 2019`. This is the same pattern as the E25 (`525018`, named "Sole E25 2019") and the LCB (`511118`, named "Sole LCB 2019").

The previous S77 does follow the rule: `577816` is named `SOLE S77 2016` and its manual is the ST725.

Other S77 rows in the same table, which are **not** this machine: 577003, 577810 (AS77), 577812 (S77 2013), 577816 (S77 2016), 577881, 577886 (US77 2006), 577887 (VS77 2007), 577888 (WS77 2008/09).
