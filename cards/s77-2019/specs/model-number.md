| Field | Value |
|---|---|
| Name in the Spirit `Models` table | SOLE S77 2019 |
| Manual cover | `ST728 Treadmill Service Manual` |

**The manual never says "S77".** It is written throughout as the **ST728**, which is the Dyaco factory code. The Sole name comes from the Spirit database, not from the manual, and the manual carries no model year anywhere. The model number is on the S77 model card, `s77-model-numbers`.

**The last two digits of the SKU are not the model year here.** This machine's number ends in `18` while the database names the row `SOLE S77 2019`. The E25 2019 and the LCB 2019 follow the same pattern.

The previous S77 does follow the rule: its number ends in `16`, its row is named `SOLE S77 2016` and its manual is the ST725.

Other S77 rows in the same table, which are **not** this machine: 577003, 577810 (AS77), 577812 (S77 2013), the S77 2016's own row, 577881, 577886 (US77 2006), 577887 (VS77 2007), 577888 (WS77 2008/09).
