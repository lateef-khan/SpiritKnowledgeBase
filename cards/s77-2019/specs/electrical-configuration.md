| Part | What the manual says it does |
|---|---|
| Safety key | Fits into the console to activate all functions. Without it the console cannot be controlled and the treadmill will not run. |
| Console | Interface that controls all functions. Contains keys, a **TFT-LCD display**, speaker, fan, hand pulse grip and the safety key. |
| Main controller | Carries the **DC** power supply for the console, the incline driver and the DC motor driver. Includes the power supply, motor driver, control circuit, incline control circuit and speed sensor. |
| Treadmill motor | A variable speed **DC** motor, 0 to 90 (or 0 to 180) volts. |
| Incline motor | An AC motor, controlled from the console through the main controller. |

**The 220 V (or CEGS) version of the lower controller area has a filter and a choke** that the 110 V version does not.

This is a DC machine: it has a lower controller and a DC drive motor, not an AC inverter.
