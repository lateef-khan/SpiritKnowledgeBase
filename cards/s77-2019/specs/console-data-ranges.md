| Window | Display range | Work range |
|---|---|---|
| Speed | 0.0 to 99.9 | **1.0 to 22 km or 0.5 to 12 mile**, adjusted in 0.1 steps |
| Incline | 0 to 99 | 0 to 15, adjusted in steps of 1 |
| Time | 0:00 to 99:99 | 0:00 to 99:59; count down can be set from 10:00 to 99:00 |
| Laps | 0 to 99 | 0 to 99 |
| Distance | 0.00 to 99.9 | 0.00 to 99.9 |
| Calories | 0.0 to 999 | 0.0 to 999 |
| Pulse | 0 to 999 | 50 to 200 BPM |

Time counts up by default; setting a time makes it count down to zero.

Pulse falls to `0` if the console has had no signal for **8 seconds**.

**The maximum speed differs from the earlier ST725 manual** for this machine family, which gives the speed work range as 1.0 to 18.0 kmph (0.5 to 12.0 mph). Both give the same 12 mph in imperial; the metric figures, 22 km/h here against 18.0 km/h there, do not agree with each other or with 12 mph.
