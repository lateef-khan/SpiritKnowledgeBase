1. Press and hold **START, STOP and ENTER** together until the display shows `Engineering mode`. Depending on the software version it may say `maintenance menu` instead.
2. Press **ENTER**.
3. Scroll with the Speed up and down keys. **STOP** goes back to the previous selection.

| Item | What it does |
|---|---|
| A. Key Test | Tests every key |
| B. Display Test | Tests all the display functions |
| C. Functions | Press Enter to open, scroll with the Speed keys |
| C-I. Display Mode | Turn **off** to have the console power down automatically after 30 minutes of inactivity |
| C-II. Pause Mode | **On** allows 5 minutes of pause; **off** pauses indefinitely |
| C-III. Maintenance | Resets the lube message and the odometer readings |
| C-IV. Units | English or Metric display readings |
| C-V. Key Tone | Turns the key beep on or off |
| D. Security | Locks the keypad. Press and hold **Start and Enter for 3 seconds** to unlock. |
| E. Exit | Leaves the menu |

**There is a second way into engineering mode**, used by the E0 procedure: remove the safety key, press STOP, START and ENTER together and refit the key at the same time.

**The earlier ST725 manual has a flatter menu**: Key Test, Display Mode, Pause Mode, Lube Message Reset, Key Tone and Child Lock, with no Display Test, no Units and no Exit. The lube reset is called Maintenance here and Lube Message Reset there, and the keypad lock is called Security here and Child Lock there.
