| Group | Imperial values | Metric values |
|---|---|---|
| Speed quick keys | 2, 3, 4, 5, 7, 9, 12 | 3, 6, 9, 12, 15, 18, 20 |
| Incline quick keys | 1, 3, 5, 7, 9, 12, 15 | the same |

The same quick key blocks are repeated on the handrails.

Other console keys: **Program**, **Enter**, **Display**, **Fan**, **Start**, **Stop**, Speed fast and slow, Incline up and down, two speakers, an **audio in** socket and an **earphone out** socket, the hand pulse grips and the safety key socket.

**The manual miscounts the quick keys in one place.** The ready mode section prints "5 preset buttons" for both the speed and the incline rapid keys, while the run mode section says "total 7 buttons" for each and lists seven values.
