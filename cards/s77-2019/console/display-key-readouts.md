Pressing **DISPLAY** during a workout switches the exercise data in the message window. **After the switch the system scans and displays automatically every four seconds.**

- `PROGRAM NAME`
- `LAPS XX`
- `VERT XXX FT` - shows `M` in metric units
- `SEG TIME XX:XX` - **not shown in HRC mode**
- `MAX SPEED XX:XX` - **not shown in HRC or MANUAL mode**

Before a program starts, the display key instead selects the speed profile or the incline profile.
