| Key | Run mode behaviour |
|---|---|
| Safety key | Pulling it away shuts the computer down automatically |
| Stop | Stops the treadmill |
| Start, Enter, Program | No function |
| Fast / Slow | Each press changes the speed by **0.1 kph (0.1 mph)**. Held down, the speed runs to MAX or MIN quickly. |
| Up / Down | Each press changes the incline by 1. **Maximum incline position 15**, minimum 0. |
| Speed rapid | 7 buttons: 2, 3, 4, 5, 7, 9, 12 (metric 3, 6, 9, 12, 15, 18, 20) |
| Incline rapid | 7 buttons: 1, 3, 5, 7, 9, 12, 15 |
| Fan | Fan on or off (optional) |

The earlier ST725 manual for this machine family prints "the maximum incline position is 12" in this same sentence, which contradicts its own incline rapid key list. This manual prints 15, which matches everything else.
