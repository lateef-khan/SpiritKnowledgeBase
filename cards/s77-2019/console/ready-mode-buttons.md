| Key | Ready mode behaviour |
|---|---|
| Safety key | Fit it in the right position to power the computer on. Pulling it away shuts the computer down automatically. |
| Start | Starts the treadmill after a **3 second** countdown on the display. In MANUAL it starts at MIN SPEED; in a program it starts at the program's preset value. |
| Stop | No function |
| Enter | Changes each function. MANUAL sets the time; a preset PROGRAM sets time and speed; Heart Rate Control 1 and 2 set time, age and target heart rate; User Program 1 and 2 set time, speed and incline. It also swaps between the incline and speed profiles. |
| Fast, Slow, Up, Down | No function until you enter a setting |
| Speed rapid | 2, 3, 4, 5, 7, 9, 12 (metric 3, 6, 9, 12, 15, 18, 20) |
| Incline rapid | 1, 3, 5, 7, 9, 12, 15 |
| Fan | Fan on or off |
| Display | Cycles the message window during exercise |

The console has four window modes: **OFF** with no safety key, **READY** with the key in, **SLEEP** which any key wakes, and **RUN**.
