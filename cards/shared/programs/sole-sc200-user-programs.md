The customizable User programs (User 1, User 2) save a workout you build yourself.

1. Select User 1 or User 2, then press Enter. A saved program runs as it is; otherwise you can enter a username: the letter A blinks, the Level Up button steps to B and the Level Down button steps to Z. Press Enter per letter (maximum 7 characters), then Stop when finished.
2. If a program is already stored, Start or Enter at the welcome screen asks Run Program? Select Yes to run it, or No and then delete the saved program; deleting is required to build a new one.
3. Enter Age, then Weight, then Time with the Level keys, pressing Enter after each.
4. The first column blinks: set the level for the first segment with the Level keys and press Enter for the next segment. Each new segment starts at the previous segment's level. Continue until all twenty segments are set.
5. The Message Window offers Start to begin (which saves the program) or Enter to modify it; Stop exits to the start-up screen.
6. During the workout the Level key changes the workload for the present column only; the next column returns to the preset level.
