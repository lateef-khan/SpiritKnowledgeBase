U1 and U2 work identically, keep a name, and build resistance plus incline profiles (steps run 11-20). 1. Press User 1/2: a saved name shows in the welcome message ('Name – A' if none, 'Name – David' in the example; the first letter blinks). Change letters with Up/Down, Enter per letter, Stop keeps/saves the name. 2-4. Enter Age, Weight, Time (Up/Down or numeric keypad). 5. Set Max Level (factory 7). 6-8. Build the workload profile column by column to all twenty segments. 9. Build the Incline profile the same way. 10. Enter saves ('New program saved'), then Start or modify; Stop exits to start-up.
