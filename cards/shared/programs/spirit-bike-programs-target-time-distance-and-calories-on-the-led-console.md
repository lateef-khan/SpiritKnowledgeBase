The four 2023 residential bike manuals - XBR25, XBR55, XBU55 and XBR95 - head this **Countdown Mode**
and print it identically.

**A Target program is set a Target Time, a Target Distance or a Target Calories figure. When the
program begins that item counts down; once it reaches zero the program ends.**

1. Press **PROGRAM** to select **TARGET PROGRAM**, then **Enter**.
2. Press **PROGRAM** to choose **Target Time**, **Target Distance** or **Target Calories**, then
   **Enter**. You may instead press **Start** to run it on the defaults.
3. **Age** (default **35**), then Enter.
4. **Body Weight** (default **155 lbs / 70 kgs**), then Enter.
5. The target item, then Enter:
   - Target Time defaults to **5 minutes**
   - Target Distance defaults to **3.00 mile**
   - Target Calories defaults to **300**
6. Press **Start**.

The manual repeats its calorie caveat here: no exercise machine can give an exact calorie count, and
the display is for comparing one workout with another.

**Nothing else in the family has these three.** The XBR95 2016, 2018 and 2021 have a **Calories** key
instead, which adds a pedal-RPM step and a three-minute warm up and cool down that Target Calories
does not - see `spirit-bike-programs-calories-program-counts-a-calorie-goal-down-to-zero`. The XBR25
2019, XBR55, XBU55 and the two ENT touchscreens have neither.

**The Spirit air bike prints its own version of these three modes** with different defaults - see
`spirit-bike-programs-air-bike-target-time-distance-and-calories-modes`.
