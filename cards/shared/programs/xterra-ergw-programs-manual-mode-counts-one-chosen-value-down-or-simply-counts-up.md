There are 2 options in MANUAL mode:

**A. Count one value down.** When you select MANUAL, TIME flashes. Press UP to set the value of TIME
to count down and ENTER to confirm - or press ENTER to skip to the next function. You can set
DISTANCE, STROKES, CALORIES or PULSE instead. **You can only set the value for one function to
count down**: "if you have set the target value for TIME, then DISTANCE can't be set." Press START.

**B. Count up.** Press START and the computer counts the values of your workout.

The STOP icon disappears when you start. **When the function you selected counts down to zero, or
you press STOP, the computer stops and displays the average value.** The ERG550W adds that
TIME/500M, SPM, WATTS and PULSE then show their averages, and "the drag force value will display in
the matrix".

| Function | Range | Increment |
|---|---|---|
| TIME | **1 min ~ 99 min** | 1 minute |
| DISTANCE | **0 ~ 99900 meters** | 100 meters |
| STROKES | **0 ~ 9990 strokes** | 10 strokes |
| CALORIES | **10 ~ 9990 Cal** | 10 calories (the ERG600W page misprints "10 strokes increments") |
| PULSE | **30 ~ 240** BPM, wireless chest strap only | 1 BPM - see the target pulse card |

TIME/500M (average time to reach 500 meters), SPM and TOTAL STROKES (0 to 9999) are readouts. The
ERG550W's WATT readout runs 0 to 999; the ERG600W shows calendar, temperature and clock in sleep.

**The ERG650W prints the same functions page but has no Manual mode**; its targets are set through
Target Single. The ERG800W's count-down programs have defaults and narrower ranges. See `see_also`.
