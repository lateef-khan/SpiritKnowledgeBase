**Twenty segments on these machines.** The 2016, 2019 and 2023 B94/R92 manuals print
**eighteen** for the same procedure. If you are on a 2011, 2013 or 2015 machine the number is twenty.

1. Select **User 1** or **User 2**, then press Enter. If a program is already saved there it is
   displayed and you are ready to begin. If not, you can enter a username: the letter "A" blinks in the
   message window; use the Level buttons to pick each letter (Up switches to "B", Down switches to "Z")
   and press Enter for each. **Maximum 7 characters.** Press Stop when finished.
2. If a program is already stored, pressing Start or Enter at the welcome message prompts
   **"Run Program?"**. Use the Level up/down keys to select Yes or No. Selecting No then asks whether to
   delete the saved program. **You must delete the current program to build a new one.**
3. Enter your **Age**, then Enter.
4. Enter your **Weight**, then Enter.
5. Enter the **Time**, then Enter.
6. The first column blinks. Set the level for that segment and press Enter. Each next segment starts at
   the level of the one before it. Repeat until all **twenty segments** are set.
7. The message window then offers Start to begin and save the program, or Enter to modify it. Pressing
   Stop exits to the start-up screen.
8. Pressing Level up/down during the program changes only the level for the **current column**. When the
   profile moves to the next column it returns to the preset work level.
9. Press **Display** to scroll through the data in the message window.
10. When the program ends the message window shows a workout summary for a short time, then returns to
    the start-up display.

**The 2011 manuals swap the two prompts in the printed text.** Step 3 reads "enter your Age. You may
enter your **weight**..." and step 4 reads "enter your Weight. You may adjust the **age** number...".
The console asks for Age first, then Weight; the 2013 and later manuals print it correctly.

The 2011 manuals also name the keys "Level Up and Down"; 2013 and 2015 print the same keys as
Level up/down arrows. Same keys, same steps.
