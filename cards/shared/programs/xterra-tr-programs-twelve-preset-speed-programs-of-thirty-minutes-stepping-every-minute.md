**Twelve preset programs, P1 to P12, each with its own speed profile.** The book prints
a picture of each profile under the heading *Preset Program Profiles* with a key reading
*Speed*; **no speed figure, segment count or level is printed for any program**, so the
profiles cannot be tabulated from the manual.

**To select and start a preset program:**

1. Make the machine ready - the TR150 book says "make sure the machine is in the read mode" (sic); the TR260 and TRX1000 books say "make sure the machine is in the stop position, single press Stop to enter into resetting state". Press **Program** to choose the desired
   program (P1, P2 ... P12), then press and release **Start** to begin the program with
   default values.
2. Each program runs **30 minutes** (the preset value). **After every minute during the program the speed is adjusted automatically.** The speed can
   also be adjusted manually at any time during the program. **3 seconds before the end
   of a program a buzzer sounds three times, then the running belt comes to a stop.**

The **TR260 page prints a contradiction**: its key under the twelve pictures reads *Incline*
and each picture carries a second trace, while the sentence under them says "each program has
its specific **speed** variations" and step 2 speaks only of speed. The TR150 and TRX1000
keys read *Speed*. The TR260 book never says whether its programs change the incline.

The TR200 prints the same twelve programs but says the speed steps **every three minutes**;
that is a different figure and has its own card (see `not_to_be_confused_with`).

The Dyaco service manuals corroborate the count: the TR150 and TR260 books list the PROGRAM
window's work range as "0, P1 to P12" and say a pre-set program "can set using time and speed"
and "starts at program preset value in PROGRAM".

On the TR150 page the text layer carries axis digits (1 to 30 across, 1 to 5 up) that are
**not printed** on the page; they are ghost text and were not carded.
