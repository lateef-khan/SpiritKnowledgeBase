The WF80 generation pairs the newer 60%/80% targets with the older Auto-Pilot feature.

- **Weight Control (HR-1)** maintains heart rate at **60%** of maximum; **Cardiovascular (HR-2)** at **80%**. Maximum is 220 minus the entered age; the target is a suggestion for normal healthy individuals (a higher entered age lowers it).
- **The Heart Rate Control program automatically controls incline** (stated on the Target Heart Rate page; this chapter prints no speed-and-elevation paragraph).
- **Auto-Pilot** is present: the HR2 button doubles as it; see `sole-treadmill-programs-heart-rate-autopilot`.

**Setup.** Chest-strap transmitter only, never the grip bar; the program will not start without a strong, steady heart-rate value. Press the **HR1 or HR2 button**; the Pulse window blinks the default target (adjust or accept); the Calorie window blinks **body weight**; the Pulse window blinks **age** (age changes the target); the Time window blinks; **press Start**. During the program the **elevation/incline buttons change the target**.

The WS/WTT8 siblings keep Auto-Pilot but target 70%/90%: see `sole-treadmill-programs-hrc-70-90-autopilot`.
