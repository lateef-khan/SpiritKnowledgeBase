Press each program button to scroll the profiles in the dot matrix (incline profile shows with the Display key), Enter selects and customizes; or press Start to bypass programming on the saved settings. Last-entered Age and Weight persist as the new defaults. Single-model books still print 'Both models will show the incline profile' — inherited boilerplate, not a second model.
