**The E55 builds twenty segments where its siblings build eighteen.** Otherwise identical to the shared 18-segment procedure: 7-character username ('A' blinks; Level arrows; Stop finishes), Run-Program/delete-to-rebuild, Age/Weight/Time, resistance profile then incline profile column by column, Start saves, Enter modifies, Stop exits, present-column-only mid-program changes, Display scrolls, summary ends.
