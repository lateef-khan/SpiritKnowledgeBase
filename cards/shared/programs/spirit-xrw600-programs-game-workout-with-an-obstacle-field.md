Choose GAME workout mode with the **MODE** button, then press **Start/Stop** to begin.

**"The goal of the Game Workout Mode is the manuveur your user dots through an obstacle field by
rowing faster or slower to raise/lower the use dot sprite."** *(printed as shown, misspellings and
all)*

- **Three dots at the left side represent the user position**, and the image **shifts one profile
  left per second** and continues to scroll.
- **The position of the user will not shift** horizontally. **The faster the user rows, the higher
  the user's position.** **When there is no input, the position goes down to the lowest.** The height
  of the user's position is equivalent to the speed the user strokes.
- **The time for the game workout starts counting down from 5 minutes and ends when time is up.**

**The Game duration is fixed at 5 minutes** and takes no user setting. Beyond the sentence above the
manual states no score, no collision rule and no win condition.

**The CRW800 books describe the same screen without that goal sentence** - no obstacle, no sprite,
nothing to steer through - and write "the faster the user **stroke**" where these write "rows". See
`crw800-2024-programs-game-workout`. The obstacle field belongs to the XRW600 page only; do not
carry it onto a CRW800.

**The XRW600's own service manual does not print the goal sentence either.** The XRW600 2019
service manual (the DW400-YR002 book) prints the Game page in the CRW800 wording - the four
numbered points above, "the faster the user **stroke**", no obstacle field, no sprite. So within the
XRW600's two books the obstacle-field goal appears only in the owner's manual. Both are recorded;
neither says the other is wrong, and nothing in the service book contradicts the four points.
