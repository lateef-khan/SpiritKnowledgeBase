**The HR key runs one program and asks you for the heart rate directly.** There is no 65% or 80%
preset and no HR interval, unlike the 4.0 bikes.

1. Press the **HR** key, then **Enter**.
2. Enter your **Age** with the Up and Down keys or the numeric key pad, then Enter.
3. Enter your **Weight**, then Enter.
4. Enter the **Time**, then Enter.
5. Adjust the **Heart rate Level** - *"the heart rate level you will experience during the program"* -
   then Enter.
6. Press **Start**; Enter goes back to modify, and Stop steps back one screen during data entry.
7. **Up or Down during the program changes your target heart rate at any time.**
8. The adjacent Display key scrolls the data in the message window.
9. When the program ends press Start to run it again, Stop to exit, **or the Facility key to save the
   program you just completed as a custom user program**.

**These books print no training-zone page**: no 220-minus-age formula, no percentage guidance and no
Borg scale, so the only heart rate arithmetic in them is the Set Up menu's note that age feeds the
VO2 and heart rate programs (`spirit-bike-programs-no-target-heart-rate-zone-page`).

The 7.0R and 7.0U 2025 books and the Dyaco MED 7.0R 2021 edition print these nine steps in the same
words; so do the 7.0T treadmill and the 7.0S/7.5S steppers, which are the same Dyaco console family
on other product lines (`spirit-mt200-programs-heart-rate-program`,
`spirit-rehab-stepper-programs-heart-rate-program-asks-for-a-heart-rate-level`).
