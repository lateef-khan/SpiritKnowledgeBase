1. Select **User 1** or **User 2** via the Program key, then press **Enter**. The dot matrix
   shows a single row of dots at the bottom unless a program is already stored.
   If a program is stored under that key it is retrieved. If not, you may program your first
   name: the display flashes the letter **"A"**; press the up key for "B", the down key for
   "Z"; press Enter after each letter and repeat until all letters are entered
   (**7 characters maximum**). When your name is displayed, press **Stop** and it is stored
   under User 1 or User 2.
2. The display blinks **Age (default 35)**; adjust, press Enter.
3. **Body Weight (default 150 lbs)**; adjust, press Enter.
4. **Time (default 30 minutes)**; adjust, press Enter.
5. The **preset top speed of the program (0.5 mph or 0.8 kph)**; adjust with the Speed keys,
   press Enter. This limits the highest speed the program can reach.
6. The **preset top incline (0%)**; adjust with the Incline keys, press Enter.

Press **Start** to begin, or **Enter** to go back one level.

**The book never says how the segment profile of a user program is built** - the pages give
the name and default entry only. The TR6.6 counts "three user defined programs" in its
summary but names only User 1 and User 2 here.
