"There are **24 different programs** to choose from for training", grouped as "**7 basic
workout programs**: Manual, Pre-Programs, Watt Program, Body Fat Program, Target Heart Rate
program, Heart Rate Control Program and User Program". Counted out: 1 manual + 12 presets
(P2-P13) + 1 watt + 1 body fat + 1 target heart rate + 4 heart rate control (55/65/75/85%)
+ 4 user = 24.

**Levels:** "The programs have **24 levels** of work displayed in **8 bars** in each column.
Each column represents 1 minute workout (unless time is changed to a new value for count
down) and each bar represents 3 levels of work."

After power-up, use UP/DOWN to select a program and press ENTER; the first parameter (Time)
flashes, and you step through the parameters with UP/DOWN and ENTER, then press START/STOP.
"Time and Distance can not be set up in the same workout."

The RSX1500 book says "**6** basic workout programs" and leaves Body Fat out of the list,
yet its 2021 printing carries a Body Fat Program page (its 2017 printing does not); the
page wins, the count is stale. The FS1.5 is a cut-down version of this console - 13
programs, 16 levels, no watt program; see `see_also`.
