There are **two** customisable User programs, **U1 and U2**, which operate identically. You can build
one from scratch or **save any preset program you complete as a custom program**.

1. Select **U1** or **U2**, then press **Enter**. If a program is already saved there it is displayed
   and you are ready to begin. If not, you may enter a username: the letter **"A"** blinks, **Level
   Up** switches to "B" and **Level Down** switches to "Z". Press Enter for each letter. **Maximum 7
   characters.** Press **Stop** when finished.
2. If a program is already stored, pressing Start or Enter at the welcome message prompts **"Run
   Program?"** - Level Up/Down chooses Yes or No. Choosing No then asks whether to delete the stored
   program. **You must delete the current program to build a new one.**
3. Enter your **Age**.
4. Enter your **Weight**.
5. Set the **Time**.
6. Set the **Max Resistance Level** of the program, then Enter.
7. The first column blinks (`SEGMENT > 1`). Set its resistance with the **Level Up** key, then Enter.
8. The next segment starts at the previous segment's level. Repeat until **all twenty segments** have
   been set.
9. The Message Center says **"PROG SAVED"** and offers to start or modify the program. **Stop** exits
   to the start-up screen.

*The XE795 2021 manual prints step 2 twice, once as the tail of step 2 and again as step 3, so its
list runs to ten numbered steps for the same nine actions. Both printings of that manual, February
and November, carry the duplication.*

**The XE195 has no custom program at all.** The XE395 2023 and XE795 2023 print these same steps but
name the slots **Custom 1 and Custom 2** and drop the Max Resistance Level step. The
XE100/XE200/XE300, XE350 and XE550 use **User 1 and User 2** with an unlimited-length name and no
"Run Program?" prompt.
