**The E95s programs stride, not incline.** 1. Press the program button, then Enter. 2-4. Enter Age, Weight, Time (Level arrows). 5. Set Max Level (highest colored segment/box). 6. Choose to turn on the stride profile — off leaves manual stride live but stops automated changes; Enter finishes. 7. Start begins; Stop steps back. 8. Level or Stride arrows adjust resistance or stride length mid-program. 9. In Manual-mode wording, DISPLAY changes the shown data. 10. A summary ends the session.
