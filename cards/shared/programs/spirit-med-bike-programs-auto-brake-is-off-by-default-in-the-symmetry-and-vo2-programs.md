**This is the 7.0 bikes' rule - off by default in Symmetry and VO2.** The 8.0U and 8.5R touchscreen
bikes print a different pair, Symmetry and Isokinetic; see the linked card.

*"The 7.0R has built-in sensing technology and software that will automatically stop the flywheel
when it senses the user is attempting to stop pedaling. This auto-braking software can be disabled
during program set up before beginning a session. The Auto-Brake is set to off for the Symmetry and
VO2 programs and can be turned on during program set up."*

So every program's setup - Manual, the three presets, Facility, Constant Power, Isokinetic and
Symmetry - carries a *"turn the auto-brake on or off then press enter"* step, and the Symmetry page
explains its own default: *"since the auto-brake may be activated with severe asymmetry the
auto-brake default setting is off."* **The VO2 test setup steps, oddly, print no auto-brake prompt at
all**, even though the setting-up page names VO2 as the other program where it is off.

Why it matters is on the safety page: the flywheel has no freewheel and is directly connected to
the pedals, so with the auto-brake disabled a spinning flywheel can be hard to stop at high RPM, and
a manual brake lever is provided.

The 7.0R and 7.0U 2025 books and the Dyaco MED 7.0R 2021 edition print this in the same words.
