The manual program works as the name implies, manually: **you control the workload yourself, not the
computer.**

1. Select **Manual** (on the 7.0T, press the manual key then the enter key).
2. Enter the **time** for the program. On the 7.0T use the up and down keys or the numeric key pad, then
   press enter to accept. On the 8.0T choose the preferred workout time on the touch screen.
3. Press **Start** to begin.

**Time is the only value the program asks for.** All data calculations use the patient information from
the set up function - on the 7.0T, the set up key at the top left of the console.

During the manual program you can scroll the data in the message window with the display key, and on the
7.0T you can switch between the speed, incline and track displays with the display key beside the dot
matrix. When the program ends you may press start to run it again, stop to exit, or (7.0T) the facility
key to save what you just did as the facility program.

The 4.0T's Manual program is set up differently: it asks for age, weight and time.

**Both MT200 owner's manuals print the 7.0T version of this word for word** - the
2010-generation manual on printed page 16, the 2022-generation manual on printed page 27.
On the MT200 you press the **manual** key then the **enter** key, exactly as on the 7.0T.

**The 7.0T 2025 owner's manual (Revision 01.10.25) prints this page word for word** as the 2026 book does; only the folio differs.
