The User programs let you build and save your own workout.

1. Select **User 1** or **User 2**, then press Enter. If a program is already saved there it is displayed and you are ready to begin. If not, you can enter a username: the letter "A" blinks in the Message Window; use the Level buttons to pick each letter (Up switches to "B", Down switches to "Z") and press Enter for each. **Maximum 7 characters.** Press Stop when finished.
2. If a program is already stored, pressing Start or Enter at the welcome message prompts **"Run Program?"**. Use Level up/down to select Yes or No. Selecting No then asks whether to delete the saved program. **You must delete the current program to build a new one.**
3. Enter your **Age** with the Level up/down keys, then Enter.
4. Enter your **Weight**, then Enter.
5. Enter the **Time**, then Enter.
6. The first column blinks. Set the level for that segment and press Enter. Each next segment starts at the level of the one before it. Repeat until all **eighteen segments** are set.

**Eighteen is right only for the 2016, 2019 and 2023 B94 and R92.** The B74, R72 and the 2011 and 2013 B94 and R92 manuals print **twenty** segments for the same procedure, and the LCB and LCR use a different Custom program entirely.
7. The Message Window then offers Start to begin and save the program, or Enter to modify it. Pressing Stop exits to the start-up screen.
8. Pressing Level up/down during the program changes only the level for the **current column**. When the profile moves to the next column it returns to the preset work level.
9. Press **Display** to scroll through the data in the Message Window.
10. When the program ends the Message Window shows a workout summary for a short time, then returns to the start-up display.
