1. Select the desired **program button**, then press **Enter**.
2. The message window prompts for **age, weight, time and max level**. Enter each with the up and
   down keys **or the numeric key pad**, pressing **Enter** to accept and move on. **Max level refers
   to the top resistance level setting for the program.**
3. Press **Start** to begin, or **Enter** to go back and modify. **Stop** goes back one level or
   screen at any point during data editing.
4. During the program the **Enter** key scrolls the data in the message window.
5. When the program ends, **Start** repeats it, **Stop** exits, **or the completed program can be
   saved as a custom program** by pressing a User key and following the message window.

## Why the picture does not change, and why one press may do nothing

*"The profiles shown in the dot matrix are merely pictures of the whole profile and will not change
in size when the work level keys are pressed."*

**The level keys change the peak level of the program, not the level of the segment you are in.**
The message window shows both: the level setting for the current segment, and the maximum level for
the peak of the profile.

*"Pressing the work keys actually change the peak level of the program not the current segment
level. **You may need to change the peak setting several times before the current segment
increases.**"*

That last sentence is the answer to "I pressed up and nothing happened". It is printed on all three
machines and has no counterpart in the Spirit stepper manuals, whose Up/Down shifts the whole
profile at once - see
`spirit-stepper-programs-preset-setup-asks-age-weight-time-and-a-max-level`.

**Pressing Start instead of Enter skips data entry** and uses the data from the **Set Up menu**
rather than a per-program default.
