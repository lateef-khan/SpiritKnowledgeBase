**The air bike console has no workout profiles.** There is no Hill, Fat Burn, Cardio, Strength,
Interval profile, no user program, no custom segment program and no fitness test. What it has is
eight modes, seven of which have their own **Quick Mode button** on the console face:

| Mode | How it starts |
|---|---|
| Quick Start | Just start pedalling |
| Interval 20/10 | INTERVAL 20-10 button |
| Interval 10/20 | INTERVAL 10-20 button |
| Interval Custom | INTERVAL CUSTOM button |
| Target Time | TARGET TIME button |
| Target Distance | TARGET DISTANCE button |
| Target Calories | TARGET CALORIES button |
| Target Heart Rate | TARGET HR button |

The rest of the keypad is **Bluetooth**, **▲/▼**, **Enter**, **Start** and **Stop**. The Quick Mode
buttons go into their mode immediately - there is no program menu to scroll.

**The AB900 2018 service manual carries the same eight modes and the same console face**: its
Display Windows drawing labels the seven Quick Mode Keys - TARGET TIME, TARGET DISTANCE, TARGET
CALORIES and TARGET HR KEY down the left, INTERVAL 20-10, INTERVAL 10-20 and INTERVAL CUSTOM down the
right - plus the BLUETOOTH key and a Control Keypad of ▲/UP, DOWN/▼, START, STOP and ENTER, and its
Console Operation pages describe Quick Start and the seven keyed modes and nothing else.

**Both owner's manuals describe these eight modes in the same words**, sentence for sentence. Every sentence
of the AB900's program pages was matched against the AB950's; the only differences found are three
wording changes, none of which changes a figure or a step:

- `chect strap` in the AB900 becomes `chest strap` in the AB950 - a typo fixed.
- "Pressing the **Stop button**" becomes "Pressing the **STOP key**".
- `pedalling` becomes `pedaling`.

**A raw n-gram comparison of the two program chapters scores far lower than that**, at roughly 63%
overlap, but the shortfall is entirely the AB950's two-column layout: `pdftotext` splices text from
the neighbouring column into the middle of sentences, so phrases break at column boundaries that do
not exist on the printed page. Do not read that figure as a difference between the machines.

**Where the two manuals genuinely differ is outside the program pages.** The AB950 adds a chest strap
fitting page, a chest strap interference page, a heart rate exertion page with the 220-minus-age
formula, and an RPE scale; the AB900 has none of these - see
`spirit-bike-programs-air-bike-2018-prints-no-heart-rate-training-page`.

**Do not answer an air bike question from an upright or recumbent bike card.** Hill, Fat Burn,
Cardio, Strength, Interval, Constant Watt, Custom, HR1/HR2 and the YMCA fitness test belong to the
CR800, CU800, CR900 and CU900 consoles. An air bike has none of them, and it could not run a level
program even if it wanted to - see
`spirit-bike-programs-air-bike-has-no-resistance-levels-because-the-fan-sets-the-load`.
