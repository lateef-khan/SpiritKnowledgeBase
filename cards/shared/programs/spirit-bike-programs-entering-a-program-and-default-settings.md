When you enter a program you have the option of entering your own personal settings. To work out
**without** entering new settings, just press **Start**. That bypasses the programming of data and
takes you directly to the start of your workout, using the default or previously saved settings.

To change the personal settings instead, follow the instructions in the message window.

**The CR900ENT and CU900ENT add a range for each field**, because the touchscreen shows one - see
`spirit-bike-programs-touchscreen-setup-defaults-age-thirty-weight-seventy-max-level-five`.

**The three 800ENT manuals do not print this paragraph.** The CU800ENT 2022 and CR800ENT 2023 say
only "Customize the program on the following screens by entering your data, or press the Start
button to begin the program using the default settings"; the CU800ENT 2024 drops it entirely and
describes the Program Setup page instead.
