**How it works.** Heart Rate Control uses the **speed and incline systems** to adjust heart rate; elevation changes move heart rate more efficiently than speed alone. The program changes speed and elevation gradually to the programmed target.

**The two programs.** Weight Control (**H-1**/**HR-1**) maintains heart rate at **70%** of maximum; Cardiovascular (**H-2**/**HR-2**) at **90%**. Maximum heart rate is 220 minus age, entered during setup. The target is a suggestion for normal healthy individuals; entering a higher age lowers the target.

**Setup.** CAUTION: chest-strap transmitter only, never the grip bar; the program needs a strong, steady heart-rate value (some books refuse to start without one). Steps: press the **HR1 or HR2 button**; the Pulse window blinks the default target (adjust or accept); the Calorie window blinks **body weight** (adjust or accept); the Pulse window blinks **age** (adjust or accept — age changes the target); the Time window blinks (adjust); **press Start**. During the program the **elevation/incline up/down buttons change the target heart rate**.

**Auto-Pilot** (the HR2 button doubles as it) is on `sole-treadmill-programs-heart-rate-autopilot`. The incline-only TT8 consoles differ: see `sole-treadmill-programs-hrc-70-90-incline-only`. The 60%/80% generation differs: see `sole-treadmill-programs-hr-60-80-menu` and `sole-treadmill-programs-hrc-60-80-autopilot-wf80`.
