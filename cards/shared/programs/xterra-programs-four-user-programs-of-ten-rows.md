"Four User Programs allow the user to create their own personal programs."

1. Select "**User**" with UP/DOWN and press ENTER.
2. "Time" flashes - set it with UP/DOWN, press ENTER, and continue through the parameters
   you want (a target time locks out distance).
3. After the parameters, **row 1 of the profile flashes**. Use UP/DOWN to set its level and
   press ENTER; repeat "until finished (**10 times total**)".
4. Press START/STOP to start the workout.

Any parameter counting down to zero beeps and stops the workout; press START to continue.
The FS1.5 has one user program built the same way; see `see_also`.
