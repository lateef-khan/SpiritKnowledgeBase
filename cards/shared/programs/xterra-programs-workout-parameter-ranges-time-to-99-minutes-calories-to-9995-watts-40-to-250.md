"More About Workout Parameters", as printed:

| Parameter | Setting range | Default | Increment | Description |
|---|---|---|---|---|
| Time | 0:00 - 99:00 | 00:00 | +/- 1:00 | At 0:00 time counts up; set to 1:00-99:00 it counts down to 0:00 |
| Distance | 0.00 - 999.0 | 0.00 | +/- 1.0 | At 0.00 distance counts up; set to 1.0-990.0 it counts down to 0.00 |
| Calories | 0 - 9995 | 0 | +/- 5 | At 0 calories count up; set to 5-9995 they count down to 0 |
| Watt | 40 - 250 | 100 | +/- 5 | "User can set watt value only in Watt control program" |
| Age | 10 - 99 | 30 | +/- 1 | Target heart rate is based on age; when heart rate exceeds the target the heart rate number flashes |
| Pulse | 60 - 220 | 90 | +/- 1 | Setting parameter for Target Heart Rate |

Notes printed with the table: "Some parameters are not adjustable in certain programs. Time
and Distance can not be set up in the same workout." When any parameter counts down to zero
the console beeps and the workout stops; press START to continue toward the unfinished goals.

The FS1.5 prints the same table without the Watt row and with calories 0-9950 in steps of
50; see `see_also`. The SB4500 uses different ranges.
