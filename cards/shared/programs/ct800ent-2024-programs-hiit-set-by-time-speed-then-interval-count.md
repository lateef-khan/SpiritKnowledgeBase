1. Select this program to begin customizing it with your personal data.
2. Set **Sprint time / Sprint Speed** and **Rest time / Rest speed**.
3. Set the **number of intervals** you want to do. **One interval stands for 1 Sprint and 1 Rest
   segment.**
4. Press **Start this program**. The program starts with a **3-minute warm-up period with the speed
   set to 50% of the sprint speed** selected previously. You can manually adjust the speed during
   warm-up if you wish.

The setup screen shows Sprint Time, Sprint Speed, Rest Time and Rest Speed as separate panes, then
an **Intervals** slider (illustrated at 20) and an **Estimated Time** readout.

**This manual prints no minimum and no maximum for any of those values.** Do not carry a range
across from another Spirit console: the 2022 touchscreen defaults to **8 intervals** and allows
**20 to 90 second** periods (`ct800ent-2022-programs-hiit-eight-intervals`), and the 2024 button
consoles default to **10 intervals**, allow **3 to 15**, and take **30 to 60 second** sprints
(`ct900-hiit-program`). Neither figure is stated for this console.
