These consoles offer **two** user slots with **no name entry** (naming arrives with the 2011/2013 consoles).

1. **Select User 1 or User 2** via the PROGRAM key (keypad books: PROGRAM keypad), then press Enter. The dot matrix shows a single row of dots at the bottom unless a program is already stored.
2. The **Time** window flashes. Adjust up from **10 minutes** if desired and press Enter — **this is a must to continue even if time is not adjusted**.
3. The Calorie window blinks a **body weight** value. Enter it and press Enter.
4. A window blinks an **Age** value (Calorie window on basic books, Pulse window on keypad books). Adjust and press Enter.
5. The **first column (segment) blinks**. Set the **speed** for segment 1 with the Fast/Slow (rapid) keys, press Enter, and repeat for every column. The first column then blinks again for **incline**: repeat the same process for all incline segments.
6. **Press Start to begin the workout and also save the program to memory.**

The UF80, VS73/S77, VTT8, WF80/F83/F85, WS73/S77 and WTT8 books add that **the previous segment value is carried over** to each new segment while programming. The basic 2006, VF63, seven-preset and VF80 books do not print that sentence. The S73/S77 book numbers the incline pass and Start as STEPs 6-7 instead of 5-6 without changing the content.
