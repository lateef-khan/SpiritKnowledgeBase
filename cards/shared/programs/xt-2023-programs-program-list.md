All five 2023 XT owner's manuals say the treadmill has **eight different programs** designed for a variety of workouts. None of them lists which eight; these are the programs the manuals document by name:

| Program | What it is |
|---|---|
| Hill | Preset pyramid profile |
| Fat Burn | Preset sustained-effort profile |
| Cardio | Preset profile with fluctuations |
| Strength | Preset build-and-hold profile |
| HIIT | Preset high/low intensity intervals |
| Fusion | Cardio and strength intervals |
| 5K | Distance run program |
| 10K | Distance run program |
| Target Time / Target Distance / Target Calories | Countdown to a goal you set |
| CUSTOM 1 and CUSTOM 2 | Two user programs you build and save |

**The XT185 has no Heart Rate program.** Its owner's manual has no Heart Rate Monitoring chapter and no Heart Rate Program section at all. The XT285, XT385, XT485 and XT685 each add a heart-rate-controlled program with four target levels - 55%, 65%, 75% and 85% of maximum heart rate.

The two families also count the presets differently:

- The **XT185 and XT285** manuals say "These eight programs have factory preset work level profiles."
- The **XT385, XT485 and XT685** manuals say "Six of these programs have factory preset Speed and Incline level profiles", and add that the treadmill "offers eight factory preset programs, two custom user defined programs, three target programs and one Manual program." That last sentence is not printed in the XT185 or XT285 manual.
