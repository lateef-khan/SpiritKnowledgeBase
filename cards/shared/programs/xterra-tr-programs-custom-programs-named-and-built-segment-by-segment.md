1. Press **Enter/Program**, use **Speed up/down** to select **CUSTOM PROGRAM**, press
   Enter/Program to display **CUSTOM1**; press up/down to select **CUSTOM2**; confirm with
   Enter/Program. The dot matrix shows a single row of dots at the bottom unless a program is
   already stored. If one is stored under that button it is retrieved. If not, you may enter
   your first name: the Message Window flashes **"A"**; an up key gives "B", a down key gives
   "Z"; press Enter/Program after each letter, repeat for all letters (**7 characters
   maximum**), then press **Stop** to store it under CUSTOM 1 or CUSTOM2.
2. **Age** - adjust, press Enter/Program. "This is a must to continue even if age is not
   adjusted."
3. **Body weight** - enter, press Enter/Program.
4. The Time Window and Message Window blink a **Time** value - adjust, press Enter/Program.
5. The **first column (segment) blinks**. Set its speed level with Speed up/down, press
   Enter/Program; the second column blinks; repeat until all segments are programmed. The
   first column then blinks again **for the incline programming**; repeat for all segments.
6. Press **Start** to begin the workout and **save the program to memory**.

**Note, as printed:** while in a User program, if you change the speed, all segment speeds
from there on also change - increase the current speed by 1 mph and the remaining segment
speeds increase by 1 mph; decrease by 0.5 mph and they decrease by 0.5 mph.

The book does not print the number of segments on this console.
