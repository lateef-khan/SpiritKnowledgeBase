The console offers Manual, Hill, Fat Burn, Cardio, Strength, Interval, two User and two heart rate programs.

Press each program button to scroll through the selections; the dot matrix window shows each program's profile. Press Enter to select a program and begin customizing, or press Start to skip setup and work out on the defaults. Then follow the Message Window prompts, which ask for Age, Weight, Time and, on presets, Max Level.

The last Age and Weight entered become the new defaults, so they only need re-entering when they change or someone else uses the machine. During data entry Stop steps back one screen.
