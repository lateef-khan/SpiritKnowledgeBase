Program 1 is the manual program: you pick the resistance level yourself (UP/DOWN during the
workout) and ride for a period of time, a number of calories or a distance.

1. Use UP/DOWN to select **MANUAL (P1)**.
2. Press **ENTER**.
3. **TIME** flashes - set it with UP/DOWN, press ENTER.
4. **DISTANCE** flashes - set it, press ENTER.
5. **CALORIES** flashes - set it, press ENTER.
6. **PULSE** flashes - set your target pulse, press ENTER. The computer alarms as soon as
   your heart rate reaches the preset figure.
7. Press **START/STOP** to begin.

Time counts down from a preset target to 0:00, distance to 0 and calories to 0; with no
target set they count up. When a target is reached the computer beeps and stops; press
START/STOP to keep going toward the next target.

The **default resistance level** the program starts at differs by book: 3 on the SB150,
SB250 and FS150; 7 on the EU150; the SB240 book prints no default. See `see_also`.
