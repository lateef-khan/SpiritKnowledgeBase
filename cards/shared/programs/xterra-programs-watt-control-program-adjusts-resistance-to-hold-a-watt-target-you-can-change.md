Select **Watt Control Program** with UP/DOWN and press ENTER. "Time" flashes first; set each
parameter with UP/DOWN and ENTER (a target time locks out distance), then press START/STOP.

"The computer will adjust the resistance load automatically depending on the speed to
maintain a constant watt value. **User can use UP / DOWN key to adjust the watt value during
workout.**" The watt target is set only in this program: range **40 to 250**, default
**100**, in steps of 5.

Any parameter counting down to zero beeps and stops the workout; press START to continue.

The SB250/EU150/SB240 watt program is different in that respect - its resistance is "not
adjustable" during the workout; see `see_also`.
