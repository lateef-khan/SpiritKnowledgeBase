The military fitness test page carries a block of body text, set in the same face as the headings,
that reads:

> These don't match the current doc Dyaco provided, but I don't have the images for these

It sits in the gap between the **Air Force** table on the left and the **Navy** table on the right,
on the page that also carries the **Army** and **Marines** tables. It is an editor's comment that
was never removed before the manual shipped, not an instruction to the reader.

**Treat the four tables on that page as unverified.** The comment says on its face that the values
printed did not match the source document Dyaco supplied and that the correct images were not
available. The values are recorded as printed on
`ct800ent-2024-programs-air-force-test-times`, `ct800ent-2024-programs-navy-test-times`,
`ct800ent-2024-programs-army-test-times` and `ct800ent-2024-programs-marines-test-times`, and all
four differ from what the 2024 CT800 and CT850 button consoles print.

The comment appears in both the CT800ENT and the CT850ENT 2024 owner's manuals, in the same place.
It does not appear in the 2022 editions.
