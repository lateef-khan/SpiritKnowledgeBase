1. Select the program you want, then press **Enter**.
2. Enter your **Age**, then press Enter.
3. Enter your **Weight**, then press Enter.
4. Set the **Time**, then press Enter.
5. Set the **Max Level**. This is the peak exertion level you will experience during the program, at
   the top of the hill. Press Enter.
6. Press **Start** to begin. **Stop** goes back one level, or screen.
7. Up or Down during the program changes the workload of the **entire profile**. The profile picture
   on the screen does **not** change - the manuals say this is deliberate, so you can see the whole
   profile at all times, because a redrawn picture would look distorted and would not be a true
   representation of the actual profile. When you make a change, the display shows the current
   column and the program maximum levels of work.
8. During the program the Scan key next to the data windows scrolls through the readings.
9. When the program ends the display shows a summary of your workout for a short time, then the
   console returns to the start-up display.

The key names differ by console. The CE800 2021, CE800 2023, CE850 2020, CE850 2022 and CES880 2025
scroll to the program with the **Program** button and scroll data with the **Up/Down Scan** button;
the CE800 2013, CE850 2016, CE900 2021 and CE900 2025 have per-program keys and use the **Display**
or **Scan** key beside the Message Window.

The CE800ENT is a touchscreen and does not print these steps - see
`ce800ent-programs-touchscreen-program-menu`.
