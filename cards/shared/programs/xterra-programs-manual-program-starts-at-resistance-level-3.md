"P1 is a manual program ... **The default resistance level is 3.**" You change it at any time
with UP/DOWN during the workout.

The EU150 book prints **7** for the same sentence, and the SB240 book leaves the sentence
out; see `see_also`. The Preset Program Profiles picture shows Program 1 MANUAL as a flat
row of three filled cells in the SB240 book, matching the level-3 default.
