*"The Power Distribution mode will measure the pedaling power throughout the cycle range and displays
the workload measurements on the screen. The screen will show a graph, workload value and power
distribution index for indicating the **lower limbs** power distribution so the user has a visual
feedback to improve the involved limb's strength."*

**Power Distribution answers a different question from Symmetry.** Symmetry compares the left leg
against the right; Power Distribution shows where in the crank revolution the power is produced.

**It is listed as one of the fifteen programs**, yet the manual describes it on the *Finishing Your
Workout* page beside the exercise summary, not among the program setups, and **states no scale for
the index, no target and no setup steps**.

*The same page states what the exercise summary does: "When the program ends, either by the set time
reaching zero or ending the program by pressing STOP at any time and then pressing Finish to end, a
summary is shown on the screen. The summary provides detailed data for the amount of time the user
exercised."*

The 8.0U and 8.5R 2025 books print this page word for word; the 8.5UE ergometer prints it for the
upper limbs (`85ue-2025-programs-power-distribution-through-the-crank-range`).
