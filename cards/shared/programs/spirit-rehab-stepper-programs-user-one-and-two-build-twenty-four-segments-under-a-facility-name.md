**Twenty-four segments, not twenty.** The Spirit CS800 and CRS800S steppers build twenty; these
machines build twenty-four. The two must not be swapped.

The **User 1 and User 2** programs let you build and save a custom program, or save any preset
program you complete as a custom one. **The User program allows you to further personalize it by
adding your facility name.**

## Designing and saving a new program

- Press either **user key**. The message window shows a welcome message containing the name you gave
  it if a program was saved before. Press **enter** to begin.
- The window shows **"name - a"** if no name is saved, or **"name - custom workout"** with the c in
  custom blinking if that name was saved. Use **up** and/or **down** to change each letter and
  **enter** to accept it. Press **stop** to keep an existing name, or to finish entering a new one.
- Enter an **age**, then enter.
- Enter a **weight**, then enter.
- Set the **time**, then enter.
- Set the **max level** - **the peak exertion level you will experience during the program** - then
  enter.
- The first column blinks; set the level for the first segment and press **enter**.
- Each next segment starts at the previous segment's level. Repeat **until all twenty-four segments
  have been set**.
- The window then tells you to press **enter** to save. It says **"new program saved"** and offers
  to start or modify the program. **Stop** exits to the start-up screen.

## Running a saved program

- Press the **user key**, then **enter**.
- **Enter time**, then press **start**.

*The last bullet of the build sequence is printed as "During the **facility** program you will be
able to scroll through the data in the message window by pressing the enter key" - on a machine
whose keys are labelled User 1 and User 2. All three books print it that way; recorded as printed.*

**These manuals never say how many characters the name may hold.** The Spirit steppers cap it at
seven; these books give no figure and none should be carried across.
