**These machines have one HRC program, not HR1/HR2.** 1. Select HRC, Enter. 2. Enter Weight (Up/Down or numeric keypad), Enter. 3. Enter Age, Enter. 4. Enter Time, Enter. 5. Adjust the HRC percent: default 70%, 60% or 80% selectable. 6. Select the Target heart rate Level. 7. Start begins; Stop steps back. 8. Up/Down during the program changes the target. 9. Display scrolls data; a summary ends the session.
