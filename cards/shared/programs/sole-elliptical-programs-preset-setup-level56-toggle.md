Press the program button (E20: or the Level 5/6 keys), then Enter. Enter Age, Weight and Time. Set Max Level — the peak exertion, the highest colored segment/box of the profile — and Enter. Then choose to turn on the incline profile; with it off you still control incline manually but automated incline changes stop. Start begins; Stop steps back. Incline/Level 5/6 adjust resistance or incline mid-program (current column only); Display scrolls data, and Enter switches the dot matrix between work and incline profiles; a summary ends the session.
