**The profile is built twice: twenty resistance segments first, then twenty stride segments.** Both
passes are required, and the manual numbers them as steps 8-9 and 10-11 of one sequence.

There are two customisable User programs, **User 1 and User 2**, which operate exactly the same way.
Both let you add your name.

1. Press the **User 1** or **User 2** key. The Message Center shows a welcome message containing your
   name if a program was saved before. Press **Enter** to begin.
2. If a program is already saved to **U1** or **U2** it is displayed and you are ready to begin. If
   not, the letter **"A"** blinks in the Message Window. Up steps to "B", Down steps to "Z". Press
   Enter for each letter, **maximum 7 characters**, then Stop.
3. If a program is already stored, pressing Start or Enter at the welcome screen asks **"Run
   Program?"**. Selecting **No** then asks whether to delete it. **You must delete the current
   program before you can build a new one.**
4. Enter your **Age**, then Enter.
5. Enter your **Weight** (Level +/- keys or the numeric key pad), then Enter.
6. Set the **Time**, then Enter.
7. Set the **Max Resistance Level**, then Enter.
8. The first column blinks (**SEGMENT > 1**). Set the **resistance** level with the Level Up key,
   then Enter.
9. Each next segment starts at the previous segment's resistance. Repeat **until all twenty segments
   have been set**.
10. You are then asked to adjust the **stride** level; the first column blinks again (**SEGMENT >
    1**). Set it with the Level +/- keys, then Enter.
11. Each next segment starts at the previous segment's stride level. Repeat **until all twenty
    segments have been set**.
12. Press **Enter** to save. The Center says **"PROG SAVED"**, then offers to start or modify.
    **Stop** exits to the start-up screen.

**A finished preset or Manual workout can be saved to a User key instead of building one by hand** -
see `xs895-programs-manual-mode-starts-at-level-one`.

*The XE895 elliptical builds its User programs the same way, resistance pass then stride pass, and
holds the fact in its own card - `xe895-2018-programs-user-programs-set-twenty-resistance-then-twenty-stride-segments`.
The two are kept apart because they are different product lines; nothing filters product line back
out at retrieval time.*
