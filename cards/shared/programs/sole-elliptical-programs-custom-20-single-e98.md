**One CUSTOM slot, not U1/U2, building twenty segments.** 1. Select CUSTOM, Enter; if empty 'A' blinks — Incline/Level arrows pick letters ('B' up, 'Z' down), Enter per letter, Stop finishes (max 7 characters). 2. A stored program offers Run Program? Yes/No; No asks to delete — deleting is required to build anew. 3-5. Menu-driven Age, Weight, Time. 6. Build the resistance profile to all twenty segments. 7. Build the incline profile the same way. 8. Start begins and saves, Enter modifies, Stop exits. Mid-program changes affect the present column only; Display scrolls data; a summary ends the session.
