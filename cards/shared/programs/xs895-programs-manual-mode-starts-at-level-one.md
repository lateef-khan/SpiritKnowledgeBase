*"The Manual program works as the name implies, manually. This means that you control the workload
and not the computer."*

1. Press the **Manual** key, then **Enter**.
2. Enter your **Age** with the Up/Down keys, then Enter.
3. Enter your **Weight**, then Enter.
4. Set the **Time**, then Enter.
5. Press **Start** to begin, or **Enter** to go back and modify.
6. **The program starts you at level one.** This is the easiest level and it is a good idea to stay
   there for a while to warm up. **Up** increases the workload; **Down** decreases it.
7. During the Manual program the **Enter** key scrolls the data in the Message Center.
8. When the program ends, **Start** repeats it, **Stop** exits, **or you can save the program you
   just completed as a custom user program by pressing a User key** and following the Message
   Center.

**Manual asks for no Max Resistance Level and no incline setting**, because there is no profile to
scale - unlike the presets, which ask for both; see
`xs895-programs-preset-setup-asks-max-resistance-level-and-incline-on-off`.

Pressing **Start** from the start-up display without choosing a program instead begins **Quick
Start**, where Time counts up from zero and the workload is set with the Level +/- buttons.
