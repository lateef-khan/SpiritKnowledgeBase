On the program setup page press **"Add Pattern"** to enter edit mode, then **connect dots to map the load** from easiest (bottom) to hardest (top). Each segment's duration follows the selected total time, settable right before start.

**Speed values are relative**: the maximum can change before each workout and all segments scale proportionally. **Elevation values are absolute and vary from -6 to +15** (the machine declines as well as inclines). The elevation pattern is optional. The flat-incline version (F80/ST90) is on `sole-treadmill-programs-touchscreen-gen2-custom-flat`.
