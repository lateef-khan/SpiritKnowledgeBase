*"The HIIT (High Intensity Interval Training) program takes advantage of the latest trend in
wellness. During the program you will perform short bursts of high intensity sprinting followed by
short rest periods. HIIT is a highly customizable interval training program. You can select the
number of intervals, time of each interval Sprint and Rest periods and the work intensity of the
levels."*

## 8.5S

1. Set the **resistance level for sprint and rest**.
2. Click **Next**.
3. Set the **sprint time, rest time and how many intervals** you want.
4. **Program time is calculated automatically.**

The setup screenshot shows Sprint Level 10, Rest Level 5, Sprint Time 00:30, Rest Time 00:30, 10
intervals and a total of 30:00. **The 8.5S book prints no warm-up sentence.**

## 8.5S-Fit

1. Select the program to begin customising it with your personal data.
2. Set **Sprint time / Sprint Level** and **Rest time / Rest Level**.
3. Set the **number of intervals**. **One interval is 1 Sprint and 1 Rest segment.**
4. Press **Start this program**. **The program starts with a 3-minute warm-up period with the
   resistance level set to 50% of the sprint level selected previously.** You can adjust the
   resistance manually during warm-up.

**The two books differ on the warm-up and must not be merged.** The 8.5S-Fit sets warm-up resistance
to **half the sprint level**; the **CS800 stepper** sets it to a **fixed level 5** and adds a
2-minute cool-down and a 90 rpm sprint target the touchscreen machines never mention - see
`spirit-stepper-programs-hiit-on-the-stepper`.

**Neither touchscreen book prints a permitted range for the number of intervals or the sprint and
rest times.** The CS800's 3-to-15 intervals and 20-to-60 second sprint are that machine's figures
and do not carry across.
