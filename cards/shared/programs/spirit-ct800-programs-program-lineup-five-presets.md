The console offers **five preset programs, a Custom user-defined program, two heart rate control
programs, a Gerkin protocol based Fitness Test and one Manual program.**

**The manual never says which five programs the count of five refers to.** Its speed/incline chart
names only four preset profiles - Hill (P1), Fatburn (P2), Cardio (P3) and Interval (P5) - and the
5K Run program is described on its own page without being called a preset. The fifth preset is
therefore not recorded here; do not assume it.

The 2012 and 2016 manuals print this sentence identically. The 2016 manual widens the Fitness Test
to five protocols while still describing it in this sentence as "a Gerkin protocol based Fitness
Test" - see `ct800-2016-programs-fitness-test-menu-five-tests`.

A later CT800 generation replaced this lineup with twelve programs, adding HIIT, a 10K Run and six
more fitness tests - see `ct850-2020-preset-program-list`.
