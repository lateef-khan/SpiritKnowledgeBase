Both books list **two Heart Rate programs (HR1 and HR2)** in PROGRAMMABLE FEATURES but **print no HEART RATE PROGRAMMING section**: the chapter runs HEART RATE PROGRAMS intro (220 minus age, 60%/80% zones) → target chart → RATE OF PERCEIVED EXERTION → USING HEART RATE TRANSMITTER → ERRATIC OPERATION → WARNING → GENERAL MAINTENANCE, with no setup steps, defaults or key sequence for HR1/HR2 anywhere.

Proved four ways: a loose grep for HR1/HR2 hits only the suite line; section-header grep shows no HEART RATE PROGRAMMING heading; the transmitter-to-maintenance pages were read on the render (pp.25-27) with no programming page between; and the books are fully OCR-supplemented so no flattened page hides it. The sibling 2023/2025 F63 books do print the steps: see `sole-treadmill-programs-hr-60-80-menu`. An owner of these two machines cannot set up HR1/HR2 from the manual.
