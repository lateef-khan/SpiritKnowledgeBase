1. Press the Program key, then Enter. 2-4. Enter Age, Weight, Time with Level UP/DOWN, Enter each time. 5. Set Max Level (highest colored segment/box of the profile). 6. Start begins; Stop steps back. 7. Level UP/DOWN adjust resistance mid-program. 8. A summary ends the session, then start-up returns. No incline toggle exists — the E20 has no incline.
