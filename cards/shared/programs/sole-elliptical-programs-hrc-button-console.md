Both programs work the same; HR1 defaults to 60%, HR2 to 80% of max. 1. Press HR1/HR2, then Enter. 2-4. Enter Age, Weight, Time. 5. Adjust the Target Heart Rate to reach and maintain. 6. Start begins; Enter is described as going back, with the printed NOTE that Stop goes back one level. 7. Level arrows during the program change the target. 8. The (adjacent) Display key scrolls data. 9. Start repeats the program, Stop exits. A steady pulse signal is required; resistance follows automatically.
