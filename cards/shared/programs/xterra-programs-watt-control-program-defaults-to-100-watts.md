Program 23 is "a Speed Independent Program". You set a TARGET WATT and the console changes
the resistance to keep your output there: "the level of resistance may increase while the
speed is too slow ... decrease while the speed is too fast", so **the level of resistance is
not adjustable** during the workout.

1. Select WATT CONTROL (P23) with UP/DOWN; press ENTER.
2. **TIME** flashes - set it, press ENTER.
3. **DISTANCE** flashes - set it, press ENTER.
4. **WATT** flashes - set the target (default **100**), press ENTER.
5. **CALORIES** flashes - set it, press ENTER.
6. **PULSE** flashes - set it, press ENTER.
7. Press START/STOP.

**NOTE** as printed: `WATT = TORQUE (KGM) * RPM * 1.03`. "If you peddle quickly, the
resistance level will decrease and if you pedal slowly, the resistance level will increase.
Always try to keep yourself in the same watt value."

The SB150 and FS150 consoles have no watt program. The SB2.5r-family watt program lets you
change the target during the workout; see `see_also`.
