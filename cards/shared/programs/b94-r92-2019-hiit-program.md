The HIIT program takes you through high levels of intensity followed by periods of low intensity. It increases endurance by depleting oxygen followed by recovery periods to replenish it, so the cardiovascular system learns to use oxygen more efficiently. The spikes in heart rate between recovery periods also aid heart rate recovery from intense activity.

It is one of the five preset programs, all of which are set up the same way.
