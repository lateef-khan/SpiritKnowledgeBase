**This is the XT385 / XT485 / XT685 sequence. On the XT185 and XT285 each preset program has its own key, no default values are printed, and Enter rather than Stop goes back a level — see the other card.**

The treadmill offers eight factory preset programs, two custom user defined programs, three target programs and one Manual program. Each preset program has a maximum speed level that is displayed in the Speed window when the workout is chosen.

1. Press the **PROGRAM** key to select the desired program (**Hill, Fat burn, Cardio, Strength, or HIIT**). Press **Enter** to set the program. The display prompts you through the programming, or you can just press **Start** to begin the program with default values.
2. If Enter was pressed, the Message Center blinks a value indicating your **Age (default is 35)**. Use the + or - keys to adjust, then press Enter. Your age determines your recommended maximum heart rate; the HR Graph Display and the Heart Rate features are based on a percentage of it.
3. The Message Center blinks a value indicating your **Body Weight (default is 150 lb / 70 kg)**. The correct body weight affects the calorie count. Use the + or - keys to adjust, then press Enter.
4. The Message Center blinks a value indicating **Time (default is 30 minutes)**. Use any of the + or - keys to adjust, then press Enter to accept. *You may press Start at any point during the programming to start the program.*
5. The Message Center blinks the **preset top speed** of the selected program (**3 mph or 5 kmph**). Use the **Speed + or -** keys to adjust, then press Enter. Each program has various speed changes throughout, so this limits the highest speed the program can reach.
6. The Message Center blinks the **preset top incline** of the selected program. Use the **Incline + / -** keys to adjust, then press Enter.

You are then done programming and may press **Start** to begin your workout, or **Stop** to go back one level and change data entered in the programming phase.
