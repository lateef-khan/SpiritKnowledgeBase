At the end screen choose 'Press Start to Repeat, Press Stop to End, or Press User to save'. Pressing USER 1 shows 'PRESS ENTER TO SAVE THIS PROGRAM TO USER1 OR PRESS STOP TO BACK TO HOME' (USER2 likewise); Enter confirms storage, Stop skips back to the home page. Pressing Start instead reruns the previous settings directly. The E98 instead saves to a single CUSTOM slot.
