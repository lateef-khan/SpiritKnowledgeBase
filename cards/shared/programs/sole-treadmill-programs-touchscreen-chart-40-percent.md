This is the 40-percent chart: warm-up reads 40/40/50, the worked example uses 40% (4 mph at a 10 mph max), and inclines run **negative (decline) to -8**. The no-decline 20-percent chart is on `sole-treadmill-programs-touchscreen-chart-20-percent`.

Speed numbers are a **percentage of the max speed** set before start (100 = the max). **Incline values are absolute.** Columns are 3 warm-up + 20 segments + 3 cool-down. HIIT alternates 100/50 speeds with a 4/0 incline pattern.
