1. Press the **PROGRAM** button to select **CUSTOM PROGRAM**, then press **Enter**.
2. Press the **PROGRAM** button to select **CUSTOM 1** or **CUSTOM 2**, then press Enter. The dot matrix display will have a single row of segments at the bottom unless a program was previously stored.
3. If a program is stored under the button pressed, it is retrieved. If not, you have the option of programming in your first name. The message window displays and flashes the letter **"A"**. Press the **Speed +** key for "B", or the **Speed -** key for "Z". After selecting a letter, press Enter. "A" is displayed and blinking again; repeat until all letters of your first name are programmed (**7 characters maximum**). When your name is displayed, press **Stop** and it is stored under either CUSTOM 1 or CUSTOM 2.
4. The Message Center blinks an **Age** value. Use the Incline +/- keys or Speed +/- keys to adjust, then press Enter. **This is a must to continue even if age is not adjusted.**
5. The Message Center blinks a **bodyweight** value. Enter your bodyweight and press Enter.
6. The clock / Message Center flashes. Use the + / - keys to adjust up **from 30 minutes** if desired, then press Enter. **This is a must to continue even if time is not adjusted.**
7. The first column (segment) blinks. Using the **Speed +/- keys or the Direct Access keys**, set the speed level for the first segment, then press Enter. The second column blinks; repeat until all segments have been programmed. The first column blinks again - this is the incline programming; repeat the process for all segments.
8. Press the **Start** button to begin the workout and also save the program to memory.
9. The profile picture is re-scaled to fit in the window, but the actual speed and incline settings remain the same as programmed.

**Note:** while in a User program, if you change the speed, all segment speeds from there on also change. For example, if you increase your current speed by 1 mph (1.6 kmph), the remaining segment speeds increase by 1 mph (1.6 kmph); if you decrease your current speed by 0.5 mph (0.8 kmph), the remaining segment speeds decrease by 0.5 mph (0.8 kmph).
