U1/U2 keep a 7-character username. 1. Select U1/U2, Enter; if empty the letter 'A' blinks — pick letters with the 5/6 Incline/Level buttons ('B' up, 'Z' down), Enter per letter, Stop finishes (max 7 characters). 2. A stored program offers Run Program? Yes/No; No asks to delete it — deleting is required to build anew. 3-5. Enter Age, Weight, Time. 6. Build the resistance profile column by column to all twenty segments. 7. Build the incline profile the same way. 8. Start begins and saves, Enter modifies, Stop exits. Mid-program Incline/Level changes affect the present column only; Display scrolls data; a summary ends the session.
