**One key, two names.** The 4.0R and 4.0U call it the **Custom** program and reach it from the
Custom key; the 7.0R and 7.0U call it the **Facility** program and reach it from the Facility key.
The procedure is the same and *"allows you to further personalize it by adding your facility name."*

1. Press the key. The message window shows a welcome message - or, if a program was saved before,
   the name you gave it. Press Enter (Confirm on the 4.0) to begin programming.
2. The window shows **"Name - A"** if no name is saved. If **"Custom Workout"** had been saved it
   shows "Name - Custom Workout" with the C blinking. Keep a saved name by pressing **Stop**, or
   change it: Up and Down (Plus and Minus on the 4.0) change the first letter, Enter saves it and
   moves to the next letter, and **Stop saves the finished name**. **No maximum length is printed.**
3. Enter an **Age**, then a **Weight**, then the **Time**, then the **Max Level** - the peak exertion
   level of the program - pressing Enter after each.
4. The first column blinks: set its level and press Enter. **Each next segment starts at the level of
   the one before.** Continue until **all twenty-four segments** have been set.
5. Press Enter to save. The window says **"New program saved"** and offers Start or modify; Stop
   exits to the start-up screen.

**Running the saved program.** Press the key, then Enter; enter the time; press Start. **On the 7.0
bikes there is one more prompt** - set the auto-brake on or off - before Start.

**Two things only one family prints.** On the 4.0 bikes you can switch a running Custom program to
**HR auto pilot**. On the 7.0 bikes **any preset you complete can be saved as the Facility program**
by pressing the Facility key when it ends, so the Facility slot need not be built segment by
segment.

The commercial CR800/CU800 Custom program stores twenty-four segments too but takes a seven
character name and asks to delete the old program first
(`spirit-bike-programs-custom-twenty-four-segments-and-a-seven-character-name`); the CU800 2012 and
the 7.0T treadmill also file their custom workout under a facility name.
