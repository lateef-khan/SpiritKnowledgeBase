1. Press **PROGRAM** to switch to **5K PROGRAM** or **10K PROGRAM**. Press **Enter** to select a program. The display prompts you to program it, or you can simply press **Start** to start the program using the default values.
2. If Enter was pressed, the Message Center blinks a value indicating your **Age**. Use the + / - keys to adjust, then press Enter. Your age determines your recommended maximum heart rate, which the Bar Graph Display and the Heart Rate features are based on.
3. The Message Center blinks a value indicating your **Body Weight**.
4. The message window displays **"USE SPEED +/- KEYS TO ADJUST SPEED"**. Use Speed +/- to adjust the speed, then press Enter.
5. You are then done programming and may press **Start** to begin your workout, or **Stop** to go back one level to change data entered in the programming phase.

**The XT185 and XT285 manuals do not say what target distance these programs set, or that the distance counts down.** The XT385, XT485 and XT685 manuals state 5 km and 10 km respectively - see the linked card - but that wording does not appear in the XT185 or XT285 manual, so it is not stated here as their behaviour.
