**Ten programs.** The control-panel page prints the program buttons as
**Manual, Hill, Fat Burn, Cardio, Strength, Interval, Custom, FIT-TEST, 2HR** — "2HR" is the
two heart rate programs, **HR1 and HR2**.

| Program | What it is |
|---|---|
| **Manual** | You control the resistance yourself. |
| **Hill**, **Fat Burn**, **Cardio**, **Strength**, **Interval** | The five factory preset work-level profiles. |
| **Custom** | One user-built program you build and save. There is **one** Custom slot, not two. |
| **Fit-Test** | The sub-maximal fitness test. |
| **HR1** | Heart rate control at 60% of maximum heart rate. |
| **HR2** | Heart rate control at 80% of maximum heart rate. |

On the 2016 and 2019 machines the same ten appear as the on-screen workout menu of the
main workout home page rather than as ten separate keys.

**This is not the same set as the B94/R92 and B74/R72 consoles.** Those have **User 1 and
User 2** instead of Custom, and they have **no Fit-Test** button at all. Do not read a
B94/R92 program list onto an LCB or LCR.

**Two contradictions printed inside these manuals, both worth knowing:**

1. The Heart Rate Programs page says the heart rate monitor can be used "during manual mode
   or during any of the **nine** different programs", while the console page lists **ten**
   program buttons.
2. In the **LCB/LCR 2019** manual the fifth preset is described under the heading **HIIT**,
   but every console illustration in the same manual labels that button **Interval**. The 2011,
   2013 and 2016 manuals call it Interval everywhere.
