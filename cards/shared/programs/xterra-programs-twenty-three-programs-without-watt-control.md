The console counts its programs **P1 to P23**:

| Programs | What they are |
|---|---|
| 1 | **Manual** - you control the tension level |
| 2 to 13 | **Twelve presets**: Steps, Hill, Rolling, Valley, Fat Burn, Ramp, Mountain, Intervals, Random, Plateau, Fartlek, Precipice |
| 14 to 17 | **Four user setting programs** (User 1 to User 4) |
| 18 to 22 | **Five heart rate control programs** - 55%, 65%, 75%, 85% and Target |
| 23 | **Body fat program** |

**There is no watt control program on these two machines.** The later SB250, EU150 and
SB240 books add it as program 23 and move body fat to 24; the SB150 and FS150 books never
mention watts anywhere in the program pages, the console function list or the profile
pictures (searched loosely for "watt" and with letter spacing allowed; the profile pages,
which are pictures, were read from a render).

Every program is entered the same way: select it with UP/DOWN, press ENTER, set the
flashing targets (TIME, DISTANCE, CALORIES, PULSE) with UP/DOWN and ENTER, then press
START/STOP. UP and DOWN change the tension level while you exercise.
