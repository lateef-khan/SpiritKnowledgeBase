At the end screen choose 'Press Start to Repeat, Press Stop to End, or Press User to save'. Pressing Custom shows 'PRESS ENTER TO SAVE THIS PROGRAM TO CUSTOM OR PRESS STOP TO BACK TO HOME'; Enter confirms storage, Stop skips back to the main workout home page. Start reruns the previous settings directly. The E95/E95s instead save to USER1/USER2 slots.
