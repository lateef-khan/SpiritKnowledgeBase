On the program setup page press **"Add Pattern"** to enter edit mode, then **connect dots to map the load** from easiest (bottom) to hardest (top). Each segment's duration follows the selected total time, settable right before start.

**Speed values are relative**: the maximum can change before each workout and all segments scale proportionally. **Incline values are absolute.** Ranges differ by book:

| Book | Printed incline range |
|---|---|
| F80-2023 | 0 to 15 (incline pattern optional) |
| ST90-2023 | no range printed |

The decline version (-6 to +15) is on `sole-treadmill-programs-touchscreen-gen2-custom-decline`.
