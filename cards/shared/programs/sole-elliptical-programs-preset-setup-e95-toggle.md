Press the program button, then Enter (steps run 11-20 continuing the chapter). Enter Weight, then Age, then Time (Up/Down). Set Max Level (peak exertion, 'at the top of the hill'). Then turn the Incline profile on or off — off leaves the manual Incline switches live. Start begins; Stop steps back. **Unlike every other book here, changing the workload mid-program changes the entire profile**, and the profile picture deliberately does not change so you always see the whole profile; the Message Window shows the current column and program maximum levels. Display (Enter key) scrolls data; a summary ends the session.
