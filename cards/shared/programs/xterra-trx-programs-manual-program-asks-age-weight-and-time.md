1. Select **Manual Program** via the Program key, then press **Enter**. The display prompts you
   through the programming, or press **Start** to begin with default values.
2. The Message window blinks an **Age** value. Adjust and press Enter.
3. The Message window displays a **Weight** value; the correct body weight affects the calorie
   count. Adjust with Speed up/down, press Enter. (The usual calorie note follows: no exercise
   machine can give an exact calorie count; the display is a reference only.)
4. If Enter was pressed, the Message window shows the default **Time of 30 minutes**. Adjust
   with Speed up/down, press Enter. (You may press Start at any time during programming.)
5. Press **Start** to begin your workout.

The book prints no default age or weight for this console. The HRC page shows the console's
own prompts as "Age> 35" and "Weight> 150"; those defaults are stated for HRC only.
