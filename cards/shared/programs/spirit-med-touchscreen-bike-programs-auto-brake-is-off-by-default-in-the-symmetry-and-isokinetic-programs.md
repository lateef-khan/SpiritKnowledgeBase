**This is the 8.0U and 8.5R rule - off by default in Symmetry and Isokinetic.** The 7.0R and 7.0U
books name a different pair, Symmetry and VO2; see the linked card.

*"The 8.0U has built-in sensing technology and software that will automatically stop the flywheel
when it senses the user is attempting to stop pedaling. This auto-braking software can be disabled
during program set up before beginning a session. The auto-brake is set to off for the Symmetry and
isokinetic programs and can be turned on during program set up."*

The Symmetry page repeats the reason: *"since the auto brake may be activated with severe asymmetry
the auto brake default setting is off."* **Isokinetic on these bikes is a workload type rather than a
program**, so the sentence means any program run with the Isokinetic workload type; no program page
prints an auto-brake step of its own.

A manual mechanical brake lever on the flywheel stops it when pressed, whatever the software setting.
The 8.0U and 8.5R 2025 books print this in the same words.
