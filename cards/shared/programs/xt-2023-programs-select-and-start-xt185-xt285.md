**This is the XT185 / XT285 sequence. The XT385, XT485 and XT685 use one PROGRAM key, print default values, and take Stop rather than Enter to go back a level — see the other card.**

1. Press the desired program (**Hill, Fat Burn, Cardio, Strength, HIIT**) key. Press **Enter** to select the program. The display prompts you through the programming, or you can just press **Start** to begin the program with default values.
2. If Enter was pressed, the Message Center blinks a value indicating your **Age**. Use the **+ / -** keys to adjust, then press Enter. Your age determines your recommended maximum heart rate; the Bar Graph Display and the Heart Rate features are based on a percentage of your maximum heart rate, so the correct age matters for those features to work properly.
3. The Message Center blinks a value indicating your **Body Weight**. The correct body weight affects the calorie count. Use the + / - keys to adjust, then press Enter.
4. The Message Center blinks a value indicating **Time**. Use any of the + / - keys to adjust, then press Enter to accept. *You may press Start at any point during the programming to start the program.*
5. The Message Center blinks the **preset top speed** of the selected program. Use the **Speed + / -** keys to adjust, then press Enter. Each program has various speed changes throughout, so this limits the highest speed the program can reach.
6. The Message Center blinks the **preset top incline** of the selected program. Use the **Incline + / -** keys to adjust, then press Enter.

You are then done programming and may press **Start** to begin your workout, or **Enter** to go back one level and change data entered in the programming phase.

Each preset program has a maximum Speed and Incline level that is displayed in the Message Center when the workout is chosen.
