These early consoles have **factory preset programs, 2 user defined programs, one Manual program (P0) and P1-P5 programs** — presets plus two user slots and manual, **with no heart rate control programs at all**. The VF63-2008 book prints the same complement.

Each preset shows its maximum speed in the Speed window when chosen. Setup is time, body weight, top speed, then Start: see `sole-treadmill-programs-selecting-basic-2006`. There is no age entry and no warm-up phase. User setup is on `sole-treadmill-programs-user-basic-keypad`.

Neighbour books one generation later add two heart rate programs; see `sole-treadmill-programs-list-ten-hrc-keypad`.
