Manual on the SC300 follows the SC200 procedure (Manual key, Enter, then Age, Weight and Time on the Level or Step height keys, Start to begin, Stop back one screen), with one extra step: the step size itself is adjustable with the step height keys during the workout.

The program starts at level one for warm-up, the Display key scrolls the Message Window data, and the workout ends with a summary before the console returns to the start-up display. See the SC200 Manual card for the shared steps.
