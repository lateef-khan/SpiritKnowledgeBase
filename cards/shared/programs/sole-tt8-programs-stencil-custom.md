This differs from the A1 TT8 Custom card (`sole-tt8-programs-custom`) twice, both verified on the render: **STOP advances each naming letter and ENTER stores the finished name** (A1 has Enter per letter, Stop to store), and there is **no segment carry-over sentence** — each new segment does not inherit the previous value.

The TT8 has **one** Custom slot (not two user slots).

1. **Select CUSTOM** via the Program keys, then press Enter. The dot matrix lights a single row of dots at the bottom unless a program is already saved; a saved program is retrieved instead.
2. **Name it (first program only).** The name window flashes "A"; the up key steps to "B", down to "Z". After selecting the letter, press **STOP**; "A" shows again. Repeat per letter, up to **7 characters**. When the name is displayed, press **Enter** to store it under CUSTOM.
3. The menu shows the **Age window** first. Adjust with the Grade keys and press Enter — **this is a must to continue even if age is not adjusted**.
4. The **Weight window** shows a body weight value. Enter it and press Enter.
5. The **Time window** shows a Time value. Adjust and press Enter.
6. The **first speed column (segment) blinks**. Set the speed and press Enter; the second column blinks. Repeat until all speed segments are set, then the first column blinks again for **grade**: repeat for all grade segments. **While running, a manual speed change shifts every later segment the same way** ("If you increase your current speed 1 mph, the remaining segment speeds will increase by 1 mph. If you decrease your current speed .5 mph, the remaining segment speeds will decrease by .5 mph, etc.").
7. **Press Start to begin the workout and also save the program to memory.** The profile picture is re-scaled to fit the window, but the actual speed and grade settings stay as programmed.
