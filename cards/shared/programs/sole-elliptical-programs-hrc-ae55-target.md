HR1 is 60% and HR2 is 80% of maximum heart rate, programmed the same way. 1. Press HR1/HR2, Enter. 2-4. Enter Age, Weight, Time (Up/Down or numeric keypad). 5. Adjust the Target Heart Rate to reach and maintain. 6. Start begins; Enter is described as going back, with the printed NOTE that Stop goes back one level. 7. Up/Down during the program changes the target. 8. The adjacent Display key scrolls data. 9. Start repeats, Stop exits, or a User key saves the finished workout as a Custom User Program.
