When you enter a program by pressing the **Program** key and then the **Enter** key, you have the option of entering your own personal settings.

- To work out **without** entering new settings, just press **Start**. That bypasses the programming of data and takes you straight to the start of your workout.
- To change the personal settings, follow the instructions in the Message Center.

**If you start a program without changing the settings, the default or saved settings are used.**

Each program can be customised with your personal information; some of it is needed to make the readouts correct. See the card on why the console asks for age and weight, and the card on which of those values are remembered between workouts.

All five 2015 XT owner's manuals print this same paragraph. The only difference is the key: **on the 2015 consoles you press the program's own key**, because each program has one, whereas the 2023 consoles have a single PROGRAM key that steps through a list.
