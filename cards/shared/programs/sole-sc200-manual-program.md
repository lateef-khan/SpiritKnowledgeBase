The Manual program works as the name implies: you control the workload yourself, not the computer.

1. Press the Manual program button, then press Enter.
2. Enter your Age with the Level keys, then press Enter.
3. Enter your Weight with the Level keys, then press Enter.
4. Set the Time with the Level keys, then press Enter.
5. Press Start to begin. Press Stop to go back one screen and change a setting.
6. The climber starts at level one, the easiest level. Press the Level up key to raise the workload and the Level down key to lower it at any time.
7. Press the Display key to scroll through the data in the Message Window.
8. When the program ends the Message Window shows a workout summary for a short time, then the console returns to the start-up display.
