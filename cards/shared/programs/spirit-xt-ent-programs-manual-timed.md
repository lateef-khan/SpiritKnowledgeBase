**Manual is a timed workout: you set a target time before you start, and you control speed and
incline yourself for the whole run.** It has no speed or incline profile.

- **XT485ENT:** the program *requires a time frame set before starting*. Use the scale or the arrows
  to adjust the target time. Speed and incline are adjusted manually while running. Press **START**
  to begin the workout.
- **XT685ENT:** the program is called **Manual (Timer)** and is described as a timed workout with
  speed and incline controlled manually at any time during the run.

Neither manual says the program asks for age or weight. On the XT685ENT the Home screen also offers
**Set Timer** as a shortcut to a manually controlled timed workout.

This is not the Manual program on the button consoles. On the 7.0T and 8.0T the same program is
reached with a physical manual key; on the CT900ENT touchscreen it asks for nothing at all.
