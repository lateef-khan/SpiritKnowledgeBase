Press the program button, then Enter. 1. Enter Weight first (Up/Down), Enter. 2. Enter Age, Enter. 3. Enter Time, Enter. 4. Adjust Max Level — the peak exertion, 'at the top of the hill'. 5. E35 models only: choose to turn off the incline profile (manual incline switches still work); other models skip this. 6. Start begins; Stop steps back. Up/Down adjust workload mid-program (E35: incline too); Display scrolls the Message Window; a workout summary ends the session.
