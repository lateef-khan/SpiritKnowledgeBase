1. Using the **Program** button select your desired program, then press **Enter**.
2. Enter your **Age**, then Enter.
3. Enter your **Weight**, then Enter.
4. Set the **Time**, then Enter.
5. Set the **Max Level** - **the peak exertion level you will experience during the program (at the
   top of the hill)** - then Enter.
6. Press **Start** to begin. **Stop** goes back one level or screen.
7. **Up or Down during the program changes the workload of the entire profile**, although **the
   profile picture on the screen will not change**. The manual gives the reason: so that you can see
   the entire profile at all times, because a redrawn picture would look distorted and would not be
   a true representation of the actual profile. When you change the workload the Dot Matrix Message
   Center shows **the current column level and the program maximum level**.
8. The Up/Down button beside the LED Data Display Window scrolls through the data during the
   program.
9. **When the program ends a summary of your workout is displayed** for a short time, then the
   console returns to the start-up display. The CS800 shows the summary in the LED Data Display
   Window; the CRS800S shows it in both the Dot Matrix Message Center and the LED Data Display
   Windows.

If you start a program without changing the settings, **the default or pre-saved settings are used**
- pressing **Start** instead of Enter bypasses data entry entirely.

**The 2021 printings of both machines carry the same nine steps**, including the sentence about the
profile picture not changing. The **2021 CS800 alone** spells the display "LED Data Dipslay Window"
in step 8, twice; the 2021 CRS800S and both 2024 books spell it correctly.
