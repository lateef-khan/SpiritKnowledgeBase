These consoles have **one** Custom slot, not two User slots.

1. Select the **CUSTOM** program, then press Enter. If a program is already saved to CUSTOM it is
   displayed and you are ready to begin. If not, you can enter a username: the letter "A" blinks; use
   the Level ▲/▼ buttons to pick each letter (▲ switches to "B", Down switches to "Z") and press Enter
   for each. **Maximum 7 characters.** Press Stop when finished.
2. If a program is already stored, pressing Start or Enter at the welcome message prompts
   **"Run Program?"**. Use Level ▲/▼ to pick Yes or No. Selecting No then asks whether to delete the
   saved program. **You must delete the current program to build a new one.**
3. Enter your **Age** with the Level ▲/▼ keys, then Enter.
4. Enter your **Weight** with the Level ▲/▼ keys, then Enter.
5. Enter the **Time** with the Level ▲/▼ keys, then Enter.
6. The first column blinks. Set the level for that segment and press Enter. Each next segment starts at
   the level of the one before it. Repeat until all **twenty segments** are set.
7. **The first column now blinks again and you build a second profile**, following the same procedure
   you used for the resistance profile.
8. The window then offers Start to begin and save the program, or Enter to modify it. Pressing Stop
   exits to the start-up screen.
9. Pressing Level ▲/▼ during the program changes only the level for the **current column**. When the
   profile moves to the next column it returns to the preset work level.
10. Press **Display** to scroll through the data in the window.
11. When the program ends the window shows a workout summary for a short time, then returns to the
    start-up display.

**Step 7 is what makes this console different.** The 2011 and 2013 consoles and every B94/R92 console
ask for one profile only; here you set twenty segments twice. The manual does not name what the second
profile controls — it says only "follow the same procedure for building the profile as you did for the
resistance profile". Do not tell a customer what the second profile is.

**Twenty segments, not eighteen.** The B94/R92 2016, 2019 and 2023 manuals print eighteen for their
User programs.

The section is headed "CUSTOM USER DEFINED PROGRAMS" and its opening sentence still says "The
customizable **User** programs", but step 1 and step 10 both name the **CUSTOM** program. Step 2 also
still says "already stored in **User**". There is one Custom slot on this console.
