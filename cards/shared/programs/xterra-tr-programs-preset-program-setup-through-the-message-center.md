**Entering a program:** press the **Enter/Program** key, use **Speed up/down** to preview what
each program profile looks like, and press Enter/Program to select it and enter the data
setting mode. If you want to work out without entering new settings, press **Start**: this
bypasses the programming and uses the default or saved settings.

**Age and Weight are remembered.** "The last Age and Weight entered will be saved as the new
default settings", so you need not re-enter them unless they change or someone else enters
different values.

**Steps for a preset program** (Hill, Fat Burn, Cardio, Strength or HIIT):

1. Press Enter/Program, select the program with Speed up/down, press Enter/Program. The
   display prompts you, or press Start for the default values.
2. The Message Center blinks **Age**. Your age sets your recommended maximum heart rate for the
   bar-graph display and the heart-rate programs. Adjust, press Enter/Program.
3. **Body Weight** - affects the calorie count. Adjust, press Enter/Program.
4. **Time** - adjust or accept, press Enter/Program. (You may press Start at any time.)
5. The **preset top speed** of the program - adjust with Speed up/down, press Enter/Program.
   Each program has various speed changes; this lets you limit the highest speed it reaches.
6. The **preset top incline** - adjust, press Enter/Program.

Press **Start** to begin, or **STOP** to go back one level and change data.

**The book prints no default age, weight, time, top speed or top incline for this console**;
the maximum speed and incline of the chosen program are shown in the Message Center.

**Calorie note, as printed:** no exercise machine can give an exact calorie count; the display
is a reference only, to monitor improvement from workout to workout.
