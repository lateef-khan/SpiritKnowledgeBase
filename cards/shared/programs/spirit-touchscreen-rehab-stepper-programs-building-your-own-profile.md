**The two machines call it different things and give different segment counts. Do not swap them.**

## 8.5S - the Facility program

*"The Facility program allows you to build and save a custom program. You can build your own custom
program or you can save any other preset program you complete as a custom program. The Facility
program allows you to further personalize it by adding your facility name."*

- Change the **resistance type, max level or total time** at the top of the setup screen. The
  workload type switches between **Level** and **Power**.
- **Click to create the profile.** Once created, the profile is shown on the screen.
- **Touch a segment to create or modify it**, then set that segment's level.
- **Click Save** after creating the profile.
- **Click Start** to run the program.

**This book never says how many segments the profile holds**, and never says how long the facility
name may be. Neither figure should be carried across from another machine.

## 8.5S-Fit - the Custom program

*"You will create the desired resistance levels for each of the **20 segments** of the program using
the keyboard on the screen. You may change these levels at any time during the workout."*

1. Select the **Custom** program to begin customising it with your personal data.
2. Use the on-screen interface to complete the desired workout profile and the desired workout time.
3. Press **Start this program**.

**Twenty segments, and no facility name.** The 8.5S-Fit has no Facility program at all.

**Both differ from the dot matrix rehabilitation steppers**, whose two User keys build
**twenty-four** segments under a facility name - see
`spirit-rehab-stepper-programs-user-one-and-two-build-twenty-four-segments-under-a-facility-name`.
