User programs U1 and U2 save a workout you build yourself, with a resistance profile and a step height profile.

1. Select U1 or U2, then press Enter. A saved program runs as it is; otherwise enter a username: the letter A blinks, the Level or Step height up button steps to B and the Down button steps to a blank. Press Enter per letter (maximum 7 characters), then Stop when finished.
2. If a program is already stored, Start or Enter at the welcome screen asks Run Program? Select Yes to run it, or No and then delete the saved program; deleting is required to build a new one.
3. Enter Age, then Weight, then Time with the Level or Step height keys, pressing Enter after each.
4. The first column blinks: set the resistance level per segment with Enter, until all eighteen segments are set. The first column then blinks again for the step height profile; build it the same way.
5. The Message Window offers Start to begin (which saves the program) or Enter to modify it; Stop exits to the start-up screen.
6. During the workout the Level or Step height key changes the level or step height for the present column only; the next column returns to the preset level.
