In the Manual program you control the workload yourself, not the computer.

1. Press the **Manual** program button. (No Enter press here.)
2. In the settings menu **Age** is displayed first. Adjust with the Level ▲/▼ keys, then press Enter.
3. Enter your **Weight** with the Level ▲/▼ keys, then Enter.
4. Enter the **Time** with the Level ▲/▼ keys, then Enter.
5. Press **Start** to begin. Press **Stop** to go back one level of the programming screen and modify settings.
6. The bike starts at **level one**, the easiest level. Staying at level one for a while to warm up is
   recommended. Level ▲ increases the workload, Level ▼ decreases it.
7. Pressing the **DISPLAY** key during the program changes the displayed information.
8. Pressing **STOP** during the workout pauses the program. The bottom left of the screen reads
   "PRESS START TO RESUME" and the lower right reads "OR PRESS STOP TO END". Pressing STOP a
   **second** time shows "STOP".
10. When the program ends the window shows a workout summary for a short time, then returns to the
    start-up display. The summary contains **TIME, DISTANCE, CALORIES, AVG. PACE, AVG. RPM,
    AVG. SPEED, AVG. LEVEL, AVG. WATTS and AVG. PULSE**.
11. The screen then reads "PROGRAM END. PRESS START TO REPEAT" on the left, "OR PRESS STOP TO END"
    in the middle and "OR PRESS USER TO SAVE" on the right. If nothing is stored, after **3 minutes**
    the display returns to the main workout home page on its own; pressing STOP returns immediately.
12. To store the workout to Custom: press **START** again and the console displays the previously
    programmed data; press the **Custom** button and the screen reads "PRESS ENTER TO SAVE THIS
    PROGRAM TO CUSTOM OR PRESS STOP TO BACK TO HOME". **Enter** confirms, **Stop** discards and
    returns to the main workout home page.

**There is no step 9.** Both the 2016 and the 2019 manuals number these steps 1-8 and then jump
straight to 10; nothing is missing from this card.

**Step 11 and step 12 disagree about which key saves the workout.** Step 11 says "OR PRESS USER TO
SAVE"; the screen illustration beside it and step 12 both say the **Custom** button. The console has a
Custom key and no User key, so treat Custom as the key to press.
