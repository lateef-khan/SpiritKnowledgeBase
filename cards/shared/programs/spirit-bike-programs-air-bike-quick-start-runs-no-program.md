**Quick Start begins automatically as soon as you start pedalling.** There is no button to press
first and nothing to set up.

- **No programs run during Quick Start.** The console simply shows all the data, including heart
  rate if a chest strap is detected.
- **Quick Start ends once pedalling stops.**
- Pressing **Stop** also ends it and displays the workout summary.

The workout summary that follows is the console's standard three-figure summary - see
`spirit-bike-console-air-bike-workout-summary-and-reset`.

**This is not a "manual program".** On an upright or recumbent Spirit bike, Manual mode lets you
raise and lower a resistance level. The air bike has no levels to raise, so Quick Start only
measures - see
`spirit-bike-programs-air-bike-has-no-resistance-levels-because-the-fan-sets-the-load`.
