1. Select **HRC** via the Program key, press **Enter**.
2. The console displays **"Adjust age, Age> 35"**. Press ENTER after adjusting.
3. **"Adjust weight. Weight> 150"**. Press ENTER after adjusting.
4. **"Adjust time. Time> 30:00"**. Press ENTER after adjusting.
5. **"Adjust target heart rate"**. The console calculates the target as **(220 - age) x 0.6**;
   if you change the target, the new percentage is displayed. Press Enter.
6. **If you press START without wearing the HR strap the console displays "This program must
   wear HR strap".**
7. If START is pressed and a heart-rate signal is detected, control begins.
8. **The program adjusts the incline only.** When the heart-rate software would normally change
   the speed, the treadmill does not change it but shows in the message window what speed you
   should set, e.g. **"SET SPEED TO 2.3 MPH"**.

**Steps 7 and 8 are printed in the voice of a software specification** ("Use the existing
heart rate control software, except use the Incline adjustments only ... do not change the
speed but instead display in the message window what the user should set the speed to"). The
behaviour they describe is carded as printed.

The chest strap instructions and the erratic-reading checklist are console facts. The TRX2500's
HRC (target default 116, no age step) and the TR65's HR1/HR2 differ; see `not_to_be_confused_with`.
