Manual means you control the workload, not the computer. 1. Press Manual, then Enter (VE35: highlight Manual, then Enter). 2. Enter Weight first with the Up/Down keys, Enter. 3. Enter Age, Enter. 4. Enter Time, Enter. 5. Press Start; Stop goes back one programming level. 6. You start at level one: warm up, then Up raises / Down lowers the load. 7. Display scrolls the Message Window data. 8. At the end the Message Window shows a workout summary, then the console returns to start-up. There is no save-as-custom ending here.
