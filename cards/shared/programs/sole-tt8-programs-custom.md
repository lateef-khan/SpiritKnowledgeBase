The TT8 has **one** Custom slot (not two user slots).

1. **Select Custom** on the program keypad, then press Enter. The dot matrix lights a single row of dots at the bottom unless a program is already saved; a saved program is retrieved instead.
2. **Name it (first program only).** The Message window flashes "A"; the arrow-5 key steps to "B", arrow-6 to "Z". Press Enter per letter, up to **7 characters**, then press **Stop** to store the name under Custom.
3. The Message window shows **Age**. Adjust with Up/Down and press Enter.
4. The Message window shows **body weight**. Adjust and press Enter.
5. The Time window flashes. Set the time and press Enter — **this is a must to continue even if the time is not adjusted**.
6. The **first speed column (segment) blinks**. Set the speed with the Fast/Slow keys and press Enter; the second column blinks, and **the previous segment value is carried over** into it. Repeat until all speed segments are set.
7. The first column blinks again for **incline**. Repeat the same process for all incline segments.
8. **Press Start to begin the workout and also save the program to memory.**

Two propagation rules, both printed: **while programming, each new segment inherits the previous value**; and **while running, a manual speed change shifts every later segment the same way** ("If you increase your current speed 1 mph, the remaining segment speeds will increase by 1 mph. If you decrease your current speed .5 mph, the remaining segment speeds will decrease by .5 mph, etc.").

The menu-console twin with two slots is on `sole-treadmill-programs-user-named-menu`.
