There are **two** customisable programs and they work identically, so the manuals describe only one.
They are called **User 1 and User 2** on the eight LED consoles of 2016 to 2021 and **Custom 1 and
Custom 2** on the four 2023 consoles.

1. Select the program, then **Enter**. If one is already saved it is displayed and you are ready to
   begin.
2. If none is saved you may enter a **username**. The letter "A" blinks; Level Up/Down changes the
   letter, Enter accepts it. **Maximum 7 characters.** Press **Stop** when finished.
3. If a program is already stored you are prompted **Run Program?** - choose Yes or No with Level
   Up/Down. Choosing No offers to **delete** the stored program, and you must delete it before you can
   build a new one.
4. **Age**, then Enter. 5. **Weight**, then Enter. 6. **Time**, then Enter.
7. The **first column blinks** (SEGMENT > 1). Set its resistance with Level Up/Down, then Enter.
8. The next segment starts at the level of the one before. Repeat **until all twenty segments have
   been set.**

**You can also save a finished workout instead of drawing one.** At the end of Manual or any preset,
press a User key and follow the message centre.

**The 2023 books drop two steps.** They have **no Max Resistance Level step** - the eight older books
ask for it between Time and the first segment - and no "press Enter to save / program saved"
confirmation at the end; the 2023 flow simply lets you press Start when the twentieth segment is set.

**The XBR25 2019 has no user program at all.** Its six-key console carries Manual, Cardio, Hill,
Fatburn, Interval and HR, yet its Manual page still ends "you can save the program you just completed
as a custom user program by pressing a User key" - boilerplate from the XBR55 book, with no key to
press.

**Twenty segments, not twenty-four.** The commercial CR800, CR800 2023 and CU800 2021 store
twenty-four - see `spirit-bike-programs-custom-twenty-four-segments-and-a-seven-character-name`. The
touchscreens store twenty but ask for no name - see
`spirit-bike-programs-custom-twenty-segments-on-the-touchscreen`.
