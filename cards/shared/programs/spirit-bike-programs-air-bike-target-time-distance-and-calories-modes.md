**These are the three Target *value* modes.** Target Heart Rate is a fourth, separate mode that works
differently - see
`spirit-bike-programs-air-bike-target-heart-rate-mode-between-sixty-five-and-eighty-five-percent`.

Target Time, Target Distance and Target Calories Mode each **allow the target goal of that value to
be customized**.

1. **Launch** - press the desired Target button: **TIME**, **DISTANCE** or **CALORIES**.
2. **Setup** - after the console has been reset, enter the target value. Adjust with **▲** or **▼**,
   then press **Enter** to confirm. **If no value has been entered, the console uses the last setting
   as the target** for that mode.
3. **Start** - the display field lights up. TARGET TIME counts the time target down; TARGET DISTANCE
   begins calculating distance; TARGET CALORIES begins calculating calories.
4. **End** - the mode ends when the target is achieved. Pressing **Stop** at any time also ends it.
   The workout summary is shown either way.

**The two manuals contradict themselves on distance and calories.** This Target mode page says
DISTANCE and CALORIES "begin calculating", while the display-panel page in the same book says both
**count down**. Both sentences are printed in both manuals. Treat the count-down wording as what the
panel actually shows, since it is the one describing the panel - see
`spirit-bike-console-air-bike-display-panels`.
