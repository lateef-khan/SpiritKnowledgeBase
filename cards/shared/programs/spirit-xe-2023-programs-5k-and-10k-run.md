The 5K Run and 10K Run programs **automatically set a target distance** for your workout - **5 km and
10 km respectively**. When the program begins the **Distance counts down**, and the program ends when
it reaches zero.

1. Press **PROGRAM** to select the **5K** or **10K** program, then Enter to set it. The display
   prompts you through the programming, or you may just press **Start** to begin with the default
   values.
2. The Message Center blinks your **Age (default is 35)**. Adjust with + / -, then Enter.
3. It blinks your **Body Weight (default is 155 lbs / 70 kgs)**. Adjust, then Enter.
4. You are done programming. Press **Start** to begin, or **Stop** to go back one level and change
   what you entered.

*The manual notes that **the Speed readout is in MPH if the console is not set to Metric readings**,
even though the target distance itself is stated in kilometres.*

**No earlier Spirit elliptical has a distance-goal program.** The 5K and 10K arrived with the 2023
consoles; the XE795 2021's nearest equivalent was its Calories program.
