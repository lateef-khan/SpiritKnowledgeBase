1. Select the desired **program key**, then press **Enter**.
2. Enter your **Age** with the Level +/- keys, then Enter.
3. Enter your **Weight**, then Enter.
4. Set the **Time**, then Enter.
5. Set the **Max Resistance Level** - **the peak exertion level you will experience during the
   program** - then Enter.
6. **Set Incline on/off**, then Enter.
7. During the program the **Enter** key scrolls the data in the message window. When the program
   ends the Message Center shows a **summary of your workout** for a short time, then the console
   returns to the start-up display.

**Step 6 is the step no other Spirit climber has.** Turning the incline off runs the program's
resistance profile with the pedals flat; see
`xs895-programs-what-each-preset-profile-does-including-the-incline` for what the elevation does when
it is left on.

**Pressing Start instead of Enter skips data entry entirely** and runs the default or saved
settings.

**Age and Weight defaults change when you enter a new number.** The last Age and Weight entered are
saved as the new defaults, so you only re-enter them when they change or when someone else has
entered different ones.

*The Manual program asks for no Max Resistance Level and no incline setting, because there is no
profile to scale - see `xs895-programs-manual-mode-starts-at-level-one`.*
