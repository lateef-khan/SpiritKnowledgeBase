These consoles have **one** Custom slot, not two User slots.

1. Select the **Custom** program, then press Enter. If a program is already saved it is displayed and
   you are ready to begin. If not — or if someone else's name is shown — you can override it or enter a
   username: the letter "A" blinks in the message window; Up switches to "B", Down switches to "Z";
   press Enter for each letter. **Maximum 7 characters.** Press Stop when finished.
2. If a program is already stored, pressing Start or Enter at the welcome message prompts
   **"Run Program?"**. Use the Up/Down arrows to pick Yes or No. Selecting No then asks whether to
   delete the saved program. **You must delete the current program to build a new one.**
3. Enter your **Age** with the Up and Down keys, then Enter.
4. Enter your **Weight** with the Up and Down keys, then Enter.
5. Enter the **Time** with the Up and Down keys, then Enter.
6. The first column blinks. Set the level for that segment and press Enter. Each next segment starts at
   the level of the one before it. Repeat until all **twenty segments** are set.
7. The message window then offers Start to begin and save the program, or Enter to modify it.
   Pressing Stop exits to the start-up screen.
8. Pressing Up or Down during the program changes only the resistance for the **current column**. When
   the profile moves to the next column it returns to the preset work level.
9. Press **Display** to scroll through the data in the message window.
10. When the program ends the message window shows a workout summary for a short time, then returns
    to the start-up display.

**Twenty segments, not eighteen.** The B94/R92 2016, 2019 and 2023 manuals print eighteen for their
User programs; every LCB and LCR manual prints twenty.

**The 2011 manuals swap the two prompts in the printed text.** Step 3 reads "enter your Age. You may
enter your **weight**..." and step 4 reads "enter your Weight. You may adjust the **age** number...".
The 2013 manuals correct this. The console asks for Age first, then Weight.
