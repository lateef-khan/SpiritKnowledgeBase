Press the program button, then Enter. Enter Age, Weight and Time. Set Max Level (highest colored segment/box). Then choose to turn on the incline profile: with it off you still control incline manually but automated incline changes stop; Enter finishes selecting. Start begins; Stop steps back. Level/Incline arrows adjust mid-program (current column only); Display scrolls data, Enter switches work/incline profiles; a summary ends the session.
