If you start a program without changing anything, the console uses these defaults:

| Setting | Default |
|---|---|
| Age | 35 |
| Time | 30:00 |
| Max Level - Hill | 7 |
| Max Level - Fatburn | 5 |
| Max Level - Cardio | 7 |
| Max Level - Strength | 8 |
| Max Level - Interval | 7 |

**The default Weight is not the same on all five machines.** The XE100 and XE200 console chapter
prints **155 Lbs**. The XE300 console chapter, in the same manual, prints **150 Lbs**, and so does
the XE350 and XE550 chapter in the XE150/XE350/XE550 manual. Both figures are printed as shown; do
not answer 150 for an XE100 or XE200.

**Age and Weight defaults are not fixed.** They change when you enter a new number, so the last age
and weight entered become the new defaults. You only re-enter them if your age or weight changes, or
if somebody else enters different ones.

**Only these five machines print the actual figures.** No Spirit commercial elliptical manual prints
a default table, and neither does any XE from 2010 on; from the XE395 2010 onwards the manuals say
only that "the default or saved settings will be used".

The XE100 and XE200 chapter also differs from the XE300 chapter on how long you keep burning
calories after a workout - it says "at an accelerated rate for at least an hour", while the XE300,
XE350 and XE550 chapters say "at about the same rate as during exercise for 20-30 minutes". Both are
printed in the same book.
