These consoles have no programs; a **target countdown** is the only workout setting. Set it
in STOP mode: press MODE until the function you want shows, press SET to raise the value
(hold SET to raise it quickly; press any key to stop), and the function counts down from
your value once you start. What each book prints:

| Machine | Targets | Ranges and behaviour as printed |
|---|---|---|
| AIR350 | TIME, CALORIES, DISTANCE | "Press MODE until the function you want is displayed. Make sure meter is not in SCAN. Press SET to increase the value"; RESET zeroes the settings; time 0:00-99:59, distance 0.1-999.9 |
| EU100 | time, distance, calories | press MODE to the function, SET to the number, MODE to accept; "The computer will beep to indicate the completion of your pre-set value. Press any button to stop the beep and the computer will now start to count up. If more than one value is preset, the first to reach the value will sound the alarm" and the next after you stop it; time to 99:00, distance to 999 miles, calories to 999 |
| FB160, FB360 | time, distance, calories, heart rate | "Press the MODE button until TIME appears, press SET button to set target time" (same for DISTANCE and CALORIE); "PULSE ... Press SET button to set target heart rate. The heart rate range can be set anywhere from **40 - 240 BPM**" |
| FB180 | time, distance, calories | the key list says "SET - Sets time, distance, calories" and "RESET - Resets time, distance, calories"; the function descriptions only count up and nothing says what happens at the target |
| MBX2500 | TIME, DISTANCE, CALORIES, PULSE | time **0:00 to 99:00**, distance **0:00 to 99:50**, calories **0 to 9990**; SET adjusts, MODE locks in; "When any function has been preset to a target the function will count down from the set value to zero. Once the target reaches zero, the monitor will beep for 8 seconds, and the function will begin counting up from zero if training is continued"; a pulse target beeps when reached (chest strap not included) |

The FB150, FB350, MB500, MB550, SB120 and UB120 have no countdown at all; see `see_also`.
