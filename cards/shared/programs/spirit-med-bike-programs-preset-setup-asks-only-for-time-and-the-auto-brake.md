**No age, no weight, no max level.** The 4.0 bikes ask for all three before a preset
(`spirit-bike-programs-preset-setup-steps`); on the 7.0 bikes that data lives in the Set Up menu and
a preset asks for two things only.

1. Select the desired program button, then press **Enter**.
2. Enter the **time** for the program with the Up and Down keys or the numeric key pad, then Enter.
3. **Turn the auto-brake on or off**, then Enter.
4. Press **Start**. You can go back and modify your settings by pressing Enter, and at any time
   during data entry the **Stop** key goes back one level or screen.
5. During the program the **Display** key scrolls the data in the message window, and the Display key
   beside the dot matrix switches between the **profile**, the **power** display and a **quarter mile
   track**.
6. When the program ends press Start to run it again, Stop to exit, **or the Facility key to save the
   program you just completed as the Facility program**.

**Why the picture never changes.** *"The profiles shown in the dot matrix are merely pictures of the
whole profile and will not change in size when the work level keys are pressed."* You enter the
maximum resistance for the peak of the profile at setup; during the program the resistance follows
the profile. **Pressing the work keys changes the peak level of the program, not the current
segment's level**, so the message window shows both the current segment's level and the peak, and
*"you may need to change the peak setting several times before the current segment increases."*

The manual prints no default time. The 7.0T treadmill's version of this page names a thirty minute
default and a three minute warm-up (`70t-2026-programs-preset-setup-steps`); neither figure is
printed for the bikes.

The 7.0R and 7.0U 2025 books and the Dyaco MED 7.0R 2021 edition print these steps in the same
words.
