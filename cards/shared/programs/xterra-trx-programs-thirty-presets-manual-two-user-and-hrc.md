The book documents **Manual**, **Built-in programs P1 to P30**, **User 1 and User 2**, and
**HRC** (heart rate control). The Dyaco service manual for both machines lists the PROGRAM
button's choices as "P1~P30, 1 HRC, 2 USER MODE".

**The 30 presets are printed only as pictures.** Pages 16 and 17 (printed 14 and 15) show
"Preset Program Displays" - a Speed and an Incline dot-matrix picture for each of P1 to P30 -
with **no figures and no names**. The dot matrix is "eighteen rows of dots (8 high)" that
"only show an approximate level (speed/incline) of effort".

Each built-in program asks for age, weight, time, a maximum speed and a maximum incline
("lift") before it starts; the setup steps, the Manual program, the User programs and HRC are
on their own cards.
