1. Press **PROGRAM** to select **CUSTOM PROGRAM**, then press **ENTER** to display **CUSTOM1**, then press **PROGRAM** to switch to **CUSTOM2**. Press ENTER to confirm; the dot matrix display will have a single row of dots at the bottom unless a program was previously stored. If a program is stored under the button pressed, it is retrieved. If not, you have the option of programming in your first name. The message window displays and flashes the letter **"A"**. Press any **Up** key for "B", or any **Down** key for "Z". After selecting a letter, press Enter. "A" is displayed and blinking again; repeat until all letters of your first name are programmed (**7 characters maximum**). When your name is displayed, press **Stop** and it is stored under either CUSTOM 1 or CUSTOM2.
2. The message window flashes **Age**. Use the **Incline + -** keys to adjust, then press Enter. **This is a must to continue even if age is not adjusted.**
3. The message window blinks a **body weight** value. Enter your body weight and press Enter.
4. The Time Window and Message Window blink a **Time** value. Adjust the time and press Enter.
5. The first column (segment) blinks. Using the **Speed + -** keys, set the speed level for the first segment, then press Enter. The second column blinks; repeat until all segments have been programmed. The first column blinks again - this is the incline programming; repeat the process for all segments.
6. Press the **Start** button to begin the workout and also save the program to memory.

**Note:** while in a User program, if you change the speed, all segment speeds from there on also change. For example, if you increase your current speed by 1 mph, the remaining segment speeds increase by 1 mph; if you decrease your current speed by 0.5 mph, the remaining segment speeds decrease by 0.5 mph.

The XT185 and XT285 manuals give no metric equivalents in that example, and no time default; the XT385, XT485 and XT685 manuals adjust the time up from 30 minutes and print the metric figures.
