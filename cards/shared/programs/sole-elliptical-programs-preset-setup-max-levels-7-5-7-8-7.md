Each preset (Hill, Fat Burn, Cardio, Strength, Interval) asks Age, Weight and Time, then Max Level — the peak exertion of the program. Factory Max Levels: Hill 7, Fatburn 5, Cardio 7, Strength 8, Interval 7. Press Start; Enter is described as going back, with the printed NOTE that Stop goes back one level. Raising/lowering load mid-program with Up/Down affects only the present position: the next column returns to the preset level. Enter (E35-family: the adjacent Display key) scrolls the Message Window; Start repeats or a User key saves the finished workout as a custom program at the end.
