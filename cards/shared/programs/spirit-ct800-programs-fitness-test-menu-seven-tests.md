The Fitness Test offers **seven** protocols: **Gerkin, Army, Navy, Air Force, Marines, PEB (Physical
Efficiency Battery) and Coast Guard.** Both manuals name the same seven; only the order printed
differs. The CT800ENT manual writes Marines as "Marine Corps" and spells PEB out as "Physical
Efficiency Battery".

**A contradiction in the 2020 manual:** its sentence reads "the dot matrix displays the 5 different
tests available: Gerkin, Army, Navy, Air Force, Marines, PEB, Coast Guard" - it says five and then
lists seven. The list of seven is what both this manual and the CT800ENT manual print elsewhere, and
both manuals print a standards table for all seven. The count of five is not reconciled anywhere in
the source and is recorded here as printed.

On the 2020 console the tests are reached with the **Fit-Test** button, then the arrow button and
**Enter**. On the CT800ENT touchscreen the Fitness Test button on the Exercise Programs menu opens
the list and you tap the test you want.

**Neither the WFI protocol nor the UK Chester Fireman test is on this menu**; those are CT900 and
CTSBS900 tests.
