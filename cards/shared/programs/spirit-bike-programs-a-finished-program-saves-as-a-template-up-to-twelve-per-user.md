**Every program can be saved as a template**, either once you have adjusted it or once you have
completed it. Press **Save as** to store it with the current settings.

- Saved programs are managed in **TEMPLATES**, one of the two categories on the Workout Programs
  screen.
- **To delete one:** tap it, then press **Delete** in the top right corner.
- **A maximum of 12 template programs can be stored.**
- **A template is only available to the user who created it.** The manual repeats this in the Profile
  section: different users can choose different unit systems, select their own favourite programs and
  save their own templates.

The XBR55ENT and XBU55ENT 2021 manuals both print this, word for word.

**Templates are not the same thing as Favorites.** A favourite is a label on any program that puts it
on the Homescreen and lists it in the FAVORITES tab of the Profile section, where it can be deleted; a
template is a stored copy of a program with your settings in it. The manuals give no limit on
favourites.

**No other Spirit bike manual gives a storage count.** The five commercial ENT touchscreens describe a
Custom program but never say how many can be kept or whether one overwrites another - see
`spirit-bike-programs-custom-twenty-segments-on-the-touchscreen`.
