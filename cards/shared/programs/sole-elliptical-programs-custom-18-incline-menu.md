U1/U2 keep a 7-character username. 1. Press USER 1/2; if empty 'A' blinks — Level arrows pick letters ('B' up, 'Z' down), Enter per letter, Stop finishes. 2. A stored program offers Run Program? Yes/No; No asks to delete — deleting is required to build anew. 3-5. The menu shows Age, then Weight, then Time. 6. Build the resistance profile to all eighteen segments. 7. Build the incline profile the same way. 8. Start begins and saves, Enter modifies, Stop exits. Mid-program changes affect the present column only; a summary ends the session. Finished workouts can also be stored to USER1/USER2 from the end screen.
