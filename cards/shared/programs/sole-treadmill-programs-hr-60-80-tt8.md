**You may use either the pulse grip sensors or a wireless heart rate chest strap (sold separately)** for either heart rate program — the only A1 books that allow the grips here. A strong, steady value in the heart rate window is still required.

- **HR1** defaults to **60%** of projected maximum; geared for **fat loss**.
- **HR2** defaults to **80%** of projected maximum; geared for improving **cardiovascular and lung function**.

1. Select **HR1 or HR2** via the Program keys, then press Enter.
2. The Message window blinks your **age**. Adjust or accept; **adjusting age changes the Target HR value**.
3. The Message window blinks the default **body weight**. Adjust or accept.
4. Adjust the **HR1/HR2 target** (60%: 220 - age x .60; 80%: 220 - age x .80); higher or lower allowed. Adjust with the Speed Up/Down keys and press Enter.
5. The Time window blinks. Adjust and press Enter.
6. Settings done: **press Start**; **Stop goes back one level or screen**.
7. **Speed may be changed anytime** with the Fast/Slow keys.
8. **Display scrolls** the message data; at the end a **summary** shows briefly, then start-up display.
9. Press Start to begin the program.

**The program controls the treadmill Incline** to raise heart rate to target automatically (upwards of five minutes; fitter takes longer). **Speed stays manual throughout, with message-window prompts** to reduce or increase speed depending on heart rate versus the selected percent.

The chest-strap-only menu-console version is on `sole-treadmill-programs-hr-60-80-menu`.
