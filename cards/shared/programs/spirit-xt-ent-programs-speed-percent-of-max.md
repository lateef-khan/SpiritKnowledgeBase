**A speed number in a preset program's profile is a percentage of the top speed of the program - the
max speed you set before you start - not a speed in mph or km/h.**

Both ENT manuals give a worked example.

- **XT485ENT (page 35):** the first Speed setting for the HILL program shows the number **20**, so
  that segment runs at **20% of the top speed**. If you set the top speed to **10 mph (16 kph)**, the
  first segment is **2 mph (3.2 kph)**. Segment **12** shows **100**, so the speed there is 100% of
  10 mph - simply 10 mph (16 kph).
- **XT685ENT (page 35):** if the max speed was set to **10.0** and the chart value is **20**, that
  segment's speed is **2.0**; a value of **100** means the segment runs at the max speed you set.
  **This manual adds that Incline values are absolute** - they are not scaled by anything you set.
  The XT485ENT manual does not print that sentence.

The programs this applies to are HILL, FAT BURN, CARDIO, STRENGTH and HIIT, which have preset speed
and incline changing profiles. **Time and maximum speed are the two settings both manuals say these
programs require;** once you choose your maximum speed, the program intensity adapts to it.
