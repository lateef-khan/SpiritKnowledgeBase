**None of these twelve consoles has a program of any kind.** Their console pages describe a
MODE key that steps through TIME, SPEED, DISTANCE, CALORIES, ODOMETER and PULSE (with a SCAN
that cycles them every 4 or 6 seconds), and nothing else:

| Machine | What the console can do beyond counting |
|---|---|
| AIR350 | a target countdown for time, calories or distance |
| EU100 | a target countdown for time, distance or calories |
| FB160, FB360 | a SET key for target time, distance, calories and a pulse alarm (40-240 bpm) |
| FB180 | a SET key that "sets time, distance, calories"; the book never describes the countdown |
| MBX2500 | a target countdown for time, distance, calories and a pulse alarm |
| FB150, FB350 | nothing - MODE only; the reset is holding MODE for 6 seconds |
| MB500, MB550 | nothing - a cycling computer with clock, auto timer, max/average speed, distance, odometer and calories, plus a user set for gender, weight, units and wheel size |
| SB120, UB120 | nothing - MODE only; holding it two seconds resets everything but the odometer |

The countdown targets are on their own card.

**Proved twice.** In every one of the twelve books the word "program" appears only on the
safety pages ("consult a physician before beginning this or any exercise program"); a
letter-spaced search, and searches for preset, interval, HRC, watt, user program, target and
count-down, hit only the countdown lines listed above. Each console chapter was read in full,
and every OCR supplement in each book (the MB500 is a scan, all eleven pages OCR) was read
for a flattened program page; none holds one. The MB550 and MB500 print the same cycling
computer; the FB350 book is the FB150's with a different cover; the FB360 is the FB160's.
