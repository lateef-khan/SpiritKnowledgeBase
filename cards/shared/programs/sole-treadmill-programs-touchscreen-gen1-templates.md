**Templates.** Every program can be saved as a template once adjusted or completed: press **"Save as"** to keep it with the current settings. Manage them in **TEMPLATES**; to delete one, tap it, then **"Delete"** in the top right corner. **Maximum 12 template programs.** A template is only available to the user who created it.

**Favorites.** Any program can be labelled **FAVORITE**; favorites appear on the **Homescreen** for immediate access.

**Profiles.** Press **+** on the starting screen for a new profile. With a **SOLE APP ACCOUNT**, scan the QR code in the pop-up: personal info uploads to the machine and the two profiles link, so workout history shows fully in the Sole app. **One Sole app account cannot link to multiple profiles on one machine.** Without an account, fill in the form (the book misprints "continiue"). Three tabs: **DATA** (physical data, editable via Save; SOME link here too), **HISTORY** (ten latest records of the current user only; tap for details; full history in the linked Sole app) and **FAVORITES** (view/delete). Different users can pick unit systems, favorites and templates.
