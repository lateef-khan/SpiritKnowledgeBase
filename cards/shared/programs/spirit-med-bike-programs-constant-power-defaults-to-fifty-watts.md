*"The Constant Power program automatically controls the resistance level at the pedals, depending on
user speed, to maintain a steady power workload."* Pedal slower and the resistance rises; pedal
faster and it eases; the watts stay where you set them.

1. Press the **Constant Power** key, then **Enter**.
2. Enter the **Time** with the Up and Down keys or the numeric key pad, then Enter.
3. Set the **target Watt Level**, then Enter. **The default setting is 50 watts.**
4. Turn the **auto-brake** on or off, then Enter.
5. Press **Start**; Enter goes back to modify, and Stop steps back one screen during data entry.
6. The Display key scrolls the data, and the Display key beside the dot matrix switches between the
   **power profile**, the **resistance profile** and a **quarter mile track**.
7. When the program ends press Start to run it again, Stop to exit, or the **Facility** key to save
   the program you just completed as the facility program.

**No age or weight is asked for** - the commercial CR/CU bikes' Constant Watt program asks for both
and prints no default (`spirit-bike-programs-constant-watt-program`). **No wattage range is printed
on the program page**; the work load range lives on the specification page and its spec card.

The 7.0R and 7.0U 2025 books and the Dyaco MED 7.0R 2021 edition print these steps and the 50 watt
default in the same words.
