Programs 14 to 17 are **User 1 to User 4**. You create the values in the order TIME,
DISTANCE, CALORIES and the resistance level in **10 columns**; the values and profile are
stored in memory after setup. Changing the load with UP/DOWN during a column does not change
the level stored in memory.

1. Use UP/DOWN to select a USER program (P14 to P17); press ENTER.
2. **Column 1** flashes - set its level with UP/DOWN, press ENTER. The default level is load 1.
3. **Column 2** flashes - set it, press ENTER.
4. Repeat until all ten columns are set; press ENTER to confirm the profile.
5. **TIME** flashes - set it, press ENTER.
6. **DISTANCE** flashes - set it, press ENTER.
7. **CALORIES** flashes - set it, press ENTER.
8. **PULSE** flashes - set it, press ENTER.
9. Press START/STOP to begin.

The SB150 and FS150 books' step 5 says "follow the above description 5 and 6" where the
SB250, EU150 and SB240 correctly say "3 and 4" - a numbering slip, the procedure is the same.
The profile page shows each user program as a sample ten-column picture with an arrow to an
empty grid.
