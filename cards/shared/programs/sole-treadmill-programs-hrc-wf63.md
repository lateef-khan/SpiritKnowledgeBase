**CAUTION: heart rate control programs are intended for the wireless transmitter chest strap only. Do not use the Pulse Grip bar.** A strong, steady heart-rate value is required.

**The Heart Rate Control program automatically controls incline** (the monitor works without the program in any mode). The book states **no default percentages and no Auto-Pilot** for H1/H2; the training-zone page alongside aims cardiovascular fitness at 80% and weight loss at 60% (see `sole-treadmill-programs-target-zone-w-series`).

1. Select **H1 or H2** via the PROGRAM keys, then press Enter.
2. The Calories window blinks the default **body weight**. Adjust or accept.
3. The Calories window blinks the **age**. Adjust or accept; adjusting age changes the target.
4. (The book numbers the next step 5.) The Time window blinks. Adjust the time and press Enter.
5. **Press Start to begin.**

The program then **steadily raises heart rate to the target automatically, which can take upwards of five minutes**; fitter people take longer.
