*"The manual program works as the name implies, manually. This means that you control the workload
yourself, not the computer."*

- Press the **manual key**, then **enter**.
- The message window prompts for **age, weight and time**. Enter each with the up and down keys **or
  the numeric key pad**, pressing enter to accept and move on.
- Press **start** to begin, or **enter** to go back and modify. **Stop** goes back one level or
  screen at any point during data editing.
- During the manual program the **enter** key scrolls the data in the message window.
- When the program ends, **start** repeats it, **stop** exits, **or you can save the program you
  just completed as a custom program by pressing the user keys** and following the message window.

**Manual asks for no max level**, because there is no profile to scale - unlike the four presets,
which ask for one; see
`spirit-rehab-stepper-programs-preset-setup-and-why-the-profile-picture-never-changes`.

**These manuals never say what level Manual starts at.** The Spirit steppers say level one; these
books do not say, and the figure must not be carried across - see
`spirit-stepper-programs-manual-starts-at-level-one-and-can-be-saved-as-custom`. The only program
these books give a starting level for is Symmetry, which starts at level 1.

**Pressing start without choosing a program** bypasses data entry and uses the data already held in
the Set Up menu.
