**This is the twenty segment version.** The CE800 2021, CE800 2023, CE850 2020, CE850 2022 and
CES880 2025 store **twenty-four** segments and cap the name at 7 characters.

The Custom Program lets you build and save a custom program, **or save any preset program you have
just completed as a custom program**. It can be personalised further by adding your facility name.

1. Press the **Custom** key. The Message Window shows a welcome message, carrying the name of any
   previously saved program. Press Enter to begin programming.
2. The window shows `Name - A` if no name is saved. If "Custom Workout" was saved it shows
   `Name - Custom Workout` with the C blinking. Up and Down change the letter, Enter saves it and
   moves on, **Stop** saves the whole name and continues. Stop also keeps an existing name unchanged.
3. Enter your **Age** (Up/Down keys or the numeric key pad).
4. Enter your **Weight**.
5. Set the **Time**.
6. Set the **Max Level** - the peak exertion level of the program. *(The CE850 2016 prints this as
   "the Max Level and Max Stride".)*
7. The first column blinks. Set the level for segment 1, then Enter.
8. The next segment starts at the previous segment's level. Repeat until **all twenty segments**
   have been set.
9. Press Enter to save. The window says "New program saved" and offers to start or modify the
   program. Stop exits to the start-up screen.
10. Up or Down during the program **only affects the present position in the profile**. When the
    profile moves to the next column it returns to the preset work level. *(This differs from a
    preset program, where Up and Down shift the whole profile.)*
11. During the program the Display key scrolls the Message Window and switches between the profile
    and a quarter mile track.

**A dangling reference in the source.** Step 11 says you "can switch to heart rate Auto-Pilot mode.
See Heart Rate section for details of this feature". **Neither the CE800 2013 nor the CE850 2016
describes Auto-Pilot anywhere.** The phrase appears exactly once in each document, here.

**What the feature is, is printed in a different book.** The Spirit XE150/XE350/XE550 owner's manual
defines it on printed page 33: at any time, during any program, pressing Auto-pilot switches the
console to heart rate control and holds your heart rate at the level it was at - see
`xe550-2005-programs-heart-rate-auto-pilot`. **That is the XE550's behaviour, not a statement about
the CE800 or CE850**, whose own manuals never say how their version works.

**The 2016 service manuals add two things the owner's manuals do not.** The CE850 2016 service
manual's console drawing labels **two** Custom keys - key 7 CUSTOM 1 and key 8 CUSTOM 2 - and its Quick
Start spec names "CUSTOM1, CUSTOM 2", where step 1 above says "the Custom key". Neither book says how
the second differs from the first; see `ce850-2016-programs-ten-numbered-program-keys-with-two-custom-and-two-heart-rate-keys`. The CE800 2016 service manual (a different
machine, not on this card) prints the save-on-finish half of this feature as a message: "PROGRAM END
PRESS START TO REPEAT OR STOP TO END OR USER KEY TO SAVE", with the USER key saving "in CUSTOM USER";
its face has one key, labelled CUSTOM, and it prints no segment count - see `ce800-2016-programs-ten-numbered-program-keys-with-fitness-test-and-constant-power`.
