**PEB (Physical Efficiency Battery) For U.S. Federal Law Enforcement.** A timed **1.5 mile / 2.4 km
run**; you control the speed manually. Maximum time allowed to pass:

| Age | Male | Female | Age | Male | Female |
|---|---|---|---|---|---|
| <=24 | 10:53 | 13:36 | 45-49 | 13:07 | 16:02 |
| 25-29 | 11:05 | 13:43 | 50-54 | 13:49 | 17:02 |
| 30-34 | 11:26 | 13:43 | 55-59 | 14:48 | 17:37 |
| 35-39 | 11:47 | 14:37 | 60+ | 15:07 | 17:37 |
| 40-44 | 12:28 | 15:12 | | | |

For more detailed information, visit: https://www.fletc.gov/peb-scores-age-and-gender

**The first bracket differs from the button consoles.** The 2024 CT800 and CT850 print **20-24 at
10:43**; this console prints **<=24 at 10:53** - a different bracket and a different time. Every
other row matches. See `ct900-law-enforcement-peb-fitness-test`.

The table is a flat image; these values were read from a 300 dpi render and checked twice.
