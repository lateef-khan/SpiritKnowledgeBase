On these five consoles, pressing Up or Down during a preset program **only affects the workload for
the present position in the profile**. When the profile changes to the next column, the workload
**returns to the preset work level**.

That is not a fault. It is printed as step 7 of every preset program in both manuals - Hill, Fat
Burn, Cardio, Strength, Interval - and again in the User 1 and User 2 custom programs.

**Every later Spirit elliptical does the opposite.** From the XE395 2010 onwards, and on every
Spirit commercial elliptical, Up and Down shift **the whole profile**, and the profile picture
deliberately does not redraw so that you can still see the shape of the workout. See
`spirit-ce-programs-preset-setup-steps`.

**Manual mode is not affected on any of them.** In Manual you set the workload yourself and it stays
where you put it.
