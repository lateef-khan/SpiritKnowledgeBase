This is the 20-percent chart: warm-up reads 20/30/40 and no incline goes below 0. The 40-percent chart with decline negatives is on `sole-treadmill-programs-touchscreen-chart-40-percent`.

Speed numbers are a **percentage of the max speed** set before start (chart 20 = 2.0 mph at a 10.0 mph max; 100 = the max). **Incline values are absolute.** Columns are 3 warm-up + 20 segments + 3 cool-down.
