No fitness test is printed for these machines: their program set is Manual, the five presets, custom user program(s) and the heart rate program(s), with no test chapter, button or score. The older-style fitness test exists only on the E98 books, and the 2023 touchscreen books carry a different YMCA-protocol test instead.
