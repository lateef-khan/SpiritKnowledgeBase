The program keys are used to **preview** each program. When you first turn the console on you may press each program key to preview what the program profile looks like.

If you decide that you want to try a program, press the corresponding program key and then press the **Enter** key to select the program and enter into the data-setting mode.

All five 2015 XT manuals print this paragraph in the same words. The 2023 XT consoles work differently: they have one **PROGRAM** key that steps through a named list instead of one key per program.
