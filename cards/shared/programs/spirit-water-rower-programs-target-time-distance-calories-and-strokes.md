*"Target Time, Target Distance, Target Calories, and Target Strokes program allow the target goal of
each value to be customized."*

1. **Launch** - press the desired **TARGET** button (TIME, DISTANCE, CALORIES, STROKES). There is a
   separate button for each.
2. **Setup** - after the console has been reset, enter the target value. **Adjust with the up and
   down arrows, then press ENTER to confirm.**
3. **Start** - each mode's display field lights up and reads out: the **time target counts down**,
   while the **distance, calories and strokes count up** toward theirs.
4. **End** - *"The mode will end when the target is achieved."* Pressing **RESET** at any time also
   ends it. **The workout summary is shown afterwards** - Total Time, Total Distance and Total Watts.

**The two machines behave differently when you enter nothing**, and this is the only difference on
the page:

| Machine | If no value has been entered |
|---|---|
| **CRW800H2O** | *"the console will not count down"* |
| **CRW900** | *"the console will use the last setting as the target value on each mode"* |

**No default figure is printed for any of the four targets on either machine**, and no maximum or
increment is given. The air rowers do print defaults - 100 M, 1:00 and 100 calories, in 50 M, 1
minute and 10 calorie steps - but those are a different console and must not be quoted here; see
`crw800-2024-programs-the-three-countdown-target-modes`.

*The CRW900 page ends the Target Heart Rate program "when the user stops **pedaling**" - a bike
sentence in a rower book. The CRW800H2O says "stops **rowing**". Recorded as printed.*
