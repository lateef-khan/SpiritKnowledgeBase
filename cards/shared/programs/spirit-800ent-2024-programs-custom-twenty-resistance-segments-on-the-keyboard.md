You create the desired **resistance levels for each of the 20 segments** of the program using the
keyboard on the screen. **You may change these levels at any time during the workout.**

1. Select the **Custom** program to begin customizing it with your personal data.
2. To adjust the resistance level profiles, use the on-screen interface to complete the desired
   workout profile **and desired workout time**. Once complete, press **Start this program**.

The LED consoles in the same 2024 range build a Custom program from console windows instead, and
store **twenty-four** resistance segments under a seven character name - see
`spirit-ce-programs-custom-twenty-four-segments` and
`spirit-bike-programs-custom-twenty-four-segments-and-a-seven-character-name`. **The touchscreen
stores twenty and asks for no name.**
