The Borg rate of perceived exertion (RPE) scale, by Swedish physiologist G.A.V. Borg, rates exercise intensity from 6 to 20 by how the effort feels:

| Rating | Perception of Effort |
| --- | --- |
| 6 | Minimal |
| 7 | Very, very light |
| 8 | Very, very light + |
| 9 | Very light |
| 10 | Very light + |
| 11 | Fairly light |
| 12 | Comfortable |
| 13 | Somewhat hard |
| 14 | Somewhat hard + |
| 15 | Hard |
| 16 | Hard + |
| 17 | Very hard |
| 18 | Very hard + |
| 19 | Very, very hard |
| 20 | Maximal |

Add a zero to a rating for an approximate heart rate: a rating of 12 is about 120 beats per minute.
