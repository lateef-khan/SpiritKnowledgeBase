The E20 has no incline, no heart-rate programs and no fit-test. E20-2016: Manual, five presets (Hill, Fat Burn, Cardio, Strength, Interval) and U1/U2 custom slots, scrolled with the single Program key. E20-2020: Manual plus five presets with HIIT in place of Interval (render-verified console keys) — and no custom slots at all: the 2020 book prints Manual and preset setup only, with no USER PROGRAMS chapter (loose and spacing-tolerant greps for user/custom/HR/fit-test across the book return only unrelated prose).
