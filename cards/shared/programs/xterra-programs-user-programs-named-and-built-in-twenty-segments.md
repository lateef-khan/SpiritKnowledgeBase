"The User Programs allow you to build and save your own workout."

1. Select **User 1 or User 2** (Program up/down keys, or the User button on the SB4.5r) and
   press Enter. If a program is already stored the message asks "**Run Program?**" - Yes
   (Enter or Start) runs it; No lets you cancel the stored program and create your own.
2. With no program stored (or after cancelling), the letter "A" flashes: pick each letter of
   your **name** with the Level up/down keys and Enter; press **Stop** to accept the name.
3. Enter your personal data and the program length, pressing Enter after each:

   | Book | Prompts |
   |---|---|
   | SB500 | Age, Weight, Time, **Top Level** |
   | SB4.5r | Weight, Age, Time |
   | FS5.8e, FS5.9e | Weight, Age, Time |

4. The message window asks for the **first segment level** for Resistance - set it with the
   Level keys, press Enter. Each next segment starts at the previous segment's level; repeat
   "until all **twenty** segments have been set".
5. On the FS5.8e and FS5.9e, repeat the same process for twenty **Incline** segments with the
   Incline up/down keys.
6. The window asks you to press Enter to **save** the program; then press Start.
7. Level (and Incline) keys adjust the workload at any time during the program; Enter
   switches the data displayed; at the end a summary shows before the start-up display.

The Sole B94/R92 bikes' user programs are the same design; see `see_also`.
