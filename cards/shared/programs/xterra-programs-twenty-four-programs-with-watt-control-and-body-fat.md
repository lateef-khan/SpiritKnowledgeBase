The console counts its programs **P1 to P24**:

| Programs | What they are |
|---|---|
| 1 | **Manual** - you control the tension level |
| 2 to 13 | **Twelve presets**: Steps, Hill, Rolling, Valley, Fat Burn, Ramp, Mountain, Intervals, Random, Plateau, Fartlek, Precipice |
| 14 to 17 | **Four user setting programs** (User 1 to User 4) |
| 18 to 22 | **Five heart rate control programs** - 55%, 65%, 75%, 85% and Target |
| 23 | **Watt control program** |
| 24 | **Body fat program** |

Every program is entered the same way: select it with UP/DOWN, press ENTER, set the
flashing targets (TIME, DISTANCE, CALORIES, PULSE) one by one with UP/DOWN and ENTER, then
press START/STOP. Reaching any target makes the computer beep and stop; press START/STOP to
carry on to the next target you set. UP and DOWN change the tension level while you exercise.

The SB150 and FS150 print the same console with **23** programs - no watt control, and body
fat is program 23; see `see_also`. The SB240 book adds a **Quick Start**: press START/STOP
without selecting a program for a manual workout with time counting up from zero.

Each program group has its own card: manual, preset profiles, user, heart rate control,
target heart rate control, watt control and body fat.
