**No.** Each console has one button, **MODE**, and the book describes nothing but readouts:

| Book | MODE does | Readouts scanned | Auto-off |
|---|---|---|---|
| ERG160 | selects a function; held 2 seconds, resets all to zero | time, stroke count, distance, calories, SPM - **6 seconds each** | 2 minutes |
| ERG220 | cycles the arrow to a readout; held 2 seconds, resets all but the odometer | time, distance, calories, SPM, pulse (and count) - **6 seconds each** | 4.5 minutes |

There is no SET key, no target time, distance, count or calorie value, no countdown, no preset
profile, no interval, no heart rate program and no heart rate exertion page. The books' contents
pages list only "Operation of Your Console"; grep for *target*, *set*, *count down*, *preset*,
*interval*, *goal* and *Borg* finds nothing in either, and the console drawing on each book's
console page, read from a render, shows the single MODE button and the readout labels only.

**The ERG180's console looks the same but adds a SET button and four target modes** - see
`see_also`. The console readout ranges belong to the console cards.
