There are **two** customisable User programs, **User 1 and User 2**. They operate exactly the same
way. You can build a program from scratch, **or save any preset program you have just completed as a
custom program**, and you can personalise either by adding your name.

1. Press the **User 1** or **User 2** key. The message window shows a welcome message carrying the
   name of any program already saved. Press **Enter** to begin programming.
2. The window shows `Name - A` if no name is saved. If "David" was saved it shows `Name - David`
   with the D blinking. Up and Down change the letter, **Enter** saves it and moves to the next, and
   **Stop** saves the whole name and continues. Stop also keeps an existing name unchanged.
3. Enter your **Age**.
4. Enter your **Weight**.
5. Set the **Time**.
6. Set the **Max Level** - the peak exertion level of the program. **The factory setting is level
   seven.**
7. The first column blinks. Set the level for segment 1, then Enter.
8. The next segment starts at the previous segment's level. Repeat until **all twenty segments** have
   been set.
9. Press Enter to save. The window says "New program saved" and offers to Start or modify the
   program. **Stop** exits to the start-up screen.

**The XE395 2010 works differently enough to have its own card.** It has no Max Level step, and after
the twenty resistance segments it asks you to build a second twenty-segment **Incline** profile - see
`xe395-2010-programs-custom-user-resistance-then-incline`.

**During the program.** On the XE100, XE200, XE300, XE350 and XE550, Up and Down affect only the
column you are in - see `spirit-xe-programs-up-and-down-change-only-the-current-column`.

**A different Custom program on the later machines.** The XE195 has none at all; the XE295, XG400 and
XE795 2021 cap the name at seven characters and ask "Run Program?" before letting you overwrite; the
XE395 2023 and XE795 2023 call the two slots **Custom 1 and Custom 2**. The commercial CE800 and
CE850 have a single Custom key.
