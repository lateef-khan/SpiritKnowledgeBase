1. Press the **Facility** key, then **Enter**.
2. Enter the **Time**, then press enter. Then press **start** to begin the program.

The program this runs is the one saved with the facility key - see
`70t-2026-programs-facility-program`, which covers building and saving it on both the 7.0T and the
MT200.

**The MT200 has no separate `user` key.** On the 7.0T a saved program is run from a `user` key
instead; the step order is otherwise the same. See `70t-2026-programs-running-a-saved-program`.
