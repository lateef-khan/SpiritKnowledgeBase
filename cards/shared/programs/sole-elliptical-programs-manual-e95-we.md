Manual means you control the workload, not the computer. Steps are numbered 9-16 continuing the chapter: press Manual, then Enter; enter Age (Up/Down or numeric keypad), Weight, Time; Start begins (Stop steps back, Enter is also described as going back); you start at level one for warm-up, Up/Down adjust load; Enter scrolls the Message Window; at the end press Start to repeat, Stop to exit, or a User key to save the finished workout as a custom user program.
