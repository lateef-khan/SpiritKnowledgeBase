1. Select **User 1** or **User 2** via the Program key, then press **Enter**. The dot matrix
   shows a single row of dots at the bottom unless a program is already stored.
2. The Message window blinks an **age** value. Adjust, press Enter.
3. It blinks a **body weight** value. Enter it, press Enter.
4. It blinks a **time** value. Adjust, press Enter.
5. **The first column (segment) blinks.** Set it with Speed up/down, press Enter; the second
   column blinks; repeat until all segments are programmed. Then press ENTER to confirm and
   enter **incline programming**; repeat for all segments.
6. Press **START** to begin the workout **and save the programmed speed and incline values**.

The book does not say how many segments there are; the dot matrix has eighteen columns.
