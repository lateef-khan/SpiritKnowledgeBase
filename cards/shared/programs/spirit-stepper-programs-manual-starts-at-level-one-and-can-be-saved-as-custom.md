The Manual program works as the name implies: **you control the workload, not the computer.**

1. Using the **Program** button select **Manual**, then press **Enter**.
2. Enter your **Age**. On the CS800 you may use the Up and Down buttons **or the numeric button
   pad**; the CRS800S names only the Up and Down buttons.
3. Enter your **Weight**, then Enter.
4. Set the **Time**, then Enter.
5. Press **Start** to begin, or **Enter** to go back and modify. At any time while editing data,
   **Stop** goes back one level or screen.
6. **The program automatically starts you at level one.** This is the easiest level and it is a good
   idea to stay there for a while to warm up. Press **Up** (CS800) or **Level Up** (CRS800S) to
   increase the workload; Down decreases it.
7. During the program the Up/Down Scan button beside the LED Data Display Window scrolls through the
   data. **On the CS800 the same button also switches between the profile display and a quarter mile
   track.** The CRS800S does not print that sentence.
8. When the program ends, press **Start** to run it again, **Stop** to exit, **or save the program
   you just completed as a Custom program** by pressing the Program button, selecting Custom, and
   following the Dot Matrix Message Center.

**Manual asks for no Max Level**, because there is no profile to scale.

**The 2021 printings carry the same eight steps.** The quarter-mile-track sentence in step 7 is on the
CS800 in both years and on neither CRS800S printing.
