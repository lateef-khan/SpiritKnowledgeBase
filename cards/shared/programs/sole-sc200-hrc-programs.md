Both programs work the same way; the only difference is that HR1 aims at 60% and HR2 at 80% of the maximum heart rate.

1. Press the HR1 or HR2 key, then press Enter.
2. Enter your Age, then Weight, then Time, pressing Enter after each.
3. Adjust the Target Heart Rate and press Enter. The shown rate comes from the program's percentage; changing the number raises or lowers that percentage.
4. Press Start to begin. Stop steps back one screen during setup.
5. During the program the Level key changes the target heart rate at any time.
6. Press the Display key to scroll through the data in the Message Window.
7. When the program ends, press Start to run the same program again or Stop to exit.

The program automatically controls resistance at the pedals, so a pulse signal (hand grips or the optional chest strap) is required for it to work.
