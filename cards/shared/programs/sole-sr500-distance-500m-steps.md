A target distance count-down mode.

1. Use the UP/DOWN buttons to set the workout distance. The default is 100M and it changes in 500M steps up or down.
2. Press Start/Stop to confirm the setting and start the mode.
3. The centre of the LCD scans every 5 seconds between the wave pattern and 500M/TIME; MODE holds one or the other.
4. The Distance window counts down from the target and shows the remaining distance.
5. Pressing UP or DOWN during the workout adjusts the resistance level.
6. At 0 the workout completes and the buzzer sounds one long beep. If paddling continues the count-down repeats.

**The 2016 service-manual card prints 50M steps for the same mode.** These two owner's books print 500M steps; follow the book for the machine in front of you.
