**Target programs can be set a Target Time, a Target Distance or Target Calories for your workout. When the program begins the target item counts down; once it reaches zero the program ends.**

1. Press the **PROGRAM** key to select **TARGET PROGRAM**, then press **Enter**.
2. Press the **PROGRAM** key to select the Target Time program, Target Distance program or Target Calories program. Press **Enter** to set the program. The display prompts you through the programming, or you can just press **Start** to begin the program with default values.
3. If Enter was pressed, the Message Center blinks a value indicating your **Age (default is 35)**. Use the + or - keys to adjust, then press Enter.
4. The Message Center blinks a value indicating your **Body Weight (default is 150 lb / 70 kg)**. The correct body weight affects the calorie count. Use the + or - keys to adjust, then press Enter.
5. The Message Center blinks the target for the program you chose:
   - Target Time - **Time, default 5 minutes**
   - Target Distance - **Distance, default 1.0 mile**
   - Target Calories - **Calories, default 300**

   Use any of the + or - keys to adjust the target item, then press Enter to accept.
6. You are then done programming and may press **Start** to begin your workout.
