**This is the WFI test, not the Gerkin protocol.** They run the same stage chart, but the score is
calculated differently.

The WFI test is a **modified Gerkin protocol**. The actual test is the same as the Gerkin chart, but the
score is calculated differently. **Neither manual states the WFI scoring formula itself**, only that it
differs from Gerkin's.

Which Gerkin chart it follows depends on the machine: the 4.0T prints one chart and the 8.0T another, and
they differ. The 7.0T has no WFI test at all.

*The 4.0T manual immediately follows this paragraph with an unrelated 18-minute "Program Speed and Incline
Chart", which contradicts the sentence above - see `40t-2026-programs-wfi-speed-incline-chart`.*
