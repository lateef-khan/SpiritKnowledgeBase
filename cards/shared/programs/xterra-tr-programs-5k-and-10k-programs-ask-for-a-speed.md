1. Press **Enter/Program**, use **Speed up/down** to select **5K PROGRAM** or **10K PROGRAM**,
   press Enter/Program. The display prompts you to program it, or press **Start** to use the
   default values.
2. **Age** - adjust, press Enter/Program (age sets the recommended maximum heart rate for the
   bar graph and heart-rate programs).
3. **Body Weight** - adjust, press Enter/Program.
4. The message window displays **"USE SPEED Up / Down KEYS TO ADJUST SPEED"**. Set the speed,
   press Enter/Program.
5. Press **Start** to begin, or **Stop** to go back one level.

The book does not say whether the distance counts down, how the incline behaves, or what
happens when the distance is reached. Spirit and Sole print the same programs with more
detail; see `see_also`.
