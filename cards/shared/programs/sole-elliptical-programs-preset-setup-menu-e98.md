Press the program button (the menu takes it from there). The menu shows Age first, then Weight, then Time (Level arrows, Enter each). Set Max Level (highest colored segment/box). Choose to turn on the incline profile — off leaves manual incline live but stops automated changes; Enter finishes. Start begins; Stop steps back. Level/Incline arrows adjust mid-program; DISPLAY changes the shown data in Manual-mode wording; a summary ends the session.
