*"The Isokinetic program provides accommodating resistance at a fixed speed level. The user controls
the resistance at the pedals by pushing harder or lighter. The desired pedaling speed is entered and
the computer increases the resistance automatically if the user tries to overcome the set speed."*

1. Press the **Isokinetic** key, then **Enter**.
2. Enter the **Time** with the Up and Down keys or the numeric key pad, then Enter.
3. Set the **target RPM Level**, then Enter. **The default setting is 30 RPM.**
4. Turn the **auto-brake** on or off, then Enter.
5. Press **Start**; Enter goes back to modify, and Stop steps back one screen during data entry.
6. The Display key scrolls the data, and the Display key beside the dot matrix switches between the
   **speed profile**, the **power profile** and a **quarter mile track**. **An RPM graph to the right
   of the dot matrix monitors your speed** - the console overview labels it "RPM scale for
   isokinetics only".
7. When the program ends press Start to run it again, Stop to exit, or the **Facility** key to save
   the program you just completed as the Facility program.

**No RPM range is printed.** The specification page calls the resistance "Constant and Isokinetic
with 50 levels of effort"; how those levels map onto the speed the program holds is not stated.

The 7.0R and 7.0U 2025 books and the Dyaco MED 7.0R 2021 edition print these steps and the 30 RPM
default in the same words. The i-Strength machines' Isokinetic mode is a different thing on a
different product (`spirit-strength-programs-isokinetic-training-mode`).
