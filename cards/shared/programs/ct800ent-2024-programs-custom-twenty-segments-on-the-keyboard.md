You create the desired **speed and incline levels for each of the 20 segments** of the program using
the keyboard on the screen. **You may change these levels at any time during the workout.**

1. Select the **Custom** program to begin customizing it with your personal data.
2. To adjust the Speed and Incline profiles, use the on-screen interface to complete the desired
   workout profiles. **Remember to give max. speed and desired workout time.** Once complete, press
   **Start this program**.

The setup screen shows a **Set Speed Profile** column strip with a **Select Max** value beside it
(illustrated at 8.0), then the same for incline.

**Custom has no warm-up** - see `ct800ent-2024-programs-all-programs-menu-of-eleven-entries`.

The button consoles in the same range build a Custom program segment by segment from console
windows instead, and save it by pressing Start - see `spirit-ct800-programs-custom-program-build`.
