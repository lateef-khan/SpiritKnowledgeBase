Press the program button, then Enter. Enter Age, Weight and Time with the Level arrows. Set Max Level — the peak exertion, the highest colored segment/box of the profile. Start begins; Stop steps back. Level/Incline arrows adjust resistance or incline mid-program; Display scrolls data and Enter switches the dot matrix between work and incline profiles; a summary ends the session. The 2023 E25 adds an incline-profile on/off question (see the toggle card).
