1. Start rowing directly with START/STOP from the main menu, or select Manual and press ENTER.
2. Set target values for TIME, METERS, CALORIES and PULSE with UP/DOWN, confirming each with ENTER. Time and Meters cannot both be preset.
3. Press START/STOP to start. UP/DOWN adjusts the resistance level from 1 to 16 during the workout.
4. A preset value counts down to 0 then stops the console with a bi-bi alarm for 8 seconds; any key stops the alarm.
5. START/STOP pauses the workout with all values saved; WATT and TIME/500M show average values.
6. RESET returns to the main menu.
