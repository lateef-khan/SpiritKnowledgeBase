U1 and U2 hold twenty-segment workouts with no naming step. 1. Select U1/U2, Enter. 2. Enter Weight (Up/Down), Enter. 3. Enter Age, Enter. 4. Enter Time, Enter. 5-6. Build the level profile column by column to all twenty segments. 7. E35 only: build the Incline profile the same way. 8. Start begins and saves, Enter modifies, Stop exits. Mid-program Up/Down changes only the present column; Display scrolls data; a summary ends the session.
