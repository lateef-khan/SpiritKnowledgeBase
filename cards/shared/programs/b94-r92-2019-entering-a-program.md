1. Press each program button to scroll through the program selections. The profile for each program is displayed in the dot matrix window.
2. Press **Enter** to select a program and begin customizing the settings.
3. To work out without entering new settings, press **Start** instead. This bypasses the programming of data and takes you straight to the start of the workout, using the default settings.
4. To change the personal settings, follow the instructions in the Message Window.
