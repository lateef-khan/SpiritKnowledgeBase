Press the program button, then Enter. Enter Age, Weight and Time with the Ramp or Level Up/Down keys. Set Max Level, the peak exertion of the program. Then choose to turn off the incline profile — off leaves manual incline control live. Start begins; Stop steps back. Ramp/Level Up/Down adjust resistance or incline mid-program (current column only); Display scrolls the message window; a summary ends the session.
