U1/U2 keep a 7-character username. 1. Select U1/U2, Enter; if empty the letter 'A' blinks — Level arrows pick letters ('B' up, 'Z' down), Enter per letter, Stop finishes. 2. A stored program offers Run Program? Yes/No; No asks to delete — deleting is required to build anew. 3-5. Enter Age, Weight, Time. 6. Build the resistance profile column by column to all eighteen segments. 7. Build the second profile the same way (incline; stride on the E95s — see its card). 8. Start begins and saves, Enter modifies, Stop exits. Mid-program changes affect the present column only; Display scrolls data (Enter switches work/incline views); a summary ends the session.
