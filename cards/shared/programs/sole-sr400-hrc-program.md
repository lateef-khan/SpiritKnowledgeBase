1. Select H.R.C. and press ENTER.
2. Set AGE (preset 25) and press ENTER.
3. Select 55%, 75%, 90% or TAG (target). The PULSE window shows the corresponding preset: 55% is 107 bpm, 75% is 146 bpm, 90% is 175 bpm, TAG is 100 bpm.
4. On TAG the flashing 100 can be reset with UP/DOWN from 0-30 up to 230.
5. Preset the TIME, then START/STOP to work out. The system adjusts the load level automatically from the rowing status.
6. START/STOP pauses with all values saved; the countdown ends with an 8-second alarm; RESET returns to the main menu.
