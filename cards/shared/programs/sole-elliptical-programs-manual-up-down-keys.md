Manual means you control the workload, not the computer. 1. Press Manual, then Enter. 2. Enter Age (Up/Down or numeric keypad), Enter. 3. Enter Weight, Enter. 4. Enter Time, Enter. 5. Press Start (the step says Enter goes back a screen; the printed NOTE says Stop goes back one level — both are printed, Stop is the consistent one). 6. You start at level one: warm up there, then raise load with Up (Down lowers it). 7. Enter scrolls the Message Window data (E35/E75/E95 books: the Display key switches profile and quarter-mile track views). 8. At the end press Start to repeat, Stop to exit, or a User key to save the workout you just finished as a custom user program.
