Both programs work the same; HR1 defaults to 60%, HR2 to 80% of max. 1. Press HR1/HR2 (E95s overlay: HRC1/HRC2). 2. The menu shows Age first (Level arrows or numeric keypad; 'next page'). 3-4. Enter Weight, Time. 5. Adjust the Target Heart Rate. 6. Start begins; Enter is described as going back, with the printed NOTE that Stop goes back one level. 7. Level arrows during the program change the target. 8. Start repeats, Stop exits. **There is no Display-scroll step**, unlike the button consoles. A steady pulse signal is required.
