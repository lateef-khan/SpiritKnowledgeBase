A timed **3 mile / 4.8 km run**. You control the speed manually. Maximum time allowed to pass:

| Age | Male | Female |
|---|---|---|
| <=26 | 28:00 | 31:00 |
| 27-39 | 29:00 | 32:00 |
| 40-45 | 30:00 | 33:00 |
| 46+ | 33:00 | 36:00 |

For more detailed information, visit: https://bit.ly/SF-Marines

**These are the same times the button consoles print**, but the first bracket is written **<=26**
here and **17-26** there, and this manual adds the metric distance - see
`ct900-marines-pft-fitness-test`. The table is a flat image; these values were read from a 300 dpi
render. See also `ct800ent-2024-programs-editorial-note-printed-in-the-manual`.
