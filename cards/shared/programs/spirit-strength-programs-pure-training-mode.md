**PURE is the ordinary mode**: the manual calls it *the type of exercise you've been
doing in the gym from the start*. It controls the concentric and the eccentric muscular
action, and it needs almost no console setup.

To run a set:

1. From the Setup Screen, set the resistance - press the **+** or **-** buttons, or
   slide a finger left or right along the bar.
2. Press the blue **BEGIN** button.
3. The Progress Screen counts the set in real time. A blue **Progress Bar** slides right
   to show the range of motion of each repetition.
4. Resistance can be changed mid-set from the same **+**, **-** or slide bar.
5. **See Chart** in the upper corner switches to a **Bar Graph** of the concentric and
   eccentric movements against milliseconds and repetitions. The set can be ended from
   that screen too.
6. When the repetitions are done, press **End Set**.
7. On the Summary Screen, **End Session** finishes, **Repeat Set** starts another set
   with every measurement reset to zero.

PURE is also the only mode that offers the **Strength Test** - see
`spirit-strength-programs-strength-test-and-three-workout-goals`.

**Pure is not the Sole SRVO's Standard mode.** Both give one resistance in both
directions, but they are different machines from different brands; see
`srvo-mode-1-standard`.
