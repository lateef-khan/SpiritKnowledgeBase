This variant differs from `sole-treadmill-programs-user-named-menu` in the naming keys only: **STOP advances each letter and ENTER stores the finished name** (the menu card has it the other way round). Everything after the naming matches.

1. **Select User 1 or User 2** via the Program keys. The dot matrix shows a single row of dots at the bottom unless a program is already stored; a stored program under that button is retrieved instead.
2. **Name it (first program only).** The name window shows "A"; step the letter with the arrow keys ("B" on up, "Z" on down), then press **STOP**. "A" shows again; repeat per letter, up to **7 characters**. When the name is displayed, press **ENTER** to store it under User 1 or User 2.
3. The menu shows the **Age window** first. Adjust and press Enter — **this is a must to continue even if age is not adjusted**.
4. The **Weight window** shows a body weight value. Enter it and press Enter.
5. The **Time window** shows a Time value. Adjust and press Enter.
6. The **first column (segment) blinks**. Set the **speed** for segment 1, press Enter, and repeat for every column. The first column then blinks again for **incline**: repeat for all incline segments.
7. **Press Start to begin the workout and also save the program to memory.**

**Changing the speed mid-workout shifts all later segments too**: "If you increase your current speed 1 mph, the remaining segment speeds will increase by 1 mph. If you decrease your current speed .5 mph, the remaining segment speeds will decrease by .5 mph, etc." All four books print the note with the worked example.
