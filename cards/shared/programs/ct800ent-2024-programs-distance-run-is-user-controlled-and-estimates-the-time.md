**Both speed and incline are controlled by the user.** Increase or decrease levels at any time
during your workout. When the program begins the distance begins to **count down**; once it reaches
zero the program ends.

The setup screen asks for a **Target Speed** (illustrated at 8.0) and prints an **Estimated Time**
beside it (illustrated as 23:15) - a figure the button consoles never show.

*The manual notes that the Speed readout is in **KPH if the console is not set to display Metric
measurements**. That is the wrong way round: the button-console manuals in the same range say the
readout is in MPH if the console is not set to Metric. The sentence is recorded here as printed.*

**5K Run and 10K Run have no warm-up.**

The button consoles describe the same two programs as an automatic 5 km or 10 km goal shown on the
track display - see `ct800-2020-programs-10k-run` and `ct900-5k-run-program`.
