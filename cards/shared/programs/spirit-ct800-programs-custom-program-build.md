1. Select the **Custom** program then press **Enter**. The dot matrix display lights a single row of
   dots at the bottom, unless there is a previously saved program.
2. The clock (**Time**) window flashes. Use the up and down adjustment keys to set the program for
   the desired time, then press **Enter**. *This is a must to continue even if the time is not
   adjusted.*
3. The **Incline** window now blinks a value indicating your **Age**. Adjust, then press Enter.
4. The **Distance** window now blinks a value indicating your **Bodyweight**. Entering your correct
   bodyweight affects the Calorie readout accuracy. Adjust, then press Enter.
5. The first **speed** setting column (segment) blinks. Adjust the speed to your desired effort
   level for that segment, then press Enter. The second column then blinks. **The previous segment's
   value is carried over to the new segment.** Repeat until all segments have been programmed.
6. The first column blinks again; the console is now ready for the **incline** settings. Repeat the
   same process for every segment.
7. Press **Start** to begin the workout **and also save the program to memory**.

**The manuals never say how many segments a Custom program holds.** They say only "repeat the above
process until all segments have been programmed". Do not assume the twenty segments the CT800ENT
touchscreen uses - see `ct900ent-custom-program`.

The 2012 and 2016 manuals add to step 3 that entering the correct age affects the Heart Rate Bar
Graph accuracy; the 2020 manual drops that sentence. The steps are otherwise identical in all three.

**The 2016 and 2020 CT850 owner's manuals print these same seven steps word for word** (both on
printed page 25), including the single row of dots, the carried-over segment value and the Start
button that saves the program to memory. Like the 2012 and 2016 CT800 manuals they say the
bodyweight affects the **Calorie** readout accuracy; they do not add the Heart Rate Bar Graph
sentence to step 3. Their step 1 names a **Program** button.

**The 2018 CT850 builds into one of two user memories, U1 or U2, and is a different procedure** -
see `ct850-2018-programs-custom-program-u1-u2`.
