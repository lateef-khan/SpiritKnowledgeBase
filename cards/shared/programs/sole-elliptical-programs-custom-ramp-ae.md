U1/U2 keep a 7-character username. 1. Select U1/U2, Enter; if empty, the letter 'A' blinks — pick letters with the Ramp/Level buttons (Up='B', Down='Z'), Enter per letter, Stop finishes. 2. If a program is stored you are offered Run Program? (Yes/No with Ramp/Level); No asks whether to delete it — deleting is required before building a new one. 3-5. Enter Age, Weight, Time (Ramp/Level). 6. Build the level profile column by column to all twenty segments. 7. Build the incline profile the same way. 8. Start begins and saves, Enter modifies, Stop exits. Mid-program changes affect the present column only.
