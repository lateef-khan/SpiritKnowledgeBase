**The XT185 and XT285 manuals give Fusion only as a setup sequence — they print no description of what the program does, and no interval, recovery or exercise detail. The XT385, XT485 and XT685 manuals describe all of that; see the linked card.**

1. Press the **PROGRAM** key to select the program. The screen prompts you to program it. You can also press **Start** to start the program using the default values.
2. If Enter was pressed, the Message Center blinks a value indicating your **Age**. Use the + / - keys to adjust, then press Enter. Your age determines your recommended maximum heart rate, which the Bar Graph Display and the Heart Rate features are based on.
3. The Message Center blinks a value indicating your **Body Weight**. The correct body weight affects the calorie count. Use the + / - keys to adjust, then press Enter.
4. The Message Center blinks the **preset top speed** of the selected program. Use the Speed + / - keys to adjust, then press Enter.
5. The Message Center blinks the **preset top incline** of the selected program. Use the Incline + / - keys to adjust, then press Enter.
6. The message center flashes the selected program's **interval motion (preset to 10)**. Adjust with the + / - key, then press Enter.
7. The information center flashes the **interval** of the selected program (**preset to 1**). Use the + / - key to adjust, then press Enter.
8. You are then done programming and may press **Start** to begin your workout, or **Stop** to go back one level to change data entered in the programming phase.

The manual contradicts itself between steps 5 and 8: step 5 ends "You are now done programming data and may press Start to begin your workout or Enter to go back one level", yet steps 6 to 8 follow and step 8 names **Stop** as the key that goes back one level. Both sentences are printed as shown.
