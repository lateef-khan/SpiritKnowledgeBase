User 1 and User 2 work identically and can be named. 1. Press User 1/2, Enter. The welcome message shows a saved name or 'Name – A'; change letters with Up/Down, Enter per letter, Stop saves the name. 2-4. Enter Age, Weight, Time (Up/Down or numeric keypad). 5. Set Max Level (factory 7). 6-7. Build the level profile column by column — each new segment copies the previous level — until all twenty segments are set. 8. 'Press Enter to save': 'New program saved', then Start or modify; Stop exits. Mid-program Up/Down changes only the present column. **You can also save any finished preset as a custom program**: press a User key at the end and follow the window.**
