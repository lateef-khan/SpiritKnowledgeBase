Both programs work the same; HR1 defaults to 60% and HR2 to 80% of maximum heart rate. 1. Press HR1/HR2, Enter. 2-4. Enter Age, Weight, Time (Up/Down or numeric keypad). 5. Adjust the Target Heart Rate (WE-E95: 'Heart rate Level') and Enter. 6. Start begins; Enter is described as going back, with the printed NOTE that Stop goes back one level. 7. Up/Down during the program changes the target heart rate. 8. Display (2007/VE: adjacent Display key) scrolls data. 9. Start repeats the program, Stop exits — 2007/VE books add: or save the finished workout as a custom user program with a User key. A monitor must show a steady heart rate first; the program controls pedal resistance automatically.
