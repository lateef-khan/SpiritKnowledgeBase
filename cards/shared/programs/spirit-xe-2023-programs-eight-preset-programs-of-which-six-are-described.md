Both consoles scroll a single **PROGRAM** key through the list. The preset page opens: "The Elliptical
has multiple different programs that have been designed for a variety of workouts. **These eight
programs** have factory preset work level profiles for achieving different goals."

**Six descriptions follow it, not eight**: **Hill, Fat Burn, Cardio, Strength, HIIT and Fusion.** The
manual does not say which two make up the difference, and this KB does not guess.

What else the PROGRAM key reaches, described elsewhere in the same chapter:

- **Manual**
- **5K Run** and **10K Run** - see `spirit-xe-2023-programs-5k-and-10k-run`
- **Target Time, Target Distance and Target Calories** - see
  `spirit-xe-2023-programs-target-time-distance-and-calories`
- **Custom 1 and Custom 2** - see `spirit-xe-2023-programs-custom-one-and-custom-two`
- **Four heart rate programs** - see `spirit-xe-2023-programs-four-heart-rate-targets`

**Interval is gone; HIIT carries its text.** The HIIT description is the Interval paragraph these
machines' predecessors printed, word for word, and neither 2023 manual has a program called Interval.
**Fusion's description is that same paragraph again** with "high levels of **cardio & strength**
intensity" in place of "high levels of intensity", so the two profile descriptions do not distinguish
themselves; Fusion's setup steps do.

*The heart rate page still carries the boilerplate sentence about "any of the **nine** different
programs".*

**The program chapters of the two 2023 manuals are the same document.** Every difference between them
is a page number, a parts list or the XE795's extra light-commercial warranty.
