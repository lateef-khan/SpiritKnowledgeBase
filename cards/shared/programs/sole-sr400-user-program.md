1. Select USER and press ENTER.
2. Set the resistance level of each column with UP/DOWN and press ENTER for the next one. Hold ENTER for 2 seconds to finish or quit setting.
3. Preset the TIME and press ENTER to confirm.
4. START/STOP starts the workout; UP/DOWN adjusts the resistance level during it.
5. The countdown ends with an 8-second alarm (any key stops it); START/STOP pauses with all values saved; RESET returns to the main menu.

**Contradiction, ruled.** The step text says the profile has 15 columns in total, while the setting flow diagram repeats the column loop until 16 ranges are set. Both readings are printed, so both are kept: the diagram governs the setting loop, so build up to 16 columns, finishing early with the 2-second ENTER hold if the console accepts the profile sooner.
