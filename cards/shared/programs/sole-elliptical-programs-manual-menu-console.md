Manual means you control the workload, not the computer. 1. Press Manual (no Enter needed). 2-4. The menu asks Age, then Weight, then Time (Level arrows; the E95s Time step also allows the stride keys); Enter each time. 5. Start begins; Stop steps back one level. 6. Level one warm-up; Level Up/Down adjust load. 7. DISPLAY changes the shown data; ENTER switches INCLINE/LEVEL profile views. 8. Stop pauses ('Press Start to Resume' / 'Press Stop to End'). 9. The SUMMARY lists TIME, DISTANCE, CALORIES, AVG. PACE, AVG. RPM, AVG. SPEED, AVG. RAMP, AVG. LEVEL, AVG. WATTS and AVG. PULSE. 10. Start repeats, Stop ends, or User/Custom saves the workout.
