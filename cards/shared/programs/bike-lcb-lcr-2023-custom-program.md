Custom is a program with **fully customisable intensity patterns**.

1. Open the Custom program page and press **"Add Pattern"** to start editing.
2. **Connect dots to map your workload throughout the 20 segments** of the program — easiest at the
   bottom, hardest at the top.
3. Set the **total time** right before you start. **Each segment's duration depends on the total time
   you select.**

A created pattern **can be edited later at any time**.

The setup page also carries a **max level** control alongside the pattern editor.

This replaces the key-driven Custom program of the earlier LCB and LCR consoles, where you stepped
through twenty blinking columns with the Level keys. There is no username entry and no
"delete the saved program before building a new one" step on this console.
