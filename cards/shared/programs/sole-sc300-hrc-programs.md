Both programs work the same way; the only difference is that HR1 aims at 60% and HR2 at 80% of the maximum heart rate.

1. Press the HR1 or HR2 key, then press Enter.
2. Enter your Age with the Level or Step height keys or the numeric key pad, then press Enter.
3. Enter your Weight the same way, then press Enter.
4. Set the Time and press Enter.
5. Adjust the Target Heart Rate and press Enter.
6. Press Start to begin. Stop steps back one screen during setup.
7. During the program the Level or Step height keys change the target heart rate or the step height at any time.
8. The Display key scrolls the Message Window data. When the program ends, press Start to repeat it or Stop to exit.
