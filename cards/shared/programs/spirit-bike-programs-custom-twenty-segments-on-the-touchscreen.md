You create the desired resistance for each of the **20 segments** of the program using the keyboard
on the screen - the CR900ENT and CU900ENT call it a **pop-out** keyboard. **You may change the
levels at any time during the workout.**

**On the CU800ENT 2022 and CR800ENT 2023:**

1. Select **Custom**, then press **Enter** to customise it with your personal data, or **Start** to
   run it on the default settings.
2. The window shows the level profile; use the on-screen interface to build the profile you want,
   then press **Next** to save and continue.
3. The following screens ask for **Time**, **Age** and **Weight**. Use the defaults or adjust them,
   then press **Start**.

**On the CU800ENT 2024** the flow is shorter: select Custom to begin customising, adjust the
resistance level profile and the workout time on the on-screen interface, then press **Start this
program**. It asks for no age or weight on this page.

**The CR900ENT and CU900ENT print only the description**, not a numbered procedure.

**No touchscreen bike asks you to name a custom program**, and none of the five manuals says how
many custom programs can be stored or whether one overwrites another.

**The LED 800 consoles store twenty-four segments and take a seven-character name** - see
`spirit-bike-programs-custom-twenty-four-segments-and-a-seven-character-name`.
