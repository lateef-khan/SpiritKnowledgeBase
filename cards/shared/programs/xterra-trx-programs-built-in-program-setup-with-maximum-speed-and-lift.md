1. Use the **program keys** to select the desired program, then press **Enter**. The display
   prompts you through the programming, or press **Start** to begin with default values.
2. The Calorie window blinks an **Age** value (the book says "Calorie window" here and
   "Message window" for the other prompts). Adjust, press Enter.
3. The Message window displays a **Weight** value. Adjust with Speed up/down, press Enter.
4. If Enter was pressed, the Message window shows the default **Time of 30 minutes**. Adjust
   with Speed up/down, press Enter.
5. The Message window shows the **maximum speed**; adjust with the speed plus/minus keys or
   accept, then press ENTER.
6. The Message window shows the **maximum value of the lift** (incline); adjust with the raise
   and minus keys or accept, then press ENTER.
7. Press **Start** to begin your workout.

No default maximum speed or lift is printed; the preset value shown depends on the program
chosen.
