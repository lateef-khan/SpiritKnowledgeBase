| Period | Components |
|---|---|
| 10 Years | Frame / Welds / Cams / Plates |
| 5 Years | Bushings / Bearings / Shocks / Pulleys / Guide Rods |
| 1 Year | Paint & Finishes / Cables / Grips / **Counter-Timer** / Pull Pin Components / Rails Wheels / Attachments / All other parts / **Labor** |
| 6 Months | Upholstery |

**This is the table that mentions the counter-timer.** These eleven machines carry a
rep counter and timer on the weight stack, so their one-year column names it. The
nineteen CSS single-station books print the same four periods with the same components
in every other respect and **no counter-timer entry at all**:
`spirit-strength-css-warranty-periods-ten-year-frame-welds-cams-plates`.

**Labour is inside the one-year column, not on a row of its own.** There is no separate
labour line here. Only the CSI generation splits labour out.

**There is one row and it is headed Commercial.** No residential or home row is printed,
so the manual states no different set of periods for a house. The one exception in this
group is the CSF-FUNT, whose row is headed **Light Commercial** with the same four
periods: `spirit-strength-csf-funt-light-commercial-warranty`.

The environment the row actually covers is narrowed by exclusion 2 rather than by the
table: `spirit-strength-warranty-use-environment`.
