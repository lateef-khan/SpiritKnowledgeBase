**Treadmill warranty, effective January 1, 2011** (ATT8-2011 and TT8C-2011 books) and **effective August 1, 2012** (TT8-2013 book — whose head misprints it "Agust 1, 2012").

| | **Residential** | **Light commercial (5 hours or less use per day)** |
|---|---|---|
| **Frame** | **Lifetime** | **Lifetime** |
| **Drive Motor** | **5 Years** | **5 Years** |
| **Parts** | **5 Years** | **3 Years** |
| **Labor** | **2 Years** | **1 Year** |

Light commercial beyond that line is excluded outright: exclusion 8 bars a "product used more than 5 hrs per day and/or in a dues paying facility". See `sole-tt8-warranty-exclusions-commercial-use-cap`.

The TT8C-2011 book has no model number and its cover names only TT8C; its warranty table is word-for-word this one, so it shares this card.

When the clock starts is separate; see `sole-treadmill-warranty-start-date-receipt-or-18-months-shipping`.
