**The one-year column does not name a counter-timer.** The dual-station CSD books, the
CSF-HRAC and the CSF-FUNT print an otherwise identical table with *Counter-Timer* added
to this column: `spirit-strength-csd-warranty-periods-with-counter-timer`. Do not read
a counter-timer term across to a CSS machine from one of those.

**Labour sits inside the one-year column.** No separate labour row is printed.

**The CSS-LEXT is not on this card.** Its ten-year column names the frame alone, with no
welds, cams or plates: `spirit-strength-warranty-periods-ten-year-column-names-the-frame-alone`.
It is the only one of the nineteen CSS books that differs, so check the machine before
quoting the ten-year column.

**The CSS-ABDO warranty page names the wrong machine.** Its heading reads
*Effective July 02, 2024- CSS-ABDO Seated Chest Press LIMITED WARRANTY*, and Seated
Chest Press is the CSS-SCPR. The model code CSS-ABDO is correct and the table is the
standard one above; only the product name in the heading is wrong. This is printed on
the page, not an extraction artefact - it survives a 300 dpi render.
