**450 lbs, in all three manuals that print a figure.**

| Manual | Printed as |
|---|---|
| CT800 2016 | `Maximum User Weight: 450 lbs` |
| CT800 2020 | `Maximum User Weight: 450 lbs` |
| CT800ENT-2022 | `Recommended User Weight Limit: 450 lb` |

**The ENT manual calls the same number a recommendation.** The 2016 and 2020 manuals print it as a
maximum. The figure is 450 in all three and no manual states what happens above it, so quote 450 lb
either way and do not present the ENT wording as a higher allowance or the earlier wording as a
hard cut-off - none of the three manuals says.

**The limit is printed in one place only.** It is a bullet of the Important Safety Instructions
list (`spirit-ct800-safety-instructions-list`, `ct800ent-2022-safety-instructions-list`); none of
these manuals carries a specification table with a user capacity.

**The CT800-2012 manual prints no user weight limit anywhere.** Do not carry 450 lbs back onto it:
`xt-2015-safety-no-user-weight-limit-printed`, which now carries that machine.

**Other Spirit treadmills print other figures**, and none of them answers for a CT800: 425 lbs on
the XT485-2023, XT685-2023, XT685-2015 and XT685ENT
(`xt-2023-safety-user-weight-limit-425-lbs`), 440 lbs on the 2026 7.0T and 8.0T
(`spirit-2026t-safety-user-weight-limit-440-lbs`), and 275, 350 and 375 lbs on the smaller 2023 XT
machines.

**The Spirit CT900 manual prints the same 450 lb figure** for that machine, filed as a
specification rather than in the safety section (`ct900-user-weight-limit`). It is a different
machine's manual; this card is the CT800 statement.
