**The maximum weight for individuals using the Strength Equipment should not exceed 330 pounds (150 kilograms).**

Word for word in all five books. The SRVO Complete bench book prints 265 pounds instead - see the linked card, a different figure means a different card. The seminar sheet prints the same 330 lb for the SRVO trainer (`srvo-overview`).
