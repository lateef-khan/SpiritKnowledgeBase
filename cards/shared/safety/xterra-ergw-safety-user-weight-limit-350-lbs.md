**This is the 350 lb figure**, printed once in each book:

| Book | As printed | Where |
|---|---|---|
| ERG650W (2021) | `User Weight Limit: 350 LBS` | the last Fitness Equipment Safety Instructions bullet (`xterra-rower-safety-instructions-list-free-space-and-tighten-bolts-with-11-fitness-bullets`) |
| ERG750W (2025) | `16. User Weight Limit: 350 lb.` | item 16 of the new-layout list (`erg750w-2025-safety-instructions-list-16-items`) |

Neither book has a specification table. The ERG750W adds the boxed note `Please ensure that you
review and adhere to the user weight restrictions and power requirements of your new machine.`

**The other water rowers print less**: ERG550W and ERG600W 300 lb
(`xterra-rower-safety-user-weight-limit-300-lbs`), ERG800W 330 lb
(`erg800w-2023-safety-user-weight-limit-330-lbs`). The Spirit water rowers print 350 lb for their own
machines (`spirit-rower-safety-user-weight-limit-350-lb`) - a Spirit card.

| Figure | Printed on | Where |
|---|---|---|
| 250 lb | ERG160 | `Weight Limit: 250 lb`, the last Fitness Equipment bullet |
| 300 lb | ERG180, ERG550W | `User Weight Limit: 300 LB`, the last Fitness Equipment bullet |
| 300 lb | ERG600W | `User Weight Limit: 300 LBS`, the last Fitness Equipment bullet |
| 300 lb | ERG220 | `Weight Limit: 300 lbs`, the last Fitness Equipment bullet |
| 330 lb | ERG800W | `21. User Weight Limit: 330 lbs.`, item 21 of the new-layout list |
| 350 lb | ERG650W | `User Weight Limit: 350 LBS`, the last Fitness Equipment bullet |
| 350 lb | ERG750W | `16. User Weight Limit: 350 lb.`, item 16 of the new-layout list |
| none | ERG400, ERG500, ERG700 | no weight limit anywhere in the book |
