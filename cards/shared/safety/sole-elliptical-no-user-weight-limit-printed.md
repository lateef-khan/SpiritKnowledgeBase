No B book prints a user weight limit anywhere - not on the safety pages, not in a specification table, not in the warranty. The only `weight` figures are the bodyweight entries the console asks for when programming age/weight programs (inputs affecting the calorie readout, not limits), program Max Level settings and heart-rate maximums.

The treadmill twin of this absence is linked; the specs section holds whatever capacity figures exist for other Sole ranges.
