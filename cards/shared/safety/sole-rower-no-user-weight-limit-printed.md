None of the four rower books prints a user weight limit - no limit sentence, no capacity table, no figure on any safety, specification or assembly page. The only `weight` in the SR400 book is the machine's own weight in the moving instructions; the SR500 and SR550 books' only matches are incidental. The safety pages of all four books were read in full against the page renders, so this is not a flattened-image miss.

Do not quote a weight limit for any of these rowers. For contrast, the strength books in this wave print 265 lbs (SRVO Complete bench) and 330 lbs (everything else) - see the linked card.
