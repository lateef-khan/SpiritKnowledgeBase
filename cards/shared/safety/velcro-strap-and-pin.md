**Warning**: if the Velcro strap or the pin is removed before the running deck is set in place, the gas cylinder expands and can hurt somebody. Ask first whether everyone is all right.

**Strap or pin removed too early**

1. Set the deck up as it would be when folded, with the deck up in the air.
2. Depending on the model, pull the lever for the lock or kick the cylinder to unlock it.
3. Gravity brings the deck back down to the floor.
4. Re-strap or reinsert the pin until the machine is fully assembled.

**Pin left in while inclining**

Leaving the pin in during an incline can damage the controller and the frame. Have the customer turn the power off and back on. While it boots, the incline returns to 0 on its own. The pin can then be removed.
