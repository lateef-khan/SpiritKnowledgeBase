**These six manuals state no user weight limit.** Not on the safety page, not in a specification
table (they have none), not in the warranty. A reader asking for one must be told the book does not
give it.

How it was checked: every page of each book was read, the whole text searched for `weight`, `limit`,
`lb`, `kg` and `capacity`, and the safety page rendered from the PDF and read as a picture in case
the line was drawn rather than set as text. The only `weight` hits are the body-weight prompt of the
program set-up (`default is 150 lbs.`) on the TR6.6 and TR6.4, which is a calorie input, not a limit.

**The TR150, printed the same day and in the same layout as the TR200, does print one** -
`Product Weight Limit: 250 lbs.` (`tr150-2021-safety-user-weight-limit-250-lbs`). The TR200 page is
that page with the bullet removed. Do not carry 250 across.

| Figure | Printed on | Where |
|---|---|---|
| 250 lbs | TR150 | `Product Weight Limit: 250 lbs.`, a bullet in the Fitness Equipment Safety Instructions |
| 265 lbs | TRX1400, WS200, WS300 | item 21 of the SAFETY INSTRUCTIONS list |
| 265 lb | TR75H | item 22 of the SAFETY INSTRUCTIONS list |
| 300 lbs | TR65, TRX2500 | item 21 (TR65) or the last Fitness Equipment bullet (TRX2500) |
| 300 lbs | TR95H | item 22 of the SAFETY INSTRUCTIONS list |
| 350 lbs | TR75, TR85, TRX3500, TRX4500, TRX5500 | item 21 (TR75, TR85) or the last Fitness Equipment bullet (TRX books) |
| none | TR200, TR300, TR6.6, TRX1000, TR260, TR6.4 | no weight limit anywhere in the book |
