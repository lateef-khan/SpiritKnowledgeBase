**The maximum weight for individuals using the Strength Equipment should not exceed 265 pounds (120 kilograms).**

Only the SRVO Complete bench book (SRB101) prints this figure. Every other strength book in this wave prints 330 pounds - see the linked card, a different figure means a different card.
