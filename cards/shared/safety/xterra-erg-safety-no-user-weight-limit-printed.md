**These three books state no user weight limit.** Not on the safety page, not in a specification
table (none of them has one), not in the warranty. A reader asking for one must be told the book does
not give it.

How it was checked: every page of each book read; the text searched for `weight`, `limit`, `lb`,
`lbs`, `kg` and `capacity`; the ERG400 scan read from its OCR supplements and the safety page
render. The only `weight` hits are the ERG700 heart-rate page (`weight control`, `weight loss` as training
goals) and the word *Limited* in every warranty heading.

| Book | Safety page | Its last bullet |
|---|---|---|
| ERG400 (2015 scan) | the thirteen-item plug-in list and seven bullets (`xterra-erg-safety-instructions-list-13-item-plug-in-list`) | *wear proper shoes* |
| ERG500 (2018) | eleven items and nine bullets (`xterra-erg-safety-instructions-list-11-items-and-9-bullets-no-weight-limit`) | *do not place any sharp object around the machine* |
| ERG700 (2022) | the same page as the ERG500 | the same |

**Do not carry a sibling's figure across.** The ERG220 prints 300 lb at the end of the same
thirteen-item list the ERG400 uses, and the ERG650W prints 350 lb after the same nine bullets the
ERG500 and ERG700 use with two more added; those are different books.

| Figure | Printed on | Where |
|---|---|---|
| 250 lb | ERG160 | `Weight Limit: 250 lb`, the last Fitness Equipment bullet |
| 300 lb | ERG180, ERG550W | `User Weight Limit: 300 LB`, the last Fitness Equipment bullet |
| 300 lb | ERG600W | `User Weight Limit: 300 LBS`, the last Fitness Equipment bullet |
| 300 lb | ERG220 | `Weight Limit: 300 lbs`, the last Fitness Equipment bullet |
| 330 lb | ERG800W | `21. User Weight Limit: 330 lbs.`, item 21 of the new-layout list |
| 350 lb | ERG650W | `User Weight Limit: 350 LBS`, the last Fitness Equipment bullet |
| 350 lb | ERG750W | `16. User Weight Limit: 350 lb.`, item 16 of the new-layout list |
| none | ERG400, ERG500, ERG700 | no weight limit anywhere in the book |
