| Function | Range as printed |
|---|---|
| SCAN | Every 6 seconds |
| TIME | 0:00 ~ 99:59 |
| SPEED | 0.0 ~ 999.9 KM/H (MILE/H) |
| DISTANCE | 0.00 ~ 999.9 KM (MILE) |
| CALORIES | 0.0 ~ 999.9 CAL |
| ODOMETER | 0.0 ~ 9999 KM (MILE) |
| PULSE | 40 ~ 240 BPM |

Battery type 2 AAA or UM 4; operating temperature 0 to +40 C; storage -10 to +60 C. The console turns on when you start pedalling or press a key and off after 4 minutes of inactivity ([auto-off card](xterra-console-battery-console-wakes-on-pedalling-and-sleeps-after-4-minutes.md)). The picture labels the window positions SCAN, DISTANCE, PULSE, TIME, SPEED, ODO and CALORIES.

**MODE** is the only key: press to select functions; **hold two seconds to reset all functions to zero except ODOMETER**. SCAN (press MODE until the marker sits at SCAN) shows time, speed, distance, calories, odometer and pulse in sequence, 6 seconds each. TIME, DISTANCE and CALORIES count from exercise start to end; the calorie readout is an estimate for an average user, for comparison between workouts on this unit. ODOMETER is the total distance travelled and **does not reset unless you remove the batteries**. PULSE shows an average current heart rate in BPM - hold the pulse grips 6 to 7 seconds ([pulse card](xterra-console-hand-pulse-reads-after-6-to-7-seconds-and-runs-high-at-first.md)).

The UB120 book prints the same page but drops the SPEED line from its Key Functions list; the window is still on its table. Neither book has a SET key, so no targets can be set.
