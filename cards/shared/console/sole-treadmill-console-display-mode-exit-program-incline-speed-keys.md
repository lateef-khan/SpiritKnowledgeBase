**Not the Up-arrow/Fast-key exit** on the older card: these books use the Program, Incline or Speed keys.

The console ships in an in-store display mode where it stays powered unless the main power switch is off. To exit for normal operation: press and hold **Stop, Enter and Display** for **5 seconds**; the display shows **Display mode - On**. Use any of the **Program, Incline or Speed up/down keys** to change the setting to **Off**, then press **Enter**. The TT8 books say **Program, Grade or Speed** instead of Incline. The 2023 LCD books print no display mode at all; they toggle a sleep mode with the same three keys.
