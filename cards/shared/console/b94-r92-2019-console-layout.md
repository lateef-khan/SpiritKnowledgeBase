The console carries:

- **Cooling fan** and a **fan power switch**
- **Speaker**
- **USB port** for charging portable devices
- **Data display**
- **Dot matrix display**, which shows program profiles
- **Message window**, which shows Laps, Speed, Level, Watts and Segment Time
- **Program buttons**: Manual, Hill, Fat Burn, Cardio, Strength, HIIT, 2 User, 2 HR
- **Control keys** and a **Display** key
- **Audio in jack** for MP3, CD or smartphone
- **Headphone jack**
