**To open it:** press and hold the **Start, Stop and Enter** keys at the same time, until the display shows **"Engineering Mode"**. Press **Enter**. Scroll with the **Up and Down** keys; the **Stop** key returns to the previous menu selection.

| Item | What the manual says it does |
|---|---|
| A. Key Test | |
| B. Display Test | |
| C. Functions | |
| C.I Display Mode | Turn **Off** to have the console power down automatically after **30 minutes** of inactivity. |
| C.II Pause Mode | Turned **On** to allow **5 minutes** of pause, turn Off to pause indefinitely. |
| C.III ODO Reset | Resets the odometer reading to zero. |
| C.IV Units | English (Imperial) or Metric display readings. |
| C.V Brake Test | For testing the brake function. |
| D. Security | |
| E. Factory Settings | For factory use only. |
| F. Exit | |

**The Pause Mode item is the other half of the Stop key's behaviour.** The console section of this same manual says only that Stop pauses the program, with no duration; this item is where the five minutes is named and where it can be turned off so the console pauses indefinitely.

**The menu is one item longer than the 2011 menu of the same family**, which has no Security item, opens on the words "Maintenance Menu", calls the brake item PWM Test, and turns Display Mode **On** rather than Off to power the console down.
