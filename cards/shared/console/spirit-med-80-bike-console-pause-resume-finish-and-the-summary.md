**Pause** - "Press STOP to pause or stop the exercise." The pause screen has two buttons: **"Press
Resume to continue the session"** and **"Press Finish to end the session."** The hard key under the
screen is labelled **START & PAUSE** and "temporarily pauses exercise and touch start to resume"
(`spirit-med-80-bike-console-function-keys-and-the-protective-sheet-to-peel-off`).

**Exercise summary** - "When the program ends, either by the set time reaching zero or ending the
program by pressing STOP at any time and then pressing Finish to end, a summary is shown on the
screen. The summary provides detailed data for the amount of time the user exercised."

**No pause length is printed.** Settings has a "Standby or Pause mode" entry
(`spirit-med-80-bike-console-settings-menu-and-the-four-viewing-modes-with-close-up-mode`) but
neither book gives it a default or a time; the LED bikes' five-minute pause does not carry over
(`spirit-med-70-bike-console-stop-reset-key-and-the-program-keys-as-a-number-pad`).

**Power Distribution** shares the Finishing page - a mode that "will measure the pedaling power
throughout the cycle range" and shows a power distribution index; it is a program and is held with
the program cards. The 8.0T prints the same pause and summary (`80t-2026-console-pause-and-summary`).
