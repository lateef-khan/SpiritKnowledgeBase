**This entry sequence is Start + Stop + Enter. It is not the CT850 sequence, which is Speed + Enter with the safety key; see `ct850-2016-engineering-mode-menu`.**

The console has built in maintenance/diagnostic software. It will, for example, change the console settings from English to Metric and turn off the beeping of the speaker when a key is pressed.

**To enter: press and hold down the Start, Stop and Enter keys. Keep holding the keys down for about 5 seconds** and the Message Center will display **Engineering Mode Menu**. Press the **Enter** key to access the menu:

| Item | What it does |
|---|---|
| 1. Key Test | Allows you to test all the keys to make sure they are functioning |
| 2. Display Test | Tests all the display functions |
| 3. Functions | Press Enter to access settings and the Speed + or - arrow to scroll |
| 4. Child Lock | Locks the keypad so no unauthorized use of the machine is allowed |
| 5. Exit | |

**Child Lock:** when it is enabled, the console will not allow the keypad to operate unless you **press and hold the Child Lock buttons for 3 seconds** to unlock the console.

All five XT 2023 manuals print this entry sequence and this top level list identically. The **Functions** sub-menu is not identical between them: see `xt-2023-console-engineering-functions-with-key-tone` for the XT185 and XT285, and `xt-2023-console-engineering-functions` for the XT385, XT485 and XT685.

**Calibration is not in this menu.** It has its own entry sequence headed "Factory settings"; see `xt-2023-console-calibration-basic`.

**Four of the five service manuals print this menu under the heading "Maintenance Menu", and they
unlock the keypad a different way.** The XT185, XT285, XT385 and XT485 2023 service manuals say: hold
Start, Stop and Enter until the display shows **"ENGINEERING MODE MENU PRESS ENTER" ("it may say
maintenance menu, depending on version")**, then Enter; scroll with Speed ▲/▼, Stop returns to the
previous menu. Items A Key Test, B Display Test, C Functions, D Security, E Exit - the same five as
above - but item D reads: *"Security - Allows you to lock the keypad ... When the child lock is
enabled, the console will not allow the keypad to operate unless you press and hold the **Start and
Enter buttons for 3 seconds** to unlock the console."* The owner's manuals say hold the **Child Lock
button** for 3 seconds. The two documents describe the same machines and disagree about the unlock
key; try both.

**The XT685-2023 service manual prints no engineering or maintenance menu at all** - its section 8.11
is the troubleshooting matrix - although its console-key table still describes a Child Lock key set
"in ENGINEERING MODE". Nothing in that book says how to open the menu on that machine.

**The service manuals also print a second way in, with the safety key.** In their E0 error note:
*"Remove safety key, press STOP & START & ENTER keys, and at the same time insert the safety key.
The display into ENGINEERING MODE."* That is the same three keys with the key inserted rather than a
5 second hold, as the 2015 books also print (`xt-2015-console-engineering-mode-menu`).
