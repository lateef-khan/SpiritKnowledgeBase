**"Note: There is a thin protective sheet of clear plastic on the overlay of the console that should be
removed before use."** A cloudy or peeling screen on a new bike is that sheet.

**Touch Screen Display** - "All information required for operation is explained on screen. The
detailed directions on how to program the various functions will be shown on each screen of the
console display."

**Function keys** - the only physical buttons:

| Key | What it does |
|---|---|
| **+ / -** (Plus/Minus) | adjust resistance level |
| **START & PAUSE** | "one touch start (quick start); temporarily pauses exercise and touch start to resume" |
| **ENTER** | confirm each setting |

**These are the keys that wake a sleeping console** - "Press any function key to wake the console up
again" (`spirit-med-80-bike-console-power-on-self-test-login-page-and-thirty-minute-power-down`) -
and the keys the service manual's Keypad Test exercises as Resistance Increase, Resistance Decrease,
Start/Stop and Enter
(`spirit-med-80-bike-console-service-tab-machine-type-loopback-nfc-keypad-beacon-and-crank-calibration`).

**The pause screen on the touchscreen has its own Resume and Finish buttons**
(`spirit-med-80-bike-console-pause-resume-finish-and-the-summary`). The 8.5UE and 8.0T print the same
three keys (`85ue-2025-console-function-keys-and-the-four-viewing-modes`, `80t-2026-console-function-keys`),
the treadmill adding speed and grade keys of its own.
