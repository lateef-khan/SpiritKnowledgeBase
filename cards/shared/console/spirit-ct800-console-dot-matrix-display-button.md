**The key that switches the view on this console is called Display.** On the later CT800 and CT850
console the same control is an Up/Down **Scan** button: `ct850-2020-dot-matrix-message-center`.

**Ten rows of dots** indicate each level of a workout in manual mode. The dots show only an
approximate level of effort - speed or incline - not a specific value; they are there to compare
intensity. In manual operation the window builds a profile "picture" as values change during a
workout.

There are **twenty-four columns**, indicating time, each one 1/24th of the total program time. When
the time counts up from zero, as in quick start, each column represents **1 minute**.

Next to the window are three LEDs labelled **Track**, **Speed** and **Incline**, with a **Display**
button:

- Track LED lit - the window shows the Track profile.
- Speed LED lit - the Speed profile.
- Incline LED lit - the Incline profile.

Press the **Display** button to change the view. After scrolling through all three, the window
**scrolls automatically, showing each profile for four seconds**, and the LED for the profile on
show blinks. One more press of the Display button returns you to the Track profile.

On this console the scrolling text is a separate window - the 20-character Message Center - not the
same panel as the dots: `ct850-2020-message-window-display`.

**The CT850-2018 owner's manual prints these two paragraphs word for word on its p. 17**, under DOT
MATRIX CENTER DISPLAY and with the same Display button, so this card covers that machine. It prints
the message window as a separate section on the next page
(`ct850-2020-message-window-display`), where the 2012 CT800 manual folds the sentence in here.
