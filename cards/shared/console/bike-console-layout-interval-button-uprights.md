The console carries:

- **Cooling fan** and a **fan power switch**
- **Speaker**
- **Data display**
- **Dot matrix display**, which shows program profiles
- **Message window**, labelled **Laps, Speed, Level, Watts, Segment Time**
- **Program buttons**: Manual, Hill, Fat Burn, Cardio, Strength, **Interval**, 2 User, 2 HR
- A **Display** key. The 2013 and 2016 panels also label a block of **control keys**; the 2015 panel does not.
- **Audio in jack** for MP3, CD or smartphone
- **Headphone jack**

**There is no USB port on this panel.** A USB charging port appears from the 2019 model year, where the Interval button is also replaced by **HIIT**. A panel with HIIT and a USB port is a later machine, not this one.
