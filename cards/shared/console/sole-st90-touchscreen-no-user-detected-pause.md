The machine **pauses automatically if no user is detected for 10 seconds**. Above **2 mile/hr (3 km/hr)** a protecting mechanism pops a **stop/resume workout window** that stays for **5 minutes**; with no action the treadmill ends the workout automatically. The popup counts down **'Machine will pause in 0:08'**. Quoted exactly as printed, typos included ('deteced', 'porgam', '2mile/hr', '5 minute').
