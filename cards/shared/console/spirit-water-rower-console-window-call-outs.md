**Eight readings, and each one doubles as the entry field for its own target mode.**

| Window | In a normal workout | When its target mode is selected |
|---|---|---|
| **Resistance** | The current resistance value | - |
| **TIME** | Total elapsed time, or a count-down | The time you select |
| **TIME/500m** and **AVERAGE** | The time needed to row 500 m at current speed, and the average | - |
| **DISTANCE** | Overall distance, in **metres** | The distance you select |
| **CALORIES** | Calories burned, counting up or down | The calorie target you select |
| **SPM** | **Strokes Per Minute** | - |
| **WATTS** | *"the power consumption during training"* | - |
| **STROKES** | Strokes counting up or down | The stroke target you select |
| **TOTAL STROKES** | *"total accumulative stroke count"* | - |
| **Heart rate** | The current heart rate | The target heart rate |

**The target symbol tells you which window is the one being chased.** *"When the target symbol is
displayed, it means that target mode is operating in that particular value."* Only that window's
figure is a goal; the rest keep counting normally.

**Two of the readings count either way and the manual does not say which is the default:**

- *"The TIME will alternate showing the remaining or elapsed time."*
- *"The DISTANCE will count or countdown in meters."* Distance on this console is **metric**, and the
  manual offers no imperial choice anywhere - unlike the Spirit air bike, which has a DISTANCE entry
  in engineering mode for exactly that. **The water rowers' engineering mode has no units entry**
  (`spirit-water-rower-console-engineering-mode-sound-and-odo`).

**STROKES and TOTAL STROKES are two different counters.** STROKES counts or counts down the strokes
**during the workout**; TOTAL STROKES is the accumulative count, and it is **the one value a Total
Reset does not clear** (`crw900-2021-console-total-reset-three-second-hold`,
`crw800h2o-console-total-reset-two-second-hold`).

**One wording difference between the two books.** The CRW900 says the resistance window shows the
value *"based on current water level"*; the CRW800H2O says only *"Resistance value displayed here."*
The CRW800H2O reaches the same figure by hand, through its LEVEL key
(`crw800h2o-console-water-level-button-six-steps`).

**This is not the CRW800 air rower's window list.** That console has seven windows with printed
numeric ranges - watts 0-2000, level 1-16, calories 0-999
(`crw800-2024-console-window-functions`). **Neither water rower manual prints a range for any
window.** Do not carry the air rower's figures across.
