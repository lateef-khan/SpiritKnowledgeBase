**Eighteen columns of dots, 8 high** (F63/F65 dual books print the sentence twice, once per model). The dots show approximate speed/incline effort only, building a profile picture as values change. When **Speed** is lit above the matrix the Speed profile shows; when **Incline** is lit the Incline profile shows. Press **Enter** to swap views; pressing it a **third time alternates** the two displays, five seconds each. (The F65-2023 book misprints this as pressing it for 'the twice time'.)
