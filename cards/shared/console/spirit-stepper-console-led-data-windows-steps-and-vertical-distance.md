**These two consoles open on Steps, not Distance.** The elliptical and bike version of this same page
opens on Distance, Calories, Pulse and Time Elapsed and is a different set of readings:
`spirit-ce-console-led-data-windows-scan`.

The **Dot Matrix Message Center**, or Profile Window, displays the workout profile. The **LED Data
Display Window** displays the exercise data. Alongside them there is a **Strides Per Minute** window
for pedal speed and a **Level** window indicating machine resistance.

| Press | The LED windows show |
|---|---|
| Initially | **Steps, Calories, Pulse, Time Elapsed** |
| Up/Down Scan once | **Watts, METs, Time Remaining**, plus a distance reading |
| Up/Down Scan again | **Scan mode**: each set for **four seconds**, then the next, in a continuous loop |
| Up/Down Scan again | Back to the beginning |

**The distance reading in the second set is not the same on the two machines.** The **CS800-2024**
prints **Vertical Distance**; the **CRS800S-2024** prints plain **Distance**. The console drawings
agree with the text - the CS800 drawing labels the lower row VERTICAL DISTANCE, WATTS, METs, TIME
REMAINING and the CRS800S drawing labels it DISTANCE, WATTS, METs, TIME REMAINING. Quote the word the
owner's own manual prints; on a stepper the two mean different things.

**The CRS800S manual spells the window "LED Data Diplay Window" four times.** It is a typographical
error in that book, not a different part.

**The CSC900-2024 stair climber has no scan key and no two sets.** It has four separate windows with
twelve data points and a button under each one:
`csc900-2024-console-four-display-windows`.
