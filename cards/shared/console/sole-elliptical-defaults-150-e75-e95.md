These consoles default to **Age 35, Weight 150 lb, Time 30:00** with the same per-program maxima as the rest of the generation (Hill 7, Fatburn 5, Cardio 7, Strength 8, Interval 7) - 5 lb lighter than the E25/E55/VE default (own card).
