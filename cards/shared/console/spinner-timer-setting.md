With no count-down set, the timer counts up from **00:00 to 99:59**.

**To set a count down:** in **DIST** or **KCAL** mode, hold the **PAGE** key for **3 seconds** to enter the timer setting.

When the count down reaches zero the display flashes and the timer starts counting up again.
