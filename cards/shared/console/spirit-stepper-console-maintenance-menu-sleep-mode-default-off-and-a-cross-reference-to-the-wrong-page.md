**Pedal the machine, then press and hold Start, Stop and Enter together for about 5
seconds.** The Message Center displays **Maintenance Mode**. Press **Enter** to open the menu.

**You have to be pedalling.** Both books say so in the first sentence - "pedal the stepper" and
"pedal the Semi-Recumbent Stepper" - and both head the page ENGINEERING MODE while the screen reads
Maintenance Mode.

1. **Key Test** - test all the keys to make sure they are functioning
2. **Display Test** - tests all the display functions
3. **Function**
   - **Units** - Imperial (miles, pounds, feet) or Metric (kilometers, kilograms, meters)
   - **Pause mode** (have five minutes)
   - **Odometer Reset**
   - **Sleep mode** - **the CRS800S-2021 prints `(Default Off)`; the CS800-2021 prints the bare
     entry with no default**
   - **Beep sound** (Control Beep)
   - **CAB Protocol or CSAFE Protocol**
4. **Service**
   - **Motor test**
   - **Csafe test**
   - **Sensor test** (test the speed sensor function)
5. **Exit**

**The sleep default was flipped, not introduced.** The 2024 printings of these same two machines
print **`Sleep mode (Default On)`** - the opposite value on an otherwise identical menu:
`spirit-stepper-console-maintenance-menu-sleep-default-on`. The CRS800S says **Off** again in words
in its TO TURN STEPPER OFF paragraph. **Always answer from the year in front of you.**

**The CRS800S-2021 cross-reference points at the wrong page.** Its TO TURN STEPPER OFF paragraph on
printed p. 20 ends "the default setting for sleep mode is OFF, **follow the instructions on page 35**
to turn it on". **Printed page 35 is SANITIZING YOUR SPIRIT FITNESS EQUIPMENT.** This menu is on
printed page **36**. Send the caller to 36.

**That same paragraph calls the machine a treadmill** - "In sleep mode, **the treadmill** will power
down most everything except for a minimum of circuitry" - in a semi-recumbent stepper manual. It is
boilerplate, not a different machine. The CS800's version of the paragraph says "the stepper".

**There is no Stride test**, because neither machine has an adjustable stride, and neither book
prints the entry.
