**To open it:** hold down **Start, Stop and Enter together for about 5 seconds**, until the message window shows "Engineering Mode". Press **Enter** to open the menu. Use the **Level up / down** keys to move through it.

Depending on software version the menu may be called the Maintenance Menu.

| Item | What it does |
|---|---|
| A. Key Test | Tests every key. |
| B. Display Test | Tests all LCDs automatically. |
| C. Functions | Press Enter, then scroll with Level up / down. |
| C.I ODO Reset | Resets the odometer. |
| C.II Units | English (Imperial) or Metric readings. |
| C.III Display Mode | Off makes the console power down after 30 minutes of inactivity. |
| C.IV Motor Test | Runs the tensioning gear motor continuously. |
| C.V Manual | Steps the gear motor. |
| C.VI Pause Mode | On allows 5 minutes of pause. Off pauses indefinitely. |
| C.VII Key Tone | Key beep on or off. |
| D. Security | Locks the keypad (child lock). |
| E. Factory Set | |
| F. Exit | Leaves the menu. |

The manual does not say what Factory Set changes.
