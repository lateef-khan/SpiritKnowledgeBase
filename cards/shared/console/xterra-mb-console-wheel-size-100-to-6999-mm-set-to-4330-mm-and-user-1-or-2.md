**Set the wheel size from 100 mm to 6999 mm.** Press **SET for 3 seconds** to enter setting mode, then press SET and MODE alternately to select the **km/h or mile/h** switch and then the right wheel size. Press **MODE for 3 seconds** when complete. In ODO mode you may also have 2 choices of wheel size by pressing **USER 1/2 on the back** of the console.

**Set the ODO value at 4330 mm when installing new batteries.** This is the figure the console needs for this bike; a fresh battery starts it at the default, so the speed and distance read wrong until 4330 is entered.

**ODO MODE (odometer).** Total distance from the beginning to the current point. **The odometer returns to zero when the battery has been taken out.** Personal data (gender, weight) is a separate entry ([user set card](xterra-mb-console-user-set-gender-weight-and-units-from-kcal-mode.md)). The MB500 book is a scan read from the render (the console pages are OCR); the MB550 book prints the same console chapter natively and is cited alongside.
