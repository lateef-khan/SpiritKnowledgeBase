**Twenty columns of dots, 10 high.** The dots show approximate effort only. In Manual Operation the window builds a profile 'picture' as values change; the 20 columns divide the total program time (1/20th each). The window shows **either** speed or incline: when **Speed** is lit the Speed profile shows, when **Incline** is lit the Incline profile shows. Press **Enter** to change views; scrolling through both starts an automatic alternation. The TT8-2013 prints extra behaviour (left-half profiles that scroll right to left).
