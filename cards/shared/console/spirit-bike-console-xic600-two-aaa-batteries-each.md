**Console:**

1. Remove the battery cover from the back of the computer.
2. Insert **2 AAA batteries** into the battery compartment and reinstall the cover.
3. When battery working voltage is too low, the **"Low battery"** indicator shows on the console
   display. That is the signal to change them.

**Speed sensor transmitter:**

1. Remove the battery cover from the transmitter.
2. Install **2 AAA batteries** in the battery compartment and reinstall the cover.

**Changing either set breaks the pairing.** The manual is explicit: when new batteries are installed
in the transmitter *or* the console, you must run the synchronising procedure again for the console
to work properly. See `spirit-bike-console-xic600-synchronising-the-transmitter`.

**Four AAA cells in total**, two in each part. The console is a sealed unit and installing batteries
is the only reason the manual allows opening it - any other opening voids the warranty.

**Both printings say AAA.** The 2018 and the 2021 manuals carry this page word for word; neither is
vaguer than the other about the cell size.
