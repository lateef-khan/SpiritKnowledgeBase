1. Remove the Safety Key. **DO NOT STAND ON THE BELT DURING CALIBRATION.**
2. Press and hold **Start** and **Speed Up** and at the same time replace the Safety Key. Keep holding them until the window displays "**Factory settings**", then press the Enter/Program key.
3. Set the display to Metric or English (miles vs. kilometers): press the Incline Up / Down key to show the one you want, then press Enter/Program. The maximum speed value is displayed in the speed window and the maximum elevation value in the incline window.
4. **Grade return – On.** This lets the incline return to zero when Stop is pressed. (For sale in Europe, EU standards require this to be off.)
5. Press **Start** to begin calibration. The process is automatic; the speed starts up without warning, so do not stand on the belt.

Unlike the older books, this one prints no wheel size and no speed or incline values to enter — the maximums are displayed, not set. Units can also be changed from the engineering mode's Functions menu ([engineering card](xterra-tr-console-engineering-mode-start-stop-enter-key-test-functions-child-lock.md)).
