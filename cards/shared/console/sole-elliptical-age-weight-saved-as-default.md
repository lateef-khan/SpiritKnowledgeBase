Age and Weight defaults change whenever a new number is entered: the **last values entered are saved as the new defaults**, so first-use entry never repeats unless values change or someone else enters theirs. Starting with Start alone uses the saved defaults. Pressing a program key scrolls its profile in the dot matrix (E35 books: Display also shows the incline profile); Enter customises, and Stop steps back one screen during entry.
