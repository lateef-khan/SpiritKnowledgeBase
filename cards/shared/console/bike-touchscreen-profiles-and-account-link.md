Launched for the first time, the console prompts you to enter as a **guest** or create a new profile. A profile lets the machine remember your physical parameters, favourite programs and templates, gives you a custom program with an adjustable intensity pattern, and lets your workout records sync with the SOLE+ mobile app.

- Tap **+** to create a new profile.
- **A maximum of 9 profiles can be created.**
- Each profile can be protected with a **passcode**.

**To link a SOLE+ account:**

1. Scan the QR code on the console screen to download the mobile app.
2. Install the app and complete registration.
3. Press **Link** at the bottom of the console screen.
4. Open the QR code scanning camera in the SOLE+ app and scan the QR code again. That links your local profile with the SOLE+ account.

**A console profile cannot be linked to more than one SOLE+ account at the same time.** If you skip this step you can reach it again later in Profile settings.
