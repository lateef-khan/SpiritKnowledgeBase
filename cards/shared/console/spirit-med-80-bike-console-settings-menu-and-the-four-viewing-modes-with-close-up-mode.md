**Settings** - "You can access the Settings to adjust the preferences, such as: **Beacon feature
setting, language, time & date, WiFi, Standby or Pause mode, and units of measurement**." The service
manuals' screenshot of the page shows its tiles: *Progress Beacon, Acceleration & Deceleration,
Language, Time & Date, WiFi, Standby, PauseMode, Account, Units (Metric / Imperial), Software* - the
last being where updates live
(`spirit-med-80-bike-console-firmware-lcb-and-console-app-update-from-a-usb-root-or-over-wifi`).
**No default and no range is printed for the standby or pause time** on either bike.

**Programming Dashboard** - the program screen carries the "exercise program main info"; "during the
programs you will be able to scroll through the data in the display".

**Viewing modes** - "You may also switch the mode between **Status, Diagram, Symmetry, and Controls**
by pressing the icon":

| Mode | What the page says |
|---|---|
| **Status** | "view the value of the current parameters" |
| **Diagram** | "select the parameter to display on the screen" - the "selected parameter progress chart" |
| **Symmetry** | the left-right power screen (the Symmetry feature is with the program cards) |
| **Controls** | "adjust the parameter" |

**Close Up Mode** - "Turn on the Close Up Mode to change the appearance of the screen." Nothing more
is printed about what it enlarges.

**"Press STOP to pause or stop the exercise"** - the pause screen is on
`spirit-med-80-bike-console-pause-resume-finish-and-the-summary`. The beacon's own colour bands are
on `spirit-med-80-bike-console-beacon-colour-bands`. The 8.5UE, 8.5S and 8.0T print the same
Settings list and the same four views (`85ue-2025-console-function-keys-and-the-four-viewing-modes`,
`80t-2026-console-settings-menu`, `80t-2026-console-screen-view-modes`).
