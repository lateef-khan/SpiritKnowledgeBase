The Message Window starts on Speed in MPH. Each **Enter** press moves through five data sets: MPH, RPM (pedal speed), **L** (current work level) and **MaxL** (program maximum), Watts (100 watts lights a 100-watt bulb), and **Ramp** (incline 1-20, switching the dot matrix to the incline profile). Scan then loops each set for four seconds; Enter again restarts. Pressing Incline keys shows the incline profile with an 'Incline' icon; workload keys switch back to the work profile.
