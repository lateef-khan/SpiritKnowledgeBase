The console ships in an in-store display mode where it stays powered unless the main power switch is off. To exit for normal operation: press and hold **Stop, Enter and Display** for **5 seconds**; the display shows 'Display mode - On'; use any of the **Program, Incline or Speed 5 keys** to change the setting to **Off**, then press **Enter**. The S77, TT8-series and 2011 books name different keys.
