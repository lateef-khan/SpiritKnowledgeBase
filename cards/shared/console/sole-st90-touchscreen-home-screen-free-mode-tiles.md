Same top icons and bottom navigation as the other first-generation touchscreens, but the shortcut tiles read **Start Free Mode, Choose a Program, Complete a Test** instead of Manual/Hill/Fatburn. Everything else on the page (activity overview, Start Workout button, Guest age/weight entry) matches the shared home-screen card.
