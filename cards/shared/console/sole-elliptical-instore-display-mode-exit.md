New consoles arrive configured in an in-store display mode where the console stays powered on unless the main switch is turned off. To exit it for normal operation, press and hold **Stop, Enter and Display together for five seconds**. The display shows **Display Mode - ON**; change it to **OFF** and press **Enter**.

The key that changes ON to OFF differs by book: the AE 2011 books say the **speed Up** key, the E98-2011 book says the **Resistance Up** key, and the 2012-2015, E55-2013-2014 and E98-2013 books say the **Level Up/Down** keys. Not to be confused with the maintenance-menu Display Mode / Sleep Mode setting, which governs auto power-down after inactivity (own cards).
