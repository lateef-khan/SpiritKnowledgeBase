When power is connected the console powers up automatically.

**These models operate on 12V/1.5A DC**, supplied by the power pack that is connected to **115 VAC**. There is a **power switch where the line cord plugs into the unit, on the front of the bike**.

**That is not the same rating as the 2019 or 2023 bikes.** The 2019 manual prints 12V/3.3A and the 2023 manual prints DC 12V/3.3A (12V/3A). Fitting a 3.3 A supply here, or a 1.5 A supply there, is reading the wrong row.

On first power-on the console runs an internal self-test:

1. All the lights turn on.
2. When the lights go off, the Message Window shows a software version (for example `VER 1.0`), and the **Distance** window shows an odometer reading.
3. The odometer reading is how many **virtual miles** the bike has gone. The Time window shows how many **hours** the bike has been used.
4. Both are displayed for only a few seconds.
5. The console then goes to the start-up display: the dot matrix scrolls the different workout profiles and the Message Window scrolls the start-up message.

The 2013 manual also carries an in-store display-mode warning after this paragraph. The 2016 manual does not print it.
