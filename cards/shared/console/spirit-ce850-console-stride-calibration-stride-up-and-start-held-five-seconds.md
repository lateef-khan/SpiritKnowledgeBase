**If there is a problem with the stride, try running the calibration.**

1. **Press the Stride up key and the Start key at the same time.**
2. **Hold them down for 5 seconds** and the stride calibration starts and runs automatically.
3. If the problem persists, contact the service department.

That is the whole procedure as printed. **No Enter press, no figure to compare against, no expected
duration and no pass or fail message.**

**The three books name the first key three ways.** The CE850-2020 says "the STRIDE up key"; the
XE895-2016 says "the Stride ▲ key"; the CE850-2016 says only "the Stride key". The stride keys are
the thumb switches on the left swing arm
(`ce850-2020-console-stride-length-18-to-24-inches-buttons-on-the-left-swing-arm`).

**The owner's manuals for two of these machines print a different key hold for the same job.** The
CE850-2016 owner's manual holds **Start and Level Up**, then presses Enter
(`ce850-2016-console-stride-calibration`); the XE895-2018 owner's manual holds **Start, Level Up
and Stop** with no Enter (`xe895-2018-errors-stride-calibration-three-key-hold`). Neither document
mentions the other, and the service manuals above are the only ones that name a Stride key.
Quote the combination for the book in front of you, and try the other if it fails.

**The troubleshooting matrix is where this is sent from**: "The stride position doesn't match
console - Console is not calibrated - Calibrate the console", and a STRIDE ERR with `- - -` (2020)
or `E3` (2016) in the stride window - "Turn off the AC switch and turn on power again. Calibrate the
monitor." Those rows and the stride-motor test procedure are held with the error cards.

**The maintenance menu of the CE850-2020 has a Stride Test, which is a test, not this calibration**
(`spirit-ce850-console-maintenance-menu-cab-or-csafe`).
