**There is no mains cord and no power switch.** The manual states the console power is created by a **built-in generator**.

- Begin pedalling and the console powers up automatically.
- If there is no movement at the flywheel the console goes to **stand-by mode** and the display turns off.
- To turn the console on again, begin pedalling.

On first power-on the console runs an internal self-test:

1. All the lights turn on.
2. When the lights go off, the Message window shows a software version (for example `VER 1.0`), and the **Distance** window shows an odometer reading.
3. The odometer reading is how many **virtual miles** the bike has gone. The Time window shows how many **hours** the bike has been used.
4. Both are displayed for only a few seconds.
5. The console then goes to the startup display: the dot matrix scrolls the different workout profiles and the Message window scrolls the start-up message.

**The generator also decides how long a workout survives a break.** Stopping pedalling holds your data for a limited time and then loses it; that is stated in a separate part of the same section.

The model years either side of this one are mains powered, so do not carry a socket or switch location onto this machine.
