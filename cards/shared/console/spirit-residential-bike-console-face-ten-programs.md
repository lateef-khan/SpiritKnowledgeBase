**The drawing that opens the CONSOLE OPERATION chapter labels seven things**, and all seven printings
print the same seven phrases:

| Call-out as printed | Where it sits |
|---|---|
| **Large Blue-LED Matrix Window** | Centre |
| **Heart Rate % Profile** | The bar graph right of the window |
| **Message Center** | Below the matrix window |
| **Fan to keep you cool** | Right of the housing |
| **Convenient cargo compartment for keys, phone, or MP3 player** | Lower left |
| **Ten innovative programs offer a variety of work-outs** | The program key row |
| **Easy-Touch Control Buttons** | Bottom |

**The page is a flattened image in every one of the seven manuals.** `pdftotext` returns the
call-outs but nothing that is drawn on the console itself; the labels below come from rendering the
page at 300 dpi and reading it.

**The console panel is silk-screened MUSCLE PROFILE** above the anatomical figure on the XBR55 and
XBU55 drawings, and the same figure sits at the top of the XBR95 console. **The call-out list never
names it**, so the drawing alone will not tell you the machine has one - the Muscle Activation Figure
paragraph two pages later does.

**"Ten innovative programs" is a label on a picture, not a program list.** The key legend printed
under the buttons is where the programs are actually named, and it is **not the same on all seven**:
the XBR55 legend reads MANUAL, HILL, FATBURN, CARDIO, STRENGTH, INTERVAL, USER, USER-2, HRA, HR-1
while the XBR95 legend reads MANUAL, HILL, FATBURN, CARDIO, STRENGTH, INTERVAL, CALORIES, FUSION,
USER1-2, HR1-2. **Count the keys on the machine in front of you before naming a program.**

**Nothing on this drawing is a speaker or an audio jack**, though all seven consoles have both. The
jack is named only in the Speakers paragraph:
`spirit-xe-console-speakers-take-an-audio-cable-and-have-no-volume-control`.

**The XBR25-2019 drawing is this drawing with two changes** - six programs instead of ten, and no
Heart Rate % Profile call-out at all:
`spirit-residential-bike-console-face-six-programs`.

**The 2023 bikes replaced this face entirely.** Their overview drawing labels an LCD Window, an
Adjustable Fan, Program Buttons, Direct Resistance Level Buttons and USB Charging, with no cargo
compartment, no muscle figure and no percent profile.

**This is not the commercial CR/CU face.** Those drawings name an ultra-bright blue LED display and a
tablet rack: `spirit-cr900-cu900-console-overview-blue-led-and-tablet-rack`.
