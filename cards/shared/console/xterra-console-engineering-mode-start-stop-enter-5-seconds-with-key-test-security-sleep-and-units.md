The console has built-in maintenance/diagnostic software (units, and switching off the speaker beep on key presses). **Press and hold Start, Stop and Enter for about 5 seconds** until the message window shows "Engineering Mode", press Enter, and navigate with the Level up/down keys.

| Menu | What it does |
|---|---|
| a. Key Test | Test every key |
| b. Exit | Enter returns to the start-up screen |
| c. Factory Set | |
| d. Security | Locks the keypad; with the child lock on, the keypad works only after **holding Start and Enter for 3 seconds** |
| e. Functions | Press Enter, scroll with Level up/down: **Sleep Mode** - On; the console darkens after 30 minutes of no use, Off keeps it lit while power is on. **Motor Test** - runs the tensioning gear motor continually. **Units** - English or Metric. **Odometer Reset.** **Pause mode** - On; Off makes one press of Stop end the program, On keeps the data 5 minutes. **Safety** - Off; On sends the machine to **Level 20** of resistance to prevent use by a child |

There is no LCD test, Manual, TYPE SET or Key Tone entry in these two books - those are on the SB500 menu ([card](../../sb500-2020/console/engineering-mode-start-stop-enter-5-seconds-with-lcd-test-type-set-and-key-tone.md)). The FS5.9e page adds an incline calibration ([card](../../fs59e-2014/console/incline-calibration-by-holding-incline-up-and-start-5-seconds.md)). The FS5.8e scan ends at printed page 22, before the General Maintenance and warranty pages its contents list promises, so what its last pages say is unknown. The Spirit CU800 service manual prints the same menu ([Spirit twin](../../cu800-2012/console/maintenance-menu-30-minute-sleep-and-start-enter-three-second-unlock.md)). The SB4.5r, FS5.8e and FS5.9e books are scans read from the render; the SB500 2014 printing is a scan of the same text as the 2020 export.
