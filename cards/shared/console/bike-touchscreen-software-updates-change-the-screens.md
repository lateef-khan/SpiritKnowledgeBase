The manual states that the User Interface images it prints reflect the software version at the time the product was produced.

- The software version may be updated occasionally to include new features or repair bugs **when the console is connected to the internet**.
- Those updates may change the UI images on the console, **which may then no longer match the manual images**.

So a console whose screens differ from the printed pictures is not faulty. The manual does not say how to check the installed version, how to trigger an update, or how to go back to an earlier one.
