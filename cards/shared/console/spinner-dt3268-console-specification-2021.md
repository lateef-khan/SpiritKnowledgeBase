| Item | Range |
|---|---|
| Cadence bar graphic | 0~199 rpm |
| RPM | 0 ~ 199 RPM |
| Speed | 0 ~ 99 KM/H |
| Pulse | 30 ~ 240 BPM (**needs a chest belt**) |
| Time, count down setting range | 1~99 minutes |
| Time, count up setting range | 00:01~99:59 |
| Protocol | BLE4.0 |

**The count down range is written differently in the 2023 console manual**, which prints "99:59~00:01" for the same line. The other rows are identical between the two manuals.

**This manual also states the console assembly contents:** a computer console, a magnet, **one chest belt**, and a speed sensor transmitter. The 2023 console manual drops the chest belt from that list.

The console manual is published by Direction Technology and carries its own one-year warranty on the monitor, chest belt and transmitter, not SOLE's.
