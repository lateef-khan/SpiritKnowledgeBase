**The default computer settings are: Age = 35, Weight = 155 Lbs., Time = 30:00.**

**Max Level is set per program**, not once:

| Program | Factory max level |
|---|---|
| **Hill** | 7 |
| **Fatburn** | 5 |
| **Cardio** | 7 |
| **Strength** | 8 |
| **Interval** | 7 |

**155 lb is what the XE100 and XE200 console section prints. The XE300 section of the same manual
prints 150 lb**, on p. 36, with every other figure identical. Nothing in the manual explains the
difference and neither section corrects the other.

**So the machine matters.** Quoting 150 for an XE100 or an XE200 is wrong by the manual's own text;
see `spirit-xe-console-factory-defaults-age-35-weight-150-time-30-00` for the XE300, XE350 and XE550
figure.

**Only the weight differs.** Age 35, Time 30:00 and all five program max levels are the same in both
sections.

**These are the values the console uses if you press Start instead of entering your own**, and they
are overwritten the moment anybody types a different age or weight:
`spirit-xe-console-the-last-age-and-weight-entered-becomes-the-new-default`.
