**IDLE MODE** — Each program profile shows in the message window in turn, and the program name cycles with it. The heart rate bar LED and the track LED stay lit. The data windows show sample values: RPM 60, CALORIES 681, TIME 30:00, DISTANCE 12.0, PULSE 125.

**DISPLAY MODE** — Preset is DISPLAY ON (disabled). You change it in Engineering Mode. With the setting ON the console never sleeps unless you switch the power off. With no RPM input in idle mode it sleeps after **30 minutes** with no key press. In display mode the LCD is blank and the backlight is off. Any key wakes it back to idle mode. Resistance in sleep mode is 1.

**EXERCISE MODE (QUICK START)** — In idle mode press START to enter MANUAL mode. Age and weight use the preset values. Time counts up from 00:00, every countable value counts up from 0, and resistance counts up from 1. You may instead pick MANUAL, PROGRAM or HRC and then press START.

**PAUSE MODE** — Press STOP. The workout values are held and the message window shows "PAUSE", with the recorded values in the upper window. After 5 seconds it shows "PRESS START TO RESUME OR STOP TO END WORKOUT". With no key press for five minutes it returns to idle mode. When you press START the tension motor returns to the level it was on before the pause.

**END MODE** — The message window shows "WORKOUT SUMMARY" and holds the workout data for 3 minutes, cycling AVG LEVEL, AVG SPD and AVG RPM every three seconds, plus total CALORIES, TIME and DISTANCE. With no key press for 3 minutes it returns to idle mode.

**RESET MODE** — In idle mode hold STOP for more than three seconds. The system resets. If child lock is on you must clear child lock first.
