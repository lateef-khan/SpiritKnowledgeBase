**Twenty columns of dots, 8 high**, one per workout segment. The dots show approximate effort only, never an exact value. In operation the window builds a profile 'picture' as speed/incline change. When the word **Speed** is lit above the matrix the Speed profile shows; when **Incline** is lit the Incline profile shows. Press **Enter** to swap views; a **third** press alternates Speed and Incline automatically, five seconds each. The AF books call the same key the 'select button' mid-paragraph ('pressing the select button a third time'); the card follows the books' own first naming (Enter).
