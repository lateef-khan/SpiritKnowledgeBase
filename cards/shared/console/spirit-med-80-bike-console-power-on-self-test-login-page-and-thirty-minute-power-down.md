**"When initially powering on the console please wait a few minutes for internal self-test. Then the
console will go to the start up display (login method page). You may now begin to use the machine
after choosing the login method."** A minute-long blank screen after the power switch goes on is
normal on this console; it is a touchscreen booting an operating system, not an LED console lighting
in seconds.

**"The console will automatically power down after 30 minutes of inactivity. Press any function key
to wake the console up again. Always turn off the main power switch when the machine is not in
use."** The function keys are the +/-, START & PAUSE and ENTER keys under the screen
(`spirit-med-80-bike-console-function-keys-and-the-protective-sheet-to-peel-off`); the main power
switch is on the input module at the front of the bike, beside the power socket.

**The bikes have a built-in universal power supply** - 100 to 240 volts, 50 to 60 Hz - and "the input
module has an input connector for the line cord, a power switch and a **5 amp fuse**".

**Faults arrive as a message.** "NOTE: If there is an issue, the console will show an error message
along with a possible solution. Follow the message to resolve the issue." Neither owner's manual
prints an error code list; the service manuals' Error Log is on the maintenance-mode cards.

**There is no odometer and no software version on the boot screen** - those are on the 7.0 series
(`spirit-med-70-bike-console-power-on-self-test-odometer-and-a-twenty-minute-power-down`), which also
powers down after 20 minutes, not 30. The 8.5UE ergometer and the 8.0T treadmill print this page as
these bikes do (`85ue-2025-console-power-on-self-test-and-thirty-minute-power-down`,
`80t-2026-console-power-on-login-page`).
