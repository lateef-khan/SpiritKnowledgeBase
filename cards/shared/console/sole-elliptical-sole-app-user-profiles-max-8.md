The App-screen art in these books reads **'Maximum possible User Profiles: 8'** with an **Add New User** button ('create space for a new profile by selecting the profile you wish to delete'). Read off the render: the OCR supplement mangles this art ('Profiles:6', 'soace', 'orotile') and must not be quoted. The 2023 touchscreen consoles allow 9 local console profiles instead (see_also).
