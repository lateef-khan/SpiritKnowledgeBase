The console has built-in maintenance/diagnostic software that lets you change settings such as English to Metric or turn off the key beep. To enter the Engineering Mode Menu, press and hold the **Start, Stop and Enter** keys for about **5 seconds** until the Message Center displays Engineering Mode Menu, then press Enter to access:

1. **Key Test** — tests all the keys.
2. **Display Test** — tests all the display functions.
3. **Functions** — press Enter, then Speed + or − to scroll:
   - **Sleep Mode** — on, the console powers down automatically after **15 minutes** of inactivity.
   - **Pause Mode** — on, a pause lasts 5 minutes; off, the console pauses indefinitely.
   - **Maintenance** — resets the lube message and the odometer readings.
   - **Units** — English or Metric.
   - **Key Tone** — turns off the speaker so no beep is heard on a key press.
   - **BEEP** — "after closing, there is no sound for key operation".
4. **Child Lock** — locks the keypad against unauthorized use; when enabled the keypad will not operate until you press and hold the Child Lock buttons for 3 seconds. The book does not say which buttons those are.
5. **Exit**.

The book prints both a Key Tone and a BEEP entry with near-identical descriptions and does not say how they differ. Calibration is a separate mode entered with Start and Speed Up ([calibration card](xterra-tr-console-calibration-start-and-speed-up-to-factory-settings-with-grade-return.md)). Spirit's 2023 XT treadmills print a near-identical menu ([Spirit twin](xt-2023-console-engineering-mode-menu.md)).
