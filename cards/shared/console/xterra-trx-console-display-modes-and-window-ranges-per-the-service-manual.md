From the shared Dyaco GT90C-NT023 / GT90D-NT024 service manual, chapter 4. Its Display Windows page says the two LCD layouts are the same, just different sizes — **6.5"** for the GT90C (TRX3500) and **7.5"** for the GT90D (TRX4500) — and the render shows PACE, CALORIES, TIME, DISTANCE and PULSE windows above an incline scale, a dot matrix, a heart-rate percentage bar and a speed scale.

**Modes.** OFF: with the treadmill on but no safety key, the console shows the idle-mode status but does not work. READY: with the key in, the message window shows "press start for quick start or program button for setup". RUN: pressing STOP or removing the key stops the treadmill instantly and enters OFF mode.

| Window | Display range | Work range | Notes |
|---|---|---|---|
| SPEED | 0.0 – 99.9 km/h | 1.0 – 16.0 km/h (0.5 – 10 mph) | FAST/SLOW change it by 0.1 |
| INCLINE | 0 – 99.9 | 0 – 15 | preset value 0 – 15; UP/DOWN move it by 1 |
| TIME | 0:00 – 99:99 | 0:00 – 99:59 | count-up setup 10:00 – 99:00; STOP saves the value and re-entering RUN continues counting |
| DISTANCE | 0.00 – 99.99 | 0.00 – 99.99 | km or miles |
| CALORIES | 0.0 – 999 | 0.0 – 999 | |
| PULSE | 0 – 999 | 40 – 220 | hand pulse or receiver (chest belt); in RUN mode, **8 seconds without a signal and the value becomes "P"** |
| PACE | 0.00 – 99.99 | 0.00 – 99.99 | how long it takes to cover each km or mile at the current speed, in min/km or min/mi |

**Contradictions.** The 10 mph work range does not match either owner's manual, which calibrate to 12 mph and badge "0-12 mph"; and the 0-15 incline matches the TRX4500's keys but not the TRX3500's 0-12. The page names neither machine, so it cannot be assigned to one.
