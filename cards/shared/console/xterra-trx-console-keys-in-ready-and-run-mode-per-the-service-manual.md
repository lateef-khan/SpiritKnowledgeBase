From the shared Dyaco GT90C/GT90D service manual. Its button-location drawing labels a speaker each side, incline shortcut keys and speed shortcut keys either side of the display, a fan vent, Incline UP (+)/DOWN (−), Speed FAST (+)/SLOW (−), the Fan key, Start & Stop key, Safety key, Enter key and Program key — with a note beside the speed shortcut keys, "Note this name relates to Bluetooth".

**READY mode**
- SAFETY KEY: fit it to power on the console; pulling it away shuts the computer down.
- START/STOP: in standby the first press gives a **3-second countdown**, then the machine runs in the Manual program (a preset program starts at its default speed). The second press **pauses**; the third starts again; and so on in a cycle.
- ENTER: sets preset program values (count-down time, distance, calories) and confirms other settings.
- PROGRAM: in standby, enters the preset programs — any of **P1-P30, 1 HRC, 2 USER MODE**.
- FAST, SLOW, UP, DOWN: non-functional unless a setting is being entered. Speed and incline rapid keys: non-functional.
- FAN: turns the fan ON/OFF.

**RUN mode**
- SAFETY KEY: pulling it away shuts the computer down.
- START/STOP: the same start/pause/start cycle.
- ENTER and PROGRAM: non-functional.
- FAST / SLOW: 0.1 kph (0.1 mph) per press; held continuously, speed runs to MAX or MIN quickly.
- UP / DOWN: one incline position per press; maximum incline position **12**, minimum 0 — right for the TRX3500, but the TRX4500's console goes to 15.
- SPEED RAPID: 10 preset buttons. INCLINE RAPID: 10 preset buttons.
- FAN: turns the fan ON/OFF.

The owner's manuals' versions are on the quick-start cards and [the pause card](xterra-trx-console-pause-with-start-stop-and-reset-by-holding-enter.md).
