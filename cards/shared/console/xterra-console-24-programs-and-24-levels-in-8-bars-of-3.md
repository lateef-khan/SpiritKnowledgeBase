**PROGRAM:** 24 different programs. **LEVEL:** the programs have **24 levels of work displayed in 8 bars in each column**; each column represents 1 minute of workout (unless time is changed to a new count-down value) and **each bar represents 3 levels**.

**Workout selection.** After power-up use UP/DOWN to select a program and press ENTER. The SB2.5r, FS2.5 and FS3.5 list 7 basic programs (Manual, Pre-Programs, Watt, Body Fat, Target Heart Rate, Heart Rate Control, User); the RSX1500 lists 6, leaving Body Fat off the list although its book still prints a Body Fat page. The programs themselves are on the Programs cards.

**Setting workout parameters.** Once a program is selected, ENTER makes "Time" flash; set it with UP/DOWN, press ENTER, and the flashing prompt moves to the next parameter; press START/STOP to start. **Time and Distance cannot both be set in the same workout**, and some parameters are not adjustable in certain programs.

The setting range, default and step of each parameter (time, distance, calories, watt, age, pulse) are on the programs card `xterra-programs-workout-parameter-ranges-time-to-99-minutes-calories-to-9995-watts-40-to-250`; this card covers the keys and the display.

The FS1.5 has the same keys with 13 programs and 16 levels ([card](../../fs15-2019/console/13-programs-and-16-levels-in-8-bars-of-2.md)).
