**To open it:** press and hold the **Start, Stop and Enter** keys at the same time, until the display shows **"Maintenance Menu"**. Press **Enter**. Scroll with the **Up and Down** keys; the **Stop** key returns to the previous menu selection.

| Item | What the manual says it does |
|---|---|
| A. Key Test | |
| B. Display Test | |
| C. Functions | |
| C.I Display Mode | Turn **On** to have the console power down automatically after **30 minutes** of inactivity. |
| C.II Pause Mode | Turned **On** to allow **5 minutes** of pause, turn Off to pause indefinitely. |
| C.III ODO Reset | Resets the odometer reading to zero. |
| C.IV Units | English (Imperial) or Metric display readings. |
| C.V PWM Test | For testing the brake function. |
| D. Factory Settings | For factory use only. |
| E. Exit | |

**Two things separate this from the 2013 menu of the same family.** This one opens on the words "Maintenance Menu" where 2013 shows "Engineering Mode"; its brake item is called **PWM Test** where 2013 calls it **Brake Test**; and it has **no Security item**, so there is no child lock here. Its Display Mode is also turned **On** to power the console down, where 2013 says turned **Off**.

**There is no ODO Reset on the later touchscreen consoles of this family**, so do not carry this list forward either.
