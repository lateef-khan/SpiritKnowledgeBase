**Both bikes' parts drawings label the console the same way**: **A. 10" touch panel console**, **B.
Vertical viewing angle adjustment**, **C. Console articulating arm horizontal adjustment**.

**"360 degree Swivel Console Articulating Arm - This provides the ability for clinicians to operate
the console from any position around the machine, and allowing a suitable viewing distance for the
patient. The tilted view angle adjustment meets a wide variety of user heights."** Both books print
the paragraph word for word.

**The 8.0U drawing labels four connections the 8.5R drawing does not.** On the upright: **M. USB Type
B Port; for Stress Testing & Data Transfer**, **N. UART Port; for Stress Testing**, **O. Power ON/OFF**,
**P. Power socket** - all four grouped at the front of the base. The 8.5R drawing stops at P.
Leveling glides, with no port call-outs, although its data transfer chapter says the same USB Type B
port is "on the front end of the product"
(`spirit-med-80-bike-console-usb-type-b-data-transfer-with-the-workout-management-software`).

**The screen is the whole console.** "All information required for operation is explained on
screen" - there is no message window, no dot matrix and no program keys; the only physical keys are
the +/-, START & PAUSE and ENTER keys under the display
(`spirit-med-80-bike-console-function-keys-and-the-protective-sheet-to-peel-off`).

The 8.5UE upper body ergometer carries the same console on the same arm
(`85ue-2025-console-ten-inch-touch-panel-on-a-360-degree-articulating-arm`). The 7.0 series is an LED
console with keys and no arm
(`spirit-med-70-bike-console-face-ten-numbered-program-keys-two-display-keys-and-a-set-up-key`).
