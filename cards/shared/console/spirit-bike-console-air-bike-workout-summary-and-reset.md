**WORKOUT SUMMARY.** The console provides a brief summary after a completed workout. **Data displayed
is Total Time, Total Distance and Total Watts** - three figures, nothing else. No average speed, no
average RPM, no calories, no heart rate.

**It is shown after every mode ends**, whether the mode reached its target, the last interval
finished, or the Stop button was pressed.

**RESET PROCESS.** To reset all saved settings, **press and hold the Stop button for 2 seconds**.

**Two things survive that reset:**

- **The metric or imperial units setting.** The reset page says so explicitly.
- **The ODO value.** The engineering mode page says the console will not erase the setting value or
  the ODO value under RESET mode.

**Only removing the batteries clears those**, which returns the console to original factory settings
and zeroes the odometer.

**Reset is why the target modes ask you for a value.** The target and interval mode descriptions all
begin "after the console has been reset" - a mode you have run before reuses the last value you
entered unless you have reset since.

**Stop has two jobs.** A short press ends a mode; a two-second hold is this reset.

**The service manual says what the reset looks like.** Hold Stop for 2 seconds in any mode: the LCD
flashes once over 2 seconds, the buzzer rings for 2 seconds, and the console returns to the standby
screen with "all settings clear reply to default values". Its engineering-mode page repeats that the
setting value and the ODO survive this reset and only a battery pull clears them.
