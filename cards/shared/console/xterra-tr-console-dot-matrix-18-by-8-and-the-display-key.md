The dot matrix display is **18 columns wide by 8 rows high**. The columns represent the segments of your workout; the rows give a visual picture of the intensity level but do not necessarily indicate a specific value. In operation the Speed / Incline dot matrix window builds a profile "picture" as values change during a workout.

When the **Speed** indicator above the dot matrix is lit the matrix shows the Speed profile; when the **Incline** indicator is lit it shows the Incline profile. Press the **Display** key to change the view between the Incline profile, the Speed profile, and Incline + Speed. After scrolling completely through the options with the Display key, the console automatically scrolls through them, showing each for **five seconds**.

The quarter-mile track drawn around the matrix is on [the track card](xterra-tr-console-quarter-mile-track-around-the-dot-matrix-with-a-laps-window.md).
