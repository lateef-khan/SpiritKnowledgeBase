**When you first turn the console on, pressing a program key previews what that program's profile
looks like.** If you decide you want to try it, press the **Enter** key to select the program and
enter the data set-up mode.

**Two different keypads do this.** On the CE800-2021, CE800-2023, CE850-2020, CE850-2022 and CES880
there is **one Program button** that steps through the programs. On the CE800-2013, CE850-2016 and
both CE900 consoles there is **one key per program**, and you press the key for the program you
want and then Enter.

**Preview only works from the start-up screen**, before a workout has begun.

The CE800ENT touchscreen has no program key; its programs are tiles behind the **Exercise Programs**
button on the Home screen.
