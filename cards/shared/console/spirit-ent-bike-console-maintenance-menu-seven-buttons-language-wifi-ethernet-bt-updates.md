**This is where Wi-Fi, Ethernet and Bluetooth are set up.** The manual's whole description:

> Set default Language, Wi-Fi or Ethernet, enable Bluetooth function, Update APP (USB of manual
> update), Update OS (reserved), Update APPS (internet function of APPs)

The screen lists seven buttons, in this order:

| Button | What the description says it is for |
|---|---|
| Default Language Setup | Set the default language |
| WiFi Setup | Wi-Fi connection |
| Etherent Setup | Ethernet connection - the button really is printed "Etherent" |
| BT Setup | Enable the Bluetooth function |
| Update App(USB) | Update APP, a USB manual update |
| Update OS | Reserved |
| System & Apps | Update APPS, the internet function of the APPs |

**That is the whole of it.** No SSID entry sequence, no static-IP fields, no update file name and no
Bluetooth pairing procedure is printed in either bike book. The CE800ENT elliptical prints exactly
this page (`ce800ent-maintenance-menu`). The CU900ENT documents its own, different, six-button
Maintenance menu screen by screen (`cu900ent-maintenance-menu`, `cu900ent-wifi-ethernet-setup`,
`cu900ent-usb-software-update`); those screens are a different console and are not evidence for
these two bikes.

**A Bluetooth chest strap is paired here.** The troubleshooting matrix of both books says, for a
strap that gives no reading: "Turn on Bluetooth on the console of system, tap the name of the
Bluetooth device you want to pair with your Bluetooth chest strap" - which is this BT Setup button.
The owner's manuals print no pairing procedure at all (`ct800ent-2022-console-heart-rate-feature`).

The treadmills of this generation print the same seven buttons with **CTP Testing** in place of
System & Apps (`spirit-ct800ent-console-maintenance-menu-language-wifi-ethernet-bluetooth`).
