In Manual setup (Up/Down to highlight the Manual icon, Enter, then Age, work level, Time, Distance, Calories in turn), the Watt icon blinks last: setting a Watt number makes the machine **hold that work rate by itself** - pedal faster and the workload drops, pedal slower and it rises (100 W keeps a 100-watt bulb burning). Watts come from pedal speed times workload. Press Start after any step to begin with the rest counting up from zero.
