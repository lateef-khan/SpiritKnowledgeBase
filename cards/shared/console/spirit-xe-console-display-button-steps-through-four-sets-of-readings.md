**There is a second Display button on the bottom left of the message window** - a different key from
the Display button beside the dot matrix.

The message window starts on **Time and Distance**. Each press brings up the next set, **four
windows in all**, in this order:

1. **Time and Distance**
2. **Pulse and Calories**
3. **Speed in RPM and MPH**
4. **Work Level and Watts**

**Press Display again while Level and Watts is showing and the Scan light comes on**: the message
window shows each set for **four seconds**, then switches to the next in a continuous loop. Press
again to return to the beginning.

**Unlike the commercial CE consoles, this list really is four items and there is no METs stop.** The
CE800-2013 and CE850-2016 print the same paragraph with **METs** added as a fifth, while still
calling it "four windows in all":
`spirit-ce-console-display-button-four-window-sets`.

**The XE100 and XE200 have neither this button nor this list.** Their message window starts on Speed
and is stepped with the **Enter** button:
`spirit-xe-console-enter-button-steps-the-message-window-from-speed`.
