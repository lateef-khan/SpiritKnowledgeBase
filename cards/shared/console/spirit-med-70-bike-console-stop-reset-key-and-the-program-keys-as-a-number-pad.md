**The Stop / Reset key provides several functions:**

| Press | What happens |
|---|---|
| **Once, during a program** | Pauses the program. "To resume the exercise session just press the Start key or start pedaling." |
| **Twice, during a workout** | The program ends and **a summary of information of the exercise session** is displayed |
| **Held for 3 seconds** | The console performs a complete Reset (the key is printed *Hold to reset*) |
| **During data entry** | **Previous Screen** - "go back one step in the programming each time you press the Stop/Reset key" |

**No pause length is printed on this page.** The commercial bikes' books say five minutes here; these
say only "pause". The length is a setting: the maintenance menu's Pause mode entry reads "Turn on
allow 5 minutes of pause, turn off to have the console pause indefinitely" in the owner's manuals,
while the service manuals say Pause on "lasts **30 minutes** then the console returns to the idle
mode" (`spirit-med-70-bike-console-maintenance-mode-with-a-sleep-switch-a-keypad-lock-and-factory-settings`).
Do not quote five minutes as a certainty.

**The program keys preview a program in idle mode** - press one to see its profile, then **Enter** to
begin (`spirit-ce-console-program-key-previews-the-profile`).

**"The program keys also function as a Number Key Pad when you are in the data-setup mode. The
number for each key is shown above the program name. If you are entering new data such as Time, Age,
weight etc., you can use these keys to enter the numbers quickly."** The keys run 1 Manual to 5 HR on
the left and 6 Facility to 0 Symmetry on the right
(`spirit-med-70-bike-console-face-ten-numbered-program-keys-two-display-keys-and-a-set-up-key`).

The 7.0T treadmill splits these into two cards (`70t-2026-console-stop-reset-key`,
`70t-2026-console-program-keys-number-pad`); the rehabilitation steppers hold them together as here.
