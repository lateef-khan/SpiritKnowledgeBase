If the bike is **not** connected to the app, the console displays **"SYNC"** when the workout is over. You can then connect with your phone or tablet to store that workout's data in the app.

**The console only stores the last workout.** When the bike returns to IDLE MODE the workout data is erased.

So a workout is only recoverable until the console goes idle. Connect before that happens.
