To get a more accurate exercise result, enter your personal data (gender, weight, units, etc.) into the computer:

1. Go to **KCAL MODE** by pressing MODE.
2. Press **SET for 3 seconds** to enter User Set.
3. Press **SET and MODE alternately** to enter the correct personal data (the pictures step through KCAL, then weight in LB, then a flashing KG/gender screen).
4. **Press MODE for 3 seconds** when complete.

The wheel size and km/h or mile/h choice is a separate setting ([wheel size card](xterra-mb-console-wheel-size-100-to-6999-mm-set-to-4330-mm-and-user-1-or-2.md)). The MB500 book is a scan read from the render (the console pages are OCR); the MB550 book prints the same console chapter natively and is cited alongside.
