The AF63/AF65 book heads this section 'MAINTENANCE MENU (F65 only)', so on that book it covers the AF65-2011 only. Entry and items match across all five books.

1. Press and hold **Start, Stop and Enter** at the same time, until the display shows 'Engineering mode' (it may say maintenance menu, depending on version). Press Enter.
2. Scroll with the **Fast/Slow** keys (the AF book writes 'Speed Fast/Slow keys' here); **Stop** returns to the previous menu selection. The selections are:
   - **A. Calibration** - used to verify calibration.
   - **B. Factory Settings** - access only allowed by manufacturing.
   - **C. Security** - locks the keypad (child lock; hold Start and Enter 3 seconds to unlock).
   - **D. Functions** (Enter; Fast/Slow to scroll): **I. Sleep Mode** (on = power down after 30 minutes inactivity); **II. Pause Mode** (on = 5 minutes of pause, off = pause indefinitely); **III. Maintenance** (reset lube message and odometer readings); **IV. Units** (English or Metric); **V. Grade Return** (returns elevation to lowest setting when pause is pressed).
   - **E. Key Test** - tests all keys.
   - **F. Display Test** - tests all display functions.
