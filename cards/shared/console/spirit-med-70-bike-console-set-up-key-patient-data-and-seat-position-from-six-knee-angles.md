**"The set up key function will allow you to enter patient data and customize the settings of the
[bike]. When the Set Up key is pressed the first option in the menu appears. Use the up/down arrows
to scroll through the menu and press the enter key to select an option."** The Dyaco MED 7.0R adds
that it also sets "seat and pedal adjustments for various knee ranges of motion".

**Patient data** - what each entry is used for:

| Entry | Used in |
|---|---|
| **Age** | VO2 and heart rate programs |
| **Gender** | VO2 program |
| **Weight** | METS and Calorie calculations and the VO2 program |
| **Height** | the Symmetry program |

**Seat position** - "User may input desired knee flexion angles (6 options) and the software will
calculate the seat's vertical position and pedal position settings." Two cautions are printed with
it: the result "is intended to aid in patient set up but may not be the final settings as patient's
body symmetry may vary slightly", and the calculation "uses the height from the Patient Data settings
for limb length" and **assumes the seat fore/aft position is in the centre of its adjustment range**.

**The six knee angle options, as printed:**

1. R Min (right leg minimum flexion) and L Min (left leg minimum flexion)
2. R Max (right leg maximum flexion) and L Max (left leg maximum flexion)
3. R Max and L Min
4. R Min and L Max
5. R Max and R Min
6. L Max and L Min

**The books say what the pedal setting is for but not what number the console gives you.** The pedal
adjustment page says only that there is "a numbered scale for repeatability and a program in the Set
Up function of the console that can assist in setting up the pedal position to accommodate various
patient knee angles". The adjustable crank runs "from 15 degrees to full range".

**Two more entries follow Patient data and Seat position** - Watts per row and Level Scale
(`spirit-med-70-bike-console-watts-per-row-10-to-100-and-a-level-scale-of-5-10-or-15-watts`).
**There is no fan entry**: the 7.0T treadmill's 2026 book gives the same key a second job as a fan
switch, and these bikes have no fan (`70t-2026-console-set-up-menu-patient-data`).

**"If you start a program without changing the settings, the data from the Set Up menu will be used."**
The rehabilitation steppers' Set up key calculates position from height alone
(`spirit-rehab-stepper-console-set-up-key-position-by-height-and-the-track-or-step-graph`).
