Press **Enter** on **Functions** to access the settings, and the **Up arrow** to scroll.

| Setting | What it does |
|---|---|
| I. Display Mode | See the contradiction below - the manuals disagree about which way to set it |
| II. Pause Mode | **Turn on** to allow **5 minutes** of pause; **turn off** to have the console pause indefinitely |
| III. Maintenance | Not described the same way in all three - see below |
| IV. Units | Sets the display to readout in **English or Metric** display measurements |
| V. Beep | **Turns off the speaker so no beeping sound is heard** |

**Display Mode is printed in opposite senses.** The **XT385-2015 and XT485-2015** manuals print
*"Turn **off** to have the console power down automatically after 30 minutes of inactivity."* The
**XT685-2015** manual prints *"Turn **on** to have the console power down automatically after 30
minutes of inactivity."* Both are reproduced as printed. The **30 minute** period is the same in all
three; only the on/off sense differs, and nothing in the manuals resolves it. Do not quote a
direction for the XT685 without testing the machine.

**Maintenance is described differently too.** The **XT385-2015 and XT485-2015** manuals print
*"Maintenance (Allows you to reset the lube message time)"*. The **XT685-2015** manual prints
**"Maintenance"** with **no description at all**.

**Do not carry the 2023 figures onto these machines.** The 2023 XT consoles call the first entry
**Sleep Mode** and give it **15 minutes**, not 30. See `xt-2023-console-engineering-functions`.

**The XT185-2015 and XT285-2015 print a different list** - the fifth entry is called **Key Tone**,
and their Maintenance entry resets the lube message *and* the odometer readings. See
`xt-2015-console-engineering-functions-key-tone`.
