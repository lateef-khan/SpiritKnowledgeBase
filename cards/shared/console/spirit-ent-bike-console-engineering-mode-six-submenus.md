**Click the Home icon at the top of the main page centre 10 times.** The setting page then offers
**a total of 6 sub-menu modes**, described word for word as:

| Item | Description printed |
|---|---|
| Engineering Mode | Set the unit, Sleep mode |
| Security | Set Lock Accumulate mileage. |
| Diagnostics | The Error Diagnostics |
| Machine Information | Set Machine Type, GS Mode, Touch sound, Sleep Mode, Safety Mode, Zero mileage. |
| Maintenance | Set default language, Wi-Fi, Ethernet, Bluetooth, USB update, update OS. |
| A / V Source Setup | Set audio/visual source. |

Each entry has its own card: `spirit-ent-bike-console-engineering-mode-units-beep-30-minute-sleep-and-5-minute-pause`,
`spirit-ent-bike-console-security-mileage-lock-four-digit-password-and-2222`,
`spirit-ent-bike-console-machine-information-rpm-detection-safety-lock-zeroing`,
`spirit-ent-bike-console-maintenance-menu-seven-buttons-language-wifi-ethernet-bt-updates` and
`spirit-ent-bike-console-av-source-setup-csafe-or-cab-protocol`. **Diagnostics** is one line -
"Recorder the error code on machine during running" - and is held with the error cards.

**Two descriptions do not match the screens they open**, exactly as on the CE800ENT elliptical
this book was copied from (`ce800ent-engineering-mode-menu`). Machine Information promises GS Mode,
Touch sound and Sleep Mode; its screen has Machine Type, RPM Detection, Safety Lock and Zeroing.
Engineering Mode promises only unit and sleep; its screen also carries Beep Mode and Pause Mode.

**Six entries, not seven.** The CR900ENT and CU900ENT bikes list seven, with TV Setup and BT Setup
at the top level (`cu900ent-engineering-mode-menu`); the CT800ENT and CT850ENT treadmills of this
generation list seven with a Lube Setup (`spirit-ct800ent-console-engineering-mode-seven-submenus`).
The ten-press gesture is the same on all of them: `spirit-ent-console-enter-engineering-mode`.

**The owner's manuals for these two bikes never print this menu.** Their console chapter ends at
the Entertainment tile (`spirit-ent-bike-console-entertainment-tv-mode`); the service manuals are
the only documents that open the setting page.

**Both books are the same document with the model name swapped.** The CR800ENT book heads its
operation page FUNCTIONS OF THIS UPRIGHT BIKE and says "The CU800ENT will also pick up wireless
heart rate transmitters" - the recumbent's book was made from the upright's without correcting
either line.
