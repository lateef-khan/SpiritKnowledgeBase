**"Below the Dot matrix display is a Heart Icon and a Bar Graph."** Grasping the hand pulse sensors, or
wearing a heart rate chest belt transmitter, "will start the Heart Icon blinking (**this may take a few
seconds**). The Message Window will display your heart rate in beats per minute."

**The bar graph "represents the percentage of maximum heart rate."** The drawing marks it **50 55 60 65
70 75 80 85 90 %** under the legend *Heart rate % profile*. **"Note: Enter the correct age in Set up
for the Bar Graph to be accurate"** - the age lives in the Set up menu's Patient data, not in a
program prompt (`spirit-med-70-bike-console-set-up-key-patient-data-and-seat-position-from-six-knee-angles`).

**The formula is not printed here.** The heart-rate program page gives the maximum as 220 minus age;
that page belongs to the program cards.

**Not a medical reading.** The operating page says the heart rate function "is not a medical device
and should not be relied on when accurate readings are necessary" and that patients in cardiac rehab
"may benefit from using an alternate heart rate monitoring system like a chest or wrist strap".

**The Dyaco MED 7.0R prints this paragraph word for word too.** The 4.0 series has neither icon nor
bar and shows the pulse in its message window alone
(`spirit-med-40-bike-console-heart-rate-from-the-grips-or-a-chest-belt-and-why-age-matters`); the
7.0T treadmill (`70t-2026-console-heart-rate-percent-bar-graph`) and the CE900 ellipticals
(`spirit-ce-console-heart-icon-and-bar-graph`) carry the same icon and bar.
