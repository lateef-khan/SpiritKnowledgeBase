"During a workout, the display console will alternately and repeatedly display the Time, Time/500M, SPM, Distance, Strokes, Total Strokes, Calories Burned and Pulse" - the same sentence in all three books; ENTER cycles the scan by hand ([key card](xterra-ergw-console-keys-up-down-enter-start-stop-reset-and-recovery.md)).

| Reading | As printed | Target setting (UP/DOWN) |
|---|---|---|
| **TIME** | - | 1 min ~ 99 min, in 1-minute increments |
| **TIME / 500M** | "Your average time to reach 500 meters is automatically displayed" | - |
| **SPM** | Strokes per minute | - |
| **DISTANCE** | - | 0 ~ 99900 meters, 100-metre increments |
| **STROKES** | - | 0 ~ 9990 strokes, 10-stroke increments |
| **TOTAL STROKES** | "Accumulates total strokes from 0 up to 9999" | - |
| **CALORIES** | - | 10 ~ 9990 Cal, 10-calorie increments (the ERG600W book misprints "10 strokes increments") |
| **PULSE** | chest strap only, target 30 to 240 ([pulse card](xterra-ergw-console-pulse-30-to-240-only-from-a-wireless-chest-strap-sold-separately.md)) | 1 BPM |
| **WATT** | ERG550W: "Current workout watts with available range from 0 up to 999"; ERG650W: "Displays the current Watt output"; the ERG600W book lists no WATT line though its face has a WATTS window | - |
| **DRAG FORCE** | ERG650W only: "Displays the current Drag Force"; the ERG550W says "the drag force value will display in the matrix" in Manual mode | - |
| **A+** | ERG650W only: the average of time, calories, watt and pulse | - |

**STROKES and TOTAL STROKES are two counters** - one you can set a target on, one that only accumulates. The ERG600W book adds three readings shown only in sleep mode - calendar, room temperature and clock ([ERG600W clock card](../../erg600w-2021/console/power-up-sets-the-clock-calendar-and-alarm-then-the-sport-screen.md)). Only one target can count down at a time; how MANUAL and RACE use these settings is a programs question. Distance is in metres with no units setting. The Spirit water rowers define TIME/500m the same way and show the same windows ([Spirit twin](spirit-water-rower-console-window-call-outs.md)); the ERG700's 500M/TIME is a matrix state with no definition ([ERG700 card](../../erg700-2022/console/scan-alternates-the-wave-pattern-and-500m-time-every-5-seconds.md)).
