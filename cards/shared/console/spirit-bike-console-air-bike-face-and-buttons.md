The console overview drawing names six areas:

- **INTERVAL DISPLAY PANEL** - across the top.
- **QUICK MODE BUTTONS** - a row either side, above the screen.
- **TIME, DISTANCE, CALORIES, WATTS, SPEED, RPM DISPLAY PANEL** - the main data panel.
- **BLUETOOTH BUTTON**.
- **HEART RATE DISPLAY PANEL** - lower left.
- **CONTROL KEYPAD** - lower centre.

**The eight quick mode buttons are named on the console face**, four down each side of the screen.
The text layer of both manuals prints only the words "QUICK MODE BUTTONS"; the names below were read
off a 170 dpi render of the drawing, which is a picture.

| Left column | Right column |
|---|---|
| **TARGET TIME** | **INTERVAL 20-10** |
| **TARGET DISTANCE** | **INTERVAL 10-20** |
| **TARGET CALORIES** | **INTERVAL CUSTOM** |
| **TARGET HR KEY** | **BLUETOOTH** |

**The control keypad is four keys around one big one:** **UP** and **START** on the left, **DOWN** and
**STOP** on the right, and a large circular **ENTER** in the middle.

**The screen's fixed legends**, also readable only from the drawing: `10/20`, `20/10`, `CUSTOM`,
`READY`, `TOTAL`, `TIME`, `WORK`, `REST`, `ROUND`, a Bluetooth mark, `TIME`, `DISTANCE`, `CALORIES`,
`WATTS`, `SPEED`, `RPM`, each of the last three with a `MAX / AVE` tag, `KM`, and on the heart rate
row `AGE`, `65%`, `85%` and `Max` with an up and a down arrow.

What each button does:

| Button | Function |
|---|---|
| **Quick Mode buttons** | Go into the associated mode **immediately** |
| **Arrow buttons** | Increase or decrease console values |
| **Start** | Go into a mode; restart a paused mode; or temporarily pause a running mode |
| **Enter** | Confirm a value when making adjustments to a mode |
| **Stop** | End a mode |
| **Bluetooth** | Upload the workout summary to the app |

**Start is also the pause key.** There is no separate pause button: pressing Start during a running
mode launches Pause Mode. See `spirit-bike-console-air-bike-sleep-ready-pause`.

**There is no resistance control, and there are no resistance levels.** These are fan-resistance
machines - resistance comes from how hard you pedal and push, so nothing on the console sets it.

**The AB950 also names an `A. LCD Screen` and a `D. Console`** as separate items in its parts
diagram: the screen is the display, the console is the housing it sits in.

**The service manual's console drawing carries call-outs the owner's manual's does not.** It labels the
**Interval Display Panel**, the **Time, Distance, Calories, Watts, Speed, RPM Display Panel**, the
**Heart Rate Display Panel**, the **Quick Mode Keys** (two columns, TARGET TIME / DISTANCE / CALORIES /
HR KEY and INTERVAL 20-10 / 10-20 / CUSTOM / BLUETOOTH), the **Bluetooth Key** and the **Control
Keypad** - the same six areas, named on the picture - and prints "Bluetooth function: Only the model
of Bluetooth device configuration" beneath it.
