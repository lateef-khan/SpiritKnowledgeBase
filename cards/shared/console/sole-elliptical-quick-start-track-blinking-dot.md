After the console powers up, just press **Start**: Quick Start mode begins, the time counts up from zero, and resistance level and incline stay manually adjustable (Level / Incline keys; the E20 books have level only). The dot matrix shows a track with a blinking dot marking progress around it. Starting a program key instead and pressing Start without entering settings works the same way with defaults.
