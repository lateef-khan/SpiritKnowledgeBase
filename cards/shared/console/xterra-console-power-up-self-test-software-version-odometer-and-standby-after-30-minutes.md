The machine is supplied with an external power supply; when power is connected the console powers up by itself. **With no input for 30 minutes the console goes to stand-by mode to save energy; press any key to turn it on.**

**Power-up sequence.** An internal self-test lights everything; when the lights go off the dot-matrix shows a **software version (e.g. VER 1.0)** and the time and distance windows show an **odometer - hours used and virtual miles**. After a few seconds the start-up display scrolls the workout profiles and operating instructions.

The SB500 prints the same page with 20 minutes ([card](../../sb500-2020/console/power-up-self-test-software-version-odometer-and-standby-after-20-minutes.md)). The SB4.5r, FS5.8e and FS5.9e books are scans read from the render; the SB500 2014 printing is a scan of the same text as the 2020 export.
