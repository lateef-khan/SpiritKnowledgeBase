Contradiction ruled: these books print the exit **twice** – the TURNING OFF item 3 says 'Use the speed Up key', while the ATTENTION box says 'Use the Up arrow or Fast key'. The card follows the ATTENTION box (the fuller instruction, repeated across all eight books) and notes the item-3 wording.

The console ships in an in-store display mode where it stays powered unless the main power switch is off. To exit: press and hold **Stop, Enter and Display** for **5 seconds**; the display shows 'Display mode - On'; use the **Up arrow or Fast key** to change the setting to **Off**, then press **Enter**.
