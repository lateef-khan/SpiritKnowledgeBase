The Display Button is **to the left of the display**. The Message Window initially displays **Speed in MPH**, and each press shows the next reading:

1. Speed in MPH
2. Watts
3. METs
4. Segment Time
5. One more press sets **Scan** mode, where all of the information is displayed in turn for **4 seconds each**.

The Dot Matrix shows the **resistance profile** of the program and a **lap track that is a quarter of a mile long**.

**The quarter mile figure is printed only in this model year.** The 2011 manual for the same family describes the Enter key cycling three dot matrix views instead and gives no lap length.
