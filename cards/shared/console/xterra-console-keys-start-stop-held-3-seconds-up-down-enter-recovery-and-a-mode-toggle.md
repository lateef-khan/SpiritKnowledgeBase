| Key | As printed |
|---|---|
| START / STOP | 1. Starts and pauses workouts. 2. Starts body fat measurement. 3. **Holding the key 3 seconds resets all functions and values to zero** |
| DOWN | Decreases the value of the selected parameter (TIME, DISTANCE, ...); during the workout, decreases the resistance load |
| UP | Increases the value; during the workout, increases the resistance load |
| ENTER | Inputs the desired value or workout mode |
| RECOVERY | Enters the heart-rate Recovery function ([recovery card](xterra-console-recovery-score-1-to-6-only-with-a-heart-rate-value.md)) |
| MODE | **Switches the display from RPM to SPEED, ODO to DIST, WATT to CALORIES** |

The five books print this key list word for word (the RSX1500's 2017 printing too). The keypad: START/STOP, UP, DOWN, MODE on the top row, RECOVERY and ENTER below (the RSX1500 picture shows the audio port between those two). The readouts and their ranges are on [the readouts card](xterra-console-readouts-speed-to-99-9-time-to-99-59-and-an-audio-port-on-top.md); how many programs and levels the display holds differs - [24 and 24](xterra-console-24-programs-and-24-levels-in-8-bars-of-3.md) or [13 and 16](../../fs15-2019/console/13-programs-and-16-levels-in-8-bars-of-2.md).
