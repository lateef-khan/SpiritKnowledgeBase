**The Message Window initially displays Speed information.** Each time the **Enter** button is
pressed the next set of information appears. Press Enter during the Level and Watts display and the
**Scan light comes on**: the window shows each set for **four seconds** then switches to the next in
a continuous loop. Pressing Enter again brings you back to the beginning.

**The manual contradicts itself about how many sets there are.** It says "**four windows in all**"
and then lists only two:

> In order: Speed in RPM and MPH, Work Level and Watts.

**Both statements are printed as above and the manual never resolves the count.** Do not quote a
list of four for these two machines; only Speed in RPM and MPH and Work Level and Watts are named.

**The XE300 in the same manual really does have four**, and a separate **Display** button rather than
Enter, because it has the larger console:
`spirit-xe-console-display-button-steps-through-four-sets-of-readings`.

**This console also has no bar graph and no quarter mile track.** Its pulse has its own window rather
than a slot in the message window.
