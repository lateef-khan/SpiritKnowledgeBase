The console has built in maintenance/diagnostic software. It will, for example, change the console
settings from English to Metric and turn off the beeping of the speaker when a key is pressed.

**To enter: press and hold down the Start, Stop and Enter keys. Keep holding them for about 5
seconds** and the Message Center will display **Engineering Mode Menu**. Press **Enter** to access
the menu:

| Item | What it does |
|---|---|
| 1. Key Test | Will allow you to test all the keys to make sure they are functioning |
| 2. Display Test | Tests all the display functions |
| 3. Functions | Press Enter to access the settings |
| 4. Security | Allows the keypad to be locked so no unauthorized use of the machine is allowed |
| 5. Exit | |

**Item 4 is called Security here, not Child Lock.** On the 2023 XT consoles the same slot is called
**Child Lock** and it is unlocked a different way; see `xt-2023-console-engineering-mode-menu` and
`xt-2015-console-keypad-lock-security`.

**The scroll key inside Functions is not printed the same in every manual.** The XT185-2015 says
*"use the Speed Up and Down keys to scroll"*, the XT285-2015 says *"Speed Up or Down arrow"*, and
the XT385-2015, XT485-2015 and XT685-2015 all say *"Up arrow to scroll"*.

**All five manuals print a second, different way in.** In the note that follows the lubrication
procedure they say: *"press and hold down the Start, Stop and Enter keys, then at the same time
insert the safety key. Keep holding the keys down until the Message Center displays Engineering Mode
Menu."* That is the same three keys but with the safety key inserted rather than a 5 second hold.
The manuals never say which one applies when, so try the plain 5 second hold first and the safety
key version if it does not open.

**Calibration is not in this menu.** It has its own entry sequence, headed "Factory settings" - see
`xt-2023-console-calibration-basic` for the XT185 and XT285 and
`xt-2015-console-calibration-fast-plus` for the XT385, XT485 and XT685.
