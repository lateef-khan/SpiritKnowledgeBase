**To open it:** hold down **Start, Stop and Enter together for about 5 seconds**, until the display shows "Engineering Mode". Press **Enter** to open the menu. Use the **Level up / down** keys to move through it.

Depending on software version the menu may be called the Maintenance Menu.

| Item | What it does |
|---|---|
| A. KEY TEST | Tests every key. |
| B. UNIT MODE | English or Metric readings. |
| C. BRAKE TEST | Tests the EMS brake. |
| D. DISPLAY MODE | Off makes the console power down after 30 minutes of inactivity. |
| E. PAUSE MODE | On allows 5 minutes of pause. |
| F. KEY TONE | Key beep on or off. |
| G. CHILD LOCK | Locks the keypad against unauthorised use. |

These consoles have no ODO Reset, Motor Test or Factory Set item. Those belong to the nine-inch display bikes.

The manual's PAUSE MODE line is cut short: it reads "Turned on to allow 5 minutes of pause, turn off to have console." with no ending. The B94 and R92 manuals finish the same sentence as "turn off to have console pause indefinitely".
