Pressing **Stop** in Engineering Mode raises the prompt **'EXIT FACTORY MODE AND RETURN TO THE HOME PAGE'**: **YES** returns to the main workout home page, **NO** returns to the Maintenance menu page. Adjust with the arrow buttons, Enter to modify, Stop to exit.
