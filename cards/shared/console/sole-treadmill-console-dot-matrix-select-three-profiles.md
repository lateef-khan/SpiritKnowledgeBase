**Twenty rows of dots, 8 high** (the books write 'rows'), one per workout segment, showing approximate effort only. When the **Speed** indicator above the matrix is lit it shows the Speed profile; when **Incline** is lit it shows the Incline profile. Press **SELECT** to change views: scrolling through all three profiles (incline, speed, incline+speed) starts an automatic scroll showing each for five seconds.
