On first power-on the console runs an internal self-test:

1. All the lights turn on.
2. When the lights go off, the Message Window shows a software version (for example `VER 1.0`), and the **Distance** window shows an odometer reading.
3. The odometer reading is how many **virtual miles** the bike has gone. The Time window shows how many **hours** the bike has been used.
4. Both are displayed for only a few seconds.
5. The console then goes to the start-up display: the dot matrix scrolls the different workout profiles and the Message Window scrolls the start-up message.

**This manual prints no electrical rating and no socket location in its Power Up section.** It does not say the console powers up when mains is connected, it does not name a DC voltage or current, and it does not say where the line cord plugs in. Other model years in this family do print those figures, and they differ between years, so do not carry one over. Absence here is the manual's actual state, not an omission from this card.

The manual does carry an in-store display-mode warning right after this paragraph, which is a separate procedure.
