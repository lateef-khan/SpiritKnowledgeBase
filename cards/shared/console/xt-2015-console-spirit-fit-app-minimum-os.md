**Your device will need to be running on a minimum operating system of iOs 7 or Android 4.4 for the
Spirit Fit App to operate properly.**

"iOs 7" is printed exactly that way in all four manuals.

**These are not the Spirit+ figures.** The 2023 XT manuals require **iOS 13.1 or Android 8.0** for
the **Spirit+** App, a different app. See `xt-2023-console-spirit-plus-minimum-os`.

**The XE295-2021 (p. 32) and XG400-2021 (p. 31) ellipticals print the same footnote**, spelled
"iOs 7" the same way, so this card is no longer treadmill-only. The **XE395-2023 and XE795-2023**
ellipticals are Spirit+ machines and need **iOS 13.1 or Android 8.0**:
`xt-2023-console-spirit-plus-minimum-os`.

**The XT185-2015 owner's manual has no app section**, so it states no requirement at all.

**The XT485ENT prints the same two figures** on its p. 49, spelled "iOs 7" the same way, even though
it is a 2023 machine. Its sibling the XT685ENT is the Spirit+ machine and needs iOS 13.1 or Android
8.0 - see `xt-2023-console-spirit-plus-minimum-os`. **The two ENT treadmills do not run the same
app.**
