A new console **might** come configured in an in-store **display mode**, where the console stays powered on unless the main power switch is turned off. The manual says that if this is the case, follow this procedure to turn it off.

1. Press and hold the **Stop, Enter and Display** keys together for **five seconds**. The display shows `Display Mode - ON`.
2. Use the **Up key** to change the setting to `OFF`.
3. Press **Enter**.

**The key is named simply "the Up key" here.** The upright and recumbent manuals of the same year name the *speed* Up key and the 2015 manual names the Level Up key for the identical step. Use the wording printed for your own machine.

There is also a Display Mode item in the console's maintenance menu, which controls whether the console powers down after a period of inactivity. That is a different setting from this one.
