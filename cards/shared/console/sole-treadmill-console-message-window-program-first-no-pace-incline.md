**No Pace and no Incline entries**, unlike the 2016/2019 books. The Message Window first shows the program name. Each **Display** press steps on: **Program, Laps, Verticle** (the F63 books' spelling; the F65-2023 book spells it 'Vertical'), **Segment Time, Max Speed (in mph), and Data Scan mode**. In Data Scan mode the information changes every **4 seconds**.
