The computer console uses a **rechargeable battery**.

1. Take the console off the handlebar.
2. Charge it with a **micro USB cable** as soon as the battery icon appears.
3. While charging the battery icon flashes. The icon disappears when the console is fully charged.

The speed sensor transmitter is separate. It takes 2 AAA batteries.
