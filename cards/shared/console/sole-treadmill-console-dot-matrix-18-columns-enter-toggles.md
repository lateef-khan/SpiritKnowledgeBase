**Eighteen columns of dots, 8 high** – the narrowest matrix in the wave. The dots show approximate effort only. When **Speed** is lit above **or below** the matrix the Speed profile shows (the only book that prints 'or below'); when **Incline** is lit the Incline profile shows. Press **Enter** to swap; pressing it a **second** time switches back – no third-press auto-alternation is printed.
