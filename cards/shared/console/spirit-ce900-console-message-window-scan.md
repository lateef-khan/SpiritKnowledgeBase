The **Dot Matrix**, or Profile Window, displays the workout profile. The **Message Window** displays
the exercise data. There is also a **Strides Per Minute window** for pedal speed and a **Level
window indicating machine resistance**, a **Heart Rate data window and bar graph**, and a **lap
counter** for distance.

The Scan button to the left of the Message Window steps through two sets of readings:

| Press | The Message Window shows |
|---|---|
| Initially | **Watts, Time Elapsed, Calories, Distance** |
| Scan once | **METs, Time Remaining, Calories/Hour, Strides** (total stride count) |
| Scan again | **Scan mode**: each set for **four seconds**, then the next, in a continuous loop |
| Scan again | Back to the beginning |

Both CE900 manuals print this word for word.

**This is not the CE800 or CE850 set.** Those consoles start on Distance, Calories, Pulse and Time
Elapsed and scan to Speed, Watts, METs and Time Remaining:
`spirit-ce-console-led-data-windows-scan`.
