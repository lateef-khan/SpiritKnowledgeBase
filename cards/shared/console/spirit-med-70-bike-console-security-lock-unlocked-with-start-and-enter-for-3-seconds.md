**Security** is the fourth item of the maintenance menu
(`spirit-med-70-bike-console-maintenance-mode-with-a-sleep-switch-a-keypad-lock-and-factory-settings`).
The owner's manuals: **"Allows you to lock the keypad so no unauthorized use is allowed. When the keypad
is locked press the start and enter key for 3 seconds to unlock."** The service manuals call it a
**child lock** - "Enable or disable the child lock. When the lock was enabled, press the START and
ENTER key for 3 seconds to unlock."

**Nothing more is printed** - no password, no message the locked console shows, and no separate
locking gesture beyond selecting the item. The 7.0T treadmill uses the same Start and Enter release
(`70t-2026-console-child-lock`). This is a keypad lock, not the mileage lock with a four-digit code on
the ENT touchscreens (`spirit-ent-bike-console-security-mileage-lock-four-digit-password-and-2222`).
