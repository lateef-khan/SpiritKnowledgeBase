**On these two machines you type two digits and then press Enter.**

1. Press either the **Select Speed** or the **Select Incline** key.
2. **Select 2 digits.**
3. **Press Enter.** The treadmill adjusts to that value automatically, so you do not have to hold a
   key down until it reaches the value.

Values are entered in **0.1 mph increments for speed** and **0.5 level increments for incline**.

The manuals print these examples:

| Press | Result |
|---|---|
| Select Incline, then 1, 0 | Incline Level 1.0 |
| Select Incline, then 3, 5 | Incline Level 3.5 |
| Select Speed, then 8, 0 | 8.0 mph or KPH |
| Select Speed, then 0, 8 | 0.8 mph or KPH |

**For the highest value these keys will take, see
`xt-2015-specs-speed-and-incline-range-xt185-xt285`.** The figures are kept in that card so there is
one place to correct them.

**The XT385, XT485 and XT685 of the same year take two *or three* digits and their paragraph never
mentions pressing Enter** - see `xt-2015-console-select-keys-two-or-three-digits`. The **2023** XT
consoles have no Select key at all; they use direct preset buttons.

The XT285-2015 manual has a hole in this sentence: it reads *"quickly by using the on the con- sole"*,
with the words naming the keys missing from the converted text. The XT185-2015 manual prints
*"by using the select keys on the console"* in the same place.
