The E95S books calibrate **stride**, not incline (the heading reads 'Stride Calibration' though the first line keeps the boilerplate 'If there is a problem with the ,'). Press the **Stride Up key and the Start key together, hold 5 seconds, then press Start**; calibration runs automatically over a MAX/MIN STRIDE page. Exit by powering off and on. Not to be confused with the E95/E98 incline calibration (own card).
