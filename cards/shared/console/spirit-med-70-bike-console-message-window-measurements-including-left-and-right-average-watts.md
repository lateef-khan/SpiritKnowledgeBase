**"The Message Window is the main display for programming instructions and relevant measurements
during a program. The measurement data shown varies depending on the program."**

Measurements include, in the books' order:

- **Time** and **Segment time**
- **RPM**
- **Pulse**
- **Work level**
- **Watts** and **Average watts (left and right leg)**
- **METS**
- **Calories**
- **Symmetry**

**You step through them with the lower Display key** - call-out 4, *Change data display*, on the left
of the keypad: "During the manual program you will be able to scroll through the data in the message
window by pressing the display key." The heart rate program page calls it "the adjacent Display key"
to tell it from the graphic key beside the dot matrix
(`spirit-med-70-bike-console-display-key-cycles-a-profile-a-power-graph-and-a-track`).

**Left and right watts are shown separately** - the overview drawing's sample reads `AVG WATTS L 0 R
30` - and the Symmetry Index is read here too: "To view the Symmetry Index number, press the Display
key located under the message window." The specification page lists the readouts as "Time and Segment
time remaining, RPM, Watts (Left and Right), METS, Symmetry Index, Heart Rate, Calories, Work Level".

**No scan interval is printed for this key.** The 4.0 series states four seconds per set; these books
say only "scroll". The 7.0T treadmill lists seven measurements for the same window
(`70t-2026-console-message-window-measurements`) and the rehabilitation steppers the same per-leg
watts (`spirit-rehab-stepper-console-message-window-shows-average-watts-per-leg-mets-and-symmetry`).
