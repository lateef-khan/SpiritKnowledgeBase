This console has **one Display button beside the dot matrix and another below the Message Window**,
and they do different jobs.

**Beside the dot matrix - what the Profile Window shows.** It has two display modes. A program
starts in **Profile** mode. Press once for a **quarter mile track**. Press again and the dot matrix
**switches back and forth between Track and Profile every few seconds**. Press again to turn that
scan off and return to Profile.

**Below the Message Window - which readings appear.** Each press brings up the next set, **four
windows in all**, in this order:

1. **Time and Distance**
2. **Pulse and Kcal (Calories)**
3. **Speed in RPM and MPH**
4. **Work Level and Watts**
5. then **METs**

Press Display while METs is showing and the **Scan light comes on**: the Message Window shows each
set for **four seconds** then switches to the next, in a continuous loop. Press again to go back to
the beginning.

**The manual lists five stops but calls it "four windows in all".** Both statements are printed as
above and neither manual resolves the count.

The later CE800, CE850, CE900 and CES880 consoles replaced this button with a **Scan** button and a
fixed pair of data sets; see `spirit-ce-console-led-data-windows-scan`.
