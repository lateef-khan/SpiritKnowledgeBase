Power the treadmill on with the switch at the front below the motor hood; the safety key must be installed or the treadmill will not power on.

When the power is turned on:

1. A message scrolls across the dot matrix showing the current **software version**.
2. The **Time** and **Distance** windows then show the **odometer readings** for a short time: the Time window shows how many **hours** the treadmill has been in use, and the Distance window how many **miles** (or kilometers, if the treadmill is set to metric) it has gone.
3. The treadmill enters idle mode, the starting point for operation.

This is the only odometer readout the two owner's manuals print. The engineering mode for these machines lists Sleep Mode, Lube Reset and Child Lock but no odometer reset ([engineering mode card](xterra-trx-console-engineering-mode-program-and-speed-keys-sleep-lube-child-lock.md)).
