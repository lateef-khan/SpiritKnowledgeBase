Your new console comes configured in an in-store **Display Mode**, in which the console remains powered on unless the main power switch is turned off.

To exit display mode for normal operation:

1. Press and hold the **Stop**, **Enter** and **Display** keys for **5 seconds**. The display shows "Display mode - On".
2. Use the Incline ▲/▼ or Speed ▲/▼ key to change the setting to **Off**, then press **Enter**.

After that the display sleeps after 30 minutes without a key press ([sleep card](xterra-treadmill-console-display-sleeps-after-30-minutes.md)). This is a different key combination from the engineering mode on the same console ([engineering card](xterra-tr-console-engineering-mode-start-and-speed-up-wheel-63.md)).
