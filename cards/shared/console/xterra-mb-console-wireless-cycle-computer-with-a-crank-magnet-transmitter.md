The console carton holds a **computer console and a speed sensor transmitter**. The transmitter counts the times the magnet mounted on the crank assembly passes the sensor and sends a coded signal to the console with the measured value (speed and cadence). The transmitter is loaded with batteries, plugged into the sensor cable already on the unit and taped to the frame; the console twists clockwise into a mount wire-tied to the front of the handlebar - "replace console battery if no digits are shown on LCD". The feature list calls the batteries "user changeable (sensor and receiver)"; no battery type is printed.

**Please note (as printed):**
1. The console is designed as a **sealed unit** and is not meant to be opened other than to install batteries. Any opened unit voids the warranty.
2. Clean it with a clean damp cloth; caustic cleaning solutions void the warranty.
3. It is **NOT waterproof, only water resistant**; excessive exposure to water voids the warranty.

**Display callouts:** A average-speed symbol (an arrow when the current speed is above or below the average), B current speed, C speed scale (km/h or mile/h), D PM indicator, E sub display, F mode symbol, G gender male, H gender female, I SCAN, J 2 users / wheel size setting. The feature list: time of day, stopwatch, trip distance, current, average and maximum speed, miles or kilometres, auto timer, odometer, motion activity display, 2 users / wheel size, user settings, exercise time and cumulative calories.
