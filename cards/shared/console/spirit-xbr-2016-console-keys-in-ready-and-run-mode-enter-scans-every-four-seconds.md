**READY MODE** (before Start):

| Key | What it does |
|---|---|
| STOP | Non-function |
| START | Starts the bike, which starts at **MIN LEVEL**; the XBR55 and XBU55 books add "In MANUAL" |
| LEVEL UP / DOWN | Non-functional until a setting has been entered |
| FAN | Fan on or off |
| ENTER | Enters parameter setting, and confirms or modifies each setting. The spec adds "confirm the every setting by pressing START key no pressing ENTER key" - Start accepts the settings and begins |

**RUN MODE** (during a workout):

| Key | What it does |
|---|---|
| STOP | Stops the bike |
| START | Non-functional |
| ENTER (as a control) | Non-functional - so printed in three books; the XBR95 book omits the line |
| LEVEL UP / DOWN | Raises or lowers the level by 1 |
| FAN | Fan on or off |
| ENTER (as the scan key) | Switches the exercise data. If the display already shows the latest data, pressing it lights the **SCAN ICON** in the message window and the display cycles automatically **every four seconds** through: `SPEED XX.X MPH`, `WATT XXX`, `LAPS XX`, `TIME XX:XX`, `MAX LV XX` (only in a program) |

**Three printings differ in one line each.** The XBU55-2016 book says Start gives "3 second final
count down on window display, then machine starts running" - a treadmill sentence in a bike book; the
other three do not print it. The XBR25-2016 book prints the speed string as `SPEED XX.XKPH`; the
other three print MPH. Otherwise the four are word for word.

**The button pages name the console's keys as FAN, START, LEVEL, STOP and ENTER** and describe the
Fan Key as "Cooling fan switch on or off" (`spirit-xbr-2016-console-face-7-5-inch-lcd-with-6-10-or-11-program-buttons`).

**The owner's manuals for the 2019 and 2021 successors describe none of this**, so a later machine
is not covered here. The CU800-2012 prints a similar chapter with a DISPLAY key in place of Enter and
a different scan list (`cu800-2012-console-keys-in-ready-and-run-mode-and-the-display-key-data-scan`).
