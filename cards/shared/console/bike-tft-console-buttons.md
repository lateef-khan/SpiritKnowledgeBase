**Program buttons:** Manual, Hill, Fat Burn, Strength, Interval, Custom, Fit-test, 2HR.
**Fan key:** switches the cooling fan on or off.

**READY MODE**

| Button | Action |
|---|---|
| STOP | No function. |
| START | Starts the bike. A 3 second count-down runs on the window display first. In MANUAL the bike starts at MIN LEVEL. |
| LEVEL UP / LEVEL DOWN | No function until the user enters a setting. |
| FAN | Fan on or off. |
| DISPLAY | No function until the user enters a setting. |
| ENTER | Enters parameter setting and confirms each setting or a changed parameter. In a workout, ENTER changes the profile shown: LEVEL PROFILE, then INCLINE PROFILE, then SCAN. In SCAN the display swaps between LEVEL PROFILE and INCLINE PROFILE every 3 seconds. |

**RUN MODE**

| Button | Action |
|---|---|
| STOP | Stops the bike. |
| START | No function. |
| ENTER | No function. |
| LEVEL UP / LEVEL DOWN | Each press changes the level by 1. |
| FAN | Fan on or off. |
| DISPLAY | Shows the exercise data for 5 seconds during a workout. |

The INCLINE PROFILE entry is carried over from a treadmill console. These bikes do not incline.
