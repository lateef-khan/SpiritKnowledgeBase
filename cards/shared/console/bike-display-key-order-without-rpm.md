The Message Window initially displays **Laps** completed. Each press of the **Display** button shows the next set of information, in this order:

1. Laps
2. Speed (in mph)
3. Level
4. Watts
5. Segment Time
6. Data Scan mode

In **Data Scan** mode the displayed information changes every **4 seconds** in the Message Window.

**There is no RPM in this list.** The 2016 and later manuals for the same console shape insert **RPM** between Speed and Level. If a customer expects a cadence readout on the Display key and this is their machine, the manual does not promise one.
