Your machine is equipped with a **child lock feature which disables the buttons on the console** to
prevent unauthorized use.

- **To turn it on, press Child Lock.** The **LED will light up**. The treadmill is then in idle mode
  and cannot be operated.
- **To unlock, hold Child Lock for 3 seconds.** **After the LED light turns off, press START to
  operate.**

This is a dedicated Child Lock button on the console, not a setting hidden in an engineering menu.

**The XT685ENT prints this word for word** on its p. 23. **The XT485ENT manual
describes no child lock at all.**

**The service manuals add two things the owner's manuals do not: the lock switches itself on after
five minutes idle, and the message the console shows.** Their Child Lock Key entry, printed
identically in the XT185, XT285, XT385, XT485 and XT685 2023 books and in the XT685ENT book: *"When
this in ENGINEERING MODE setting lock key ON that all keyboard button no working, then MW will show
the 'HOLD CHILD LOCK BUTTON 3 SECONDS TO UNLOCK'. (On the IDLE MODE does not work after 5 minutes of
detection, the locked will ON.) if lock key off at ENGINEERING MODE setting, that unit keyboard can
working."* So: the lock is armed from the engineering-mode Security entry, **a console left idle for
5 minutes locks itself**, and the message window then says to hold the Child Lock button 3 seconds.

**The service manuals' menu says the unlock key is Start and Enter**, not Child Lock
(`xt-2023-console-engineering-mode-menu`); the key table above and this owner's-manual paragraph say
Child Lock. Try both.

**The XT485ENT service manual's Settings screenshot does show a Child Lock item**, between Date Time
and Units (`xt485ent-2023-console-calibration-behind-the-software-version-and-password-20160620`),
although neither its owner's manual nor its key tables describe one.
