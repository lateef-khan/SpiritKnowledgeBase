When power is connected the console powers up automatically. There is no separate on switch.

These models operate on **12V/3.3A DC**, supplied by the power pack connected to **115 VAC**. The power socket is where the line cord plugs into the unit, on the front of the bike.

On first power-on the console performs an internal self-test:

1. All the lights turn on.
2. When the lights go off, the Message Window shows a software version (for example `VER 1.0`), and the Distance window shows an odometer reading.
3. The odometer reading is how many **virtual miles** the fitness bike has gone. The Time window shows how many **hours** the fitness bike has been used.
4. Both are displayed for only a few seconds.
5. The console then goes to the startup display: the dot matrix scrolls the different workout profiles and the Message Window scrolls the start-up message.

The odometer can be reset to zero from the maintenance menu.
