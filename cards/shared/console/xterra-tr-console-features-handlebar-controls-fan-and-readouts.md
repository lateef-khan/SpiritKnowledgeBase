- **Handlebar speed and incline controls.** The treadmill lets you make speed and incline changes on the side handrails.
- **Built-in fan.** Press the Fan key on the left side of the console to turn it on.
- **Console readouts.** The console displays Pace, Calories burned, Time (elapsed or countdown), Distance traveled, Pulse, Speed, Incline, Program Name, the number of Laps completed and Segment Time, plus a Speed & Incline profile graph that shows how hard you have worked and how challenging the upcoming segments will be. The LCD drawing labels CALORIES, HEART RATE, DISTANCE, LAPS and PACE windows across the top, INCLINE, TIME and SPEED in the middle, a dot matrix with speaker, heart and Bluetooth SYNC icons, a heart-rate percentage dial, and a message line.
- **Enter / Program keys.** Press Enter/Program to enter program mode and use Speed Up/Down to preview what each program profile looks like; press Enter/Program again to select the program and enter the data-setting mode.
- **Incline.** Adjustable any time after belt movement with the Incline Up/Down keys or the Direct Incline key then a number. The display shows the incline percent in increments of **0.5** as adjustments are made, and the incline returns to zero unless the main power switch or safety key was turned off while it was at a higher setting.

The console overview names the LCD window, the safety key, the Program button, an accessory holder, direct incline buttons (left) and direct speed buttons (right). The dot matrix and quarter-mile track have their own card ([dot matrix card](xterra-tr-console-dot-matrix-20-by-10-and-the-quarter-mile-track.md)), as do the pulse grips ([pulse card](xterra-tr-console-pulse-grips-or-a-chest-strap-but-not-during-heart-rate-programs.md)).
