**The dot matrix has two display modes and a scan.** To the left of the dot matrix is a button
labelled **Display**.

1. A program begins in **Profile** display mode.
2. **Press Display once** and the display switches to a **quarter mile track**.
3. **Press Display again** and the **Track indicator light beside the button starts to blink**. That
   is **Scan mode**: the display switches back and forth between Track and Profile **every few
   seconds**.
4. **Press Display again** to turn scan off and return to Profile.

**This is the button beside the dot matrix, not the one below the message window.** The other Display
button changes which readings appear: `spirit-xe-console-display-button-steps-through-four-sets-of-readings`.

**The XE350 has no such button and cannot be switched.** Its manual states plainly that **the XE350
shows the dot matrix and track at the same time**:
`xe350-2005-console-shows-the-dot-matrix-and-track-together`.

**The XE100 and XE200 have neither.** Nothing in their console section mentions a track or a Display
button.
