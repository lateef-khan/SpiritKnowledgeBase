| Function | Range as printed |
|---|---|
| AUTO SCAN | Every 6 seconds |
| TIME | 0:00 ~ 99:59 |
| SPEED | 0.0 ~ 999.9 KM/H (MILE/H) |
| DISTANCE | 0.00 ~ 999.9 KM (MILE) |
| CALORIES | 0.0 ~ 999.9 CAL |
| ODOMETER | 0.0 ~ 9999 KM (MILE) |
| PULSE | 40 ~ 240 BPM |

Battery type 2 AAA or UM 4; operating temperature 0 to +40 C (32-104 F); storage -10 to +60 C (14-140 F).

**Buttons.** **MODE** - push to select functions. **SET** - sets a target for time, distance, calories and hand pulse. **RESET** - resets time, distance, calories and hand pulse.

**Functions.** SCAN: press MODE until SCAN appears; the monitor rotates through time, speed, distance, calorie, odometer and pulse, 6 seconds each. TIME, DISTANCE and CALORIE: press MODE until the name appears, then SET to set the target (distance counts to a maximum of 999.99 miles - the functions text says 999.99 where the table says 999.9; the card keeps both). PULSE RATE: press MODE until PULSE appears, SET to set a target heart rate anywhere from 40 to 240 BPM, then hold both contact pads ([pulse card](xterra-console-hand-pulse-reads-after-6-to-7-seconds-and-runs-high-at-first.md)). A faint or blank display means replace the batteries ([battery card](xterra-console-two-aaa-um4-batteries-and-a-faint-display.md)); the monitor shuts off after 4 minutes without a signal ([auto-off card](xterra-console-battery-console-wakes-on-pedalling-and-sleeps-after-4-minutes.md)).

The parts lists name the console **X3529** on both bikes. The FB180 console is the same layout with a speed window to 99.9 and a SET key that does not set pulse ([card](../../fb180-2025/console/mode-set-and-reset-keys-with-speed-to-99-9-and-a-phone-ledge.md)).
