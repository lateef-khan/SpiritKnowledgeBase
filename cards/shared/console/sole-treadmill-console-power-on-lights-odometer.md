Plug into a wall outlet, switch on the front power switch below the motor hood, and fit the safety key – the machine will not power on without it. **All the lights on the display light for a short time** (no software-version scroll on these books); then the Time and Distance windows show odometer readings (hours used, miles – or kilometres if set to metric; TT8 books add 'see maintenance for changing settings' and repeat the software version as a message); then the machine enters **idle mode**.
