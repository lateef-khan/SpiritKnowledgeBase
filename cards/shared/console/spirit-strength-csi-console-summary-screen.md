> When the program is ended, the Summary Screen displays and provides summary data from the exercise
> including Average Milliseconds, Total Time, Total lb, Total KCAL, Repetitions, Average Watts.

## The six figures

| Figure | What the manual says it is |
|---|---|
| **Avg m/s** | *provides possible benefit with athletic performance or physical therapy measures and may not be relevant to most users* |
| **Total Time** | the cumulative time counting upwards |
| **Total lb** | the cumulative resistance lifted during the entire set |
| **Total KCAL** | the cumulative kcals for the entire set |
| **Reps** | the cumulative repetitions for the set; **resets to zero with each set** |
| **Avg watts** | listed among the summary data, and **the manual defines it nowhere** |

Average Watts is the one figure the Summary Screen adds over the Progress Screen. It is the only one
of the six with no definition printed anywhere in the book.

## Leaving the screen

**End Session** ends the session, **Repeat Set** starts another set with every measurement reset to
zero, and the three other mode tiles along the bottom edge switch mode - see
`spirit-strength-programs-four-i-strength-training-modes`.

The screen header carries an **AUTO EXIT IN** countdown; the session ends itself if it runs out. See
`spirit-strength-csi-console-auto-exit-two-minutes`.

There is **no** workout total across sets, **no** printed or emailed summary, and **no** statement
that anything is saved once End Session is pressed.
