The Message Window starts on elapsed Time, Program Name and Distance (miles). Each Display press moves one set on: Speed (mph), RPM and Watts (100 watts lights a 100-watt bulb); then Calories, Level (1-20) and Pulse; then the Incline level, then scan mode, where the information changes every 4 seconds. The E35 shows its incline profile when Display is pressed.
