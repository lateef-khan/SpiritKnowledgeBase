**This card is what a 37-second video shows on the console; the key sequence that opens the menu is
not on it.** A hand covers the keypad while the idle message scrolls, and the next frame is already
in engineering mode. **The entry keys come from the books**: Start, Stop and Enter held about five
seconds (`spirit-xe-console-engineering-mode-with-an-lcd-test-and-a-safety-item`).

| Time | What the message window reads |
|---|---|
| 0-8 s | Idle: 0000 / 00:00 / 00000 / 00000, the profile bar graph, and the scrolling "…OR QUICK START OR PROGRAM BUTTON FOR SETUP" |
| 8-12 s | The windows blank; **EM** on the top line, **ENGINEERING MODE** then **MENU PRESS** scrolling below |
| 12-14 s | **LCD TEST** |
| 14-16 s | **EXIT** |
| 16-18 s | a lone **0** at the right, then **DISPLAY MODE** scrolling |
| 18-20 s | **ODO** over **ODO RESET** |
| 20-26 s | the odometer value **0:15** in the time window, **ODO RESET** below; a hand reaches to the keys |
| 26-28 s | **RST** over **ODO RESET**; the time window reads **0:00** - the odometer has been reset |
| 28-32 s | **FUNCTIONS** scrolling |
| 32-37 s | the full-segment test (88:88, 88888, every LED lit), then the idle screen |

**What this adds to the printed menu.** The books list Key Test, LCD Test, Functions (Display Mode,
Pause Mode, ODO Reset, Units, Beep, Motor Test, Safety) and Security, and say of ODO Reset only
"resets the odometer". The video shows **the odometer displayed in the time window while ODO RESET is
selected, and RST as the confirmation** after which it reads 0:00. The **0:15** on this console is
fifteen hours.

**An EXIT item is on the screen and in no printed menu.** Neither XS895 owner's manual nor the
XS300B-YS006 service manual lists an Exit; the video shows one between LCD TEST and DISPLAY MODE.
The order of appearance - LCD TEST, EXIT, DISPLAY MODE, ODO RESET, FUNCTIONS - is the order the
technician scrolled, not necessarily the menu's own, and the Key Test, Units, Beep, Motor Test,
Safety and Security items are never on screen.

**The keypad on the video reads INTERVAL, USER 1, USER 2 and HR 1** among its program keys, where
the service manual's Function Button Locations legend prints **HIIT, 2User, 2HR**. Same keys, two
spellings; the printed drawing is the owner's-manual face
(`spirit-xe-console-face-call-outs-muscle-profile-heart-rate-profile-and-speakers`).

**Authority 2.** The audio track was not transcribed and the frames were read by eye; the figures
here are what the screen showed, not what a manual states. Where the video and the books differ, say
so to the caller rather than choosing.
