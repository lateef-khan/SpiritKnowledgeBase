"Eighteen rows of dots (8 high)" indicate each segment of a workout — the book's phrasing for an 18-column, 8-row matrix. The dots only show an approximate level of speed or incline effort, not a specific value, and in operation the Speed / Incline dot matrix builds a profile "picture" as values change.

Press the **PROGRAM** button to change the view: it switches among the **incline**, **speed** and **1/4-mile track** images.

**1/4 Mile Track.** The track is displayed around the dot matrix window; pressing PROGRAM switches to the 1/4-mile track "in mile". The flashing dot indicates your progress, and once the 1/4 mile is complete the feature begins again. These books print no laps window.

On the TR6.6 and TR6.4 the same job is done by a separate Display key ([card](xterra-tr-console-dot-matrix-18-by-8-and-the-display-key.md)). The TRX2500 book prints no dot matrix section at all.
