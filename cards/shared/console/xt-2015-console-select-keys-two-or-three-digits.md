**On these three machines you type two *or three* digits, and the paragraph never mentions pressing
Enter.**

1. Press either the **Select Speed** or the **Select Incline** key.
2. **Select either 2, or 3 digits.** The treadmill adjusts to that value automatically, so you do
   not have to hold a key down until it reaches the value.

The manuals print these examples:

| Press | Result |
|---|---|
| Select Incline, then 1, 0 | Incline Level 1.0 |
| Select Incline, then 3, 5 | Incline Level 3.5 |
| Select Speed, then 8, 0 | 8.0 mph or kmph |
| Select Speed, then 0, 8 | 0.8 mph or kmph |

**Only the XT385-2015 manual states the increments** - 0.1 mph for speed and 0.5 for incline level.
The XT485-2015 and XT685-2015 manuals print no increment sentence at all.

**For the highest value these keys will take, see `xt385-2015-speed-and-incline-range` and
`xt-2015-specs-speed-and-incline-range-xt485-xt685`.** Those three machines do not all print the
same maximum, which is why the figures live in two cards and not here.

**The XT185-2015 and XT285-2015 take two digits and then Enter** - see
`xt-2015-console-select-keys-two-digits`. The **2023** XT consoles have no Select key at all; they
use direct preset buttons.
