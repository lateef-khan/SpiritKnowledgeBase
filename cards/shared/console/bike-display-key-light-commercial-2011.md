The Display Button is **to the left of the display**. The Message Window initially displays **Speed in MPH**, and each press shows the next reading:

1. Speed in MPH
2. Watts
3. METs
4. Segment Time
5. One more press sets **Scan** mode, where all of the information is displayed in turn for **4 seconds each**.

**The Enter button changes the dot matrix view during a program.** Pressing it cycles the Dot Matrix profile views — Resistance and Laps. After scrolling through the two profiles and Laps, the Dot Matrix scrolls the three displays automatically, showing each for **4 seconds**. The icon for each view lights while that view is displayed.

The 2013 console of the same family drops the Enter-key view cycling and fixes the Dot Matrix on the resistance profile and a lap track.
