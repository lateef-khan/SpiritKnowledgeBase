After power-up or reset, Up/Down highlights the Program icon and Enter enters program mode: the display shows **P1 for two seconds**, then its profile; keep pressing Up/Down through **12 programs**. Enter selects; Start begins with defaults or each window (Time, Distance, Calorie, Pulse) customises in turn - Up grows the profile, Enter confirms, and Start at any point begins with the rest counting up. A **Pulse number sets an alarm that beeps at the target heart rate**. At the end: beeps; Start restarts, Reset returns to start-up. Program detail itself is programs' territory.
