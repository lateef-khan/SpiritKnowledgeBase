The Message Window initially displays **Laps** completed. Each press of the **Display** button shows the next set of information, in this order:

1. Laps
2. Speed
3. RPM
4. Level
5. Watts
6. Segment Time
7. Data Scan mode

In **Data Scan** mode the displayed information changes every **4 seconds**.
