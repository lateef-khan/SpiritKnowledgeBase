**Program buttons:** Manual, Hill, Fat Burn, Cardio, Interval, User 1 & 2, HR1 & 2.
**Fan key:** switches the cooling fan on or off.

**READY MODE**

| Button | Action |
|---|---|
| STOP | No function. |
| START | Starts the bike. A 3 second count-down runs on the window display first. In MANUAL the bike starts at MIN LEVEL. |
| LEVEL UP / LEVEL DOWN | No function until the user enters a setting. |
| FAN | Fan on or off. |
| ENTER | Enters parameter setting and confirms each setting or a changed parameter. |

**RUN MODE**

| Button | Action |
|---|---|
| STOP | Stops the bike. |
| START | No function. |
| ENTER | No function. |
| LEVEL UP / LEVEL DOWN | Each press changes the level by 1. |
| FAN | Fan on or off. |

**During a workout**, pressing ENTER switches the exercise data shown. If the latest data is already showing, ENTER lights the SCAN icon and the display then cycles every four seconds through: LAPS XX, SPEED XX.X MPH, L XX MAX LV XX (program mode only), WATT XXX.X, SEG TIME XX:XX.

The manuals list this behaviour twice, once under "ENTER button: non-functional" and once under "DISPLAY KEY" as an ENTER press. Take the DISPLAY KEY entry as the working description.
