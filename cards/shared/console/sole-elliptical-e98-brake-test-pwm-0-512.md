Select **BRAKE TEST** in Engineering Mode and press Enter; the screen shows BRAKE TEST with **L1 PWM xxx**. Press Enter into L1, adjust the value with **Level Up/Down**, Enter to confirm, and repeat through **L20**, when the test completes back to the menu. A greater PWM value means greater output; range **0-512**. Stop ends the test (Stop/Enter/arrow convention on the page). Read from the render: this page is a stencil image in the owner's book.
