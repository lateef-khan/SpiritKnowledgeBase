> For each i-Strength machine, the Home Screen is the place you will start from.

## What the Home Screen holds

- **Welcome**, with the machine's own exercise named beside it - *Chest Press* on the CSI-CPSP.
- **Strength Test** - the test that recommends a working resistance. See
  `spirit-strength-programs-strength-test-and-three-workout-goals`.
- **How To Use** - captioned on the button *Learn how to exercise on this device*. It opens the
  on-screen exercise instruction; what that screen holds is
  `spirit-strength-programs-how-to-use-lives-on-the-console`.
- **Four training-mode tiles** along the bottom - Pure, Eccentric, Isokinetic and Elastic Band -
  each with a one-line description under it. What the four modes do is
  `spirit-strength-programs-four-i-strength-training-modes`.
- The **time** in the top right, with the **gear symbol** beside it that opens Settings. A separate
  **System Settings** button, which the manual places *at the top right of the console*, is what
  leads to the network pages.

Selecting a tile opens that mode's **Setup Screen**. The console returns to the Home Screen after a
restart, and Settings' **Done** button returns to it too. **Home** is also a button in the top left
of the mode screens.

**The console is a touchscreen throughout** - the manual's every instruction is *select*, *press* or
*use a finger to slide*. There is no key strip, no dial and no membrane button described anywhere in
the book.

**No console at all on any other Spirit strength machine.** The CSS and CSD stations get a two-window
battery rep counter; the CSF and ST800 units get nothing.
