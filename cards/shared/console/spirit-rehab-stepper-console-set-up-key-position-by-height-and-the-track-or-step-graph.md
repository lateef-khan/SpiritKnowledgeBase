**Press the Set Up key and the first option in the menu appears.** Use the **up/down arrows**
to scroll through the menu and **enter** to select an option.

**The set up menu has two items and no more.**

**1. Position (seat and arm position setting).** The user enters **their height in inches** - or in
**centimetres if the machine is set to metric measurements** - and **the software calculates the
position for the seat and arms**. *"This feature is intended to aid in patient set up but may not be
the final settings as patient's body symmetry may vary slightly."*

**2. Track or step graph.** The **segmented track surrounding the profile display area** can be set
to display **as a track** or **as a foot position indicator**. **During any program, press the
Symmetry key to switch the display.**

**The metric cross-reference is broken in the two 2025 books.** The MS300-2021 sends you to
**"see page 57"**, which is where its maintenance menu and its Units entry really are. The 7.0S-2025
and 7.5S-2025 print **"see page Maintenance"** - the page number was never filled in. Their menu is
on printed p. 39 (7.0S) and p. 41 (7.5S):
`spirit-rehab-stepper-console-maintenance-menu-with-a-five-window-sensor-test`.

**The MS300-2021 page hides half of this text from `pdftotext`.** Printed p. 22 extracts 202 words
and renders 240; the sentences about patient body symmetry and about the segmented track are behind a
flat image and come back only from a 300 dpi render. **Read the render, not the extraction, on that
page.**

**The Position setting does not move anything by itself.** Nothing on the page says the seat or the
arms are powered - the console calculates a number for a person to set by hand.
