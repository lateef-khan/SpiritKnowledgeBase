1. **Press and hold the START, ENTER and STOP buttons until the display beeps.**
2. **"ENGINEERING MODE"** scrolls across the screen; press **ENTER**.
3. Press **UP** or **DOWN** to scroll through the sub-menus, **ENTER** to open one, **STOP** to exit
   Engineering Mode.

| Sub-menu | What it does |
|---|---|
| **Key Test** | Press ENTER, then press all buttons on the console |
| **Display Test** | Press ENTER; the console tests each segment or LED. Look for any burned out or not working |
| **Functions** | The settings below |
| **Security** | **Child Lock On/Off** - press ENTER to turn on or off |
| **Factory Set** | Press ENTER to go back to original factory settings. **This will reset saved user programs** |
| **Exit** | Press ENTER to exit Engineering Mode |

**Inside Functions, in the printed order**, each toggled or run with ENTER:

1. **Sleep Mode On/Off**
2. **Pause Mode On/Off**
3. **Odometer Reset**
4. **Units English/Metric**
5. **Beep Sound On/Off**
6. **Brake Test** - press ENTER to begin the test
7. **Bike or Elliptical** - press ENTER to switch from one to the other
8. **Exit** - leaves the Functions menu

**No timing is printed for the hold, and no minutes for Sleep Mode.** The book says only "until
display beeps"; every later Spirit bike menu holds the same three keys for about 5 seconds. Neither
a sleep timeout nor a pause length is given.

**Factory Set is what makes this menu different.** No later XBR or XBU menu has one; the 2016
service books and the 2019 owner's manuals go Key Test, LCD Test, Functions, Security
(`spirit-xbr-2016-console-maintenance-menu-20-minute-sleep-described-motor-test-and-safety`,
`spirit-xe-console-engineering-mode-with-an-lcd-test-and-a-safety-item`). The 2007 XE ellipticals
have a Motor test where this menu has a Brake Test
(`spirit-xe-console-maintenance-menu-with-a-motor-test-and-security`).

**Bike or Elliptical is the setting that must be right on these bikes.** The book does not say what
goes wrong if it is set to Elliptical.

**This is a Spirit Manufacturing dealer manual**, one book for both models; nothing on this page
distinguishes the XBR25 from the XBR55, and the same procedure is printed once for both.
