If there is a problem with the step height, run the calibration: press the **Step-height up key and the Start key at the same time and hold for 5 seconds**. The calibration starts and runs automatically. If the problem persists, contact the Sole service department.

The book names a Step-height up/down key pair for this and for navigating the maintenance menu; the console face verified on the render labels that rocker **LEVEL**. Press the up side of the LEVEL rocker with Start.
