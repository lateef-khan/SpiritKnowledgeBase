**Both the 2025 Spirit Medical books and the Dyaco PT books draw the same console.** The owner's manual
labels six things - **Message Window, Dot Matrix Window, Fan, Resistance Keys, Program Keys, Function
Keys** - and the service manual numbers the same six, calling the resistance keys **"Resistance level or
adjustment up / down keys"**. The PT edition uses the service manual's wording.

**What the drawing shows beyond its labels** (read from a render; the text layer holds only the six
labels):

| Area | On the face |
|---|---|
| Message Window | One text window with **two rows of legends**: **Distance, Calories, Pulse, Time** above it and **Speed, Cal/hr, Watts, METs** below it, each row with an indicator dot |
| Dot Matrix Window | The profile display in the middle |
| **RPM** and **Level** | Two small numeric windows under the dot matrix |
| Fan | The grille under the display |
| Level **+ / -** | Two rocker keys, one at each end of the keypad |
| Program keys | **Fitness, VO2, METs, HR, HR auto pilot** under a "Program" heading |
| Function keys | **Display (Scroll), Fan, Start, Stop, Confirm** |

**The confirm key is the enter key.** Every procedure in these books says "press the confirm key"
where other Spirit consoles say Enter; only the VO2 and heart-rate program pages slip back to "press
enter" and "Up and Down keys". There is no numeric keypad, no Set Up key and no Enter key on this face.

**The console includes a built-in fan** - the Fan key is one of the five function keys. Nothing in
either book gives it speeds.

**The service manual drawing colours the function keys** - Display and Fan blue, Start green, Stop red,
Confirm blue - which the owner's manual drawing does not show.

The Level windows read the resistance level, of which there are 40 (`spirit-ce-console-quick-start-time-counts-up`).
The 7.0 series console is a different face with ten numbered program keys
(`spirit-med-70-bike-console-face-ten-numbered-program-keys-two-display-keys-and-a-set-up-key`).
