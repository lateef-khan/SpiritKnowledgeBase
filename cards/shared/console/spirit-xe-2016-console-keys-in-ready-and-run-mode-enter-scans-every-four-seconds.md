**READY MODE** (before Start):

| Key | What it does |
|---|---|
| STOP | Non-function |
| START | Starts the elliptical: "there will be 3 second final count down on window display, then machine starts running. In MANUAL, elliptical starts at MIN LEVEL" |
| LEVEL UP / DOWN | Non-functional until a setting has been entered |
| INCLINE UP / DOWN | Non-functional until a setting has been entered - **printed in the XE195, XE295 and XG400 books, which have no incline; the XE795 book omits the two lines** |
| FAN | Fan on or off |
| ENTER | Enters parameter setting, and confirms or modifies each setting. The spec adds "confirm the every setting by pressing START key no pressing ENTER key" - Start accepts the settings and begins |

**RUN MODE** (during a workout):

| Key | What it does |
|---|---|
| STOP | Stops the elliptical |
| START, ENTER (as a control) | Non-functional |
| LEVEL UP / DOWN | Raises or lowers the level by 1 |
| FAN | Fan on or off |
| ENTER (as the scan key) | Switches the exercise data. If the display already shows the latest data, pressing it lights the **SCAN ICON** in the message window and the display cycles automatically **every four seconds** through: `SPEED XX.X`, `WATT XXX`, `LAPS XX`, `TIME XX:XX`, `MAX LV XX` (only in a program) |

**Two books print the speed in KPH, two in MPH.** The XE195-2016 and XE295-2016 print `SPEED
XX.XKPH`; the XE795-2016 and XG400-2016 print `SPEED XX.XMPH`. Their function tables all say "mile
per hour". Otherwise the four are word for word.

**No Incline row in Run mode and no ALT in the scan.** The three 2016 books with a powered stride or
ramp - the CE850, XE395 and XE895 - add both
(`spirit-ce850-2016-console-keys-in-ready-and-run-mode-incline-half-steps-and-alt-in-the-scan`);
the Ready-mode INCLINE lines above are the leftover of that spec on machines that have nothing to
raise.

**The button pages name the console's keys as FAN, START, LEVEL, STOP and ENTER**
(`spirit-xe-2016-console-face-7-5-inch-lcd-with-6-or-10-program-buttons`).

**The owner's manuals for the 2018, 2019 and 2021 successors describe the scan differently** - as
the Message Center showing laps, segment time and max level
(`spirit-xe-console-message-center-scan-shows-laps-segment-time-and-max-level`) - so a later
machine is not covered here. The 2016 residential bikes print this chapter with the same two
KPH/MPH printings (`spirit-xbr-2016-console-keys-in-ready-and-run-mode-enter-scans-every-four-seconds`).
