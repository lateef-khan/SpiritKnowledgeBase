**TM MODE (auto timer).** The auto timer operates automatically when there is motion. **Importantly, pressing SET for 3 seconds returns all exercise results on the display to zero - except ODO mode.**

**Motion activities display.** When you start to ride, the motion symbol shows on the display; the faster you work, the faster the icon moves.

**DST MODE (distance).** Your distance from the beginning to the current point (shown in the sub display with the mile/km symbol). The odometer is on [the wheel size card](xterra-mb-console-wheel-size-100-to-6999-mm-set-to-4330-mm-and-user-1-or-2.md); an average-speed **Err** clears with this reset ([card](xterra-mb-console-current-maximum-and-average-speed-and-the-err-reading.md)). The MB500 book is a scan read from the render (the console pages are OCR); the MB550 book prints the same console chapter natively and is cited alongside.
