| Stop key | What happens |
|---|---|
| **Pressed once** while running | Pause. The tread-belt **slowly decelerates to a stop**, **the incline goes to zero percent**, and the **Time, Distance and Calorie readings hold**. **After 5 minutes the display will reset and return to the start up screen.** |
| **Pressed a second time** | The program ends and a **workout summary is displayed**. |
| **Pressed a third time** | The console **returns to the idle mode (start up) screen**. |
| **Held down for more than 3 seconds** | The **console resets**. |

**To resume from pause, press the Start key.** The **speed and incline will return to their previous
settings**.

These manuals describe no way to change the 5 minute pause timeout.
