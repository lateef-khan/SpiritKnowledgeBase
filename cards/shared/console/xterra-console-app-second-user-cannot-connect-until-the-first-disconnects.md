"First user can be connected, but the second user is disconnected":

1. The **first user must disconnect Bluetooth in the app** before the second user can use it. If it still will not connect, **power off the equipment and turn it back on** ("power off the equipment to reopen").
2. **Reboot** the phone or tablet.

The machine holds one Bluetooth link at a time. This answer comes from the two-page **XTERRA APP Q & A** sheet of October 2018, written for the original Xterra App (iOS 7.0 / Android 4.3). The 2023-2025 books use the XTERRA+ app instead; the app card for those machines is [here](xterra-treadmill-console-xterra-plus-app-ios-13-android-8.md).
