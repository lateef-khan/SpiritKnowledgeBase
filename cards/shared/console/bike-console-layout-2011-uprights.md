Both console diagrams in this manual carry the same labels:

- **Cooling fan** and a **fan power switch**
- **Speaker**
- **Data display**
- **Dot matrix**, which shows program profiles
- **Message window**, labelled **Distance, Watts, Speed, Segment Time**
- **Program buttons**: Manual, Hill, Fat Burn, Strength, Interval, 2 User, 2 HR
- **Control keys** and a **Display** key
- **Audio in jack** for MP3, CD or smartphone
- **Headphone jack**

**There is no Cardio program button on this panel and no USB port.** Cardio appears on the button row from the 2013 model year onward, and a USB charging port from 2019.

**The message window legend on this panel is not the list the Display key actually cycles.** The panel says Distance, Watts, Speed, Segment Time; the manual's Basic Information paragraph gives three different sets of readings and names Program Name, RPM, Calories, Level and Pulse as well. Both are printed in this one manual.
