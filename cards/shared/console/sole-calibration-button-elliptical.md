1. **Clear error codes**: power the elliptical off, wait a few seconds, then power it back on.
2. **Enter calibration mode**: with the machine on, press and hold **Start** and **Incline Up** on the main console (under the screen, not on the arms). On 2026 models it is **Start** and **Fan**. Keep holding for about 10 seconds. The screen should show a calibration menu; if not, repeat.
3. **Start calibration**: step off the elliptical first, because it moves on its own. Press **Start** when prompted. The machine runs the incline from lowest to highest by itself.
4. **After**: on success the machine reboots to the home screen. Note any error codes that appear, and watch the behaviour, for example if it stops early or will not incline.

**The per-model service books calibrate differently.** The 2016/2019/2023 books hold Incline Up and Start for 5 seconds with no menu (`e25-2016-incline-calibration`); the E25-2026 book holds Start and Fan for 3 seconds. This card is the technician note's menu path, not the books' key-hold path.
