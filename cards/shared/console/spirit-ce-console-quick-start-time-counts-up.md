**Quick Start is the quickest way to start a workout: after the console powers up, press Start.**

- The **Time counts up from zero** and all workout data starts to accrue.
- The **workload is adjusted by hand** with the Up and Down keys. The CE800-2021, CE800-2023 and
  CES880 manuals name these the **Level Up and Down** buttons; the others just say Up and Down.
- The dot matrix shows the **bottom row lit**. As you increase the workload more rows light, and
  the machine gets harder to pedal as the rows increase.
- The dot matrix has **24 columns of lights and each column represents 1 minute**. At the end of the
  24th column the display wraps around and starts at the first column again.

**On four of these machines the dot matrix may start as a track instead.** The CE800-2013,
CE850-2016, CE850-2020 and CE850-2022 manuals add that it shows a **quarter mile (0.4 km) track
display or just the bottom row lit at first, depending on how the Display button has been set.**
The CE800-2021, CE800-2023, CE900 and CES880 manuals print only the bottom row.

**How many resistance levels you get is not the same on all of them.** See
`spirit-ce-specs-forty-resistance-levels` and
`spirit-ce850-specs-twenty-resistance-levels` before quoting a number.

**The CE800ENT is a touchscreen and works differently**; see `ce800ent-quick-start`.

**Ten Spirit commercial *bike* owner's manuals print this section too**, so this card covers bikes
as well as ellipticals and its product line is no longer elliptical-only: CU800-2012 p. 14,
CR900-2018 p. 14, CU900-2018 p. 13, CR800-2021 p. 15, CU800-2021 p. 15, CR900ENT-2021 p. 24,
CU900ENT p. 22, CR800-2023 p. 15, CR900-2025 p. 14 and CU900-2025 p. 14. All ten print the same
paragraph, including the 24 columns and the wrap-around at the 24th.

**The bikes split the same three ways the ellipticals do.**

- **Level Up and Down**, and a **Dot Matrix Message Center**: CR800-2021, CR800-2023, CU800-2021.
- **Up and Down**, and a plain **dot matrix display**: CR900-2018, CU900-2018, CR900-2025,
  CU900-2025, CR900ENT-2021, CU900ENT, CU800-2012.
- **A track instead of the bottom row at first**: only the **CU800-2012**, which prints the same
  "depending on how the display button has been set" clause the CE800-2013 and CE850 manuals do.

**The dot matrix paragraph is printed for the two 2021 touchscreen bikes as well**, word for word,
even though the CR900ENT and CU900ENT consoles are 10.1" touchscreens with no matrix of lights. The
page block was reused; the Start key and the counting-up time are the part that describes those
machines.

**The 2022, 2023 and 2024 touchscreen bikes print a shorter Quick Start** with no dot matrix at all:
`spirit-ent-bike-console-quick-start-touchscreen`.
