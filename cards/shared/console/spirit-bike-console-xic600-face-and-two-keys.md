The console drawing names three things and nothing else:

- **Large LCD Matrix Window** - the single display area.
- **Built-in Heart Rate Receiver** - the console reads a chest belt itself; there is no separate
  receiver box and there are no hand-grip pulse sensors on this bike.
- **Easy-Touch Control Buttons** - **two** red keys, and the whole console chapter is written around
  them. The text never gives them names, only positions: **the left hand key** and **the right hand
  key**. Every setting on this bike is reached by combinations of those two.

**The two keys are labelled on the console itself, and the text never says so.** The drawing on the
same page - which is a picture, with only 15 words of real text behind it - shows the left key
moulded **`MODE / RESET`** and the right key moulded **`START`**. Both printings carry the same
photograph. So when the manual says "press the left hand key", the key in front of the rider reads
MODE/RESET, and "hold the right hand key for 3 seconds" is the START key.

**The screen shown in that drawing** carries a curved cadence gauge marked **0, 40, 60, 80, 100, 120,
140, 160** with `rpm` beside it, a large RPM figure, a wireless-signal icon and a heart icon on the
second row, **KCAL**, and **SPEED** with an `M/H` tag on the bottom row.

**The manual calls the console three different things** - "console", "computer console" and "Cycling
Monitor" - all for the same part. The Cycling Console carton holds the computer console and the
speed sensor transmitter.

**Handling rules the manual attaches to it:**

1. It is a **sealed unit**, meant to be opened only to install batteries. Opening it voids the
   warranty.
2. Clean it with a clean damp cloth. Caustic cleaning solutions void the warranty.
3. It is **water resistant, not waterproof**. Excessive exposure to water voids the warranty.

**The chest strap is sold separately** - the manual says so where it describes the heart rate
window.
