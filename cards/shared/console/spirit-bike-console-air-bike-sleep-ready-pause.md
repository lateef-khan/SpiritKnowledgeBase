**SLEEP MODE.** After **60 seconds of inactivity** the console switches into power-saving Sleep Mode
and **the display switches off**. **Rotating the pedals or pressing any button** launches Ready Mode.

**READY MODE.** Tells the user the console is powered on and ready to enter any mode. After **60
seconds of inactivity** it drops back into Sleep Mode.

**PAUSE MODE.** During any mode of operation, **pressing the Start button launches Pause Mode for 5
minutes**. The console **beeps every 30 seconds and the display flashes** as a reminder. If there is
no activity within the 5 minutes, the console switches to Ready Mode.

- To **continue** the current program, press **Start** again.
- To **quit** the paused program, press **Stop**, which launches Ready Mode.

**A blank display is normally Sleep Mode, not a dead console.** Pedal or press a key before
suspecting the batteries.

**The beep every 30 seconds is deliberate**, not a fault code. It stops when you resume, stop, or let
the five minutes run out. The beep can be silenced altogether from engineering mode - see
`spirit-bike-console-air-bike-audio-on-off`.

**Start is the pause key.** There is no dedicated pause button on this keypad.

**The service manual's sleep rule names three inputs.** The console sleeps 60 seconds after standby with
"without pressing any key, RPM signal, heartbeat signal input" - so a heart-rate strap that is still
transmitting keeps it awake, as pedalling does. Its Pause Mode paragraph is the owner's manual's word
for word.
