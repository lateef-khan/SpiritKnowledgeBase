**A landscape LCD with a SPIRIT badge above it, and one row of five keys below.**

| Call-out | What it is |
|---|---|
| **Large Blue-LED Matrix Window** | The dot-matrix band across the centre of the display |
| **Built-in Heart Rate Receiver** | The heart symbol at the left of the lower digit row |
| **Easy-Touch Control Buttons** | The key row below the display |
| **"Ten innovative programs offer a variety of work-outs"** | A caption, not a part |

**The key row is five keys and reads, left to right: RESET, START/STOP, MODE, DOWN, UP.** Every one
carries a printed label under it. **The keys are colour-coded on this machine** - **RESET green**,
**START/STOP red**, **MODE blue**, and **DOWN and UP grey**. The CRW800 draws the same five keys in
the same order but colours only START/STOP (`crw800-2024-console-screen-overview`).

**The window labels are STROKES/MIN, TIME and DISTANCE across the top and HEARTRATE, CALORIES, WATT
and LEVEL across the bottom.** The drawing shows them lit with a worked example: **36**, **4:02**,
**1317**, **135**, **64**, **460**, level **4**.

**"Blue-LED" is the manual's own word and it is what the render shows** - the display is backlit blue
with white digits. The CRW800 books drop "Blue" from the same call-out and print the console
greyscale. **It is the quickest way to tell the two consoles apart in a photograph.**

**The drawing says "Ten innovative programs" while the Mode key steps through eleven** - Manual,
Distance, Time, Calories, 20/10 Interval, 10/20 Interval, Custom Interval, Fat Burn, Cardio, Strength
and Game (`crw800-2024-console-button-functions`). Nothing in either XRW600 printing resolves it, and
the CRW800 books carry the same contradiction.

**No Bluetooth symbol, no app, no USB socket and no power input is drawn or named anywhere in either
XRW600 manual.** A loose word search of both returns no `bluetooth` and no `usb` at all, and the
manual names no power source for the console (`xrw600-console-no-power-source-is-named`).

**The 2019 and 2021 printings draw the same console.** Their whole console chapters agree sentence
for sentence - 47 sentences of five words or more, all 47 shared.

**The XRW600-2019 service manual prints the same drawing on its Display Windows page** - Large
Blue-LED Matrix Window, Built-in Heart Rate Receiver, Easy-Touch Control Buttons, the ten-programs
caption, the five keys and the same worked example - in greyscale, so it confirms everything here
except the key colours. The CRW800-2016 service manual draws the same console under the same
Blue-LED label (`crw800-2024-console-screen-overview`).
