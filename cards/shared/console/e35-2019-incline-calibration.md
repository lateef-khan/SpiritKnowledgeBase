If there is a problem with the incline, try running the calibration.

Press the **Incline UP key and the Start key at the same time and hold them down for 5 seconds**. The incline calibration starts and runs automatically.

If the problem persists, contact the service department.

Calibration is also the fix the E3 troubleshooting table sends you back to.
