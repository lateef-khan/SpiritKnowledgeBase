Use the Engineering Mode to set speed and distance to metric, or to run the calibration procedure if there is a problem with the speed.

1. Press and hold the **Start** and **Speed ▲** keys for **5 seconds** while installing the safety key. All the segments light, then the message window shows the software versions and tells you to press Enter.
2. The display asks for **grade return**. Set to ON, this resets the incline to zero when you stop a program.
3. The message window shows the setting for **English (miles) or Metric (kilometers)**; use the ▲/▼ keys to select and press Enter.
4. The message window asks for the wheel size for calibration. Enter **63**.
5. The display shows the lowest speed setting — for miles it should be **0.5**. Adjust with ▲/▼ and press Enter.
6. The display shows the top speed setting — for miles it should be **12.0**.
7. The display asks for the top incline setting; enter **15**.
8. Press **Start** to begin calibration. This is an automatic process; the belt will move and change speeds without warning — be careful. When calibration is done the console returns to the start-up screen. The TR6.4 book adds: **DO NOT STAND ON THE BELT DURING CALIBRATION.**

The same two books print a different key combination — Start, Stop and Enter — for the engineering Functions menu that resets the Lube message ([lube card](xterra-tr-console-reset-lube-from-the-engineering-mode-functions-menu.md)); neither book says the two are the same mode. The in-store display mode has its own combination again ([display mode card](xterra-tr-console-exit-in-store-display-mode-stop-enter-display.md)).
