A new console may come configured in an in-store **display mode**, where the console stays powered on unless the main power switch is turned off.

To exit display mode for normal operation:

1. Press and hold the **Stop, Enter and Display** keys together for **five seconds**. The display shows `Display Mode - ON`.
2. Use the **Level Up key** to change the setting to `OFF`.
3. Press **Enter**.

**The key named here is the Level Up key.** The 2011 and 2013 upright and recumbent manuals name the *speed* Up key for the same step, and the 2011 light commercial manuals name simply the Up key. The three manuals do not agree, so use the one printed for your own machine.

There is also a Display Mode item in the console's maintenance menu, which controls whether the console powers down after a period of inactivity. That is a different setting from this one.
