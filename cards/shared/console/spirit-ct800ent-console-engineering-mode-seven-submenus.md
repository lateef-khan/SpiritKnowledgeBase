**Click the Home icon at the top centre of the main page 10 times.** The setting page then offers
**seven sub-menu modes**, described word for word as:

| Item | Description printed |
|---|---|
| Engineering Mode | Set the Speed and Incline |
| Security | Set Lock Accumulate mileage. |
| Diagnostics | The Error Diagnostics |
| Machine Information | Set Machine Type, GS Mode, Touch sound, Sleep Mode, Safety Mode, Zero mileage. |
| Maintenance | Set default language, WiFi, Etherent, Bluetooth, USB update, update OS. |
| A / V Source Setup | Set audio/visual source. |
| Lube Setup | Set Lube Suggest. |

Each entry has its own card: `spirit-ct800ent-console-engineering-mode-speed-and-incline-defaults-wheel-2-98`,
`spirit-ct800ent-console-security-mileage-lock-100-to-990-km`,
`spirit-ct800ent-console-machine-information-gs-beep-sleep-safety-zeroing`,
`spirit-ct800ent-console-maintenance-menu-language-wifi-ethernet-bluetooth`,
`spirit-ct800ent-console-av-source-setup-cab-hdmi-or-csafe-infrared` and
`spirit-ct800ent-console-lube-setup-default-4000-hours`. **Diagnostics** opens an Error Code Log
screen - the manual's screenshot lists E1, E5, E7 and E4 entries - and is held with the error cards.

**Seven entries, not six.** The CE800ENT elliptical in the same console family lists six - it has no
Lube Setup (`ce800ent-engineering-mode-menu`). The CU900ENT bike lists seven different ones, with TV
Setup and BT Setup at the top level (`cu900ent-engineering-mode-menu`). The ten-press gesture is the
same on all of them: `spirit-ent-console-enter-engineering-mode`.

**The owner's manuals for these two treadmills never print this menu.** The CT850ENT-2022 owner's
manual uses the ten presses only as step 1 of a calibration routine written in the LED console's
words (`ct850ent-2022-console-calibration-touchscreen`), and the support note on connecting to the
internet names the Maintenance tab (`spirit-ent-console-wifi-setup`).
