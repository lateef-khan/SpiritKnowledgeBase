**On these two consoles it is the ENTER key that cycles the message window during a workout, and one
of the readouts is an ALTITUDE in metres.** The XT185-2015 and XT285-2015 use a DISPLAY key and cycle
a different list: `spirit-xt-2015-console-keys-with-a-display-key-and-rapid-0-to-9`.

**READY mode**

| Key | Behaviour |
|---|---|
| Safety Key | Fit it in the right position to power on the computer. Pull it away and the computer shuts down automatically. |
| Stop | Non-functional. |
| Start | **3 second final countdown** on the window display, then the machine runs. MANUAL starts at MIN SPEED; PROGRAM starts at the preset value. |
| Enter | Changes each function (MANUAL sets time; pre-set PROGRAM sets time and speed; Heart Rate Control 1~2 sets time, age and heart rate; User Program 1~2 sets time, speed and incline). Before running a program it sets the personal profile, for example age. After a program is chosen it shows the speed or incline profile in the dot matrix. |
| Fast, Slow | Non-functional unless you have entered a setting. |
| Up, Down | Printed as non-functional unless you have entered a setting in the XT385-2015 book; the XT485-2015 book omits the two lines. |
| Quick SPEED & INCLINE | Non-functional. |
| Fan | Turns the fan on and off. |
| Handrail Control | Turns the handrail switch off. |

**RUN mode**

| Key | Behaviour |
|---|---|
| Safety Key | Pull it away and the computer shuts down automatically. |
| Stop | Stops the treadmill. |
| Start | Non-functional. |
| Fast | Each press adds **0.1 kph (0.1 mph)**. Held down, the speed climbs quickly to MAX SPEED. |
| Slow | Each press removes 0.1 kph (0.1 mph). Held down, the speed falls quickly to MIN SPEED. |
| Up | Each press raises the position by **0.5**; the maximum incline position is 15. |
| Down | Each press lowers the position by 0.5; the minimum is 0. |
| Quick SPEED & INCLINE | Press Speed or Incline, then **2 or 3 digits**, and the treadmill adjusts to that value automatically. |
| Fan | Turns the fan on and off. |
| Enter | Switches the exercise data shown in the message window - the list below. |
| Handrail Control | Turns the handrail switch off. |

The ENTER key cycles, and in SCAN MODE the console shows each item for **four seconds**:

```
SEG TIME  X:XX        (not shown in HRC MODE)
ALTITUDE  XXXX M      (unit: metres)
SPEED     XX.X  MAX XX.X   (actual speed and the maximum reached)
SCAN
```

**ALTITUDE is the vertical climb, printed in metres only** - the book gives no feet figure and no
formula. The XT185-2015 and XT285-2015 consoles print the same quantity as VERT in feet or metres.

The owner's-manual view of the digit entry is `xt-2015-console-select-keys-two-or-three-digits`, and
of the handrail switch `xt-2015-console-handrail-controls-and-disable-switch`.
