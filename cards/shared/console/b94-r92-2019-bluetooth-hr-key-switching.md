The console has one Bluetooth device (BLE 4.0) shared between the app and a Bluetooth heart rate chest strap, so the **heart rate key on the keypad** switches which one it serves.

1. In idle mode with the heart rate Bluetooth LED **not lit**, the Bluetooth function is used only for the app.
2. In idle mode, press the **heart rate key**. The Bluetooth LED lights. Bluetooth is now used only for the wireless heart rate chest strap. Wear the strap; the console connects and shows the Bluetooth heart rate value.
3. When the workout is over, the console's Bluetooth automatically switches back to the app.
