**Twenty rows of Red dots, 8 high** (tri-color on the F83/F85/S73/S77; the TT8 book prints red only), one per workout segment, showing approximate effort only. Three LEDs beside the window – **Track, Speed, Incline** – plus a **Display button** pick the view: Track LED lit shows the Track profile, Speed LED the Speed profile, Incline LED the Incline profile. Scrolling through all three with the Display button starts an automatic scroll, four seconds each, with the matching LED blinking; one more press returns to Track.
