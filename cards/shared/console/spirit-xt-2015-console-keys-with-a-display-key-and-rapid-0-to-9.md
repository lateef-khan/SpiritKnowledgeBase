**These two consoles have a DISPLAY key that cycles the message window and RAPID keys that take two
typed digits.** The XT385-2015 and XT485-2015 use the ENTER key for the cycle and their readouts
include an altitude: `spirit-xt-2015-console-keys-with-enter-cycling-altitude`.

**READY mode**

| Key | Behaviour |
|---|---|
| Safety Key | Fit it in the right position to power on the computer. Pull it away and the computer shuts down automatically. |
| Stop | Non-functional. |
| Start | **3 second final countdown** on the window display, then the machine runs. MANUAL starts at MIN SPEED; PROGRAM starts at the preset value. |
| Enter | Changes each function. MANUAL sets time; a pre-set PROGRAM sets time and speed; Heart Rate Control 1~2 sets time, age and the heart rate value; User Program 1~2 sets time, speed and incline. |
| Fast, Slow, Up, Down | Non-functional unless you have entered a setting. |
| Rapid | 10 preset buttons, 0 to 9, coupled with the speed and incline buttons - **disabled in ready mode**. |
| Fan | Turns the fan on and off. |
| Display | During exercise, polls the message window. |
| Program | Press PROGRAM ▲/▼ to choose, confirm every setting with ENTER, then press START. Six programs (Manual, Hill, Fat Burn, Cardio, Strength, Interval) plus USER1, USER2, TH60 PCT and THR80 PCT. |

**RUN mode**

| Key | Behaviour |
|---|---|
| Safety Key | Pull it away and the computer shuts down automatically. |
| Stop | Stops the treadmill. |
| Start, Enter, Program | Non-functional. |
| Fast | Each press adds **0.1 KPH (0.1 mph)**. Held down, the speed climbs quickly to MAX SPEED. |
| Slow | Each press removes 0.1 KPH (0.1 mph). Held down, the speed falls quickly to MIN SPEED. |
| Up | Each press raises the position by **1**. The maximum incline position is 15. |
| Down | Each press lowers the position by 1. The minimum is 0. |
| Rapid | Press the Speed or Incline key first, then **two digits**, and the treadmill adjusts to that value. |
| Fan | Turns the fan on and off. |
| Display | While selecting a program it switches between the SPEED and INCLINE profile. During a workout it switches the exercise data in the message window; after the switch the system scans automatically every **four seconds**. |

The DISPLAY key cycles, in this order:

```
PROGRAM NAME
LAPS      XX
VERT      XXX FT   (metric units show "M")
SEG TIME  XX:XX    (not shown in HRC MODE)
MAX SPEED XX:XX    (not shown in HRC or MANUAL MODE)
```

**The XT285-2015 book also draws a handrail disable button on its console page**: press it once and
the handrail quick buttons (incline and speed) are disabled and the LED lights; press it a second
time and they are enabled and the LED goes off. The XT185-2015 book draws no such button, and its
owner's manual describes none either (`xt-2015-console-handrail-controls-and-disable-switch`).

The two-digit entry as the owner's manual describes it is `xt-2015-console-select-keys-two-digits`.
