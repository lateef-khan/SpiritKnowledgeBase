**D. Security** in the engineering mode menu locks the keypad so the machine cannot be used without authorisation.

With the child lock enabled, the console will not let the keypad operate unless you **press and hold Start and Enter for 3 seconds** to unlock it.

Reach the setting by holding Start, Stop and Enter together to enter the engineering mode menu, then scrolling to Security with the Speed ▲/▼ keys.

**Owner's-book variant.** The same Security item and the same 3-second Start-plus-Enter unlock are printed word-for-word in the 2011/2013 owner's books (AF65/AF80/AS77/ATT8/TT8C/F60/F63/F65/F80/S77/TT8): those books enter the menu by holding Start, Stop and Enter (the 2013 F65/F80/S77 books add "and install safety key") and scroll with the Fast/Slow or Speed 5/6 keys. The 2007–2010 books print a shorter Security item with no unlock procedure.
