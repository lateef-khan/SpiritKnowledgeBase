**IDLE MODE** — The console shows each program name.

**DISPLAY MODE** — Preset is DISPLAY ON (disabled). You change it in Engineering Mode. With the setting ON the console never sleeps unless you switch the power off. With no RPM input in idle mode it sleeps after **30 minutes** with no key press. In display mode the screen is blank and the backlight is off. Any key wakes it back to idle mode. In sleep mode resistance is 1 and the fan is off.

There is also a quick key: in idle mode hold **ENTER + STOP + DISPLAY for 2 seconds**, use UP/DOWN to set sleep mode OFF or ON, then press ENTER to confirm and return to idle mode.

**EXERCISE MODE (QUICK START)** — In idle mode press START to enter MANUAL mode. Age and weight use the preset values. Time counts up from 00:00, every countable value counts up from 0, and resistance counts up from 1. You may instead pick MANUAL, PROGRAM, USER1, USER2, HRC1 or HRC2 and then press START.

**PAUSE MODE** — Press STOP. The workout values are held and the message window shows "PAUSE". With no key press for five minutes it returns to idle mode. Resistance drops to 1. When you press START the tension motor returns to the level it was on before the pause.

**END MODE** — The message window shows "WORKOUT SUMMARY" and lists the finished workout. With no key press for 3 minutes it returns to idle mode.

**RESET MODE** — In idle mode hold STOP for more than three seconds. The system resets, shows "RESET" for 2 seconds, then returns to idle mode. If child lock is on you must clear child lock first.
