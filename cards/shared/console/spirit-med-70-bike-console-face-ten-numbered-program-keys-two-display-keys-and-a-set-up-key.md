**All three books - the 2025 7.0R and 7.0U owner's manuals and the Dyaco MED 7.0R - draw the same
console and number the same eight call-outs:**

| # | Call-out | What the drawing shows |
|---|---|---|
| 1 | **Change graphic display** | A **Display** key (legend *Cycle / Scan*) beside the dot matrix, with three LEDs under it: **Track, Profile, Power** |
| 2 | **Program keys** (left) | **1 Manual, 2 Hill, 3 Plateau, 4 Interval, 5 HR** |
| 3 | **Message window** | The single-line text window below the dot matrix (the sample reads `AVG WATTS L 0 R 30`) |
| 4 | **Change data display** | A second **Display** key (*Cycle / Scan*) at the left of the lower keypad |
| 5 | **RPM scale for isokinetics only** | A column of marks **10 to 100** up the right edge of the dot matrix |
| 6 | **Dot matrix display** | The profile window (the sample reads `SYMM`) |
| 7 | **Program keys** (right) | **6 Facility, 7 VO2, 8 Constant Power, 9 Isokinetic, 0 Symmetry** |
| 8 | **Function keys** | **+**, **Enter**, **-**, **Set up**, **Start**, **Stop** (*Hold to reset*) |

Under the dot matrix sits a heart icon and a **Heart rate % profile** bar marked **50 55 60 65 70 75
80 85 90 %** (`spirit-med-70-bike-console-heart-icon-and-percent-of-maximum-bar-graph`).

**The program-key numbers are a keypad.** "The program keys also function as a Number Key Pad when
you are in the data-setup mode. The number for each key is shown above the program name"
(`spirit-med-70-bike-console-stop-reset-key-and-the-program-keys-as-a-number-pad`).

**There is no fan, no fan key, no Confirm key and no Level window on this console.** Resistance is
the + and - keys; "the operator can increase the workload using the Up and Down Key on the console",
as the operating-principle page puts it. The 4.0 series is a different face
(`spirit-med-40-bike-console-face-two-row-message-window-rpm-and-level-windows-and-five-program-keys`)
and the 7.0T treadmill labels its own drawing differently (`70t-2026-console-screen-layout`).

**The label text is invisible to `pdftotext`** - the page extracts to its heading alone - so an
extraction that reports "no console drawing" for these books is wrong.
