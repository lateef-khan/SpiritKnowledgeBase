**To wake it:** in power saving mode press the **PAGE** key. The console goes to the "QUICK Start" state.

**To change the display:** press the **MODE** key to pick TIME, DIST or KCAL.

The troubleshooting section of the same manual lists a different set for the MODE key: SPEED (SPD), DISTANCE (DIST), TIME (TIME) and CLOCK (CLK). The two lists do not agree and the manual does not say which console version each belongs to.
