**These machines are supplied with an external power supply.** When power is connected the console
**powers up automatically**; there is no on/off switch in the instruction.

The self-test then runs in this order:

1. The console performs an **internal self-test** and **all the lights turn on**.
2. When the lights go off, the **dot matrix display shows a software version (i.e. VER 1.0)**.
3. The **message window shows an odometer reading** - **how many hours** the elliptical has been used
   and **how many virtual miles** it has gone. The manuals print the display as `ODO 123 MI 123 HRS`.
4. The odometer stays up **for only a few seconds**.
5. The console goes to the start-up display: the **dot matrix scrolls the program profiles** and the
   **message window scrolls the start-up message**. You may now begin to use the console.

**`ODO 123 MI 123 HRS` is the manual's own example, not your machine's total.** Both 123s are
placeholders.

**How long the console waits before it blanks is not the same on both books.** The 2005 XE150,
XE350 and XE550 go to stand-by after **four minutes**; the 2007 XE100, XE200 and XE300 after
**twenty**. See `spirit-xe-console-stand-by-after-four-minutes-without-input` and
`spirit-xe-console-stand-by-after-twenty-minutes-without-input`.

**Where each manual prints it.** The 2005 paragraph is printed inside the combined XE350/XE550
description and names "the XE Series Elliptical", which is that manual's name for all three
machines; the XE150's own console pages do not repeat it. The 2007 manual prints it twice, once for
the XE100 and XE200 and once for the XE300, wording it identically both times.

**Later XE ellipticals dropped the ODO line.** From the XE395-2010 on, the distance and time windows
carry the totals instead and no `ODO` string is printed:
`spirit-xe-console-power-up-self-test-with-the-totals-in-the-data-windows`.

**Three printings of the Spirit XBR95 residential recumbent bike print the same `ODO 123 MI
123 HRS` line**, so this card is no longer elliptical-only. It is on **p. 14, POWER**, in the 2016,
the 2018 and the 2021 manual alike: the internal self-test, all the lights on, then the software
version in the dot matrix and the odometer in the Message Center, worded exactly as the XE100 to
XE550 word it - **how many hours the bike has been used and how many virtual miles it has gone**.

**The XBR95 gets there a different way.** It has no power cord: its console runs off a built-in
generator and you start pedalling to wake it, so the self-test happens as you begin rather than when
you plug in. See `spirit-xe795-console-power-up-by-pedalling`.

**No other Spirit residential bike prints the ODO line.** The XBR25, XBR55 and XBU55 of every
printing, and the XBR95's own 2023 successor, put the totals in the distance and time windows
instead: `spirit-xe-console-power-up-self-test-with-the-totals-in-the-data-windows`.
