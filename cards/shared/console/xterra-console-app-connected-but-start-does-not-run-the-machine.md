"App is connected, app does no function when you press START of the console, the machine doesn't run": the sheet calls this **a machine issue**, not an app issue - **provide the error code from the console and contact the service unit.**

Error-code meanings are on the machine's errors cards. This answer comes from the two-page **XTERRA APP Q & A** sheet of October 2018, written for the original Xterra App (iOS 7.0 / Android 4.3). The 2023-2025 books use the XTERRA+ app instead; the app card for those machines is [here](xterra-treadmill-console-xterra-plus-app-ios-13-android-8.md).
