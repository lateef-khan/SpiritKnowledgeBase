**READY MODE** (before Start):

| Key | What it does |
|---|---|
| STOP | Non-function |
| START | Starts the elliptical: "there will be 3 second final count down on window display, then machine starts running. In MANUAL, elliptical starts at MIN LEVEL" |
| LEVEL UP / DOWN | Non-functional until a setting has been entered |
| INCLINE UP / DOWN | Non-functional until a setting has been entered |
| FAN | Fan on or off |
| ENTER | Enters parameter setting, and confirms or modifies each setting. The spec adds "confirm the every setting by pressing START key no pressing ENTER key" - Start accepts the settings and begins |

**RUN MODE** (during a workout):

| Key | What it does |
|---|---|
| STOP | Stops the elliptical |
| START, ENTER (as a control) | Non-functional |
| LEVEL UP / DOWN | Raises or lowers the level by 1 |
| **INCLINE UP / DOWN** | Raises or lowers the position by **0.5**; "the maximum incline position is 20", "the minimum incline position is 0" |
| FAN | Fan on or off |
| ENTER (as the scan key) | Switches the exercise data. If the display already shows the latest data, pressing it lights the **SCAN ICON** in the message window and the display cycles automatically **every four seconds** |

**The scan list.** The CE850-2016 and XE895-2016 print "CYCLE MODE WILL FIRST DISPLAY `SPEED
XX.XMPH` AND THEN DISPLAY": `WATT XXX`, `LAPS XX`, `ALT XXXXM`, `TIME XX:XX`, `MAX LV XX` (only in a
program). **The XE395-2016 adds one line**, `MAX INC XX.X` (only in a program), after MAX LV.

**Incline here is the stride motor on the CE850 and XE895.** Those two books' function tables set
the same control as a **stride of 18 to 24 in half steps**
(`spirit-ce850-2016-console-data-ranges-stride-18-to-24-and-level-1-to-20`); this key table's 0 to
20 is the treadmill-style range of the spec it was copied from. On the XE395-2016 the incline is a
real ramp with its own 0-to-20 half-step table
(`xe395-2016-console-data-ranges-incline-0-to-20-in-half-steps-and-level-0-to-20`).

**The XE195, XE295, XE795 and XG400 books of the same year print no Incline row in Run mode and no
ALT in the scan** (`spirit-xe-2016-console-keys-in-ready-and-run-mode-enter-scans-every-four-seconds`).
The owner's manuals of the XE395-2018 and XE895-2018 describe the scan differently
(`spirit-xe-console-message-center-scan-shows-laps-segment-time-and-max-level`).
