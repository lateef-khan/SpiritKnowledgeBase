Read off the printed table (verified against the render):

| Window | Range |
|---|---|
| WATTS | Display 0~999 |
| CALORIES | Display 0~9999; setting 0~9990 Cal |
| METERS | Display 0~99900 |
| PULSE | Display 0-30~230 BPM |
| TIME/500M | Display 0:00~99:00; **re-scans every 6 seconds**, showing the time needed to finish 500 meters at the current speed |
| SPM | 10~90 strokes per minute |
| LOAD | Setting 1~16 |
| STROKES | Display 0~9999; **scans every 6 seconds with Total Strokes**. Total strokes clear at power-off (adaptor plug out) |
| TIME | Total workout time display |

The console face adds a **built-in pulse receiver** and a **big function-value display** whose top line cycles MANUAL / PROGRAM / H.R.C. / RACE / USER. Mode operation itself is a programs-side fact.
