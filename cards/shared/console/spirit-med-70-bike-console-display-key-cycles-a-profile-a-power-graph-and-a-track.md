**"The Dot Matrix Display is used for displaying graphic feedback and has three basic displays for
most programs, except for Isokinetic and Symmetry programs which are described later."**

1. A program starts on a **workload profile** (constant resistance).
2. "To the left of the dot matrix there is a key labeled display. Pressing this key will switch the
   display to show a **Power graph (watt profile)**",
3. "and then a **track**" - the program pages call it "a quarter mile track".
4. "**When both LEDs under the key are blinking, the graph will scan through the three displays.**"

**This is the upper Display key** - call-out 1, *Change graphic display*, whose three LEDs read Track,
Profile and Power. The second Display key, under the message window, changes the **data** readout
instead (`spirit-med-70-bike-console-message-window-measurements-including-left-and-right-average-watts`).
The 4.0 series has only the data key
(`spirit-med-40-bike-console-display-key-two-data-sets-and-a-four-second-scan`).

**The Isokinetic program adds a speed profile and lights the RPM scale** - "you may also switch between
the speed profile, power profile or a quarter mile track ... There is an RPM graph to the right of the
dot matrix to monitor user speed." The drawing marks that scale **10 to 100** and labels it "RPM scale
for isokinetics only". **The Symmetry program replaces the profile with the left-right power graph**;
both programs are held with the program cards.

**How tall the power graph is depends on Watts per row** in the Set up menu - 10 watts a row by
default, all ten rows lit meaning 100 watts
(`spirit-med-70-bike-console-watts-per-row-10-to-100-and-a-level-scale-of-5-10-or-15-watts`).

In Quick start the profile columns are minutes: 24 columns, one minute each, wrapping at the 24th, with
50 levels drawn in 10 rows (`spirit-ce-console-quick-start-time-counts-up`). The 7.0T treadmill's
Profile key cycles speed, incline and track instead (`70t-2026-console-dot-matrix-profiles`).
