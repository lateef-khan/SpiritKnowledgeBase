**The dealer manual prints this menu for the XT375, XT475 and XT675 only** - its heading says so -
and the XT175 and XT275 have no engineering mode in the book at all.

**To enter: remove the tether cord, press and hold START, ENTER and STOP, and replace the tether
cord.** The display says **ENGINEERING MODE**. Press ENTER, then scroll the sub-menus with UP and
DOWN and press ENTER to open one.

| Sub-menu | What it holds |
|---|---|
| Calibration | **Speed Calibration** - a mode in which you can test the speed. **Incline Calibration** - a mode in which you can test the incline. |
| Factory Settings | **View** the wheel size, max incline, and max and min speed with UP and DOWN. **They cannot be changed here.** |
| Security | **Child Lock On/Off.** Press ENTER to turn it on or off. **To unlock the display, press START and ENTER.** |
| Functions | **Sleep Mode On/Off** (ENTER toggles). **Units English/Metric** (ENTER changes). **Maintenance**: **Lube Message Reset** and **Odometer Reset**, ENTER resets each. **Pause Mode On/Off** (ENTER toggles). |
| Display Test | Tests all LEDs. |
| Key Test | Tests all buttons on the console. |

**The values are changed in the FACTORY SETTING calibration routine, not here** - this menu only
lets you read them: `spirit-xt-2007-console-calibration-factory-setting-wheel-2-810-or-3-060`.

**No timeout is printed for Sleep Mode and no duration for Pause Mode.** The later XT menus give 30
minutes and 5 minutes; nothing in this manual does.

The later XT consoles use the same three keys but hold them for about 5 seconds with the safety key
in, and lay the menu out differently: `xt-2015-console-engineering-mode-menu`.
