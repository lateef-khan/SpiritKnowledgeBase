When power is connected the console powers up automatically.

**These models have no power pack.** The manual states they are **connected directly to 115 VAC**, and there is a **power switch where the line cord plugs into the unit, on the left side near the front**.

On first power-on the console runs an internal self-test:

1. All the lights turn on.
2. When the lights go off, the Message window shows a software version (for example `VER 1.0`), and **the Calorie window shows an odometer reading**.
3. The odometer reading is how many **virtual miles** the bike has gone. The Time window shows how many **hours** the bike has been used.
4. Both are displayed for only a few seconds.
5. The console then goes to the startup display: the dot matrix scrolls the different workout profiles and the Message window scrolls the start-up message.

**The odometer sits in a different window on later machines.** From the 2013 model year onward the same manual paragraph puts the odometer in the **Distance** window, not the Calorie window. Read the window name off the card for your own year.

These manuals also carry an in-store display-mode warning, which is a separate procedure.
