**There is no power switch and no mains lead.** The console sits in **Power Saving Mode** with the
display off until you wake it.

**Hold down any key** to wake the console and go to the start-up screen, also called the
**"QUICK START" active state**. From there just pedal - no program to choose and nothing to set.

The manual prints the two states side by side, labelled *Power Saving Mode* and *QUICK START Mode*.

**A blank display is normally this, not a fault.** The troubleshooting page's first line for "No
Display on Console" is the same instruction: hold down any key to bring the console to Quick Start
mode. Only if that fails does it send you to the batteries.

**This is not the CIC850's gesture.** On that bike a single press of the **Page** key wakes the
console; there is no Page key here.
