> To enter Settings, select the **gear symbol in the upper right of the screen, next to the Time**.
>
> Settings are password protected and for facility staff only. **Password: Dy23751545**

The password is printed in the owner's manual exactly as above, capital D and lowercase y. The
screen that asks for it says access is limited to club personnel.

## What Settings holds

> Settings are where facility staff can view and adjust pertinent machine settings. These would
> include Sound Volume, Screen Brightness, Units, Language, as well as viewing System Software and
> Hardware.

| Setting | How it is changed |
|---|---|
| **Sound Volume** | *Adjust the Sound Volume by sliding left and right* |
| **Screen Brightness** | *Adjust the Screen Brightness by sliding Right to Left* |
| **Units** | *Change the Units by selecting either Metric or Imperial* |
| **Language** | a drop-down; see `spirit-strength-csi-console-nine-languages` |
| **Software & Hardware** | view only - the manual says *viewing*, not adjusting |
| **Gym App** | the menu carries an **Add to Gym App** entry, which the manual never explains |
| **Updates** | an **Update** button; see `spirit-strength-csi-console-wifi-and-software-update` |

**To leave: press Done**, which returns to the Home Screen.

The Units choice is Metric or Imperial only. The manual gives **no** default for any of these, **no**
way to reset them, and **no** second or engineer-level password - `Dy23751545` is the only one the
book prints.
