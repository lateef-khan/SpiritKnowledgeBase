The Message Window starts on Speed. Each **Enter** press moves to the next of four windows: Speed in RPM and MPH, then Work Level and Watts. Pressing Enter on the Level/Watts display lights **Scan**: the window rotates each data set for four seconds in a loop; Enter again returns to the start.
