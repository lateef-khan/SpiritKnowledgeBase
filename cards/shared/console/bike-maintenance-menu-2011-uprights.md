**To open it:** press and hold **Start, Stop and Enter** together for about **5 seconds**, until the message window shows "Engineering mode". Press **Enter** to open the menu. Use the **Level up and down** keys to navigate.

| Item | What the manual says it does |
|---|---|
| A. Key Test | Lets you test all the keys to make sure they are functioning. |
| B. Display Test | Tests all the display functions. |
| C. Functions | Press Enter to access settings, use Level up/down to scroll. |
| C.I Sleep Mode | Turn **on** to have the console power down automatically after **30 minutes** of inactivity. |
| C.II Pause Mode | Turned **on** to allow **5 minutes** of pause, turn off to have the console pause indefinitely. |
| C.III ODO Reset | Resets the odometer. |
| C.IV Units | English or Metric display readings. |
| C.V Beep | Turns the key beep on or off. |
| C.VI Motor Test | Continually runs the tensioning gear motor. |
| C.VII Exit | |
| D. Security | Locks the keypad against unauthorised use. With child lock enabled the keypad will not operate unless you press and hold **Start and Enter for 3 seconds** to unlock the console. |
| E. Factory Settings | Access only allowed by manufacturing. |

**This is not the menu the later bikes have.** From the 2013 model year the same section prints a different order and different items: ODO Reset first, a **Display Mode** item instead of Sleep Mode, an added **Manual** gear-motor stepping item, **Key Tone** instead of Beep, and Exit moved out of Functions to become item F. Count the items before quoting a letter to a customer.
