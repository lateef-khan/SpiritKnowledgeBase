Every one of these manuals prints the same note:

> **Age and Weight default settings will change when you enter a new number.** So the **last Age and
> Weight entered will be saved as the new default settings.** If you enter your Age and Weight the
> first time you use the elliptical, **you will not have to enter it every time you work out** unless
> either your Age or Weight changes, **or someone else enters a different Age and Weight**.

**There is one slot, not one per user.** In a household where two people use the machine, whoever
entered last owns the defaults. Nothing in any of these manuals offers a second user profile.

**Skipping data entry uses those defaults.** Press **Start** at a program's first data screen and the
console bypasses programming and uses the default, or last saved, settings.

**This matters most for the readouts that depend on them.** Age sets the heart rate targets and, on
the consoles that have one, the percent-of-maximum bar graph; weight feeds the calorie estimate,
which the same paragraph warns is only a guide:
`spirit-xe-console-calorie-note-you-keep-burning-at-an-accelerated-rate-for-an-hour`.

**The XE150 is not covered.** Its console section describes no age or weight defaults, and its
Target HR program asks for an age each time it is set up.

**Two machines print a factory default set as well**, and the numbers are not the same on both:
`spirit-xe-console-factory-defaults-age-35-weight-150-time-30-00` and
`spirit-xe-console-factory-defaults-with-a-155-pound-weight`.

**The XE395ENT stores profiles instead.** Its touchscreen keeps up to nine, each with its own data;
see `xe395ent-2021-console-profiles-and-the-spirit-app-link`.
