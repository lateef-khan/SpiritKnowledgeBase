Wear the **chest strap** (optional, sold separately). While a pulse value is displayed, press **RECOVERY** to start. Every window stops except TIME and PULSE: TIME shows **0:60** and counts down to 0:00. The computer then shows the recovery grade (Picture 18 shows F6):

| F | Grade |
|---|---|
| 1.0 | OUTSTANDING |
| 1.0 < F < 2.0 | EXCELLENT |
| 2.0 < F < 2.9 | GOOD |
| 3.0 < F < 3.9 | FAIR |
| 4.0 < F < 5.9 | BELOW AVERAGE |
| 6.0 | POOR |

Press RECOVERY again to return to the main menu. The same page remarks: **E-2** means check the cables are connected and undamaged; after changing the **RF battery allow 15 seconds** to pair with the console, and re-pair if it takes longer (fault-side facts, not carded here).
