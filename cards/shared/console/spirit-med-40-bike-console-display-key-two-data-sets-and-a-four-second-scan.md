**The message window initially displays distance, calories, pulse and time.** "On the bottom left of
the key pad is a key labeled display. Each time this display key is pressed the next set of
information will appear."

| Press | The message window shows |
|---|---|
| Initially | **Distance, Calories, Pulse, Time** |
| Display once | The next set - the drawing's second row: **Speed, Cal/hr, Watts, METs** |
| Display again, during the second set | **Scan mode**: each set for **four seconds**, then the next, in a continuous loop |
| Display again | Back to the first set |

**The text never names the second set.** The console drawing does: its message window carries two
rows of legends, Distance / Calories / Pulse / Time and Speed / Cal/hr / Watts / METs, and the key
itself is printed **Scroll** with **Display** under it. All six books - the two 2025 owner's manuals,
the two service manuals and the two Dyaco PT editions - print the paragraph word for word.

**When you begin a program the dot matrix displays the workout profile.** There is no second display
key beside the dot matrix and no track or power-graph view on this console; that is the 7.0 series
(`spirit-med-70-bike-console-display-key-cycles-a-profile-a-power-graph-and-a-track`).

The 4.0T treadmill's Display key runs the same four-second scan
(`40t-2026-console-display-key-and-scan`); the commercial bikes with a Scan button show Time Remaining
in the second set where this console shows Cal/hr (`spirit-ce-console-led-data-windows-scan`).
