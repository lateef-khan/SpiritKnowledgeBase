Because of the generator system, the console **shuts off if there is no movement at the flywheel**.

- If you are in a program and have to stop pedalling, your information is **saved for up to 5 minutes**.
- When you resume pedalling the program continues at that point and data keeps accumulating from where you left off.
- **If more than 5 minutes has elapsed, the console returns to the start up screen and all data from that workout is lost.**

This is not the console's Pause feature. The Stop key's own pause behaviour is described separately, and this manual gives no duration for it.
