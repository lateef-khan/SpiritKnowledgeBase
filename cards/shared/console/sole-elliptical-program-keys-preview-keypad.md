Pressing each program key at power-on **previews** its profile; pressing the wanted key then Enter enters data-setting mode. In data-setting mode the same keys are a **number key pad** (a digit sits under each key) for fast Age/weight entry. On the WE55/WE95 the keys add a third job as hidden workload/incline Quick keys (own card).
