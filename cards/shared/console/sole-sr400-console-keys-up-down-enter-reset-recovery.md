**UP** raises the function value or setting selection; **DOWN** lowers it. Under Manual and Program modes UP/DOWN adjust the resistance, which has **16 levels, L1 to L16** (Figure 12: press START/STOP, then UP/DOWN to pick the load).

**ENTER** confirms a setting or selection. **Hold ENTER for 2 seconds and the computer reboots.**

**RESET** clears a setting value, and returns to the main menu after a finished workout.

**START/STOP** starts or stops rowing. **RECOVERY** measures heart-rate recovery (see_also); it needs a chest strap on, and works only while a pulse value is displayed.
