**UNPLUG THE BIKE BEFORE PERFORMING ANY MAINTENANCE.** (Printed "UNPLUG RECUMBENT BIKE" on the
CR900 and "UNPLUG UPRIGHT BIKE" on the CU900 and CU800ENT.)

| Item | Daily | Weekly | Monthly | Quarterly | Biannually |
|---|---|---|---|---|---|
| Entire Bike | Clean | | Inspect | | |
| Unit Hardware | | Inspect | | | |
| Detailed Cleaning | | Clean | | | |
| Console Hardware | | | | Inspect | |
| Levelers | Inspect | | | | |
| Handle / Seat | Clean | | Vertically Adjust | | |
| Pedals | Clean | | Inspect | | |
| Connections & Fixings | | | Inspect | | |
| Console Overlay | Clean | | | | Inspect |
| USB Port | | Inspect | | | |
| Accessory Cups | Clean | | | | |

Eleven items, five intervals, and **no annual column** — the table stops at Biannually.

## The unplug warning contradicts the CR900 and CU900 themselves

Both 2025 manuals state elsewhere that the bike **has a built-in generator for power and does not
need to be plugged into an AC outlet**, and neither parts list contains a power cord. There is
nothing to unplug on those two machines; read the line as "make sure the bike cannot be pedalled
while you work on it", and note the safety warning that the generator produces A.C. power while the
bike is being used — do not service it while the generator is spinning. The **CU800ENT 2024 does
have a mains cord** (parts list item 135, Power Cord), so on that machine the instruction is
literal. See `spirit-disconnect-from-the-outlet-before-cleaning-or-service`.

## This is not the elliptical table

The CE900 2025 and CES880 2025 print a ten- and nine-row version of the same table. Theirs has
**Entire Unit** rather than Entire Bike, the CE900 adds a **Tracks / Wheels** row, and **neither
has a Handle / Seat row or a Connections & Fixings row** —
`ce900-2025-maintenance-machine-care-schedule`,
`ces880-2025-maintenance-machine-care-schedule`. The Spirit treadmill tables are different again
(`ct900-maintenance-schedule`, `ct900ent-general-maintenance-schedule`). No row of either belongs
here.

## Ten bike manuals print no schedule at all

Only these three of the thirteen Spirit commercial bike owner's manuals carry a table. The CR800
2021/2023, CR800ENT 2023, CR900 2018, CR900ENT 2021, CU800 2012/2021, CU800ENT 2022, CU900 2018 and
CU900ENT 2021 give the post-workout wipe-down and the noise checks only
(`cu900ent-general-maintenance`). **There is no interval to quote for those ten machines.**

The same three manuals also carry the four-step post-workout routine that goes with this table —
`spirit-2026t-maintenance-post-workout-machine-care`.
