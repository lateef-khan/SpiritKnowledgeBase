The troubleshooting table's two belt rows, as printed (the page is a picture in both books and was read from the render):

| Question | Possible cause | Maintenance method |
|---|---|---|
| The running belt doesn't run smoothly | Insufficient lubrication | Add silicone oil lubricant |
| | Running belt is too tight | Adjust running belt tightness |
| Running belt slipped | Running belt too loose | Adjust running belt tightness |
| | Motor belt is too loose | Adjust motor belt tightness |

The book prints no motor-belt procedure; the belt page says tightening the motor belt is a job for a trained service person. The rear-roller tension adjustment is `xterra-ws-maintenance-belt-tension-rear-roller-screws-5-mm-allen-wrench`; lubrication is `xterra-treadmill-maintenance-deck-lubrication-s-line-18-inches-from-the-motor-cover` at the interval on `xterra-treadmill-maintenance-lubrication-interval-every-90-days-or-90-hours`. The rest of the table - power, safety key, fuse and the E01 to E07 codes - belongs to the errors cards.
