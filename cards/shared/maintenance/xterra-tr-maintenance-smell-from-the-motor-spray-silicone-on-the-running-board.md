The last row of the troubleshooting page, as printed:

> **SMELL**: if any smell comes out from the motor, please firstly spray out some silicone on the running board (please refer to RUNNING BOARD MAINTENANCE), and see if the situation improves. Then consult the distributor for necessary help.

The heading it cites, "Running Board Maintenance", does not exist in either book; the lubrication pages are headed "Running Deck Lubrication" (TR75H) and "Deck Lubrication" (both). The procedures: `tr75h-2025-maintenance-deck-lubrication-three-one-foot-lines-with-the-straw`, `xterra-treadmill-maintenance-deck-lubrication-s-line-18-inches-from-the-motor-cover`. The same page's E1, E3 and E6 rows belong to the errors cards, as does the service manual's current-limit scenario whose first remedy is also "add lubricant between the running deck and running belt".
