"No power" can mean the power stops in many places. Trace it from the wall plug, to the motor controller, then up to the console.

1. Check the power cord is plugged in properly and the on/off switch is flipped ON.
   - **No**: plug it in properly and flip the switch on. If it works, you are done. If not, run the voltage test below.
   - **Yes**: ask whether the on/off switch lights up. **An ST90 has no light in its switch, so treat it as unlit.** If it is an ST90 straight out of the box, just send computer cables, because they were most likely pinched during assembly.
2. If the switch lights up, have the customer remove the motor hood cover and look for lights on the motor controller.
   - **Lights on**: ask whether the machine was recently assembled, taken apart or moved. If yes, replace the computer cables. If no, check every wire is plugged into the motor controller. If wires were loose and the light now comes on, it is fixed. If they were all plugged in, or plugging them in did not help, run the voltage test.
   - **No lights**: replace the motor controller.
3. If the switch does not light up, ask whether the machine is plugged straight into its own circuit on a non-GFCI outlet.
   - **Yes**: ask whether the breaker on the machine is tripped. If it is, reset it. If the machine still does not work, run the voltage test.
   - **No**: run the voltage test.

**Voltage test**

1. Test power at the outlet. If it is not about 120V, the outlet is the problem and an electrician has to look at it.
2. Plug the power cord into the outlet but not into the machine. If the power through the cord is not about 120V, replace the power cord.
3. With the machine unplugged, disconnect the white and black connecting wires that run from the on/off switch (or the filter, if the machine has one) to the motor controller. Put the multimeter probes on the wires you just unplugged. Plug the power cord into the outlet and into the machine's power socket, then turn the on/off switch ON.
   - About 120V: replace the motor controller.
   - Not about 120V: replace the white and black connecting wires, the on/off switch, the breaker and the power socket.
