Either the machine thinks a button is being pressed, or the motor controller is acting on its own.

1. Ask whether the machine was recently assembled, taken apart or moved.
   - **Yes**: replace the computer cables. **If the machine is older than 2020**, replace the computer cables, the upper speed cable and the speed adjustment switch.
   - **No**: go to step 2.
2. Ask whether the speed number on the console changes when the speed physically changes.
   - **Yes**: something in the console is commanding the change. Replace the console assembly. **If the machine is older than 2020**, first disconnect the speed adjustment switch and try again. If it now behaves, replace the speed adjustment switch. If not, replace the console assembly.
   - **No**: go to step 3.
3. Check for wear, then the outlet, then noises:

1. Ask how often the customer lubricates. Either way, check the running belt and running deck for wear. Slide a hand between belt and deck palm up and feel whether the texture in the middle is gone. Turn the palm down and feel the deck for damage.
   - Good: go on.
   - Worn or damaged: replace the running belt, and the running deck only if it is damaged.
2. Ask about squeaking or knocking noises. If there are any, ask whether they come from the front or the rear, and replace the front roller or the rear roller, possibly both.


If everything looks good, the answer is almost always the motor controller.
