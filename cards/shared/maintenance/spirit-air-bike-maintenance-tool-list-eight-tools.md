Servicing needs basic and sometimes specialty tools depending on the job. Spirit recommends having
these **eight** available:

| Tool | Purpose |
|---|---|
| Crank Puller | Removing cranks and pedals |
| Metric Allen (Hex Key) Wrench Set | Tightening or removing various Allen head screws throughout the product |
| Metric Sockets Set | Tightening or removing various hex nuts used throughout the product |
| Metric Open Wrench Set | Tightening or removing various hex nuts used throughout the product |
| Square Drive Ratchet Wrenches | To use in conjunction with Allen head and or hex socket sets |
| Torque Wrench | Tightening various critical bolts throughout the product to specific torque specifications |
| Phillips Head Screwdriver Set | Tightening or removing various Phillips head screws used throughout the product |
| Flat Head Screwdriver Set | Prying off specific shrouds from wedged locations |

The AB900 spells the fifth row "Square Drive **Ratched** Wrenches"; the AB950 spells it "Ratchet".
Same tool.

**No sizes are given.** The table names sets, not individual wrench or socket sizes, and the manuals
name no torque figure to set the torque wrench to except the AB950's pedal figure
(`ab950-2024-assembly-pedal-torque-33-to-37-lb-ft`).

## The JB950 list is one row shorter

The Johnny G Spirit Bike prints **seven** rows: it has **no Flat Head Screwdriver Set**, and its
crank puller is for "**Removing crank**" rather than "Removing cranks and pedals" — consistent with
its warning that members should not change the pedals. See
`jb950-2022-maintenance-tool-list-seven-tools`.

This is the service tool list, not the assembly kit. The wrenches shipped in the box are a separate
list in each manual's assembly chapter.
