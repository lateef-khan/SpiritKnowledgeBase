A sudden stop can come from an error code, from lost power, or from the machine no longer sending power to the drive motor. The job is to tell an outside cause, such as a house breaker tripping, from an inside one, such as a damaged motor controller.

**If the customer got an error code**, follow the guide for that code instead.

**If the console turned off completely**:

1. Ask about lubrication, and check the running belt and running deck for wear.
   - Good: go to step 2.
   - Worn or damaged: replace the running belt, the running deck if damaged, and the controller.
2. Ask whether the machine is plugged straight into its own circuit on a non-GFCI outlet.
   - Yes: go to step 3.
   - No: move it to its own non-GFCI circuit and try again. If it runs, it is fixed. If not, replace the motor controller.
3. Run a battery test on the drive motor.
   - Passes: go to step 4.
   - Fails: replace the drive motor and the motor controller.
4. Ask about squeaking or knocking noises. If there are any, ask front or rear, and replace that roller (possibly both) together with the motor controller. If there are none, replace the motor controller.
