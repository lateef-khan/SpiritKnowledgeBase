**Wipe down all areas in the sweat path with a damp cloth after each workout.**

That is the only fixed-interval care any B manual prints - `after each workout` is the single schedule in this wave, so one card covers it. Rail and wheel cleaning is done when a noise develops, not on an interval. The 2026 generation prints the same sentence (see the linked card).

The three C climber books (sc200-2016, sc200-2019, sc300-2017) and the SRVO-2021 book print the sentence word for word, so they are on this card; the card is now cross-line (`product_line: *`). The SRVO book pairs it with a weekly cable wipe on its own card.
