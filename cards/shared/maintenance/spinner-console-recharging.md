The console holds a **rechargeable** battery. There is no cell to replace.

What the owner's manuals say (SB700 2020, SB700 2021, SB900 2020, SB900 2021):

1. This requires a standard **USB to micro-USB cable**.
2. Connect your console input to a standard USB wall charger.
3. When the battery icon is showing, console battery is low. Please charge your console as soon as possible.

What the DT-3268 console manual adds (and is the only source for the SB900 2023):

> Computer console uses rechargeable battery; remove console from handlebar. Use micro USB cable to charge once the battery icon appears. When charging, battery icon will flash, battery icon will disappear when fully charged.

So: take the console off the handlebar to charge it, the icon flashes while charging, and the icon disappears when it is full.

The **speed sensor transmitter** on these same machines still takes 2 AAA cells. Only the console is rechargeable.
