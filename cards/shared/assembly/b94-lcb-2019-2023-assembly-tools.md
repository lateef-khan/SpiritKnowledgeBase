| Item | Tool |
|---|---|
| #76 | Combination M5 Allen Wrench & Phillips Head Screw Driver |
| #92 | 13/15mm Wrench |
| #93 | Phillips Head Screwdriver |
| #100 | 12/14mm Wrench |

Four tools. The M5 Allen wrench (#76) is the one used to secure the seat handle bar / handlebars onto the console mast, which is why it does not appear in the 2011-2016 tool sets.

**The B94 2019 ships the same four tools** and is covered by its own card.

**Tool item numbers are not shared between models.** The same `#` is a different part on another Sole bike, so use the list printed in your own machine's manual.
