The labels are words, not letters, and the three manuals do not use the same
words. Printed as they appear:

| 2016 manual | 2020 manual | CT800ENT manual |
|---|---|---|
| CONSOLE | CONSOLE | CONSOLE |
| CONSOLE FAN | CONSOLE FAN | CONSOLE FAN |
| READING RACK | READING RACK | *(not labelled)* |
| HEART RATE GRIPS | HEART RATE GRIPS | HAND PULSE SENSORS |
| DRINK BOTTLE HOLDER | BOTTLE HOLDER | CUP HOLDER |
| SAFETY Button | SAFETY KEY | SAFETY KEY |
| HANDLEBARS | HANDLEBARS | HANDRAILS |
| CONSOLE MAST | CONSOLE MAST | CONSOLE MAST |
| SIDE RAILS | SIDE RAILS | SIDE RAILS |
| MOTOR COVER | MOTOR COVER | MOTOR COVER |
| RUNNING BELT/DECK | RUNNING BELT/DECK | RUNNING BELT/DECK |
| TREAD-BELT TRACKING | TREAD-BELT TRACKING | TREAD-BELT TRACKING |

**Twelve labels on the two LED-console manuals, eleven on the touchscreen one.**
The CT800ENT diagram drops the reading rack and renames three parts; the machine
still has a reading rack, which its own console page calls a "Tablet-friendly
reading rack".

Between 2016 and 2020 only two words change: **SAFETY Button** becomes **SAFETY
KEY**, and **DRINK BOTTLE HOLDER** becomes **BOTTLE HOLDER**. The same two names
drift through the rest of both manuals, which use "safety button", "safety key"
and "safety tether cord" for the same magnetic key.

**The 2012 manual prints no such diagram.** Its equivalent page is a photograph of
the console alone with its features called out, so nothing here is claimed for
that machine.
