Four tools are supplied with each of these machines (the E35-section page heads the list "Tolls"):

| Item | Tool |
| --- | --- |
| #108 | Phillips Head Screw Driver (1 pc) |
| #107 | Short Phillips Head Screw Driver (1 pc) |
| #109 | 12m/m Wrench (1 pc in the E35 list, 2 pcs in the E95 list) |
| #106 | 13/14m/m Wrench (1 pc) |
