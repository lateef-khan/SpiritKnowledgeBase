Four tables, one per step, in inch sizes apart from the last. Item numbers are the
assembly-drawing numbers. **All three printings list the same items in the same
quantities**; only the wording of the type column and one washer description differ.

## Step 1

| Part | Type | Description | Qty |
|---|---|---|---|
| 50 | BOLT / Hex Head Bolt | 3/8" x 135mm | 2 |
| 151 | WASHER / Curved Washer | O3/8" x 23 x 2.0T | 2 |

## Step 2

| Part | Type | Description | Qty |
|---|---|---|---|
| 51 | BOLT / Hex Head Bolt | 5/16" x UNC18 x 5/8" | 7 |
| 72 | FLAT WASHER | O8 x O19 x 1.5T | 6 |
| 99 | CURVED WASHER | O5/16" x 19 x 1.5T | 1 |

**Both CU800ENT printings misprint item 72 here as "O8 x O19 x 5/8"".** Their own
step-3 table gives the same item as O8 x O19 x 1.5T, and so does the CU800 2021 book in
both places. 1.5T is the thickness; 5/8" is the length of item 51 on the line above.

## Step 3

| Part | Type | Description | Qty |
|---|---|---|---|
| 51 | BOLT / Hex Head Bolt | 5/16"X5/8" | 2 |
| 72 | WASHER / Flat Washer | 5/16"X18" (2021) or O8 x O19 x 1.5T (ENT) | 2 |
| 103 | SPLIT WASHER | 5/16" (2021) or O5/16" x 1.5T (ENT) | 2 |

The 2021 book writes item 72 as **5/16"X18"** in this table and as **O8 x O19 x 1.5T**
in step 2 - the same washer, written two ways, and the 18 is a millimetre outside
diameter rather than inches.

## Step 4

| Part | Type | Description | Qty |
|---|---|---|---|
| 58 | SCREW / Philips Head Screw | M5 x 12mm | 6 |

Six screws for the whole step: four hold the console, two the beverage holder. The only
metric fastener in the build.

## What the tables do not print

**No torque figure for any bolt, and none for the pedals.** Nothing in any of the four
tables covers the pedals, the seat or the seat mount slide; those thread or clamp onto
parts already fitted.

The CU800 2012 manual draws its hardware instead of tabulating it and its step 1 is a
different fastener in a different count. See
[that card](../../cu800-2012/assembly/cu800-2012-assembly-hardware-kit.md).

## The 2024 redesign reprints all four tables

The **CU800 2024** manual prints these four tables row for row. It prints the **2021**
descriptions in step three - item 72 as **5/16"X18"** and item 103 as **5/16"** - not
the CU800ENT ones, and item 72 in step two is the correct **ø8 x ø19 x 1.5T** rather
than the CU800ENT misprint.
