Fifteen lines, with quantities as printed:

| Qty | Part |
|---|---|
| 1 | Main Frame |
| 1 | Console Mast |
| 1 | Rear Stabilizer |
| 1 | Seat Back Frame |
| 1 | Front Handle Bar |
| 1 | Handle Bar |
| 1 | Seat Back Cover |
| 1 | Console Mast Cover |
| 1 | Front Stabilizer Cover |
| 1 | Rear Stabilizer Cover |
| 1 | Console |
| 1 | Seat Cushion |
| 2 | Cup Holders |
| 2 | Pedals |
| 1 | Hardware Kit |

**Both printings list the same fifteen lines**, in the same order, although their
parts lists and one hardware table differ - see
[the front handlebar bolt card](spirit-cr800-assembly-front-handlebar-bolt-change.md).

## The touchscreen carton is three lines shorter

The CR800ENT panel drops the **Seat Back Cover**, the **Front Stabilizer Cover** and
the **Rear Stabilizer Cover** and keeps the other twelve. Its build has no step that
fits any of the three. See
[the touchscreen parts card](../../cr800ent-2023/assembly/cr800ent-2023-assembly-parts-included.md).

## What the panel does not say

It gives no carton count, no shipping weight and no box dimensions, and it does not
name the seat carriage - item 4 in the steps - which arrives on the main frame. The
build never fits the Front Stabilizer Cover or the Rear Stabilizer Cover: no step
mentions either, although both are packed.
