Fifteen lines, with quantities as printed:

| Qty | Part |
|---|---|
| 1 | Main Frame |
| 1 | Console Mast |
| 1 | Rear Stabilizer |
| 1 | Seat Back Frame |
| 1 | Front Handle Bar |
| 1 | Handle Bar |
| 1 | Seat Back Cover |
| 1 | Console Mast Cover |
| 1 | Front Stabilizer Cover |
| 1 | Rear Stabilizer Cover |
| 1 | Console |
| 1 | Seat Cushion |
| 2 | Cup Holders |
| 2 | Pedals |
| 1 | Hardware Kit |

**Both printings list the same fifteen lines**, in the same order, although their
parts lists and one hardware table differ - see
[the front handlebar bolt card](spirit-cr800-assembly-front-handlebar-bolt-change.md).

## The touchscreen carton is three lines shorter

The CR800ENT panel drops the **Seat Back Cover**, the **Front Stabilizer Cover** and
the **Rear Stabilizer Cover** and keeps the other twelve. Its build has no step that
fits any of the three. See
[the touchscreen parts card](../../cr800ent-2023/assembly/cr800ent-2023-assembly-parts-included.md).

## What the panel does not say

It gives no carton count, no shipping weight and no box dimensions, and it does not
name the seat carriage - item 4 in the steps - which arrives on the main frame. The
build never fits the Front Stabilizer Cover or the Rear Stabilizer Cover: no step
mentions either, although both are packed.

## Seven Spirit residential recumbents print the same fifteen lines

The **XBR95** 2016, 2018 and 2021 panels, the **XBR25 2019**, the **XBR55** 2019 and
2021 panels and the **XBR55ENT** panel list the same fifteen parts, in the same order,
with the same quantities. Nothing is added and nothing is left out.

**Their hardware is not the CR800 hardware.** The same carton list covers two different
fastener sets: the CR800 step one takes a 3/8" x 135mm bolt and a curved washer, the
XBR machines a 3/8" x 53mm bolt with a flat washer and a cap nut. See
[the XBR hardware card](spirit-xbr-assembly-hardware-kit.md) and, for the XBR25,
[its own hardware card](spirit-xbr25-assembly-hardware-kit.md).

**These seven builds never fit the Front Stabilizer Cover or the Rear Stabilizer Cover
either.** Both are packed and no step mentions either, exactly as on the CR800. Step one
does fit two **End Caps (32)** into the front stabilizer tube, and the panel does not
list those.

## The four 2023 residential recumbents print a shorter panel

The XBR55 and XBR95 2023 panels drop the Console Mast Cover and both stabilizer covers
and add a **Console Tablet Holder** - thirteen lines. The XBR25 2023 panel drops the
same three and adds nothing - twelve. See
[the 2023 parts card](spirit-xbr-2023-assembly-parts-included.md) and
[the XBR25 2023 card](../../xbr25-2023/assembly/xbr25-2023-assembly-parts-included.md).

## The 2024 redesign prints the same fifteen lines

The **CR800 2024** carton lists the same fifteen lines in the same order, all three
stabilizer and seat-back covers included. The touchscreen **CR800ENT 2024** carton is
still three lines shorter and drops the same three; see
[the touchscreen parts card](../../cr800ent-2023/assembly/cr800ent-2023-assembly-parts-included.md).
