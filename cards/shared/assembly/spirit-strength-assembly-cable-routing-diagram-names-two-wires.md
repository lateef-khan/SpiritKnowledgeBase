The CABLE ROUTING DIAGRAM page carries a two-row legend and nothing else:

| No. | Description | Spec | Qty |
|---|---|---|---|
| A | Dry Reed Pipe Connection Wire | | 1 |
| B | Power Line | | 1 |

**Two wires in the whole machine.** A is the lead from the reed switch that the magnet
pulley passes - the repetition counter's sensor. B is the power line that has to be
threaded through the frame in step 1, before the door frame is bolted on.

**The diagram itself is a drawing with two lettered callouts and no route description.**
There is no text on the page saying where either wire runs; the route is only shown, and
on most of these books the page is flat artwork with no text behind it.

The order of work matters more than the diagram. If the power line is not threaded first,
the machine has to come apart - see
[that card](spirit-strength-assembly-thread-the-cable-before-joining-the-frames.md).

## Eight manuals in the same range print no such page at all

The six CSF units and both i-Strength machines have no cable routing diagram. See
[that card](spirit-strength-assembly-no-cable-routing-diagram-on-the-functional-range.md).
