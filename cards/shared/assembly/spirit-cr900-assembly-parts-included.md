Seventeen lines, with quantities as printed:

| Qty | Part |
|---|---|
| 1 | Main Frame |
| 1 | Console Mast |
| 1 | Rear Stabilizer |
| 1 | Seat Back Frame |
| 1 | Front Handle Bar |
| 1 | Rear Handle Bar |
| 1 | Seat Back Cover |
| 2 | Console Mast Covers |
| 1 | Console Bracket Cover |
| 2 | Rear Stabilizer Covers |
| 1 | Console |
| 1 | Seat Cushion |
| 2 | Cup Holders |
| 1 | Rear Handle Bar Cover |
| 2 | Pedals |
| 1 | Hardware Kit |
| 1 | Seat Cover Retaining Bracket |

**All three printings list the same seventeen lines**, in the same order. The 2025
manual moves the panel onto its own page headed PARTS INCLUDED; nothing is added or
dropped.

## What the panel does not say

It gives no carton count, no shipping weight and no box dimensions, and it does not
name the seat carriage frame - item 5 in the steps - even though the build bolts three
separate parts to it. The seat carriage arrives on the main frame.

## The upright carton is a different list

The CU900 panel has **twelve** lines and shares only the main frame, rear stabilizer,
console, console mast, pedals and hardware kit with this one. See
[the upright parts card](spirit-cu900-assembly-parts-included.md).
