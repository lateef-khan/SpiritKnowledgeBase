The parts list names the front stabilizer (B), the rear stabilizer (C), the slide track (D), the saddle (E), the pedals (F, F1 left, F2 right), the pedal base frame (G) with its shaft (G1), and the fixing pin (I).

The fasteners called out on the assembly figures are:

| Item | Description |
| --- | --- |
| J1 | Screw M8x16 |
| J2 | Washer |
| Tool | 14mm wrench |

Every assembly step in this book fastens with the J1 screw, with washers (J2) named only on the slide-track step. The 14mm wrench is the only tool named.
