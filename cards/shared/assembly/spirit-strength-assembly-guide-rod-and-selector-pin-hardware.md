The guide-rod half of the weight-stack step is the same on every machine that prints it:

| Description | Specification | Qty |
|---|---|---|
| Guide rod | | 2 |
| Guide rod fixed plate | | 1 |
| Rubber bumper | Φ64xΦ32xΦ20x35 | 2 |
| Rubber bumper | Φ38xΦ21x10 | 2 |
| Rod end cover | | 4 |
| Selector pin | | 1 |
| Pulley Set with Magnets | Φ89x32 | 1 |

**Two bumper sizes, two of each** - the big Φ64 pair takes the stack's landing, the small
Φ38 pair sits at the rod ends. **Four rod end covers**, two per rod.

**What changes from machine to machine is everything below this**: the plate count and
plate weight of the stack itself, the number of plain pulley sets, and the fasteners that
carry them. Take those from your own step table.

## Two printed counts on this panel are wrong

The **squat/standing calf extension** prints **3** rod end covers where two rods need
four, and the **shoulder press** prints **11** magnet pulleys where the machine has one.
Both figures are on the printed page, not extraction damage. See
[the mismatched counts card](spirit-strength-assembly-fastener-counts-that-do-not-balance.md).

## The lat pulldown uses a different pulley

Its step 1 panel lists **Pulley Set 114x25.8**, not the Φ89x32 that the rest of the range
carries. Do not order a Φ89 pulley against that machine on the strength of this card.

The **CSS-DELT's 2026 revision** (SP-4312, 20260821, whose text layer is a shifted font - read from its OCR supplements and renders) prints this exactly as its 2025 printing does.
