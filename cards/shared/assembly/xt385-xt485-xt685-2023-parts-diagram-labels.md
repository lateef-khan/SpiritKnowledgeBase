**This is the diagram that starts at A. Tablet Holder.** On the XT185-2023 and
XT285-2023 the same letters point at different parts, because that diagram has
no tablet holder and starts at A. LCD Screen.

| Label | Part |
|---|---|
| A | Tablet Holder |
| B | LCD Screen |
| C | Accessory tray |
| D | Console buttons |
| E | Safety stop key |
| F | Cup holders |
| G | Hand pulse sensors |
| H | Handlebar Speed/Incline |
| I | Uprights |
| J | Motor cover |
| K | Belt |
| L | Side rails |
| M | Levelers |
| N | Transport wheels - **XT685-2023 only** |

A to M are the same on all three machines. Only the XT685-2023 diagram carries
the N label; the XT385-2023 and XT485-2023 diagrams stop at M, even though those
two machines do have transport wheels that engage when the deck is folded.
