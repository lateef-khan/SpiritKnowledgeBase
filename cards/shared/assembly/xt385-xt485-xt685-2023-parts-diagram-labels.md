**This is the diagram that starts at A. Tablet Holder.** On the XT185-2023 and
XT285-2023 the same letters point at different parts, because that diagram has
no tablet holder and starts at A. LCD Screen.

| Label | Part |
|---|---|
| A | Tablet Holder |
| B | LCD Screen - the XT685ENT prints **TouchScreen** |
| C | Accessory tray |
| D | Console buttons |
| E | Safety stop key |
| F | Cup holders |
| G | Hand pulse sensors |
| H | Handlebar Speed/Incline |
| I | Uprights |
| J | Motor cover |
| K | Belt |
| L | Side rails |
| M | Levelers |
| N | Transport wheels - **XT685-2023 and XT685ENT only** |

A to M point at the same parts on all four machines, and **B is the only label
whose wording changes**: the XT685ENT writes TouchScreen where the other three
write LCD Screen. It is the same label pointing at the same screen.

The XT385-2023 and XT485-2023 diagrams stop at M, even though those two machines
do have transport wheels that engage when the deck is folded. The XT685-2023 and
the XT685ENT both carry the N label.

**The XT485ENT is not on this card.** Its diagram is a different one - unlettered
callouts, and a different set of parts - and is held on its own card.
