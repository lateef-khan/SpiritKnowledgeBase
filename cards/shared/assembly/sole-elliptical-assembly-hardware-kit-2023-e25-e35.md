The hardware is bagged per assembly step. Numbers in parentheses are assembly-drawing item numbers. The E25-2023 and E35-2023 books print identical checklists, and the assembly steps use identical part numbers, so one card covers both machines.

**Hardware Step 1**

| Item | Description | Qty |
| --- | --- | --- |
| #126 | 3/8" x 3/4" Hex Head Bolt | 2 pcs |
| #169 | O10 x 2T Split Washer | 10 pcs |
| #165 | O3/8" x O19 x 1.5T Flat Washer | 10 pcs |
| #136 | M5 x 10mm Phillips Head Screw | 2 pc |
| #127 | 3/8" x 2-1/4" Hex Head Bolt | 4 pcs |
| #131 | 3/8" x 3/4" Socket Head Cap Bolt | 4 pcs |
| #195 | O10 Star Washer | 4 pc |

**Hardware Step 2**

| Item | Description | Qty |
| --- | --- | --- |
| #122 | 5/16" x 15mm Hex Head Bolt | 10 pc |
| #123 | 5/16" x 1-1/4" Hex Head Bolt | 2 pc |
| #136 | M5 x 10mm Phillips Head Screw | 4 pc |
| #149 | 5/16" x 7T Nylon Nut | 2 pc |
| #160 | O5/16" x O20 x 1.5T Flat Washer | 6 pc |
| #162 | O5/16" x O23 x 3T Flat Washer | 4 pc |
| #164 | 8.5 x O26 x 2.0T Flat Washer | 2 pc |

**Hardware Step 3**

| Item | Description | Qty |
| --- | --- | --- |
| #71 | Switch Wire Cap | 2 pcs |

| #149 | 5/16" x 7T Nylon Nut | 6 pcs |
| #168 | O8 x 23 x 1.5T Curved Washer | 4 pcs |

**Hardware Step 4**

| Item | Description | Qty |
| --- | --- | --- |
| #136 | M5 x 10mm Phillips Head Screw | 18 pcs |
| #139 | 3.5 x 12mm Sheet Metal Screw | 14 pcs |
| #141 | M6 x 10mm Phillips Head Screw | 4 pcs |

The 2026 E35 book prints the same kit except its Step 4 bag holds 10 sheet metal screws instead of 14, so the 2026 hardware card stays separate; see that card for the 2026 machine.
