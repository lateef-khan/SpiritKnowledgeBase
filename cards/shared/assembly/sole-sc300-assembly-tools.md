**This is the SC300 tool list, not the SC200 list: the item numbers differ (149-152 here, 116-119 there).**

| Item | Tool |
| --- | --- |
| #151 | Phillips Head Screw Driver |
| #152 | M8 L Allen Wrench |
| #149 | 13/14mm Wrench |
| #150 | 12/14mm Wrench |

The assembly steps call these out by number only, so this table is what turns "Wrench (149)" into a size.
