**On the stride machines the "incline motor" is the stride motor. It comes out with the console set to 21", goes
back with the console set to 18", and a new one is zeroed to 245 +/- 1 mm.** The XE395's incline motor zeroes to
204 +/- 1 mm; do not mix the two.

1. Remove the slider adjustment by its instructions, and use an **M6 Allen wrench** to release the **socket head cap
   bolt (M8 x 40L)** which secures the fixing piece on the main frame.
2. **Plug in the power supply before removing the incline motor; use the console to set the program to 21"** (figure
   2). If the gear motor is to come off, adjust the resistance control to **max (level 20)**, then cut off the power.
3. Use **two 17 wrenches** to release the **incline set screws (Ø10 x 62L)**, **flat washer (3/8" x 19 x 1.5T)**,
   **nylon nut (M10 x 8T)** and **nylon washers (Ø24 x Ø10 x 3T) x 2 pcs** from the **moving range adjusting
   assembly**.
4. Release the **incline set screws (Ø10 x 40L)**, **flat washer (3/8" x 19 x 1.5T)** and **nylon nut (M10 x 8T)**
   which fix the incline motor.
5. Use a Phillips head screwdriver to release **tapping screws (Ø5 x 19L) x 4 pcs** and the **circuit cover** from the
   main frame.
6. Cut the cable ties of the fixed wires with diagonal pliers, use a Phillips head screwdriver to release the
   **tapping screw (Ø5 x 19L)** from the incline motor, and unplug the wire from the incline motor to the controller
   (**remember the wire position**). The incline motor wire can then be pulled out and the incline motor removed.
7. Before removing the **gear motor**, take out the **steel cable** first.
8. Use a Phillips head screwdriver to release **tapping screws (Ø5 x 19L) x 2 pcs** from the gear motor. Pull out the
   connected wire, then remove the gear motor.
9. **Remember all the wire positions before releasing the controller**, then pull out all the wires and remove
   **tapping screws (Ø5 x 19L) x 2 pcs** from the **control plate** on the main frame.
10. To remove the **spring**, use **two 14 wrenches** to release the **hex head bolt (3/8 x 19L)**, **washer (3/8" x 19 x
    1.5T)** and **nylon nut (3/8" x 7T)** which fix the moving range adjusting assembly.
11. Use a **12 mm wrench** to release the **hex head bolt (5/16" x 1/2")** and **washer (5/16" x 23 x 1.5T)** fixed on
    the **incline rotate axle A Ø17 x 108L**.
12. Pull out the incline rotate axle Ø17 x 108L from the other side, then remove the moving range adjusting assembly.
13. Use a round bar smaller than Ø17 to knock out the **J4FM bushing**.
14. Reassemble in the reverse order as disassembly.
15. When reassembling, the **incline rotate axle must be aligned with the notch plane** before the screw is fastened.
16. Reassemble the incline motor with the **nylon washers (Ø24 x Ø10 x 3T) x 2 pcs**.
17. With the incline motor and all the wires fastened, **plug in the power supply and use the console to set the
    program to 18"**, then fasten the **socket head cap bolt (M8 x 40L)** fixed on the spring, and fasten all the parts.

**Zero a new motor before fitting it (printed in 9-4 Controller, Incline Motor, Tension Motor Problem, not here):**
make sure it has been reset, then **turn the tubing clockwise to the end**. Turn the tubing again but
**counterclockwise two and a half circles**, or let the centre between the two holes be **245 +/- 1 mm**.

9-4 also prints the gear motor cable repair on its own: if the gear motor cable is worn or damaged, remove the
steel cable and use a Phillips screwdriver to remove the **tapping screw 5x19** securing the gear motor cable, and
replace the cable with new.
