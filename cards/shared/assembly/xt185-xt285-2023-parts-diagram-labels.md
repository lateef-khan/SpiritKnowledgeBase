**This is the diagram with no tablet holder.** The letters mean something
different on the XT385-2023, XT485-2023 and XT685-2023, whose diagram starts at
A. Tablet Holder and shifts every later letter along.

| Label | Part |
|---|---|
| A | LCD Screen |
| B | Accessory tray |
| C | Console buttons |
| D | Safety stop key |
| E | Cup holders |
| F | Hand pulse sensors |
| G | Remote handlebar buttons |
| H | Uprights |
| I | Motor cover |
| J | Belt |
| K | Side rails |
| L | Levelers |
| M | Transport wheels |
