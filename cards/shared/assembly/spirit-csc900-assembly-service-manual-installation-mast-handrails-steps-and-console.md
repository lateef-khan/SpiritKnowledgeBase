**Pull the communication wire up while the mast goes down, and do not tighten the horizontal handrail until the
side handrails are on.** Both books print the installation identically, with the same photographs.

**(a) Secure the console mast.** 1. Insert the decoration ring. 2. Wire goes through the console mast. 3. Mounting
bolt - **M8*20 / φ8 flat washer** and **M8*65 / φ8 flat washer**. *Put the communication wire into the console
mast, attach it to the installation hole, and when placing the console mast downward tighten up the communication
wire at the same time to prevent clamping.*

**2. Install the horizontal handrail assembly.** 1. Pass the connecting wire through the hole. 2. Secure the
position of the horizontal handrail. 3. Install the mounting plate and bolts - **M8*30 / φ8 curved washer**.
4. Secure the horizontal handrail **(the bolt won't tighten)** - it is left loose. 5. Install the left and right
handrails - **M8*20 / φ8 curved washer**: *the fixed position is close to the iron plate, and the position of the
bolt bulge is on the inside of the machine*; prevent wire clamping. After the left and right handrails are
installed, tighten the bolts.

**3. Install the steps assembly.** 1. Install the column assembly - **M8*55 / φ8 flat washer**. 2. Fix the left
and right handrails - **M8*20**, three of them called out. 3. Install the step base - **M8*20 / φ8 flat washer**
twice, and an **M8*20 flat head bolt inside the foot stand**. 4. and 5. Install the handrail covers - *install
the inside set screw first* (**ST4.2*16**), then the outside screw (**M4*25**).

**Install the console.** 1. Remove the screw. 2. Push the back cover. 3. Remove the back cover - *the buckle can
be taken off*. 4. The wire goes through the wire hole. 5. Install and tighten the bolts. 6. Plug the wire and put
the extra wire into the tube. 7. Install the back cover. 8. Install the back cover screw.

**After installation, power on testing.** 1. Insert the power wire. 2. Power on. 3. Testing.

The M8*65 agrees with the owner's-manual step text and drawing against that book's M6 table row. The ST4.2*16 and
M4*25 handrail-cover call-outs are printed on the page in both service manuals, including the 2022 book, while
the 2021 and 2024 owner's manuals moved to M4 x 30L; see the two owner's-manual cards on those screws. No
quantities are printed anywhere on these pages.
