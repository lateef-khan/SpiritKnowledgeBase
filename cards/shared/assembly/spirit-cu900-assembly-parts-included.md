Twelve lines, with quantities as printed:

| Qty | Part |
|---|---|
| 1 | Main Frame |
| 1 | Rear Stabilizer |
| 1 | Seat |
| 2 | Seat Bracket Covers |
| 1 | Console |
| 1 | Console Mast |
| 1 | Front Handle Bar |
| 1 | Handle Bar Cover |
| 2 | Console Mast Covers |
| 2 | Pedals |
| 1 | Cup Holder |
| 1 | Hardware Kit |

**All three printings list the same twelve lines**, in the same order. The 2025 manual
moves the panel onto its own page headed PARTS INCLUDED; nothing is added or dropped.

## One cup holder, not two

The recumbent carton holds **2 Cup Holders**, one at each end of the rear handlebar.
This one holds **1**, on the console mast.

## What the panel does not say

It gives no carton count, no shipping weight and no box dimensions. It names a
**Handle Bar Cover**, which the steps call the CONSOLE BRACKET COVER (35), and it does
not name the seat post - item 8 in the steps - which arrives on the main frame.

## The recumbent carton is a different list

The CR900 panel has **seventeen** lines. See
[the recumbent parts card](spirit-cr900-assembly-parts-included.md).
