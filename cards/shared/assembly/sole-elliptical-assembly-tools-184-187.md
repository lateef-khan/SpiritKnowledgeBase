Four tools are supplied with each of these machines:

| Item | Tool |
| --- | --- |
| #184 | 13/14mm Wrench (160mm) |
| #185 | Short Phillips Head Screwdriver |
| #186 | Phillips Head Screwdriver |
| #187 | 12/14mm Wrench (160mm) |

The steps call for two wrenches at once wherever a bolt-and-nut pair is tightened, so keep both #184 and #187 to hand. (The WE books add "(1 pc)" to each line; the contents are the same.)
