Five tools are supplied with each of these machines:

| Item | Tool |
| --- | --- |
| #186 | 13/14mm Wrench (160mm) |
| #189 | 12/14mm Wrench (160mm) |
| #187 | Short Phillips Head Screwdriver |
| #188 | Phillips Head Screwdriver |
| #197 | L Allen Wrench |

The L Allen wrench is new against the 2016 set; it fits the socket cap mast bolts of step 1.
