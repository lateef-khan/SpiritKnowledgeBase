The hardware is bagged per assembly step. Numbers in parentheses are assembly-drawing item numbers. One section covers both the AE55-2011 and the AE95-2011, so one card covers both.

| Item | Description | Qty |
| --- | --- | --- |
| #164 | 3/8" x 19 x 1.5T Flat Washer | 2 pcs |
| #170 | 5/16" x 20 x 1.5T Flat Washer | 4 pcs |
| #181 | 3/8" x 23 x 2T Curved Washer | 2 pcs |
| #180 | 3/8" x 2T Split Washer | 1 pc |
| #141 | M5 x 10mm Phillips Head Screw | 4 pcs |
| #157 | 3/8" x 7T Nylon Nut | 2 pcs |
| #182 | 5/16" x 1.5T Split Washer | 4 pcs |

**Hardware Step 2**

| Item | Description | Qty |
| --- | --- | --- |
| #175 | 25mm Wave Washer | 4 pcs |
| #165 | 3/8" x 30 x 2T Flat Washer | 2 pcs |
| #75 | Grommet | 2 pcs |
| #142 | 3.5 x 12mm Sheet Metal Screw | 8 pcs |
| #132 | 3/8" x 3/4" Hex Head Bolt | 2 pcs |

The step-2 sidebar on the instruction page says 2 wave washers while this checklist says 4; the step text fits two, one per side. This card lists the checklist count and the step card rules for the sidebar.

| Item | Description | Qty |
