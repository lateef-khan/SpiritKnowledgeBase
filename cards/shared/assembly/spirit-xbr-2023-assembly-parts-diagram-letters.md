**Both manuals key the same fourteen letters to the same fourteen names.**

## This diagram names things the older drawing did not

The pre-2023 XBR drawing writes its labels on the picture rather than lettering them, and
it names **fourteen different parts** - including the console mast cover, the crank arms,
the front stabilizer and the main frame, none of which is lettered here. The 2023 list
adds the **Tablet Holder**, the **Adjustable Fan**, the **Console Buttons**, the **Seat
Slide Rail**, the **Rear Frame** and the **Transport Wheel**, and it is the first
residential recumbent page in this family to point at a transport wheel at all. See
[the older diagram card](spirit-xbr-assembly-parts-diagram-callouts.md).

**It still does not point at the levellers**, which the same book's setting-up page tells
you to turn with an M14 wrench - see
[the levelling card](spirit-xb-2023-assembly-levelling-m14-wrench.md).

## The names on the diagram are not the names in the build

The diagram says **Tablet Holder**; the build fits the same item as the **Console Holder
(153)** and the carton panel calls it the **Console Tablet Holder**. Three names for one
part in one book.

## The other two 2023 residential bikes letter shorter lists

The **XBR25 2023** diagram runs **A to M** and has no tablet holder, so every letter from
A on is shifted by one against this list. The **XBU55 2023** diagram runs **A to L**. Do
not read a letter off the wrong machine - see
[the XBR25 card](../../xbr25-2023/assembly/xbr25-2023-assembly-parts-diagram-letters.md)
and [the XBU55 card](../../xbu55-2023/assembly/xbu55-2023-assembly-parts-diagram-letters.md).
