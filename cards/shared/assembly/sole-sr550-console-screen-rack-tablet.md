1. Install the Screen Rack (163) and the Console Holder Assembly (7) with three Button Head Socket Bolts (147), two Curved Washers (149) and Flat Washer (148), using the Combination M5 Allen Wrench & Phillips Head Screw Driver (127).
2. Connect the Computer Cable (44) to the Console (43). Use the Combination M5 Allen Wrench & Phillips Head Screw Driver (127) to install the Console (43) on the Screen Rack (163) with four Phillips Head Screws (85), then secure the Rotary Shaft Cover (169) with two Phillips Head Screws (85).
3. Install the Tablet Holder (166) to the Console (43) with five Sheet Metal Screws (150), using the Combination M5 Allen Wrench & Phillips Head Screw Driver (127).
