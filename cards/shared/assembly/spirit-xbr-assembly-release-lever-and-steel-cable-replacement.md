**Steel cable (58):**

1. Use the **8 mm wrench** to hold the **nut of the gas cylinder**.
2. Use the wrench to release the **head bolt of the release lever (40)** and remove the **steel cable (280L) (58)**. Reverse to refit.

**Release lever (40):**

3. With the steel cable (280L) (58) removed, use the **12/13 mm wrench** to release **one 5/16" x UNC18 x 1-1/2" hex head bolt (188)**, **one Ø5/16" x Ø18 x 1.5T flat washer (76)** and **one 5/16" x 6T nyloc nut (91)**, and the release lever (40) and the **Chen Chin torsion spring (186)** come off the **seat carriage (4)**. Put the torsion spring (186) on the release lever (40) when assembling. Reverse to refit.
4. Check the release lever (40) if the machine's motion feels unsmooth; if it does, adjust the screws.

Six books print this word for word. "Chen Chin" is the manufacturer's name for the torsion spring as printed; "280L" is the cable's 280 mm length.

The gas cylinder itself has its own procedure in every book except the XBR25 2016, which stops at holding its nut here.
