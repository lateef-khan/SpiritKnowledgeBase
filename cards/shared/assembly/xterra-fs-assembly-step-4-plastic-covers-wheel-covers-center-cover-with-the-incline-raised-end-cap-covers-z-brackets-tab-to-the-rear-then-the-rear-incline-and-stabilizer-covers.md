Hardware step 4: **14 M5 x 15 Phillips head screws (115), 8 sheet metal screws 3.5 x 12 (119), 4 M6 x 10 Phillips head screws (122)**. "Note: use the Phillips head screwdriver (157) to tighten the hardware in this step."

1. Install the two wheel covers (79 left, 80 right) with four Phillips head screws (115).
2. Install the center cover (85) with four Phillips head screws (115). **You need to raise the incline to install the center cover.**
3. Install the swing arm end cap covers (81 & 82 left, 83 & 84 right) with the eight sheet metal screws (119).
4. Install the two "Z" shaped metal brackets (24) as shown with four Phillips head screws (122). **The Z brackets should be installed so the tab with the tapped hole is pointing toward the rear.**
5. Install the rear incline cover (87) with two Phillips head screws (115). Install the rear stabilizer cover (88) with four Phillips head screws (115).

Fourteen screws (115): four, four, two and four. Raising the incline for item 2 means the machine has to be plugged in and powered before the last step - the power-up page follows in the console chapter. Word for word the same in both books.
