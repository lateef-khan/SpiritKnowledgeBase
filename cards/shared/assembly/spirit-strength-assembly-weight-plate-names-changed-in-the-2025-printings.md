**The plates did not change part numbers, only descriptions.** A customer reading a 2024
book and a warehouse reading a 2025 book will use different words for the same item, so
order against the item number and the weight, never the description.

| Machine | Item | Earlier printing | 2025 printing |
|---|---|---|---|
| ab crunch / back extension | 47 | `10lb counterweight set` x1 | `10lb top plate` x1 |
| | 48 | `10lb selected iron set` x1 | `10lb counterweight plate` x1 |
| | 49 | `15lb selected iron set` x6 | `15lb weight stack` **x9** |
| | 50 | `10lb selected iron set` x9 | `10lb weight stack` **x6** |
| inner / outer thigh | 053 | `10LB top weight plate` x1 | `10lb top weight stack` x1 |
| | 054 | `10LB weight plate` x10 | `10lb weight stack` x10 |
| | 125 | `15LB weight plate` x4 | `15lb weight stack` x4 |
| leg press / calf extension | 54 | `15LB weight plate` x14 | `15 lb selection counter weight` x14 |
| | 94 | `10 lb counterweight` x1 | `10 lb counterweight` x1 |
| pull-up / dip assist | 073 | `10LB Weight Stack` x1 | `10lb counter weight stack-B` x1 |
| | 074 | `10LB Weight Stack` x2 | `10lb counter weight stack-A` x2 |
| | 075 | `10LB Weight Stack` x5 | `10lb weight stack-C` **x1** |
| | 076 | `10LB Top Weight Stack` x1 | `10lb top weight stack` x1 |
| | 117 | `20LB Weight Stack` x12 | **`15lb weight stack`** x12 |

## The word "counterweight" moved down a plate on the ab crunch / back extension

In the February 2024 book the **top** plate (47) is the `counterweight set` and the one
under it (48) is a `selected iron set`. In the 2025 revision the top plate (47) is the
`top plate` and the one under it (48) is the `counterweight plate`. The drawing order is
unchanged; only the names moved. Asking for "the counterweight" without an item number
gets the wrong plate on one of the two books.

## Two of these are more than a rename

The ab crunch / back extension swaps its 15 lb and 10 lb counts, and the pull-up / dip
assist's twelve plates go from `20LB` to `15lb` and its 075 row from 5 to 1. Both figures
were read from 600 dpi renders of both printings. **The stack total therefore differs
between printings on those two machines**; the totals live on the `section: specs` stack
cards, and a total is only good for the printing it was added up from.

## The leg extension / leg curl runs the change backwards

Its **February 2025** printing prints the new-style names - `15lb counterweight plate`
(84), `15lb top plate` (85), `15lb weight plate` (86) x13. Its **March 2025** printing,
the later of the two, prints `15 lb select iron components`, `15LB top weight plate` and
`15LB weight plate` for the same three items and the same quantities. The plates are the
same; the March book simply did not take the rename.

Nothing in these tables is a spare-part number you can order against; they are item
numbers from the assembly drawing - see
[the unpacking card](spirit-strength-assembly-hardware-split-into-four-steps.md).
