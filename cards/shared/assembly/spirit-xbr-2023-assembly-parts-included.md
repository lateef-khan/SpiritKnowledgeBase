Thirteen lines, with quantities as printed:

| Qty | Part |
|---|---|
| 1 | Main Frame |
| 1 | Console Mast |
| 1 | Rear Stabilizer |
| 1 | Seat Back Frame |
| 1 | Front Handle Bar |
| 1 | Handle Bar |
| 1 | Seat Back Cover |
| 1 | Console Tablet Holder |
| 1 | Console |
| 1 | Seat Cushion |
| 2 | Cup Holders |
| 2 | Pedals |
| 1 | Hardware Kit |

**Both manuals list the same thirteen lines, in the same order.**

## Two changes from the older printings

The XBR55 2019 and 2021, XBR55ENT and XBR95 2016, 2018 and 2021 panels list **fifteen**.
The 2023 panel:

- **adds the Console Tablet Holder**, which is the item the build fits as the **Console
  Holder (153)** with three extra Phillips screws, and
- **drops the Console Mast Cover, the Front Stabilizer Cover and the Rear Stabilizer
  Cover.**

**Dropping the Console Mast Cover is a mistake.** Step two of the same manual still
slides the cables "through the bottom of the **Console Mast Cover (31)**" and tells you
to get its orientation right. The part is fitted and it is not on the panel. The two
stabilizer covers were never fitted by any step in this family, so dropping those two
matches the build.

See [the fifteen-line card](spirit-cr800-assembly-parts-included.md).

## What the panel does not say

No carton count, no shipping weight, no box dimensions. It does not name the **End Caps
(32)** step one taps into the front stabilizer tube, the **Gas Cylinder (57)** step four
fits, or the **Seat Carriage (4)**, which arrives on the main frame.

## The XBR25 2023 panel is one line shorter again

It drops the same three covers and **does not add a tablet holder** - twelve lines. See
[that card](../../xbr25-2023/assembly/xbr25-2023-assembly-parts-included.md).
