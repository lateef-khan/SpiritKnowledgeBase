**This is the SR550 pack, not an SR500 pack: part 121 is named a Split Washer here (Spring Washer in both SR500 books), and only this box holds the screen-rack and console kit (parts 147-150).**

**Hardware Step 1** - main frame and front stabilizer

| Item | Description | Qty |
| --- | --- | --- |
| 109 | O3/8" x O19 x 1.5T Flat Washer | 4 pcs |
| 121 | O10 x 2T Split Washer | 4 pcs |
| 120 | 3/8" x 3/4" Hex Head Bolt | 4 pcs |

**Hardware Step 2** - rear track, folding end assembly

| Item | Description | Qty |
| --- | --- | --- |
| 122 | 5/16" x O18 x 1.5T Flat Washer | 4 pcs |
| 123 | M8 x P1.25 x 12L Button Head Socket Bolt | 5 pcs |
| 129 | M6 x P1.0 x 10L Button Head Socket Bolt | 4 pcs |

**Hardware Step 3** - pedals, connecting cover and seat

| Item | Description | Qty |
| --- | --- | --- |
| 85 | M5 x P0.8 x 10L Phillips Head Screw | 3 pcs |
| 122 | 5/16" x O18 x 1.5T Flat Washer | 6 pcs |
| 123 | M8 x P1.25 x 12L Button Head Socket Bolt | 6 pcs |
| 124 | M6 x 15L Phillips Head Screw | 4 pcs |
| 125 | O1/4" Split Washer | 4 pcs |

**Hardware Step 4** - screen rack, console holder, console and tablet holder

| Item | Description | Qty |
| --- | --- | --- |
| 85 | M5 x P0.8 x 10L Phillips Head Screw | 6 pcs |
| 147 | M8 x 20L Button Head Socket Bolt | 3 pcs |
| 148 | O8 x O19 x 1.5T Flat Washer | 1 pc |
| 149 | O8 x O23 x 1.5T Curved Washer | 2 pcs |
| 150 | 4 x 16mm Sheet Metal Screw | 5 pcs |

The checklist prints the #148 flat washer quantity as "( pc)" with the number lost, but step 4 on PDF p.9 fits exactly one Flat Washer (148), so the box holds one.
