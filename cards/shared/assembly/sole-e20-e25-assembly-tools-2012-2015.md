Five tools are supplied:

| Item | Tool |
| --- | --- |
| #149 | M5 Allen Wrench & Phillips Head Screw Driver (combination) |
| #150 | Phillips Head Screwdriver |
| #151 | 13/14mm Wrench (160mm) |
| #152 | 12/14mm Wrench (160mm) |
| #153 | M8 L Allen Wrench (E20 Only) |

The M8 L Allen wrench is marked E20 Only; the E25 steps never call for it.
