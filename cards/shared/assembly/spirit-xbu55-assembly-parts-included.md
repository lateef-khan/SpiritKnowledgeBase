Fourteen lines, with quantities as printed:

| Qty | Part |
|---|---|
| 1 | Main Frame |
| 1 | Console Mast |
| 1 | Rear Stabilizer |
| 1 | Seat |
| 1 | Front Handle Bar |
| 1 | Handle Bar |
| 1 | Console Mast Cover |
| 1 | Front Stabilizer Cover |
| 1 | Rear Stabilizer Cover |
| 1 | Console |
| 1 | Seat Cushion |
| 1 | Water Bottle Holder |
| 2 | Pedals |
| 1 | Hardware Kit |

**All three printings list the same fourteen lines, in the same order.**

## What the panel does not say

It gives no carton count, no shipping weight and no box dimensions. It does not name the
**Seat Mount Slide (7)**, the **Seat Bracket (6)** or the **Seat Adjustment Knob (86)**
that step four fits, and it does not name the **End Caps (41)** that step one taps into
the front stabilizer tube.

**The build never fits the Front Stabilizer Cover or the Rear Stabilizer Cover.** Both
are packed and no step mentions either - the same defect the CU800 2021 carton has.

The panel calls item 116 a **Water Bottle Holder**; step four calls the same item the
**Drink Bottle Holder**.

## This is not the CU800 carton

The commercial CU800 2021 panel lists **eleven** lines and does not list a seat, a seat
cushion or a front handle bar at all. Same machine shape, different carton. See
[that card](../../cu800-2021/assembly/cu800-2021-assembly-parts-included.md).

## The 2023 XBU55 carton is three lines shorter

It drops the **Seat**, the **Handle Bar** and both stabilizer covers, and adds a
**Tablet Holder** - eleven lines. Its step three still fits a handle bar the panel no
longer lists. See
[that card](../../xbu55-2023/assembly/xbu55-2023-assembly-parts-included.md).
