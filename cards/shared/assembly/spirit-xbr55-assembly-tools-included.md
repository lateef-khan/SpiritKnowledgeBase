Four tools, printed as a TOOLS INCLUDED list:

- **12/14mm Wrench**
- **13/15mm Wrench**
- **13/14mm Wrench**
- **Phillips Screwdriver**

All five printings list the same four, and **no Allen key of any size**. This build uses
hex-head and Phillips heads throughout; nothing in it takes a hex key.

**The two 2023 books number them:** **#112** is the 12/14mm, **#113** the 13/15mm,
**#114** the Phillips screwdriver and **#130** the 13/14mm. Those are the same numbers
the older steps call for without ever saying which size each is - so the 2023 panel is
the only place in this family that maps number to size.

## The XBR95 carton holds three, not four - until 2023

The **XBR95 2016, 2018 and 2021** cartons list **three**: 12/14mm, **14/15mm** and a
Phillips screwdriver. No 13/15mm and no 13/14mm. **Their own steps still call for
wrenches 112, 113 and 130** - four item numbers out of a three-tool panel - so those
three books ask for a tool their carton list does not name. The XBR95 2023 book fixes
it by shipping the XBR55 four. See
[the three-tool card](spirit-cr800-assembly-tools-included.md).

The **XBR25** cartons, 2019 and 2023, hold the same three as the older XBR95 and are on
that card too.

## The upright carton is a different set again

The XBU55 and XBU55ENT cartons hold **three** - 13/15mm, 12/14mm and a Phillips
screwdriver, with no 13/14mm. See
[the upright tools card](spirit-cu800-assembly-tools-included.md).

**A 14mm is in this carton**, in the 12/14mm and the 13/14mm, so the wrench the
levelling sentence asks for is in the box. See
[the levelling card](../../ct800-2016/assembly/ct800-2016-assembly-levelling-pads.md).
