Eleven lines, with quantities as printed, the same in both books:

| Qty | Part |
|---|---|
| 1 | main frame |
| 1 | rear stabilizer |
| 1 | console mast |
| 1 | handle bar |
| 1 | console mast cover |
| 1 | front stabilizer cover |
| 1 | rear stabilizer cover |
| 1 | console |
| 1 | drink bottle holder |
| 2 | pedals |
| 1 | hardware kit |

The seat (19), the seat mount slide (7), the seat adjustment knob (86) and the console bracket cover (42) that the steps fit are not listed; the recumbent 4.0R lists two bottle holders and a seat back frame and a front handle bar this machine does not have. No carton count, weight or box size is printed. The PT edition prints "Size: 108 x 55 x 136 cm, Weight: 60.5 kg" under its last assembly drawing instead - the specs section's fact.
