**This is the DC-adapter power-up, not the SC300's 120-volt direct connection with a power switch.**

When power is connected to the climber the console will automatically power up. These models are powered by an external adapter that provides DC power to the unit. The cord plugs into the unit on the left side near the front.

When it is first powered on the console will perform an internal self-test. During this time all the lights will turn on, the Message Window will show a software version (i.e.: VER 1.0), and the TOTAL STEPS Window will display how many total steps the climber has been used. The Time Window shows how many total hours the climber has been used.

The odometer and time will remain displayed for only a few seconds, then the console will go to the startup display. The dot matrix display will be scrolling through the different workout profiles and the Message Window will be scrolling the start up message. You may now begin to use the console.
