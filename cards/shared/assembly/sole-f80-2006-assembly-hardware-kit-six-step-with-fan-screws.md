Hardware supplied in the box (one flat list, no per-step breakdown in this book):

| Item | Size | Part | Qty |
|---|---|---|---|
| - | 5/16 x 1/2 | Button Head Socket Screw | 12 pcs |
| - | M3 x 18 mm | Self Tapping Screw | 3 pcs |
| - | - | Safety Key | 1 pc |
| - | - | Deck / Belt Lubricant | 1 pc |
| - | - | Combination M5 Allen Wrench & Screwdriver | 1 pc |
| - | - | M6 Allen Wrench | 1 pc |

Eight of the twelve screws fix the uprights and four fix the console support; the three M3 screws fix the fan assembly to the console.
