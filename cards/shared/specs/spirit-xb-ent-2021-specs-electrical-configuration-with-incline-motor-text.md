**Section 3, both books:** CONSOLE - controls all functions of the Bike, with key controls and a
**TFT LCD touch panel**. MAIN CONTROLLER - "the DC power supply for console, incline driver and
tension motor driver, link the console to output appropriate voltages for tension motor that
control the Bike functions". TENSION MOTOR - increases or decreases the brake resistance;
**work voltage DC 4.5 ~ 7.5 V**.

**The XBU55ENT adds a fourth part the XBR55ENT does not print:** "INCLINE MOTOR: This is an AC
motor. User can to control variable elevation by console within main controller." **Neither bike
has an incline motor.** Both books' engineering mode nevertheless carries an *Incline Test* and
an *Incline Calibration* page (the console section), and the XBU55ENT troubleshooting matrix a
row "The incline position doesn't match console" - all inherited from the elliptical/treadmill
template. On a bike, the only motor is the tension gear motor.

The chapter-2 photographs name no incline motor either - what they do name is on
`spirit-xbr55ent-xbu55ent-specs-parts-electronic-parts-named`.

The 800-series ENT books have the same stray incline-motor paragraph:
`spirit-cr800ent-cu800ent-specs-electrical-configuration-induction-brake`.
