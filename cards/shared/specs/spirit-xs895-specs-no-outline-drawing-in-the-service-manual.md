**There is no outline drawing.** The XS895 service manual (titled XS300B-YS006) gives chapter 1,
*Outlines*, exactly one page, and that page carries the heading alone - the render shows nothing
under it, and the next page is already chapter 2. Every other Dyaco-template stepper book in the
repository draws its machine with leader-line labels here; this one does not.

So **the book never names the covers, shrouds, rails or arms of the XS895 as a set**. The names it
does use appear only inside procedures - *Chain cover (R)*, *Console mast cover*, *Handle Bar
Cover*, *Rear Side Case*, *Slide Wheel Covers*, *Incline Cover*, *Incline Bracket*, *Pedal Arm*,
*Swing Arm A/B/C*, *Rear Rail assembly*, *Bushing Housing* - and none carries a number. The
owner's manuals print a parts list; this book does not
(`spirit-climber-specs-parts-which-service-manuals-print-a-parts-list`).

What the book does draw is on the electrical side: a block diagram, display-board, interface-board
and amplifier connections, a motor plug and a circuit diagram
(`spirit-xs895-specs-unit-block-diagram-display-board-driver-board-amplifier-and-fuse`).

The XS895 is an incline stepper, not the XE895 elliptical whose book does print an outline
(`spirit-climber-specs-xs895-is-not-the-xe895`).
