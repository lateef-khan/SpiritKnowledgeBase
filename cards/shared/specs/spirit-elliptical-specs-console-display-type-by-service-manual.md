Every service manual names the display in its console entry, and most add a size on the Window
Display line:

| Display | Machines |
|---|---|
| **LED display** (LED windows with a dot-matrix message centre) | CE800-2016, CE800-2021, CE850-2020, CE900-2021 |
| **LCD display**, no size printed | CE850-2016 |
| **7.5" LCD display** | XE195, XE295, XG400, XE395, XE795-2016, XE895 |
| **7.5" LCD panel, touch** ("LCD touch panel") | XE795-2023 |
| **TFT LCD touch panel**, no size printed | XE395ENT |
| **10.1" TFT display** | CE900ENT |
| **15.6" TFT display** | CE1000ENT |

Two things the table shows that the family names do not: the **CE850 changed from an LCD console
in 2016 to an LED console in 2020**, and the **XE895 - the CE850-2016 manual under another name -
prints a 7.5" LCD size where the CE850-2016 book prints none**. The XE395ENT's touch panel is
described but never measured in its book.

None of these books prints a resolution, a colour or a backlight type. The layouts are the
console cards' (`spirit-xe-2016-console-face-7-5-inch-lcd-with-6-or-10-program-buttons`,
`ce900ent-console-layout-10-1-inch-tft-fan-start-level-stop-enter-and-headphone-socket`,
`ce1000ent-2023-console-15-6-inch-tft-with-nfc-login-and-shortcut-keys`). The bikes' table is
`spirit-bike-specs-console-display-type`.
