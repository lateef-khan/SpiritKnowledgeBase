**The XT385-2023 and XT485-2023 owner's manuals print the same parts list.**
All 223 rows match on item number, description and quantity, so one list serves
both machines. The two machines still differ elsewhere - the XT385 user weight
limit is 375 lbs and the XT485 is 425 lbs - so do not read this shared list as
meaning the machines are identical.

The numbers below are the callout numbers on the Exploded View Diagram on
page 48. The diagram itself is a picture with numbers on it and no text, so
this table is the only readable form of it.

**These numbers are not the XT185/XT285 numbers.** This list calls the Drive
Motor 34; on the XT185 and XT285 the Drive Motor is 027. The XT685 renumbers
again (Drive Motor 20).

**On the printed numbering.** The list is not a continuous run. The numbers
that appear are: 1-6, 8-24, 26-29, 31-73, 75, 77, 79-90, 92-109, 111-115, 117-122, 124, 126-127, 130-136, 139, 141-142, 148, 150-153, 160, 163, 166, 168-174, 178, 300-301. Any number outside that run is not printed
in these manuals at all - it is not a missing page.

Two printing faults, left as printed:

- **Item 52 and item 52-01 carry the same description**, "Console Top
  Cover(big)". Both manuals print it that way. Check the exploded view before
  ordering either one.
- **Item 131 is printed across two lines**, as "Combination Allen Wrench &
  Phillips Head" then "Screw Driver"; it is rejoined here as one description.
