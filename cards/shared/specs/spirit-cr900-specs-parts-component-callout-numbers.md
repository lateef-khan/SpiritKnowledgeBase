**Both recumbent books print the same 29-row table** beside an exploded drawing of the covers, and both
print it under a heading that was never finished: *2. Component Description Change drawing. Add table that
can be modified so I can write English descriptions..* - an editor's note left in the page.

| Part Number | Part Description |
|---|---|
| 1 | Console Assembly |
| 2 | Console Assembly |
| 3 | Book Rack |
| 4 | Deflector Fan Grill |
| 5 | End Cap |
| 6 | Console Chin Cover |
| 7 | End Cap |
| 8 | Seat Back Cover |
| 9 | Console Mast Cover-L |
| 10 | Console Mast Cover-R |
| 11 | Rear Shroud (L) |
| 12 | Rear Shroud (R) |
| 13 | Beam Cover |
| 14 | Rear Shroud (L) |

| 16 | Block |
| 17 | Front Stabilizer Cover |
| 18 | Rear Stabilizer Cover (L) |
| 19 | Rear Stabilizer Cover (R) |
| 20 | Cap |
| 21 | Aluminum Axle End Cap |
| 23 | Drink Bottle Holder (R) |
| 24 | Drink Bottle Holder (L) |
| 25 | Handpulse W/Cable Assembly |
| 26 | Handpulse W/Cable Assembly |
| 27 | Pedal |
| 28 | Release Lever |
| 29 | Off Switch Bracket |

**Four names are printed twice.** Items 1 and 2 are both *Console Assembly*, 11 and 14 are both *Rear
Shroud (L)*, 12 and 15 both *Rear Shroud (R)*, and 25 and 26 both *Handpulse W/Cable Assembly*. The drawing
does not resolve which is which. **Item 22 is not printed.**

**These are call-out numbers on a drawing, not Spirit part numbers, and the list covers only the covers.**
Neither book prints a part number to order against, and neither prints an exploded view of the drive
system, the seat carriage or the electronics - the driver board, generator and speed sensor are named on
the chapter-2 pages instead (`cu900ent-electronic-parts-locations`). The owner's manuals for both machines
print no parts list at all (`spirit-bike-specs-which-manuals-print-a-parts-list`).

**The upright books print a different, 20-row list** under the same heading - side cases, seat covers and
an electronic module, with no beam cover or off switch bracket (`cu900ent-component-callout-numbers`).
