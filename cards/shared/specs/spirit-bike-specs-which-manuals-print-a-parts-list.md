**Eight of the thirteen print both an exploded view and a numbered parts list.
Five print neither.**

| Manual | Exploded view | Parts list | Header printed above the list |
|---|---|---|---|
| CR800-2021 | p. 40 | p. 41 | `CR800-XR880-SB023-01 Part List_SPIRIT` |
| CR800-2023 | p. 40 | p. 41 | `CR800-XR880-SB023-01 Part List_SPIRIT` |
| CU800-2021 | p. 40 | p. 41 | `CU800-XU880-SB023-01 Part List_SPIRIT` |
| CR800ENT-2023 | p. 46 | p. 47 | `CR800ENT Part List_SPIRIT` |
| CU800ENT-2022 | p. 46 | p. 47 | `CU800ENT Part List_SPIRIT` |
| CU800ENT-2024 | p. 52 | p. 53 | none - just `PARTS LIST` |
| CR900-2025 | p. 36 | p. 37 | none - just `PARTS LIST` |
| CU900-2025 | p. 35 | p. 36 | none - just `PARTS LIST` |
| **CR900-2018** | **none** | **none** | - |
| **CR900ENT-2021** | **none** | **none** | - |
| **CU800-2012** | **none** | **none** | - |
| **CU900-2018** | **none** | **none** | - |
| **CU900ENT-2021** | **none** | **none** | - |

For the five with none, the table of contents ends at the warranty, and a search
of the whole document returns no `Main Frame ... 1` row, no *nylon nut*, no *hex
head bolt* row and no item-number column. **The only part numbers those five give
are the step-by-step hardware callouts inside the assembly chapter**, which cover
fasteners for assembly and nothing else. For a CU900ENT the service manual fills
part of the gap - see `cu900ent-outlines-part-names` - but it too carries no
numbered parts list.

## The document code above the list is not the model number

Five of the eight print a header line above the first row, and three of those
carry a second, factory-side code the Spirit model name never uses:

- `CR800-XR880-SB023-01 Part List_SPIRIT` above the CR800-2021 and CR800-2023
  lists.
- `CU800-XU880-SB023-01 Part List_SPIRIT` above the CU800-2021 list.
- The CR800-2023 exploded-view page is headed **`XR880-SPIRIT 爆炸圖`** and the
  CR800ENT-2023 exploded-view page **`XR480-SPIRIT 爆炸圖`** - the drawing labels
  were left untranslated (爆炸圖 is Chinese for *exploded diagram*), and note that
  the ENT drawing says **XR480**, not XR880.

**These are document and factory codes. None of them is a serial number, and none
of them is a part number to quote to a customer.** The CR800ENT-2023 and
CU800ENT-2022 lists also print a trailing **200710** after their last row; it is
not an item.

The three newest books - CU800ENT-2024, CR900-2025 and CU900-2025 - dropped the
code line and print only `PARTS LIST`.

## Do not read one bike's list for another

The recumbent and upright lists are almost entirely different documents, even
between a CR and CU pair whose manuals are otherwise 77% to 90% identical.
Measured at word level over the parts pages alone, CR800-2021 against CU800-2021
is **10.5%** alike, CR800ENT-2023 against CU800ENT-2022 **18.4%**, and CR900-2025
against CU900-2025 **18.7%**. The recumbent carries a seat carriage, an aluminium
seat track, eight seat track wheels and a seat back frame with no upright
equivalent.

**Item numbers are not stable across books either.** The Induction Brake is item
**055** in the CR800ENT-2023 list and item **20** in both CU800ENT lists; see
`spirit-bike-specs-generator-brake-or-induction-brake`.

## The two CR800 printings are the same list with five changes

The CR800-2021 and CR800-2023 lists carry the same document code and the same
items in the same order, with two items removed and three quantities altered -
see `spirit-cr800-specs-parts-list-2021-vs-2023` before quoting a quantity.
