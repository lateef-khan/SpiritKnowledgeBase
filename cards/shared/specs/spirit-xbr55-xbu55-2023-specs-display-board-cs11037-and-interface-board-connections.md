**Display board.** The XBR55 diagram is marked **CS11037-02ES** and the XBU55 diagram
**CS11037-01ES**; the photographs in both books show a sticker reading **CS11037-01ES** on a
board silkscreened **CS11037 Rev 1.1**. Same connector map on both:

| Connector | Lead |
|---|---|
| **AJ1 / BJ1** | SPEAKER |
| **J3** | FAN |
| **J2** | HR HANDLEBAR |
| **J4** | USB CHARGER |
| **J9** | WIRELESS HEART RATE RECEIVER |
| **J1** | KEYS BOARD |
| **J12** | SYSTEM CABLE |

**Interface board** (the small board the grip leads meet): **J2** SYSTEM CABLE, **J3** HANDGRIP
PLUSE SENSOR (spelt so). No board number is printed for it.

Neither book prints pin definitions for these sockets; the one pin list is the eleven-way
"display board to controller board" header photographed on the error page,
`spirit-xbr55-xbu55-2023-specs-display-to-controller-11-pin-definition`.
