Four different consoles sit across the sixteen commercial bikes, and only two of
them state a screen size.

| Machines | What the manual calls the display |
|---|---|
| CR900ENT-2021, CU900ENT-2021 | **10.1" touchscreen display with multiple viewing modes** |
| CR900-2025, CU900-2025 | **Premium ultra-bright white LED display** |
| CR900-2018, CU900-2018 | **Premium, ultra-bright blue LED display** |
| CU800-2012 | **Large Blue-LED Matrix Window** plus a **20-Character Message Center** |
| CR800-2021, CR800-2023, CU800-2021, **CR800-2024**, **CU800-2024** | LED Data Display Windows plus a Dot Matrix Message Center - **no colour and no size given** |
| CR800ENT-2023, CU800ENT-2022, CU800ENT-2024, **CR800ENT-2024** | "Touchscreen" - **no size given anywhere in the book** |

**10.1 inches is the only screen dimension any of the sixteen manuals prints,
and it belongs to the CR900ENT and the CU900ENT only.** Do not quote it for a
CR800ENT, a CU800ENT, or any LED machine.

## The 900 LED display changed colour between 2018 and 2025

The CR900 and CU900 books print the same marketing callout page in both
generations, and the display line is the one thing on it that changed:

- **2018 printings: "Premium, ultra-bright blue LED display".**
- **2025 printings: "Premium ultra-bright white LED display".**

Everything else on the page is the same in both - an integrated adjustable fan
for workout comfort, an easy to read lap counter, an LED heart rate graph, a
large LED matrix window to track workout progress, and a tablet friendly reading
rack holder. If a customer says the display on their CR900 is blue and yours is
white, that is the generation, not a fault.

## Where the full console drawing is described

**This card answers the display specification only** - what kind of panel, what
colour, what size. The call-out drawing each manual prints around it, with the fan
key, the Scan buttons, the message centre and the USB charger, is a console
question and lives in the `console` section:

- `spirit-ce-console-blue-led-console-face` - the CU800-2012 drawing, with its
  Large Blue-LED Matrix Window, 20-Character Message Center, Heart Rate % Profile,
  Easy-Touch control buttons and cargo compartment.
- `spirit-ce-console-led-console-face` - the CR800-2021, CR800-2023 and CU800-2021
  drawing, with two Scan buttons, a dot matrix message centre and a USB charger.
- `cu900ent-console-layout` - the CU900ENT console, from the service manual.

The CR900ENT-2021 and CU900ENT-2021 marketing page pairs the 10.1" touchscreen
with an integrated adjustable fan, a tablet friendly reading rack holder and an
accessory tray. The CR800ENT-2023 and CU800ENT-2022 console page labels a
Touchscreen, an adjustable fan angle, a tablet-friendly reading rack, a USB
charging port and Start, Stop and Level controls - **but never a size**.

## The 2024 reissue changed nothing here

The CR800-2024, CU800-2024 and CR800ENT-2024 books are the New Black Units
reissue, and each keeps its predecessor's display wording exactly. The two LED
books still label only "LED Data Display Windows" and a "Dot Matrix Message
Center" with no colour and no size, and the CR800ENT-2024 still says only
"Touchscreen". **A search of all three books, native text and the OCR of every
page, returns no inch measurement that is not a thread callout.**

One slip is worth knowing about: the CR800-2024 troubleshooting table reads "LED
displays not bright, incomplete or imperfect. 1. **LCD** displays are broken." The
book uses both words for one screen; so does the CRW800-2024 rower - see
`spirit-climber-rower-2024-specs-console-display-type`. It is a house habit, not
a description of two different panels.

## What none of the sixteen owner's manuals gives

**No Spirit commercial bike owner's manual states a screen resolution, a
brightness figure, or the operating system the console runs on.** Where an ENT
book names iOS or Android it is describing the *customer's phone* - the minimum
for the Spirit+ App, or a Screen Mirroring note - never the console.

**Panel technology is stated in exactly one place, and it is not an owner's
manual.** The CU900ENT *service* manual calls its screen a **10.1" TFT Display**
(see `cu900ent-console-layout`). No owner's manual in this range says TFT, LCD or
OLED about any machine. Do not carry the CU900ENT's TFT description across to a
CR800ENT or a CU800ENT.

For anything beyond the colour, the size and the word *touchscreen*, go to Spirit
Fitness. See `spirit-bike-specs-no-specification-table` for the rest of the
missing specification data.
