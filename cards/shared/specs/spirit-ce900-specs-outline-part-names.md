Both books print the same two drawings with the same English labels; the CE900ENT adds the Chinese
name of each part.

**p. 5, the shrouded machine:** Console Assembly, Drink Bottle Holder, Chin Cover, Console Mast
Cover, Handle Bar Cover, Side Case, Pedal, Cover, Pedal Arm Cover, Slide Wheel Cover, Foot Pad.

**p. 6, the frame with the shrouds off:** Console Mast, Seat Handle Bar (L) and (R), Handpulse
Assembly (labelled twice, one per grip), Crank Arm Assembly, Main Frame, **Generator/Resistance**,
Pedal Arm (R) and (L), Connecting Arm (R) and (L), Rail, Aluminum Track.

**Generator/Resistance is the label in both books**, including the CE900ENT, whose own electrical
configuration calls the same unit an *EMS flywheel*, whose block diagram calls it a *brake
flywheel*, and whose circuit diagram feeds the machine from a 24 V adapter rather than a
generator. The skeleton drawing was carried over from the generator machine unchanged.

The Outlines chapter prints **no dimensions, no machine weight and no user weight limit** in
either book. Both books also carry a 33-row *Component Description* list of the plastic parts
inside their disassembly chapter, which is a parts page rather than an outline.
