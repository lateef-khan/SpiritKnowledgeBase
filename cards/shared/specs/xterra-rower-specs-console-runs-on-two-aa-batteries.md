**Two AA cells.** Six rower books name the type; only the two magnetic rowers print a temperature block with it.

| Book | What it prints | Temperature block |
|---|---|---|
| ERG160 | "BATTERY TYPE 2 AA or UM 3" (UM 3 is the JIS name for an AA cell) | operating 0 to +40 C (32 to 104 F); storage -10 to +60 C (14 to 140 F) |
| ERG180 | "Battery Type 2pcs of Size AA", under a page headed SPECIFICATIONS | operating "0c - +40c"; storage "-10c - +60c" |
| ERG220 | "Insert the 2 AA batteries to activate the Console"; "install 2 AA batteries in the battery case on the back of the Console (95)" | none |
| ERG550W | "Install 2 AA batteries (included)" | none |
| ERG600W | "Install 2 AA batteries (included)"; "This meter uses 2 AA batteries, which are included ... change both of them. Do not mix battery types. Do not mix old and new batteries" | none |
| ERG650W | "Place the 2 AA batteries into the Console (No. 54)" at assembly step 3 | none |

The ERG550W, ERG600W and ERG650W books say the cells are **included**; the ERG160, ERG180 and ERG220 books do not
say either way. Removing the cells resets every stored value on the ERG220 and ERG600W ("Changing the batteries will
reset all values"); a lit battery symbol (ERG160, ERG180) or an abnormal display (ERG220: re-install the batteries)
is the books' cue to replace them - the errors section holds those tables. The ERG160 block also prints "LOGO
SIZE:55.2*9.3MM", a layout note left in the file, not a specification.

The same blocks list the display ranges (TIME 0:00 to 99:59, COUNT 0 to 9999, DISTANCE 0 to 9999 metres, SPM 0 to
999, and on the ERG180 PULSE 60 to 240 BPM); the console section holds those.

Different figures on other Xterra rowers: the ERG500 takes **two AAA** cells
(`erg500-2018-specs-console-runs-on-two-aaa-batteries`), the ERG750W book never names its cells
(`erg750w-2025-specs-console-battery-type-not-printed`), and the ERG400, ERG700 and ERG800W run from an external
adapter. Six Xterra bikes run their consoles on two AAA cells
(`xterra-specs-console-runs-on-two-aaa-batteries-with-a-0-to-40-c-operating-range`); the Spirit air rower's console
runs on two C cells (`crw800-2024-specs-resistance-system`).
