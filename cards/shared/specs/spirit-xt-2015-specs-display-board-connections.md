The board is silkscreened **AA01382 V1.0**. Section 6.1 is one photograph with these call-outs:

**Components named**: Bluetooth Module, Main IC, two Display ICs, Heart Module.

**Connections named**: Connection with Handrail Pulse; Connection with 4-pin of AMP wires; Connection with
6-pin Main control wires; Connection with Quick incline handrail buttons; Connection with Quick speed
handrail buttons; Connection with Wireless heart receiver; Connection with FAN (twice, one per fan);
Connection with KEY BOARD; Connection with Safety key.

No connector numbers and no pin definitions are printed for any of them; the only pin table in these books
is the 6-pin main control cable, on its own card. Section 6.2 "Display Board PCB Component Locations" is
a bare photograph.

The XT385 / XT485 books of the same year have a different console (LCD with LINE OUT, no Bluetooth) and
print only a bare photograph for this section.
