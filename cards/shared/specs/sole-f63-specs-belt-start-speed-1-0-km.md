**The F63/UF63-2006 belt starts "at 1.0 km" (the book's words; read as 1.0 km/h).** This book prints no calibration section and no other speed figure; its rapid speed keys (2 through 10) are console-section content. It differs from the 0.5 mph start the other legacy books print, so it has its own card.
