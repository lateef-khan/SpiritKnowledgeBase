The console is the **DT-3268 universal spinner bike console**.

| Value | Range |
|---|---|
| Cadence bar graphic | 0 ~ 199 rpm |
| RPM | 0 ~ 199 RPM |
| Speed | 0 ~ 99 KM/H |
| Pulse | 30 ~ 240 BPM (needs a chest belt) |
| Time, count down | 1 ~ 99 minutes |
| Time, count up | 00:01 ~ 99:59 |
| Protocol | BLE 4.0 |

The console assembly is a computer console, a magnet, one chest belt and a speed sensor transmitter. The sensor in the transmitter counts how many times the magnet on the crank passes it, then sends a coded signal with speed and cadence to the console.
