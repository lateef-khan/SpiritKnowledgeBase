The numbers come from the customer-service model table (`dbo.MODEL` in `CustService`); a manual rarely prints one. A row reading *not confirmed* has no settled number yet. Two numbers in one cell are one machine in two colours (the 2023 owner's manual file carries 551223, the service manual file 551123).
