Both walking-treadmill books print, under the heading *Display and Key Distribution Specs*:

| Window | Range |
|---|---|
| Speed | 1.0 to 13.0 (Imperial System: 0.6 to 8.0 mph) |
| Time | 0:00 to 99:59 |
| Distance | 0.00 to 99.99 |
| Calories | 0 to 9999 |
| Heart Rate | 50 to 200 |
| Steps | 0 to 9999 |

The speed line is the machine's working range: the *How to use the treadmill* page says "The machine will begin at a
speed of 1.0-13.0Km/h (0.6-8.0mph)" and "The treadmill will then start at .6 MPH"; the Quick Start says "The starting
speed is 0.6mph". The + and - keys stop responding "once the maximum speed limit is reached" and "once the minimum
speed limit is reached"; the Speed 3 and Speed 6 shortcut keys jump to 3 and 6 km/h or mph. The keys themselves are
described on the console section's cards.

The WS300 adds an incline range on the same page (`ws300-2023-specs-incline-range-0-to-10-percent`); the WS200
prints none because it has no incline (`ws200-2023-specs-no-incline`). Neither book prints a specification table.
