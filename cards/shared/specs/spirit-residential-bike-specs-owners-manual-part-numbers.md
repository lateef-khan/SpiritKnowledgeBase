**Only six of the fourteen manuals print an identifying number of their own, and
they print it in two different formats and two different places.**

| Manual | Number printed | Where |
|---|---|---|
| XBR55 2019 | `P#: 551118` | back cover |
| XBU55 2019 | `P#: 551218` | back cover |
| XBR25 2023 | `XBR25_251123_OM_20240418` | front cover, bottom left |
| XBU55 2023 | `XBU55_552123_OM_20240412` | front cover, bottom left |
| XBR55 2023 | `XBR55_551223_OM_20240715` | front cover, bottom left |
| XBR95 2023 | `XBR95_951123_OM_20240715` | front cover, bottom left |
| XBR95 2016, XBR95 2018, XBR25 2019, XBR55 2021, XBU55 2021, XBR95 2021, XBR55ENT 2021, XBU55ENT 2021 | **none** | - |

The 2023 code is not a part number in the same sense: it is a document filename
stamped on the cover, and its trailing eight digits are an **export date in 2024**,
later than the warranty effective date inside the book. Do not read it as the
model year.

## 551150 is not printed in either ENT manual

The XBR55ENT 2021 and XBU55ENT 2021 files both arrive named `..._551150_OM_...`,
which makes it look as though Spirit gave one part number to both books. **Neither
document prints 551150 anywhere.** A search of the full text of both PDFs for
`551150` and for `P#` returns nothing, and their front covers carry only
`XBR55ENT RECUMBENT BIKE OWNER'S MANUAL` and `XBU55ENT UPRIGHT BIKE OWNER'S
MANUAL`. The number exists only in the filenames. **Do not quote 551150 to a
customer as either manual's part number.**

## Every pre-2023 book dates itself on its back cover instead

All ten books printed before 2023 stamp a revision line under the Jonesboro
address, and that stamp is the reliable way to tell two printings apart:

| Manual | Copyright | Revision |
|---|---|---|
| XBR95 2016 | © 2016 | 01.26.2016 |
| XBR95 2018 | © 2018 | 08.22.2018 |
| XBR25 2019 | © 2018 | 02.04.2019 |
| XBR55 2019 | © 2018 | 02.04.2019 |
| XBU55 2019 | © 2018 | 02.04.19 |
| XBR55 2021 | © 2021 | 02.04.2021 |
| XBU55 2021 | © 2021 | 02.04.2021 |
| XBR95 2021 | © 2021 | 03.16.2021 |
| XBR55ENT 2021 | © 2021 | 11.30.2021 |
| XBU55ENT 2021 | © 2021 | 11.30.2021 |

The XBU55 2019 stamp is written `02.04.19`, two digits where every other book uses
four; it is the same date as the XBR55 2019 stamp. The four 2023 books print no
revision line at all - their back cover reads only `©2023 All Rights Reserved` and
the model name, so the front-cover code is the only version marker they have.
