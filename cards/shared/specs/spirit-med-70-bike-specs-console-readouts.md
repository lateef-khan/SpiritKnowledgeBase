The Readouts block names nine values, the same in all three books:

Time and Segment time remaining, RPM, Watts (Left and Right), METS, Symmetry Index, Heart Rate,
Calories, Work Level.

This is the spec sheet's list of what the machine measures; how each is paged through in the message
window is a console question. **Watts (Left and Right) and Symmetry Index are what mark this
platform out** - the Symmetry program reads the two pedals separately and the Watts readout is per
leg. The Basic Information page lists the same set with *Pulse* for Heart Rate and *Average watts
(left and right leg)* added.

**The 8.0U and 8.5R specification pages carry no Readouts block at all**, so this list must not be
quoted for them; their console shows the same kinds of value on a touchscreen. The 7.0T treadmill's
list is a different eleven (`70t-2026-specs-console-readouts`).
