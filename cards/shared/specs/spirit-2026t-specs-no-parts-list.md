**Neither manual prints a parts list.** Each has an Exploded View Diagram - a
drawing with bare callout numbers on it - and the Warranty section begins on the
very next page. There is no table anywhere in either book that says what a
callout number is, and neither book prints a manufacturer part number for any
component.

So a callout number read off one of these diagrams **cannot be resolved from the
owner's manual**. Get the parts list from Spirit Fitness or from a service
manual, and say the owner's manual does not contain one.

**Do not resolve them from the 4.0T list either.** The 2026 4.0T manual does
print a full parts list, but it is that machine's own numbering for a different
frame; see `40t-2026-specs-parts-list`.
