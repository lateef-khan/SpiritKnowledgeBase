Both CRW800 service manuals print the same two outline drawings with the same labels - the 2016
book as native text, the 2020-version book as a flattened image. **No item numbers, part numbers
or quantities are printed**; these are names on leader lines.

**Drawing 1 - the assembled rower, fifteen labels**

| Left column | Right column |
|---|---|
| Chain Cover (L) | Console Assembly |
| Latch | Chain Cover (R) |
| Handle | Galvanized iron net |
| Connecting Cover | Controller Assembly |
| Seat | Front Stabilizer |
| Aluminum Track | Pedal |
| Rear Stabilizer | End Cover |
| Adjustment Foot Pad | |

The **Galvanized iron net** is the mesh guard over the fan housing, the **Latch** is the handle
hook on the chain cover, and the **Controller Assembly** is the handlebar with the wireless
resistance buttons - the same names the replacement chapters use.

**Drawing 2 - the bare frame, six labels**: Console Holder Assembly, Flywheel & Fan, Flywheel
Pulley / Latch / Spring Latch (one leader), Hook, Pedal, Seat Attaching Board.

The XRW600 book, which is 89% this text, redraws the page with different names - Nylon Net for
the mesh, Handlebar Cover, Chain Cover Foam, Handgrip End Cap and Rubber Foot
(`xrw600-2019-specs-outline-part-names`). The water rowers have their own outline
(`crw800h2o-outlines-part-names`).
