The troubleshooting procedure matrix prints two rows for the chest belt in all five service manuals:

*Condition:* Wireless lost its function (no pulse displayed on monitor).

| Reason | Solve |
|---|---|
| 1. Chest belt not worn properly | 1. Check the chest belt has proper contact with the skin and is oriented correctly |
| 2. Distance is too far and exceeds the range of the receiver | 2. Use the chest belt in front of the console, within **3 feet** |
| 3. Chest belt battery is weak or dead | 3. Replace with a new lithium battery, type **CR2032** |

*Condition:* Chest belt too close to the treadmill. *Reason:* Weak battery. *Solve:* Replace with a new lithium battery, type CR2032.

The second condition is printed exactly so - "too close" - with the same weak-battery remedy; it reads as a misprint for a belt that only works when held close. The grip counterpart is `xterra-treadmill-errors-hand-pulse-not-working-two-hands-cable-board`. Which straps the console pairs with (analogue, Bluetooth) is a console card.
