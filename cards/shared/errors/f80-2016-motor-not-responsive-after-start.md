1. If the belt moves but stops after a short time and the display shows **"E1"**, run a calibration.
2. If you press start, the belt never moves and the display then shows **E1**, contact service.

**Twenty-two stencil owner's manuals print this same two-way E1 row** in their SERVICE CHECKLIST tables (locator): "If the belt moves, but stops after a short time and the display shows E1, run calibration" / "If you press Start and the belt never moves, then the display shows E1, contact service." Three books print a different variant with its own card: the F60-2020 book prints only the contact-service branch with no code (`f60-2020-errors-motor-never-moves-no-code`); the TD80 prints bare LS with a sensor check (`td80-2019-errors-motor-not-responsive-ls`); the ST90 books print both branches under Err (`st90-2021-err-after-pressing-start`, `st90-2023-err-after-pressing-start`).
