**This is the TR150 and TRX1400 wording of the row**; the TR260 book names a console connector and the TRX books a 12-pin computer connector (`tr260-2023-errors-no-display-when-safety-key-inserted-console-cable`, `xterra-trx-errors-no-display-when-safety-key-inserted-12-pin-computer-cable`).

*Condition:* When insert safe key, no display on monitor.

| Reason | Solve |
|---|---|
| 1. Haven't switched the ON/OFF switch | 1. Switch the AC switch |
| 2. Inserted the safe key in the wrong position | 2. Insert the safe key in the right position |
| 3. **5-PIN main control wires** not plugged in properly | 3. Check the wire and connect again |
| 4. 5-PIN main control wires are broken | 4. Replace 5-PIN main control wires |
| 5. Fuse on controller is blown | 5. Replace fuse or controller |
| 6. Varistor on controller is blown | 6. Replace varistor or controller |
| 7. Safety equipment is broken (open circuit) | 7. Replace safety key device |
| 8. Other components are faulty | 8. Replace console |

The opposite fault - the treadmill runs with no key in - is `xterra-treadmill-errors-runs-without-safety-key-safety-device-shorted`. E0 with the key in is `xterra-treadmill-errors-e0-safety-module-plus-12v-loop`.
