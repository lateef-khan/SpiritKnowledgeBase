E0 means the safety key is not in place or the safety switch is faulty on every Xterra treadmill whose owner's manual prints it. The books word it three ways:

| Books | Printed meaning | Printed checks |
|---|---|---|
| TR150, TR200, TR260, TRX1000 (2021 batch) | Safety Switch Malfunction | 1. If safety key switch is placed properly? 2. Is safety harness in the console connected properly? Any connector damaged? 3. Is safety switch defective? |
| TR65 | Safety Switch Malfunction | 1. If safety key is placed properly? - Place properly. 2. Is safety key defective? - Replace safety key |
| TR300 | Safety switch is open. A reminder of putting on the safety key | none |
| TRX2500, TRX3500, TRX4500 | Safety Key is not in place. A reminder to put in the safety key | none |
| TRX1400 | Safety switch is open. Put on the safety key to eliminate the error | none |

The 2021-batch books print "safety harness I the console" - the "I" is a typo for "in".

Where a service manual exists the same code has a full procedure: `xterra-treadmill-errors-e0-safety-module-plus-12v-loop` (TR150, TRX1400) and `xterra-treadmill-errors-e0-safety-key-device-buzzer-test` (TR260, TRX2500, TRX3500, TRX4500). The TR6.6 and TR6.4 print no E0 at all, and the TR75H and TR95H show three dashes rather than a code for a missing key (`xterra-tr-errors-jkexer-console-shows-three-dashes-safety-key`).
