**Meaning**: the console does not light up when the machine is powered on.

1. Check that the power plug, the fuse and the control wires are all connected tightly.
2. If the power light is on, replace the control wire between the console and the controller.
3. If the power light is off, replace the controller. A new controller needs a calibration.
4. If it still does not light, replace the console.

On a TT9 or ST90 the same fault points at the inverter instead of the controller: check the power plug, fuse and control cable; if the power indicator is on, replace the control cable between console and inverter; if it is off, replace the inverter; then replace the console.
