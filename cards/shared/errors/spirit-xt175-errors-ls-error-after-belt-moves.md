**This is the LS row for a belt that did move - not the row for a belt that never moved at all** (`spirit-xt175-errors-ls-error-no-belt-movement-pwm-led`), and not a Sole LS (`sole-ls-error`).

1. Run the calibration procedure.
2. Adjust the speed sensor.
3. Check the roller for a magnet (`spirit-xt175-errors-check-roller-for-magnet`).
4. Check the wire harness for continuity (`spirit-xt175-errors-checking-wire-harness-continuity`).
5. If the roller has a magnet and the sensor adjustment does not fix it, replace the speed sensor.

Printed identically in the 2008 XT dealer manual and the CT800 2016 service manual's *Treadmill Troubleshooting* chapter. The speed sensor adjustment the XT manual sets at about 1/16 inch from the front roller is a maintenance procedure; the CT800 2016's fuller LOW SPEED pages check the same sensor with a 3 mm gap (`ct850-2016-low-speed-check-rpm-sensor`). The calibration procedure is a console fact.
