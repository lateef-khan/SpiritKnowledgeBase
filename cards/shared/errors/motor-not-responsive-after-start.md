1. If the belt moves but stops after a short time and the display shows **"LS1/LOW SPEED"**, run a calibration.
2. If you press start, the belt never moves and the display then shows **LS1/LOW SPEED**, contact service.

**This manual names the code LS1/LOW SPEED and points at "section 8.2 on Error Message: LS1/LOW SPEED". There is no such section in this manual** - section 8.2 is E1, and no LS code appears anywhere else. The equivalent F80 manual prints E1 in this row instead. Treat the symptom as the E1 no-RPM-signal path.

**Nineteen older owner's manuals print this same two-way row with the code as plain "LS", covering forty-one machines.** The 2011–2013 books (AF63/65, AF80/83/85, AS77, ATT8, F60-2013/2014, F63-2013/2015, F65-2013/2014, F80/F85-2013, S77-2013, TT8-2013, TT8C-2011) say "run calibration" / "contact service"; the 2009/2010 books (WF63, WF80/83/85, WS73/77, WTT8) add "(See procedure on next page)"; the 2007/2008 books (UF80/83/85, VF80/83/85, VS73/77, VTT8) say "try re-calibrating the treadmill (see calibration procedure below)". Same fault, same split, same remedies — corroborated in each book's SERVICE CHECKLIST table (e.g. AF63/AF65-2011 PDF p. 31, WF63-2009/2010 PDF p. 26). The TT9-2018 prints the same branches with E1 instead and has its own card (`tt9-2018-errors-e1-motor-not-responsive`); the 2006-family and VF63-2008 books print "Make certain clock is running" instead (`sole-treadmill-errors-clock-running-motor-not-responsive`).
