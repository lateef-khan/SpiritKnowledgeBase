**These are battery consoles, so the first cause is the batteries and there is no adapter or outlet to check** - the recumbent-bike twin of this row starts with "adapter not plugged in" (`xterra-errors-monitor-does-not-display-adapter-then-computer-wires`) and does not apply here.

The row as the seven owner's manuals print it:

| Problem | Cause | Solution |
|---|---|---|
| Monitor does not display | Batteries not installed | Install batteries |
| | Computer wires not connected | Ensure the computer wires are connected properly at the upright and computer |

Wording differs by book and nothing else does: the ERG500, ERG550W, ERG600W, ERG650W and ERG750W print *Monitor does not display*; the ERG160 and ERG220 print *Console does not turn on* and *Battery not installed / Install battery* in the singular. The ERG160 book prints only this row - its whole troubleshooting page is these two lines.

**The two water-rower service manuals carry the same fault one step further.** Their Q&A page asks *The console without display* and answers: check if the batteries have enough power; if not, change new ones to try; if still not OK, **change a new console** (ERG550W SM p. 19; ERG600W SM p. 20, word for word). So a console that stays dark on fresh batteries with the wires seated is replaced, not repaired.

A console that lights but shows no count or distance while rowing is the next row down, with its own causes (`xterra-rower-errors-no-count-or-distance-sensor-wire-then-monitor`); a console that turns itself on is a stuck key (`xterra-ergw-errors-console-powers-on-by-itself-control-key-stuck-new-console`). The ERG750W service manual prints a second, part-numbered version of the no-display fault for the console it calls TZ-8145-2AA (`erg750w-2025-errors-no-action-or-dim-lcd-power-failure-batteries-and-battery-case-wires`).

**None of these books prints an error code**; a code on the screen is not a fault these consoles report (`xterra-errors-rower-and-strength-books-print-no-error-codes-except-one-rower`). The Spirit CRW800H2O water rower's service manual answers the same question in the same words (`crw800h2o-console-shows-no-display`).
