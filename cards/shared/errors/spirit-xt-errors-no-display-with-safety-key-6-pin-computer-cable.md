Eight causes, in the order the manual lists them. The 2023 XT185, XT285, XT385, XT485 and XT685 service manuals print the row identically.

| Reason | Solve |
|---|---|
| Haven't switch ON/OFF switch | Switch the AC switch |
| Insert the Safe key on wrong position | Insert the safe key on right position |
| 6 PIN Computer connector not plugged in properly | Please check the wire and connect again |
| 6 PIN computer cable is broken | Replace 6 PIN computer cable |
| Fuse on controller is blown | Replace fuse or controller |
| Varistor on controller is blown | Replace varistor or controller |
| Safety device is broken (open) | Replace safety key device |
| Other components are faulty | Replace console |

These consoles hang on a **6-pin** computer cable. The same row names a **12-pin** cable on the 2015 XT385 and XT485, the CT800 2016, the CT850 2016 and the CT1000ENT (`ct850-2016-no-display-when-safety-key-inserted`), *6-PIN Main control wires* on the 2015 XT185 and XT285 (`spirit-xt-2015-errors-no-display-with-safety-key-6-pin-main-control-wires`), and a plain *console cable* on the CT800 2020 family (`ct850-2020-no-display-when-safety-key-inserted`). The fault list is the same eight in every one.

If the display shows `E0` rather than nothing, that is the safety switch loop (`spirit-xt-errors-e0-safety-key-loop`).
