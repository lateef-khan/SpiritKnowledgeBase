1. **Separate bikes that may be set to the same console code and are cross-talking**, or **re-synchronise the transmitter and console**. The manual points back to its own synchronising procedure for that.
2. Relocate the bike to a different part of the room, away from any RF interference areas.

**"Console code" is this manual's own phrase for the transmitter identity**, and the fix is the `ID - -` / `ID 0` synchronising sequence, not the MODE and PAGE speed pair stage of the later consoles.
