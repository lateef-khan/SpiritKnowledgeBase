**This is E1, not E2 (the resistance actuator).**

E1 is an EEPROM error in the display board. It is a software fault. A pinched computer cable or a damaged display board can cause it.

1. Ask whether the machine has recently been assembled, disassembled or moved.
2. **Yes** - replace the **Computer Cable**.
3. **No** - replace the **Display Board**.

**The manuals answer this differently.** The sr500-2016 service manual defines E1 as a console EEPROM failure and says to replace the console (Electronic Desk). The sr550-2023 service manual documents no E1 at all. See `sr500-2016-e1-eeprom-failure` for the manual's own answer.
