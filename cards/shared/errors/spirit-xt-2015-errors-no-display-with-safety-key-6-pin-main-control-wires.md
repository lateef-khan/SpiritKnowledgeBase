Eight causes, in the order the manual lists them. The 2015 XT185 and XT285 service manuals print the row identically.

| Reason | Solve |
|---|---|
| Haven't switch ON/OFF switch | Switch the AC switch |
| Insert the Safe key on wrong position | Insert the safe key on right position |
| 6-PIN Main control wires not plugged in properly | Please check the wire and connect again |
| 6-PIN Main control wires are broken | Replace 6-PIN Main control wires |
| Fuse on controller is blown | Replace fuse or controller |
| Varistor on controller is blown | Replace varistor or controller |
| Safety device is broken (open circuit) | Replace safety key device |
| Other components are faulty | Replace console |

The cable is the same 6-pin main control wire the E0 and E5 sections talk about (`spirit-xt-errors-e0-safety-key-loop`, `spirit-xt-errors-e5-console-controller-communication-poor`). The 2023 XT books call it a *6 PIN computer cable* (`spirit-xt-errors-no-display-with-safety-key-6-pin-computer-cable`) and the 2015 XT385 and XT485 a *12 PIN computer cable* (`ct850-2016-no-display-when-safety-key-inserted`).
