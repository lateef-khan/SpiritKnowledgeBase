**This is E-3 with a hyphen, the E98 incline calibration error — not the Sole treadmill E3 incline fault (`sole-e3-error`), which names controllers and cables instead of a STOP bypass. Its wording differs from the E95 card, so it keeps its own card.**

The book prints: “If calibration causes an Incline error, the screen will show “E-3”. You can press the STOP key to bypass.” The screen shows a red warning panel reading E-3 with “Press Stop to bypass” beneath it. If calibration passes, the main workout home screen returns.

Calibration is started with the Incline Up and Start keys (the book's Incline Calibration paragraph); the maintenance-menu procedure itself is a console fact. To leave the calibration page the book says to power the unit off and back on; if the problem persists, contact customer service.
