**This is the CT800ENT 2024's E1, and it is not the CT800 2024's E1.** The two books of the same
2024 family print the same code string against a different cause and a different remedy.

| Field | Value |
|---|---|
| Code | E1 |
| Cause, word for word | Drive motor didn't send output signal during workout. |
| Solution, word for word | Check all the wires which from Drive motor connect well. |

**No speed sensor is named, and no part is condemned.** The whole remedy is the drive motor
wiring. The CT800 2024 answers the same code by blaming the speed sensor and telling the reader to
replace it - see `spirit-2024-errors-e1-no-speed-sensor-signal`. Do not offer a CT800ENT 2024 owner
a speed sensor on the strength of this code.

**The cause names the workout.** This is a fault raised while the belt is running, not at power on.

The same manual's TROUBLESHOOTING table answers `Motor is not responsive after pressing start` with
no code at all - `Reset power. If still no good contact service.`
(`ct900ent-motor-unresponsive-after-start`).
