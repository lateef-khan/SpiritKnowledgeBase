**The 2009-2010 E55/E95 book names an incline/ramp error with no code number — not the E-3 calibration error the 2015-2019 E95/E98 books print.**

The book prints: “If the console shows an error for the incline/ramp, re-calibrating the system may resolve the problem. Press and hold the Start & work level UP keys for 5 seconds. The message window will show “Calibration”; press enter. The calibration process is automatic and the system will restart when finished.”

No code, no further diagnosis and no parts are printed for this error; the step-by-step calibration procedure itself is a console fact.
