These books print no LS, E1 or other code in this row, and no calibration pointer at all — none of the four books contains the word "calibration" anywhere.

> Motor is not responsive / Display is lit — Make certain clock is running.

The clock is the time display: if Start was pressed and the console works, the time should be counting. This row covers the F63-2006, UF63-2006, F80/F83/F85-2006, S73/S77-2006, US73/US77-2006, TT8/UTT8-2006 and VF63-2007 books. Later books replace this row with the two-way LS / E1 split (run calibration if the belt moved, contact service if it never did): see `sole-ls-error`.
