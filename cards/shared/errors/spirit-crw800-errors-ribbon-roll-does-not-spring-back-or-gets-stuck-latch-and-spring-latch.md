Two questions, printed the same way in all three books.

**Q: Ribbon Roll can't spring back.**
**A:** Release the Chain Cover (R) (72) and check the Latch (26). If the ribbon roll can spring back, the problem could be broken on the other side. Please pull it out and check. If the Latch (26) cannot spring back, please release the Attaching Plate (8R) to check the connections of Spring Latch (27~2) and Latch (26). **If the Spring Latch (27~2) is broken, please replace it directly.**

**Q: Ribbon Roll works not smoothly or gets stuck.**
**A:** The Ribbon Roll may get in reverse position. Please pull it out and check, please also check Chain Cover (R) (72).

**The latch is the recoil.** These rowers return the handle with a latch and spring latch behind the right chain cover, not with a bungee cord; the test is whether the *latch* springs back once the cover is off. A latch that does spring back means the fault is on the other side of the roll; one that does not means the spring latch behind the attaching plate, and a broken spring latch is a part, not an adjustment.

**A roll fitted backwards sticks.** The second answer is a check for a ribbon roll that has been refitted the wrong way round after a repair - and for the chain cover rubbing it. No lubrication and no tension figure is printed for either answer; the replacement steps for the latch and spring latch are the flywheel pulley section of the same books.

The water rower answers a handle that will not return with bungee tension instead (`crw900-2021-errors-belt-slips-off-the-bungee-pulley`). Sole prints this Q&A for its SR500: `sr500-2016-ribbon-roll-will-not-retract`.
