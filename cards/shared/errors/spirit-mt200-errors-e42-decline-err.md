**This is the MT200 E42 (Decline Err) - not E41 (Incline Err) on the same machine, and not
the 7.0T's `ER2 Decline Err`, which is the same fault under a different identifier.**

| Field | Value |
|---|---|
| Code | E42 |
| Name, as printed | Decline Err |

**The table lists no cause and no remedy for E42.** Every numbered code from E1 to E38 in
the same table carries at least one; this row carries none. Do not read the neighbouring
column's causes across into it - they belong to the numbered codes above.

Both MT200 owner's manuals print the row identically: the 2010 revision, effective July
2013, and the 2022 revision. Neither adds a description, a test procedure or a part number.

The MT200 declines as well as inclines - the specifications give a rear grade of 0 to 10% -
so the manual gives the decline direction its own code rather than folding it into E41.

**The same fault is not numbered on every Spirit treadmill.** The 7.0T 2026 prints this
fault as `ER2` rather than `E42`, and adds a note the MT200 does not - that it shows in the
Grade window (`70t-2026-errors-er2-decline-err`).
