Both water-rower service manuals ask *The console can power on by itself* and answer in one line, word for word the same:

> The control key gets stuck, change a new console.

That is the whole answer. Neither book names a test to confirm the key is stuck, a way to free it, or any repair short of a new console. These consoles normally wake on a stroke or a key press and sleep after a few minutes, so a console that lights with nobody at the machine is a key held down inside it, and it will also run the AA cells flat.

The Spirit CRW800H2O service manual prints the same question and the same one-line answer (`crw800h2o-console-powers-on-by-itself`).
