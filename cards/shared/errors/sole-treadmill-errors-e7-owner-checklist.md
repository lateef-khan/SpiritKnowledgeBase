**This is the stencil-era owner's-manual E7 (abnormal voltage input) — the 2026 books print no E07 (their voltage faults are E05/E06), and it is not Spirit's E7.**

The six owner's manuals print the same ERROR MESSAGES table with OK/NG checkboxes. The F80-2023, F85-2023 and F89-2023 prints read 'E1_'..'E7_' on the OCR layer — the render shows a plain code beside the checkbox column.

| ERROR | MEANING | POSSIBLE CAUSE |
|---|---|---|
| Console showing E7 | Abnormal extemal [sic] voltage input | Check and make sure of proper voltage input for the treadmill. |

The book prints 'extemal' for external (render and OCR agree). The service manuals' deeper E7 procedure (input power) is a separate card: see `f65-2023-e7-input-power-error`.
