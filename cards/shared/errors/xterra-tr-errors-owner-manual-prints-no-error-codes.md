The TR75 and TR85 owner's manuals (both Rev 06.07.24) contain **no error code table**. Their *Troubleshooting* section is a single page, the *Service Checklist Diagnosis Guide*, whose rows are symptoms (display does not light, belt not centered, motor not responsive, only reaches 5 mph, belt stops when the tether is pulled, trips the 15 amp circuit, computer shuts off when touched, house breaker trips) - none of them names a code.

Checked three ways: the table of contents lists Troubleshooting as one page (printed 46); a search of the whole text layer for `E` followed by a digit finds only program-page and parts-list hits; and the troubleshooting page carries no OCR supplement, so nothing on it was drawn rather than set as text. The sibling TR65 book of the same layout prints an eight-code *Error Code Guide* (`tr65-2023-errors-owner-error-code-guide-eight-codes`); the TR75 and TR85 books simply omit that page. No service manual for either machine is in the knowledge base.

The symptom rows themselves are carded: `xterra-treadmill-errors-display-does-not-light-five-checks-ac-outlet`, `xterra-treadmill-errors-motor-not-responsive-after-start-contact-service`, `xterra-tr-errors-only-reaches-5-mph-14-gauge-120-volt`, `xterra-treadmill-errors-trips-15-amp-circuit-high-belt-deck-friction`, `xterra-treadmill-errors-computer-shuts-off-when-console-touched-static`, `xterra-treadmill-errors-house-breaker-trips-but-not-treadmill-breaker`.
