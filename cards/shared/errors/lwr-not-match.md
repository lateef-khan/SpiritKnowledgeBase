**What it means.** The console is set to a different model than the machine it is sitting on.

**Check assembly first.** If the machine was recently assembled or re-assembled **and** it does not pass calibration, replace the **Computer Cables**.

**Fix the model setting**

1. Log in to a profile and tap the **Gear** icon to open the Settings menu.
2. Tap the word **Settings** over and over until a new screen pops up.
3. Scroll down to **Machine Type**.
4. Select the correct model.
5. The console reboots. LWR Not Match should be gone.

**If it does not go away**

1. Replace the **Console** or **Display Board**. Also replace the **Computer Cables** if the machine was recently assembled.
2. If neither fixes it, replace the **Incline Controller**.
