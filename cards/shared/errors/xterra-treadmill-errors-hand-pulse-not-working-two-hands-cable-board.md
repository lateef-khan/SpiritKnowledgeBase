The troubleshooting procedure matrix prints this row in all five service manuals:

*Condition:* Hand pulse lost its function (no pulse displayed on monitor).

| Reason | Solve |
|---|---|
| 1. Hands not on the hand pulse sensors, or only one hand on a sensor | 1. Two hands hold the hand pulse |
| 2. The connector of HANDPULSE W/WIRE and console not connected properly | 2. Connect the cable again |
| 3. The wires got damaged when connecting the HANDPULSE W/WIRE and console | 3. Replace with new cable |
| 4. Hand pulse board is broken | 4. Replace console or hand pulse board |

The chest-strap counterpart is `xterra-treadmill-errors-wireless-pulse-not-working-chest-belt-3-feet-cr2032`; a reading that is present but jumps is `xterra-treadmill-errors-erratic-pulse-display-chest-belt-interference-receiver`.
