The *Service Checklist Diagnosis Guide* in the TR65, TR75, TR85 and TRX1400 owner's manuals prints one line:

*Motor is not responsive after pressing start:* If you press Start and the belt never moves, contact service.

That is the whole owner's entry for these four books. The TR300 book adds a first line for a belt that moves and then stops with E1 - run calibration (`xterra-treadmill-errors-e1-no-speed-signal-for-10-seconds-owner-list`); the TR6.6 and TR6.4 print the same pair with LS (`xterra-tr-errors-ls-no-speed-signal-for-8-seconds`). The TRX1400 service manual has the real diagnosis: `xterra-treadmill-errors-does-not-start-when-start-pressed-motor-m-plus-m-minus-wire` and `xterra-treadmill-errors-e1-solution-flow-chart-reset-power-then-dc-12v`.
