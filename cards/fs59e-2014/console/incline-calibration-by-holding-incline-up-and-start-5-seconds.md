"**Incline Calibration:** If there is a problem with the incline, try running the calibration. **Press the Incline Up key and the Start key at the same time. Hold them down for five seconds** and the incline calibration will start and run automatically. If the problem persists, contact XTERRA Fitness service department."

It sits under the engineering-mode section but is a separate key hold, not a menu entry ([engineering card](../../shared/console/xterra-console-engineering-mode-start-stop-enter-5-seconds-with-key-test-security-sleep-and-units.md)).
