**Press the "Welcome" button ten consecutive times to enter engineering mode.** The screen it opens
is headed **Maintenance Mode** and carries four groups. **Set the machine type first**: under About
This Machine, "There are three modes: Treadmill / Elliptical / Bike. Please select for the machine.
The selection must match the actual machine otherwise it will be unable to operate the machine
properly."

| Group | Item | What the manual says |
|---|---|---|
| About This Machine | Type | Treadmill / Elliptical / **Upright Bike / Recumbent Bike** - the table names four, the sentence above it names three. Must match the machine. The screenshot shows **Upright Bike**. |
| | Reset Odometer, Display Brightness | Shown on the screenshot; not described |
| Preferences | Beep | ON / OFF for beep sound mode |
| | Pause Mode | ON / OFF Pause Time Mode, set in **Minutes : Seconds** |
| | Sleep Mode | ON / OFF. "The display always lights when turns off. When there is no action for **15 minutes** after turning on the power, it enters sleep mode." |
| | Workout Time Limit | ON / OFF; sets a limit on machine usage time |
| Machine Setup | Club Information | Information or promotional display provided by the club |
| | Language | The default language for the first-page window; **12 languages** in the menu |
| | Date & Time | Sets the console time |
| | Units | English / Metric |
| | Video | **STB / TV / None** |
| | Protocol | **C-SAFE or CAB** for the TV switching box; choose one only |
| | WiFi | Opens the WiFi setting |
| | Software, Firmware | Update automatically over a wired or WiFi network, or from USB - `cu1000ent-2023-console-software-update-usb-root-and-automatic` |
| | App Manager | Updates the app software automatically over a wired or WiFi network |
| Service | Key Test, NFC Test, Communication Test, Brake Test, Sensor Tests, Error Code Log | `cu1000ent-2023-console-service-tab-key-nfc-communication-brake-sensor-tests-and-error-log` |

**No GS Mode.** The CT1000ENT-2023 treadmill, whose service manual this book mirrors page for page,
carries a GS Mode row under Preferences; the bike's Preferences are Beep, Pause Mode, Sleep Mode
and Workout Time Limit only (`ct1000ent-2023-console-maintenance-mode-welcome-ten-times-four-groups`).

**Fifteen minutes, not thirty.** The CR900ENT, CU900ENT, CR800ENT and CU800ENT touchscreens sleep
after 30 minutes (`cu900ent-engineering-mode-settings`,
`spirit-ent-bike-console-engineering-mode-units-beep-30-minute-sleep-and-5-minute-pause`); the 2024
Hello-Guest consoles say 15 (`cu800ent-2024-console-maintenance-mode-and-engineering-menu`).

**"Welcome", not Home and not Hello Guest.** The older ENT bikes open their menu on ten presses of
the Home icon (`spirit-ent-console-enter-engineering-mode`); the 2024 ENT machines on ten presses
of Hello Guest. The word on this console's screen is Welcome.

The owner's manual for this machine is not in the repository; nothing here is corroborated by it.
