**Default: OFF, and while it is off the child lock has no effect. Setting range: ON or OFF.**

**To turn it on**

1. Open **Machine Information** in the engineering menu and set **Child Lock** to **ON**.
2. **Repower the machine, or re-plug the safety key.** The setting does not take effect until you do.

**What the user sees when it is on**

The display goes to IDLE MODE and shows **【CONSOLE LOCKED】**, with **【Press Start and Display to enable operation】** along the bottom.

**To unlock**

Press **START and DISPLAY within 2 seconds** of each other. The console then enters IDLE MODE.

**The unlock gesture is not the same on every F85.** The 2016 and 2019 manuals for the neighbouring builds unlock by **holding Start and Enter for 3 seconds**. This console uses Start and Display, within 2 seconds.
