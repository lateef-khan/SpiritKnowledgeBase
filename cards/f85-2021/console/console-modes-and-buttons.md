**This is a touchscreen console.** The panel is a **10.1" TFT TOUCH PANNEL**. Only START, STOP, the fan key, the quick key rows and the safety key are physical; FAST, SLOW, UP, DOWN and the function button are touch controls.

**The four window display modes**

| Mode | What it means |
|---|---|
| OFF | The safety key is not in the console. Every window is blank. |
| READY | The treadmill is on and the safety key is inserted. The message window shows the program profile name and cycle. Press the **START** button, or touch **"START WORKOUT"** on the panel, to run in Manual. |
| SLEEP | Pressing any button returns the console to READY. |
| RUN | Pressing STOP, or removing the safety key, stops the treadmill instantly and drops it into OFF. |

**READY mode**

| Control | Behaviour |
|---|---|
| SAFETY KEY | Fit it in the right position to power the computer on. Pulling it away shuts the computer down automatically. |
| STOP | No function. |
| START | Starts the treadmill after a 3 second countdown on the window display. In MANUAL it starts at MIN SPEED; in a PROGRAM it starts at the program's preset value. |
| Touch panel function button | Changes each function. MANUAL sets time. Preset PROGRAMs and Fitness tests set time and speed. Heart Rate Control 1 to 2 sets time, age and heart rate value. User Program 1 to 2 sets time, speed and incline. |
| Touch FAST, SLOW, UP, DOWN | Non functional until the user enters a setting. |
| FAN | Turns the cooling fan on and off. |
| DISPLAY | **No function in READY mode.** |

**RUN mode**

| Control | Behaviour |
|---|---|
| SAFETY KEY | Pulling it away shuts the computer down automatically. |
| STOP | Stops the treadmill. |
| START | Non functional. |
| Touch FAST | Increases speed by 0.1 kph (0.1 mph) per press. Held down, it runs up to MAX SPEED quickly. |
| Touch SLOW | Decreases speed by 0.1 kph (0.1 mph) per press. Held down, it runs down to MIN SPEED quickly. |
| Touch UP | Raises the incline by 1 per press, to a maximum position of **15**. |
| Touch DOWN | Lowers the incline by 1 per press, to a minimum of 0. |
| FAN | Turns the fan on and off (optional). |
| DISPLAY | Cycles through **three training diagrams**. |

**This console offers Fitness tests** alongside the manual, preset, heart rate control and user programs. The manual names the category on the READY mode page but does not list the individual tests.
