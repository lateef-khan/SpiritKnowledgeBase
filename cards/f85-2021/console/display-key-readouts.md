| Mode | What the display key does |
|---|---|
| READY | **Nothing. The manual lists it as "Non-function".** |
| RUN | Changes the training diagram, cycling through **three** of them. |

**This console shows the workout view as pictures, not as a text list.** The 2016 and 2019 manuals for the neighbouring builds print a list of text readouts for this key — lap count, vertical distance, segment time and max speed. This manual replaces that list with three training diagrams and prints no text strings at all.
