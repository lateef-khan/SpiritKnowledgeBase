The matrix treats the **FAST/SLOW speed adjustment switch** and the **UP/DOWN incline adjustment switch** as one row, with one list of causes and fixes.

| Reason |
|---|
| The connector between the SPEED CABLE and the CONSOLE is not connected properly. |
| The connector between the SPEED CABLE and the SPEED ADJUSTMENT SWITCH wire cable is not connected properly. |
| The button of the SPEED ADJUSTMENT SWITCH is broken. |
| The connector of the SPEED CABLE, or of the SPEED ADJUSTMENT SWITCH wire cable, is damaged. |

**Solve, in order**

1. Connect the cables again.
2. Check the wire of the SPEED ADJUSTMENT SWITCH.
3. Replace with a new cable.
4. Replace with a new SPEED ADJUSTMENT SWITCH.

**Run Key Test first.** The engineering menu's Key Test names each key and waits for it to be pressed, which separates a dead switch from a dead cable without taking a cover off.
