| Symptom | Reason | Solve |
|---|---|---|
| The speed of the belt does not match the console display | The console is not calibrated | 1. Calibrate the console. 2. Replace the controller. |
| The incline position does not match the console | The console is not calibrated | Calibrate the console. |

Run the calibration first in both cases. Only replace the controller if a successful calibration leaves the speed still wrong.

For an incline that sits at the wrong resting position rather than showing the wrong number, check **Grade Return** before calibrating.
