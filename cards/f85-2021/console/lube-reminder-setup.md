**What it does.** Lube Setup reminds the user to lubricate the deck. **Default 90 hours. Setting range 90 to 200 hours.** The **total using hour** is shown in the upper right of the display.

**What the user sees.** When the machine is powered on and the total using hour has reached the set figure, the display shows **【LUBE DECK PRESS STOP TO RESET LUBE MESSAGE】** for 3 seconds, then closes the message and goes to IDLE MODE.

**Two ways to clear it**

1. While the message is showing, press **STOP**.
2. Or open **Lube Setup** and hit **【Zeroing】**. The display asks **【Are you sure the lube parameter need to be reset?】** — select Yes.

**What resetting does and does not clear**

- Once cleared, the message does not appear again until the next interval, the default 90 hours or the user's own figure.
- **The total using hour and the total distance are not cleared by dismissing the message.** They keep accumulating.
- Using **Zeroing** before the interval has elapsed **does** reset the accumulated using hour to zero.
