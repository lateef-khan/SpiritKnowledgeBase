**This console has no button combination.** The menu is opened from the screen.

1. Go to the **Settings** page.
2. **Press 10 times on the word "Settings"** to enter engineering mode.

Six main functions are listed:

| Function | What it is for |
|---|---|
| Engineering Mode | Calibration. |
| Diagnostics | |
| Machine Information | Grade Return, Beep Mode, Display Mode and Child Lock. |
| Maintenance | |
| Lube Setup | The lube reminder hours and the reset. |
| Key Test | Key by key test. |

**Key Test**

1. Hit **Key Test**. The display names a key; press that key.
2. When every key has been pressed the display shows **【All Done!】** within 5 seconds.

**The manual does not describe Diagnostics or Maintenance.** It lists both as menu items and then documents only Engineering Mode, Machine Information, Lube Setup and Key Test.
