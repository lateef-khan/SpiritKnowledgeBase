| Quick key row | Mile values | Kilometre values |
|---|---|---|
| Speed | 2, 3, 4, 5, 7, 9, 12 | 3, 6, 9, 12, 15, 18, 22 |
| Incline | 1, 3, 5, 7, 9, 12, 15 | same |

Pressing one in RUN mode takes the machine straight to that speed or incline. **There are seven preset buttons on each row**, and this manual says so on both the READY mode and RUN mode pages.

**Watch the top metric speed.** This manual gives the highest metric quick key as **22**, matching the console's working range of 1.0 to 22.0 km/h. The 2019 manual for the neighbouring build gives the highest metric quick key as 20.
