| Field | Value |
|---|---|
| Code on the service manual cover | ST538-YT056 |
| Name on the source document | SOLE F85 ENT 2021 |
| Name used inside the manual | ST538 Treadmill |
| Sole model number (SKU) | **not resolved** |

**There is no 2021 F85 row in the Spirit database.** The `Models` table holds 585816 "SOLE F85 2016", 585818 "SOLE F85 2019", 585820 "SOLE F85 2020" and 585822 "SOLE F85". It has no row named for 2021.

**The nearest candidate is 585820, "SOLE F85 2020".** Another card in this knowledge base, on the 2.0 to 2.4 software update, states plainly: "Applies to the F85, SKU 585820, which is called both the 2020 and the 2021 machine", and it is filed against both model ids. That is the only in-house statement linking a SKU to a 2021 F85, and it points at 585820.

**Do not read a year off this manual.** ST538 is the Dyaco factory code for the platform and covers more than one model year: the 2019 F85 manual is ST538-YT034 and this one is ST538-YT056. The suffix after the dash identifies the build, not ST538 itself.

**The manual never prints "F85", "ENT" or a six digit number.** Every heading says ST538. The words "F85 ENT 2021" come from the file name of the source document.
