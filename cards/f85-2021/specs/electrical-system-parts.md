| Part | What it does |
|---|---|
| Safety key | Fits on the console and activates all functions. With no safety key the console cannot be controlled, and **the display shows "Please Replace the Safety Key"**. |
| Console | The interface that controls all functions of the treadmill. Made up of key controls and a **TFT 10.1" TFT TOUCH PANNEL** display. |
| Main controller (also called the lower controller or driver board) | Carries the DC power supply for the console, the incline driver and the DC motor driver. It links the console to the motors and outputs the voltages that run them. |
| Treadmill motor | A variable speed DC motor. |
| Incline motor | An AC motor. The user sets the elevation from the console, through the main controller. |

**This is a touchscreen machine.** The safety key definition on this page is the only place in the manual where the on-screen wording of the safety key fault is quoted outside section 8.
