**The service manual and the owner's manual print two different menus for this console.** The
owner's manual's menu has Functions (Unit, Pause mode, Odometer reset, Beep sound, LED Brightness,
Model), a Service entry with a Brake Test and a CSAFE Test, an ANT ID entry and an Update Code entry
(`40t-2026-console-maintenance-mode-menu`). The service manual's menu, below, is the CT900-style list
with a Sleep Mode, an odometer in hours, an Incline Return setting and a Service Mode with motor
readouts. Nothing in either book mentions the other; expect one of the two on the machine.

**To enter: press and hold Start, Stop and Confirm at the same time.** The message window shows
**"ENGINEERING MODE MENU PRESS CONFIRM"**; press Confirm.

| Item | What it does |
|---|---|
| KEY TEST | MW shows PRESS ALL KEYS. Each key pressed shows its number on the MW, e.g. S1. When all keys are pressed MW shows **TEST PASSED** for 3 seconds, then exits to the next test. |
| DISPLAY TEST | Lights all LEDs. Press Stop to end the test and exit to the next. |
| SLEEP MODE - ON | Default **ON**. Sleep after **30 minutes**. |
| ODOMETER | MW shows **ODOMETER _ _ _ _ _ HRS**, then **CONFIRM TO RESET**; Confirm resets the odometer and exits to the next test. |
| UNITS - ENGLISH | Default English. |
| SPEAKER - ON | Default ON. |
| INCLINE RETURN - ON | Default **ON**: the incline returns to the home position when Pause is pressed. **OFF** leaves the incline where it is on Pause, but it still returns home when the program ends. |
| SERVICE MODE | **INCLINE** - use the incline keys; MW displays **A1 xxxxx A2 xxxxx**. **DRIVE MOTOR** - use the speed keys, each press adds 0.1 mph/kph; MW shows **AMPS**. **CSAFE** - Confirm to run; nothing more is printed. |

**Two things the owner's manual's menu has that this one does not**: a Pause mode setting (five
minutes or indefinite - `40t-2026-console-pause-mode-setting`) and an LED brightness setting.
**Two things this one has that the owner's manual's does not**: the 30-minute Sleep Mode and Incline
Return.

**The odometer here counts hours**, as the ODOMETER _ _ _ _ _ HRS prompt shows; the owner's manual's
Odometer reset says "Time and distance".

**The same page prints an EEPROM ERR recovery** - hold Stop for 3 seconds to reset the console, or
hold Start, Stop and FAN together for 3 seconds to clear the EEPROM - which is an error-message
procedure and is held with the error cards.

The A1 / A2 readings are what the factory-settings calibration displays too:
`40t-2026-console-factory-settings-min-0-3-to-0-7-max-down-to-10-0`.
