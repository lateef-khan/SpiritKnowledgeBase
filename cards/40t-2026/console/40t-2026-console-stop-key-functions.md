The Stop key has four functions.

| What you do | What happens |
|---|---|
| Press once during a program | **Pauses the program for 5 minutes.** Press Start to resume |
| Press twice during a workout | Ends the program, shows a summary of the session, then returns to the start up screen |
| Hold down for 3 seconds | The console performs a **complete Reset** |
| Press during data entry | **Previous Screen** - goes back one step in the programming |

**The five-minute limit is a setting, not a fixed figure.** Maintenance mode's
Pause mode item turns it off so the console pauses indefinitely; see
`40t-2026-console-pause-mode-setting`.
