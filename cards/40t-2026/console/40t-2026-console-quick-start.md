This is the quickest way to start a workout.

1. Let the console power up.
2. **Press the Start key.** This initiates Quick Start mode.

In Quick Start the **Time counts up from zero**, all workout data starts to accrue,
and **the workload is adjusted manually with the Plus and Minus keys**. As you
increase the workload more rows light, indicating a harder workout.

**The 7.0T and 8.0T Quick Start works differently** - their belt holds at zero
speed until the user raises it, and speed and incline are set with Up/Down keys.
See `spirit-2026t-console-quick-start-zero-speed`.

**The 4.0T service manual prints this section word for word** in its chapter 4.

**The 2025 printings of the 4.0T owner's manual - February (Revision 02.04.25) and May (Revision 05.19.25), one document twice - print this section word for word on the same page**, so this card covers the 40t-2025 as well. The ST8700A service manual prints Quick start on its p. 14. **The 2025 printings have no reverse mode**; the 2026 book and the ST8700A service manual add one, reached by slowing to 0.0 mph (`40t-2026-console-reverse-mode-from-zero-speed-with-a-3-mph-ceiling`).
