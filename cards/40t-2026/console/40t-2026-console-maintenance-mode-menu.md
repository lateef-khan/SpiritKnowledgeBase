The console has built-in maintenance/diagnostic software.

**To enter it: press and hold the Start, Stop and Confirm keys together for about
2 seconds**, until the Message Window displays "Maintenance mode". Press the
**Confirm** key to open the menu.

| Menu item | What it does |
|---|---|
| Key test | Test all the keys. Press all the keys one at a time |
| Display test | Tests all display functions by lighting each LED sequentially |
| Functions | Press Confirm to open the sub-menu below |
| &nbsp;&nbsp;Unit | English (imperial) or metric readings. **Default is imperial**, so bodyweight and height read in pounds and inches |
| &nbsp;&nbsp;Pause mode | On allows 5 minutes of pause; off makes the console pause indefinitely |
| &nbsp;&nbsp;Odometer reset | Resets the odometer to zero (Time and distance) |
| &nbsp;&nbsp;Beep sound | Turn the speaker on or off to silence the beeping |
| &nbsp;&nbsp;LED Brightness | Adjust the LED brightness |
| &nbsp;&nbsp;Model | Select the kind of device |
| Service | Brake Test; CSAFE Test (tests the CSAFE functions) |
| ANT ID | Adjust the ANT ID |
| Update Code | Switch bootloader on/off. **The default is off** |
| Exit | Press Confirm to leave maintenance mode and restart |

**This is the 4.0T menu only.** The 7.0T menu is entered with Start + Stop + Enter
and holds different items, including a Service Mode with motor tests and a
calibration routine; see `70t-2026-console-maintenance-mode-menu`. The 8.0T manual
prints no maintenance or service mode at all.
