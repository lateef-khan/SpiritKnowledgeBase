The overview drawing labels seven things, two displays and five groups of keys:

| Label | What it is |
|---|---|
| Message Window | The upper text display |
| Dot Matrix Window | The graphic display below it |
| Incline/Decline Keys | Left side of the keypad |
| Program Keys | Below the incline keys |
| Direct Keys | Right side of the keypad |
| Speed Keys | Below the direct keys |
| Function Keys | Bottom of the keypad |

**That is everything the drawing names.** It prints no legend for the individual
keys inside each group, and no count of how many keys a group holds.

The console also carries C-SAFE **POWER** and **COMM** ports at the back; see
`ct850-2020-c-safe-ports`, which this manual's page 16 matches word for word.

**The 2025 printings of the 4.0T owner's manual draw the same console with the same seven call-outs, one label apart**: their fifth call-out reads **Quick Keys** where this book reads Direct Keys. The render also shows what the labels leave out - a message window with legends Distance / Calories / Pulse / Time and Watts / Cal/hr / METS / Pace, a dot matrix with Track, Speed and Incline LEDs beside it, Grade and Speed windows under it, a fan grille, Grade and Speed rockers, quick keys marked Grade -3 3 6 and Speed 2 5 8, program keys and a bottom row Display, Fan, Start, Stop, Confirm, Profile. So this card covers the 40t-2025.

**The ST8700A service manual labels the same face with six call-outs and a seventh group the owner's manuals do not name: REVERS Keys**, beside the Quick Keys - the reverse mode the 2026 book describes without labelling a key (`40t-2026-console-reverse-mode-from-zero-speed-with-a-3-mph-ceiling`).
