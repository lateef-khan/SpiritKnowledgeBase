The overview drawing labels seven things, two displays and five groups of keys:

| Label | What it is |
|---|---|
| Message Window | The upper text display |
| Dot Matrix Window | The graphic display below it |
| Incline/Decline Keys | Left side of the keypad |
| Program Keys | Below the incline keys |
| Direct Keys | Right side of the keypad |
| Speed Keys | Below the direct keys |
| Function Keys | Bottom of the keypad |

**That is everything the drawing names.** It prints no legend for the individual
keys inside each group, and no count of how many keys a group holds.

The console also carries C-SAFE **POWER** and **COMM** ports at the back; see
`ct850-2020-c-safe-ports`, which this manual's page 16 matches word for word.
