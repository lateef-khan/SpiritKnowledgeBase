**Unplug the treadmill before performing any maintenance.**

| Task | How To | Daily | Weekly | Monthly | Semi-Annually | Annually |
|---|---|:-:|:-:|:-:|:-:|:-:|
| Wipe down unit | Damp cloth w/ water | ✔ | | | | |
| Clean under belt | Towel or vacuum | | | ✔ | | |
| Check belt tension/tracking | Feel/visual | | ✔ | | | |

| Check hardware | Wrench | | | ✔ | | |
| Inspect for deck wear | Visual | | | | ✔ | |
| Inspect drive belt | Visual | | | | ✔ | |

The table prints an **Annually** column but ticks nothing in it.

## The motor-cover interval disagrees with the prose

The Machine Care text on page 43 says to remove the motor hood and vacuum it out **once a year**.
This table ticks "Clean under motor cover" under **Semi-Annually**. The manual reconciles the two
nowhere. See `spirit-2026t-maintenance-vacuuming-and-motor-hood` for the prose half.

## This is not the CT900ENT schedule

The CT900ENT prints the same seven tasks but ticks "Clean Under Motor Cover" **monthly** and has no
Annually column at all (`ct900ent-general-maintenance-schedule`). Three different intervals exist
for one task across the Spirit range; use the one printed for the machine in front of you.

The 7.0T manual prints no maintenance schedule table. The 8.0T prints a different table organised
by period rather than by task — `80t-2026-maintenance-cleaning-schedule`.
