You enter a program by pressing a program key and then the **Confirm** key. From there you have
the option of modifying the settings.

- To begin **without** entering new settings, press **Start**. This bypasses the programming of data
  and takes you directly to the start of the program.
- If you start a program without changing the settings, **the default or pre-saved setting is used**.
- To change the settings, follow the instructions in the Message Window.
- At any time during the editing of data, press **Stop** to go back one level, or screen.
- During a program, press **Display** to scroll through the data in the Message Window.
- When the program ends you may press **Start** to begin the same program again, or **Stop** to exit it.

The 7.0T and 8.0T manuals answer this question differently: on those machines the console takes the
data from the Set Up menu instead of a default or pre-saved value.

**The 4.0T 2025 owner's manual (Revision 02.04.25, reprinted as Revision 05.19.25) prints this page word for word**; only the folio differs, and both printings are cited. The 4.0T ST8700A service manual repeats the paragraph in its operation chapter.
