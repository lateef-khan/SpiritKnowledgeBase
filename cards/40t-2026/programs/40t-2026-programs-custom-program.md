The Custom program lets you build and save a custom program, and personalise it by adding your
facility name.

1. Press **Confirm** at the welcome message to begin programming. If you had previously saved a
   program, the message contains the name you gave it.
2. The Message Window shows `Name - XXXXXXX` if no name is saved, or the saved name (for example
   `Name - CustomA`) with the first letter blinking. Use Plus and/or Minus to change a letter and
   **Confirm** to save it and move to the next letter. Press **Stop** when the name is finished - or
   press Stop straight away to keep the existing name.
3. Enter an **Age**, then Confirm.
4. Enter a **Weight**, then Confirm.
5. Enter the **Time**, then Confirm.
6. Now set the **speed of each segment**. The first column blinks; adjust the level and press Confirm
   to move to the next segment. Each new segment starts at the level of the one before.
   **Continue until all twenty four segments have been set.**
7. Now set the **grade of each segment**, the same way, until all twenty four segments have been set.
8. The Message Window tells you to press **Confirm to save the program**. After saving it says
   `PRESS START TO BEGIN OR CONFIRM TO MODIFY`. Pressing Stop exits to the start up screen.

During the Custom program you can scroll the data with the **Display** key, and you can switch to
**Heart Rate Auto-Pilot** mode.
