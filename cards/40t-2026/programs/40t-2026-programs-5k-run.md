This program automatically sets a **5 Kilometre distance** as your goal. The dot matrix shows how many
track you have (**one track is the equivalent of 0.4 kilometres, or 1/4 mile**). When the program
begins the Distance counts down; once it reaches zero the program ends.

*Please note that the Speed readout is in MPH if the console is not set to Metric.*

Time is not asked for during setup: the preset setup sequence skips the Time step for the 5K program.

The CT900 and CTSBS900 manuals describe their 5K Run differently - there, one loop of the track
display is the equivalent of the whole 5 kilometres. That is a separate card.

**The 4.0T 2025 owner's manual (Revision 02.04.25, reprinted as Revision 05.19.25) prints this page word for word**; only the folio differs, and both printings are cited.
