**Beep Mode (Buzzer Switch). Default: ON. Setting: ON/OFF.** It lives in Machine Information inside
engineering mode.

It controls **the finger hitting sound of the touch panel only**, not the physical keys on the console keyboard.

- **ON**: the buzzer sounds when the user hits the touch panel.
- **OFF**: the buzzer sound is closed.

The manual gives no setting for the physical key beep on this console.
