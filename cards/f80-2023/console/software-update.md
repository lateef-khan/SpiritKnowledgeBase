1. A **yellow dot on the gear icon** in IDLE MODE means the main program needs updating.
2. Go to the **Settings** page. If a software update is detected, the **Update** button lights up.
3. Click **Update**. The version changes once the update finishes.
4. If the software is already current, the page shows **"Up to date"**.

**Do not interrupt the power supply during the update.** The manual warns this can damage the system and stop it
working properly in the future.

The machine needs a Wi-Fi connection for updates to arrive.
