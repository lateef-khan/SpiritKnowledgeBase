Sleep Mode is in **Settings**, and **its default is OFF**.

- **Sleep Mode OFF**: removing the SAFETY KEY does not turn the screen off, and there is no Sleep Mode.
- **Sleep Mode ON**: removing the SAFETY KEY turns the screen off and activates Sleep Mode. With the key in, no
  operation on the IDLE MODE page for **15 minutes** puts the device into Sleep Mode by itself. **The device
  cannot enter Sleep Mode without the SAFETY KEY inserted.**
- While the screen is off in Sleep Mode, **any key wakes the device**.

**A second setting also controls this.** Engineering mode has a **Display Mode** switch whose default is ON, and
whose OFF position powers the console down after **30 minutes** of inactivity. The two settings use opposite
polarity and different timers. The company-wide sleep mode cards give the range "15 to 30 minutes" because of
this.
