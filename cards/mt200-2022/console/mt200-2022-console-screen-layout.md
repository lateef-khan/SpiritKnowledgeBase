The overview drawing numbers six parts:

1. **Large LED matrix window**
2. **16-character messsage center** - the manual prints "messsage" with three s's
3. **Incline buttons**
4. **Tablet friendly reading rack holder**
5. **Heart rate %**
6. **Speed buttons**

**That is everything the drawing names.** It does not label the set up key, the
display keys, the program keys, the start or stop keys or the forward and reverse
keys, although the text on the following pages describes all of them.

**The 2026 7.0T drawing names the same six things with different words** - Dot Matrix
Display, Message Window and Heart Rate % Profile - so the two label sets are kept on
separate cards; see `70t-2026-console-screen-layout`. **The 2010 MT200 manual prints
the console picture with no labels at all**, so there is no equivalent card for that
machine.

The **16-character** figure is the only place either MT200 manual states the size of
the message window.
