Section 5, item 2 of the 7.0T service manual:

1. If the belt does not move **and an error code shows** on the display, follow the instruction in the error code section (`spirit-mt200-errors-error-code-table`).
2. Otherwise **check the motor resistance between all three wires - it should be about 2 ohms.** Replace the motor if the values are very different from each other.

The motor is a three-phase AC motor driven by the inverter, so the three readings should agree; one open or far higher pair is a failed winding. A belt that moves and then stops with an error is the next item (`mt200-2022-errors-belt-moves-then-error-brake-and-encoder-check`).
