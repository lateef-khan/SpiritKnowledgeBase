The manual's whole exercise instruction for this machine is one picture of the
placard fitted to the machine. The placard is titled **ABDOMINAL**.

It carries a front and a back body figure with the muscles the exercise works
picked out, then a **START** and a **FINISH** drawing of a person on the machine.

**Placard part number #311008415**, printed beside the picture.

**A second machine prints the same number.** The CSS-TEXT triceps extension manual also gives
#311008415 for its own, different placard - see `css-text-programs-workout-placard`.
Both books were read from the printed page, so this is what Spirit printed, not an
extraction error. Quote the number with the machine beside it, and check the artwork
before ordering.

**No words go with the drawing.** The manual names no muscle, gives no starting
position in prose, no range of motion, no rep or set count and no warm-up. See
`spirit-strength-programs-exercise-instruction-is-the-machine-placard` for what
that means across the range.
