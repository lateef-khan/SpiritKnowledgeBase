**READY MODE**

| Button | Action |
|---|---|
| Stop | No function. |
| Start | Starts the bike. A 3 second count-down runs on the window display first. In MANUAL the bike starts at MIN LEVEL. |
| Fan | Fan on or off. |
| Display key | No function. |

**EXERCISE MODE**

| Button | Action |
|---|---|
| Stop | Stops the bike. |
| Start | No function. |
| Fan | Fan on or off. |
| Display key | Shows the exercise state during a workout. There are three modes: data states, charts and track. |

This console has only four physical keys in the table. Level is adjusted on the touchscreen, and the earlier LCB and LCR manuals list Level Up and Level Down keys that this one does not.
