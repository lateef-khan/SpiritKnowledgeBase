**IDLE MODE** - pick a **guest** or a **personal account**. The main Training screen shows an overview of your activity and shortcuts to an immediate Start, a manually controlled timed workout ("Timer") and up to 3 favourite programs. In guest mode you set age and weight here; in user mode the profile already holds age, weight and so on, so you do not re-create it. Either way the values make the workout summary more accurate.

**SLEEP MODE** - with the setting **"OFF"** the console never sleeps unless the power is switched off. With it set **"ON"**, and no RPM input in idle mode, it sleeps after **15 minutes** with no key press. In sleep mode the TFT LCD shows nothing and the backlight is off; press any key to wake it back to idle mode. In sleep mode the manual notes "Incline = 1, Cooling Fan off".

**CHILD LOCK MODE** - pre-set is CHILD LOCK OFF (disabled), and you set it on or off in Settings. With it on the screen shows "CONSOLE LOCKED". Turn it off by pressing **START and ENTER for more than two seconds**, after which it enters idle mode. No key works while it is active.

**EXERCISE MODE** - from idle, press START to enter MANUAL mode. Age and weight are preset values, time counts from 00:00, all countable data counts from 0 and resistance counts up from 1. Or pick a program icon - MANUAL, HILL, FAT BURN, CARDIO, STRENGTH, HIIT, CUSTOM, HEAT RATE, FITNESS TEST - and press START.

**PAUSE MODE** - press STOP. The exercise parameters are recorded and the resistance level drops to 1. Press START, or touch the Resume icon, and the resistance returns to the level before the pause. With no key press for **five minutes** it returns to idle mode.

**END MODE** - the touchscreen shows the workout summary. With no key press for **3 minutes** after the summary is finished the system enters idle mode.

**RESET MODE** - in idle mode, hold the Stop key for **3 seconds** to restart the system. Clear child lock first. Reset clears all screens and enters idle mode after restarting.

**This differs from the earlier generation.** The LCB 2016, LCB 2019 and LCR 2016 manuals give a sleep timer of 30 minutes; this manual gives 15. The 2023 sleep mode section also mentions "Incline = 1", carried over from a treadmill console. This bike does not incline.
