1. **Press the Program keys** to view the programs, then press **Display/Enter** to select one: **P2-Hill, P3-Fat Burn, P4-Cardio, P5-Strength, P6-Interval**. You can **just press Start** to run it on the preset values.
2. If Display/Enter was pressed, the **incline window displays Age**. Adjust with the speed knob key, press Display/Enter.
3. The **incline window then displays body weight**. **Entering the correct body weight will affect the calorie count.** Adjust, press Display/Enter.
4. The **time window then displays the total workout time desired**. Adjust, press Display/Enter.
5. The **speed window displays the preset max speed of the selected program**. Adjust, press Display/Enter. **Each program has various speed changes throughout; this allows you to limit the highest speed the program will reach at its peak.**
6. **Press Start to begin. The program will begin with a 3 minute warm-up. To bypass it and go directly to the beginning of the program, press Start again.**

**You may press Start at any time during the programming** to start with the information already input.

**The printed profiles are percentages, not speeds.** The max speed you set at step 5 is what those percentages apply to. See `f65-2026-hill-program-profile` and the four profile cards it links to.
