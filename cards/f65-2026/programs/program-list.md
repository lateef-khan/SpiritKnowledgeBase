**Eight built-in programs:**

| Slot | Program |
|---|---|
| **P1** | Manual |
| **P2** | Hill |
| **P3** | Fat Burn |
| **P4** | Cardio |
| **P5** | Strength |
| **P6** | Interval |
| **H1** | Heart Rate, default 60% of projected maximum |
| **H2** | Heart Rate, default 80% of projected maximum |

That is **one Manual program, five preset profiles and two Heart Rate programs**.

**This page names the wrong machine.** The sentence reads *"The F63 / have Eight built-in programs"* - in an F65 owner's manual. The count and the slot names that follow it are the ones printed here, and no F65 figure is given anywhere else to check them against.

The manual describes **no user-defined programs** and no way to store one.
