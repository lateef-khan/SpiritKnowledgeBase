**This is a console message, not one of the E-codes on page 28.**

If the console displays **"Safety key removed, machine stopped, click Replace the key to Operate"**, **put the safety key back to continue using the treadmill.**

The message is exactly what the tether cord is designed to produce. Removing the key also **secures the treadmill from unauthorized use**, and the manual asks you to **remove the tether cord after use** for that reason. See `f65-2026-safety-tether-cord`.
