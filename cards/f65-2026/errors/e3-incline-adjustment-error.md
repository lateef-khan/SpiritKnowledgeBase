**This is E3 (incline adjustment error), not E03 (the hardware current is too large) and not E31 (overtemperature).**

**Meaning:** incline adjustment error.

1. **Check whether the incline cable is properly connected.**
2. **Connect the incline cable and power it on.**
3. **Connect the incline wire and re-calibrate it.**

Step 3 sends you to calibration; see `f65-2026-calibration-procedure`, where the **maximum elevation value is 15**.

**E3 is the only single-digit code in this table.** Every other code is printed with two digits.
