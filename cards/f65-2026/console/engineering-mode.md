The console has **built-in maintenance/diagnostic software**. It can change console settings such as **mile to metric** and **turn off the beeping of the speaker when a key is pressed**.

**To enter:** press and hold down the **Start, Stop and Display/Enter** keys. **Re-power or insert the safety key**, and the **time window will display "F2"**. Use the **speed knob button** to make a selection and press **Display/Enter** to enter it.

| Item | What it does |
|---|---|
| **1. Key Test** | Allows you to test all the keys to make sure they are functioning |
| **2. Display Test** | Tests all the display functions |
| **3. Functions** | Press Display/Enter to access settings, use the speed rotation button key to select |
| 3. I. **Sleep Mode** | Turn on to have the console power down automatically after **15 minutes** of inactivity |
| 3. II. **Pause Mode** | Turn on to allow **5 minutes** of pause, turn off to have the console pause **indefinitely** |
| 3. III. **Lube Message Reset** | Reset lube message |
| 3. IV. **Odometer Reset** | Reset odometer readings |
| 3. V. **Units** | Sets the display to read out in **Mile E** or **Metric H** measurements |
| 3. VI. **Beep** | Turns off the speaker so no beeping sound is heard |
| **4. Security** | Locks the keypad so no unauthorized use is allowed - see `f65-2026-child-lock` |
| **5. Exit** | Leave the menu |

Item 3.III is printed in the manual as **"Lube Messagr Reset"**.

**The lube message has two documented reset routes and the manual never links them.** This menu item is one. The diagnosis guide and the lubrication page instead say to **power the treadmill three times**; see `f65-2026-lube-message`.
