The steps below only work as a sequence; each window is confirmed with Display/Enter before the next appears.

1. **Remove the safety key.**
2. **Press and hold Start and Speed 3** and at the same time **replace the safety key**, until the window displays **"F1"**, then press **Display/Enter**.
3. Set the display to show **Metric or Mile settings (Miles/E vs Kilometers/H)** with the **speed knob key**, then press Display/Enter. The **incline window shows Grade return - ON** (the stop button is pressed and does allow incline to return to zero; **for sale in Europe, EU standards require this to be off**), then press Display/Enter.
4. **Distance window shows roller diameter. Make sure the roller size diameter is 63**, then press Display/Enter.
5. **Time window shows motor diameter. Make sure the motor size diameter is 35**, then press Display/Enter.
6. **Speed window shows pulley diameter. Make sure the pulley size diameter is 100**, then press Display/Enter.
7. **Speed window shows the maximum speed of 12**, then press Display/Enter.
8. **Distance window shows minimum velocity 0.5**, then press Display/Enter.
9. **Incline window displays maximum elevation 15**, then press Display/Enter.
10. **Press the Start button to begin calibration. The process is automatic.**

The manual prints **no units** against the roller, motor and pulley diameters, and **no warning that the belt starts moving** once calibration begins.
