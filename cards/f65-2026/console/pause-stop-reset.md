| Stop key | What happens |
|---|---|
| **Pressed once** | Pause. The tread-belt **slowly decelerates to a stop**, the **incline goes to zero percent**, and the **time, distance and calorie readings hold**. **After 5 minutes the display resets and returns to the start up screen.** |
| **Pressed a second time** | The program ends and a **workout summary is displayed**. |
| **Pressed a third time** | The console **returns to the idle mode (start up) screen**. |
| **Held down for more than 3 seconds** | The **console resets**. |

**To resume while in pause mode, press the Start key.** The **speed and incline return to their previous settings.**

The engineering mode menu has a **Pause Mode** setting: on allows 5 minutes of pause, off makes the console pause indefinitely. See `f65-2026-engineering-mode`.
