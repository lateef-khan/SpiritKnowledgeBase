In Run Mode:

- **Safety Key** - pull it away and the computer shuts down automatically.
- **Stop Key** - stops the treadmill.
- **Start Key** and **Enter Key** - non-functional.
- **Speed Fast / Speed Slow** - change speed by 0.1 KPH (0.1 mph) per press. Held down, the speed runs quickly to MAX or MIN SPEED.
- **Incline Up / Incline Down** - change the incline position by 1 per press. **The maximum incline position is 15 and the minimum is 0.**
- **Speed quick Keys** - set 2/3/4/5/7/9/12 quickly.
- **Incline quick Keys** - set position 1/3/5/7/9/12/15 quickly.
- **Display key** - changes the three training diagrams, from Stats to Charts to Track.
- **Program Key** - non-functional.

Pressing the DISPLAY key during a workout also switches the exercise data on the message window, after which the system scans and displays automatically every four seconds: PROGRAM NAME, LAPS XX, VERT XXX FT (metric shows "M"), SEG TIME XX:XX (not in HRC mode), MAX SPEED XX:XX (not in HRC or MANUAL mode).

**Note on the printed table**: this description of the DISPLAY key behaviour is printed in the manual against the **Fan key** row, and a separate Display key row follows it. The fan key only turns the fan on and off.
