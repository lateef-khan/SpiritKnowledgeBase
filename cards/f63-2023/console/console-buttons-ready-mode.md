In Ready Mode:

- **Safety Key** - insert it in the right position to power on the console. Pull it away and the console shuts down automatically.
- **Stop Key** - no function.
- **Start Key** - starts the treadmill. There is a **3 second countdown** on the window display, then the machine starts running. In MANUAL it starts at MIN SPEED; in a PROGRAM it starts at the program preset value.
- **Enter Key** - changes each function. MANUAL sets time. A pre-set PROGRAM sets time and speed. Heart Rate Control 1~2 sets time, age and the heart rate value. User Program 1~2 sets time, speed and incline. It also swaps and polls the incline and speed profile display.
- **Speed Fast / Speed Slow / Incline Up / Incline Down** - non-functional unless the user has entered a setting.
- **Speed quick Keys** - 7 preset buttons: **2, 3, 4, 5, 7, 9, 12**.
- **Incline quick Keys** - 7 preset buttons: **1, 3, 5, 7, 9, 12, 15**.
- **Fan Switch** - turns the fan on and off.
- **Display key** - no function in this mode.
- **Program Key** - press the ▲ / ▼ program keys to choose, confirm each setting with ENTER, then press START.
