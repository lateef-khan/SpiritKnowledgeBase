The program function has **6 programs**: Manual, Hill, Fat Burn, Cardio, Strength and Interval. It also has **USER1**, **USER2**, **TH60 PCT** and **THR80 PCT**.

Press the PROGRAM ▲ / ▼ keys to choose one, confirm every setting by pressing ENTER, then press START to exercise.

What ENTER can set depends on the program: MANUAL sets time, a pre-set PROGRAM sets time and speed, Heart Rate Control 1~2 sets time, age and the heart rate value, and User Program 1~2 sets time, speed and incline.
