1. Remove the safety key.
2. Press and hold **Start** and **Speed ▲**, and at the same time replace the safety key. Keep holding Start and Speed ▲ until the window displays **"Factory settings"**, then press **Enter**.
3. Set the display to Metric or English (miles or kilometres) with the **incline ▲ / ▼** key, then press Enter. The maximum speed value shows in the speed window and the maximum elevation value shows in the incline window.
4. **Grade return - On.** This lets the incline return to zero when Stop is pressed. Machines sold in Europe need it off, because EU standards require that.
5. Press **Start** to begin the calibration. The process is automatic and **the speed starts up without warning, so do not stand on the belt.**
