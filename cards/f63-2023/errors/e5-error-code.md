**This is E5, not E6 (controller component fault) and not E0.**

**Definition**: the communication between the console and the controller is poor. It may be a faulty main control wire, but the display board or the controller may also be malfunctioning.

**Cause**: the main control wire is possibly broken, but a component of the controller or the console can also cause it.

| Part | Troubleshooting |
|---|---|
| Lower controller board | Replace the main control wire. |
| Main control wires | Reinsert or replace the main control wire. |
| Display board | Replace the display board. |
