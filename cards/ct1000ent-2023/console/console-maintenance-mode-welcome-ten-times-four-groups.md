**Press the "Welcome" button ten consecutive times to enter engineering mode.** The screen it opens
is headed **Maintenance Mode** and carries a **To Android** button and four groups. **Set the machine
type first** - under About This Machine, "There are three modes: Treadmill / Elliptical / Bike. The
selection must match the actual machine otherwise it will be unable to operate the machine
properly."

| Group | Item | What the manual says |
|---|---|---|
| About This Machine | Type | Treadmill / Elliptical / **Upright Bike / Recumbent Bike** - the table names four, the sentence above names three. Must match the machine. |
| | Reset Odometer, Display Brightness | Shown on the screenshot; not described |
| Preferences | Beep | ON / OFF for beep sound mode |
| | GS Mode | Treadmill mode only. **ON: the incline will not resume. OFF: the incline will resume.** Under Elliptical / Bike mode set it OFF. |
| | Pause Mode | ON / OFF Pause Time Mode, set in **Minutes : Seconds** |
| | Sleep Mode | ON / OFF. "The display always lights when turns off. When there is no action for **15 minutes** after turning on the power, it enters sleep mode." |
| | Workout Time Limit | ON / OFF; sets a limit on machine usage time |
| Machine Setup | Language | The default language for the first-page window; **12 languages** in the menu |
| | Date & Time | Sets the console time |
| | Units | English / Metric |
| | Video | **STB / TV / None** |
| | Protocol | **C-SAFE or CAB** for the TV switching box; choose one only |
| | WiFi | Opens the WiFi setting |
| | Software, Firmware | Update automatically over a wired or WiFi network, or from USB - `ct1000ent-2023-console-software-update-usb-root-and-automatic` |
| | App Manager | Updates the app software automatically over a wired or WiFi network |
| Service | Key Test, NFC Test, Drive Motor Test, Incline Motor, Error Code Log | `ct1000ent-2023-console-incline-only-calibration-and-service-tests` |

**Fifteen minutes, not thirty.** The CT900ENT and CT800ENT-2022 touchscreens sleep after 30 minutes
(`ct900ent-console-engineering-mode-settings-max-speed-12-or-20-and-incline-only-calibration`,
`spirit-ct800ent-console-machine-information-gs-beep-sleep-safety-zeroing`); the 2024 Hello-Guest
consoles say 15 (`cu800ent-2024-console-maintenance-mode-and-engineering-menu`).

**"Welcome", not Home and not Hello Guest.** The CT800ENT, CT850ENT and CT900ENT open their menu on
ten presses of the Home icon (`spirit-ent-console-enter-engineering-mode`); the 2024 ENT machines on
ten presses of Hello Guest. The word on this console's screen is Welcome.

The owner's manual for this machine is not in the repository; nothing here is corroborated by it.
