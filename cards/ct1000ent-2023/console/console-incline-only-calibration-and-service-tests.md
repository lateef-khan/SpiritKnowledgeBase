The Service group of Maintenance Mode (`ct1000ent-2023-console-maintenance-mode-welcome-ten-times-four-groups`)
holds five items, word for word:

| Item | What the manual says |
|---|---|
| Key Test | Press the "button" to start calibration. The corresponding screen display of the physical button flashes. |
| NFC Test | Correspond to the location of the NFC sensor; when the sensor is detected, the information is displayed on the screen. |
| Drive Motor Test | Tests the corresponding information of motor kilometres per hour and rotational speed. |
| Incline Motor | **Press "Calibration" to start calibrating. It calibrates the incline motor only. There is no calibration for the tread belt.** When calibration is completed the calibration window disappears. |
| Error Code Log | Diagnoses and saves malfunction error messages for a technician. **Press "Error Code Log" ten consecutive times to clear** the error messages. |

**Calibration on this console is the incline only, exactly as on the CT900ENT**
(`ct900ent-console-engineering-mode-settings-max-speed-12-or-20-and-incline-only-calibration`). No
safety key gesture, no wheel size and no belt run apply. The Key Test line says "to start
calibration", which is a copy-and-paste from the Incline Motor line; the test flashes the on-screen
copy of each physical button pressed.

**The Error Code Log is the console's fault history** and its entries are held with the error cards;
this card records only how to reach and clear it. The manual's troubleshooting matrix sends the
reader to "the calibration procedure" for a belt speed that does not match the display and for an
incline position that does not match the console, which on this machine means this incline
calibration.

The owner's manual for this machine is not in the repository; nothing here is corroborated by it.
