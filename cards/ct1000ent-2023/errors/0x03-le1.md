**This is 0x03, and it is not any other code in the same table.**

| Field | Value |
|---|---|
| Error Code | 0x03 |
| Description, word for word | LE1 |
| Remarks Error | By Inverter Error |

**The manual prints no cause and no fix for this code.** The table has three columns and none of them is a solution column; the only tool the error chapter names is a multi-meter. Anything beyond the description above would be invention. The CTSBS900 slat-belt treadmill explains `LE1` with a cause and a remedy for its own inverter (`ctsbs900-le1-inverter-low-voltage`) - a different machine, and the only Spirit page that says what this mnemonic means. The CT900ENT lists what looks like the same fault under a two-digit hex code (`ct900ent-errors-01h-low-voltage-trip`).

The whole table is on `ct1000ent-2023-errors-error-code-list-25-hex-codes`. The console's Error Code Log stores these codes and clears with ten presses of its button (`cu900ent-error-code-log`).
