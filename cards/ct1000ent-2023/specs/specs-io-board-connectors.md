The console's I/O board is drawn from underneath with these call-outs:

| Call-out | Pins printed |
|---|---|
| Key Board CONNECT | **20 PINS** |
| SYSTEM CABLE CONNECT | **8 PINS** |
| TV CONNECT | - |
| HDMI CONTACT | - |
| CONTACT GROUND | - |
| Internet CONNECT | - |
| C-safe CONNECT | - |
| Console Power CONNECT | - |

The 8-pin system cable is the cable the error chapter calls the "8-PIN cable"; the troubleshooting matrix
of the same book, copied from an older machine, talks about a "12 PIN Computer connector" that this
machine does not have. The CT900ENT draws the same board with a **24-pin** keyboard connector.
