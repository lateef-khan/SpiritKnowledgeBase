Two drawings, names only - **no item numbers, part numbers or quantities**.

**Drawing 1 - the assembled rower, fifteen labels**

| Left column | Right column |
|---|---|
| Console Assembly | Chain Cover (R) |
| Latch | Chain Cover (L) |
| Handlebar Cover | Nylon Net |
| Pedal & Wire Tie Mount | Chain Cover Foam |
| Seat | Handle |
| Aluminum Track | Front Stabilizer |
| Handgrip End Cap | |
| Rubber Foot | |
| Rear Stabilizer | |

**Drawing 2 - the bare frame, seven labels**: Console Holder Assembly, Handle, Pedal, Seat
Attaching Board, Flywheel & Fan, Flywheel Pulley / Latch / Spring Latch (one leader), Handle Bar
Cover.

**What the names tell you.** The mesh over the fan is a **Nylon Net** here, where the CRW800 books
call the same guard a *Galvanized iron net* (`spirit-crw800-specs-outline-part-names`), and this
drawing has no *Controller Assembly* - the XRW600 has no wireless resistance buttons on the
handle. The second drawing labels a **Flywheel & Fan**, which is the only place in either XRW600
manual that names the resistance mechanism; the owner's manual never does
(`spirit-xrw600-specs-resistance-mechanism-never-named`,
`xrw600-2019-specs-service-manual-names-a-fan-flywheel-and-gear-motor`).

The chapter heading reads **DW400-YR001** while the cover and every other heading read
DW400-YR002 - a stale heading, not a second machine.
