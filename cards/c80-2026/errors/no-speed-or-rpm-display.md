1. **First make sure the speed sensor cable is properly connected to the back of the console.**
2. If the cable is connected correctly, the fault is either the sensor's position or the sensor itself.
3. Using the parts replacing guide, **remove the front right plastic cover of the main frame**. Verify that the **gap between the speed sensor and the magnet on the front roller is less than 2 mm**.
4. **If the sensor position is correct, the speed sensor should be replaced.**

The gap figure is also stated on its own card, because it is the number a technician looks up without reading the whole symptom.
