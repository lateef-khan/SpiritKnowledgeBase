The console has **three** buttons.

| Button | What it does |
|---|---|
| **Settings** | 1. In the settings state: switch values; each press increases the value. 2. In query mode: check the maximum (MAX) and average (AVG) of speed/heart |
| **Start/Pause** | 1. In settings mode: confirm the current value. 2. In stop state: run the console. 3. In working state: pause exercise. 4. Hold press for 3 seconds to return to the IDEL mode. |
| **Mode** | 1. In stop state: switch function modes. 2. In pause state: enter query mode and switch the display of heart rate/Speed. 3. In working state: switch the display of various functions. |

Two things about this table as printed:

- The Settings entry ends mid-phrase at **"speed/heart"**. The manual gives no more of that sentence, and no word is added here.
- **"IDEL"** is the manual's spelling throughout, for what is elsewhere the idle mode.

The printed table has a **Graphics** column showing the button icons. That column is images only and does not survive extraction, so the buttons are identified here by their printed descriptions.

**There is no separate start button, no stop button and no resistance button on the console.** Resistance is set by the Gear Shift Assembly lever on the right upright, not from the console.
