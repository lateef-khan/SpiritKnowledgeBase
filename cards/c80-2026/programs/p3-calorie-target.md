**P-3 Mode - Calorie Target Exercise Mode.**

1. Press the **"Set"** button to set target calories. **Range: 50-500 kcal.**
2. After setting, press the **"Start/Pause"** button to start or pause.
3. During exercise, press buttons to check related exercise data.
4. Press and hold the **"Start/Pause"** button to end exercise and return to the IDEL mode.

**There is a second calorie program.** P-5 takes the same 50-500 kcal range but fixes the workout time at 15 minutes; this one runs until the calories are reached with no time limit.

The manual **never asks for the user's age or weight** in any program, so it does not say what the calorie figure is calculated from.
