**P-2 Mode - Distance Target Exercise Mode.**

1. Press the **"Set"** button to set exercise distance. **Range: 1.00-10.00 km (miles).**
2. After setting, press the **"Start/Pause"** button to start or pause.
3. During exercise, press buttons to check related exercise data.
4. Press and hold the **"Start/Pause"** button to end exercise and return to the IDEL mode.

**There is a second distance program.** P-6 sets the same kind of target but fixes the workout time at 10 minutes; this one runs until the distance is reached with no time limit. The manual prints P-6's range as **1.0-10.0** and this one's as **1.00-10.00** - the same bounds at different printed precision, which is how it appears on the page.

The range is printed as **"km (miles)"** and the manual never says which unit the console is set to or how to change it.
