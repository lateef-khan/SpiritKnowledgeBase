**P-4 Mode - Heart Rate Target Exercise Mode, with a time target that can also be set.**

1. Press the **"Set"** button to set **exercise time and target heart rate**. **Heart rate range: 100-180.**
2. After setting, press the **"Start/Pause"** button to start or pause.
3. During exercise, press buttons to check related exercise data.
4. Press and hold the **"Start/Pause"** button to end exercise and return to the IDEL mode.

**This is the only program that takes two settings.** The manual gives a range for the heart rate but **prints no range for the time** in this program; P-1's 5-30 minutes is stated only for P-1, so do not quote it here.

**This program needs a working pulse signal.** The manual warns in capitals: **do not use the heart rate program if your heart rate is not registering properly on the display.** The machine reads pulse from a Bluetooth heart rate belt - there are no hand grip sensors on it.

The manual also does not say what the machine does when the target is reached or missed. On a manual treadmill it cannot change speed or incline, so the program can only display against the target.
