**P-1 Mode - Time Target Exercise Mode.**

1. Press the **"Set"** button to set exercise time. **Range: 5-30 minutes.**
2. After setting, press the **"Start/Pause"** button to start or pause.
3. During exercise, press buttons to check related exercise data.
4. Press and hold the **"Start/Pause"** button to end exercise and return to the IDEL mode.

**This is the only program whose time the user chooses.** P-5 fixes the time at 15 minutes and P-6 fixes it at 10 minutes, and neither lets the time be changed - so a customer who wants a 20-minute calorie workout has to use this program and watch the calorie readout instead.

The manual prints **no step size** for the setting, so it does not say whether the time moves in one-minute or five-minute increments.
