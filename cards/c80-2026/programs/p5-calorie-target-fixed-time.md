**P-5 Mode - Calorie Target Exercise Mode, Fixed Time.**

1. Press the **"Settings"** button to set the target calories. **Range: 50-500 kcal.**
2. **Exercise time is fixed at 15 minutes.**
3. After setting, press the **"Start/Pause"** button to start or pause.
4. During exercise, you can press buttons to check relevant exercise data.
5. Hold the **"Start/Pause"** button to end exercise and return to the IDEL mode.

**The fixed 15 minutes cannot be changed.** The manual gives no way to alter it in this program. A customer who wants a different length with a calorie goal has to use P-3, which takes the same 50-500 kcal range with no time limit at all.

This is the only program entry that writes the button as **"Settings"** rather than **"Set"**; the button table on page 10 calls it Settings, so it is the same key throughout.
