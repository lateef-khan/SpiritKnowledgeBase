The manual gives no yes or no. It says:

**"To check if your Garmin device can be used for heart rate transmission, please refer to the list of supported devices provided on www.soletreadmills.com"**

So the answer for any particular Garmin model has to come from that list, not from this manual. **No supported models are named in the manual**, and no other brand of watch is mentioned.

What the manual does state elsewhere is that the machine supports **Bluetooth heart rate belts** - see `c80-2026-bluetooth-heart-rate-belt`.
