The Sole model number is the six digit SKU in the Spirit database `Models` table. The service manual carries a different code, the Dyaco factory code, on its cover.

| Model | Sole model number (SKU) | Code on the manual cover |
|---|---|---|
| CC81 | 581519 | XS500-YP002 |

**The database does not give this machine a model year.** The row is named only "SOLE CC81". The wider Sole convention is that the last two digits of the model number are the model year, but there is no year in the name to check the suffix `19` against, so the year is not stated here.

Two other Sole rows sit near this one and are **not** the CC81:

| ModelNumber | ModelName | ModelType |
|---|---|---|
| 520516 | SOLE SC200 | Stepper |
| 520517 | SC200 | Elliptical |

A search for an SC300 row returned nothing, so the SC300 named in the 2021 Bluetooth tracker has no row in this table.
