| Field | Value |
|---|---|
| Sole model number (SKU) | **581519** |
| Code on the service manual cover | XS500-YP002 |
| Manual publisher | Dyaco International Inc. |
| Console | 5.5" LCD display. Contains the key controls and the LCD display. |
| Main controller | Includes the power supply and the motor driver control circuit. |
| Resistance | Tension motor pulling a steel cable on to a brake, DC 4.5 to 7.5 V, 20 working resistance levels. |
| Sensors named | Speed sensor, rotary switch, heart rate receiver. |
| Family | Vertical climber, drive belt from a drive pulley to a flywheel, idler wheel tensioner. |

The manual describes the console as the "interface that controls all functions of the climber".

The model number comes from the Spirit database `Models` table, not from the service manual. The manual prints only the factory code.
