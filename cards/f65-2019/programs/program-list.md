The program function has **6 programs**: Manual, Hill, Fat Burn, Cardio, Strength and Interval.

It also has **USER1, USER2, THR60 PCT and THR80 PCT**. (The manual prints the third one as "TH60 PCT" in the list and "THR80 PCT" for the fourth.)

Press the PROGRAM keys (▲/▼) to choose one, confirm every setting with ENTER, then press START.

Setting ranges by program, from the ENTER button description: MANUAL sets time; a preset PROGRAM sets time and speed; Heart Rate Control 1~2 sets time, age and the heart rate value; User Program 1~2 sets time, speed and incline.
