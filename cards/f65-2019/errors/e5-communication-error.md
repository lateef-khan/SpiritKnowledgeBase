**This is E5, not E4 (motor power wire) and not E6 (lower controller fault).**

**Definition**: poor communication between the console and the lower controller. It is almost always a bad main control wire, but the console board or the lower controller can also be at fault. The signal runs over the main control wire.

| Part | Troubleshooting |
|---|---|
| Lower controller board | Replace main control wire. |
| Main control wires | Reinsert Main control wire. Replace main control wire. |
| Display board | Replace upper control board. |

The table's first row is printed exactly as above: the part is named "Lower controller board" but the action given is to replace the main control wire.
