**This chapter has one User program, not U1/U2, and no naming.** 1. Select User, Enter. 2. Enter Weight first (Up/Down), Enter. 3. Enter Age, Enter. 4. Enter Time, Enter. 5-6. Build the level profile column by column to all twenty segments. 7. Start begins and saves, Enter modifies, Stop exits. Mid-program Up/Down changes only the present column. Display scrolls data; a summary ends the session.
