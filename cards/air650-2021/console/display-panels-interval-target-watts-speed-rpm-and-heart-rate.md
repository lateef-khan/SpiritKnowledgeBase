**Interval Display.** Shows all details of the Interval 20/10, 10/20 and Custom modes. The top-most blocks tell which interval mode is operating and whether the current interval is in **WORK** or **REST**. TOTAL TIME shows the total run time while the large numeric display shows the work or rest segment time. **88/88** shows the current interval and the total number of intervals.

**Target Time, Distance & Calories Display.** When a target mode is running the target symbol is active next to the value. TIME alternately shows remaining and elapsed time; DISTANCE counts down in miles or kilometres depending on the console setup ([units card](metric-or-imperial-and-the-engineering-mode-behind-start-and-enter.md)); CALORIES counts down the target to zero.

**Watts, Speed & RPM.** Shown during all modes. Watts varies through the workout, monitoring the work produced; Speed is derived from the current RPM (pedal speed), in miles or kilometres per the setup; RPM is pedal rotations per minute.

**Heart Rate Display (chest strap not included).** When the console detects a signal from a wireless monitor the BPM shows in the large three-digit field and the heart icon flashes. **If the console detects no signal it shows `- - -` in that field.** In target heart rate mode the target range is active on the right of the panel, the arrows flash to say pedal faster or slower, and the Target Heart Rate icon lights when you are in range. Three dashes is not a fault - it means no strap signal ([strap card](heart-rate-from-a-wireless-chest-strap-with-no-bluetooth-and-no-grips.md)).

The Spirit AB900 service manual prints the same four panel descriptions word for word as its Function Description ([Spirit twin](../../shared/console/spirit-bike-console-air-bike-display-panels.md)).
