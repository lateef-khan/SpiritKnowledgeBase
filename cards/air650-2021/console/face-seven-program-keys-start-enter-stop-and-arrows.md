The console prints **seven program keys** - INTERVAL 20/10, INTERVAL 10/20, INTERVAL CUSTOM, TARGET TIME, TARGET DISTANCE, TARGET CALORIES and TARGET HEART RATE - and four control keys. "Selecting one of the 7 program buttons will immediately begin the set up of that program."

| Key | Function as printed |
|---|---|
| START | Begin a program selection, restart a paused program, or temporarily pause an ongoing program |
| ENTER | Confirm values when making adjustments in a program mode |
| STOP | End a mode |
| UP / DOWN arrows | Increase or decrease program selection values |

**There is no Bluetooth key.** The Spirit AB900 console this one is derived from has a BLUETOOTH key on its keypad; the AIR650 service note says "Blue Tooth: No", and the AIR650 owner's manual prints no Bluetooth key and no app page. What each program does is on the Programs cards; the four display panels are on [the panels card](display-panels-interval-target-watts-speed-rpm-and-heart-rate.md).
