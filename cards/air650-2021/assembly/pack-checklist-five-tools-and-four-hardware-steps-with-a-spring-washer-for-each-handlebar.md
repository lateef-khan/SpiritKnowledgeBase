|---|---|---|---|
| 1 | 50 | 3/8" x 2" Carriage Bolt | 2 |
| 1 | 71 | 3/8" x 25 x 2T Flat Washer | 4 |
| 1 | 84 | 3/8" x 2-1/4" Hex Head Bolt | 2 |
| 1 | 135 | 3/8" Cap Nut | 2 |

| 3 | 136 | M8 x 20 mm Bolt | 2 |

| 3 | 148 | M16 x 3T Spring Washer | 2 |
| 4 | 58 | M5 x 12L Phillips Head Screw | 4 (printed "4cs") |

This is the Spirit AB900's kit and tool list under another name - same numbers, same sizes - except that the Spirit book calls item 148 a "star washer, 16.7 mm dia x 2.5T" and this book calls it an "M16 x 3T spring washer"; the drawing on both is the toothed washer that sits under each handlebar. The Spirit book also lists the kit as a table with the carriage bolt printed 3/8" x 53 mm; here it is 3/8" x 2". No parts list and no rubber-mallet note are printed in this book.
