"These TARGET programs operate in the same manner. You select which value you want to focus
on and you set a goal as the target value."

**Launch:** press any Target mode button. **Setup:** enter the target value with the up/down
arrows and press ENTER. "If no particular value has been set, then the console will default
to the most recent target value for each mode." **Start:** the targeted field is displayed
and the target counts **down (Time and Calories) or up (Distance)**. **End:** STOP ends the
program at any time and a workout summary is displayed.

On the display the target symbol sits next to the value in target mode; time alternately
shows remaining and elapsed, distance counts in miles or kilometres per the console setup,
and calories count the target down to zero.
