"Your Airbike Pro offers several different program selections with different intensities and
durations ... Selecting one of the **7 program buttons** will immediately begin the set up of
that program":

| Button | Mode |
|---|---|
| INTERVAL 20/10 | eight Tabata intervals, 20 s work / 10 s rest |
| INTERVAL 10/20 | eight intervals, 10 s work / 20 s rest |
| INTERVAL CUSTOM | your own work, rest and number of intervals |
| TARGET TIME | count a set time down |
| TARGET DISTANCE | count a set distance |
| TARGET CALORIES | count set calories down |
| TARGET HEART RATE | a BPM range from your age (chest strap not included) |

**Quick Start** needs no button: "begins when you get on the bike and begin pedaling ... As
the pedals stop moving, the mode will end." START begins a program, restarts a paused one
or pauses it; ENTER confirms values; STOP ends a mode; the up/down arrows change values.
Every mode ends with a workout summary (total time, distance, watts).

There are no resistance levels - the fan sets the load - and no preset profiles. The Spirit
AB900 air bike has the same console modes; see `see_also`.
