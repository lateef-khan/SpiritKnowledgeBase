"The Custom Interval mode allows you to set up the length of the Work / Rest intervals and
the total amount of intervals."

**Launch:** press the INTERVAL CUSTOM MODE button. **Setup:** enter the total number of
intervals, then the work and rest interval times - adjust each with the up/down arrows and
press ENTER to confirm. **Start:** a countdown from 3 begins each interval. **End:** the
program ends after the last interval; STOP ends it at any time, and a workout summary is
displayed.
