The Settings page opens from the **gear icon in the status bar** of the home screen. The screenshot in
the calibration chapter shows ten items:

| Item | As shown |
|---|---|
| Units | **Imperial / Metric** |
| Child Lock | A switch |
| Sleep Mode | **ON / OFF / Retail** - three positions, Retail selected in the screenshot |
| Screen Brightness | A slider |
| Date & Time | May 9, 2023, 02:37 PM |
| WiFi | The connected network name |
| Language | English |
| Software | v2.0, "Up to date" |
| Media Apps | An **Update** button |
| Passcode | A switch |

**The manual describes none of these**; they are what the screenshot shows on the way to the hidden
calibration page (`xt685ent-2023-console-calibration-behind-five-taps-on-settings`). No sleep
time-out is printed for ON, and the manual does not say what Retail does.

**The XT485ENT Settings screen is a different layout** - Display, WiFi, Bluetooth, Software, Date
Time, Child Lock, Units - and its hidden page needs a password
(`xt485ent-2023-console-settings-menu`,
`xt485ent-2023-console-calibration-behind-the-software-version-and-password-20160620`).

The owner's-manual view of this console's child lock is `xt-2023-console-child-lock`, and of its
profiles and passcode `xt685ent-2023-console-profiles-and-account-link`.
