**Users can create up to 12 Custom programs, each with fully customisable speed and incline
patterns.**

1. In the **Custom** tab, press **"+ New program"**.
2. Name your program and start editing.
3. **Mapping the Speed profile is required; the Incline profile is optional.**
4. **Connect dots** to map your load through the program, from easiest at the bottom to hardest at
   the top.
5. **Each segment's duration depends on the selected total time** - you can set the total time right
   before you start.

**Speed levels in the pattern are relative.** The maximum value can be set after the pattern is
finished, and **all the segments are then adjusted proportionally**.

**Incline values are absolute and vary from 0 to 15.**

The XT485ENT builds its own the other way round - by sliding profile columns, saved as one of 12
**templates**, and a template is only visible to the user who created it. See
`xt485ent-2023-programs-custom-and-templates`.
