**This program takes you through high and low intensity periods followed by strength exercises using
free weights; elevation will spike in different segments. Work and recovery time can be customised
for this program.**

The manual prints the structure as a table of **five numbered cycles**, each of Cardio, Strength and
Rest, between a warm-up and a cooldown:

| Phase | Speed | Incline |
|---|---|---|
| Warm-up, 3 segments | 1, then 2, then 3 | 0, 0, 0 |
| Cardio (each of the 5 cycles) | max | the incline you set |
| Strength (each of the 5 cycles) | 0 | 0 |
| Rest (each of the 5 cycles) | 2 | 0 |
| Cooldown, 2 segments | 2, 2 | 0, 0 |

The printed row reads `1 2 3 | max 0 2 | max 0 2 | max 0 2 | max 0 2 | max 0 2 | 2 2` for speed and
`0 0 0 | incline 0 0 | incline 0 0 | incline 0 0 | incline 0 0 | incline 0 0 | 0 0` for incline -
twenty values against a header of warm-up, five Cardio/Strength/Rest cycles and a cooldown, which is
what the table above rebuilds. **The belt is stopped for the strength phase; that is what speed 0
means.**

**The manual names no strength exercises and prints no interval-count or interval-time defaults.**
The button-console XT385, XT485 and XT685 manuals name five dumbbell exercises and print defaults of
10, 20 or 30 intervals, a 1:00 interval and a 0:30 recovery; if you need those, see
`xt-2023-programs-fusion-strength-exercises` and `xt-2023-programs-fusion-workout-structure`. **The
XT485ENT prints something different again** - a Fusion with no free weights at all.
