**The 5K and 10K programs automatically set a target distance for your workout - 5 km and 10 km
respectively.**

On the **program setup page**, the console shows the **estimated total time for the run, based on
the target speed you have selected.**

That is all this manual prints about them. It gives no age or weight prompt and no default speed.
**Do not answer from the button-console card:** on the XT385, XT485 and XT685 the same two programs
are reached with the PROGRAM key and ask for Age (default 35), Body Weight (default 150 lb / 70 kg)
and Speed (default 0.5 mph), and the estimated time is not mentioned. See
`xt-2023-programs-5k-10k-run-xt385-xt485-xt685`.

The XT485ENT owner's manual documents no distance run program at all.
