**HILL, FATBURN, CARDIO, STRENGTH and HIIT run the segment values below.** Speed values are a
percentage of the max speed you set before starting; incline values are absolute. See
`spirit-xt-ent-programs-speed-percent-of-max`.

The printed header names 22 columns: **Warm-up, segments 1 to 20, and Cooldown.** Every printed row
holds **26 values**, so four values in each row cannot be assigned to a named column. The values are
preserved below in their printed left-to-right order; consult page 36 of the manual before relying
on an exact segment.


**The Strength speed row is the odd one out:** it opens `20 30 40 63` where the other four rows open
`20 30 40 50`. It still carries 26 values, so this is what the source prints, not a dropped value.

**No other Spirit manual prints these numbers.** The button-console XT385, XT485 and XT685 manuals
print a profile picture only, with no numeric table. The XT485ENT prints a written description of
each program instead. The CT900ENT, the 7.0T and the MT200 all print charts with different values.
