**Heart rate, Time, Distance and Calories are "target" programs: each one ends when the target you
set before starting is reached.** They live under the **Targets** tab of the All Programs screen.

**This console counts heart rate as a target program.** The button-console XT385, XT485 and XT685
have three target programs - Target Time, Target Distance and Target Calories - and keep the heart
rate programs separate; see `xt-2023-programs-target-programs-xt385-xt485-xt685`. The XT485ENT
documents no target programs at all.

The manual prints no default values for Time, Distance or Calories on this console. For the heart
rate target, which has its own setup rules, see `xt685ent-2023-programs-heart-rate-program`.
