| Window | What it reads | Range |
|---|---|---|
| **Stroke/min** | The equivalent strokes per minute | Not stated |
| **Time** | The time; **accumulated for each workout mode**. When set to count down it shows the time remaining | **00:00 - 99:59** (minute : second) |
| **Distance** | Accumulated for each workout mode. When set to count down it shows the remaining distance | **0 - 9999**, then switches to the format **1X.XX** above 9999 |
| **Heart Rate** | Beats per minute | **40 - 220 bpm** |
| **Calories** | The value of calories dissipated | **0 - 999** |
| **Watts** | The Watt value **for each stroke** | **0 - 2000** |
| **Level** | The current resistance level | **1 - 16** |

**Two windows change format rather than overflow, and both look like errors if you do not know.**

- **Watts above 999 uses a decimal point to mean thousands.** 1000 shows as **1.00**, 1009 as
  **1.01**, 1240 as **1.24**, 1250 as **1.25**, 2000 as **2.00**. A rower showing "1.24" is reading
  1240 watts, not 1.24 watts.
- **Distance above 9999 switches to 1X.XX.**

**The resistance level is shown by dots, two levels to a dot.** *"Level 1 and 2 would light the first
dot, level 3 and 4 would light the second dot, etc."* - so the sixteen levels are drawn as eight
dots, and two adjacent levels look identical on the display.

**The heart rate window shows nothing at all when there is no signal.** When a signal is detected the
**small dot at the lower right corner of the heart rate window blinks** together with the value. An
empty window is the manual's own way of saying "no strap and no grip contact", not a fault.

**Watts is per stroke, not an average.** The manual says so in those words and gives no averaging
window.

**The 500M/TIME window is not in this list** - it appears only in four of the workout modes and
alternates with the wave pattern: `crw800-2024-console-scan-500m-time`.

**Every range above is printed identically in all four manuals** - CRW800-2021, CRW800-2024,
XRW600-2019 and XRW600-2021. Nothing widens or narrows between the printings.

**The XRW600 books add one bullet under Calories that the CRW800 books do not print:** *"The calorie
value is based on built in estimates of the average user and may not reflect accuracy. To have a more
accurate basis of caloric burn - please contact your physician and they can assist you."* The
CRW800's calorie entry stops at the 0 - 999 range. **The disclaimer is the XRW600's alone**, though
the estimate behind the number is the same on both.

**A wording difference with no figure behind it:** the CRW800 books say the calorie window shows
*"the value of calorie dissipated"*, the XRW600 books *"the value of calories burned"*. Same window,
same range.
