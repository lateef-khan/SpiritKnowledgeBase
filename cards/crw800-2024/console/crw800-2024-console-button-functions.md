**Five keys, and what each one does depends on which of three states the console is in: idle,
setting, or stopping.**

| Key | What it does |
|---|---|
| **MODE** | **In idle mode**, each press steps to the next workout mode. **To choose one**, stop when the matrix window shows the pattern you want; the parameter window value to be set then blinks once a second. |
| **UP** | **In the setting mode of a target workout**, counts the parameter up. **One increment per press.** |
| **DOWN** | Counts the parameter down, one increment per press. |
| **START/STOP** | **In idle mode**, enters **Manual** workout mode. **In setting mode**, confirms the value the window is showing and starts the workout. **During a workout**, ends it - all message windows stop counting. |
| **RESET** | **In stopping mode**, switches the display back to idle mode. **The Reset button is valid only in stopping mode.** **Held for 3 seconds under any mode, it turns the console on again.** |

**The default workout mode after turning the unit on is Manual.**

**The Mode key steps through eleven modes in this order:** MANUAL, DISTANCE, TIME, CALORIES,
20/10 INTERVAL, 10/20 INTERVAL, CUSTOM INTERVAL, FAT BURN, CARDIO, STRENGTH, GAME. **What each of
those modes does is a programs question**, not a key question; this card covers only the order the
key walks them in.

**The console drawing says "Ten innovative programs" while the Mode list has eleven entries.** The two
statements are in the same book, on p. 16 and p. 15, and nothing in it resolves them; both are
reproduced as printed. See `crw800-2024-console-screen-overview`.

**There is no pause on this console.** START/STOP ends the workout; it does not hold the readings for
a period and let you resume. Do not offer this machine the five-minute pause of the LED ellipticals
and bikes (`spirit-ce-console-stop-button-press-once-twice-hold`) or the thirty-second staircase lock
of the CSC900 (`csc900-2024-console-start-stop-pause-thirty-seconds`).

**"Turns on the console again" is the manual's own wording** for the three-second hold. It does not
say what is cleared, or whether the odometer survives.
