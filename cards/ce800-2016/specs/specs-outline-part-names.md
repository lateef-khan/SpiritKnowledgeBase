The book is titled **XE890B-AE10M** on its cover; the ingest table maps it to the 2016 CE800.

**p. 4, the shrouded machine:** Handle Bar Axle Inner Cover, Console Assembly, Front Handle Bar
Cover, Rear Handle Bar Cover, Console Mast Cover and Console Mast Cover (R), Round Disk Cover,
Pedal Arm Cover (R), Front Stabilizer Cover, Side case (L) and (R), Connecting Arm Cover A (L) and
(R), Connecting Arm Cover B (L) and (R), Pedal (L), **Incline Bottom Cover**, Rear Stabilizer Cover
(A) and (B), Wheel Cover, End Cap, Aluminum Step Rail.

**p. 5, the frame with the shrouds off:** Swing Arm (L) and (R), Console Mast,
**Generator/Brake Controller**, Drive Belt, Flywheel, Cross Bar, Connecting Arm (L) and (R), Main
Frame, Pedal Arm (L) and (R), End Cap, Aluminum Step Rail, Aluminum Track.

**"Incline Bottom Cover" is a leftover label.** Nothing else in the book gives this machine an
incline: the electrical configuration names a console, a main controller and a generator flywheel
only, the circuit diagram has no incline motor, and the disassembly chapter never removes one.
The console chapter's Function page carries the same inheritance - it says LEVEL "displays the
incline position from 0 to 20". Read both as text carried over from an incline model.

The Outlines chapter prints **no dimensions, no machine weight and no user weight limit**. The
2020-version CE800 labels a different frame with a beam cover and a rear rail assembly
(`ce800-2021-specs-outline-part-names`).
