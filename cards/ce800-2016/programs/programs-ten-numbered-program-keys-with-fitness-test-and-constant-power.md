The console drawing on the Function Button Locations page numbers ten program keys, five
down each side of the LED matrix. The same digits are printed on the keys, so they double as a
number pad:

| Key | Left column | Key | Right column |
|---|---|---|---|
| 1 | MANUAL | 6 | INTERVAL |
| 2 | HILL | 7 | CUSTOM |
| 3 | FAT BURN | 8 | FITNESS TEST |
| 4 | CARDIO | 9 | HR |
| 5 | STRENGTH | 0 | CONSTANT POWER |

That is one Custom key, one Fitness Test key, **one** heart rate key and a **Constant Power** key.

**The book contradicts its own drawing twice.** The caption beside the drawing reads "(Manual,
Hill, Fat Burn, Cardio, Strength, Interval, Custom, Fit-Test, 2HR)" - two HR keys and no Constant
Power. The Quick Start spec on p. 13 says you choose a program with the keys "MANUAL, PROGRAM,
CUSTOM, FIT-TEST, HRC1, HRC2" - again two heart rate programs, again no Constant Power. The drawing
is the only one of the three that shows the console, and it is the one that agrees with the CE800
2013 owner's manual, which describes a single HR program and a Constant Power program
(`spirit-ce-programs-heart-rate-control-operation`, `spirit-ce-programs-constant-power-watt`). The
same ten keys sit on the CU800 2012 bike console
(`cu800-2012-programs-ten-innovative-programs-on-the-console-badge`).

**Everything else this service manual says about programs**, and it says nothing more:

- When a workout ends the message window reads "PROGRAM END PRESS START TO REPEAT OR STOP TO END OR
  USER KEY TO SAVE", and the USER key "saves the parameter in CUSTOM USER". The key on the face is
  labelled CUSTOM, not USER. The 2013 owner's manual's Custom program, which stores twenty segments
  and can save a finished workout, is `spirit-ce-programs-custom-twenty-segments`; **this book prints
  no segment count**.
- In program mode the data scan adds a "LEVEL XX MAX XX" reading, and a "SEG TIME" reading is shown
  in every mode except HRC (heart rate control).
- In ready mode "you could select the profile of SPEED by pressing DISPLAY key when select the
  program (P0~P5, CUSTOM, FIT-TEST)". An elliptical has no speed profile; that sentence, like
  "treadmill starts at MIN LEVEL" on the same page, is treadmill template text left in this book.
  P0 to P5 is the only place the book counts the presets, and the book never maps those six slots
  to the key names.

**No profile chart, no preset descriptions, no setup sequence, no percentage and no fitness test
protocol are printed anywhere in this service manual.** Those rest on the CE800 2013 owner's
manual, whose console this drawing matches key for key. The CE850 of the same year has a different
right-hand column - two Custom keys and two HR keys, no Fitness Test, no Constant Power - see
`ce850-2016-programs-ten-numbered-program-keys-with-two-custom-and-two-heart-rate-keys`.
