**This is the 2017 XE890B-AE10M book's procedure, and it is the one that prints the bolt sizes.** The CE800 (2020) /
CE800ENT books describe the same job as "the bolts, flat washers, spring washers" and "curve washers" with no
sizes; this book names flat washers only and no spring or curve washer.

1. Use a hex-key wrench to remove, from the **rail support tube**: **3/8" x UNC16 x 2-1/4" button head socket bolt
   x 2**, **3/8" x UNC16 x 3-3/4" button head socket bolt x 2**, **3/8" x 19 x 1.5T flat washer x 2**, **3/8" x UNC16
   x 2" flat head socket bolt x 2**. Then remove the **rail support assembly**.
2. Use a Phillips head screwdriver to remove the **M5 x P0.8 x 12L Phillips head screws** of **rear stabilizer cover
   A/B** and take the covers down.
3. Use a **6 mm hex-key wrench** to remove the **3/8" x UNC16 x 2-1/4" button head socket bolt**, **3/8" x UNC16 x
   3-3/4" button head socket bolt**, **3/8" x UNC16 x 2" flat head socket bolt** and **3/8" x 19 x 1.5T flat washer**,
   then take down the **rail assembly**.
4. Reassemble in the reverse order as disassembly.

Step 3 prints the same four part names as step 1 without counts. Step 1 does not say what size hex key it needs;
only step 3 names 6 mm.
