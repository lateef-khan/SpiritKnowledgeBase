The console has built-in maintenance/diagnostic software for settings such as English/Metric units or turning off the console beeps. **Press and hold Start, Stop and Enter for about five seconds** until the message window shows "Engineering Mode" (the book says the menu "may be called Engineering Mode, depending on version"), press Enter, and navigate with the Resistance up/down keys.

| Menu | What it does |
|---|---|
| a. Key Test | Test every key |
| b. LCD Test | Test all display functions |
| c. Functions | Press Enter, navigate with Resistance up/down: **Sleep Mode** - On; the console darkens after 30 minutes of no use, Off keeps it lit while power is on. **Motor Test** - runs the tensioning gear motor continually. **Manual** - steps the gear motor. **TYPE SET** - Bike or Elliptical. **Key Tone** - key-press beeps on/off. **Units** - English or Metric. **Odometer Reset.** **Pause mode** - On; Off makes one press of Stop end the program, On keeps the data five minutes before the startup screen. **Safety** - Off; On sends the machine to **Level 20** of resistance automatically to prevent use by a child |
| d. Security | Locks the keypad; with the child lock on, the keypad works only after **holding Start and Enter for three seconds** |
| e. Factory Set | |
| f. Exit | Enter returns to the startup screen |

The customer power-up page prints stand-by after **20** minutes where this menu prints 30 ([power-up card](power-up-self-test-software-version-odometer-and-standby-after-20-minutes.md)). The SB4.5r and FS5.9e menus are shorter ([card](../../shared/console/xterra-console-engineering-mode-start-stop-enter-5-seconds-with-key-test-security-sleep-and-units.md)). The Spirit CU800 service manual prints the same menu ([Spirit twin](../../cu800-2012/console/maintenance-menu-30-minute-sleep-and-start-enter-three-second-unlock.md)). Same in the 2014 printing.
