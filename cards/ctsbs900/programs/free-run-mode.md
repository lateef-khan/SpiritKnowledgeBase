In Free Mode, the running belt is able to move freely under the user's own power (self-powered, motor-neutral operation) — unlike Treadmill Mode's motorized belt or [Sled Mode's](sled-mode-manual.md) resistance-generating belt.

1. Select Free Mode to enter free mode.
2. The running belt can move freely under free mode. Please hold on to the hand rail and start running.
3. **Incline default is 6% and cannot be adjusted.** Based on safety design, the incline will be locked at 6%. This is an exception to the general incline behavior described in [console/incline-adjustment.md](../console/incline-adjustment.md).
4. Press **Stop** and wait for the incline to go down to 0 level to exit free mode.
