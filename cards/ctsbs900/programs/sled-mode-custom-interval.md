Custom Interval is a sub-mode of [Sled Mode](sled-mode-manual.md) that alternates timed sled-pushing intervals with timed rest periods.

1. Set **SLED TIME** (default 20 seconds, range 5 seconds to 5 minutes).
2. Set **REST TIME** (default 20 seconds, range 5 seconds to 5 minutes).
3. Set **Sled Resistance** (default 4, range 1–12). The user can also adjust the sled resistance at any time; the resistance remains at that level for the total duration of the interval program.
4. The display shows SLED TIME with a countdown timer for the sled exercise, then shows REST TIME with a countdown timer for rest time.
5. The user continues to alternate back and forth between sled time and rest time until they press **STOP**.
