A timed **1.5 mile run**. You control the speed manually. Maximum time allowed to pass the test:

| Age | Male | Female |
|---|---|---|
| 17-21 | 16:36 | 19:42 |
| 22-26 | 17:30 | 20:36 |
| 27-31 | 17:54 | 21:42 |
| 32-36 | 18:48 | 23:06 |
| 37-41 | 19:30 | 24:06 |
| 45-49 | 16:09 | 17:02 |
| 50-54 | 16:46 | 17:27 |
| 55-59 | 17:10 | 18:35 |
| 60-64 | 18:53 | 19:44 |
| 65+ | 20:36 | 20:53 |

For more information visit: http://bit.ly/SF-Navy

See [programs/fitness-test-overview.md](fitness-test-overview.md) for how to select and start this test.
