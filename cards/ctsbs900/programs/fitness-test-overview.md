When the **Fit Test** program is selected, the Dot Matrix (DM) display shows **GERKIN** — this is the first of 9 different tests available:

1. Gerkin — see [programs/fitness-test-gerkin.md](fitness-test-gerkin.md)
2. WFI — see [programs/fitness-test-wfi.md](fitness-test-wfi.md)
3. Army (pft) — see [programs/fitness-test-army.md](fitness-test-army.md)
4. Navy (prt) — see [programs/fitness-test-navy.md](fitness-test-navy.md)
5. Air Force (prt) — see [programs/fitness-test-air-force.md](fitness-test-air-force.md)
6. Marines (pft) — see [programs/fitness-test-marines.md](fitness-test-marines.md)
7. Law Enforcement (peb) — see [programs/fitness-test-peb-law-enforcement.md](fitness-test-peb-law-enforcement.md)
8. U.S. Coast Guard — see [programs/fitness-test-coast-guard.md](fitness-test-coast-guard.md)
9. U.K. Chester Fireman (Performance & Prediction protocols) — the source does not provide a separate detail page for this test's procedure or scoring in this manual.

To select a different test, press the **Fitness Test** button again to cycle to the next test; continue pressing until the test you want is shown in the message window. To select your desired fitness test, press **Enter**.

## Fit Test Operation
1. For each program the Message Window will prompt you to enter your personal data such as **Age, Weight, Height, Gender**. Adjust the settings using the keypad or Up/Down buttons, then press **Enter** to accept the new number and proceed to the next screen.
2. After all required data is entered, press **Start** to begin the test.
