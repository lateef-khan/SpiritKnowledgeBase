1. Select a preset program button then press **Enter** to begin customizing the program with your personal data, or just press the **Start** button to begin the program with the default settings.
2. After selecting a program and pressing Enter to set your personal data, the **Message window** will prompt you through the settings starting with time. The default value of 20 minutes is displayed and you may press Enter to accept or change it using the button pad or **Up/Down buttons**, then press Enter to move to the next step.
3. The Message Window will now blink a value indicating your **Age**. Entering the correct age affects the Heart Rate Bar Graph accuracy and is also needed for HR programs. Use the button pad or Up/Down buttons to adjust, then press Enter.
4. The Message Window will now blink a value indicating your **Bodyweight**. Entering your correct bodyweight affects Calorie readout accuracy. Use the button pad or Up/Down buttons to adjust, then press Enter.
5. The Message Window will now blink, showing the preset **top speed** of the selected program. Use the button pad or Up/Down buttons to adjust, then press Enter. Each program has various speed changes throughout; this allows you to limit the highest speed the program will attain during your workout.
6. Now press the **Start** button to begin your workout, or the **Stop** button to return to the previous screen.
7. There will be a 3-minute warm-up to begin. You can press **Start** to bypass this and go straight to the workout. During the warm-up the clock will count down from three minutes.

For the exact speed/incline profile of each preset program, see [programs/preset-programs-speed-incline-table.md](preset-programs-speed-incline-table.md).
