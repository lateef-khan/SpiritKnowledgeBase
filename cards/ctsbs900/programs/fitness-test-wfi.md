The **WFI** test is a modified **Gerkin** protocol. The actual test uses the same stage/speed/grade chart as Gerkin — see [programs/fitness-test-gerkin.md](fitness-test-gerkin.md) — but the score is calculated differently.

For before/during/after-test guidance (which applies to both the Gerkin and WFI tests), see [programs/fitness-test-gerkin-wfi-protocol-guidance.md](fitness-test-gerkin-wfi-protocol-guidance.md).
