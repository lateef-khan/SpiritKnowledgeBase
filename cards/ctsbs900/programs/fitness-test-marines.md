A timed **3 mile run**. You control the speed manually. Maximum time allowed to pass the test:

| Age | Male | Female |
|---|---|---|
| 17-26 | 28:00 | 31:00 |
| 27-39 | 29:00 | 32:00 |
| 40-45 | 30:00 | 33:00 |
| 46+ | 33:00 | 36:00 |

For more information visit: http://bit.ly/SF-Marines

See [programs/fitness-test-overview.md](fitness-test-overview.md) for how to select and start this test.
