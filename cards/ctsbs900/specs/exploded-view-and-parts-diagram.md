The manual includes a full exploded-view parts diagram of the treadmill frame, uprights, console rack, deck, belt, rollers, and motor/drive assembly, with numbered callouts for each part used by service technicians. The frame/chassis model designation printed on this page reads approximately **"CP14LEUB1"** (small superscript/symbol next to it was not clearly legible in the source scan).

**Note on this content:** The diagram is a dense numbered-parts illustration rather than a text table; individual callout numbers could not be reliably mapped to part names from the page image alone, so no part-number list is reproduced here. For parts identification or ordering, contact Spirit Fitness using the information in [warranty/warranty-service-and-contact.md](../warranty/warranty-service-and-contact.md).

**There is no parts list in this book, only the drawing.** The table of contents
runs `Exploded View Diagram 53`, `Warranty 54` - there is no Parts List entry, and
no table of item number, description and quantity appears anywhere in the manual.
Nothing in the book maps any callout number to a part name or to an orderable part
number.

**The callout numbers on the drawing run from 1 to 399**, about 170 distinct
values, and include sub-callouts written with a decimal point - `23.1` through
`23.7`, `123.1` and `135.1`. The drawing also carries the code **CP14LEUB1**.
Because the page is a bare drawing, the printed page number 53 is not
distinguishable from a callout in the text layer; read a number off the drawing
itself before quoting it.

**Do not look a number from this drawing up in the CT900 parts list.** That list
stops at 144 and uses a `43~01` style for its sub-numbered rows, not a decimal -
see `ct900-full-parts-list-and-exploded-view`. Any callout above 144, and every
decimal sub-callout, exists only here.

**The assembly instructions in this same book use letters, not numbers.** Parts are
lettered A through P and the hardware a through s - "Screws (a), Spring washers
(b), and Washers (c)". So the drawing's numbers and the assembly's letters are two
schemes with nothing joining them. The pre-assembly page nevertheless still says
"The numbers in the instructions that are in parenthesis (#) are the item number
from the assembly drawing for reference"; that sentence is carried over from a
manual whose steps did use numbers, and no step in this book prints a number in
parentheses.
