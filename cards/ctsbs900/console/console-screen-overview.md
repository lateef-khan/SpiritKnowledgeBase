The console layout includes:
- **LED Data Display Windows** — numeric columns down each side (0–20 incline scale on the left, 1–15 speed scale on the right) with **Direct Access Speed Buttons** on the right side and an incline scale on the left.
- **Dot Matrix Message Center** — the central pixel display showing the 1/4-mile track, workout data, and program setup prompts.
- **LEVEL / SPEED indicator** and the small runner icons showing current activity.
- **Scan button** — cycles the LED data display windows.
- **MODE SELECT** — toggles between Treadmill, Free (Neutral), and Sled Trainer modes.
- **SLED RESISTANCE LEVELS** — direct-access buttons 1–15 for Sled Mode resistance.
- **PROGRAMS** button with **Up/Down/Enter** controls.
- Lower message window with **DISTANCE, CALORIES, PULSE, TIME ELAPSED, PACE, WATTS, METS, TIME REMAINING** indicators.
- **Tablet-friendly reading rack** below the display.
- **Start, Stop, Speed, and Incline controls** on the console arms.
- **Safety Stop Key** — the emergency stop button between the handrails. Full procedure: [safety/safety-stop-key-and-tether-cord.md](../safety/safety-stop-key-and-tether-cord.md).
- **Contact Heart Rate Grips** — stainless steel hand pulse sensors on both handrails.

For the full list of programs and modes reachable from this console, see [programs/programmable-features-overview.md](../programs/programmable-features-overview.md).
