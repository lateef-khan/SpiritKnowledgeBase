The Pulse (Heart Rate) window displays your current heart rate in beats per minute during the workout. You must use both the left and right stainless steel sensors to pick up your pulse. Pulse values are displayed anytime the computer is receiving a Grip Pulse signal. You may use the Grip Pulse feature while in Heart Rate Control — see [programs/heart-rate-control-hrc.md](../programs/heart-rate-control-hrc.md).

If no pulse signal is received during a Heart Rate program, the Message Window shows **CHECK PULSE** and the program cannot proceed — see [programs/heart-rate-control-hrc.md](../programs/heart-rate-control-hrc.md) for details, or [console/heart-rate-chest-strap-troubleshooting.md](heart-rate-chest-strap-troubleshooting.md) if using the chest strap.
