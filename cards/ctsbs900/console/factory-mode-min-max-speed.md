**Entering Factory Mode:** When the console performs a power-on reset, press the **Start** and **Speed Up** keys simultaneously to enter Factory Mode.

1. After entering Factory Mode, the MW first displays "FACTORY SETTING," then displays "UNITS – ENGLISH" or "UNITS – METRIC." Use the Up/Down keys to switch between English and Metric units, and press Enter to confirm.
2. The MW displays "ADJUST MIN SPEED," and the SPEED window shows the value. Use the Up/Down keys to adjust the setting.
   - Metric range: 0.8–1.0 KPH
   - English range: 0.5–0.6 MPH
   Press Enter to confirm.
3. The MW displays "ADJUST MAX SPEED," and the SPEED window shows the value. Use the Up/Down keys to adjust the setting.
   - Metric range: 16.0–25.0 KPH
   - English range: 10.0–15.6 MPH
   Press Enter to confirm.
4. The MW displays "FINISHED," followed by the scrolling message "CONSOLE RESET."

A quick-reference version of these ranges is at [specs/speed-and-incline-ranges.md](../specs/speed-and-incline-ranges.md). Note the default Quick Start speed (0.5 mph / 0.8 kph — see [assembly/quick-start.md](../assembly/quick-start.md)) falls at the low end of the min-speed range set here.
