From the Maintenance Mode main menu, select **FUNCTION >** and press **Enter** to access this submenu. Use the **Up/Down** keys to select each option.

| Setting | Options | Default |
|---|---|---|
| UNITS | ENGLISH / METRIC | English |
| PAUSE MODE | ON / OFF | ON |
| ODOMETER RESET | (action — clears total distance and total time) | — |
| SLEEP MODE | ON / OFF | ON |
| BEEP MODE | ON / OFF | ON |
| GS MODE | ON / OFF | OFF |
| OTA AUTO | ON / OFF | ON |

Details:
- **UNITS – ENGLISH / METRIC:** Press Enter to change the setting. The MW displays "UNITS – ENGLISH" or "UNITS – METRIC."
- **PAUSE MODE – ON/OFF:** Press Enter to toggle. The MW displays "PAUSE MODE – ON" or "PAUSE MODE – OFF."
- **ODOMETER RESET:** Press Enter to clear the total distance and total time.
- **SLEEP MODE – ON/OFF:** Press Enter to toggle. The MW displays "SLEEP MODE – ON" or "SLEEP MODE – OFF."
- **BEEP MODE – ON/OFF:** Press Enter to toggle. The MW displays "BEEP MODE – ON" or "BEEP MODE – OFF."
- **GS MODE – ON/OFF:** Press Enter to toggle. The MW displays "GS MODE – ON" or "GS MODE – OFF."
- **OTA AUTO – ON/OFF:** Press Enter to toggle. The MW displays "OTA AUTO – ON" or "OTA AUTO – OFF."

To exit Maintenance Mode entirely, select **EXIT** from the main menu.
