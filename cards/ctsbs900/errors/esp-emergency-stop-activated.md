This code appears when the safety key/tether cord is pulled or the safety stop system is triggered — see the full procedure at [safety/safety-stop-key-and-tether-cord.md](../safety/safety-stop-key-and-tether-cord.md). To clear a normal (intentional) trip, push the pulled-out safety key part back into its socket. If it persists after re-inserting the key, use the causes below.

| Possible Cause | Corrective Action |
|---|---|
| Safety key cable detached | Check safety key wiring |
| Safety key switch failure | Replace safety key switch |
| Control cable failure | Replace control cable |
| Inverter failure | Replace inverter |
| Console main PCB failure | Replace console main PCB |
