**OE (Inverter overvoltage)** is easy to confuse with **OC** (Inverter output overcurrent — see [errors/oc-inverter-output-overcurrent.md](oc-inverter-output-overcurrent.md)), **OH** (Inverter overheat), **OL/OL1/OLO** (overload codes). OE relates to the braking resistor circuit, similar to [errors/dbup-braking-fault-detection.md](dbup-braking-fault-detection.md).

| Possible Cause | Corrective Action |
|---|---|
| Braking resistor wire detached | Check wiring |
| Braking resistor failure | Replace braking resistor |
| Inverter failure | Replace inverter |
