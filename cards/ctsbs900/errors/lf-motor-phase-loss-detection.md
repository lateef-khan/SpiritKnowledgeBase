**LF (Motor phase loss detection)** is not the same as **GF** (Inverter ground fault — a different single/double-letter code, see [errors/gf-inverter-ground-fault.md](gf-inverter-ground-fault.md)).

| Possible Cause | Corrective Action |
|---|---|
| Motor wire detached | Check motor wiring |
| Inverter failure | Replace inverter |
| Motor failure | Replace motor |
