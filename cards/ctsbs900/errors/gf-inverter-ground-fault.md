**GF (Inverter ground fault)** is not the same as **LF** (Motor phase loss detection — similar two-letter code, different meaning; see [errors/lf-motor-phase-loss-detection.md](lf-motor-phase-loss-detection.md)).

| Possible Cause | Corrective Action |
|---|---|
| Inverter ground fault | Replace inverter |
| Insulation pad under AC motor cracked, causing arcing from motor shell to frame | Replace motor insulation pad |

This error is related to the machine's grounding — see [safety/grounding-instructions.md](../safety/grounding-instructions.md) for grounding requirements. Poor grounding can also cause erratic heart rate readings — see [console/heart-rate-chest-strap-troubleshooting.md](../console/heart-rate-chest-strap-troubleshooting.md).
