**LP (Inverter low voltage warning)** is a distinct, separate code from **LE1 (Inverter low voltage)** — see [errors/le1-inverter-low-voltage.md](le1-inverter-low-voltage.md). Both share the same possible causes and corrective actions in the source manual.

| Possible Cause | Corrective Action |
|---|---|
| Mains voltage too low | Check if mains voltage meets inverter requirement |
| Inverter failure | Replace inverter |
| Filter failure | Replace filter |
| Choke failure | Replace Choke |

See [safety/electrical-safety.md](../safety/electrical-safety.md) for voltage-variance warnings and [specs/electrical-requirements.md](../specs/electrical-requirements.md) for the required dedicated circuit.
