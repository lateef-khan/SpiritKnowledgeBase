**EER (Inverter EEPROM error)** is not the same as **PRER** (Inverter Flash memory error — a different memory-related code, see [errors/prer-inverter-flash-memory-error.md](prer-inverter-flash-memory-error.md)).

| Possible Cause | Corrective Action |
|---|---|
| Inverter failure | Replace inverter |
