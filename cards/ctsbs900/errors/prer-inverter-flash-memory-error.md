**PRER (Inverter Flash memory error)** is not the same as **EER** (Inverter EEPROM error — a different memory-related code, see [errors/eer-inverter-eeprom-error.md](eer-inverter-eeprom-error.md)).

| Possible Cause | Corrective Action |
|---|---|
| Inverter failure | Replace inverter |
