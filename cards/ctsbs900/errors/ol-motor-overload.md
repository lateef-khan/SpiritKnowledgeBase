**OL, OL1, and OLO look very similar and are easy to mix up — they are three distinct codes:**
- **OL = Motor overload** (this file)
- **OL1 = Inverter overload** — see [errors/ol1-inverter-overload.md](ol1-inverter-overload.md)
- **OLO = System overload** — see [errors/olo-system-overload.md](olo-system-overload.md)

| Possible Cause | Corrective Action |
|---|---|
| Running belt/deck aging | Apply lubricant to running belt |
| Running belt/deck damaged | Replace running deck and belt |
| Inverter failure | Replace inverter |
| Motor failure | Replace motor |

For the lubrication procedure, see [maintenance/lubricating-drive-belt-teeth.md](../maintenance/lubricating-drive-belt-teeth.md).
