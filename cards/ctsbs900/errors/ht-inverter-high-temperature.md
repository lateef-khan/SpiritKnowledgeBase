**HT (Inverter high temperature)** is easy to confuse with **OH** (Inverter overheat — a very similarly worded code, see [errors/oh-inverter-overheat.md](oh-inverter-overheat.md)) and **NTCF** (a sensor fault rather than an actual high-temperature condition — see [errors/ntcf-inverter-temperature-sensor-fault.md](ntcf-inverter-temperature-sensor-fault.md)). Unlike OH, HT's cause list does not include a clogged fan.

| Possible Cause | Corrective Action |
|---|---|
| Running belt/deck aging | Apply lubricant to running belt |
| Running belt/deck damaged | Replace running deck and belt |
| Inverter failure | Replace inverter |

For the lubrication procedure, see [maintenance/lubricating-drive-belt-teeth.md](../maintenance/lubricating-drive-belt-teeth.md).
