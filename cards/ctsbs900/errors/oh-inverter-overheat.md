**OH (Inverter overheat)** is easy to confuse with **HT** (Inverter high temperature — a separate, similarly-worded code, see [errors/ht-inverter-high-temperature.md](ht-inverter-high-temperature.md)) and **NTCF** (a sensor *fault*, not an actual overheat — see [errors/ntcf-inverter-temperature-sensor-fault.md](ntcf-inverter-temperature-sensor-fault.md)). Also don't confuse with OC/OE/OL/OL1/OLO.

| Possible Cause | Corrective Action |
|---|---|
| Inverter fan clogged with dust / poor heat dissipation | Clean inverter fan |
| Running belt/deck aging | Apply lubricant to running belt |
| Running belt/deck damaged | Replace running deck and belt |
| Inverter failure | Replace inverter |

For the lubrication procedure, see [maintenance/lubricating-drive-belt-teeth.md](../maintenance/lubricating-drive-belt-teeth.md).
