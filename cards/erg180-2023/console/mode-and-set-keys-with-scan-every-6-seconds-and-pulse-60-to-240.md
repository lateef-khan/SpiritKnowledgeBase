**The console face** (Console Screen - Overview): an **elastic tablet holder** at the top, one **LED window** at the bottom, a **SET** button to its left and a **MODE** button to its right. The drawing's legend strip under the digits reads SCAN, TIME, SPEED, DIST, CAL, ODO - a stock bike picture; the text below it, which this card follows, describes a rower window with count, SPM and pulse and no speed or odometer.

| Function | Range as printed |
|---|---|
| Scan | Every 6 seconds |
| Time | 0:00 - 99:59 |
| Count | 0 - 9999 times |
| Distance | 0 - 9999 meters |
| Calories | 0 - 9999 cal |
| SPM | 0 - 999 times / min |
| Pulse | 60 - 240 BPM |

Battery type 2 pcs of size AA ([battery card](../../shared/console/xterra-erg-console-two-aa-batteries-and-where-they-go.md)); operating temperature 0 to +40 C; storage -10 to +60 C.

**MODE:** push to select a function; **push and hold 2 seconds to reset time, count, distance and calories.** **SET:** sets the values of time, count, distance and calories when not in scan mode.

**SCAN:** press MODE until the function is TIME and the word SCAN appears at the left and flashes; the window then rotates through all six functions - time, count, distance, calorie, SPM and pulse - **6 seconds each**. Press MODE once during the cycle and SCAN disappears, leaving the function you stopped on; to return to SCAN press MODE round to TIME again. TIME, COUNT, DISTANCE and CALORIES run from exercise start to end; SPM is strokes per minute; **PULSE is the current heart rate - "please wear the wireless heartbeat chest belt before measuring"** - and "the measurement value can not be regarded as the basis of medical treatment". The console has no pulse grips; wearing the strap is on [the strap card](../../shared/console/xterra-treadmill-console-chest-strap-not-included-with-a-cr2032-battery.md).

The four count-down targets that SET enters (time, count, distance, calories) are a programs question. STOP after 4 seconds, the battery symbol and the 2-minute shut-off are on [the auto-off card](../../shared/console/xterra-erg-console-wakes-on-rowing-or-mode-shows-stop-after-4-seconds-and-shuts-off-after-2-minutes.md); pairing with Kinomap or the XTERRA+ app is on [the Kinomap card](../../shared/console/xterra-rower-console-kinomap-pairing-and-the-console-goes-blank-while-an-app-is-connected.md) and [the app card](../../shared/console/xterra-treadmill-console-xterra-plus-app-ios-13-android-8.md). The ERG160's one-key console has no pulse and no SET ([ERG160 card](../../erg160-2020/console/single-mode-key-with-scan-every-6-seconds-and-six-readouts.md)).
