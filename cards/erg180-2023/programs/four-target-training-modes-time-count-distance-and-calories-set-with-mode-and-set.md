"This computer has four target training modes: time, count, distance and calories." The console has
two buttons: **MODE** selects functions (hold 2 seconds to reset), **SET** sets the values "when not
in scan mode". The book's contents page files this under **Programs - Target Buttons**.

**Before setting, leave SCAN**: if "SCAN" is flashing on the display, press MODE again until it
disappears.

Each mode works the same way:

1. Press MODE to switch to the function - **TIME**, **COUNT**, **DIST** or **CAL**.
2. Press SET to set the target (**press and hold SET to speed up the setting**); stop pressing when it
   reaches the required value.
3. Start rowing. **The display counts down.**
4. When the count-down reaches zero **the function flashes** to indicate the training target is
   complete. If you continue to train, the computer automatically starts to **count up from zero**.

**To modify a target** during or after setting, press and hold MODE for about 2 seconds to clear all
settings and set again; after the setting process or completion, "press RESET button directly to
clear all settings" - the console has no RESET button, so this means holding MODE.

The book prints no range, step or default for the targets; the specifications page gives the display
ranges as Time 0:00-99:59, Count 0-9999 times, Distance 0-9999 meters, Calories 0-9999 Cal. There is
no pulse target (pulse, 60-240 BPM, is a readout from a wireless chest belt) and no program beyond
these four targets.

**The ERG160 and ERG220 share the MODE-only console shape but have no SET button and no targets** -
see `see_also`. The Xterra bikes with a SET key print a similar page - see
`xterra-programs-no-preset-programs-only-a-target-countdown`.
