Press **PROGRAM** after turning the power on to enter program mode with the window displaying
**P01**. **There are 24 built-in programs.** The PROGRAM key cycles P01 to P24, then HRC,
then back to P01.

Press PROGRAM to select a program (P01 to P24) and enter the time setting with the preset
time of **30 minutes**. Press **SPEED up/down** or **INCLINE up/down** to change the time
within **5 to 99 minutes**. Press **START** to begin.

**The book prints no profile picture, table or description for any of the 24 programs** - the
programs page is two paragraphs and nothing else, confirmed on the rendered page. What each
program does can only be seen on the console.

The Dyaco service manual for this console corroborates "24 programs (P1 to P24)" and says a
pre-set program "can set using time and speed" and "starts at program preset value in
PROGRAM". The same service manual says the console "also has H-1 and H-2", while its own
PROGRAM window description and the owner's manual name only **H-1**; see the HRC card.
