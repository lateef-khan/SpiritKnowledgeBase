| Button | What it does |
|---|---|
| **Program** | In ready mode, scrolls the program selection in sequence: P01 … P24, HRC, then back to P01. |
| **Enter** | In manual mode, scrolls to select count-down time, count-down distance or count-down calorie mode. In program mode it sets the time; in HRC mode it sets time and target heart rate. |
| **Stop** | During operation, pauses the machine. In setting mode, returns to ready mode or goes back to the previous setting. |
| **Start** | In ready mode, starts operation. |
| **Speed Up / Speed Down** | During operation, changes the speed in steps of **0.1 MPH**; press and hold for a continuous change. |
| **Direct Speed 3, 6, 9** | Jumps to that speed; the treadmill adjusts to it automatically. |
| **Incline Up / Incline Down** | During operation, changes the incline level; press and hold for a continuous change. |
| **Direct Incline 3, 6, 9** | Jumps to that incline level. |

The console overview names the LCD window, the direct incline buttons (left of the LCD), the safety key, the direct speed buttons (right), the program button and an accessory holder; the service manual's button-location drawing adds two speakers and labels the row under the LCD as Incline Up/Down, Speed Fast/Slow, then ENTER, STOP, safety key, START, PROGRAM.

The service manual describes the same keys by mode on [the ready-and-run-mode card](keys-in-ready-and-run-mode-per-the-service-manual.md).
