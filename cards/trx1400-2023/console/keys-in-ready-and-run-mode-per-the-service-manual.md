From the Dyaco T3-NT053-01 service manual:

**READY mode**
- SAFETY KEY: fit it to power on the computer; pulling it away shuts the computer down and shows E0.
- STOP: hold 3 seconds and the display resets.
- START: a **3-second final countdown**, then the machine runs — at minimum speed in Manual, at the program's preset value in a Program.
- ENTER: changes each function — in idle mode it sets time, distance and calories; a preset Program sets time and speed; Heart Rate Control sets time, age and the heart-rate value.
- FAST, SLOW, UP, DOWN: non-functional unless a setting is being entered. RAPID: non-functional.
- PROGRAM ▲/▼: choose a program, confirm each setting with ENTER, then START. The page counts 24 programs (P1 to P24) "and also has H-1 and H-2" — the owner's manual prints one HRC program.

**RUN mode**
- SAFETY KEY: pulling it away shuts the computer down and shows E0.
- STOP stops the treadmill; START is non-functional.
- ENTER: takes turns showing calories and distance.
- FAST / SLOW: 0.1 kph (0.1 mph) per press; held continuously, speed runs to MAX or MIN quickly.
- UP / DOWN: one incline position per press, maximum 10, minimum 0.
- RAPID: six preset buttons beside the display — speed 3, 6, 9 on the right and incline 3, 6, 9 on the left (the page misprints both sets as "Rapid speed buttons").
- PROGRAM: non-functional.

The owner's manual's own button list is on [the features card](button-functions-and-direct-keys-3-6-9.md).
