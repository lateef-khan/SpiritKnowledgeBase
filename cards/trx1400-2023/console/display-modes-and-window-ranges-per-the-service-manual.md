From the Dyaco T3-NT053-01 service manual, chapter 4:

**Modes.** OFF: with no safety key the treadmill shows **E0**. READY: with the key in, the message window shows the program profile name and cycles; press START to start in Manual mode. SLEEP: pressing any button returns the treadmill to READY. RUN: pressing STOP or removing the key stops the treadmill instantly.

| Window | Display range | Work range | Notes |
|---|---|---|---|
| SPEED | 0.0 – 99.9 | 1.0 – 16.0 km or 0.5 – 10 mile | FAST/SLOW change it by 0.1 |
| INCLINE | 0 – 99.9 | 0 – 10 | preset value 0 – 10; UP/DOWN move it by 1 |
| TIME | 0:00 – 99:99 | 0:00 – 99:59 | Count-down setup 10:00 – 99:00; STOP saves the value and re-entering RUN continues counting up |
| DISTANCE | 0.00 – 99.9 | 0.00 – 99.9 | km or miles |
| CALORIES | 0.0 – 9999 | 0.0 – 999 | |
| PULSE | 0 – 999 | 40 – 220 bpm | hand pulse or receiver (chest belt); in RUN mode, **8 seconds without a signal and the value becomes 0** |
| PROGRAM | 000 – 999 | 0, P01 – P24, HRC (H-1) | one press of Program shows one mode |

The service manual's LCD layout and display-window drawings are pictures with no readable text; the owner's manual's console overview is on [the button functions card](button-functions-and-direct-keys-3-6-9.md).
