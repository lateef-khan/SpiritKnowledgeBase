The TRX1400 owner's *Error Code Guide* defines E2 as: **E2 Overload error. Controller detected over rated current for 6 seconds.**

Every other Xterra owner's manual that prints a time says **3 seconds** (`xterra-treadmill-errors-e2-over-rated-current-for-3-seconds`). The TRX1400 service manual defines the same code as over current on the lower board and gives the fix - silicone oil, an unblocked belt, then the lower control board or the motor (`xterra-treadmill-errors-e2-over-current-silicone-oil-then-board-or-motor`) - without a time.
