The board is silkscreened **Base-Board-TMILL-V2.0**; its label reads Customer Model xT495 110018, Part
Number A001010652, INC-A0002703, C006_XT485_T10018, S014_210127_ENM 2021.01.29, 210201A001 - so the board
itself is marked for an "xT495" and the software family C006_XT485.

Sockets named on the photograph: **HAND PULSE WIRES**, **SPEAKER**, **INCLINE HANDRAIL WIRE**, **SPEED
HANDRAIL WIRE**, **KEYBOARD WIRE**, **MP3 AUDIO INPUT BOARD**, **BLUETOOTH/AUDIO BOARD**, **COMPUTER
CABLE**, **SAFETY KEY WIRE**, **12Vdc TRANSFER BOARD**, **DC FAN**, **HR WIRELESS**, **USB BOARD** and
**GROUNDING**.

No pin definitions are printed; the only pin table in the book is the 5-pin computer cable. The XT685ENT
board has a different socket set for its 15.6-inch screen.
