**The console diagram labels the socket "3.5mm Audio-input only (no output)".** It
feeds the **Integrated Speakers**, which the same drawing labels.

**Headphones will not work in it.** The label says so in as many words, and the
manual prints no other audio socket.

**Its sibling is the opposite way round.** The XT685ENT of the same year has an
**audio output jack for private listening** - a headphone jack - on the front of its
console; see `xt685ent-2023-console-audio-jack-headphone-output`. **The two ENT
treadmills contradict each other on this point**, so check the label on the machine
before answering.

The manual states **no volume control** for this console either way. On the 2015 XT
machines the volume has to be set on the source device; see
`xt-2015-console-speakers-and-audio-jack`.
