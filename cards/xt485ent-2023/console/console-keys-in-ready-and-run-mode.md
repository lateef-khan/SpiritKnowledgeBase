**This console has no ENTER key in either table, and its quick keys take typed digits.** The
XT685ENT keypad is the base XT685 layout with ten preset quick keys, a Child Lock and a DISABLE key:
`xt685ent-2023-console-keys-in-ready-and-run-mode`.

**READY mode**

| Key | Behaviour |
|---|---|
| Safety Key | Set it in the right position to power on the computer. Pull it away and the computer shuts down automatically. |
| Stop | Non-functional. |
| Start | **3 second final countdown** on the window display, then the machine runs. MANUAL starts at MIN SPEED; PROGRAM starts at the preset value. |
| Fast, Slow | Non-functional unless you have entered a setting. |
| Quick SPEED & INCLINE | Non-functional. |
| Fan | Turns the fan on and off. |
| Handrail Switch Control | Turns the handrail switch off. |

**RUN mode**

| Key | Behaviour |
|---|---|
| Safety Key | Pull it away and the computer shuts down automatically. |
| Stop | Stops the treadmill. |
| Start | Non-functional. |
| Fast | Each press adds **0.1 kph (0.1 mph)**. Held down, the speed climbs quickly to MAX SPEED. |
| Slow | Each press removes 0.1 kph (0.1 mph). Held down, the speed falls quickly to MIN SPEED. |
| Up | Each press raises the position by **0.5**; the maximum incline position is 15. |
| Down | Each press lowers the position by 0.5; the minimum is 0. |
| Quick SPEED & INCLINE | Press Speed or Incline, then **2 or 3 digits**, and the treadmill adjusts to that value automatically. |
| Fan | Turns the fan on and off. |
| Handrail Switch Control | Turns the handrail switch off. |

The console drawing on the same page labels the **Disable Button** as "On Handrail SPEED/INCLINE
Switch ON or OFF", the Fan Button as the cooling fan switch, and the Safety Key as the emergency
function. The owner's manual's version of the digit entry is
`xt485ent-2023-console-direct-access-keys-two-or-three-digits`, and of the handrail button
`xt485ent-2023-console-handrails-on-off-button`.

**There is no Child Lock key in this book's tables**, and the owner's manual describes none either
(`xt-2023-console-child-lock`). The Settings page screenshot in the calibration chapter does show a
Child Lock item: `xt485ent-2023-console-calibration-behind-the-software-version-and-password-20160620`.
