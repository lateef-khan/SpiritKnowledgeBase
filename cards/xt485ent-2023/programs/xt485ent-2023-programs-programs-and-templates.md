**The WORKOUT PROGRAMS section holds two categories: Programs (programs with predefined speed and
incline changing profiles) and Templates (regular programs saved with your personal adjustments).**
Tap the category names to switch between them.

- To get more information on a program, **tap the program preview**. In that view you can scroll
  sideways to see all the program descriptions in the selected category.
- Press **CHOOSE** to select and adjust a program.

These are the programs this manual documents by name:

| Program | What it is |
|---|---|
| MANUAL | Timed workout, speed and incline set by hand |
| HILL | Preset pyramid profile |
| FAT BURN | Preset sustained-effort profile |
| CARDIO | Preset profile with fluctuations |
| STRENGTH | Preset build-and-hold profile |
| HIIT | Preset high/low intensity intervals |
| CALORIES | Preset sustained-effort profile |
| FUSION | Preset cardio-and-strength intervals |
| CUSTOM | A profile you draw yourself |
| HR1 and HR2 | Heart rate programs at two fixed targets |

**The manual prints no total count and no menu screenshot listing, so this table is assembled from
the pages that describe each program.** It documents no 5K, 10K, Target, Fitness Test or Fusion
free-weight program on this machine.

This is not the eight-program list of the button-console XT385, XT485 and XT685, and it is not the
five-tab layout of the XT685ENT.
