From the Dyaco GT75A-NT050 service manual, chapter 4. Its Display Windows page labels the console: LCD Display, Incline Rapid Keys, Speed Rapid Keys, Enter Key, Fast/Slow Keys, Incline Up/Down Keys, Start Key, Stop Key, Programs Key, Safety key.

**Modes.** OFF: with no safety key the treadmill enters OFF mode and the windows show **E0**. READY: with the key in, press START to start in Manual mode. RUN: pressing STOP or removing the key stops the treadmill instantly and enters OFF mode.

| Window | Display range | Work range | Notes |
|---|---|---|---|
| SPEED | 00.0 – 99.9 mph (km/h) | 0.5 – 10.0 mph | FAST/SLOW change it by 0.1 |
| TIME | 00:00 – 99:99 | 00:00 – 99:59 | Count-down setup 10:00 – 99:00; STOP saves the value and re-entering RUN continues counting |
| DISTANCE | 0.0 – 99.9 | 0.0 – 999 | km or miles |
| CALORIES | 0.0 – 999 | 0.0 – 999 | |
| PULSE | 0 – 999 | 40 – 220 bpm | hand pulse or receiver; a chest belt must be worn for the receiver |
| PROGRAM | 000 – 999 | 0, P1 – P12 | |

The 10.0 mph work range agrees with the owner's manual's rapid keys ending at 10; the calibration procedure's "maximum speed 16.0" is the kilometre figure ([calibration card](calibration-program-key-eng-wheel-42-max-16.md)).
