From the Dyaco GT75A-NT050 service manual:

**READY mode**
- SAFETY KEY: fit it to power on the computer; pulling it away shuts the computer down.
- START: a **3-second final countdown**, then the machine runs — at minimum speed in Manual, at the program's preset value in a Program.
- STOP: slowly lowers the speed until the belt stops.
- ENTER: changes each function — Manual can set time, a preset Program can set time and speed.
- PROGRAM: selects a program (Manual, P1-P12).
- FAST, SLOW, UP and DOWN: non-functional unless a setting is being entered. Speed and incline rapid keys: non-functional.

**RUN mode**
- SAFETY KEY: pulling it away shuts the computer down and shows E0.
- STOP stops the treadmill; ENTER and PROGRAM are non-functional.
- FAST / SLOW: 0.1 mph per press; held continuously, speed runs to MAX or MIN quickly.
- UP / DOWN: one incline position per press; the page says "the maximum incline position is **16**" and the minimum 0 — but the rapid keys, the calibration step and the owner's manual all stop at **10**, so treat 16 as an error in the page.
- SPEED RAPID KEYS: 2, 4, 6, 8, 10 kph (mph). INCLINE RAPID KEYS: 0, 3, 5, 7, 10 levels. (The page calls each set "3 preset buttons" and then lists five.)

The owner's manual's version is on [the quick-start card](quick-start-rapid-speed-2-to-10-and-rapid-incline-0-to-10.md).
