The TR260 service manual's *Outlines* page is a line drawing of the folded-frame treadmill with thirteen red
numbered callouts and this table:

| No. | Parts Name |
|---|---|
| 1 | Console |
| 2 | Locking Knob |
| 3 | Transportation Wheel |
| 4 | Cylinder |
| 5 | Running Belt |
| 6 | Motor Cover |
| 7 | Foot Rail |
| 8 | Incline/Hand Pulse Complex |
| 9 | Speed/Hand Pulse Complex |
| 10 | Rear Adjustment Base (R) |
| 11 | Rear Adjustment Base (L) |
| 12 | Left Upright |
| 13 | Right Upright |

Callout 8 sits on the left handlebar end and 9 on the right, so the incline keys ride the left grip and the speed keys
the right. Callout 7 appears twice, once on each foot rail. The drawing carries **no dimensions** and the book prints
no specification table.
