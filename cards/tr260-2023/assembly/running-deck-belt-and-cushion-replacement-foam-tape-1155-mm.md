"To do these replacements need to unmount Cylinder first."

1. Fold the treadmill. Unmount the **cylinder** with an **L-Allen wrench and a 12 mm open-end wrench**.
2. The **foot rails are pasted on the running deck with foam tape**. Follow the direction of the arrow to
   remove each foot rail and clean off the foam tape.
3. Remove the **8 running deck locking bolts** and take off the running deck. Now replace the running
   deck, running belt and cushions, and reverse the steps to install them.
4. Adjust the running belt tension and centre it.
4. (printed as a second "Step 4") Prepare **double-sided foam tape 1T x 10 mm x 1155 L, four pieces** -
   **each foot rail needs 2 pieces**. Apply the tape where the arrows show and stick the rail to the
   running deck.
5. Install the rear adjustment cover.

The Allen key size for the cylinder is not printed (the TRX1400 book says M5 for the same job), no
bolt torque is given, and the number of cushions is not stated. **The TRX1400's tape is 1170 mm long,
not 1155.** The page prints two steps numbered 4.
