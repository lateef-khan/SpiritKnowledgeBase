**This printing has a WARM UP button. The 2021 and 2024 printings do not, and this one has no
FITNESS TESTS button.** That is the whole difference between the two consoles' program keys.

**Eight program keys:**

- **WARM UP**
- **FAT BURNING**
- **TRAINING**
- **ROLLING HILLS**
- **CHALLENGE**
- **INTERVAL**
- **TARGET** - Target Training, with Time, Vertical Distance or Calories as the goal.
- **USER PROGRAM** - all 24 segments of the dot matrix display.

All six profile buttons, WARM UP included, run **the same ten setup steps** and the same defaults -
see `csc900-2024-programs-preset-setup-defaults-of-age-thirty-five-and-thirty-minutes`.

**This manual prints no description of what any program does.** Each of the six profile pages is the
button name and the ten steps and nothing else. The paragraphs that say Fat Burning keeps the user at
low to moderate intensity, that Challenge introduces anaerobic training, and so on, arrive with the
2021 printing - see `csc900-2024-programs-seven-buttons-and-a-fitness-tests-button`.

**There is no WFI test, no CPAT test and no Fitness Tests button.** A loose search of the whole book
for "WFI", "CPAT", "VO2" and "fitness test" returns **zero hits of each**, and the table of contents
runs `19 PROGRAMMABLE FEATURES` straight to `29 GENERAL MAINTENANCE`. The firefighter protocols
arrived in **2021**, not in 2024.

There is also no Manual program, no heart rate control program and no heart rate training page - see
`csc900-2024-programs-no-heart-rate-training-page`.
