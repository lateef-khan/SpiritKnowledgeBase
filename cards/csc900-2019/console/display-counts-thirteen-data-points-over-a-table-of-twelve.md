**The sentence and the table do not agree, and the table is right.**

The 2019 book says: *"The console display is separated into 4 separate display windows with
**thirteen** total data points."* The table printed directly beneath it has **four columns of three
rows - twelve cells**, and no thirteenth reading appears anywhere on the page:

| | Window one | Window two | Window three | Window four |
|---|---|---|---|---|
| **1** | Vertical Distance | Calories | Time Elapsed | Steps Per Minutes |
| **2** | Heart Rate | Calories / Minute | Time Remaining | Steps |
| **3** | METs | Watts | Total Program Time | Floors |

**Spirit corrected it in the next printing.** The **CSC900-2021**, **CSC900-2024** and
**CSC880-2025** books print the identical table under a sentence that says **twelve**
(`csc900-2024-console-four-display-windows`). Nothing in the table changed; only the count did. **A
caller who reads thirteen off a 2019 manual is looking for a reading the console does not have.**

Everything else on the page survived unchanged: a button below each window changes that window's
data point, **Vertical distance counts 0 to 999 feet or meters then rolls over to 1 to represent
1,000** with a light in the decimal space that moves with each 1,000, and **changing from imperial to
meters is done by pressing 1, 2, 3, OK**.
