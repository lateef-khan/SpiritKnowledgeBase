1. Under normal use the console screen displays. If there is no display, first check the **AC adapter** to make sure it is in the correct position.
2. Next, check that all the wires are inserted firmly and securely onto the console.
3. Then remove the **AC adapter fuse** to check for damage, and replace it if damaged.
4. Remove the console cover and the left and right chain covers. Check whether all the wires are inserted in the correct positions and whether any wires are broken.
