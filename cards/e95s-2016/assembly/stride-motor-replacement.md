1. Remove the slider adjustment following its instructions, and use an **M6 Allen wrench** to release the **socket head cap bolt M8 x 40L** securing the fixing piece on the main frame.
2. **Plug in the power supply before removing the incline motor. Use the console to adjust the program to 21".** If the gear motor is to come off, adjust the resistance control to max (level 20), then cut off the power.
3. Use **two 17 wrenches** to release the **incline set screws (10 x 62L)**, **flat washer (3/8" x 19 x 1.5T)**, **nylon nut (M10 x 8T)** and **two nylon washers (24 x 10 x 3T)** from the moving range adjusting assembly.
4. Release the **incline set screws (10 x 40L)**, **flat washer (3/8" x 19 x 1.5T)** and **nylon nut (M10 x 8T)** which fix the incline motor.
5. Use a Phillips head screwdriver to release **four tapping screws (5 x 19L)** and the circuit cover from the main frame.
6. Cut the cable ties with diagonal pliers, use a Phillips head screwdriver to release the **tapping screw (5 x 19L)** from the incline motor, and unplug the wire from the incline motor to the controller. **Remember the wire position.** The incline motor wire can then be pulled out and the motor removed.
7. Before removing the gear motor, take out the **steel cable** first.
8. Use a Phillips head screwdriver to release **two tapping screws (5 x 19L)** from the gear motor. Pull out the connected wire, then remove the gear motor.
9. **Remember all the wire positions before releasing the controller**, pull out all the wires, and remove **two tapping screws (5 x 19L)** from the control plate on the main frame.
10. To remove the spring, use **two 14 wrenches** to release the **hex head bolt (3/8 x 19L)**, **washer (3/8" x 19 x 1.5T)** and **nylon nut (3/8" x 7T)** on the moving range adjusting assembly.
11. Use a **12mm wrench** to release the **hex head bolt (5/16" x 1/2")** and **washer (5/16" x 23 x 1.5T)** on the incline rotate axle A 17 x 108L.
12. Pull out the incline rotate axle 17 x 108L from the other side, then remove the moving range adjusting assembly.
13. Use a round bar smaller than 17 to knock out the J4FM bushing.
14. Reassemble in the reverse order as disassembly.
15. When reassembling, the **incline rotate axle must be aligned with the notch plane** before the screw is fastened.
16. Reassemble the incline motor with **two nylon washers (24 x 10 x 3T)**.
17. With the incline motor and all wires fastened, plug in the power supply, **use the console to adjust the program to 18"**, then fasten the **socket head cap bolt (M8 x 40L)** on the spring and fasten all the parts.

Note steps 2 and 17: the motor comes off with the console set to **21"** and goes back on with the console set to **18"**.
