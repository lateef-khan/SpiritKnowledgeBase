**READY MODE**
- STOP: non-function.
- START: starts the elliptical after a 3 second countdown on the window display. In MANUAL the elliptical starts at MIN LEVEL.
- LEVEL UP / LEVEL DOWN / STRIDE UP / STRIDE DOWN: non-functional if the user has not entered a setting.
- FAN: controls fan ON/OFF.
- DISPLAY: non-functional if the user has not entered a setting.
- ENTER: enters parameter setting. In workout mode ENTER changes the dot matrix display: LEVEL PROFILE -> INCLINE PROFILE -> SCAN (SCAN changes every 3 seconds).

**RUN MODE**
- STOP: stops the elliptical.
- START: changes the LEVEL and STRIDE profile.
- ENTER: non-functional.
- LEVEL UP / LEVEL DOWN: each press changes level by 1.
- STRIDE UP / STRIDE DOWN: each press changes position by **0.5**; maximum stride position **24**, minimum **18**.
- FAN: controls fan ON/OFF.
- DISPLAY: press DISPLAY to display the exercise data for **5 seconds** during a workout.

Note the source disagrees with itself about ENTER: the READY MODE entry says "in workout mode, pressing ENTER key can modify DM display", while the RUN MODE list says ENTER is non-functional and gives the profile change to START. The READY MODE entry also still names the INCLINE PROFILE, on a machine that adjusts stride.
