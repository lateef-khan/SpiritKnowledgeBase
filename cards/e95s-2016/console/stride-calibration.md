If there is a problem with the stride, try running the calibration.

Press the **Stride UP key and the Start key at the same time and hold them down for 5 seconds**. The stride calibration starts and runs automatically.

If the problem persists, contact the service department.

Calibration is also the fix the E3 troubleshooting tables send you back to.
