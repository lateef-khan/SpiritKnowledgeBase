| Reading | Display range | Work range | Notes |
|---|---|---|---|
| SPEED | 0.0 to 99.9 | 0.0~99.9 | miles per hour |
| STRIDE | 0 to 99 | **18 to 24** | position shown 18 to 24, preset value 18 to 24, each press changes by **0.5** |
| LEVEL | 0 to 99 | 1 to 20 | position shown 1 to 20, preset value 1 to 20, each press changes by 1 |
| TIME | 0:00 to 99:99 | 0:00 to 99:59 | count down setup range 10:00 to 99:00 |
| LAPS | 0 to 99 | 0 to 99 | total working laps |
| DISTANCE | 00.0 to 99.9 | 00.0 to 99.9 | miles |
| CALORIES | 00.0 to 999 | 00.0 to 999 | cumulative |
| PULSE | 0 to 999 | 40 to 220 BPM | hand pulse or chest belt receiver |

In RUN mode, if the elliptical has no pulse signal for **8 seconds** the displayed value becomes 0.

**The stride range is 18 to 24 in steps of 0.5**, not an incline of 1 to 20. The manual gives no unit for the stride figure. Note that the E3 test procedure elsewhere in this manual says "20 for max stride, 0 for lowest stride"; that sentence is carried over from the incline machines and does not match this table.

The LEVEL entry is printed with the stride wording: "Display the stride position from 1 to 20". That is how the source reads.
