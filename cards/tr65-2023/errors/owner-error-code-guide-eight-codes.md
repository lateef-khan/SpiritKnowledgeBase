The owner's manual prints an *Error Code Guide* with a meaning and a solution against each of eight codes:

| Error number | Meaning | Solution / cause printed |
|---|---|---|
| E0 | Safety Switch Malfunction | 1. If safety key is placed properly? - Place properly. 2. Is safety key defective? - Replace safety key |
| E1 | Missing speed signal | 1. Check and make sure speed sensor is connected - Connect the speed sensor. 2. Speed sensor is defective - Replace the speed sensor |
| E2 | Over current protection. Treadmill overload, controller protection is activated | 1. Check and make sure of proper walking belt alignment. Make sure of periodic lubrication to minimize belt resistance - See general maintenance. 2. Any roller bearing damage? - Replace roller. 3. Motor overheated? - Replace motor |
| E3 | Incline Error | 1. Is the cable between incline motor and controller connected correctly and properly? Connect properly. 2. Check if incline mechanism being stock or defective? - Replace incline motor. 3. Is VR connected properly or with interference? - Replace incline motor |
| E4 | Improper motor input voltage | Motor is not connected properly or not connected to the controller |
| E5 | Communication disconnected between the console and the controller or communication error | Confirm proper connection between the console and the controller - Connect properly or replace cables |
| E6 | Controller Malfunction | Controller component failure - Replace controller |
| E7 | Abnormal Power Input | Check for proper voltage input for the treadmill |

The same page prints the factory-settings entry and calibration values; those are console facts and are not repeated here. No service manual exists for this machine in the knowledge base, so this owner's table is the only source for its codes.
