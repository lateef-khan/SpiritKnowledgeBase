1. Press the **Program** button to scroll to **USER 1** or **USER 2** and press **Enter**.
2. Use **SPEED up/down** to adjust the time up from **30 minutes** if desired. Press Enter.
3. Press SPEED up/down to set the speed level for the segment and **INCLINE up/down** to set
   its incline level, then press Enter. **Repeat until all 20 segments have been
   programmed.**
4. Press **Start** to begin the workout.

The book does not say whether the segments are saved for the next session, and it prints no
name entry for the user programs.
