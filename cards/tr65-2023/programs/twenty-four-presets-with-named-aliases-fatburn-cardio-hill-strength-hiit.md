The Program window "displays the program selected, between **Manual, P1-P24, Fatburn-P9,
Cardio-P12, Hill-P14, Strength-P17, HIIT-P22, HR1, HR2, User1 or User2**", and the PROGRAM
button scrolls through the same list. So five of the 24 numbered presets double as named
programs: **P9 Fatburn, P12 Cardio, P14 Hill, P17 Strength, P22 HIIT**.

"The treadmill has **24 different programs** that have been designed for a variety of
workouts. These 24 programs have factory preset work levels profiles for achieving different
goals."

**To select and start a preset program:**

1. Press the **Program** button to scroll from Manual through the preset programs. Press
   **Enter** to select the program you want.
2. Preset time for programs is **30 minutes**. Press **SPEED up/down** to modify the time.
3. Press **START** to begin.
4. During the program you can adjust SPEED and INCLINE with the up/down buttons or use the
   rapid keys to jump directly to a setting.
5. Press **STOP** to stop, or pull the safety key away to shut down the computer.

The book prints each program as a 20-column **SPEED** bar chart and a 20-column **INCLINE**
bar chart on pages 25 to 27 (printed 24 to 26), and then, on page 28 (printed 27), a numeric
table of every segment; the table is on its own card. In the pictures, P1 to P10 have an
empty incline chart, matching the table, which prints no incline row for them.
