| Button | What it does |
|---|---|
| **SPEED (FAST)** | Increases the speed by 0.1 mph; hold 3 seconds to increase rapidly. During program setting it raises the value being set. |
| **SPEED (SLOW)** | Decreases the speed by 0.1 mph; hold 3 seconds to decrease rapidly. During setting it lowers the value. |
| **INCLINE (UP)** | Increases the incline by 1 level; hold 3 seconds for rapid change. During setting it raises the value. |
| **INCLINE (DOWN)** | Decreases the incline by 1 level; hold 3 seconds for rapid change. During setting it lowers the value. |
| **ENTER** | Sets Time, Distance, Calorie and other functions for program setting. |
| **PROGRAM** | Selects a preset program: MANUAL, P1-P24, FATBURN (P9), CARDIO (P12), HILL (P14), STRENGTH (P17), HIIT (P22), USER1-USER2 or HR1-HR2. |
| **START** | Starts the treadmill at the 0.5 mph start speed. |
| **STOP** | Pressed once during training, the treadmill enters pause mode and slows to a complete stop; the incline returns to its starting position while paused. Press Start again to resume with all set values (speed and incline) restored. |
| **FAN** | Turns on the fan. |
| **Speed shortcut keys 1-10** | Set the speed rapidly. |
| **Incline shortcut keys 0-10** | Set the incline rapidly. |

The book prints no second-press behaviour for STOP and no reset key combination. The Programs section holds how each program is set up.
