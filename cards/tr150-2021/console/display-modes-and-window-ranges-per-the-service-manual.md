From the Dyaco GT65-NT014 service manual, chapter 4:

**Modes.** OFF: with no safety key in the console the treadmill shows **E0**. READY: with the key in, press START to start in Manual mode. SLEEP: pressing any button returns the treadmill to READY. RUN: pressing STOP, or removing the key, stops the treadmill instantly.

| Window | Display range | Work range | Notes |
|---|---|---|---|
| SPEED | 0.0 – 99.9 | 1.0 – 16.0 km or 0.5 – 12 mile | FAST/SLOW change it by 0.1 |
| TIME | 0:00 – 99:99 | 0:00 – 99:59 | Count-down setup 10:00 – 99:00; preset is count up; STOP saves the value, and re-entering RUN continues counting up |
| DISTANCE | 0.00 – 99.9 | 0.00 – 99.9 | km or miles |
| CALORIES | 0.0 – 999 | 0.0 – 999 | |
| PULSE | 0 – 999 | 40 – 220 bpm | "by using hand pulse or receiver"; a chest belt must be worn for the receiver |
| PROGRAM | 000 – 999 | 0, P1 – P12 | one press of Program shows one mode |

Two contradictions to know: the 12-mile speed maximum here is not what the calibration procedure sets (10 miles, [calibration card](calibration-program-key-eng-wheel-42-max-16.md)), and the owner's manual for the TR150 prints no pulse feature at all, while this page describes one. The LCD layout and key drawings in this chapter are pictures with no readable text.
