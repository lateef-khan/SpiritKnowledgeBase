**IDLE MODE**

| Button | Action |
|---|---|
| Stop | No function. |
| Start | Starts the bike. A 3 second count-down runs on the window display first. In MANUAL the bike starts at MIN LEVEL. |
| Level Up / Level Down | No function until the user enters a setting. |
| Fan | Fan on or off. |
| Enter | No function. If a program has been chosen, press Enter to modify the setting. |
| Program | Selects a program to begin a workout. |
| Display key | No function. |

**EXERCISE MODE**

| Button | Action |
|---|---|
| Stop | Stops the bike. |
| Start | No function. |
| Level Up / Level Down | Each press changes the level by 1. |
| Fan | Fan on or off. |
| Enter | No function. |
| Program | Selects a program to begin a workout. |
| Display key | Switches the exercise data shown. Press again on the last data to start a data scan that cycles every 4 seconds. |

The scan cycle shows "LAPS XX" first, then "SPEED XX.X MPH", "SPEED XX.X RPM", "L XX MAX LV XX" (program mode only), "WATT XXX" and "SEG TIME XX:XX".

**The Enter and Display rows contradict each other.** Both mode tables say the Enter button has no function, but the Display key row describes the scan as an Enter press. Take the Display key row as the working description.
