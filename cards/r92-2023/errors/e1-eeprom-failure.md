**This is E1, not E2 (gear motor). Those are the only two codes this bike has.**

Definition: when the EEPROM is damaged, or there is a problem with access to it, all windows turn off, all outputs stop and the message window displays **"E1"**.

Troubleshooting: **the EEPROM is abnormal, replace the Display Board directly.** The manual gives no other step.

The error table prints the meaning as "EEPROM failure".

**The named part changed between generations.** The R92 2016, B94 2016 and B94 2019 manuals answer the same fault with "replace the upper controller". This manual names the Display Board.
