| Item | Tool |
|---|---|
| #112 | 12/14mm Wrench |
| #114 | Phillips Head Screwdriver |
| #132 | **13/15mm Wrench** as printed in the tool list |

**The manual contradicts itself about #132.** The ASSEMBLY TOOLS list on page 5 labels #132 a **13/15mm** wrench. Every instruction that uses it - the seat handle bar in step 2 and the pedals in step 4 - calls #132 the **14/15mm** wrench. The LCR 2013 and all later LCR manuals print 14/15mm in the tool list as well.

The manual never reconciles the two. Read the size stamped on the wrench in your own box before answering a customer.

**Tool item numbers are not shared between models.** The same `#` is a different part on another Sole bike, so use the list printed in your own machine's manual.
