Hardware: **#65** 3/8" x 2-1/4" Hex Head Bolt (4 pcs), **#77** 3/8" x 19 x 1.5T Flat Washer (6 pcs), **#84** 3/8" x 25 x 2T Flat Washer (4 pcs), **#176** 3/8" x 3/4" Hex Head Bolt (6 pcs), plus four M5 x 15mm Phillips Head Screws.

1. Install the Rear Stabilizer (7) onto the Main Frame (1) with four Hex Head Bolts (65) and four Flat Washers (84), using the **12/14mm Wrench (112)**.
2. Install the **Seat Back Cover (128)** onto the Seat Back Bracket (5) with four Phillips Head Screws (**136**), using the Phillips Head Screw Driver (114).
3. Install the Seat Back Bracket (5) onto the Seat Carriage (4) with six Hex Head Bolts (**167**) and six Flat Washers (77), using the **12/14mm Wrench (112)**.

**Two item-number conflicts in this step, both left as printed.**

- The four M5 x 15mm Phillips head screws are called **#136** here but listed as **#99** in the assembly pack checklist on page 3 - where #99 is also used for eight M5 x 12mm screws in step 4. The LCR 2013 and 2016 checklists print them as #136, which agrees with this instruction.
- The six 3/8" x 3/4" bolts are called **(167)** here but **#176** in the checklist and in the hardware box printed beside this very step. There is no item 167 anywhere in the checklist.

The R92 of the same year has no seat back cover and no Phillips screws in step 1.
