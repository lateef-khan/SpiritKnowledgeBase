The console has built-in maintenance/diagnostic software - it can switch the display between English
and Metric, and turn off the key beep, among other things.

**Press and hold Start, Stop and Enter for about 5 seconds.** The message window displays
`ENGINEERING MODE MENU PRESS ENTER`. Press **Enter** to open the menu. The manual notes the mode
**may be called Maintenance menu or Engineering mode depending on the software version**.

- **a. Key test** - test all the keys to make sure they are functioning
- **b. Display test** - tests all the display functions
- **c. Functions** (press Enter to access settings)
  1. **Sleep mode** - turn on to have the console power down automatically after **30 minutes of
     inactivity**
  2. **Pause Mode** - on allows 5 minutes of pause; off makes the console pause indefinitely
  3. **ODO reset**
  4. **Units** - English or Metric
  5. **Beep** - the beep when a key is pressed
  6. **D/A test** - tests the brake resistance
  7. **SAFETY**
- **d. Security** - locks the keypad so no unauthorised use is allowed

**The manual prints "SAFETY" with no explanation at all.** It is the seventh Functions entry and
nothing else in the manual describes it. Do not guess what it does.

**Thirty minutes, not twenty.** The CE800-2013 menu is laid out almost identically but prints a
**20-minute** sleep and an Elliptical-or-Bike setting where this one has SAFETY:
`ce800-2013-console-engineering-mode-elliptical-or-bike`.

Stride calibration is entered a different way and is a separate card:
`ce850-2016-console-stride-calibration`.
