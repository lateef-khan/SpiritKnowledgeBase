These are the callout numbers on the exploded view drawing. The drawing is a
picture with bare numbers on it and no text, so the table below is the only
readable form of it.

**139 rows are printed.** The whole item numbers that appear are 1-18, 20, 22-37, 40-53, 55-73, 75-78, 80-97, 99-104, 106-113, 116-130, 153-154, 160. Any number outside that run is **not printed in this manual at all** - 19, 21, 38, 39, 54, 74, 79, 98, 105, 114, 115, 131, 132, 133, 134, 135, 136, 137, 138, 139, 140, 141, 142, 143, 144, 145, 146, 147, 148, 149, 150, 151, 152, 155, 156, 157, 158, 159 are absent, not a missing page.

**This is the first parts list the repository holds for a Spirit stepper.** No
earlier CS800 manual is carded, so there is nothing to compare it against.

## What the list says about how the machine works

The manual's prose never names the resistance system. **The parts list does:**

- **Item 26 `Flywheel`, item 27 `Magnet`, item 33 `Gear Motor`** and item 34 a
  200 mm reed switch. A gear motor moving a magnet against a flywheel is a
  motor-set magnetic brake.
- **Item 36 `Power Adaptor`, item 32 a 100 mm power cord**, item 37 a
  `Transformer Power Cord(Optional)` and items 124 and 126 further power cords,
  one marked `(Optional)`. **The machine plugs in.** There is no
  `Generator/Brake` row anywhere in the list.
- **Item 125 is a `TV Adapter`.**

See `spirit-climber-2024-specs-resistance-system`.

## What tells this list apart from the recumbent stepper's

The CS800 is the standing stepper and the CRS800S the recumbent one. They share
118 item numbers and agree on **two** of them, so a number read from the wrong
book is almost certainly the wrong part. The recumbent list carries a seat
carriage, an aluminium seat track, eight seat track wheels, a locking gas
cylinder and a rotate disk that this machine has no equivalent of, and runs to
239 rows against this list's 139.

## The console is item 30 with sixteen sub-items

Items 30-1 to 30-16 are the console's own parts, printed in the manual with a
tilde (`30~1`) and written here with a hyphen so the numbers sort.

**No flywheel weight, step height, machine weight or resistance rating is printed
against any row.** See `spirit-climber-specs-no-specification-table`.

Both parts-list pages carry a full, clean text layer, so every row here comes from
`pdftotext -layout` run on the PDF itself. The `text.md` extract of this source
also carries an OCR supplement for each of these pages; that supplement is
garbled and **is not the source of any figure on this card**.
