**UNPLUG STEPPER BEFORE PERFORMING ANY MAINTENANCE.**

| Item | Daily | Weekly | Monthly | Quarterly | Biannually |
|---|---|---|---|---|---|
| Entire Stepper | Clean | | Inspect | | |
| Unit Hardware | | Inspect | | | |
| Detailed Cleaning | | Clean | | | |
| Console Hardware | | | | Inspect | |
| Steps | Clean | | Inspect | | |
| Console Overlay | Clean | | | | Inspect |
| Accessory Tray | Clean | | | | |
| Stop Switch | Clean | | | Inspect | |
| Emergency Switch | Clean | | | Inspect | |

Nine items, five intervals, and **no annual column** — the table stops at Biannually.

## The CRS800S prints the same nine rows and leaves the last one empty

The CRS800S semi-recumbent stepper's table is this table row for row and mark for mark **except that
its Emergency Switch row carries no interval at all** — the cells are blank on the printed page.
Answer a CRS800S from `crs800s-2024-maintenance-machine-care-schedule`, not from here, and do not
read a daily clean or a quarterly inspection of its emergency switch off this card.

## It is not the stairclimber table and not the treadmill table

The **CSC900** stairclimber prints nine rows too, but names the first row *Entire Unit* rather than
Entire Stepper, swaps the order of Unit Hardware and Detailed Cleaning, and has **Accessory Cups**
where this machine has an **Accessory Tray** — `csc900-2024-maintenance-machine-care-schedule`. The
Spirit treadmill table is eighteen rows with an Annually column
(`ct900-maintenance-schedule`), and the rower's is seven
(`crw800-2024-maintenance-machine-care-schedule`).

## Two things this table does not have

- **No Levelers row.** Neither stepper table lists the levellers, although both machines' Machine
  Care text tells an owner to check levelling when a noise persists
  (`ct800-2016-maintenance-squeak-thump-or-clicking`). There is no printed interval for that check.
- **No USB Port row**, which the bike, elliptical and treadmill tables all carry.
