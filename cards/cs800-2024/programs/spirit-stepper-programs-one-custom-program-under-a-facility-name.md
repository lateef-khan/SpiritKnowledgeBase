**This machine has one Custom program with a facility name.** The CRS800S has **two** - Custom 1 and
Custom 2, named after the user - see
`spirit-stepper-programs-two-custom-programs-named-after-the-user`. The two must not be swapped.

The Custom Program lets you build and save a custom program, or **save any preset program you
complete as a custom program**. It can also carry **your facility name**.

1. Press the **Custom** button. The Dot Matrix Message Center shows a welcome message; if you saved
   a program before, the message contains the name you gave it. Press **Enter** to begin.
2. The Center shows **"Name - A"** if no name is saved, or **"Name - Custom Workout"** with the C
   blinking if that name was saved. Use Up and/or Down to change each letter and **Enter** to accept
   it. Press **Stop** to keep an existing name, or to finish entering a new one.
3. Enter your **Age**, then Enter.
4. Enter your **Weight**, then Enter.
5. Set the **Time**, then Enter.
6. Set the **Max Level** - the peak exertion level during the program - then Enter.
7. The first column blinks; set the level for the first segment and press **Enter**.
8. Each next segment starts at the previous segment's level. Repeat **until all twenty segments have
   been set**.
9. Press **Enter** to save. The Center says **"New program saved"**, then offers to start or modify
   the program. **Stop** exits to the start-up screen.
10. **Up or Down during the program only affects the present position in the profile.** When the
    profile moves to the next column it returns to the preset work level.
11. During the program the buttons beside the matrix scroll the data, switch between the profile
    display and a **quarter mile track**, and can **switch to heart rate Auto-Pilot mode**.

*Steps 10 and 11 are printed under the heading "User 1 or User 2 program" on a machine that has only
one Custom program. The wording is recorded as printed.*
