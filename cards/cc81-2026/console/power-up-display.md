On power up the console lights up all the characters, then shows:

- **Time window** - the total time the machine has been used since it was new.
- **Total Step window** - the total steps since new.
- **Message Window** - the software version (for example `VER 1.0`).

After **3 seconds** the console goes to the start-up display and the machine is ready for use.

**Note on the source.** The sentence is printed as "the console will display all light up all the characters", a typesetting fault in the manual; the meaning is that every character lights up. This page also calls the machine "the stepper" while the rest of the manual calls it a climber, which has its own card.
