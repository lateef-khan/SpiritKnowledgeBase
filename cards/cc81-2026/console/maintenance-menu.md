The console has built-in maintenance/diagnostic software. It is where the console settings are changed - English to Metric, or turning off the key beep, for example.

1. Press and hold the **Start, Stop and Enter** keys together.
2. Keep holding for about **2 seconds**. The Message Window displays **"Engineering Mode"**.
3. Press **Enter** to access the menu.
4. **Rotate the Level knob** to navigate the menu, then press **Enter**.

**The menu**

- **A. Key Test** - lets you test all the keys to make sure they are functioning.
- **B. Display Test** - automatically tests all LCDs.
- **C. Functions** - press Enter to access settings, use the Level knob to scroll. See the settings card.
- **D. Factory Set** - the manual lists this item and gives no description of what it does.
- **E. Exit** - select to exit the Maintenance Menu.

**On the two names.** The manual calls it the Maintenance Menu but says it "may be called Engineering Mode, depending on version", and the message the console actually displays is "Engineering Mode". Both names are the same menu.
