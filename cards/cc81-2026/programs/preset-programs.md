The Climber has **five** different programs designed for a variety of workouts. All five have factory preset work level profiles for achieving different goals:

| Program | Goal |
| --- | --- |
| Hill | Simulates going up and down a hill. |
| Fat Burn | A lower, steady exertion workout. |
| Cardio | Cardiovascular function and endurance. |
| Strength | Lower-body muscular strength. |
| HIIT | Intervals of high then low intensity. |

Each program has its own card, and each has its own key on the console. The Manual program, which is not a preset, is a separate card again.
