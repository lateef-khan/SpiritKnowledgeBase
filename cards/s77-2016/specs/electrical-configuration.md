| Part | What the manual says it does |
|---|---|
| Safety key | Fits on the console and activates all functions. Without it the console cannot be controlled. |
| Console | Interface that controls all functions of the treadmill. |
| Main controller | Carries the **DC** power supply for the console, the incline driver and the DC motor driver. Links the console to the motor and outputs the voltages that control the treadmill. |
| Treadmill motor | A variable speed **DC** motor, 0 to 180 VDC (0 to 90 VDC on a 120 Vac machine). |
| Incline motor | An AC motor, controlled from the console through the main controller. |

**The console is described as an LCD display in this section**, while section 4 shows a **10.1 inch TFT panel**. Both refer to the same console.

This is a DC machine: it has a lower controller and a DC drive motor, not the AC inverter of the slat belt models.
