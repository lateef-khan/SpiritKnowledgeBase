| Field | Value |
|---|---|
| Sole model number (SKU) | 577816 |
| Name in the Spirit `Models` table | SOLE S77 2016 |
| Manual cover | `ST725 Treadmill Service Manual` |

**The manual never says "S77".** It is written throughout as the **ST725**, which is the Dyaco factory code. The Sole name and the SKU come from the Spirit database, not from the manual.

**The manual also names an ST535, once.** The CE version note is headed "Special Note on ST725 CE version" and its first line reads "Besides normal version, ST535 treadmill is with a CE version." One of the two codes in that sentence is wrong and the manual gives no way to tell which.

The SKU digits agree with the year here: `577816` ends in `16` and the row is named `SOLE S77 2016`. The next S77 does not follow the rule - `577818` ends in `18` but is named `SOLE S77 2019`.

Other S77 rows in the same table, which are **not** this machine: 577003, 577810 (AS77), 577812 (S77 2013), 577881, 577886 (US77 2006), 577887 (VS77 2007), 577888 (WS77 2008/09), 577818 (S77 2019).
