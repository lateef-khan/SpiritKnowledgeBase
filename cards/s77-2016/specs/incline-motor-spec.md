| Field | Value |
|---|---|
| Type | AC motor |
| Voltage | **230 volt**; **115 volt on a 120 Vac machine** |
| Power wires | Four: red, black, white, green |
| Sensor | One 3-pin position sensor cable |

| Wire | Terminal | Effect |
|---|---|---|
| Red | UP | AC voltage here raises the incline |
| Black | DOWN | AC voltage here lowers the incline |
| White | COM | Neutral |
| Green | Ground | - |

**The manual gives two different figures for the mains at the incline motor.** Section 3 says 230 volt with 115 volt in brackets for a 120 Vac machine. The E3 test procedure on page 49 says the voltage between the neutral (white) wire and the up or down wire "should be about the same as the mains voltage ~ 110VAC (230VAC)". Measure against the supply the machine is actually on.
