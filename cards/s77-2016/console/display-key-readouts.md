Pressing **DISPLAY** during a workout switches the exercise data shown in the message window:

- `LAP XXX`
- `VERTICAL XXXX M` (unit: metre)
- `SEGMENT TIME X:XX` - **not shown in HRC mode**
- `MAX SPEED XX.X`

Before a program starts, the display key instead switches between the speed profile and the incline profile as a dot matrix.
