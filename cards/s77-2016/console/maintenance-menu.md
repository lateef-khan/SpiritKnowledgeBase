1. Press and hold **START, STOP and ENTER** together until the display shows `Engineering mode`. Depending on the software version it may say `maintenance menu` instead.
2. Press **ENTER**.
3. Scroll with the Speed up and down keys. **STOP** goes back to the previous selection.

| Item | What it does |
|---|---|
| A. Key test | Tests every key |
| B. Display mode | Turn **off** to have the console power down automatically after 30 minutes of inactivity |
| C. Pause mode | **On** allows 5 minutes of pause; **off** pauses indefinitely |
| D. Lube message reset | Resets the lube message and the odometer readings |
| E. Key tone | Turns the key beep on or off |
| F. Child lock | Locks the keypad. Press and hold **START and ENTER for 3 seconds** to unlock. |

**There is a second way into engineering mode**, used by the E0 procedure: remove the safety key, press STOP, START and ENTER together and refit the key at the same time.

**The later ST728 manual for this machine family has a different menu**: Key Test, Display Test, Functions (Display Mode, Pause Mode, Maintenance, Units, Key Tone), Security and Exit.
