| Key | Run mode behaviour |
|---|---|
| Safety key | Pulling it away shuts the computer down automatically |
| Stop | Stops the treadmill |
| Start, Enter | No function |
| Fast / Slow | Each press changes the speed by **0.1 kph (0.1 mph)**. Held down, the speed runs to MAX or MIN quickly. |
| Up / Down | Each press changes the incline by 1 |
| Speed rapid | Jumps to 2, 3, 4, 5, 7, 9 or 12 |
| Incline rapid | Jumps to 1, 3, 5, 7, 9, 12 or 15 |
| Fan | Fan on or off (optional) |

**The manual gives two different maximum inclines.** This section says "the maximum incline position is 12", while the incline rapid keys reach **15** and the console data ranges give the incline work range as 0 to 15. The later ST728 manual for this machine family prints 15 in this same sentence.
