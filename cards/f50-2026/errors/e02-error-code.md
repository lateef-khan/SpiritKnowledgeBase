**This is E02, a two-digit code. It is not E2. Do not confuse it with E22, the communication error, which has a completely different remedy list.**

**Meaning printed in the manual:** "Hall mistake".

- **Motor is not connected properly, or not connected to the controller.**
- **Replace the motor.**
- **Replace the controller.**

**The remedies for E02 are printed without step numbers**, unlike every other row in this table. They are reproduced above in printed order; the manual does not say whether the order is a sequence.

**E02 and E04 carry almost the same remedy list.** E04 is phase loss and its list is numbered 1 to 3 with the same three actions.
