**The manual gives one line:** "**Check the problem handling based on the error code reported.**"

In other words, this symptom has **no remedy of its own** - read the code on the console and work that code's card. The codes that stop the motor are **E01, E02, E03, E04, E05, E06 and E31**; **E22** means the console and controller are not talking at all.

If **no** code is shown and the display is dark, that is a different row - see the dark display card.
