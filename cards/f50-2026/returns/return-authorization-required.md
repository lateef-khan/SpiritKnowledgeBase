**DO NOT SHIP ANY UNIT TO OUR FACTORY WITHOUT A RETURN AUTHORIZATION NUMBER. All units arriving without a return authorization number will be refused.**

If a unit or part does go back:

- **All transportation costs, both to the factory and on return to the owner, are the responsibility of the owner.**
- **The owner is responsible for adequate packaging on return to SOLE.**
- **SOLE is not responsible for damages that occur during shipping. Make all freight damage claims with the appropriate freight carrier.**

**Before returning the product to a retailer**, the manual asks you to call Sole first - see the separate card.
