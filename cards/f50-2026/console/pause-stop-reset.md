- **Press the red Stop key once while running to pause.** The tread-belt **slowly decelerates to a stop** and **the incline goes to zero percent**. **Time, Distance and Calorie readings hold** while the unit is in pause mode. **After 5 minutes the display resets and returns to the start-up screen.**
- **To resume, press the Start key while in pause mode. The speed and incline return to their previous settings.**
- **Press Stop a second time** and **the program ends and a workout summary is displayed**.
- **Press Stop a third time** and **the console returns to the idle (start-up) screen**.
- **Hold Stop down for more than 3 seconds** and **the console resets**.

**The 5-minute pause is a setting, not a fixed rule.** The Engineering Mode Menu has a **Pause Mode** item: **on** allows 5 minutes of pause, **off** lets the console pause indefinitely. Both halves are stated in this manual and neither page mentions the other.
