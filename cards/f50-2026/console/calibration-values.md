The calibration routine steps through six values. Each is printed as a number with **no unit**:

| Step | Window | Value the manual tells you to confirm |
|---|---|---|
| 4 | Distance | Roller size diameter is **49** |
| 5 | Time | Motor size diameter is **28** |
| 6 | Speed | Pulley size diameter is **88** |
| 7 | Speed | Maximum speed of **10** |
| 8 | Distance | Minimum velocity **0.5** |
| 9 | Incline | Maximum elevation **17** |

**No units are printed for any of these numbers.** The roller, motor and pulley figures are described only as "diameter"; maximum speed and minimum velocity are plausibly mph, since the same routine sets Miles/E as one of two unit choices, and maximum elevation is plausibly percent - but **the manual states none of that**, so do not quote units from this card.

This manual has **no specification table**, so these are the only machine numbers it prints.
