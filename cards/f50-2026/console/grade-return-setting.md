Step 3 of the calibration routine shows this setting in the **INCLINE window**, printed as:

> "The INCLINE window shows Grade return - ON (he stop button is pressed and does allow incline to return to zero. For sale in Europe, EU standards require this to be off) , then press Display/Enter"

**What is certain:** the setting is called **Grade return**, it is reached inside the calibration routine, its default is **ON**, it governs **whether the incline returns to zero when the stop button is pressed**, and **units sold in Europe must have it off because of EU standards**.

**What is damaged:** the sentence in brackets starts "he stop button", almost certainly a dropped "T" from "The stop button". The text as printed reads "does allow incline to return to zero" - it is not recoverable from this source whether ON means the incline returns to zero or the opposite. **No mapping has been invented here.**

The Pause/Stop behaviour on page 14 states plainly that **pressing Stop once sends the incline to zero percent**, which is consistent with the default being ON.
