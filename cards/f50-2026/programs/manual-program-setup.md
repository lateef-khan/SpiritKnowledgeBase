1. **Press the Program keys to view the programs on the screen, then press the Display/Enter key to select the program you would like to perform.**
2. **You can just press the Start key to begin the program using the preset program values** for age, weight and other program-specific information.
3. **If Display/Enter was pressed, the Incline window will display Age.** Use the **speed knob key** to adjust your age, then press Display/Enter.
4. **The Incline window then displays your body weight.** **Entering the correct body weight will affect the calorie count.** Adjust with the speed knob key, then press Display/Enter.
5. **The Time window then displays the total workout time desired.** Adjust with the speed knob key, then press Display/Enter.
6. **Press Start to begin the program.**

**You may press Start at any time during programming to start with the information you have already entered.**

**The manual program is the one with no speed or incline profile behind it.** The preset programs P1 to P12 add a **max speed step** and a **3-minute warm-up** that the manual program setup does not mention.
