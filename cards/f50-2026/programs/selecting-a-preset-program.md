1. **Press the Program keys to view the programs on the screen, then press the Display/Enter key to select the program** - **P1, P2, P3, P4 ... P12**. **You can just press the Start key to begin using the preset program values** for age, weight and other program-specific information.
2. **If Display/Enter was pressed, the Incline window displays Age.** Adjust with the speed knob key, then press Display/Enter. **You may press Start at any time during programming to start with what you have already entered.**
3. **The Incline window then displays your body weight.** **Entering the correct body weight will affect the calorie count.** Adjust, then press Display/Enter.
4. **The Time window then displays the total workout time desired.** Adjust, then press Display/Enter.
5. **The Speed window displays the preset max speed of the selected program.** Adjust with the speed knob key, then press Display/Enter. **Each program has various speed changes throughout; this lets you limit the highest speed the program will reach at its peak.**
6. **Press Start to begin the program. The program begins with a 3 minute warm-up. To bypass this and go directly to the beginning of the program, press Start again.**

**The 3-minute warm-up here and the warm-up columns in the profile table are not tied together by the manual.** Every profile row prints **three warm-up columns and three cool-down columns**, and the manual never says whether those three columns are the 3 minutes named in step 6.

The step list is printed with a stray duplicated numeral - step 2 reads "2. 2." in the source.
