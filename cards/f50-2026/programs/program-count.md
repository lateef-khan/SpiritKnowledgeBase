**The manual contradicts itself in a single sentence.** As printed:

> "The F50 / have Eight built-in programs: one Manual program (P0), twelve preset profiles (P1-P12)."

**"Eight built-in programs" cannot be reconciled with "one Manual program plus twelve preset profiles", which is thirteen.** No other page in the manual gives a program count. The rest of the manual is consistent with **thirteen**: the selection page says "PP1, P2, P3, P4....P12", and the profile table on pages 19 to 20 prints **twelve numbered rows, P1 through P12**, each with its own speed and incline profile.

**No winner is picked here.** The count sentence is reproduced as printed; the twelve profiles are each carded separately from the table, which is the part of the manual that can be checked.

**The sentence is also damaged.** "The F50 / have" has a dangling slash where a second model name would sit, so this line was probably shared with another machine's manual.
