1. **Install Front Console Mast Cover (L) (47), Rear Console Mast Cover (L) (48), Front Console Mast Cover (R) (49) and Rear Console Mast Cover (R) (50) onto the Console Assembly (11) with Sheet Metal Screw (95) 4pcs**, using the M5 Allen Wrench Head Screw Wrench (97).
2. **Install Frame Base Cover (L) (42) and Frame Base Cover (R) (43) onto the Left Upright (4) and Right Upright (5) with Phillips Head Screw (87) 4pcs**, using the M5 Allen Wrench Head Screw Wrench (97).
3. **Install Console Outer Cover Mast Cover (46) onto the Console Assembly (11) with Phillips Head Screw (87) 2pcs**, using the Allen Wrench Head Screw Wrench (97).
4. **Insert Square Safety Key (20) into the Console Assembly (11).**

Steps 1 to 3 use screws that take a **Phillips** driver, but the manual names the combination tool (97) by its Allen-wrench end each time. Tool 97 is a **combination M5 Allen wrench and Phillips head screwdriver**, so the Phillips end is the working end here.
