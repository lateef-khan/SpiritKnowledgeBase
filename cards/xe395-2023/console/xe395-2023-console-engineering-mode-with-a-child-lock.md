**To open it: press and hold Start, Stop and Enter together for about 5 seconds.** The Message Center
displays **Engineering Mode Menu**. Press **Enter** to reach the menu.

| Item | What it does |
|---|---|
| **1. Key Test** | Tests all the keys |
| **2. Display Test** | Tests all the display functions |
| **3. Functions** | Press Enter for the settings; **the + or - arrow scrolls them** |
| **4. Child Lock** | Allows the keypad to be locked to prevent unauthorized use |
| **5. Exit** | |

**Inside Functions, in the printed order:**

1. **Units** - English or Metric display measurements
2. **Pause Mode** - turn on to allow **5 minutes** of pause, turn off to pause indefinitely
3. **ODO Reset** - resets the odometer
4. **Sleep Mode** - **turn off** to have the console power down automatically **after 15 minutes** of
   inactivity
5. **Beep** - turns off the speaker so no beeping sound is heard
6. **Motor test** - continually runs the tensioning gear motor

**Fifteen minutes, not twenty.** Every earlier residential XE that prints a timeout prints **20**
minutes; both 2023 machines print **15**. Do not carry the older figure onto this machine.

**The lock is called Child Lock here** where the 2021 machines call it Security, and on this machine
it is **also a labelled key on the console face** with its own hold-to-unlock behaviour:
`xe395-2023-console-child-lock-key-and-how-to-unlock-it`.

**The XE795-2023 menu is the same shape with two differences** - **PWM test** in place of Motor test,
and **no Child Lock item at all**:
`xe795-2023-console-engineering-mode-with-a-pwm-test`.

**All four 2023 Spirit residential bikes print this menu**, so this card is no longer
elliptical-only: the **XBR25** (p. 29), the **XBR95** (p. 35) and the **XBR55** and **XBU55** (p. 36).
Same three-key entry, same five items, same **Display Test**, same fifteen-minute **Sleep Mode**, same
**Motor test** described as continually running the tensioning gear motor, same **Child Lock** and
**Exit**.

**The bikes print the six Functions settings in a different order.** They run **ODO Reset, Units,
Sleep Mode, Pause Mode, Beep, Motor test**; the XE395-2023 runs Units, Pause Mode, ODO Reset, Sleep
Mode, Beep, Motor test. **The same six settings, listed differently** - quote the items, not their
numbers.

**The XBR25-2023 names a key its console does not have.** Its item 3 reads "Press Enter to access
settings and **Speed** + or- arrow to scroll" in the manual of a bike with no speed control; the other
three bikes and the XE395-2023 print "+ or - arrow". It is a leftover from the treadmill wording, not
a different keystroke.

**The XBR95-2023 has a Motor test where its own earlier printings had a DA Test.** The 2016, 2018 and
2021 XBR95 books test the brake resistance instead:
`xe795-2021-console-engineering-mode-with-a-da-test`. That is the one real console change across the
XBR95's four printings, and it arrives in 2023 rather than between 2016 and 2021.

**Fifteen minutes on the bikes too.** Every 2019 and 2021 bike that prints a timeout prints 20
minutes; all four 2023 bikes print 15.
