These are the callout numbers on the exploded view drawing. The drawing is a
picture with bare numbers on it and no text, so the table below is the only
readable form of it.

**239 rows are printed.** The whole item numbers that appear are 1-104, 106-107, 111-127, 129-132, 134-189, 191-217, 219-223, 241-243, 245-247, 249. Any number outside that run is **not printed in this manual at all** - 105, 108, 109, 110, 128, 133, 190, 218, 224, 225, 226, 227, 228, 229, 230, 231, 232, 233, 234, 235, 236, 237, 238, 239, 240, 244, 248 are absent, not a missing page.

**This is the first parts list the repository holds for a Spirit recumbent
stepper.** No earlier CRS800S manual is carded, so there is nothing to compare it
against and no earlier item numbering to confuse it with.

## What the list says about how the machine works

The manual's prose never names the resistance system. **The parts list does:**

- **Item 38 `Fly Wheel`, item 32 `Magnet`, item 115 `Gear Motor`** and item 118 a
  350 mm encoder cable. A gear motor moving a magnet against a flywheel is a
  motor-set magnetic brake.
- **Item 125 `Power Adapter (110V,220V)`, item 121 a 100 mm DC power cord** and
  item 247 a `Transformer Power Cord (220V,Optional)`. **The machine plugs in; it
  does not generate its own power.** There is no `Generator/Brake` row anywhere
  in the list.
- Item 114 is an `Optical Sensor Board`, not a hall sensor.

See `spirit-climber-2024-specs-resistance-system`.

## Two rows are printed identically, and one is a page number

**Items 13 and 16 both read `Seat Back Bracket` quantity 1**, and **items 27-10
and 27-13 both read `Console Display Board` quantity 1**; neither pair can be
told apart from this list. Items 241 and 242 both read `Sticky Banding Stripe`
quantity 2.

**Item 132 is `5/16" x UNC18 x 5/8"_Hex Head Bolt` quantity 2.** The printed page
number 39 sits immediately to the right of that row in the layout and is not part
of it.

## The console is item 27 with sixteen sub-items

Items 27-1 to 27-16 are the console's own parts, printed in the manual with a
tilde (`27~1`) and written here with a hyphen so the numbers sort. Item 27-16 is
printed `CASFE Board`, a transposition of CSAFE the book does not correct.

**No flywheel weight, seat travel, machine weight or resistance rating is printed
against any row.** See `spirit-climber-specs-no-specification-table`.

## How this table was read

Both parts-list pages carry a full, clean text layer, so every row here comes from
`pdftotext -layout` run on the PDF itself. The `text.md` extract of this source
also carries an OCR supplement for each of these pages; that supplement is
garbled and **is not the source of any figure on this card**.

**Every number, size and quantity is reproduced exactly as printed.**
