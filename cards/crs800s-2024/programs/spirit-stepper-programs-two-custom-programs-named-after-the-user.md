**This machine has two Custom programs. The CS800 has one, stored under a facility name** - see
`spirit-stepper-programs-one-custom-program-under-a-facility-name`.

**Custom 1 and Custom 2 operate exactly the same way**, so the manual describes them once. Both let
you personalise the program by adding **your name**.

1. Using the **Program** button choose the Custom programs, then press **Enter**. The Dot Matrix
   Message Center shows a welcome message containing your name if a program was saved before.
2. If a program is already saved to **CUS1** or **CUS2** it is displayed and you are ready to begin.
   If not, the letter **"A"** blinks in the LED Data Display Window. Up steps to "B", Down steps to
   "Z". Press Enter for each letter, **maximum 7 characters**, then Stop.
3. If a program is already stored, pressing Start or Enter at the welcome screen asks **"Run
   Program?"**. Selecting **No** then asks whether to delete it. **You must delete the current
   program before you can build a new one.**
4. Enter your **Age**, then Enter.
5. Enter your **Weight**, then Enter.
6. Set the **Time**, then Enter.
7. Set the **Max Resistance Level**, then Enter.
8. The first column blinks (**SEGMENT > 1**). Set the resistance level with the Level Up button and
   press Enter.
9. Each next segment starts at the previous segment's level. Repeat **until all twenty segments have
   been set**.
10. Press **Enter** to save. The Center says **"Program Saved"**, then offers to start or modify.
    **Stop** exits to the start-up screen.
