**UNPLUG SEMI-RECUMBENT STEPPER BEFORE PERFORMING ANY MAINTENANCE.**

| Item | Daily | Weekly | Monthly | Quarterly | Biannually |
|---|---|---|---|---|---|
| Entire Stepper | Clean | | Inspect | | |
| Unit Hardware | | Inspect | | | |
| Detailed Cleaning | | Clean | | | |
| Console Hardware | | | | Inspect | |
| Steps | Clean | | Inspect | | |
| Console Overlay | Clean | | | | Inspect |
| Accessory Tray | Clean | | | | |
| Stop Switch | Clean | | | Inspect | |
| **Emergency Switch** | | | | | |

Nine items, five intervals, and **no annual column** — the table stops at Biannually.

## The Emergency Switch row is printed with no interval in any column

The row exists, the machine has the switch, and **every one of its five cells is blank**. This is
the only difference between this table and the CS800 stepper's, which gives the same row a **daily
clean and a quarterly inspection**
(`cs800-2024-maintenance-machine-care-schedule`). The row above the empty one, Stop Switch, does
carry the daily clean and quarterly inspection on both machines.

The blank was confirmed on the rendered page rather than inferred from an OCR miss: the page is a
flattened image, so the row was cropped from a 300 dpi render and read directly. **Do not fill it in
from the CS800.** If a customer asks how often to service the emergency switch on a CRS800S, the
answer is that their manual prints no interval, and the neighbouring Stop Switch row is the closest
thing the book gives.

## What else is missing from this table

- **No Levelers row**, although the Machine Care text tells an owner to check levelling when a noise
  persists (`ct800-2016-maintenance-squeak-thump-or-clicking`).
- **No USB Port row**, which the Spirit bike, elliptical and treadmill tables all carry.
- **No row for the step rails or the pedal carriage wheels**, even though this is the one machine of
  the fourteen whose manual prints a cleaning procedure for them —
  `crs800s-2024-maintenance-step-rail-and-carriage-cleaning`. That procedure has **no interval**,
  and this table does not supply one.
