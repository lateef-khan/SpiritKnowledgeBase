Hardware: **#58** M5 x 12mm Phillips Head Screw (6 pcs), **#161** 3.5 x 12L Sheet Metal Screw (4 pcs).

1. Insert the Computer Cable (29) and the two Hand pulse W/Cable Assemblies (26) onto the Console Assembly (34).
2. Secure the Console Assembly (34) onto the Console Mast (2) with the four Phillips Head Screws (58) by using the Phillips Head Screw Driver (93).
3. Install the Pedals (L)(R) (45)(46) onto the Crank Arms (16L)(16R) by using the **13/15mm Wrench (92)**.
4. Turn on the Brake Tension Knob (86) and put the Sliding Seat Mount (7) on the Seat Slider (6).
5. Let the Brake Tension Knob (86) through the Flat Washer (71), the Seat Slider (6) and the Sliding Seat Mount (7); adjust the position and tighten the Brake Tension Knob (86) with the Fix Plate (8).
6. Install the Seat (19) on the Sliding Seat Mount (7) by using the **12/14mm Wrench (100)**. Apply the screw of the Brake Tension Knob (86) and tighten.
7. Install the Tablet Holder (160) to the back of the console with four Sheet Metal Screws (161) by using the Phillips Head Screw Driver (93).
8. Secure the Beverage Holder (116) onto the Console Mast (2) with the two Phillips Head Screws (58) by using the Phillips Head Screw Driver (93).

Six #58 screws: four for the console, two for the beverage holder. **No stabilizer cover is fitted in this step** - unlike every LCB up to 2016.

The LCB 2023 prints the same eight instructions but adds **four Star Washers (165)** under the four console screws in item 2.

**This step no longer warns about the left pedal's reverse thread.** The instruction is only "install the pedals onto the crank arms using the 13/15mm Wrench (92)". The warning is printed in the 2011-2013 B94 and LCB manuals and in every R92 and LCR manual, but not here. The left pedal is still reverse-threaded; the manual just does not say so in this step.
