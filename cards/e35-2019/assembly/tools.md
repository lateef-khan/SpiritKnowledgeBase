Four tools are listed:

| Item | Tool |
| --- | --- |
| #184 | 13/14mm Wrench |
| #185 | Short Phillips Head Screwdriver |
| #186 | Phillips Head Screwdriver |
| #217 | L Allen Wrench |

The steps still call for a 12/14 wrench as (187) in several places, but no such wrench is in this list. Keep a 12/14mm wrench of your own to hand for the bolt-and-nut pairs.
