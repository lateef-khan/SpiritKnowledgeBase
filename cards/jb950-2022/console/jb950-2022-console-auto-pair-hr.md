**Purpose: to turn ON or OFF the HR pairing function during Warm Up Mode.** The manual's reason:
**not all cycling classes are done using heart rate**, and facilities have the option to simplify the
user set-up and get riders into Manual Mode where HR tracking is not used.

1. Press the **Play Key** to change the setting.
2. Press **+ or -** to switch between **OFF** and **ON**.
3. Press the **Play Key** to accept and exit to the setting screen.
4. Press **+** for the next screen, or reset the console to exit Maintenance Mode.

**The default setting is OFF.**

**When OFF, pairing a strap can only be done through the PAIR HR DEVICE function inside Programs
Mode** - hold the Play Key for 3 seconds during Warm Up Mode. It is not lost, only moved.

**The manual names this setting two different ways.** The maintenance menu contents list on page 51
calls it **Auto Detect HR**; the page itself heads it **AUTO PAIR HR**. Same setting, and there is
only one.

**It is not the same as the HR Zone setting** on the next page, which turns the coloured HR LED on or
off and defaults to ON. Turning the LED off still tracks heart rate; turning this off changes only
where the rider pairs.

**Either way, a strap can only be paired during Warm Up Mode.** A rider who puts one on later needs a
console reset - `jb950-2022-console-pair-heart-rate-strap`.
