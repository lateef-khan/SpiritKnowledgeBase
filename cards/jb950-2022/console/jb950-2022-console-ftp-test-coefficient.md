**Purpose: to change the coefficient used for the 5-minute FTP Test.** The manual's reason: **some
testers use a coefficient of 85% in determining the watts level result for the 5-Min FTP Test, others
suggest it should be 80%**, so the setting exists to follow whichever protocol the facility uses.

1. Press the **Play Key** to change the setting.
2. The coefficient displays as **`80 PCT`** with **80 flashing**.
3. Press **+ or -** to change between **80% and 85%**.
4. Press the **Play Key** to accept and exit to the setting screen.
5. Press **+** for the next screen, or reset the console to exit Maintenance Mode.

**The default is 80%.**

**It changes the number, not the test.** The 5-minute protocol itself is unchanged; the coefficient is
what the measured 5-minute power is multiplied by to give the FTP watts figure the console reports.

**So the same rider tested on two bikes can get two different FTPs** if the studio's consoles are set
differently. Set every bike in a room the same way before running tests, and write down which
coefficient a recorded FTP was measured at.

**This affects only the 5-minute test.** The manual also documents a **20-minute** FTP protocol, and
gives no coefficient setting for it.
