**Purpose: to change the brightness of the display.**

1. Press the **Play Key** to change the setting.
2. Press the **+ Key or - Key** to switch between **LED Brightness 1, 2 or 3**.
3. Press the **Play Key** to accept and exit to the setting screen.
4. Press **+** for the next screen, or reset the console to exit Maintenance Mode.

**The default brightness setting is 2** - the middle of the three.

**Three levels is the whole range.** There is no automatic dimming, no light sensor, no per-program
setting and no off.

**It is a per-bike setting.** A studio that dims the lights for a class has to walk the room and set
each console, pedalling each bike above 30 RPM to wake it first.

**A display that is dim on one bike and bright on the next is this setting, not a fault.** Check it
before suspecting the LED panels - and if whole characters are missing rather than merely faint, run
the Display Test instead (`jb950-2022-console-display-test`).
