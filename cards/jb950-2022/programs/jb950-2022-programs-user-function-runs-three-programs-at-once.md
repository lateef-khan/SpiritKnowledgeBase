**The USER function adds another program to run concurrently. The console is capable of running all
three programs at the same time.**

**To reach it:** once you have left Warm Up Mode, **press the Play Key for 3 seconds while in any
program**. **END RIDE or USER** displays. Press **+** or **-** to toggle, press **Play** to select.

**With USER selected:**

- Press **Play**. **If HR is paired, DISCONNECT HR displays.**
- Press **+** to scroll through the programs: **POWER ZONE**, **LAP**.
- Use the **+ Key** and the **Play Key** to activate or disable each program.

What each one can do from here:

- **Power Zone** - USER can turn the program ON or OFF.
- **FTP Test** - USER can be used to access and run FTP tests inside the Power Zone program.
- **Lap Program** - USER can enable or disable the program.

**Heart rate is the exception and it cannot be added here.** "Because USER function is activated
after leaving Warm Up Mode, programs will not start with a Warm Up. **HR can ONLY be paired during
Warm Up Mode.** If HR is not already paired, then USER function cannot activate HR. Console reset is
required."

**To reset the console:** press and hold **+** and **Play** simultaneously for 3 seconds. This
reverts to Warm Up Mode.

**A program started through USER begins without a warm-up**, because you are already riding. That is
the trade for not having to reset the console.
