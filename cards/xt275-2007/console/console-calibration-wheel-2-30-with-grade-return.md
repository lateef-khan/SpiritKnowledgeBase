**The wheel size here is 2.30, and the routine ends with a Grade return step.** The XT175 in the same
dealer manual uses 2.50 and confirms with START (`xt175-2007-console-calibration-wheel-2-50-max-10-0`);
the XT375, XT475 and XT675 use 2.810 or 3.060 and a maximum of 12
(`spirit-xt-2007-console-calibration-factory-setting-wheel-2-810-or-3-060`).

1. **Remove the tether cord.**
2. **Replace the tether cord while holding the buttons.** The display goes into test mode. Press
   **ENTER**.
3. Adjust the **wheel size** with UP or DOWN. **It should be set to 2.30.** Press ENTER.
4. Adjust the **minimum speed** with UP or DOWN. **It should be set to 0.5.** Press ENTER.
5. Adjust the **maximum speed** with UP or DOWN. **It should be set to 10.0.** Press ENTER.
6. Adjust the **maximum elevation** with UP or DOWN. **It should be set to 15.** Press ENTER.
7. **Grade return On/Off.** Use UP or DOWN to change it. **It should be ON.** Press START.
8. The unit auto-calibrates the speed and then the incline and resets when complete. **Do not stand
   on the belt during calibration.**

**Step 2 never names the buttons.** The manual prints "Replace the tether cord while maintaining the
buttons" without a preceding line that says which buttons to hold; the XT175 routine immediately
above it holds START and FAST, and the XT375/XT475/XT675 routine below it holds START and FAST too,
so that is the likely omission, but the manual does not state it for this model. Reproduced as
printed.
