**Treadmill warranty, effective February 1, 2018.**

| Component | **Residential** | **Light commercial (5 hours or less use per day)** |
|---|---|---|
| **Frame** | **Lifetime** | **Lifetime** |
| **Drive Motor** | **Lifetime** | **5 Years** |
| **Parts** | **5 Years** | **3 Years** |
| **Labor** | **2 Year** (sic) | **1 Year** |

The table then defines cosmetic items (grips, console overlays, labels/decals) **without printing any cosmetic period** — carded as printed, with no days figure.

Ruled contradiction: exclusion 8 bars "product use in any environment other than a residential setting" while this table gives light-commercial columns. Both readings stand; the table is the more specific printed term for use of 5 hours or less per day, so this card follows the table and notes the exclusion. See `sole-treadmill-warranty-exclusions-9-item-residential`.

When the clock starts is separate; see `sole-treadmill-warranty-start-date-receipt-or-18-months-shipping`.
