5K Run and 10K Run **set a 5 or 10 kilometre distance goal automatically**. The track display shows one loop equal to the distance and the Distance window starts at 5K/10K; **the distance counts down and the program ends at zero**. Speed is driven manually throughout.

**The Speed readout is in MPH unless the console is set to Metric.** Neither run has a warm-up mode. The 2026 equivalents are on `f80-2026-distance-run-programs`.
