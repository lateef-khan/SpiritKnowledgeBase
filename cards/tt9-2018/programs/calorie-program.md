Select **CALORIE**, then press **ENTER** to customise (or START for defaults). The touch Calories window darkens with the calorie-consumption value; set it with the numeric keypads, press ENTER, and press **START**.

Like the other goal programs, CALORIE has **no warm-up mode**. The F60-2016 calorie countdown in quick-start mode is a cousin: see `f60-2016-programs-preset-programs-and-custom-targets`.
