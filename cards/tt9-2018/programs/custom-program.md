Select **Custom**, then press **ENTER** (or START for defaults). The window shows the **speed profile and incline profile**; touch the **rename icon** to rename the program and enter the profile. After setting, both profiles show on screen for adjustment; the **next/save icon** stores the new profiles, popping the **Time/Age/Weight/Mix Speed** entry window. Then **START** begins the test run of the new program.

Custom has **no warm-up mode**. The button-console Custom with carried-over segments is a different design: see `sole-tt8-programs-custom`.
