The touch screen is worked by touching function buttons directly or with the physical **FAST/SLOW** (speed), **START**, **STOP** and **UP/DOWN** (incline) keys below it. The first-page **HOME** offers four items, usually starting with **Language** (13 languages; touch one to return, HOME or the return icon to go back). **Internet** gives 6 connections (cable or WiFi required) for browsing mid-workout; START still starts the belt. **Exercise Program** opens the Menu (12 program modes; Manual asks for Profile, time, age, weight, then START). After starting, the **SIMPLE** view shows all values (speed right, incline left, bar chart middle switchable with SPEED/INSLINE buttons – the book's spelling), plus TV and INTERNET buttons and a PROGRAM button back to selection; **TRACK** adds the lap track; **DASHBOARD** is a third skin. Ending (first-page button or STOP) shows the summary with all accumulated values.
