**BT Setup** is the seventh Settings entry
(`ce900ent-console-engineering-mode-seven-settings-entries-machine-information-first`). Its
buttons:

| Button | What it does |
|---|---|
| (version field) | Shows the version of the Bluetooth module - the screenshot reads `VERADK2-20140206` |
| Clear | Clears all messages on the window |
| Pair Mode | The window displays "Enter pairing mode" and waits for a connection |
| Deleted Pair | The window displays "OK" and disconnects the Bluetooth connection |
| Reset | The window displays "Bluetooth device is power on" and Bluetooth turns on again |
| Rename BT Device | Modifies the name of the Bluetooth connection; press it again to enter the new name |
| (volume) | "Button for headphone volume control" |

**Pairing procedure, as printed:**

1. Press **Pair Mode**. The window shows "Enter pairing mode".
2. On the phone or tablet, turn Bluetooth on and search for devices. The display shows
   **"ENT console"**. Select it. Both the phone and the console then start the coding request;
   confirm on both and pairing completes.

**The manual gives no PIN and no timeout**, and does not say whether the console pairs for audio, for
heart rate, or for both. The volume control on this screen is labelled for headphones, and the
console has a headphone socket at the right of its key row
(`ce900ent-console-layout-10-1-inch-tft-fan-start-level-stop-enter-and-headphone-socket`).

**The CU900ENT and CR900ENT bike books print this page word for word**
(`cu900ent-bluetooth-pairing`). Their owner's manual pairs from a BT icon on the home screen and
shows the console as A2DP (`ct900ent-bluetooth-pairing`); no owner's manual for this elliptical is
in the repository.
