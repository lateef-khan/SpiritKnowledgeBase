Reach it by **pressing the Home button ten consecutive times**
(`spirit-ent-console-enter-engineering-mode`). The **Settings** list that opens has seven
entries, in this order:

1. **Engineering Mode** - wheel size, beep, sleep, units
   (`ce900ent-console-engineering-mode-settings-wheel-size-na-beep-30-minute-sleep-and-units`)
2. **Security** - distance lock
   (`ce900ent-console-security-distance-lock-100-to-9999-miles-password-2222`)
3. **Diagnostics** - the Error Code Log; "Diagnose and save malfunction error messages for
   technician to inspect the machine and troubleshooting", cleared by pressing the **Error Code
   Log** button ten consecutive times. The log's entries are held with the error cards.
4. **Machine Information** - machine type, GS mode, child lock, speaker, odometer, versions
   (`ce900ent-console-machine-information-machine-type-gs-mode-child-lock-speaker-and-versions`)
5. **Maintenance** - language, software updates, internet, network, machine setup, FTP
   (`ce900ent-console-maintenance-menu-six-buttons-and-twelve-languages`)
6. **TV Setup** - tuner source and channel scanning
   (`ce900ent-console-tv-setup-tuner-source-channel-scan-and-hdmi`)
7. **BT Setup** - Bluetooth pairing
   (`ce900ent-console-bt-setup-pair-mode-rename-and-headphone-volume`)

**Do Machine Information first.** The manual is explicit:

> After entering engineering mode, first priority is to enter "Machine Information" mode to set the
> type of the machine. There are three modes: Treadmill / Elliptical / Bike. Please select for the
> machine. The selection must match the actual machine otherwise it will be unable to operate the
> machine properly.

**This is the CU900ENT and CR900ENT bike menu, printed unchanged for the elliptical**
(`cu900ent-engineering-mode-menu`). The CE800ENT elliptical's setting page has **six** entries
instead - an A/V Source Setup entry, and neither TV Setup nor BT Setup at the top level
(`ce800ent-engineering-mode-menu`). The CE1000ENT-2023 opens a different four-group Maintenance
Mode on ten presses of Welcome
(`ce1000ent-2023-console-maintenance-mode-welcome-ten-times-four-groups`).
