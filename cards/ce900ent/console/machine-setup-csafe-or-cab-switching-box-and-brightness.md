Machine Setup is the fifth button of the Maintenance menu
(`ce900ent-console-maintenance-menu-six-buttons-and-twelve-languages`). The manual prints one line
for it:

> Select "C-SAFE or CAB" button for TV switching box (Choose one is allowed only)

So the two are mutually exclusive - set one, not both. A separate **brightness adjustment** button
sits alongside them; the screenshot shows Brightness Control at 102 and a CSAFE Port Setup switch.

**The manual gives no cable specification, no port location and no rule for which to pick.** The
CE800ENT elliptical calls the same pair **C-Safe protocol** (HDMI transfer to a TV screen) and **CAB
protocol** (connect a set-top box), on its A/V Source Setup screen (`ce800ent-av-source-setup`).

**This is a different thing from TV Setup**, which is where the tuner source is chosen and channels
are scanned (`ce900ent-console-tv-setup-tuner-source-channel-scan-and-hdmi`).

**No owner's manual for this machine is in the repository.** On the CU900ENT and CR900ENT bikes,
which print this line word for word, the owner's manual adds that the choice is about what the
Csafe port drives (`cu900ent-tv-switching-box-selection`); the same is likely here but is not on
record.
