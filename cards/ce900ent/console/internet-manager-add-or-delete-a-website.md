The console ships with **6 preset web pages**, "such as Face Book / You Tube etc."

**To delete one:** press and hold its button for **2 seconds** and the web page is deleted. The
manual's worked example is the You Tube button.

**To add one:**

1. Add a folder named **`Dyaco`** to a USB Transcend stick and copy the icon image for the new
   site into it. Insert the stick into the USB slot on the back of the console and turn the power
   on - the manual says "turn on the power of the treadmill"; the page block is reused across the
   range.
2. Enter the new website address - the manual's example is `flipboard.com`.
3. Enter the new file name - the manual's example is `flipboard`. This is the icon file name the
   new site will use.
4. Press the **Internet Manager** button **10 consecutive times** to enter the preset
   add-a-website mode, then hit **OK** to complete adding the website.

The manual does not say whether a seventh site is possible or what happens when the list is full.

**No owner's manual for this machine is in the repository.** On the CU900ENT and CR900ENT bikes,
which print these two pages word for word (`cu900ent-internet-manager-add-website`), the owner's
manual describes a different on-screen route with no USB stick; whether this elliptical's
owner's manual does the same is not on record.
