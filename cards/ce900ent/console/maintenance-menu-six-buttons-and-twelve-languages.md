Maintenance is the fifth Settings entry
(`ce900ent-console-engineering-mode-seven-settings-entries-machine-information-first`). It holds
six buttons:

1. **Default Language Setup**
2. **Software Update Manager** - `ce900ent-console-software-update-from-a-dyaco-usb-folder`
3. **Internet Manager** - `ce900ent-console-internet-manager-add-or-delete-a-website`
4. **WiFi/Ethernet Setup** - `ce900ent-console-wifi-ethernet-setup-dhcp-or-static-ip`
5. **Machine Setup** - `ce900ent-console-machine-setup-csafe-or-cab-switching-box-and-brightness`
6. **FTP Settings** - `ce900ent-console-ftp-settings-error-log-upload`

**Default Language Setup** sets "the default language for the first page window. There are 12
languages in the menu." The rendered grid shows them in two columns:

| | |
|---|---|
| English | Español |
| Deutsch | 日本語 |
| Français | Italiano |
| 繁體中文 | 简体中文 |
| Português | Nederlands |
| 한국어 | Norsk |

**No owner's manual for this machine is in the repository.** On the CU900ENT and CR900ENT bikes,
whose service manual prints this page word for word (`cu900ent-maintenance-menu`), the owner's
manual explains Machine Setup; here the service manual's own line under Connection Type is the only
description (`ce900ent-console-machine-setup-csafe-or-cab-switching-box-and-brightness`).

**The CE800ENT elliptical has a different Maintenance menu**: seven buttons, with Wi-Fi and Ethernet
split apart, a BT Setup button, and no Internet Manager, Machine Setup or FTP Settings
(`ce800ent-maintenance-menu`).
