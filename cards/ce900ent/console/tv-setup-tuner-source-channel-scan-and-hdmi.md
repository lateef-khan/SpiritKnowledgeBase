**Tuner Source** selects the player source, "such as TV / HDMI mode".

To scan channels:

1. Hit **OSD Menu** to open the main menu, and select **AUTO / DTV / ATV Tuner**.
2. Hit **OSD Enter**.
3. Select the country with the **arrow keys**.
4. Hit **OSD Enter** again to start channel searching. Wait until the search ends.
5. Hit **Update Channel List** to update the list. The screenshot notes "Please scan channels
   first" - the button only rewrites the list from what the scan found.

For **HDMI**, hit **HDMI** directly on Tuner Source and connect the signal source.

**OSD Command** - the drop-down showing `PON` - "is for software R&D engineer only". Leave it alone.

The screen also carries an **OSD Exit** button and a four-way arrow pad. The channel list in the
screenshot is a Taiwanese one (VHF CH 16); it is the demonstration machine's, not a shipped default.

**The CU900ENT and CR900ENT bike books print this page word for word** (`cu900ent-tv-setup`). On
those bikes the owner's manual prints a different Air/Cable scan for the same screen
(`ct900ent-tv-tuner-setup`); no owner's manual for this elliptical is in the repository, so which
menu its console shows is not on record.

The C-SAFE or CAB choice for a TV switching box is a different setting, under Machine Setup
(`ce900ent-console-machine-setup-csafe-or-cab-switching-box-and-brightness`).
