The **Engineering Mode** entry of the Settings list holds four controls.

| Control | Value in the screenshot | What it does |
|---|---|---|
| WHEEL SIZE | **NA** | Shown but carries no value - not applicable on this machine |
| BEEP MODE | ON | ON / OFF for beep sound mode |
| SLEEP MODE | OFF | ON / OFF for sleep mode |
| UNITS | KM | English / Metric mode switching |

Sleep mode, word for word:

> The display always lights when turns off. When there is no action for 30 minutes after turning
> on the power, it enters sleep mode.

Read that as: with sleep mode **off** the display stays lit; with it **on** the console sleeps after
**30 minutes** of no action.

**WHEEL SIZE reads NA here.** On a treadmill console in this family it is a real calibration value;
on this elliptical it is inert. **There is no Pause Mode entry** - the CE800ENT's settings screen has
one (`ce800ent-engineering-mode-settings`); this one does not.

**Thirty minutes is the figure for this console family** (`cu900ent-engineering-mode-settings`,
`ct900ent-sleep-mode-auto-shutoff`). The CE1000ENT-2023 sleeps after **15**
(`ce1000ent-2023-console-maintenance-mode-welcome-ten-times-four-groups`); do not carry either
figure onto the other machine.
