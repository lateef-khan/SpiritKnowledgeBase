1. From the Ethernet Configuration screen, press **"Etherner Configuration"** **10 consecutive
   times** to enter the Android setting mode. The button really is printed with that spelling.
2. Hit **Date & Time**.
3. Select the area - the screenshot's time zone is Taipei Standard Time, the demonstration
   machine's.
4. Check **Automatic Date & Time** "to apply the time provided by the web".
5. **Resume the machine's power when complete.** The manual writes "Please resume the treadmill
   power"; the page block is reused across the range.

Step 4 needs a working network connection, so set Wi-Fi or Ethernet up first
(`ce900ent-console-wifi-ethernet-setup-dhcp-or-static-ip`).

**The CU900ENT and CR900ENT bike books print the same five steps** (`cu900ent-date-and-time-setup`).
