The home screen - the manual also calls it "the first page" - carries four tiles:

| Tile | |
|---|---|
| **TV** | **Language** |
| **Exercise Programs** | **Internet** |

Below them the screen prints:

> To begin workout press the START key on the keypad below. To view an Exercise Program or change
> the Language, select either key above.

So a workout is started from the **physical START key**
(`ce900ent-console-layout-10-1-inch-tft-fan-start-level-stop-enter-and-headphone-socket`), not
from a tile. Pressing **Home ten times** from here opens engineering mode
(`spirit-ent-console-enter-engineering-mode`).

**This book prints no program list, no Quick Start paragraph and no power-up step.** Its Product
Operation chapter is two picture pages; the Exercise Programs tile is named on the screenshot and
nowhere else. No owner's manual for this machine is in the repository.

**The CU900ENT and CR900ENT bikes show the same four tiles** (`cu900ent-home-screen`), and their
owner's manuals say the console powers up from the cord and enters this screen; whether the
elliptical is mains powered the same way is not stated in this book - its Driver Board function
page marks a DC 24V input, which is a specs matter.
