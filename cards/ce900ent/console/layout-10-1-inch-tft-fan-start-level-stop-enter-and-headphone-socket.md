**The only call-out on the Display Windows page is 10.1" TFT Display.** The photograph under it
shows a speaker grille across the top of the housing, a phone or tablet ledge above the screen, a
SPIRIT badge, and one row of physical keys below the screen, left to right:

| Key | Marking |
|---|---|
| 1 | **FAN** |
| 2 | **START** |
| 3 | **LEVEL -** |
| 4 | **LEVEL +** |
| 5 | **STOP** |
| 6 | **ENTER** |

A **headphone socket** sits at the right-hand end of that row. The book's General Information line
says the console "Contains Key controls and TFT Display".

**The facing page, headed "Function Locations", is not a console drawing.** It is a photograph of
the back of the console I/O board - an RJ45 socket, an HDMI socket and the wiring connectors - with
no readable call-outs; the I/O Board Bottom page that follows names them (Internet, Console Power,
HDMI, System Cable 8 pins, hand pulse wires, C-safe, TV) and belongs with the specs cards.

**No owner's manual for this machine is in the repository**, so nothing here is corroborated by
one, and no fan speed, reading rack or accessory tray is named anywhere in this book.

**This is the same console the CU900ENT and CR900ENT bikes carry** - the same 10.1" call-out, the
same six keys and the same socket (`cu900ent-console-layout`). The CE800ENT elliptical's console is
described differently, with a keypad drawing and a USB port (`ce800ent-console-layout`).
