**This is E1, not E2 (cable tensioner communication).**

Definition: when the screen displays **"E1" "RAM ERROR"** it means the system console EEPROM has failed. **All functions are disabled.**

Troubleshooting: **replace the console (Electronic Desk).** The manual gives no other step for E1.

**The code list and the message disagree in wording.** The error code list calls E1 "Console (Electronic Desk) EEPROM failure", while the on-screen message reads RAM ERROR. Both refer to the same fault on this machine.
