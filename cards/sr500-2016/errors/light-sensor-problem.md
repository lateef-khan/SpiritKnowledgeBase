Checks, in the manual's order:

1. Check that the **receiving board is in the correct position**.
2. Check whether the **light-emitting point and the receiving point are obstructed by dust**.
3. Check the cable connection.
4. Replace the **light sensor module**.

The manual lists this as a fault heading only. It does not say which reading on the console goes wrong when the light sensor fails.
