Any valid key press generates a beep. **In power off mode, pressing any key turns the console on.** The owner books add the wake/sleep detail: the LCD wakes on any button, rowing (speed sensed) starts Manual mode, and **one minute of inactivity** sends the console to sleep.

**MODE key.** Under idle mode each press switches the workout mode along the sequence. To choose a mode, wait until the matrix window shows the pattern you want and the parameter value to be set blinks once per second. The owner books give the sequence: **MANUAL, DISTANCE, TIME, CALORIES, 20/10 INTERVAL, 10/20 INTERVAL, CUSTOM INTERVAL, FAT BURN, CARDIO, STRENGTH, GAME**, with Manual the default after turning on.

**UP key.** Under the setting mode of the target workout the parameter counts up; one increment per press.

**DOWN key.** The same, counting down; one increment per press.

**Start/Stop key.** Under idle mode it enters Manual workout mode. During setting it confirms the value the window is showing and starts the mode. Pressed again it ends the current workout mode and all message windows stop counting.

**Reset key.** Pressed under stopping mode the image switches to idle mode. **It is valid only in stopping mode.** Under any mode, pressing it for **3 seconds** turns the console on again.
