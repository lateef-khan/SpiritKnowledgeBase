Pressing MODE from idle steps through the modes in this fixed order:

    MANUAL -> DISTANCE -> TIME -> CALORIES -> 20/10 INTERVAL -> 10/20 INTERVAL ->
    CUSTOM INTERVAL -> Fat Burn -> Cardio -> Strength -> Game

**The default workout mode after turning the unit on is Manual.**

When the console is turned on the screen shows a full display and the buzzer beeps for two seconds. Press Start to go directly to Manual, or press MODE to select a mode. **The program name scrolls from left to right** to tell the user which one is selected.
