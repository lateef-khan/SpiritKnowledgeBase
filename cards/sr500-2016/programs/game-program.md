Press **Start/Stop** to begin the Game workout mode.

- **Three dots at the left side represent the user position.** The image shifts one profile to the left every second and keeps scrolling.
- The user's position does not shift sideways. **The faster the user strokes, the higher the user's position**; with no stroke the position falls to the lowest. Height is equivalent to stroke speed.
- The game **counts down from 5 minutes** and ends when time is up.
