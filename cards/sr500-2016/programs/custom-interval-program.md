A user-defined interval mode. The default is **10 seconds exercise / 10 seconds rest**.

1. The value at the **left** side of the matrix window flashes to set the **exercise** time. Use UP/DOWN to adjust it - the default is 10 seconds, in **1-second increments**. Press Start/Stop to confirm.
2. The value at the **right** side of the matrix window flashes to set the **rest** time, the same way. Press Start/Stop to confirm and start the mode.
3. During the workout the centre of the LCD shows the current exercise count-down with the wave, or the rest count-down with the rest mark.
4. Pressing UP or DOWN during the workout adjusts the resistance level.
5. There are **10 exercise/rest cycles** for each workout time.
6. When the workout completes the buzzer sounds one long beep. **If paddling continues the count-down repeats.**
