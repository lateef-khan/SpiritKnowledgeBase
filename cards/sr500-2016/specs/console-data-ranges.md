| Window | What it shows | Range |
|---|---|---|
| stroke/min (s/m) | The equivalent strokes per minute. | - |
| Time | Counts up, or counts down and shows time remaining when a target is set. Accumulates for each workout mode. | **00:00~99:59** (minute:second) |
| Distance | Accumulates for each workout mode; counts down and shows remaining distance when a target is set. Over 9999 it switches to the format **1X.XX**. | **0~9999** |
| Heart Rate | When a signal is detected the small dot at the lower right corner of the window blinks with the value. **With no signal the window shows nothing.** | **40~220 bpm** |
| Calories | The calories dissipated. | **0~999** |
| Watts | The watt value **for each stroke**. Over 999 the display uses a point for the thousands digit: 1000 shows 1.00, 1009 shows 1.01, 1240 shows 1.20, 1250 shows 1.25, 2000 shows 2.00. | **0~2000** |
| LEVEL | The current resistance level. Levels 1 and 2 light the first dot, 3 and 4 the second dot, and so on. | **1~16** |
