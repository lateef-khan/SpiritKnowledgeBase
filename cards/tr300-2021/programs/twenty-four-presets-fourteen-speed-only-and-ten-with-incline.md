**The console provides 24 programs, P1 to P24.** Fourteen of them (**P1 to P14**) have only a
preset **speed** profile; the last ten (**P15 to P24**) have **speed and incline** both
programmed. The book warns that the last ten "are designed for the advanced users so that
**children under age of 16 are not recommended**."

**To select and start a preset program:**

1. Make sure the machine is in the stop position; a single press of **Stop** enters the
   resetting state. Press **Program** to choose the desired program (P1 ... P24), then press
   and release **Start** to begin the program with default values.
2. Each program continues **30 minutes** (the preset value). After every one minute during the
   program, the program and speed can be altered manually or automatically. **3 seconds before
   the end of the program a buzzer sounds three times, then the running belt comes to a stop.**

**The profile pictures print no figures.** Page 16 (printed 14) shows 24 small pictures with a
key of *Speed* and *Incline*; no speed, incline or segment value is printed, so the profiles
cannot be tabulated from this book. The TRX2500 book prints the same 24-program layout
(fourteen speed-only, ten with incline) **with** a minute-by-minute detail chart; that chart is
evidence for the TRX2500 only.

The Heart Rate Control (HRC) program is described separately.
