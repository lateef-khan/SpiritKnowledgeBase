To start calibration, **hold the Enter button while installing the safety key**. The assembly chapter's final step tells you to run this procedure once the treadmill is put together.

1. The message window asks for the wheel size. Adjust to **60** and press Enter.
2. The message window shows the setting for **English (miles) or Metric (kilometers)**. Use the ▲/▼ keys to select and press Enter.
3. The display shows the lowest speed setting — for miles it should be **0.5**. Adjust with ▲/▼ and press Enter.
4. The display shows the top speed setting — for miles it should be **10.0**. Adjust with ▲/▼ and press Enter.
5. The display asks for the top incline setting. Set to **10** and press Enter.
6. Press **Start** to begin calibration. Be careful: this is an automatic process, the belt will move and change speeds without warning. When calibration is done the console returns to the start-up screen.

This book prints a second, different way in: Start, Stop and Enter held while the key goes in, for the Functions menu that resets the Lube message ([lube reset card](../../shared/console/xterra-tr-console-reset-lube-from-the-engineering-mode-functions-menu.md)). The TR6.6 and TR6.4 use wheel size 63 and a 12.0 mph maximum ([their card](../../shared/console/xterra-tr-console-engineering-mode-start-and-speed-up-wheel-63.md)).
