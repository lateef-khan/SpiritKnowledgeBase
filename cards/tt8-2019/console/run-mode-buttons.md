**DC model: TT8 2019 ST928-YT035, DC drive motor. The AC inverter TT8 2019 (ST928A-YT037) is a different machine and this card does not apply to it.**

- **SAFETY KEY**: pulling it away shuts the computer down automatically.
- **STOP**: stops the treadmill.
- **START** and **ENTER**: non-functional.
- **FAST / SLOW**: each press changes speed by **0.1 kph (0.1 mph)**. Held down, the speed runs quickly to
  MAX or MIN SPEED.
- **UP / DOWN**: each press changes incline by 1. The manual states the maximum incline position is 15 and
  the minimum is 0 here, even though the GRADE range elsewhere in the same manual is -6 to 15.
- **BLE**: non-functional.
- **SPEED RAPID**: sets speed to 2, 3, 4, 5, 7, 9, 12 directly. On the 22.0 kph spec the presets are **3, 6, 9, 12, 15, 18, 22**.
- **GRADE RAPID**: sets incline to -4, -2, 2, 4, 6, 9, 12 directly.
- **FAN**: turns the cooling fan on and off.
- **DISPLAY**: switches the exercise data shown in the message window — LAP XXX, VERTICAL XXXX M (metres),
  SEGMENT TIME X:XX (not shown in HRC mode), MAX SPEED XX.X.
