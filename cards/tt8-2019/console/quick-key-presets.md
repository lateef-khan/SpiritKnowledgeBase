**DC model: TT8 2019 ST928-YT035, DC drive motor. The AC inverter TT8 2019 (ST928A-YT037) is a different machine and this card does not apply to it.**

**Speed quick keys: 2, 3, 4, 5, 7, 9, 12** On the 22.0 kph spec the presets are **3, 6, 9, 12, 15, 18, 22**.

**Grade (incline) quick keys: -4, -2, 2, 4, 6, 9, 12**

The keys behave the same in ready mode and in run mode: the machine goes to that value directly.

Beware the neighbouring TT8 variants — the speed preset row is one of the places where the AC and DC builds
and the model years differ, so read the value off the machine in front of you rather than from memory.
