**DC model: TT8 2019 ST928-YT035, DC drive motor. The AC inverter TT8 2019 (ST928A-YT037) is a different machine and this card does not apply to it.**

**SPEED** — display range 0.0 to 99.9. **WORK range is 0.5 ~ 12.0 mph (1.0~18.0 kmph)**, adjusted in 0.1 km/h (mph) steps. The manual adds: "Note: Specific spec has 22.0kph of maximum speed."

**GRADE (incline and decline)** — the window shows the incline position from 0 to 15. Display range 0 to
99. **Work range -6 to 15**, and the incline preset value is -6 to 15. Each UP/DOWN press changes it by 1.

**TIME** — count up by default; setting a time makes it count down. Display range 0:00 to 99:99, work range
0:00 to 99:59, count-down setup range 10:00 to 99:00. Pressing STOP in RUN Mode saves the time value, and
re-entering RUN Mode continues counting up.

**LAPS** — display and work range 0 to 99.

**DISTANCE** — display and work range 0.00 to 99.9, in kilometres or miles.

**CALORIES** — display and work range 0.0 to 999.

**PULSE** — display range 0 to 999, work range **50 to 200 BPM**. In RUN Mode, with no signal for **8
seconds** the value drops to 0.

The manual contradicts itself on the incline floor: the GRADE function says the work range is **-6 to 15**, but the RUN MODE description of the DOWN button says "the minimum incline position is 0". Both sentences are in this manual.
