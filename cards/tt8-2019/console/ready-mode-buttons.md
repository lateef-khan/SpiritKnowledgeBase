**DC model: TT8 2019 ST928-YT035, DC drive motor. The AC inverter TT8 2019 (ST928A-YT037) is a different machine and this card does not apply to it.**

- **SAFETY KEY**: fit it in the right position to power on the computer. Pulling it away shuts the computer
  down automatically.
- **STOP**: no function.
- **START**: starts the treadmill. There is a **3 second countdown** on the window display, then the machine
  starts running — at MIN SPEED in MANUAL, or at the program preset value in a PROGRAM.
- **ENTER**: changes each function. MANUAL sets time. A pre-set PROGRAM sets time and speed. Heart Rate
  Control 1~2 sets time, age and the heart rate value. User Program 1~2 sets time, speed and incline.
- **FAST / SLOW / UP / DOWN**: non-functional unless you have entered a setting.
- **BLE**: with a BLE wireless chest strap, press once in ready mode to turn it on and a second time to turn it off. BLE can only be switched in ready mode.
- **SPEED RAPID**: preset buttons for rapid speed — 2, 3, 4, 5, 7, 9, 12. On the 22.0 kph spec the presets are **3, 6, 9, 12, 15, 18, 22**.
- **GRADE RAPID**: preset buttons for rapid incline — -4, -2, 2, 4, 6, 9, 12.
- **FAN**: turns the cooling fan on and off.
- **DISPLAY**: after choosing a program, shows the speed or incline profile in dot-matrix.

The manual calls both rapid rows "5 preset buttons" and then lists seven values in each. The seven values
are what the machine actually offers.
