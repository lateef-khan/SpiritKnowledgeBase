**DC model: TT8 2019 ST928-YT035, DC drive motor. The AC inverter TT8 2019 (ST928A-YT037) is a different machine and this card does not apply to it.**

**This is E5, not E6 (lower controller component) and not E3 (incline VR).**

Definition: communication between the console and the lower controller is
poor. It is usually a bad main control wire, but the display board or the controller itself can also be at
fault.

Cause: the main control wire is possibly broken. E5 can also come from a component of the lower controller
or of the console board.

| Part | Troubleshooting |
|---|---|
| Lower controller board | Replace the main control wire. |
| Main control wires | Reinsert the main control wire. Replace the main control wire. |
| Display board | Replace the upper control board. |
