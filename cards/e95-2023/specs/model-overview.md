The cover reads **E95(2023)**, **SE698-SE040**, "ENT Elliptical Trainer". That factory code is the manual's own name for the machine. **ENT** is how the cover marks the entertainment console model.

This is the Sole E95 of model year 2023. The Spirit database SKU is **595022**.

What the manual says the machine is made of:

- **Console** - the interface that controls all functions. It holds key controls and a **TFT LCD touch panel**.
- **Controller** - the circuit board holding the DC power supply for the console, the incline driver and the tension motor driver.
- **Gear motor** - increases and decreases the resistance level of the brake.
- **Incline motor** - an AC motor the user drives from the console to change elevation.

The E98 of the same year uses an **EMS brake** instead of a gear motor, so its resistance figures and its parts do not transfer to this machine.
