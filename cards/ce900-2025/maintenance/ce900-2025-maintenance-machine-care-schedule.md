**UNPLUG ELLIPTICAL BEFORE PERFORMING ANY MAINTENANCE.**

| Item | Daily | Weekly | Monthly | Quarterly | Biannually |
|---|---|---|---|---|---|
| Entire Unit | Clean | | Inspect | | |
| Detailed Cleaning | | Clean | | | |
| Unit Hardware | | Inspect | | | |
| Console Hardware | | | | Inspect | |
| Levelers | Inspect | | | | |
| Pedals | Clean | | Inspect | | |
| Tracks / Wheels | | Clean | Inspect | | |
| Console Overlay | Clean | | | | Inspect |
| USB Port | | Inspect | | | |
| Accessory Cups | Clean | | | | |

Ten items, five intervals, and **no annual column** - the table stops at Biannually.

## The CES880 table is this table minus the tracks and wheels

The CES880 suspension elliptical prints the same nine other rows with the same marks and **no
Tracks / Wheels row at all** (`ces880-2025-maintenance-machine-care-schedule`). It has no tracks.
Do not quote a weekly track clean for a CES880.

Neither elliptical table is the Spirit treadmill table. The CT900 and CTSBS900 print an
eighteen-item table with an Annually column (`ct900-maintenance-schedule`) and the CT900ENT a
seven-task one (`ct900ent-general-maintenance-schedule`). No row of either belongs here.

**The CE900 2021, CE800 (all printings), CE800ENT and CE850 (all printings) manuals print no
schedule table of any kind.** They give the post-workout wipe-down and the noise checks only. There
is no interval to quote for those seven machines.

## Three 2024 New Black Units ellipticals print the same ten rows

The **CE800 2024**, **CE850 2024** and **CE800ENT 2024** print this table with the same ten rows in
the same order and the same marks in the same columns, checked cell by cell from a 300 dpi render,
under the same *UNPLUG ELLIPTICAL BEFORE PERFORMING ANY MAINTENANCE* line.

**The table is a picture in all three 2024 manuals.** `pdftotext` returns the heading and the
unplug line and nothing else, so a text-only reading reports no schedule.

## The weekly track clean has no printed method on the 2024 machines

The **Tracks / Wheels** row tells an owner to clean weekly and inspect monthly, but **none of the
three 2024 elliptical manuals prints a cleaning method for them** - no cloth, no alcohol, no
scraper, and no lubrication rule either way. The method exists only in the CE900 2021 and CE900 2025
books (`spirit-ce900-maintenance-track-and-wheel-cleaning`), and that is a CE900 text. Say the
interval and say the method is not printed, rather than importing the CE900 paragraph.

**The CE900 2021, CE800 (2013/2021/2023), CE800ENT and CE850 (2016/2020/2022) manuals still print no
schedule table of any kind.**
