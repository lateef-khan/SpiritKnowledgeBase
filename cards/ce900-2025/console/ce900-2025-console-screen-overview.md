The overview drawing names six things and nothing else:

- **Integrated adjustable fan** for workout comfort
- **Premium ultra-bright white LED display**
- **LED heart rate graph**
- **Easy to read lap counter**
- **Large LED matrix window** to track workout progress
- **Tablet friendly reading rack holder**

**No key is named on this drawing.** The Start, Stop, Enter, Scan, program and number keys are
described only in the manual's text, never labelled on the picture.

**The 2021 CE900 drawing names the same things but calls the display BLUE.** That page had no text
layer in the PDF and has since been recovered by OCR: it prints *Premium, ultra-bright **blue** LED
display*, and it carries **no Tablet friendly reading rack call-out**. See
`ce900-2021-console-screen-overview`. **White is the 2025 word; blue is the 2021 word.** Do not
quote either colour for the other year.

The machine-overview drawing on p. 7 of this manual is a separate picture and names the console, the
console fan, the tablet rack, the pulse sensors and a **water bottle holder** among the parts of the
elliptical.
