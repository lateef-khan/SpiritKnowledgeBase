The console has built-in maintenance/diagnostic software - it can switch the display between English
and Metric, and turn off the key beep, among other things.

**Pedal the elliptical, then press and hold Start, Stop and Enter for about 5 seconds.** The Message
Center displays **Maintenance Mode**. Press **Enter** to open the menu.

**This menu is flat - nine entries, no Function or Service sub-menus:**

1. **Key Test** - test all the keys to make sure they are functioning
2. **Display Test** - tests all the display functions
3. **Sleep Mode** - turn on to have the console power down automatically after **20 minutes of
   inactivity**
4. **Odometer Reset**
5. **Units** - English or Metric
6. **Speaker** - turns off the speaker so no beeping sound is heard
7. **Brake Test** - tests the brake resistance
8. **Sensor Test** - tests the speed sensor function
9. **Unit Type** - sets machine type; **Bike or Elliptical**

**There is no Pause mode entry and no Csafe test in this menu**, both of which the CE800 and CE850
menus carry.

**The 2021 CE900 owner's manual has no engineering mode section at all.** Nothing in that document
describes how to reach maintenance mode or what it contains, so nothing on this card may be quoted
for that machine.

**Twenty minutes, and only here.** The CE850-2016 prints 30 minutes for the same setting and the
CE800-2013 prints 20; see `ce850-2016-console-engineering-mode-security-lock` and
`ce800-2013-console-engineering-mode-elliptical-or-bike`.

**The 2025 CR900 and CU900 bike owner's manuals print this menu word for word** - CR900 p. 30,
CU900 p. 29 - so this card covers bikes as well as the CE900-2025 elliptical and its product line is
no longer elliptical-only. Same nine flat entries in the same order, same **20 minutes**, same
**Brake Test**, same **Unit Type** for Bike or Elliptical, and the same instruction to **pedal the
machine** and hold Start, Stop and Enter for about 5 seconds until the Message Center reads
**Maintenance Mode**. Both bike manuals head the page **ENGINEERING MODE MENU** while the screen says
Maintenance Mode, exactly as the elliptical's does.

**On a bike the Unit Type setting is the one that must be right.** The manual does not say what goes
wrong if it is set to Elliptical.

**The 2018 CR900 and CU900 owner's manuals print the same nine items too** - CR900-2018 p. 29,
CU900-2018 p. 28 - so this card covers those two machines as well. **Their page is headed MAINTENANCE
MODE MENU, not ENGINEERING MODE MENU**, which is why a search for the word "engineering" finds
nothing in either document; the word appears nowhere in them. Same nine entries in the same order,
same 20 minutes, same pedal-and-hold entry, same Maintenance Mode on the Message Center.

**The CR900-2018 calls the first entry Button Test, not Key Test.** Its whole manual writes "button"
where the CU900-2018 writes "key" - *"Button Test (Will allow you to test all the buttons to make sure
they are functioning)"*. Same test, same position; only the word differs, and the other eight entries
are word for word.

**The 2021 and 2023 CR800 and CU800 bikes have the older two-level menu** with Function and Service
sub-menus, a Csafe test and a Pause mode:
`spirit-ce800-console-maintenance-menu-function-and-service`.

**All four bike manuals print it under a different heading than the elliptical does.** The 2018
manuals head the page **MAINTENANCE MODE MENU**; the 2025 manuals and the CE900-2025 head it
**ENGINEERING MODE MENU**. All six say the screen itself reads **Maintenance Mode**.
