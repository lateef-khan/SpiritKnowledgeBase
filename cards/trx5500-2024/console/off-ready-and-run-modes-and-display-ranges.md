From the Dyaco GT90D-NT041 service manual, chapter 4 (a 10-inch touch screen).

**Modes.** OFF: with the treadmill on but no safety key, the console shows "PLEASE REPLACE THE SAFET KEY" [sic] and does not work. READY: with the key in, the message window shows "press start workout". RUN: pressing STOP or removing the key stops the treadmill instantly and enters OFF mode.

| Function | Range |
|---|---|
| SPEED | work range **0.6 – 12.0 mph** (1.0 – 18.0 km/h); FAST/SLOW change it by 0.1 |
| INCLINE | 0 – 15, preset 0 – 15; UP/DOWN move it by 1 |
| TIME | work 0:00 – 99:59; count-up setup 10:00 – 99:00; STOP saves the value and re-entering RUN continues counting |
| DISTANCE | 0.00 – 99.99 km or miles |
| CALORIES | 0.0 – 999 |
| PULSE | 40 – 220, hand pulse or receiver (chest belt); in RUN mode 8 seconds without a signal shows 0 |
| PACE | 00.00 – 99.99 min/km or min/mi |

The 0.6 mph minimum here disagrees with the owner's manual's 0.5 mph quick start and the 0.5 mph MIN SPEED on the engineering Device Info page ([engineering card](engineering-mode-behind-the-software-version-and-password-20160620.md)).

**Keys.** START/STOP: the first press in standby gives a 3-second countdown, then the Manual program runs (a preset program starts at its default speed); the second press pauses; the third starts again; and so on. PROGRAM: in standby, enters the presets — P1-P30, HEART RATE and Custom mode. FAST/SLOW: 0.1 per press, running to MAX or MIN when held. UP/DOWN: one incline position per press, 0 to 15. FAN: ON/OFF. In RUN mode PROGRAM is non-functional. The owner's manual's touchscreen description is on [the quick-start card](quick-start-and-physical-buttons.md).
