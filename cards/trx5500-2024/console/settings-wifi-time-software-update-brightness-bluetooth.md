- **WIFI** — internet connection settings.
- **DATE** or **TIME** — the machine time settings, which define the time information in the workout summary. Both 12- and 24-hour formats are available.
- **SOFTWARE** — check the current software version or update if a new one is available: press Update to upload and install the latest version. Be connected to the Internet.
- **DISPLAY** — adjust the brightness of the screen.
- **BLUETOOTH** — pair Bluetooth devices, including Bluetooth chest straps, earphones or speakers.

The service manual's calibration route runs through this same Settings page and the Software entry ([engineering card](engineering-mode-behind-the-software-version-and-password-20160620.md)).
