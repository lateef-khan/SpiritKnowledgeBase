**CUSTOM** lets you create a speed and incline changing profile **by sliding up and down on
the profile columns**. The on-screen description: "You will create the desired speed and
incline levels for each of the **20 segments** of the program using the pop out keyboard on
this screen ... After the program has started, you still have the ability of changing these
levels whenever you desire."

Once the profile is defined, choose the **target time** and **maximum speed** so the intensity
adapts accordingly.

**Templates.** Every program can be saved as a template once adjusted or once completed: press
**Save as** to save it with the current settings (also offered on the workout summary screen).
Saved programs are managed under **TEMPLATES**; to delete one, tap it, then press **Delete**
in the top right corner. **A maximum of 12 template programs can be stored**, and a template
is only available to the user who created it.
