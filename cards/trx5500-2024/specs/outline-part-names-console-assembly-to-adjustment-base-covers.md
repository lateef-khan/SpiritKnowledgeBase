The TRX5500 book's *Outlines* chapter is two photographs with lettered-box callouts and no numbers.

**Page 4 (the whole machine)**, in the order the boxes run down the page:

| Callout | Where it points |
|---|---|
| Console Assembly | the console head |
| Speed Rapid Key with Hand pulse Sensor | the right handlebar grip |
| Incline Rapid Key with Hand pulse Sensor | the left handlebar grip |
| Upright(R) | the right upright |
| Upright(L) | the left upright |
| Drive Motor Cover | the motor hood |
| Foot Rail | the left foot rail |
| Running Belt | the belt |
| Adjustment Base Cover(R) | the right rear end cap |
| Adjustment Base Cover(L) | the left rear end cap |

**Page 5 (under the hood)**: **Drive Motor**, **Incline Motor** and **Controller**.

So the speed keys are on the right grip and the incline keys on the left, each grip also carrying a hand-pulse sensor.
No dimension is printed on either page and the book has no specification table.
