The photograph shows the board mounted in the back of the console housing, with a large heat-sinked processor at its
centre. Fifteen callouts:

| Callout | Where |
|---|---|
| USB wires socket | top, left of centre |
| Wireless Pulse Socket | top left |
| Safety key wires socket | left, upper |
| Main Control wires Socket | left, middle - the 5-pin cable |
| Fan power wires socket | left, lower |
| Bluetooth & Wifi board | small green daughter board at the bottom left, on its own cable |
| MP3 Audio input wires socket | bottom left |
| Display IC | top right, on the green daughter board |
| Hand Pulse Socket | right, upper |
| Main IC | centre right |
| Key board wires Socket | bottom centre |
| Speed Handrail keys | blue socket, bottom right |
| Incline Handrail keys | blue socket, bottom right, beside it |
| Speaker | white socket, bottom right corner |

No silkscreen model or sticker text is legible in the photograph. The 6-1-1 and 6-1-2 pages are the same board top
and bottom without captions. The block diagram for this machine draws no USB or Bluetooth box even though the board
has both.
