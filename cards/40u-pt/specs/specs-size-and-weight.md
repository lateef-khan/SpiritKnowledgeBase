**Size: 108 x 55 x 136 cm. Weight: 60.5 kg.** One line under the last assembly step, with no
specification page, no inch equivalent and no labels beyond the order; read it as length x width x
height. **The height is 136 cm** - the page was rendered to settle it, because the OCR of the page
reads 146.

**This is the only dimension or weight any 4.0U book prints.** The 2025 Spirit owner's manual for the
same upright has no specification at all
(`spirit-med-bike-specs-which-owners-manuals-print-a-specification-page`). The recumbent 4.0 R's
line is 144 x 74 x 120 cm and 80 kg (`40r-pt-specs-size-and-weight`), and the later 7.0U upright's
page gives 110 x 57 x 138 cm and 53.3 kg (`70u-2025-specs-dimensions-and-weight`) - a near twin in
footprint. No shipping weight or carton size is printed.
