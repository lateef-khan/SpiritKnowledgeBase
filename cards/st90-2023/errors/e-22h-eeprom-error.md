**This is E-22H on the AC inverter, and it is not any other code that starts with the same characters.** This is memory inside the inverter, not the console. E-21H is the other memory code and is about the flash program area.

| Field | Value |
|---|---|
| Code | E-22H |
| Description | EEPROM error |

The manual's cause column, word for word:

> Malfunction Contact your SOLE dealer.

The whole printed table is on the card `st90-2023-inverter-error-code-list`. This machine runs an AC inverter, so it does not use the E1 to E8 code set of the DC digital controller fitted to the F63, F65, F80, F85, F89 and TT8.
