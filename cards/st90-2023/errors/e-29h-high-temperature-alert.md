**This is E-29H on the AC inverter, and it is not any other code that starts with the same characters.** This is an *alert*, not the overheat trip. `dusk` is a typo for dust in the printed manual; the instruction is to clean dust off the cooling fan.

| Field | Value |
|---|---|
| Code | E-29H |
| Description | High temperature alert |

The manual's cause column, word for word:

> Abnormal temperature, please clean dusk on cooling fan.

The whole printed table is on the card `st90-2023-inverter-error-code-list`. This machine runs an AC inverter, so it does not use the E1 to E8 code set of the DC digital controller fitted to the F63, F65, F80, F85, F89 and TT8.
