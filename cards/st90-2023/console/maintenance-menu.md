**Maintenance** is listed as one of the six functions on the engineering page, between Machine Information and Lube Setup.

**The manual does not describe what is on it.** Section 8.2 names it in the function list and then never returns to it; the numbered walk-through covers only Calibration, Machine Information, Lube Setup and Key Test.

The earlier ST90 manual documents its Maintenance page as holding the default language setup and a USB app update. On this console the language moved out to the settings page, so what remains here is not stated.
