**Software** in the settings page shows the treadmill's preset software version.

When the console has an update waiting, the **idle mode page** shows `NEW SOFTWARE VERSION AVAILABLE!` above the Settings button.

**Media APPs** is a separate entry. If the console has found third party apps that need updating, the update button lights up there.
