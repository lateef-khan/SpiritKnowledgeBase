Open the **Unit** function in the settings page and touch the icon to swap between **METRIC** and **IMPERIAL**. The default is IMPERIAL.

| Value | Unit |
|---|---|
| Distance | mi / Km |
| Speed | mph / Km/h |
| Height | ft, in / cm |
| Weight | lb / Kg |

The calibration has its own maximum and minimum speed values, and they are entered separately in each unit system.
