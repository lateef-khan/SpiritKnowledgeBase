**GR Mode** (Grade Return) is a setting in the engineering menu's Machine Information page, default **ON**. It is not a fault.

**GR Mode ON** - the incline should be at zero when:

- the treadmill is powered on
- the user pauses during a workout
- the display is on the SUMMARY page
- the display is on the HOME page
- the safety key is plugged back in

Unplugging the safety key does **not** return the incline to zero; plugging it back in does.

**GR Mode OFF** - the incline stays where it is in all of those cases, including when the safety key is unplugged and plugged back.

**One line of this page contradicts the rest of it.** With GR Mode off, the manual says "Press START to begin; the incline should be at zero or at the current set level" - it gives both answers for the same case.
