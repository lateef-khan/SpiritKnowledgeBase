Touch the settings icon while the console is in **idle mode**. The settings page holds:

1. Units System
2. Wi-Fi
3. Date & Time
4. Software
5. Media APPs
6. Screen Brightness
7. Language
8. Child Lock
9. Sleep Mode

**This is a different list from the earlier ST90 console**, which had 11 entries including Bluetooth, Wired network and Display mode, and put language under the engineering menu instead.

Touching the word **Settings** ten times on this page opens engineering mode.
