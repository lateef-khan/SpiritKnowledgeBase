| Setting | Default | Options |
|---|---|---|
| GR Mode (Grade Return) | ON | ON / OFF |
| Beep Mode (Buzzer Switch) | ON | ON / OFF |
| Display Mode | ON | ON / OFF |
| Child Lock | OFF | ON / OFF |

**Beep Mode** is about the touch panel specifically. On, the buzzer sounds when a finger hits the panel; it does not cover the physical console keys.

**Display Mode** on means the console does not power down when the safety key is removed. Off means it does, and the display turns off to power the console down after **30 minutes** of inactivity. Any key wakes it.

**GR Mode**: if the incline does not return to zero with GR Mode off, switch it to ON, go back to Settings, and the incline should return to zero.
