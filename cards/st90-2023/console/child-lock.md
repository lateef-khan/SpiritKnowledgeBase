The default is **off**.

**Turning it on**: set Child Lock on in the settings page, or in the engineering menu's Machine Information page. **Repower the machine or re-plug the safety key** to make it take effect.

**What you see**: the idle page shows `CONSOLE LOCKED`, and beneath it `Press Start and Display to enable operation`.

**Unlocking**: press the **START** and **STOP** keys together for 3 seconds.

The two pages of this manual describe the unlock differently. Section 8.1.8 says press and hold Start and Stop **at the same time for 3 sec**; the Machine Information page says press START and STOP **within 3 seconds**. Both name the same two keys.
