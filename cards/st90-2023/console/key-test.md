1. From the engineering page, hit **Key Test**.
2. The display names a key. Press that key.
3. Repeat until every key has been pressed.
4. When all the keys have been pressed, the display shows `All Done!` within 5 seconds.

Use this before replacing a handrail rapid key: it tells you whether the console is seeing the button at all.
