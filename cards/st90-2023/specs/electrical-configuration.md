| Part | What the manual says it does |
|---|---|
| Safety key | Fits on the console and activates all functions. Without it the console cannot be controlled, and the display shows **"Please Replace the Safety Key"**. |
| Console | Interface that controls all functions. Comprised of key controls and a **TFT touch panel** display. |
| Main controller (inverter) | Carries the AC power supply for the console, the incline driver and the AC motor driver. Includes the power supply, AC motor, incline motor, AC control board control circuit and incline control circuit. |
| Drive motor | A variable speed AC motor. It can increase or decrease speed. |
| Incline motor | An AC motor, controlled from the console through the main controller. |

**One line here describes a machine that is not this one.** The main controller entry ends "...link the console to output appropriate voltages for DC control Board that controls the Treadmill functions". This machine has an AC inverter and no DC control board. The same line appears in the earlier ST90 manual.
