| Field | Value |
|---|---|
| Type | AC motor |
| Voltage | **110 volt** on a 120 Vac machine, **220 volt** on a 230 Vac machine |
| Power wires | Four: red, black, white, green |
| Sensor | One 3-pin position sensor cable |

| Wire | Function |
|---|---|
| Red | UP. AC voltage here raises the incline. |
| Black | DOWN. AC voltage here lowers the incline. |
| White | COM, neutral. |
| Green | Ground. |

The 3-pin cable is the incline **VR**, the position sensor named by E-3H and E-52H. The earlier ST90 manual gives the incline motor as 110 volt with no 230 Vac variant.
