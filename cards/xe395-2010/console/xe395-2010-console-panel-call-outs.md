The drawing names eight areas:

| Call-out | What the manual says is in it |
|---|---|
| **MUSCLE PROFILE** | - |
| **SPEAKER** | - |
| **DATA DISPLAY** | **RPM, Calories, Time, Distance and Pulse** |
| **HEART RATE PROFILE** | The colour bar graph, **to the left of the LCD** |
| **DOT MATRIX** | **Resistance Level, Program Profiles, Incline Level and Lap Track** |
| **MESSAGE CENTER** | **Program Name, Speed, Watts, Laps, Segment Time and Altitude** |
| **COOLING FAN** | - |
| **PROGRAM BUTTONS** | **Manual, Hill, Fat Burn, Strength, Interval, 2 User, 2 HR** |
| **CONTROL KEYS** | - |

**The program-button call-out is incomplete.** As printed it reads *Manual, Hill, Fat Burn,
Strength, Interval, 2 User, 2HR* - nine keys - and leaves **Cardio** out, though the machine has ten
programs. **Ten is the count to quote**; see
`xe395-2010-programs-console-diagram-omits-cardio-from-the-program-buttons`.

**Incline Level and Lap Track sit inside the dot matrix**, not in separate windows. **Altitude** in
the Message Center is elevation gain based on the incline through the program:
`xe395-2010-console-message-center-scan-shows-altitude`.

**The drawing does not label the individual control keys.** The operating text names **Start**,
**Stop**, **Enter**, **Level Up** and **Level Down**, and a **fan button on the left side of the
console**. **Do not describe a key this manual does not name.**

**The six programs match the 2005 and 2007 machines** - Manual, Hill, Fat Burn, Cardio, Strength and
Interval - with two User keys and two Heart Rate keys alongside them.
