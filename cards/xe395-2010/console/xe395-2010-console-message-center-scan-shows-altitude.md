**The Message Center starts by displaying the Program name.** In scan mode during a program:

1. **Speed**, for four seconds
2. **Watts** - an indication of workload. *If 100 watts is displayed, you are doing enough work to
   keep a 100-watt light bulb lit.*
3. **Segment Time**
4. **Laps completed**
5. **Altitude** - **elevation gain from start to finish, based on the Incline level throughout the
   program**

**Pressing the Enter button again brings you back to the beginning.**

**Altitude and the incline readout are what set this console apart.** The console call-outs name the
Message Center's contents as *Program Name, Speed, Watts, Laps, Segment Time, and Altitude*, and the
dot matrix as *Resistance Level, Program Profiles, Incline Level, and Lap Track*.

**The 2021 and 2023 machines scan a different list** - Laps completed, Segment time and **Max level**,
with no Altitude - because none of them has this machine's ramp:
`spirit-xe-console-message-center-scan-shows-laps-segment-time-and-max-level`.
