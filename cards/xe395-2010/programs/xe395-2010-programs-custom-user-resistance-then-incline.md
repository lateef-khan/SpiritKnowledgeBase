There are **two** customisable User programs, **User 1 and User 2**, which operate identically. You
can build one from scratch or **save any preset program you complete as a custom program**, and you
can personalise either by adding your name.

1. Press the **User 1** or **User 2** key. The Message Center shows a welcome message carrying the
   name of any saved program. Press **Enter** to begin.
2. The Message Center shows `Name - A` if nothing is saved, or the saved name with its first letter
   blinking. Up/Down change the letter, **Enter** saves it and moves on, **Stop** saves the whole
   name and continues.
3. Enter your **Age**.
4. Enter your **Weight**.
5. Set the **Time**.
6. You are now asked to set the **Resistance Level for each segment of the profile**.
7. The first column blinks (`SEGMENT > 1`). Set its resistance with the **Level Up** key, then Enter.
8. The next segment starts at the previous segment's level. Repeat until **all twenty segments** have
   been set.
9. **The first column blinks once more, this time to build the Incline profile.** Follow the same
   procedure as steps 7 and 8.
10. Press **Enter** to save. The Message Center says "New program saved" and offers to Start or
    modify the program. **Stop** exits to the start-up screen.

**There is no Max Level step here.** Unlike the XE100/XE200/XE300 and XE350/XE550 User programs, this
one goes straight from Time to the per-segment levels.

**No other Spirit elliptical builds two profiles.** The XE295, XG400 and XE795 2021 build twenty
resistance segments only; the XE195 has no custom program at all.
