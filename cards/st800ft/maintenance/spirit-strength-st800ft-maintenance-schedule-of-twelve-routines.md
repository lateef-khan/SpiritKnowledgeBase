**The ST800FT has the fullest maintenance schedule of the thirty-nine Spirit strength machines, and
the only one that tells you when to throw a cable away.**

| ROUTINE | COMMERCIAL | HOME | LATEST DATE ENTRY |
|---|---|---|---|
| Inspect: Links, Pull Pins, Snap Locks, Swivels, Weight Stack Pins | Daily | Weekly | |
| Clean: Upholstery | Daily | Weekly | |
| **Inspect: Cables or Belts and their tension** | **Daily** | **Weekly** | |
| Inspect: Accessory Bars, and Handles | Weekly | Monthly | |
| Inspect: All Decals | Weekly | 3 Months | |
| Inspect: All Nuts and Bolts, Tighten if needed | Weekly | 3 Months | |
| Inspect: Anti-Skid Surface | Weekly | 3 Months | |
| Clean & Lubricate: Guide Rods with a Teflon (PTFE) based lubricant | Monthly | 3 Months | |
| Lubricate: Seat Sleeves, Turcite Bushings, Linear Bearing | Monthly | 3 Months | |
| Clean and Wax: All Glossy Finishes | 6 Months | Yearly | |
| Repack with Grease: Linear Bearings | 6 Months | Yearly | |
| **Replace: Cables, Belts and Connecting Parts** | **Yearly** | **3 Years** | |

The page's own lead-in:

> For best performance, Spirit recommends the following maintenance schedule. Check the integrity
> and function of the following parts. Replace all worn components immediately. **Your equipment
> comes with a commercial schedule decal. For in home use, please follow the maintenance schedule
> listed below.**

## Read that last sentence before quoting an interval

**The decal on the machine is the commercial schedule.** A home owner reading the decal is reading
the wrong column, and the manual says so. Ask which setting the machine is in before quoting a
figure.

## The two rows that make this machine different from the whole range

- **Replace: Cables, Belts and Connecting Parts — Yearly / 3 Years.** No other Spirit strength
  manual gives a cable a service life. See
  `spirit-strength-st800ft-maintenance-cables-inspected-daily-and-replaced-yearly`.
- **Named lubricants.** Teflon (PTFE) for the guide rods, and a grease repack for the linear
  bearings. See
  `spirit-strength-st800ft-maintenance-teflon-guide-rods-and-a-lithium-bearing-repack`. Every other
  book in the range names no lubricant on its maintenance page.

## The blank column is the repair log

*LATEST DATE ENTRY* is the printed form of the manual's own requirement to *keep a repair log of
all maintenance activities* — `spirit-strength-maintenance-owner-responsibility-and-repair-log`.

## Two further pages behind this table

The book does not stop at the schedule. Printed p. 28 explains what to look for on the links, pull
pins, upholstery, decals, nuts and bolts and anti-skid surfaces
(`spirit-strength-st800ft-maintenance-upholstery-decals-nuts-and-anti-skid-care`), and printed p. 29
explains how to check a cable and how to lubricate each part
(`spirit-strength-st800ft-maintenance-inspect-a-cable-by-eye-and-by-hand`).

**No torque figure appears on any of them** —
`spirit-strength-maintenance-no-torque-figure-for-any-fastener`.

## Do not read this table onto the CSF-FUNT

The **CSF-FUNT** is Spirit's other functional trainer and it is on the CS template: a
daily-to-bi-monthly tick table with twelve rows, no home column, no named lubricant and no
replacement interval — `spirit-strength-csf-funt-maintenance-schedule-without-an-upholstery-row`.
Two functional trainers, two entirely different maintenance regimes.
