**Launched for the first time, the console prompts you to either enter as a guest or create a new profile.**

- **Tap + to create a new profile.**
- **A maximum of 9 profiles can be created.**
- **Each profile can be protected with a passcode.**

The manual recommends setting up your own profile because it lets the machine remember your **physical parameters, favourite programs and templates**, gives you **a custom program with an adjustable intensity pattern**, and lets your **workout records synchronise with the SOLE+ mobile app**.

**In Guest mode you can still set age and weight**, on the Home screen, so the workout summary is calculated more accurately.
