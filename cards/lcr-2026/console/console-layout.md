The console drawing is labelled with five things:

| Label on the drawing |
|---|
| **Cooling fan** |
| **Fan power switch** |
| **Volume control** |
| **USB charger** |
| **Speaker** |

**The drawing itself is lost in this text extraction**, so the position of each label on the panel is not recoverable from this document - only the list of labels.

**The charging port is named two ways.** This drawing calls it **USB CHARGER**; page 11 calls it a **Type-C Power Port**. See `lcr-2026-type-c-charging-port`.

The drawing names no keys, but the rest of the manual refers to a **physical START key**, a **physical STOP key** and **side control panels** for resistance, plus a touchscreen with a bottom navigation bar.
