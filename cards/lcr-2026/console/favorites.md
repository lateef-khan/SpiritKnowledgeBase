**Any class, collection or program can be labelled as a Favorite.**

- **To "like" a program:** open the program setup page and **tap the "ribbon" icon in the upper left corner** of the screen.
- **To remove the label:** un-tap the ribbon icon.
- **Up to 12 favourite programs appear on the Home page** for easier access.
- Manage previously labelled programs on the **Favorites page**, reached from the Home page or the user Profile page.

**Favorites are not the same as Templates.** A favourite is a bookmark; a template stores a program with a set of parameters. Templates have their own limit of 12.
