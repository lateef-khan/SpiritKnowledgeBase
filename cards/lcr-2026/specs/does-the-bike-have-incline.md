**The manual talks about incline in five places and never describes an incline mechanism.** There is no incline key, no incline range, no incline motor and no incline step in the assembly instructions. A sixth passage says the machine controls resistance instead.

Printed as incline:

- page 16 - "Manual program is a timed workout with **resistance and incline** controlled manually at any time during the workout."
- page 16 - "Hill, Fatburn, Cardio, Strength and Interval follow preset **resistance and incline** changing patterns."
- page 17 - "**Heart Rate program uses incline to control your heart rate.** The incline gradually increases until you reach your target heart rate."
- page 17 - "Custom is a program with fully customizable **resistance and incline** patterns... **Incline values are absolute and can be set directly. Incline pattern is optional.**"
- page 20 - "Use side control panels or physical keys to adjust **resistance and incline**."

Printed as resistance:

- page 23 - "**The Heart Rate program automatically controls resistance at the pedals.**"

Pages 17 and 23 contradict each other about the same program. **This card picks no winner, because the manual does not.** Treat every incline reference in this manual as unconfirmed for this machine until someone checks a console.

**The same wording turns up on the previous machine.** The service manual card `lcr-2023-console-modes` records that the LCR 2023 sleep mode section prints "Incline = 1", calls it a carry-over from a treadmill console, and states that **that** bike does not incline. That is a different machine and a different document, so it is evidence about where the wording comes from, **not** an answer for this one.
