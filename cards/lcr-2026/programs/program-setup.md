1. **Select the "Programs" tab of the bottom navigation bar.**
2. **Tap any program card to open its Program Setup page**, where you can learn more about the program and set the properties of your workout.
3. **Adjust workout parameters** in any of three ways: **drag the ruler**, **tap the + and - buttons**, or **tap on the number to open a numpad and type the value directly**.
4. **Press the "Start This Program" button on the screen, or the physical "START" key on the machine**, to begin.

**Total Time and Max Resistance** are the two settings that define the duration and the overall intensity of a preset profile workout.

A program can be marked as a favourite from this same page (the ribbon icon), and saved as a template once it is finished.
