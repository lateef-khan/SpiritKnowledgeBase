**Custom is a program with fully customisable resistance and incline patterns.**

1. **On the program setup page, press "Add Pattern" to enter edit mode.**
2. **Connect dots to map your load throughout the program**, from **easiest at the bottom to hardest at the top**.
3. **Each segment's duration depends on the selected total time**, which you can set right before the start.

How the two axes behave is different:

- **Resistance values are relative.** The maximum can be changed before each workout and **all the segments are adjusted proportionally**.
- **Incline values are absolute and can be set directly. The incline pattern is optional.**

A custom program is one of the reasons the manual gives for creating a personal profile rather than riding as a guest. Once finished, a program can be **saved as a template**.

The incline half of this is printed on a machine whose manual describes no incline mechanism. See `lcr-2026-does-the-bike-have-incline`.
