**"With all SOLE Heart Rate fitness bike machines you may use the heart rate monitor feature without using the Heart Rate program. This function can be used during manual mode or during any of the nine different programs."**

The nine programs the manual names are **Manual, Hill, Fatburn, Cardio, Strength, Interval, HIIT, Heart Rate and Custom**.

The same paragraph is where the manual says **"The Heart Rate program automatically controls resistance at the pedals"**, which page 17 contradicts by saying that program uses incline. That dispute is set out in `lcr-2026-heart-rate-program`.

**Entering your age is what the console uses for the heart rate programs.** If you enter your age during programming, the console calculates your maximum heart rate automatically.
