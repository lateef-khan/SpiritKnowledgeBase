| Mode | What it means |
|---|---|
| OFF Mode | The user has not inserted the safety key on the console. |
| READY Mode | The treadmill is ON and the safety key is inserted. The message window shows the program profile name and cycle. Press START to start the treadmill in Manual Mode. |
| SLEEP Mode | Pressing any button takes the treadmill back to READY Mode. |
| RUN Mode | Pressing STOP, or removing the safety key, stops the treadmill instantly and puts it in OFF Mode. |
