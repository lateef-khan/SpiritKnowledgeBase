In RUN MODE:

- **SAFETY KEY** - pull it away and the computer shuts down automatically.
- **STOP** - stops the treadmill.
- **START** and **ENTER** - non-functional.
- **FAST** / **SLOW** - change speed by 0.1 KPH (0.1 mph) per press. Held down, the speed runs quickly to MAX or MIN SPEED.
- **UP** / **DOWN** - change the incline position by 1 per press. **Maximum incline position 15, minimum 0.**
- **SPEED RAPID** - 7 buttons: 2, 3, 4, 5, 7, 9, 12.
- **INCLINE RAPID** - 7 buttons: 1, 3, 5, 7, 9, 12, 15.
- **FAN** - turns the fan on and off.
- **DISPLAY KEY** - selects the SPEED or INCLINE profile while a program is being chosen. During a workout it switches the exercise data on the message window, after which the system scans and displays automatically every four seconds:
  - PROGRAM NAME
  - LAPS XX
  - VERT XXX FT (metric units show "M")
  - SEG TIME XX:XX (not shown in HRC mode)
  - MAX SPEED XX:XX (not shown in HRC or MANUAL mode)
- **PROGRAM KEY** - non-functional.
