The machine has **two** speakers, a left and a right, driven from two ports on the display main board.

| Item | Value |
|---|---|
| Size | 36 × 36 × 18 mm |
| Frequency range | 430 to 12000 Hz |
| Impedance | 4 ohm |
| Power | 3 W |
| Sensitivity | 90 dB |
| Type | full frequency, single horn |
| Connector | XH2.5, wire length 105 |
| Supplier code | TDA |

**Two part numbers carry this identical description in the key component list: `004.028.0052625` (row 9) and `004.057.0054999` (row 11).** The manual gives no way to tell which is the left and which the right, or whether one supersedes the other. Check with the parts desk before ordering.

The speaker cable is a separate part: `004.050.0057226`, "PC260 horn cable, PHS-2Y TO TJC3-2P, UL1007, 350mm".
