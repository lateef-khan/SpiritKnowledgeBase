Open the app, go to the **Settings** tab, find the SRVO under the **SRVO**
heading, then press the information **(i)** button beside it. That opens
**Device Info**.

**Device Info is where the SRVO master volume is set.** The screen shows:

| Row | What it is |
|---|---|
| Device Name | the machine's Bluetooth name |
| Serial Number | the machine's serial number |
| WiFi | the network the SRVO has joined |
| Sound Volume | the master volume |
| Software Version | the firmware on the machine |
| Disconnect | drops the current connection |
| Unpair Device | removes the machine from the app |

The values in the screenshot belong to one demo machine and are not defaults.
