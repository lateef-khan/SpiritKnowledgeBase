Maintenance is the fifth Settings entry. It holds six buttons:

1. **Default Language Setup**
2. **Software Update Manager**
3. **Internet Manager**
4. **WiFi/Ethernet Setup**
5. **Machine Setup**
6. **FTP Settings**

**Default Language Setup** offers **12 languages**, laid out in two columns:

| | |
|---|---|
| English | Español |
| Deutsch | 日本語 |
| Français | Italiano |
| 繁體中文 | 简体中文 |
| Português | Nederlands |
| 한국어 | Norsk |

It sets the language of the first-page window.

**Machine Setup is never explained.** It is drawn on the menu and the manual never opens it - no
screenshot, no description, nothing. The other five all have their own pages.

The elliptical in the same console family has a different Maintenance menu: seven buttons, with
Wi-Fi and Ethernet split apart, a BT Setup button, and no Internet Manager, Machine Setup or FTP
Settings.
