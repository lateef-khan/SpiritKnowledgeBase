The **Engineering Mode** entry of the Settings list holds four controls.

| Control | Value in the screenshot | What it does |
|---|---|---|
| WHEEL SIZE | NA | Not applicable on this machine - it is shown but carries no value |
| BEEP MODE | ON | ON / OFF for beep sound mode |
| SLEEP MODE | OFF | ON / OFF for sleep mode |
| UNITS | KM | English / Metric mode switching |

Sleep mode, word for word:

> The display always lights when turns off. When there is no action for 30 minutes after turning on
> the power, it enters sleep mode.

Read that as: with sleep mode **off** the display stays lit; with it **on** the console sleeps after
**30 minutes** of no action.

**WHEEL SIZE reads NA here.** On a treadmill console in the same family wheel size is a real
calibration value; on this bike it is inert.

The elliptical in the same console family has Units, Beep, Sleep and **Pause Mode**, and no wheel
size.
