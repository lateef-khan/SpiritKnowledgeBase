1. From the Ethernet Configuration screen, press **"Etherner Configuration"** **10 consecutive
   times** to enter the Android setting mode. The button really is printed with that spelling.
2. Hit **Date & Time**.
3. Select the area.
4. Check **Automatic Date & Time** to take the time provided by the web.
5. **Resume the machine's power when complete.**

Step 4 needs a working network connection, so set Wi-Fi or Ethernet up first.

The manual writes step 5 as "Please resume the treadmill power when complete" in the bike manual;
the same page block is reused across the range.
