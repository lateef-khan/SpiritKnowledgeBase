The home screen - the manual also calls it "the first page" - carries four tiles:

| Tile | |
|---|---|
| **TV** | **Language** |
| **Exercise Programs** | **Internet** |

Below them the screen prints:

> To begin workout press the START key on the keypad below. To view an Exercise Program or change
> the Language, select either key above.

So a workout is started from the **physical START key**, not from a tile.

Pressing **Home ten times** from here opens engineering mode.

**This manual prints no program list.** The Exercise Programs tile is named on this screenshot and
nowhere else; there is no table of program names and no setup sequence anywhere in the manual.
