> Select "C-SAFE or CAB" button for TV switching box (Choose one is allowed only)

So the two are mutually exclusive - set one, not both. A separate **brightness adjustment** button
sits alongside them.

The manual gives no cable specification, no port location and no rule for which to pick. The
elliptical in the same console family calls the same pair **C-Safe protocol** (HDMI transfer to a
TV screen) and **CAB protocol** (connect a set-top box), on its A/V Source Setup screen.

This is a different thing from **TV Setup**, which is where the tuner source is chosen and channels
are scanned.
