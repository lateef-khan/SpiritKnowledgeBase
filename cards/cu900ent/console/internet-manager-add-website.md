The console ships with **6 preset web pages**, "such as Face Book / You Tube etc."

**To delete one:** press and hold its button for **2 seconds** and the web page is deleted. The
manual's worked example is the You Tube button.

**To add one:**

1. Add a folder named **`Dyaco`** to a USB Transcend stick and copy the icon image for the new site
   into it. Insert the stick into the USB slot on the back of the console and turn the power on.
2. Enter the new website address - the manual's example is `flipboard.com`.
3. Enter the new file name - the manual's example is `flipboard`. This is the icon file name the new
   site will use.
4. Press the **Internet Manager** button **10 consecutive times** to enter the preset
   add-a-website mode, then hit **OK** to complete adding the website.

The manual does not say whether adding a seventh site is possible, or what happens when the list is
full.
