Eight connections are called out on the I/O board behind the console:

- **Internet CONNECT**
- **GROUND**
- **Console Power CONNECT**
- **HDMI CONTACT**
- **SYSTEM CABLE CONNECT (8 PINS)**
- **Right Hand Pulse Wire**
- **Left Hand Pulse Wire**
- **C-safe CONNECT**
- **TV CONNECT**

The 8-pin system cable is the same **8 PIN COMPUTER CABLE** the circuit diagram runs from the
console down to the driver board.

The CR900ENT recumbent's book prints the same I/O board page with the same nine call-outs. The
CU1000ENT's I/O board is a different layout with pin counts on every socket
(`cu1000ent-2023-specs-io-board-bottom-connections`).
