**p. 5** labels the shrouded machine: **Seat Handle Bar**, **Console Assembly**,
**Handpulse W/Cable Assembly**, **Console Mast**, **Seat**, **Beverage Holder**,
**Console Mast Cover**, **Pedal**, **Side Case**, **Transportation Wheel**, **Rear Stabilizer**.

**p. 6** is a flattened image and was read from the 300 dpi render. It labels the frame with the
shrouds off: **Seat Handle Bar (L)** and **(R)**, **Seat**, **Console Mast**, **Main Frame**,
**Idler Bracket**, **Induction Brake**, **Pedal** (both sides), **Rail Assembly**,
**Crank Arm**, **Rear Stabilizer**.

The Outlines chapter carries **no dimensions, no machine weight, no maximum user weight and no
resistance-level count**. Those figures are not printed anywhere in this manual.

The 2018 CU900 book prints the same two drawings with the same labels, *Induction Brake*
included, on the same upright frame. The recumbent CR900 books label a different frame
(`spirit-cr900-specs-outline-part-names`).
