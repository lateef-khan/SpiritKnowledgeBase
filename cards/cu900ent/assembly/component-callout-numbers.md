The exploded view on this page carries call-outs **1~5, 6-20**. This is the table printed beside it.

| Part Number | Part Description |
|---|---|
| 1 | Console Assembly |
| 2 | Console Assembly |
| 3 | reading race holder |
| 4 | cooling fan |
| 5 | End Cap |
| 6 | Side Case (L) |
| 7 | Sider Case (R) |
| 8 | Front Stabilizer Cover |
| 9 | Rear Stabilizer Cover |
| 10 | Rear Cover |
| 11 | Cap |
| 12 | Console Mast Cover-L |
| 13 | Console Mast Cover-R |
| 14 | Console Mast Cover |
| 15 | Electronic Module |
| 16 | Beverage Holder |
| 17 | Front Seat Cover |
| 18 | Rear Seat Cover |
| 19 | Pedal |
| 20 | Release Lever |

**Parts 1 and 2 are both printed "Console Assembly".** That is what the table says. The drawing draws
call-outs 1 to 5 as one leader marked `1~5.` pointing at the console cluster, so the two rows cannot
be told apart from this page. Do not order from these numbers.

**These are call-out numbers on a drawing, not Spirit part numbers.** The manual prints no part
numbers to order against, and it prints no exploded view for the drive system or the seat mechanism.

`Sider Case (R)` in row 7 is printed that way; row 6 prints `Side Case (L)`.

The CU900 (SU8800-SB008) 2018 service manual prints the same twenty callouts, so this list serves the CU900 and the CU900ENT alike; the recumbent CR900 / CR900ENT list is `spirit-cr900-specs-parts-component-callout-numbers`.
