**This book has one Custom program, not U1/U2, and names Resistance keys.** 1. Select Custom, Enter; if empty or showing someone else's name, enter a username ('A' blinks; Up='B', Down='Z'; max 7 characters; Stop finishes). 2. A stored program offers Run Program? Yes/No with a delete prompt — deleting is required to build anew. 3-5. Enter Age, Weight, Time (Incline/Resistance Up/Down). 6. Build the level profile to all twenty segments. 7. Build the incline profile. 8. Start begins and saves, Enter modifies, Stop exits. Mid-program changes affect the present column only; Display scrolls data; a summary ends the session.
