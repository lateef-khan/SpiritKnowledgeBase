**This book names the keys differently from the 2013 E98 book.** Press the program button, then Enter. Enter Age, Weight and Time with the Incline or Resistance Up/Down keys. Set Max Level (highest colored segment/box). Then choose whether to turn off the incline profile with the Incline Up/Down keys, Enter. Start begins; Stop steps back one screen and Enter restarts programming from the beginning. Incline/Resistance Up/Down adjust mid-program; Display scrolls data; a summary ends the session.
