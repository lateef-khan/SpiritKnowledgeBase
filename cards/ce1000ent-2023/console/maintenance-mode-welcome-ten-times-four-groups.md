**Press the "Welcome" button ten consecutive times to enter engineering mode.** The screen it opens
is headed **Maintenance Mode** and carries four groups. **Set the machine type first**: under About
This Machine, "There are three modes: Treadmill/ Elliptical/ Bike. Please select for the machine.
The selection must match the actual machine otherwise it will be unable to operate the machine
properly."

| Group | Item | What the manual says |
|---|---|---|
| About This Machine | Type | Treadmill / Elliptical / **Upright Bike / Recumbent Bike** - the table names four, the sentence above it names three. Must match the machine. |
| | Reset Odometer, Display Brightness | Shown on the screenshot; not described |
| Preferences | Beep | ON / OFF for beep sound mode |
| | Pause Mode | ON / OFF Pause Time Mode, set in **Minutes : Seconds** |
| | Sleep Mode | ON / OFF. "The display always lights when turns off. When there is no action for **15 minutes** after turning on the power, it enters sleep mode." |
| | Workout Time Limit | ON / OFF; "set limit machine usage time" |
| Machine Setup | Language | The default language for the first-page window; **12 languages** in the menu |
| | Date & Time | "Set console time system" |
| | Units | English / Metric |
| | Video | **STB / TV / None** |
| | Protocol | **C-SAFE or CAB** for the TV switching box; "Choose one is allowed only" |
| | WiFi | "Please hit WiFi button to proceed WiFi setting" |
| | Software, Firmware | Update automatically over a wired or WiFi network, or from USB - `ce1000ent-2023-console-software-update-usb-root-and-automatic` |
| | App Manager | Updates the app software automatically over a wired or WiFi network |
| Service | Key Test, NFC Test, Brake Test, Sensor Tests, Brake Test, Error Code Log | `ce1000ent-2023-console-service-tab-key-nfc-brake-test-twice-sensor-tests-and-error-log` |

**The screenshot on the entry page is a treadmill's.** Its About This Machine panel reads Model
CT1000, its Preferences carry a GS Mode and an Autopause, its Machine Setup a Club Information row,
and its Service tab a Drive Motor Test and an Incline Motor entry - none of which the elliptical's
printed table has. The red arrow on it points at the **Type** field set to **Elliptical**, which is
the one thing on that picture meant for this machine.

**No Club Information row and no GS Mode on the printed table.** The CU1000ENT-2023 bike's table
has a Club Information row under Machine Setup
(`cu1000ent-2023-console-maintenance-mode-welcome-ten-times-four-groups`); the elliptical's does
not, and neither has the treadmill's GS Mode
(`ct1000ent-2023-console-maintenance-mode-welcome-ten-times-four-groups`).

**Fifteen minutes, not thirty.** The CE900ENT sleeps after 30
(`ce900ent-console-engineering-mode-settings-wheel-size-na-beep-30-minute-sleep-and-units`).

**"Welcome", not Home.** The CE900ENT and CE800ENT open their menu on ten presses of the Home icon
(`spirit-ent-console-enter-engineering-mode`); the word on this console's screen is Welcome.

The owner's manual for this machine is not in the repository; nothing here is corroborated by it.
