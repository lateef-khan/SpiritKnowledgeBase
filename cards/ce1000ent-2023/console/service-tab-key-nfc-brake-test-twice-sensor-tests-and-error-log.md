The Service group of Maintenance Mode
(`ce1000ent-2023-console-maintenance-mode-welcome-ten-times-four-groups`) prints six rows, word for
word:

| Item | What the manual says |
|---|---|
| Key Test | Press the "button" to start calibration. The corresponding screen display of the physical button flashes. |
| NFC Test | Please correspond to the location of the NFC sensor, and when the sensor is detected, the information will be displayed on the screen. |
| Brake Test | **Resistance output test.** (If testing, please contact the relevant personnel or maintenance personnel) |
| Sensor Tests | Test that the sensor is working. (If testing, please contact the relevant personnel or maintenance personnel) |
| Brake Test | Resistance output test. (If testing, please contact the relevant personnel or maintenance personnel) - **printed a second time, identically** |
| Error Code Log | Diagnose and save malfunction error messages for technician to inspect the machine and troubleshooting. **Press "Error Code Log" ten consecutive times to clear** the error message. |

**Brake Test is printed twice and there is no Communication Test.** The CU1000ENT-2023 bike's table
has a Communication Test ("hardware tests such as RS232 or USB") in the position where this book
repeats the Brake Test
(`cu1000ent-2023-console-service-tab-key-nfc-communication-brake-sensor-tests-and-error-log`).
Whether the elliptical's console shows five tests or six is not settled by the book; the duplicate
row is what it prints.

**There is no calibration on this elliptical.** The CT1000ENT-2023 treadmill's Service tab has an
Incline Motor entry with a Calibration button
(`ct1000ent-2023-console-incline-only-calibration-and-service-tests`); the Key Test line's "to
start calibration" is a copy-and-paste from that treadmill page - the test flashes the on-screen
copy of each physical button pressed.

**Three of the rows tell you to call someone.** Both Brake Test rows and Sensor Tests carry "please
contact the relevant personnel or maintenance personnel"; the manual gives no readings, pass values
or steps for any of them.

**The Error Code Log is the console's fault history** and its entries are held with the error
cards; this card records only how to reach and clear it.

The owner's manual for this machine is not in the repository; nothing here is corroborated by it.
