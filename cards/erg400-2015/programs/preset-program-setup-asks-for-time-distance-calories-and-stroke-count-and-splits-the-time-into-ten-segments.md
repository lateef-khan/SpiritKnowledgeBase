1. Use the UP/DOWN keys to find the desired preset. Then press ENTER.
2. **The Time window blinks.** Enter a time frame for your workout, then press ENTER.
   *"NOTE: Program segments are based off of total workout time. (EX: A thirty minute workout has
   ten segments that are three minutes each.)"*
3. **The Distance window blinks.** Enter your desired distance, then press ENTER.
4. **The Calories window blinks.** Enter how many calories you would like to burn, then press ENTER.
5. **The Count window blinks.** Enter how many strokes you would like to achieve, then press ENTER.
6. Press the START key to begin your workout.

The book prints no default, range or increment for any of the four values, and does not say what the
console does when a distance, calorie or count value is reached. The profile's resistance follows
the picture for the preset you chose - see the profiles card - and UP/DOWN still change the level
during the workout. The user program is set up the same way, then asks for a resistance per segment.
