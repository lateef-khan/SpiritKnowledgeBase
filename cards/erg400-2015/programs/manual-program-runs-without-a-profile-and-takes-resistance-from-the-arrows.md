The manual program is **P0**, and START from idle goes straight into it.

1. Use the UP/DOWN keys to find **P0**. Then press START.
2. Use the UP/DOWN keys to adjust resistance during the workout (one level per press; hold 2 seconds
   or more for fast key mode).
3. If needed, press the STOP key to pause your workout, and the START key to resume.
4. When you are finished, press and hold the STOP key.

Manual asks for no time, distance, calories or count - those are entered only for a preset or user
program - and it draws no profile. The resistance runs to sixteen levels.
