1. Use the UP/DOWN keys to find the **User** program. Then press ENTER.
2. Follow the same procedure as a preset to select Workout Time, Distance, Calories Burned and Row
   Count (each window blinks in turn; ENTER confirms each).
3. Now create the profile: using the UP/DOWN keys, select the desired resistance for the first
   segment, then press ENTER. Repeat until **all ten segments** have the resistance levels you want.
4. Once all ten are set, press START to begin your customized workout.
5. **"Once a User program is created, it will be saved until any future adjustments are made to that
   program."**

There is one user program. Each segment is a tenth of the workout time; the resistance runs to
sixteen levels and is drawn as blocks of two levels each.
