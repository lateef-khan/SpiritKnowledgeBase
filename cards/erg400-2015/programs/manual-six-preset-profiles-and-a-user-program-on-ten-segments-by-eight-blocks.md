The console shows Total Workout Time, Number of Strokes, Distance Rowed, Calories Burned, Strokes
Per Minute, Watts Produced, Resistance Level, Program Selected, Rowing Position and Program Profile.
Five keys: **UP/DOWN** choose the program, change a setting, and adjust the level during a workout
(1 per press; hold 2 seconds for fast mode); **ENTER** confirms a setting; **START** begins ("pressing
this key under nonoperational mode, starts P0 exercise mode"; held 3 seconds it resets everything);
**STOP/RESET** pauses, and resets when pressed at any time.

The programs, chosen with UP/DOWN:

| Program | Name | Card |
|---|---|---|
| **P0** | Manual | manual program card |
| **P1** to **P6** | Rolling (printed "Polling"), Valley, Fat Burn, Ramp, Mountain, Mountain (2) | preset setup card and profiles card |
| **User** | your own ten-segment profile | user program card |

**Reading a program profile.** "The ten horizontal blocks represent time segments. Segment lengths
are determined by the total workout time selected for a program. The eight vertical blocks represent
resistance. Each block represents two levels of resistance, with a maximum of **sixteen levels** of
resistance." A thirty-minute workout therefore has ten segments of three minutes each.

**UP and ENTER pressed together switch distance from KM to Mile.** There is no heart rate program,
no interval program and no target countdown; the book has no heart rate page at all beyond the
safety warning. The whole book is a scan, read from the OCR supplement and the 300 dpi render.

**Same shapes, other grids.** The Xterra bikes' twelve-preset consoles draw Rolling, Valley, Fat Burn
and Mountain on the same ten-by-eight grid with the same block heights - see `see_also`; their Ramp
and interval shapes differ from this rower's.
