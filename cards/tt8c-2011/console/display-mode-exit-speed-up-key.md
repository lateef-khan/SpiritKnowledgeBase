This book prints **no ATTENTION box** – only the TURNING OFF item: press and hold the **Stop/Enter/Display keys for 5 seconds**; the display shows 'Display Mode - ON'; use the **speed Up key** to change the setting to **OFF**, then press **Enter**. Its sibling books add an ATTENTION box naming the Up arrow or Fast key instead.
