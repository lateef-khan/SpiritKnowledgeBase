| Key | Behaviour in idle mode |
|---|---|
| Stop | **Press and hold for 3 seconds to reset the console.** |
| Start | Starts a workout in Manual mode. |
| Level + / - | **Non-functional.** |
| Enter | Opens the data settings page. Also used to confirm settings. |

Holding **Enter for 2 seconds** in idle mode is a separate gesture - it opens the Bluetooth setting
mode, where the console is switched between the app and a chest strap.
