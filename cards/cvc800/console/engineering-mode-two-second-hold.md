**Two seconds, not five.** Every other Spirit console that opens this menu on Start, Stop
and Enter asks for about **five** seconds; this one asks for about **two**.

1. Press and hold **Start, Stop and Enter** together for about **2 seconds**.
2. The Message Window displays **"Engineering Mode"**. Press **Enter** to open the menu.
3. Use **Up/Down** to move through it and **Enter** to select.

| Item | What it does |
|---|---|
| **A. Key Test** | Tests all the keys to make sure they are functioning |
| **B. Display Test** | Automatically tests all LCDs |
| **C. Functions** | Enter to reach the settings, Up/Down to scroll |
| **D. Factory Set** | No description is printed |
| **E. Exit** | Selects out of Maintenance Mode |

**Inside Functions, in the printed order:**

1. **ODO Reset** - resets the odometer
2. **Units** - Imperial (miles, pounds, feet) or Metric (kilometers, kilograms, meters)
3. **Sleep Mode** - **turn on** to have the console power down automatically after **30 minutes** of
   inactivity
4. **Motor Test** - continually runs the tensioning gear motor
5. **Manual** - allows stepping of the gear motor
6. **Pause Mode** - turn on to allow 5 minutes of pause, turn off to pause indefinitely
7. **Key Tone** - turns the key beep on or off

**The book calls it two names on the same page.** The heading is ENGINEERING MODE, the instruction
says "the Maintenance Menu (may be called Engineering Mode, depending on version)", the screen reads
**"Engineering Mode"**, and the Exit line says Maintenance Mode. All four mean this menu.

**Four items here are on no other Spirit climber menu**: **Factory Set**, **Manual** (step the gear
motor), **Key Tone** as the beep control, and **Display Test** rather than an LCD Test. **There is no
Key Test order number, no Units default, no Sleep Mode default and no description of Factory Set** -
do not tell an owner what Factory Set clears.

**The steppers' menu is a different list on a different hold.** The CS800 and CRS800S open on a
**five**-second hold and offer a Sensor test, a Csafe test and a CAB/CSAFE protocol choice that this
menu has not:
`spirit-stepper-console-maintenance-menu-sleep-default-on`.

**The paragraph opens "TThe console has built in..."** - a doubled T in the printed book. It is a
typographical error, not a different heading.
