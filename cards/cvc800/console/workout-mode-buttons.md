| Key | Behaviour during a workout |
|---|---|
| Stop | **Once** - pause mode. **Twice** - stops the workout mode. **Three times** - back to idle mode. |
| Start | Returns to workout mode from pause mode. |
| Level + / - | Adjusts the resistance level. |
| Enter | **Non-functional.** |

Enter and the Level keys swap roles between idle mode and workout mode: Level does nothing in idle,
Enter does nothing during a workout.
