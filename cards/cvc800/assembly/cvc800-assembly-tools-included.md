Four tools, printed without item numbers:

- 13/14m/m Wrench
- 12/14m/m Wrench
- Phillips Head Screw Driver
- L Allen Wrench-M8

## The steps name five tool numbers for those four tools

The panel gives no numbers, so the only way to match a tool to a step is by what the
step calls it:

| Number | The step calls it | Which tool that is |
|---|---|---|
| 135 | Wrench | 13/14m/m Wrench |
| 136 | Wrench | 12/14m/m Wrench |
| 137 | Screw Driver | Phillips Head Screw Driver |
| 138 | L Allen Wrench | L Allen Wrench-M8 |
| 139 | Screw Driver | **nothing on the panel** |

**No.139 appears once**, in step four item 5, where the track slide wheel covers are
fastened "using the Screw Driver (No.139)". The same job in items 1, 2 and 3 of the same
step uses **the Screw Driver (No.137)**. There is no fifth tool in the carton, and the
book never says what 139 is. Use the one screwdriver you have.

## The CS800 prints the same panel with numbers, and one more tool

The CS800 stepper ships the same carton manifest and prints its tools as 13/14m/m
Wrench (116), 12/14m/m Wrench (117), Phillips Head Screw Driver (118), L Allen
Wrench-M8 (119) **and L Allen Wrench-M6 (120)**. The CVC800 has no M6 Allen wrench and
no step that needs one - its socket head cap bolts are all 3/8" and take the M8 key.
See [that card](../../cs800-2024/assembly/cs800-2024-assembly-tools-included.md).

## Step zero needs the Allen wrench before any hardware comes out of the bag

The first thing the build does is use **L Allen Wrench (No.138)** to take two 3/8" x
3/4" socket head cap bolts out of the machine and throw them away. Take that tool out
first.

## No torque figure and no levelling tool

No step gives a torque figure. The maintenance chapter's noise item calls for a **14mm
wrench** for the levelling pads, which is not among these four - the 13/14 and 12/14
wrenches each carry a 14mm jaw, and the book never says to use one for that job. See
[the levelling card](../../ct800-2016/assembly/ct800-2016-assembly-levelling-pads.md).
