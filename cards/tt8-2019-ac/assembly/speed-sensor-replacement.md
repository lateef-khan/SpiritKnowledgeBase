**AC model: TT8 2019 ST928A-YT037, AC drive motor driven by an inverter. The DC drive motor TT8 2019 (ST928-YT035) is a different machine and this card does not apply to it.**

1. Remove the motor top cover.
2. Remove the speed sensor wiring and replace the part.
3. **After replacement a test to check the sensor registers the magnet is required.**

Set the gap before you close the cover: the sensor must sit as close to the pulley as possible without touching and aligned with the magnet. This manual gives no gap figure; the DC-motor TT8 2019 manual specifies less than 3 mm.
