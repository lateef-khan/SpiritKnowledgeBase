**AC model: TT8 2019 ST928A-YT037, AC drive motor driven by an inverter. The DC drive motor TT8 2019 (ST928-YT035) is a different machine and this card does not apply to it.**

**This is E-41H, one code in the inverter set. It is not any of the E0 to E7 codes used by the
DC-motor TT8 2019.**

Printed description: "OLO System Overload Warning"

OLO as a **warning**. The same OLO condition as a fault is E-0CH.

Troubleshooting, in the manual's order:

1. Check if the motor current is too high.
2. Replace the inverter.
