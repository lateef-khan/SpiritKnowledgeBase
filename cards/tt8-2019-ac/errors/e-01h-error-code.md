**AC model: TT8 2019 ST928A-YT037, AC drive motor driven by an inverter. The DC drive motor TT8 2019 (ST928-YT035) is a different machine and this card does not apply to it.**

**This is E-01H, one code in the inverter set. It is not any of the E0 to E7 codes used by the
DC-motor TT8 2019.**

Printed description: "Low voltage jump, confirm input power is too low"

The inverter saw the input supply drop away.

Troubleshooting, in the manual's order:

1. Check the power supply is normal.
2. Replace the inverter.

**E-01H is not E1.** The DC-motor TT8 2019 (ST928-YT035) has an E1 that means the display board received no RPM signal. This machine has no E1 at all.
