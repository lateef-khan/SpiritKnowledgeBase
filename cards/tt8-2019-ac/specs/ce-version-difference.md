**AC model: TT8 2019 ST928A-YT037, AC drive motor driven by an inverter. The DC drive motor TT8 2019 (ST928-YT035) is a different machine and this card does not apply to it.**

Besides the normal version there is a **CE version**. Both versions are exactly the same in functions and
outlines except that:

- the power input is **110 AC for the normal version** versus **230 VAC for the CE version**, and
- an additional **filter choke circuit** is added for the CE version, shown in the circuit diagram.
