**Three seconds on this machine.** *"To reset all saved settings, press and hold RESET button
for 3 seconds."* The keypad call-out puts it the same way: *"Hold for 3 seconds for a Total Reset of
all values (except Total Strokes)."*

**Two seconds on the CRW800H2O**, whose console is otherwise the same casting and the same five keys
(`crw800h2o-console-total-reset-two-second-hold`). **One second apart on two near-identical water
rowers - check which machine you are answering before you quote a hold time.**

**TOTAL STROKES survives, and the manual states the exception in the call-out and nowhere else.**
Everything else the console has stored is cleared.

**Two things a Total Reset does not touch:**

- **TOTAL STROKES**, as above.
- **The ODO and the engineering mode settings.** *"The console settings and ODO will not be reset
  using the RESET Mode, however, removing the batteries will return the console to original factory
  settings and the ODO value will be zero"*
  (`spirit-water-rower-console-engineering-mode-sound-and-odo`).

**Reset has four jobs on this console**, all printed in one call-out: *"clear a value, to pause your
workout, end your workout. Hold for 3 seconds for a Total Reset."* A short press is not the reset -
in Pause Mode it goes to the STOP screen, and in Stop Mode it clears a value.

**Reset is why the target modes ask you for a value.** Each target program's Setup line begins *"when
operating a target program (after the console has been reset)"*; a mode you have run before **reuses
your last setting as the target value** unless you have reset since. **The CRW800H2O behaves
differently here** - if no value is entered its console *"will not count down"*.
