The program buttons are MANUAL, HILL, FAT BURN, STRENGTH, INTERVAL, 2 USER and 2HR.

**READY MODE**
- STOP: non-function.
- START: starts the elliptical after a 3 second countdown on the window display. In MANUAL the elliptical starts at MIN LEVEL.
- LEVEL UP / LEVEL DOWN / INCLINE UP / INCLINE DOWN: non-functional if the user has not entered a setting.
- FAN: controls fan ON/OFF.
- DISPLAY: selects program P0~P5, U1~U2; pressing DISPLAY changes the LEVEL and INCLINE profile.
- ENTER: enters parameter setting. In workout mode ENTER changes the dot matrix display: LEVEL PROFILE -> INCLINE PROFILE -> SCAN (SCAN changes every 3 seconds).

**RUN MODE**
- STOP: stops the elliptical.
- START and ENTER: non-functional.
- LEVEL UP / LEVEL DOWN: each press changes level by 1.
- INCLINE UP / INCLINE DOWN: each press changes position by 1; maximum incline position 20, minimum 1.
- FAN: controls fan ON/OFF.
- DISPLAY: switches the exercise data. If the information shown is the latest data, pressing DISPLAY makes the message window auto display every four seconds through: LAPS XX, SPEED XX.X MPH, RPM XXX, LEVEL XX, WATTS XXX, SEG TIME X:XX.

Note the source disagrees with itself about ENTER: the READY MODE entry says "in workout mode, pressing ENTER key can modify DM display", while the RUN MODE list says ENTER is non-functional.
