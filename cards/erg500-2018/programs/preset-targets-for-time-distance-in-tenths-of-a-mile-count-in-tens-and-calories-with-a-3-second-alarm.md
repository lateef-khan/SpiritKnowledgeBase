**MODE** changes between the presets TIME, COUNT, DISTANCE, CALORIES and PULSE; **UP** and **DOWN**
raise and lower the setting value; **RESET** held 2 seconds zeroes everything. Set a target before
training with UP and DOWN:

| Function | Accumulates | Each setting step | At the target |
|---|---|---|---|
| **TIME** | 00:00 up to 99:59 | **1:00 minute** | time starts counting up immediately and sounds a **3 second alarm** |
| **DISTANCE** | 0.0 up to **99.9 M (MILE)** | **0.1 M (MILE)** | distance starts counting up and sounds a 3 second alarm |
| **COUNT** | 0 up to 9999 | **10 count** | count starts up and sounds a 3 second alarm |
| **CALORIE** | 0 up to 9999 kcal, in 0.1 kcal increments | **1 kcal** | the calorie value starts up and sounds a 3 second alarm |

The calorie figure "is a rough guide for comparison between different exercise sessions and should
not be used as a medical standard." A pulse target is set the same way and has its own card - see
`see_also`.

**Distance on this console is in miles, not meters** - the only rower in the range whose book says so.
The ERG180's targets count down and flash instead of beeping; the ERG700's count down from a
printed default. If no signal reaches the console for 4 minutes the display shuts off and all
function data resets to zero.
