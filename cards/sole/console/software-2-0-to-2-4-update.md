Applies to the F85, SKU 585820, which is called both the 2020 and the 2021 machine. Updating from 2.0 to 2.4 locks the console with a message saying it needs update 2 of 2.

**To clear the lock**

1. Select a profile.
2. Go to Settings, then Wifi.
3. **Completely forget the customer's Wi-Fi network.**
4. Power cycle the machine, off and back on.
5. Select a profile.
6. Go to Settings, then Software.
7. While on the Software screen, tap the **Wifi** icon in the top right corner.
8. Reconnect to the customer's Wi-Fi.
9. Press **Done** to go back to the Software screen. The Update button should now appear.

**After the update finishes**

1. Go to Settings, then Bluetooth.
2. Turn Bluetooth ON.
3. Connect to "F85".
4. Go to Software and press **Update**.
