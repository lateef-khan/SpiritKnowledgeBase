The Workout Programs section holds **two categories**, switched by tapping the category name:

- **Programs** - programs with predefined level and incline changing profiles.
- **Templates** - regular programs saved with your personal adjustments.

Tap a program preview to read its description; you can scroll sideways through all the descriptions
in the selected category. Press **CHOOSE** to select and adjust a program.

**Favorites.** Any program can be labelled a **FAVORITE**. Favorite programs appear on the Homescreen
so you can reach them at any time.

**The CUSTOM program** lets you set the level and incline variations within a program profile. Once
the profile is defined you choose a target time and a maximum level, and the intensity adapts to
them.

**Saving a template.** Every program can be saved as a template once adjusted, or once completed -
press **Save as** to save it with the current settings. You can also save a finished workout as a
template from the workout summary screen. Manage saved programs in **TEMPLATES**: tap one, then press
**Delete** in the top right corner to remove it.

- **A maximum of 12 template programs can be stored.**
- **A Template program is only available to the user who created it.**

Completed workouts appear in the **History** tab of the Profile section.

**No other Spirit residential XE elliptical works this way.** The XE295, XG400 and XE795 2021 have two
fixed User slots; the XE195 has none.
