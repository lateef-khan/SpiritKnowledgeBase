**The Homescreen provides an activity overview and suggests shortcuts to the training options.**

- **In Guest mode you can provide your physical data here**, which helps the machine calculate your
  workout summary more accurately. **Use the scales or arrows to adjust your age and weight.**
- **The Start Workout button starts the workout immediately.**

**Across the top**, the drawing labels: **Log out**, **Pair HR device**, **Adjust volume**, **Fan
on/off**, **Pair Bluetooth Device**, **Activity Overview**, **Current User**, **Wifi Settings**. It
also marks a **User data setting** area and a **Quick Start** shortcut.

**Along the bottom, six tabs**: **Homescreen**, **Workout Programs**, **Profiles**, **Internet &
Apps**, **Screen Mirroring**, **Settings**.

**Favourite programs also land here.** Any program can be labelled FAVORITE, and favourites appear
on the Homescreen so they can be reached at any time.

**The XT485ENT treadmill Homescreen is the same layout with one icon fewer.** Its top row has no
**Pair Bluetooth Device** icon; everything else, including the six tabs, is printed word for word.
See `xt485ent-2023-console-homescreen`.

**Guest data is not saved.** To keep age, weight and history between sessions you need a profile:
`xe395ent-2021-console-profiles-and-the-spirit-app-link`.

**Both Spirit ENT residential bikes print the same Homescreen page** on their **p. 22**, so this card
is no longer elliptical-only. Same activity overview and shortcuts, same Guest-mode physical data with
scales or arrows for age and weight, same Start Workout button, same eight icons across the top - Log
out, Pair HR device, Adjust volume, Fan on/off, Pair Bluetooth Device, Activity Overview, Current User
and Wifi Settings - and the same **six tabs** along the bottom: Homescreen, Workout Programs,
Profiles, Internet & Apps, Screen Mirroring and Settings.
