**Settings is reached from the bottom right corner of the screen.** Eight items, in the printed
order:

| Tap | What it does |
|---|---|
| **DISPLAY BRIGHTNESS** | Adjusts the brightness of the screen |
| **WIFI** | Internet connection settings |
| **BLUETOOTH** | Pairs Bluetooth devices, **including Bluetooth chest straps, earphones or speakers** |
| **SOFTWARE** | Check the current software version, or update if a new one is available. **Press Update to upload and install the latest version - you must be connected to the Internet** |
| **DATE** or **TIME** | Changes the machine time settings. **These define the time information in the workout summary.** **Both 12 and 24 hour formats are available** |
| **CHILD LOCK** | Locks the screen |
| **UNITS** | Switches between the imperial and metric system |
| **DISPLAY MODE** | Turns the screen ON/OFF |

**This is where Bluetooth headphones and a Bluetooth chest strap are paired**, not from a phone. The
console's own 3.5 mm jack is an input only and cannot drive headphones:
`xe395ent-2021-console-panel-call-outs-and-the-audio-jack`.

**This is not an engineering or service menu.** It holds no calibration, no odometer reset, no
diagnostics and no key test, and this manual describes none for this machine - unlike every
LED-console XE, which reaches an engineering menu by holding Start, Stop and Enter.

**The closely-related XT485ENT treadmill Settings menu has only five of these items.** It has no
Child Lock, no Units and no Display Mode, and its brightness item is labelled **DISPLAY** rather than
DISPLAY BRIGHTNESS. See `xt485ent-2023-console-settings-menu`; the two menus are not
interchangeable.

**Units here changes the whole console.** Each profile can also carry its own unit system:
`xe395ent-2021-console-profiles-and-the-spirit-app-link`.

**Both Spirit ENT residential bikes print the same eight items in the same order** on their **p. 19**,
so this card is no longer elliptical-only: DISPLAY BRIGHTNESS, WIFI, BLUETOOTH, SOFTWARE, DATE or
TIME, CHILD LOCK, UNITS and DISPLAY MODE, with the same descriptions word for word.

**This is where a Bluetooth chest strap is paired on these two bikes.** Their console has no Polar
receiver and no Pulse Grip Feature paragraph, so the strap comes in here, alongside earphones and
speakers. Their own 3.5 mm jack is an input only:
`xe395ent-2021-console-panel-call-outs-and-the-audio-jack`.

**Neither ENT bike's owner's manual describes an engineering menu.** No key test, no display test, no
odometer reset and no calibration is described anywhere in either owner's book. **Their service
manuals do print one** - an Engineer Mode opened by clicking the word Settings ten times on this
page, with a Function page, a Service page of tests and a Factory Setting page:
`spirit-xb55ent-console-engineer-mode-ten-presses-on-settings-function-page-30-minute-sleep`,
`spirit-xb55ent-console-engineer-mode-service-tests-key-motor-incline-sensor` and
`spirit-xb55ent-console-engineer-mode-factory-setting-machine-type-blename-and-an-incline-calibration`.
