**Click the word "Settings" on the Settings page 10 times to enter Engineer Mode.** The Settings
page shown is the eight-item one the owner's manual describes - Display Brightness, WiFi, Bluetooth,
Software, Date, Time, Child Lock, Units, Display Mode
(`xe395ent-2021-console-settings-menu-and-its-eight-items`). Engineer Mode has three pages:
**Function**, **Service** and **Factory Setting**, plus a Calibration screen.

**1. Function**, word for word:

| Item | What the manual says |
|---|---|
| Units | Switch between "imperial" and "metric" |
| Odo | Click on "Reset" to clear all odometer. The screenshot shows `Odo 9999 HOUR 9999 KM` |
| Display Mode | **Default is OFF.** When set OFF, "the electronic watch" will go to sleep without any operation within **30 minutes**. Press any key to wake up. |
| Beep Mode | Turn off beep mode, no beeping sound is heard. |
| Software Update | Pressing **"USB"** to update APK. Pressing **"OSOTA"** to update OS, then press "Check for update" down below the screen. Pressing **"Command"** to update SUB PCB. |

**Read the Display Mode line as printed.** It says the console sleeps when the setting is **OFF**,
which is the reverse of the LED ellipticals' Sleep Mode wording. The owner's manual describes the
same item on the ordinary Settings page as simply "turns the screen ON/OFF" and prints no minutes.

**Thirty minutes here.** The 2023 LED XE ellipticals sleep after 15
(`xe395-2023-console-engineering-mode-with-a-child-lock`); do not carry that figure onto this one.

**Three update buttons, no file names.** The manual does not say what goes on the USB stick, where
the stick plugs in, or what "SUB PCB" the Command button updates. The owner's manual's route is the
over-the-internet **Update** button on the Settings page.

**The owner's manual says this machine has no engineering menu.** It describes only the Settings
page. This service manual is the first document to print one; the Service and Factory Setting pages
are `xe395ent-2021-console-engineer-mode-service-tests-key-motor-incline-sensor` and
`xe395ent-2021-console-engineer-mode-factory-setting-machine-type-blename-and-incline-calibration`.

**This is the elliptical the page was written for.** The XBR55ENT and XBU55ENT bike books print it
unchanged, incline tests and all
(`spirit-xb55ent-console-engineer-mode-ten-presses-on-settings-function-page-30-minute-sleep`).
