**Display board - drawn as CS11039-01ES**; the board photographed beside it is silkscreened
**CS11039 Rev 1.3** with the sticker **CS11039-02ES_V10**. Eight call-outs:

| Socket | Lead |
|---|---|
| **AJ1** | SPEAKER |
| **BJ1** | SPEAKER |
| **J1** | KEY BOARD |
| **J2** | HR HANDLEBAR |
| **J3** | FAN |
| **J4** | USB CHARGE |
| **J6** | SYSTEM CABLE |
| **J9** | WIRELESS HR |

**Interface board** in the swing arm (no part number printed): **JK7 SYSTEM WIRE**, **JK9** and
**JK8 HANDGRIP PLUSE SENSOR** (spelt so). No thumb-switch socket - this console has direct
resistance keys instead.

The speakers hang directly off the display board; there is no separate amplifier, and no RPM IN
socket - the speed sensor now lands on the controller
(`xe795-2023-specs-generator-controller-cs52005-23-connections`). The system cable is the **6 PINS
COMPUTER CABLE** of the circuit diagram (`xe795-2023-specs-circuit-diagram-6-pin-computer-cable`);
its pins are not defined anywhere in this book. Order by the sticker on the fitted board, -02ES
on the sample photographed. The 2023 XBR95 bike uses the same board
(`xbr95-2023-specs-display-board-cs11039-and-interface-board-connections`).
