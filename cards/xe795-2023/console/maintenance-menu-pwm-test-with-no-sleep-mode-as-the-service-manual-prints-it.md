**This is the menu as the XE795-2023 service manual prints it. The owner's manual for the same
machine prints a different one** - see the end of this card.

**Press and hold Start, Stop and Enter for about 5 seconds.** The Message Window displays
**"Engineering Mode"**. Press **Enter** to open the menu; the **Level ▲/▼** keys move through it.

| Item | What it does |
|---|---|
| **A. Key Test** | Test all the keys to make sure they are functioning |
| **B. Display Test** | Tests all the display functions |
| **C. Functions** | Press Enter to access settings, use Level ▲/▼ keys to scroll |
| **E. Exit** | There is no item D |

**Inside Functions, in the printed order:**

1. **ODO Reset** - resets the odometer
2. **Units** - English or Metric display measurements
3. **Pause Mode** - turn on to allow **5 minutes** of pause, turn off to pause indefinitely
4. **Beep** - turns off the speaker so no beeping sound is heard
5. **PWM test** - **tests the Brake resistance**

**No Sleep Mode.** The XE795-2023 owner's manual (p. 37) prints the same four top-level items and the
same PWM test, but its Functions list has a **fifteen-minute Sleep Mode** as its third entry and
scrolls with the + or - arrow (`xe795-2023-console-engineering-mode-with-a-pwm-test`). **The two
documents disagree about the same machine and neither mentions the other.** Read the console in
front of you before quoting either list.

**No keypad lock in either document.** Nothing in this book describes any way to lock the keypad;
the XE395-2023's Child Lock is that machine's alone
(`xe395-2023-console-engineering-mode-with-a-child-lock`).

**PWM test is this machine's name for the brake test.** The 2016 service manual and the 2018 and
2021 owner's manuals call the same entry DA Test
(`xe795-2021-console-engineering-mode-with-a-da-test`). **The XBR95-2023 bike's service manual
prints this list word for word, Sleep Mode missing and item D skipped alike**
(`xbr95-2023-console-maintenance-menu-pwm-test-with-no-sleep-mode-and-no-child-lock`).
