**To open it: press and hold Start, Stop and Enter together for about 5 seconds.** The Message Center
displays **Engineering Mode Menu**. Press **Enter** to reach the menu.

| Item | What it does |
|---|---|
| **1. Key Test** | Tests all the keys |
| **2. Display Test** | Tests all the display functions |
| **3. Functions** | Press Enter for the settings; **the + or - arrow scrolls them** |
| **4. Exit** | |

**Inside Functions, in the printed order:**

1. **ODO Reset** - resets the odometer
2. **Units** - English or Metric display measurements
3. **Sleep Mode** - **turn off** to have the console power down automatically **after 15 minutes** of
   inactivity
4. **Pause Mode** - turn on to allow **5 minutes** of pause, turn off to pause indefinitely
5. **Beep** - turns off the speaker so no beeping sound is heard
6. **PWM test** - **tests the brake resistance**

**There is no keypad lock in this menu.** The XE395-2023 of the same year has a **Child Lock** item
and a Child Lock key on the console; this manual has neither, and nothing in it describes any way to
lock the keypad. **Absence is the answer here** - do not offer an XE795-2023 owner the XE395-2023
procedure.

**PWM test is this machine's name for the brake test.** The 2021 XE795 called the same thing **DA
Test**; the description - "tests the brake resistance" - is identical. See
`xe795-2021-console-engineering-mode-with-a-da-test`.

**Fifteen minutes, not twenty.** Both 2023 machines print 15 where every earlier XE printed 20.
