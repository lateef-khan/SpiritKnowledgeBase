# XS895 stepper: entering engineering mode and resetting the odometer (video, 37 s)

Source file: `Climbers Steppers/XS895/XS895 enter EM and reset ODO.MP4` in the Spirit
Service Manuals folder. 1280x720, 30 fps, 00:00:37, with an audio track that was not
transcribed. This text describes the console screen at one frame every two seconds,
read by eye from the frames on 2026-09-11. The console is labelled **XS895** with a
MUSCLE PROFILE figure at the left, a HEART RATE % PROFILE column (50–90 %) at the
right, an INCLINE rocker at the lower left, a LEVEL rocker at the lower right, and
between them a row of program keys labelled (left to right, as far as legible)
… BURN, CARDIO, STRENGTH, INTERVAL, USER 1, USER 2, HR 1 … and START / STOP keys.

**The key presses themselves cannot be identified from the picture**: a hand covers
the keypad while the message window scrolls "…OR QUICK START OR PROGRAM BUTTON FOR
SETUP", and the frame after it shows the screen already in engineering mode. Which
key or key combination opens the menu must come from the service manual, not from
this video.

| t (s) | Message window / screen |
|---|---|
| 0–8 | Idle screen: 0000 / 00:00 / 00000 / 00000 windows, the profile bar graph, and the scrolling message "…OR QUICK START OR PROGRAM BUTTON FOR SETUP". A hand rests on the program keys. |
| 8–10 | The windows blank; the message window reads **EM** on the top line and **ENGINEERING MODE** scrolling on the bottom line. |
| 10–12 | **EM** / **MENU PRESS** (scrolling). |
| 12–14 | **LCD TEST** — the first menu item shown. |
| 14–16 | **EXIT** — a menu item. |
| 16–18 | A blank window showing only a digit at the right (**0**), then **DISPLAY MODE** (scrolling). |
| 18–20 | **ODO** on the top line, **ODO RESET** on the bottom line. |
| 20–26 | The odometer value is shown in the time window as **0:15** with a figure at the right; the bottom line reads **ODO RESET**; a hand reaches to the keys. |
| 26–28 | Top line **RST**, bottom line **ODO RESET**; the time window reads **0:00** — the odometer has been reset. |
| 28–32 | **FUNCTIONS** (scrolling) — the menu moves on. |
| 32–37 | The console leaves the menu and shows the full-segment test / normal idle display (88:88, 88888, all LEDs lit), then the idle screen. |

What the video establishes: the XS895 console has an engineering mode whose items
include **LCD TEST**, **EXIT**, **DISPLAY MODE**, **ODO RESET** (with a **RST**
confirmation that zeroes the odometer) and **FUNCTIONS**, in that order of
appearance. It does not establish the entry key sequence, the full item list, or
what FUNCTIONS holds.
