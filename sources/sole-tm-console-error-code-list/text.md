Treadmill System Maintenance Guide (DC Digital Controller)

Customer Models: || F63/F65/F80/F85/F89/TT8

Error Code || Error Cause || Solution

E1 || 校正狀態下時，控制器無讀取到速度訊號 / No speed signal detected by the controller in calibration mode. || 1.Check if the speed sensor is properly connected or replace the speed sensor. / 2.Replace the controller (requires recalibration). / 3.Replace the main motor.

E2 || 當機台過載，控制板啟動過電流保護 / Overload causes the control board to trigger overcurrent protection. || 1.Check if the main motor or running belt is blocked or abnormal. / 2.Ensure there is enough lubricant between the belt and the deck. / 3.Check for abnormal noise in front and rear rollers; replace if necessary. / 3.Replace the controller (requires recalibration).

E3 || 揚升異常 / Incline abnormality. || 1.Check if the Incline motor cable is connected properly. / 2.If not due to wiring, replace the elevation motor (requires recalibration). / 3.If the issue persists, replace the controller (requires recalibration).

E4 || 馬達兩端電壓不正常或馬達接線異常 / Abnormal voltage at motor terminals or motor cable issues. || 1.Check if the main motor cable is connected properly.  / 2. Check for loose or corroded motor terminals. / 3. Replace the controller (requires recalibration).  / 4. Replace the main motor.

E5 || 電子錶與控制板通信中斷或通訊異常 / Communication disruption between console and control board. || 1.Ensure the connection between the console and controller is intact.  / 2. Check if all control wires are properly connected or damaged.  / 3. Replace the controller (requires recalibration).  / 4. Replace the console.

E6 || 控制器異常 / Controller malfunction. || 1.Check if there is abnormal resistance in the drivetrain; address if found.  / 2. Replace the controller (requires recalibration).

E7 || 外部電壓異常 / External voltage abnormality. || 1.Check if the external AC input is normal.  / 2. Check if the AC terminals on the controller are loose or corroded.  / 3. Replace the controller if damaged by E4/E6 issues (requires recalibration).

E8 || 控制器EEPROM異常 / Controller EEPROM malfunction. || Replace the controller (requires recalibration).

No Display || 當上電後，電子錶沒有點亮 / Console does not light up when powered on. || 1.Check if the power plug, fuse, and control wires are securely connected. / 2.If power light is on, replace the control wire between console and controller. / 3.If power light is off, replace the controller (requires recalibration).  / 4.Replace the console.

Safety Key || 安全KEY裝置及檢測說明 / Safety key setup and detection. || 1.Ensure the safety key is properly inserted. / 2.Check if the safety key cable is intact. / 3.Replace the console. / 4.Replace the controller (requires recalibration).

AC Inverter - Rhymebus

Customer Model: || TT9/ST90

Error Code || Error Cause || Solution

E-01H || 低電壓跳脫，確認輸入電源是否過小 / Low voltage || 1.Follow the inverter troubleshooting. / 2.Replace the inverter.

E-02H || 溫度感測異常 / Abnormal temperature

E-04H || OC輸出過電流 / Overcurrent

E-06H || OE 變頻器過電壓 / Converter overvoltage

E-07H || PFC異常 / Abnormal PFC

E-08H || GF 落地異常 / GF abnormal

E-09H || OH變頻器過熱 / Converter overheat

E-0AH || OL馬達過載異常 / Motor overload

E-0BH || OL1變頻器過載異常 / Converter oberload

E-0CH || OLO系統過載異常 / System overload

E-21H || PrEr Flash 程式故障 / Abnormal PrEr Flash

E-22H || EEPROM故障 / EEPROM error

E-23H || 低電壓顯示 / Low voltage

E-25H || 緊急停機顯示 / Emergency Stop || 1.Check if the 2-pin control cable connection is intact and undamaged. / 2.Replace the inverter.

E-26H || drvF Driver 設定錯誤 / drvF Driver setting error || 1.Follow the inverter troubleshooting. / 2.Replace the inverter.

E-27H || LP 輸入低電壓 / Low power voltage

E-28H || HP輸入高電壓 / High power voltage

E-29H || Ht 高溫顯示 / High temperature alert

E-41H || OLO系統過載警訊 / System overload alert

E-42H || Ht 高溫警訊 / High Temperature alert

E-50H || 電子錶與變頻器通訊出錯 / Communication error || 1.Check if the control cable has loose or damaged connections. / 2.Replace the inverter. / 3.Replace the console (recalibration needed).

E-51H || 電子錶(內部)上下位機通訊出錯 / Inter-communication error || 1.Check if internal console wiring is disconnected or has poor contact. / 2.Replace the console (recalibration needed).

E-52H || 機台校正時，前揚升或後揚升出錯 / Incline calibration error || 1.Check if front/rear incline motor wiring is secure and has good contact. / 2.Check if the incline motor is jammed or faulty (replacement requires recalibration). / 3.Replace the inverter.

E3(Red) / E-53H || 機台(前面)揚升出錯 / Incline (Front) error || 1.Check if the incline motor wiring to the inverter terminal is secure and has good contact. / 2.Check if the incline motor is jammed or faulty (replacement requires recalibration). / 3.Replace the inverter.

E3(Green) || 機台(後面)揚升出錯 / Incline (Rear) error || 1.Check if the incline motor wiring to the incline adapter board terminal is secure and has good contact. / 2.Check if the incline motor is jammed or faulty (replacement requires recalibration). / 3.Replace the incline adapter board. / 4.Replace the console (recalibration needed).

No Display || 當上電後，電子錶沒有點亮 / Console does not light up after power-on || 1.Check if the power plug, fuse, and control cable are connected properly. / 2.If the power indicator is on, replace the control cable between the console and the inverter. / 3.If the power indicator is off, replace the inverter. / 4.Replace the console (recalibration needed).

Safety Key || 安全KEY裝置及檢測說明 / Safety Key device and detection instructions || 1.Check if the safety key is correctly inserted. / 2.Check if the safety key wiring (including the 2-pin inverter wire) is properly connected. / 3.Replace the console (recalibration needed). / 4.Replace the inverter.
