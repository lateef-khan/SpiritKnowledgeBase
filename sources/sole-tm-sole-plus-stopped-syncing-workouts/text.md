# Sole+ Stopped Syncing Workouts from Machine

SOLE+ can sometimes get unlinked from the machine for whatever reason which would cause new workouts to not sync to the app. You may need to verify that the machine and SOLE+ app is fully up to date, connected to the internet (doesn't have to be on the same network), and possibly re-link the customer's profile to SOLE+. Check the following to determine where the problem lies:

1. Login to the Profile that is no longer syncing.
2. Open up the settings.
3. Ensure the treadmill is connected to your wifi network.
4. See if any software updates are available for the machine. You may need to unplug the machine and plug it back into the outlet for it to check for the latest updates.
5. Ensure no updates are pending through the Google Play Store or Apple App Store for the SOLE+ app.
6. Exit out of the settings. Tap the customer's profile image at the top of the screen.
7. Below the customer's profile name, it may have a Link button or say it's already linked. If a Link button is present, try linking by scanning the QR code. If it's already linked, try deleting the profile with the Delete button at the top of the current page and relink the profile from the login screen.

If the SOLE+ app is still unable to connect using the QR code, replace the console assembly.
