Engineering Mode (Ellipticals)

For All Non-Touchscreen Ellipticals:

Turn on the power switch of the machine if it isn’t already powered on.
Press and hold the Stop, Enter, and Start buttons.
Keep holding the buttons until the screen says EM or Engineering Menu. This should only take 10 seconds.
You may let go of all the buttons and press Enter.

This menu can be navigated by pressing the level/resistance up and down buttons to change selections, pressing enter to choose a selection, and pressing stop to navigate back a menu. If any selection is changed, you must press the enter button to lock in the selection or it will not save.
The following options are normally available:

Key Test
Note: You have to press all the buttons to exit the Key Test.
Each button press registered will make the machine beep and display a number.
Display Test
The display will fully light up to make it easy to see any dead spots
Functions
Display Mode (might be called Sleep Mode)
If called Display Mode, setting to ON will prevent the screen from turning off. Setting it to OFF will allow the machine to go to sleep after 15-30 minutes of inactivity.
If called Sleep Mode, setting to ON will allow the machine to go to sleep after 15-30 minutes of inactivity. Setting it to OFF will prevent the screen from turning off.
Pause Mode
Pause mode is where the machine will allow the user to pause their workout and allow resuming within 5 minutes without losing their current workout’s stats. If the user does not press start again within the time limit, the machine will end the workout. Pressing stop a second time will also end the workout. Setting to ON will enable this functionality, and setting to OFF will make it so the stop button ends the workout on the first press immediately.
Odo Reset
This will show the machine’s odometer readings since the lube message was last reset. Pressing enter will reset the lube message and the odometer.
Units
Sets the machine’s units to be in Miles or Kilometers. Setting to ENG will change units to Miles (ENG was probably meant to mean English but that’s technically incorrect as Imperial is the correct term). Setting it to MET will set it to metric units and use Kilometers.
Motor Test
The machine will automatically adjust the gear motor from its lowest to highest resistance levels to ensure functionality.
Manual
This option will give you control of the gear motor. Pressing the up or down level buttons will change the current resistance level and display the current values of what the machine is sending to the gear motor.
Key Tone
Setting to ON will allow the machine to make audible beeps whenever buttons are pressed and in other instances the machine would make a beep noise from the speakers. Setting to OFF mutes most beeps.
Security (aka Child Lock)
Can be set to ON or OFF. If set to ON, the machine will display CONSOLE LOCKED when booted or after a bit of inactivity. To unlock, you have to hold the Start and Enter buttons for a few seconds to unlock.
Factory Set
Selecting this will reset all the settings in the engineering menu back to their defaults. This does not reset any user workouts configured on the machine.
Exit

For All Touchscreen Ellipticals:

Turn on the power switch of the machine if it isn’t already powered on.
Login to a personal account or choose the Guest profile.
Open the settings by pressing the gear icon in the top-left corner.
Rapidly tap the word “Settings” several times until the Engineering Menu appears.

This menu can be navigated by tapping the selections and tapping the X button at the top-left to exit the engineering menu entirely.

The following options are normally present in this menu:
Function
Unit
Displays the current units in use. Can be changed between Miles and Kilometers. Units can also be changed in the normal settings menu and are not required to be changed here.
Odo
Displays the amount of hours and kilometers the machine has been used over the machine’s lifetime. Can be reset to zero by pressing the reset button.
Sleep Mode
Can be set to OFF, ON, and RETAIL. Setting to ON will allow the machine to turn itself off after 15-30 minutes of inactivity. Setting to OFF will prevent the machine’s screen from turning off without turning off the power switch. Setting to RETAIL will have the machine display promo videos after 3 minutes of inactivity. This setting can also be accessed through the regular settings menu.
Beep
Setting to ON will allow the machine to make audible beeps whenever buttons are pressed and in other instances the machine would make a beep noise from the speakers. Setting to OFF mutes most beeps.
5K HeartRate
This setting is to control whether the machine will listen for 5kHz heart rate monitors. Setting to OFF will disable listening for these heart rate monitors, but will still allow for Bluetooth/ANT+ heart rate monitors to connect.
Software Update
Displays some functions meant for engineering purposes for managing the console’s software. Should not be touched by the consumer.
Machine Type
Sets the machine’s type for the console so it knows what parameters to operate with. Setting to an incorrect machine will cause error codes to be thrown.
Service
Key Test
Note: You have to press all the buttons to exit the Key Test.
Each button press registered will make the machine beep and display which button was pressed.
Motor Test
Manual: Will allow direct control of the gear motor using the plus and minus buttons.
Auto: Will automatically move the gear motor from its lowest to highest values.
Incline Test
Manual: Will allow direct control of the incline motor using the plus and minus buttons.
Auto: Will automatically move the incline motor from its lowest to highest values.
Sensor Test
Will display currently sensed values for the heart rate and speed sensors. The acronyms displayed mean the following:
HRM: Heart Rate Monitor
HP: Hand Pulse
WP: Wireless Pulse
RPM: Rotations per Minute
Factory Setting
Restore Factory
Resets the machine’s user profiles and saved workout data. Will not reset any media apps and performs exactly the same as the hidden menu in the login screen that allows for a factory reset.
First Launch
Will set the machine to a state where any previously shown tutorials will be displayed again as if first getting the machine.
Grade Return
Setting to ON will make the machine reset its incline to 0 after booting and logging into a profile. Useful in the event of power loss. Setting to OFF will disable this functionality.
Territory
Changes the territory of the machine which sets parameters to comply with regulations set by the given region. Can be set between US, Global, and Mandarin.
BLE Name
Changing this will allow setting the name that is broadcasted over bluetooth and displayed in the SOLE+ app when connecting to the machine.
OTA Url
Changes the URL location to pull any over-the-air software updates from and only meant for engineering purposes.
Calibration
Press the start button next to Incline Calibration to have the machine recalibrate the incline motor. Calibration is necessary whenever the console, incline controller, or incline motor get replaced.
