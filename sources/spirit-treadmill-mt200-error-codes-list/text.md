Error Codes List MT200 - English
E1 Over Current
Check the running deck and running belt lubrication, inverter or drive motor, and motor
brake.


E2 Over Voltage
Check AC line voltage.


E3 Over Voltage Deceleration
Check AC line voltage and motor brake.


E4 Ground Fault
Check wiring, replace inverter.


E5 IGBT Fault
Check wiring, replace inverter.


E6 Drive Overload
Check the running deck and running belt lubrication, motor brake, inverter, and drive
motor.


E7 Thermal Overload
Check motor brake, the running deck and running belt lubrication, inverter, and drive
motor.


E8 Over Torque
Check motor brake, the running deck and running belt lubrication, inverter, and drive
motor.


E9 Over Speed Current
Check motor brake, the running deck and running belt lubrication, inverter, drive motor.
E10 Over Current Acceleration
Check the running deck and running belt lubrication, inverter, drive motor.


E11 Over Current Deceleration
Check the running deck and running belt lubrication, inverter, drive motor.


E12 EPROM Read
Check AC line voltage, reset power, check inverter.


E13 EPROM Write
Check AC line voltage, reset power, check inverter.


E14 External Fault
Reset power.


E15 U Phase Current
Reset power, check inverter.


E16 W Phase Current
Reset power, check inverter.


E17 Hardware Fault
Reset power, check inverter.


E18 IGBT Overheat
Check inverter fan and heat sink.


E19 Ambient Temperature
Check air vent, check fan.


E20 Inrush Fault
Reset power, check inverter.
E21 Input Signal Lost
Check wiring, check inverter.


E22 RS-485 Fault
Check wiring.


E23 PID Error
Check wiring, check parameter settings.


E24 RS-485 Error
Check inverter, check RS-485 cable.


E25 Auto Tune
Check drive motor wires, reset power.


E26 Brake Chopper
Reset power, check inverter.


E27 PG Error
Check motor encoder.


E28 Phase Loss
Check wiring, check inverter.


E29 Current Signal Stop
Reset power, check inverter.


E30 CPU Error
Check electronic circuit fault.


E31 Fan Error
Check inverter fan.
E32 Analog Input Error
Check wiring, check inverter.


E33 Over Torque
Check whether there are any abnormalities on the mechanism, lubrication, motor brake,
drive motor, and inverter.


E34 Thermal Overload 2
Check motor brake, the running deck and running belt lubrication, inverter, and drive
motor.


E35 Motor Selection
Check motor wiring.


E36 Low Voltage Bus Run
Check AC line voltage, check inverter.


E37 Low Voltage Bus
Check AC line voltage, check inverter.


E38 External Brake
Check parameter settings.


E41 Incline Error
Check incline motor.




E42 Bad communication Error

Replace the main computer cable, and then replace the inverter, at last replace the console.
