E3 Error (Elliptical)
Incline Error
(If machine has been recently (re)assembled AND does not pass calibration, replace Computer Cable and Incline Power Cords)

This error happens when the machine notices something wrong when trying to control the incline motor. This error can happen if the console, incline/brake controller, or incline motor has been recently replaced if the machine was not recalibrated afterwards. Always run a calibration first to see if it resolves the issue and perform the following:

Run a calibration
If calibration passes, press the “Start” button and press the Incline Up button.
If machine inclines and declines, machine is fixed
If machine still pulls up an E3 Error, move on to the next point
If calibration fails or E3 still present after calibration, ask if the incline motor moved at all:
If the answer is Yes, something about the signal going back up to the Console is being interrupted.
If machine is from 2016 or newer
Replace the Incline/Brake Controller or Display Board
If machine is older than 2016, run a Pin Test
If machine passes Pin Test, replace Computer Cable and Display Board
If machine fails Pin Test, replace Computer Cable and Incline/Brake Controller
If the answer is No, something about the signal going down to the Incline/Brake Controller is being interrupted.
If machine is from 2016 or newer
Replace Incline/Brake Controller or Incline Motor
If machine is older than 2016, run a Pin Test
If machine passes Pin Test, replace Computer Cable and Display Board
If machine fails Pin Test, replace Computer Cable and Incline/Brake Controller
