F85 (585820) 2.0 to 2.4 Update

When updating from 2.0 to 2.4, the console will lock saying it needs update 2 of 2. Follow these instructions to resolve.

Select Profile
Go to Settings
Go to Wifi
Completely forget customer’s Wifi
Power cycle machine (turn off and back on)
Select Profile
Go to Settings
Go to Software
While on Software screen, tap Wifi icon in top right hand corner of screen
Reconnect to customer’s Wifi
Press “Done” to go back to Software screen
Update button should appear

After the update is complete, follow these instructions

Go to Settings
Go to Bluetooth
Turn Bluetooth ON
Connect to “F85”
Go to Software
Press “Update”
