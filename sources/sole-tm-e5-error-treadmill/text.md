E5 Error (Treadmills)
Miscommunication between Console and Controller
(If machine has been recently assembled, replace Computer Cables)

This error is when the console and motor controller are having trouble communicating with each other and most commonly happens if computer cables have gotten pinched or aren’t plugged in correctly. It can also happen if the motor controller or the console/display board is damaged. Check the following to see where the issue might be coming from:

Ask if machine has been recently assembled, disassembled or moved:
If answer is Yes, replace Computer Cables
If answer is No, Motor Controller has most likely been damaged, move on to step 2
Ask about Lubrication (Question: How often do you lubricate?)
Whether the machine has been properly lubricated or not, check Running Belt and Running Deck have been worn or damaged (Slide hand between running belt and deck palm up first. See if texture of running belt is gone in the middle. Palm down, see if running deck is damaged.)
If Running Belt and Running Deck are in good condition, move onto Step 3
If Running Belt or Running Deck are worn or damaged, replace Running Belt, Running Deck and Controller (Running Deck only has to be replaced if it is worn or damaged)
Ask if machine is plugged up directly into its own circuit on a non-GFCI outlet
If answer is yes, move onto Step 4
If answer is no, have customer plug up machine into its own circuit on a non-GFCI outlet and have them try running the machine again
If machine runs, machine has been “fixed”
If machine does not run, replace Motor Controller
Ask if they have squeaking or knocking noises coming from the machine.
If answer is yes, asking if noise is coming from front or rear of the machine, depending on answer replaced Front Roller or Rear Roller (possibly both) and Motor Controller
If answer is no, replace Motor Controller
If replacing the controller does not fix the problem, the last resort is to replace the console/display board.
