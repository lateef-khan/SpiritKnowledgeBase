# LWR Not Match

(Comes on E95, E95S, E98, SB1200, E35, LCB and LCR models)

(If machine has been recently (re)assembled AND does not pass calibration, replace Computer Cables)

This comes up when the console is set to a different model than what it is sitting on top of.

1. Login to a profile and tap the "Gear" icon to open Settings menu
2. Tap the word "Settings" multiple times until new screen pops up
3. Scroll down to "Machine Type"
4. Select the correct model
5. Console reboots and LWR Not Match should be gone

If the error does not go away, replace the Console or Display Board. Also replace Computer Cables if recently assembled. If neither of these fix, replace the Incline Controller.
