Bluetooth Connectivity Issues

Bluetooth connectivity in the SOLE+ app should work on any machine manufactured on or after August 2021 and will allow the machine’s workout to be controlled by the mobile device or allow an Apple Watch to broadcast heart rate (see Apple Watch Connectivity for specific requirements). Any machines made since 2018 will also support being used as a bluetooth speaker by connecting to BT-Speaker in the mobile device’s system settings. If bluetooth is not connecting through the SOLE+ app or BT-Speaker is unable to be connected to on a modern enough phone, perform the following:

Non-Touch Screen Models
Make sure nothing else is connected to the machine by checking other devices the customer has that have Bluetooth capabilities.
If there are other devices connected to the machine, have the customer disconnect them and connect up their phone or tablet
If there are no other devices connected and machine is not a treadmill, replace Console Assembly
If there are no other devices connected and the machine is a treadmill, follow the following instructions
Remove Safety Key
Press and hold “Start” and “Incline Up” buttons
While holding buttons, reinsert Safety Key
Hold buttons until you see BLUETOOTH on the screen
If Bluetooth is OFF, press “Incline Up” button to change it to ON
Press “Enter” button to confirm and exit
Try connecting phone or tablet
If bluetooth works, no further diagnosis
If bluetooth does not work, replace Console Assembly

Touch Screen Models
Make sure no other devices are connected to the machine by opening the Bluetooth menu on the machine
If no other devices are connected, make sure Software is fully up to date
If Software is up to date, replace Console Assembly
If Software is not up to date, update Software and try connecting Bluetooth again
If Bluetooth works, no further diagnosis is needed
If Bluetooth does not work, replace Console Assembly
If other devices are connected, disconnect them and try connect the customer’s phone or tablet again
If Bluetooth connects, no further diagnosis is needed
If Bluetooth does not connect, but connected to other devices, something about the customer’s phone or tablet is not allowing it to connect.
