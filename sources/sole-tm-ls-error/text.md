LS Error
Low Speed
(If error is coming up after machine has been assembled, just replace Computer Cables)

This error only happens on 2016 and older treadmills. If computer cables have not been pinched, it can be caused when the machine is not going the speeds it is expecting. A simple calibration can fix it entirely, but can also be caused by friction between the belt and the deck, a worn motor controller, or if the motor is no longer moving.

Run calibration
Pass: Press “Start” button for a quick start
If it runs, machine should be fixed
If it doesn’t run, move onto Step 2
Fail: move on to Step 2
Ask, “Does the running belt move at all before the LS Error comes up?”
Answer is yes:
Ask, “How long does the running belt move for?”
Answer is moves for less than 10 seconds
Remove Motor Hood Cover and check alignment of speed sensor
If sensor is aligned properly, move on to Step 3
If sensor is not aligned properly, align it and run calibration again
If calibration passes, press the “Start” button for quick start. If machine runs properly, diagnosis should be complete
If calibration fails, move onto Step 3
Answer is moves for longer than 10 seconds
Move onto Step 3
Answer is no:
Remove Motor Hood Cover so you can see the Motor Controller, press the “Start” button and see if PWM light comes on the controller
Answer is yes:
Move onto Step 3
Answer is no:
Ask if machine has been recently assembled, disassembled or moved
Answer is yes, replace Computer Cables
Answer is no:
If machine is older than 2016, run a Pin Test
If machine passes Pin Test, replace Upper Computer Cable  and Display Board
If machine fails Pin Test, replace Middle Computer Cable, Lower Computer Cable and Motor Controller

Ask about Lubrication
Whether machine has been properly lubricated or not, check Running Belt and Running Deck have been worn or damaged
If Running Belt and Running Deck are in good condition, move onto Step 4
If Running Belt or Running Deck are worn or damaged, replace Running Belt, Running Deck and Controller (Running Deck only has to be replaced if it is worn or damaged)
Ask if machine is plugged up directly into its own circuit on a non-GFCI outlet
If answer is yes, move onto Step 5
If answer is no, have customer plug up machine into its own circuit on a non-GFCI outlet and have them try running the machine again
If machine runs, machine should be fixed
If machine does not run, replace Motor Controller
Run Battery Test on Drive Motor
If Drive Motor passes Battery Test, move onto Step 6
If Drive Motor fails Battery Test, replace Drive Motor and Motor Controller
Ask if they have squeaking or knocking noises coming from the machine.
If answer is yes, asking if noise is coming from front or rear of the machine, depending on answer replaced Front Roller or Rear Roller (possibly both) and Motor Controller
If answer is no, replace Motor Controller
