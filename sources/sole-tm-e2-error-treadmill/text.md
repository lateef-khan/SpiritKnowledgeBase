E2 Error (Treadmill)
Controller Over Current
For machines prior to 2016, refer to E3 Error as this was an incline error for older units
(If error comes up after machine has been assembled, replaced Computer Cables)

This error happens when the machine notices the controller is drawing too much power to get the motor up to speed. This is commonly caused by friction between the belt and the deck or by a damaged motor controller. Check the following to determine any wear and potential background issues that could be tripping the error.

Ask about Lubrication (Question: How often do you lubricate?)
Whether machine has been properly lubricated or not, check Running Belt and Running Deck have been worn or damaged
If the Running Belt and Running Deck are in good condition, check if the machine is properly lubricated. If lubricating does not fix, move on to Step 2.
If Running Belt or Running Deck are worn or damaged, replace Running Belt, Running Deck and Controller (Running Deck only has to be replaced if it is worn or damaged)
Ask if machine is plugged up directly into its own circuit on a non-GFCI outlet
If answer is yes, move onto Step 3
If answer is no, have customer plug up machine into its own circuit on a non-GFCI outlet and have them try running the machine again
If machine runs, machine should be fixed
If machine does not run, replace Motor Controller
Ask if they have squeaking or knocking noises coming from the machine.
If answer is yes, ask if noise is coming from front or rear of the machine, depending on answer replaced Front Roller or Rear Roller (possibly both) and Motor Controller
If answer is no, replace Motor Controller
