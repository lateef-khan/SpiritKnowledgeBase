Popping/Vibrating Noise Only When Inclining

When you get a popping noise only when inclining the treadmill, it is most likely that the gas cylinder for the folding function has dried out. It is self lubricating, so the more you fold it up, the more it lubricates itself. Try lifting and lowering the deck 10-15 times into the folding position. That should lubricate the cylinder.
