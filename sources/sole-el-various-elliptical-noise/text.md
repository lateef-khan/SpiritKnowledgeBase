Various Elliptical Noises

Squeaking/Grinding noises from rail area
Ask if rails have been lubricated
If answer is Yes, have customer check for damage on the rails or slide wheels
If damage is found replace the damage parts
If no damage is found, spin Slide Wheels manually
If Slide Wheels all spin, ask if the customer heard a noise when they spun the Slide Wheels
If answer is Yes, replace Slide Wheels
If answer is No, have customer lubricate rails again
If answer is No, have customer lubricate

Popping/Creaking noise from Pedals
Ask if customer foot is positioned properly on the pedal and not lifting their heel
If the customer is using the machine properly, ask which side specifically is making the noise, replace Pedal and Foam Tape
If the customer is not using the machine properly, inform them of how to use the machine and try again. If customer is still getting noise, replace Pedal and Foam Tape.

Loud Knocking noise from machine
Ask if customer foot is positioned properly on the pedal, not lifting their heel and how fast they are trying to use the machine
If customer is using the machine properly, ask which side noise is coming from
If noise is coming from one side or the other and outside of the flywheel area, replace rod end bearings and rod end sleeves and possibly the bushings for the crossbar and pedal arm.
If noise is coming from inside the machine, replace Bearing and Bearing/Axle Stopper
If the customer is not using the machine properly, inform them of how to use the machine and try again. If noise is still present ask which side the noise is coming from.
If noise coming from one side or the other and outside of the flywheel area, replace rod end bearings and rod end sleeves
If noise is coming from inside the machine, replace Bearing and Bearing/Axle Stopper


Rubbing noise from front of machine
Have the customer send you a video of them using the machine showing both the left and right sides of the machine. Look at the spinning Round Disk Cover. If it looks like the Round Disk Cover is wobbling or is too close on one side to the Side Shroud Cover, replace Crossbar
