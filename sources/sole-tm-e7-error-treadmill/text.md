E7 Error (Treadmills)
Improper Voltage into Machine
(If machine has just been assembled, replace Computer Cables)

This error can be a result of abnormal voltage coming into the machine and into the motor controller if it’s not a result of pinched cabling. External factors such as GFCI outlets, extension cords, power strips, and surge protectors can trigger this error even if the machine has worked fine with them before. If the machine is 
plugged directly into an outlet and the voltage coming into the machine is ~120V, then it can be any of the components in the machine that lead up to the motor controller if the voltage drops at any point, or the motor controller itself. Perform the following to see where the issue may lie:

Ask if machine is plugged up directly into its own circuit on a non-GFCI outlet
If the answer is yes, ask the customer to use a multimeter to check where power stops or slows. Voltage should be around 120V AC all the way to the Motor Controller.
If the customer finds voltage all the way to the Motor Controller is good, replace the Motor Controller.
If customer find a stop or slow if voltage, replace parts from where they found the found the problem back to the last check point (details below)
If answer is no, have customer plug up machine into its own circuit on a non-GFCI outlet and have them try running the machine again
If machine runs, machine should be fixed
If machine does not run, replace Motor Controller
If replacing the motor controller, ask about Lubrication (Question: How often do you lubricate?)
Whether the machine has been properly lubricated or not, check Running Belt and Running Deck have been worn or damaged (Slide hand between running belt and deck palm up first. See if texture of running belt is gone in the middle. Palm down, see if running deck is damaged.)
If Running Belt and Running Deck are in good condition, move on to Step 3
If Running Belt or Running Deck are worn or damaged, replace Running Belt, Running Deck (Running Deck only has to be replaced if it is worn or damaged), move on to step 3
If replacing the motor controller, ask if they have squeaking or knocking noises coming from the machine.
If the answer is yes, ask if noise is coming from the front or rear of the machine. Depending on the answer, replace the Front Roller or Rear Roller (possibly both)

Voltage Test
With a multimeter:

Test power at the outlet. If power is not ~120V, an electrician will need to check out the outlet as the outlet is the issue.
Plug the Power Cord into the outlet, but not into the machine. If power through Power Cord is not ~120V, replace Power Cord.
With the machine unplugged, disconnect the White and Black Connecting Wires from On/Off Switch (or Filter if the machine has one) that plug into the Motor Controller. Connect multimeter probes to the wires you just unplugged. Plug up Power Cord into outlet and machine’s Power Socket. Turn ON the On/Off Switch.
If power is ~120V, replace Motor Controller
If power is not ~120V, replace White and Black Connecting Wires, On/Off Switch, Breaker, and Power Socket
