Engineering Mode (Treadmills)

For All Non-Touchscreen Treadmills:

Turn on the power switch of the machine if it isn’t already powered on.
Press and hold the Stop, Enter, and Start buttons. (2026 models: Stop, Start and Display/Enter)
Insert the safety key while holding those buttons, and keep holding the buttons until the screen says EM or Engineering Menu. This should only take 10 seconds.
You may let go of all the buttons and press Enter.

This menu can be navigated by pressing the speed/incline up and down buttons to change selections, pressing enter to choose a selection, and pressing stop to navigate back a menu. If any selection is changed, you must press the enter button to lock in the selection or it will not save.

The following options are normally available:
Key Test
Note: You have to press all the buttons to exit the Key Test.
Each button press registered will make the machine beep and display a number.
Display Test
The display will fully light up to make it easy to see any dead spots
Functions
Display Mode (might be called Sleep Mode)
If called Display Mode, setting to ON will prevent the screen from turning off. Setting it to OFF will allow the machine to go to sleep after 15-30 minutes of inactivity.
If called Sleep Mode, setting to ON will allow the machine to go to sleep after 15-30 minutes of inactivity. Setting it to OFF will prevent the screen from turning off.
Pause Mode
Pause mode is where the machine will allow the user to pause their workout and allow resuming within 5 minutes without losing their current workout’s stats. If the user does not press start again within the time limit, the machine will end the workout. Pressing stop a second time will also end the workout. Setting to ON will enable this functionality, and setting to OFF will make it so the stop button ends the workout on the first press immediately.
Maintenance
This will show the machine’s odometer readings since the lube message was last reset. Pressing enter will reset the lube message and the odometer.
Units
Sets the machine’s units to be in Miles or Kilometers. Setting to ENG will change units to Miles (ENG was probably meant to mean English but that’s technically incorrect as Imperial is the correct term). Setting it to MET will set it to metric units and use Kilometers.
Key Tone
Setting to ON will allow the machine to make audible beeps whenever buttons are pressed, for the workout countdown, and most other instances the machine would make a beep noise from the speakers. Setting to OFF mutes all beeps.
Security (aka Child Lock)
Can be set to ON or OFF. If set to ON, the machine will display CONSOLE LOCKED when booted or after a bit of inactivity. To unlock, you have to hold the Start and Enter buttons for a few seconds to unlock.
Exit

For All Touchscreen Treadmills:

Turn on the power switch of the machine if it isn’t already powered on.
Login to a personal account or choose the Guest profile.
Open the settings by pressing the gear icon in the top-left corner.
Rapidly tap the word “Settings” several times until the Engineering Menu appears.

This menu can be navigated by tapping the selections, tapping the back arrow at the top to go back a menu, and tapping the home button at the top to exit the engineering menu entirely.

The following options are normally present in this menu:
Engineering Mode
Units
Displays the current units in use. Can be changed between Miles and Kilometers. Units can also be changed in the normal settings menu and are not required to be changed here.
Max Incline
Displays the max incline the machine will be allowed to go. Do not change unless set incorrectly.
Wheel Size
The size of the roller’s diameter (not the pulley). Changing this will require a recalibration and will influence the speed the walking belt will move. Incorrect values input here will make the machine go a different speed compared to what it is set to on the screen. It is advised to not change this unless set incorrectly for the machine.
Max Speed
Displays the max speed the machine will be allowed to go. Do not change unless set incorrectly.
Min Speed
Displays the minimum speed the machine will be allowed to go. Do not change unless set incorrectly.
Calibration
The machine can be calibrated by pressing the Calibration button. Calibrating will lock in the values set for min speed, max speed, max incline, units, and wheel size.
Diagnostics
Will display a history of error codes.
A button will be available to clear error codes if any are present.
Machine Information
Grade Return
Setting to ON will make the machine reset its incline to 0 after booting and logging into a profile. Useful in the event of power loss. Setting to OFF will disable this functionality.
Beep Mode
Setting to ON will make the machine beep on each button press and during the workout countdown. Setting it to OFF will disable these beeps entirely.
Child Lock
Setting to ON will lock the console on boot or after enough inactivity. When the console is locked, the user must press and hold the START and STOP buttons for a few seconds until it unlocks. Setting to OFF will disable this functionality. This setting can also be changed in the normal settings menu.
Distance/Hour
Displays the cumulative time and distance the machine has been used for its lifetime. Separate from the stats used for the lube message.
Zeroing
Pressing this button will reset the distance/hours the machine has been used over its lifetime.
SW/FW/OS Version
Version info for the software, firmware, and OS that is currently installed in the console.
Maintenance
This menu has functionality meant for the manufacturer engineers to install apps and firmware. Nothing of use to the end user.
Lube Setup
Time
Shows the amount of hours of use that the machine will wait to pass before displaying the lube message. 90 hours is the recommended value to be set here.
Cumulative Time/Distance
The amount of time/distance that the machine has been used for since the last time the lube message has been reset.
Zeroing
Pressing this button will reset the time/distance used for the lube message.
Key Test
Note: You have to press all the buttons to exit the Key Test.
Each button press registered will make the machine beep and display what key was pressed.
