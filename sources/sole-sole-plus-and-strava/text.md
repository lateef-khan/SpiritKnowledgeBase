# Sole+ and Strava

Customers are able to link their Sole+ accounts with Strava to be able to sync their workout activity into Strava. Sole+ is able to sync various metrics such as elapsed time, average speed, max speed, calories burned, distance, elevation gain, and heart rate.

To get Strava to sync, a customer can go into any workout activity in Sole+ and hit the share button for Strava. [screenshot in original]

Doing so the first time will take you to a web browser to login with a Strava account to then link Sole+ to. You will see the following. Make sure to checkmark the box that says "Upload your activities" and then hit authorize. [screenshot in original]

If it provides a warning in red that activities will not contain heart rate data, the customer needs to enable a setting in Strava. The customer can go to Strava > Profile > Settings > Health Data and get the following screen to enable recording health data which will allow Sole+ to send heart rate history to Strava. [screenshot in original]

If everything has been set up correctly, workouts can now be synced to Strava. Each workout will have to be manually and individually synced using the share menu for the activity as seen earlier. The following is what a synced Strava workout would look like. [screenshot in original]
