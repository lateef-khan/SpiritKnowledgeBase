Sudden Stop on Treadmill

A sudden stop can be triggered by error codes popping up, loss of power to the machine, or if the machine stops sending power to the drive motor for whatever reason. Check the following as we need to verify if the cause is external, such as a house breaker popping, or if it’s internal to the machine, such as a damaged motor controller or any other possibility:

Ask if Console turned off completely or if they got an error code
If Console turned off completely, check the following
Ask about Lubrication
Whether machine has been properly lubricated or not, check Running Belt and Running Deck have been worn or damaged
If Running Belt and Running Deck are in good condition, move onto Step 2
If Running Belt or Running Deck are worn or damaged, replace Running Belt, Running Deck and Controller (Running Deck only has to be replaced if it is worn or damaged)
Ask if machine is plugged up directly into its own circuit on a non-GFCI outlet
If answer is yes, move onto Step 3
If answer is no, have customer plug up machine into its own circuit on a non-GFCI outlet and have them try running the machine again
If machine runs, machine should be fixed
If machine does not run, replace Motor Controller
Run Battery Test on Drive Motor
If Drive Motor passes Battery Test, move onto Step 4
If Drive Motor fails Battery Test, replace Drive Motor and Motor Controller
Ask if they have squeaking or knocking noises coming from the machine.
If answer is yes, asking if noise is coming from front or rear of the machine, depending on answer replaced Front Roller or Rear Roller (possibly both) and Motor Controller
If answer is no, replace Motor Controller
If customer received an error code, follow specific error code guide
