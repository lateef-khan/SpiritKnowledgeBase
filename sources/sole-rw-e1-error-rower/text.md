 E1 Error (Rower)
Software Issue
(If machine has been recently (re)assembled, replace Computer Cable)

This is an EEPROM error in the display board of the machine which is a software issue that could be caused by pinched computer cables or a damaged display board. Perform the following to see what needs to be replaced:

Ask if machine has been recently assembled, disassembled or moved
If answer is Yes, replace Computer Cable
If answer is No, replace Display Board
