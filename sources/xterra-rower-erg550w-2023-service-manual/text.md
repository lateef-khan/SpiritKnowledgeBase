Service                                                           1.Q&A
Problem                                                           Console can not display date   Rev.
Q:The console without data                                                                              1
A:When there is no display, check as below:
1.Check if you pull a complete stroke, at lease 1M from the
front strap wheel. Console set this regulation to protect
children playing this rowing machine not as right operation
guide.
2.Check if batteries have enough power? If not, change new
battery to try.
3.Check if wires are connected properly? If not, try to connect
all the wires again.                                                                                    2
4.Check if two magnets are right in mesh belt wheel? If not,
press a new magnet on hole of mesh belt wheel.
5.Check if wires have breakage? If yes, change new wire.
6.If all is OK, change a new console.

Q:The console can power on by itself
A: The control key gets stuck, change a new console.
                                                                                                        3
Q:The console without display
A: Check if batteries have enough power? If not, change new
battery to try. If still not OK, change a new console.
Q:The console can not get pulse data
A:Check if use a 5.0KHZ chest belt, you must wear chest belt
correctly.
