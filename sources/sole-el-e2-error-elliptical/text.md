E2 Error (Elliptical)
Gear Motor Issue
(If machine has been recently assembled, replace Computer Cable)

This error happens when the machine notices something is wrong with the gear motor or is unable to communicate with it. Check the following to see where the problem may lie:

Ask machine has been recently assembled, disassembled or moved
If answer is Yes, replace Computer Cable
If answer is No, replace Gear Motor if present
If Gear Motor was replaced and did not fix or the machine dIf E2 is still present, replace Display Board
oes not have a gear motor, replace Incline/Brake Controller
For machines with an Induction Brake if E2 is still present, replace Induction Brake

(If machine is older than 2016, it can be further diagnosed with a Pin Test)
If machine passes Pin Test, replace Display Board
If machine fails Pin Test, replace Computer Cables, Incline/Brake Controller and Gear Motor
