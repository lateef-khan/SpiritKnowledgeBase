NEW CONTROLLER & BRAKING
RESISTOR INSTALLATION GUIDE
Applicable Models: F63 / F65 / F80 / F83 / F85 (2026 Version)

Step 1: Disconnect all cables from the original controller. Using a Phillips screwdriver, remove the two
Ø 5 × 16 mm black Phillips pan head self-drilling screws, then remove the original controller.




Step 2: Using a power drill, drill two Ø 3.5 mm mounting holes on the right side of the main frame to install
the braking resistor mounting bracket. After drilling, be sure to remove all metal shavings from the
surrounding area.
Note: The first mounting hole should be drilled approximately 140 mm from the front end of the right-side
main frame tube. This drilling location applies to all applicable models.

Step 3:

         Install the braking resistor mounting bracket onto the main frame, and secure it with two Ø 5 × 16
          mm black Phillips pan head self-drilling screws.
         Install the braking resistor onto the mounting bracket, and secure it with two Ø 5 × 16 mm black
          Phillips pan head self-drilling screws.
         Install the new controller onto the main frame, and secure it with two Ø 5 × 16 mm black Phillips
          pan head self-drilling screws.
         Reconnect all cables to the new controller.
