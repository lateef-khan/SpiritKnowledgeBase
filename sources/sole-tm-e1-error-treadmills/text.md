E1 Error (Treadmills)
Software/Speed Sensor Issue
(If error comes up after machine has been assembled, replaced Computer Cables)

This error usually indicates an issue with registering the signal from the speed sensor and normally only happens during a calibration. Could be an issue with the speed sensor, the software processing the signal, or how the signal travels from the sensor to the controller to the console.

Either Speed Sensor is not aligned properly or damaged; or software issue
Make sure the speed sensor is aligned properly.
See if the LED light on the controller lights up every time the magnet passes by the sensor. Not every machine will have a light indicator, so it can only be used to confirm the sensor works.
If the sensor can be confirmed to be working, replace Console Display Board or Console Assembly
If there is no light indicator, replace the speed sensor and potentially replace the Console Display Board or Console Assembly
Last resort is to replace the motor controller if it’s not sending the speed sensor signal to the console
