Elliptical Level Changes by Itself
(If machine has been recently assembled, replace Computer Cable, Upper Resistance Wire and Lower Resistance/Incline Wire)

This can be caused by the machine thinking a button has been pressed. This can be the result of a shorted button wire or as buttons wear out and get stuck. This can also be caused by a malfunctioning incline/brake controller or gear motor. Perform the following to see where the issue resides:

Ask if machine has been recently assembled, disassembled or moved
If answer is Yes, replace Computer Cable, Upper Resistance Wire and Lower Resistance/Incline Wire
If answer is No, move on to Step 2
Ask if level changes on the console when it physically changes
If answer is Yes, disconnect Level handle switch from Console and try machine again
If machine does work, replace Upper Resistance Wire, Lower Resistance/Incline Wire, Handpulse Thin Film Label and Level Label
If machine does not work, replace Console Assembly
If answer is No, replace Incline/Brake Controller or Gear Motor
