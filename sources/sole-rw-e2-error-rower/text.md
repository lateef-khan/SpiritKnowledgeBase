 E2 Error (Rower)
Gear Motor Issue
(If machine has been recently assembled, replace Computer Cable)

This error happens when the machine notices something is wrong with the gear motor or is unable to communicate with it. Check the following to see where the problem may lie:

Ask machine has been recently assembled, disassembled or moved
If answer is Yes, replace Computer Cable
If answer is No, replace Gear Motor
If issue still present after replacing Computer Cable and Gear Motor, replace Display Board
