F85/F89/TT8 (585822, 589822, 588822) Start Button Grayed Out
If the Start button is grayed out, you can try to fix it pretty quick. Turn off the machine, remove the motor hood cover, and disconnect the potentiometer from the rear incline controller, then reconnect. Pic is attached for reference.

If this doesn’t work, replace the Rear Incline Controller.
