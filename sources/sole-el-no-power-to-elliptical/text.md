No Power to Elliptical
(If machine has recently been assembled, disassembled or moved; replace Computer Cable)

This can be caused by power stopping anywhere on the way to the console. Power has to pass through the power cord, through the fuse in the power socket/switch, to the incline adapter (sometimes called a filter or transformer) and incline/brake controller, then up to the display board. Check the following to see where power seems to be stopping at:

Ask if power cord is plugged up properly
If the answer is Yes, check the fuse that is between the power socket and switch. If the fuse is blown, have the customer go buy a new fuse. If the fuse is not blown, move on to the next step.
If the answer is “No”, try to plug up the power cord properly and try again.
If the console still makes a beeping noise when the switch is turned on, replace the display board or console assembly.
If the power cord is plugged up properly, the fuse is not blown and still no power, replace the Incline/Brake Controller and Incline Adapter (sometimes called a filter or transformer).
