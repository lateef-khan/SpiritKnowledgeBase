   GENERAL INFORMATION


CONSOLE:
   Interface that controls all functions of the Indoor Cycle.

LOWER CONTROLLER:
   The controller consists of the generator interface and switching power supply for the console and brake motor control circuitry.

BRAKE :
   The brake assembly consists of Neodymium magnets for creating Eddy current resistance, a gear motor to control resistance levels and
   closed-loop feedback encoder for precise brake position information to the console.

CONSOLE:
   The console contains the LED display, computer IC (MCU), memory, control circuitry and communications module for BLE (2 channels) and ANT+

5.3 MAINTENANCE MENU IN CONSOLE SOFTWARE

Maintenance Mode

IT IS NECESSARY FOR THE CONSOLE TO BE POWERED ON IN ORDER TO ACCESS MAINTENANCE
MODE. PEDALING ABOVE 30 RPM IS ALL THAT IS NEEDED TO ILLUMINATE CONSOLE. OR USE
OPTIONAL 9V POWER ADAPTER TO POWER CONSOLE WITHOUT PEDALING. (Adapter available as a
service part through your Spirit distributor).


MAINTENANCE MODE offers following menu:
---KEY TEST
---DISPLAY TEST
---ODOMETER
---UNITS - ENGLISH/METRIC
---BRAKE TEST
---RPM SENSOR
---UPDATE SOFTWARE
---LED BRIGHTNESS
---BIKE ID
---AUTO DECTECT HR
---HR ZONE
---DEMO MODE
---CALIBRATION


ENTERING MAINTENANCE MODE
- Pedal or plug in 9v adapter to power on the console, enter MAINTENANCE
  MODE and change the settings.
- Simultaneously press and hold + KEY, - KEY and PLAY KEY on Forward Control Pad for 3 seconds.
- Console displays MAINTENANCE MODE.


NOTE: If console displays CONSOLE RESET, instead of MAINTENANCE MODE, then ALL 3 keys on Forward
Control Pad were possibly not pressed and held simultaneously or for enough time; attempt action again.

Maintenance Mode - Settings
KEY TEST
- Purpose of this setting is to ensure that each of the keys function properly.
   -Press PLAY KEY to enter setting.
   - Follow the instruction from console to PRESS ALL KEYS.
   -There are 5 keys that control the bike:
        o Forward Control Panel: + KEY, - KEY and PLAY KEY.
        o Handlebar Ends: Right Side + KEY, Left Side – KEY.
   -TEST PASSED displays if all Keys are functioning properly.
   -System will return to menu screen.
   -Press + KEY for next option or RESET CONSOLE to exit MAINTENANCE MODE.


DISPLAY TEST
- Purpose of this setting is to ensure that each of the 23 LED display modules are fully functional.
   -Press PLAY KEY to enter setting.
   -All sections of each of the 23 LEDs will illuminate.
   -Press PLAY KEY to turn off.
   -Press PLAY KEY again.
       o All LEDs will illuminate the #1, then automatically cycle from #1–9 and A-Z.
       o LED color lights for HR ZONE and POWER ZONE cycle through colors.
   -Display will turn off then will return to menu screen.
   -Press + KEY for next screen or RESET CONSOLE to exit MAINTENANCE MODE.



ODOMETER
- The Odometer is used to track the number of hours the bike has been in use.
   -System will automatically display ODOMETER HRS.
   -HOLD PLAY TO RESET appears.
   -To Reset Odometer, press and hold PLAY KEY.
      o Odometer is useful to keep track of bike usage for routine maintenance considerations.
                                                           40                                   Service Manual
        o Odometer is useful when considering moving bikes around in studio to even out usage.
    -System will revert to setting screen.
    -Press + KEY for next screen or RESET CONSOLE to exit MAINTENANCE MODE.


UNITS
 - Purpose of this setting is to change from ENGLISH (Imperial) to METRIC distance calculation.
    -Press PLAY KEY to change setting.
    -Default setting is ENGLISH.
        o For the MILES FOR LIVES program, distance goal and SPD AVG and SPD PEAK in Workout Results
        will Only display in ENGLISH.
    -Press + KEY for next screen or RESET CONSOLE to exit MAINTENANCE MODE.


BRAKE TEST
 - Purpose of this setting is to test the magnetic resistance system.
    -Press PLAY KEY to enter BRAKE TEST.
    -MOTOR TEST AUTO
        o Press PLAY KEY to Auto-run the motor in a continuous loop from L-1 to L-20 and back to L-1.
        o Press PLAY KEY to end, return to BRAKE TEST.
    -MOTOR TEST MANUAL
        o Use + KEY and -KEY to set the target, press PLAY KEY for moving the brake to the target position and
        press again for back to zero position.
        o Hold PLAY KEY and + KEY to reset the console and leave the test.
        o ENCODER displays. This shows the target ENCODER count, or brake position digital value, and is an
        important tool to know whether the encoder is functioning properly.
        o Upper Right displays LIMIT SENSOR CONDITION.
               1 = HOME When 1 is displayed the brake is at the home position.
               2 = ACTIVE RANGE When 2 is displayed the brake is between home and end position.
               3 = END When 3 is displayed the brake is at the end limit sensor.
         o Lower display displays Encoder Set Value. When you press a key to move the motor this is the
         value/position that the brake should move to. The Encoder is the actual position the brake reaches.
    -LIMIT SENSOR
        o Use + KEY and -KEY to move the brake. Top left shows the home position sensor, top right shows the
        end limit sensor and bottom show the encoder counts.
        o Hold PLAY KEY to ends.

CALIBRATION
Calibration contains sensitive settings of the braking system. Making changes will affect the
resistance curve.
      - When changing the console to a new one make sure to enter the calibration offset number from the old
console into the new one. The calibration number is written on the console mounting bracket of the original
console. This number should now be written or recorded on the new console for future reference.
The offset calibration number is determined in the factory on a dynamometer to compensate for standard
tolerances between frames.
- At the Calibration prompt press Play. Console will now show the setting of the calibration offset number.
This number is the encoder count from when the brake moves from the home position sensor to the Level 1
position.
Example display: The top number 80 is the actual encoder count. The bottom number 80 is the actual offset
adjustment number. These two numbers should match closely but could be off by a few counts up or down,
this is normal. The number 2 indicates that the sensor flag is in between the home position sensor and the
end of travel sensor. If the number 1 is shown it means the flag is at the home position sensor. If it is 3 then
the flag is at the end of travel sensor.

6.1 Console software update
1. Download the .zip file and extract the two software update files. Copy the 2 update software files to
   the root directory of a blank USB Disk. The USB disk must be empty with no other files or folders.
2. Access the USB connector at bottom of console & plug in USB device.




3. Turn on the console and enter MAINTENANCE mode. Go to UPDATE SOFTWARE then press
   PLAY key.




4. Press +/- key to change Bootloader to ON and press PLAY key.




5. Press and hold PLAY & + key to reset console. The console shows SEARCH UPDATE after reset.
