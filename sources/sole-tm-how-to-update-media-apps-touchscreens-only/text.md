How to Update Media Apps (Touchscreens Only)

Make sure you are connected to Wifi
Once connected to Wifi, you should automatically get notifications for updates
Tap “Gear” icon to open Settings menu
Tap option “Media Apps”
You will see a list of the media apps. Each one that needs to be update will have a red “Update” button by it.
Tap the red “Update”
Update will take a few moments and console will reset
