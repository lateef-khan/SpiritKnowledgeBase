No Power to Treadmill
(If machine has been recently assembled, and you have check if the Power Cord is plugged up properly and On/Off Switch is flipped ON, replace Computer Cables)

No power can mean a lot of things as to where power may be stopping. The best way to determine where the problem lies is to trace power starting where the machine plugs in all the way to the motor controller and then up to the console. Perform the following to see what part may be the culprit:

Check that Power Cord is plugged in properly and On/Off Switch is flipped ON
If answer is Yes, ask if On/Off Switch lights up. If an ST90, treat as if the power switch is not illuminated since it does not have a light. If an ST90 and out of the box, just get computer cables since they likely were pinched if everything is plugged up correctly.
If answer is Yes, have customer remove Motor Hood Cover and see if there are light lit up on the Motor Controller
If the answer is Yes, ask if machine has been assembled, disassembled or moved recently
If the answer is Yes, replace Computer Cables. If answer is No, make sure all wires are plugged up into the Motor Controller
If answer is No, replace Motor Controller
If wires are all plugged up, have customer check voltage and replace necessary parts (details below)
If wires are not all plugged up, customer plugs them up and light comes on, machine should be working
If wires are not all plugged up, customer plugs them in and light does not come on, have customer check voltage and replace necessary parts (details below)
If answer is No, ask customer if machine is plugged up directly into its own circuit on a non-GFCI outlet
If answer is Yes, ask if Breaker on machine is tripped
If answer is Yes, have customer reset Breaker
If machine is working now, no further diagnosis
If machine is still not working, have customer check voltage replace necessary parts (details below)
If answer is no, have customer check voltage and replace necessary parts (details below)
If answer is No, have customer plug up Power Cord properly and flip On/Off Switch ON
If machine works, no further diagnosis is needed
If machine does not work, follow instructions checking voltage and replace necessary parts (details below)

Voltage Test
With a multimeter:

Test power at the outlet. If power is not ~120V, an electrician will need to check out the outlet as the outlet is the issue.
Plug the Power Cord into the outlet, but not into the machine. If power through Power Cord is not ~120V, replace Power Cord.
With the machine unplugged, disconnect the White and Black Connecting Wires from On/Off Switch (or Filter if the machine has one) that plug into the Motor Controller. Connect multimeter probes to the wires you just unplugged. Plug up Power Cord into outlet and machine’s Power Socket. Turn ON the On/Off Switch.
If power is ~120V, replace Motor Controller
If power is not ~120V, replace White and Black Connecting Wires, On/Off Switch, Breaker, and Power Socket
