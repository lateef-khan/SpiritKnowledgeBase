4-2 Operation
 4-2-1 IDLE MODE

 The main window will display the name of each program cyclically, and at the same time display profile of the corresponding program in the dot window.

 4-2-2 QUICK START

 a) Press START key will enter MANUAL MODE when the console in the IDLE MODE. The workout time will count from “00:00”, all other data will count from “0”
 and resistance level will start from level 1.
 b) Use quick select key(MANUAL, HILL, FATBURN, CARDIO, STRENGTH, HIIT) to select one of the programs then press START key to enter the program. (The
 parameters will be the default value.)

 4-2-3 PAUSE MODE

 a) Press STOP key in the workout will enter PAUSE MODE, all display windows will record the workout value and resistance level will set to level 1.
 b) When press START key to start workout, the resistance level will return to the level the user set before the pause.

 4-2-4 DISPLAY MODE

 a) When there is no RPM or Pulse exceeds 30min, the console will enter the SLEEP MODE.
 b) The LCD will stop showing and turn off the backlight when the console enter the SLEEP MODE. Press any key can wake up the console and enter the IDLE
 MODE.
 c) When the console in the SLEEP MODE, the resistance level will set to level 1 and turn off the fan.

 4-2-5 END MODE

 a) The console will beep three times when the workout is finished. The main window will show “WORKOUT SUMMARY” and the workout value, if the user press
 START key, the console will start a workout with the same setting again.
 b) Press STOP key in END MODE will enter IDLE MODE.


  Dyaco International Inc.                                                                                                                                   14
 4-2-6 RESET MODE

 Press and hold the STOP key exceeds 3sec when in IDLE MODE, the console will reset the system.



4-3 Functions
 4-3-1 TIME

 TIME is either COUNT UP or COUNT DOWN. System preset is COUNT UP; if user sets the time then timer will COUNT DOWN. DISPLAY range is 0:00 to 99:99.
 WORK range is 0:00 to 99:59(min：sec). COUNT DOWN setup range is 10:00 to 99:00. When TIME is set, the timer will COUNT DOWN until zero.

 4-3-2 TOTAL STEPS

 Display the current distance in steps. DISPLAY range is 0 to 99999. WORK range is 0 to 99999.

 4-3-3 CALORIES

 Displays the cumulative calories burned at any given time during your workout. DISPLAY range is 0 to 9999. WORK range is 0 to 9999.

 4-3-4 LEVEL

 Display the current level position. DISPLAY range is 0 to 99. WORK range is 1 to 20.

 4-3-5 PULSE

 Displays the heart rate beat by using receiver. When use receiver, a chest belt must be worn. DISPLAY range is 0 to 999. WORK range is 40 to 220 BPM.

 4-3-6 VIRTICAL

 Displays the height in FT/MTR. DISPLAY range is 0 to 99999.WORK range is 0 to 99999.

7-4-1 TENSION MOTOR OPERATION

      Console

      1. Key signal travels to the display. The main program IC then sends a command signal to the drive board.
      2. Console directly controls the motor. Level UP:+4~5VDC;Level DOWN:- 4~5VDC



7-4-2 TENSION MOTOR TROUBLESHOOTING

      Console

      1. If the key beeps when pressed, assume that the signal was sent.
      2. Inspect console power output to the motor. Press the Level Up is +4~5VDC;Level DOWN is -4~5VDC.If there is power to the motor, but the
         motor does not operate, replace it. If there is no power output, inspect whether the transformer has power.

      Data cable

      Inspect the cable and connections.




   Dyaco International Inc.                                                                                                                       30
7-4-3 TENSION MOTOR VOLTAGE TEST PROCEDURE

1.   Put multi-meter to the 20VDC setting. Place probes on the motor control wire (Red probe in palm wire, Black probe in black wire) on the drive board.
2.   Turn on unit power. The display lights up.
3.   Press LEVEL UP. Normal reading: +5~6VDC.Motor operates. Resistance increases.
4.   Press LEVEL DOWN. Normal reading: -5~6VDC.Motor operates. Resistance decreases.
5.   If there is no voltage, check the transformer, if there is no output, replace it.

2. Display Test (Tests all the display functions)
3.   Function
      -Units (Sets the display to read out in English or Metric display measurements)
           -Pause mode (have five minutes)
           -Odometer Reset (Resets the odometer)

           -Beep sound(Control Beep)
           -CAB Protocol or CSAFE Protocol
4.   Service
            -Motor test
            -Csafe test
            -Sensor test(Test the speed sensor function)
