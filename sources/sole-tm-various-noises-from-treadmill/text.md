Various Noises From Treadmill: 

Rubbing Noise
Check if the running belt is tracked properly to the center.
If the running belt is tracked properly, have the customer remove Motor Hood Cover and see if the drive belt is tracked properly or damaged. If the drive belt is not tracked or is damaged, replace the drive belt.
If the running belt is not tracked properly, walk the customer through running belt tracking. Running Belt tracking instructions are in the Owner’s Manual

Clicking/Clunking/Knocking/Squeaking Noises
Ask customer where noise is coming from and if the noise is present all the time or only while someone is on the machine
If noise is coming from the front or rear of the machine all the time, replace either Front Roller or Rear Roller (possibly both)
If noise is coming from directly under the customer only while they are on the machine, replace deck cushions. You can also ask if it seems like the noise is only coming from the left or right side. That will help you determine how many deck cushions to send.
If noise is only coming from the front of the machine while the customer is on it (possibly making noise per footstep), have the customer make sure all hardware is tight. If it is, replace nylon washers and deck cushions.
