  SPIRIT FITNESS POWER REQUIREMENTS*
TREADMILLS
All Spirit Fitness treadmills require power to operate regardless of console configuration.
Circuits should be dedicated to each machine and require a non-looped (isolated) ground.

• A dedicated circuit for each unit requires each outlet does not have anything else operating on the same circuit.

• A non-looped (isolated) ground requires that each circuit has an individual neutral/ground connection from it and terminating

 at an approved earth ground.
• The power cord on treadmills uses a NEMA 5-20P plug (except for CT800 and XT685 which can use the            NEMA 5-15P).
• The treadmill receptacle must be a NEMA 5-20R receptacle (except for CT800 and XT685 which can use the NEMA 5-15R).
