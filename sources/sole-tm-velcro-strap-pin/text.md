Velcro Strap & Pin

If Velcro Strap or the Pin is removed before the running deck is set in place, the gas cylinder will expand and could possibly hurt somebody. Be sure to ask if everyone is ok.

Set up the deck like it would normally be when you fold up the deck, where the deck is up in the air.
Depending on the model, pull the lever for the lock or kick the cylinder to unlock it
Gravity will bring the deck back down to the floor.
Restrap or reinsert the Pin until the machine is fully assembled.

If the pin is not taken out before the machine is inclined, that can hurt the controller and the frame. If they left it in and started the incline. Have them turn off the power and turn it back on. While it is booting up, the incline will return back to 0 on its own. Then you should be able to remove the pin.
