Part Name             Part Description

Console               Interface that controls all functions of the treadmill.

Safety Key            To fits on the Console that activate all functions. If no safety key, console can not be controlled.

Main Controller       The circuit board consist of the DC power supply for console、incline driver and DC motor driver, link the console to output
                      appropriate voltages for motor that control the treadmill functions.

Treadmill Motor       This is a variable speed for DC motor. To control the0-90(120VAC) or 0 –180(230VAC) voltages on the main controller, it can
                      to increase or decrease speed of running belt.



GENERAL INFORMATION

Console               Includes button control and 10-inch touch screen display.

Main controller       Include power supply, Motor driver control circuit and Incline control circuit.

Treadmill motor       DC motor with variable speed range 0-90 or (0-180) volt.
                      Have three wires red, black and green.
                      If there is DC voltage on the Red (white) wire (M+) the treadmill motor will turn clockwise.
                      If there is DC voltage on the Black wire (M-) the treadmill motor will turn counter-clockwise.
                      The higher the voltage the faster the motor turns. The green wire is ground.

Incline Motor         This is a 120 volt (230 volt) AC motor.
                      Requires four wire connection: red, black, white and green.
                      Has one 3 pins cable for position sensor.
                      If there is AC voltage on the Red wire (UP), the incline motor will increase the incline.
                      If there is AC voltage on the Black wire (DOWN), the incline motor will decrease the incline.
                      The White wire (COM) is neutral. The green/yellow wire is grounding wire.

4-2 Operation
 4-2-1 OFF MODE

 If treadmill is turned on, when user does not insert the SAFETY KEY on the console, the console display will show “PLEASE REPLACE THE SAFET KEY” , but console
 does not work.

 4-2-2 READY Mode

 When the treadmill is turned on and SAFETY KEY is inserted in console, the message window will show “press start workout”.

 4-2-3 RUN Mode

 In RUN Mode, pressing the “STOP” button and removing the SAFETY KEY will cause the treadmill stop instantly and enter OFF Mode.



4-3 Functions
 4-3-1 SPEED

 Display the current speed in Kilometer or Mile per hour.
 DISPLAY range is 0.0 MP/H or KM/H.
 WORK range is 0.6 to 12.0 MPH (1.0 to 18.0. KMH)
 Press FAST or SLOW to adjust speed, each increment and decrement is 0.1 KM/H (MPH).

 4-3-2 INCLINE

 Display the incline position from 0 to 15.
 DISPLAY range is 0.
 WORK range is 0 to 15.

  Dyaco International Inc.                                                                                                                                        14
INCLINE preset value is 0 to 15.
Press UP or DOWN to adjust incline, each increment and decrement is 1.

4-3-3 TIME

Time can count up or count down. System preset is count up; if user sets the time then timer is count down.
DISPLAY range is 00:00.
WORK range is 0:00 to 99:59.
Count up setup range is 10:00 to 99:00.
When TIME is set, the count will go to zero.
In RUN Mode, press “STOP” button to save value of time and enter “RUN Mode” again that value will continue count up time.

4-3-4 DISTANCE

Display the current distance in kilometer or Mile.
DISPLAY range is 0.00 to 99.99.
WORK range is 0.00 to 99.99.

4-3-5 CALORIES

Displays the cumulative calories burned at any given time during your workout.
DISPLAY range is 0.0.
WORK range is 0.0 to 999.

4-3-6 PULSE

Displays the heart rate beat by using hand pulse or receiver. When use receiver, a chest belt must be worn.
DISPLAY range is 0.
WORK range is 40 to 220.
In RUN Mode, if the treadmill doesn’t have a signal for 8 seconds then display value will become “ 0 ”.

WORK range is 00.00 to 99.99.

   Checking the speed sensor

   Step 1: Remove the motor cover hood.
   Step 2: The speed sensor is located on the left side of the frame, right next to the front roller pulley (the pulley will have a belt around it that also
   goes to the motor). The speed sensor is small and black with a wire connected to it.
   Step 3: Make sure the sensor is as close as possible to the pulley without touching it. You will see a magnet on the face of the pulley; make sure the
   sensor is aligned with the magnet. There is a screw that holds the sensor in place that needs to be loosened to adjust the sensor. Re-tighten the
   screw when finished.

   So, for calibrating speed, technician will need to bring a speed sensor (w/its cable) then install nearby the motor flywheel to do the calibration as
