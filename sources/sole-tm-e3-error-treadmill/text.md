E3 Error (Treadmill)
Incline Error
(Shows as E2 on machines prior to 2016)
(If machine has been recently (re)assembled AND does not pass calibration, replace Computer Cables)

This error can pop up when there’s a problem with the incline motor or with a motor controller, but can be a false positive for brand new machines or machines that parts have recently been replaced in. Always make sure to run a calibration and check for behavior as a calibration can fix the error for good. If this error showed up after replacing a motor controller or console/display board, there’s a good chance the machine just needs to be calibrated as those parts always require a calibration when installed so the machine knows how to operate with the new parts. Perform the following steps to see where the incline error may be stemming from:

Run a calibration
If calibration passes, press the “Start” button to quick start the machine and press incline buttons.
If machine inclines and declines, machine is fixed
If machine still pulls up an Incline Error, move on to the next point
If calibration fails or incline error is still present after calibrating, ask if the incline motor moved at all:
If the answer is Yes, something about the signal going back up to the Console is being interrupted.
If machine is from 2016 or newer
Replace Motor Controller or Display Board
If machine is older than 2016, run a Pin Test
If machine passes Pin Test, replace Upper Computer Cable and Display Board
If machine fails Pin Test, replace Middle Computer Cable, Lower Computer Cable and Motor Controller
If the answer is No, something about the signal going down to the Motor Controller is being interrupted
If machine is from 2016 or newer
Replace Motor Controller or Incline Motor
If machine is older than 2016, run a Pin Test (Most of the time, this test is unnecessary. Usually it’s safe to go with the motor controller.)
If machine passes Pin Test, replace Upper Computer Cable and Display Board
If machine fails Pin Test, replace Middle Computer Cable, Lower Computer Cable and Motor Controller
If replacing the motor controller, ask about Lubrication (Question: How often do you lubricate?)
Whether the machine has been properly lubricated or not, check Running Belt and Running Deck have been worn or damaged (Slide hand between running belt and deck palm up first. See if texture of running belt is gone in the middle. Palm down, see if running deck is damaged.)
If Running Belt and Running Deck are in good condition, move on to Step 3
If Running Belt or Running Deck are worn or damaged, replace Running Belt, Running Deck (Running Deck only has to be replaced if it is worn or damaged), move on to step 3
If replacing the motor controller, ask if they have squeaking or knocking noises coming from the machine.
If the answer is yes, ask if the noise  is coming from the front or rear of the machine. Depending on their answer, replace the Front Roller or Rear Roller (possibly both)
