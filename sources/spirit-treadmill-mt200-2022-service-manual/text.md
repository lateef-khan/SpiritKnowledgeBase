    4.2.1 Maintenance Mode
    a. Press and hold the Start, Stop and Enter key at the same time, until the display shows “ENGINEERING MODE” (it may say maintenance mode,
       depending on version). Press the Enter key. You can now scroll through the menu using the up and down keys. Use the Enter key to enter into
       the selected test/function. Use the Stop key to return to previous menu selection. The menu selections are:
    b. Key Test – Press enter and the display shows „Press all keys‟. Press each key to verify it is functioning correctly. Each key press produces a
       beep sound and a number will show on the display. If you press a key and there is no beep and no number displayed then that key has
       malfunctioned. When all keys have been pressed the display will show „Passed‟.
    c. Display test - Lights all LED lights sequentially for visual checking.
    d. Functions
            i. Sleep - Turns SLEEP MODE ON or OFF. When set to „off‟ the console power is always on. When set to „on‟ the console will go to sleep
               after 30 minutes of inactivity.
           ii. Pause - Turns PAUSE MODE ON or OFF. When set to „on‟ the Pause lasts 30 minutes then the console returns to the idle mode. When
               set to „off‟ the pause lasts indefinitely.
          iii. Odometer reset - Reset odometer readings
          iv. Units - Set the measurement values to display in ENGLISH or METRIC
           v. Grade Return (GS Mode) - Turns GS MODE ON or OFF. Turning the GS mode „on‟ will return the elevation to lowest setting when pause
              is pressed. When set to „off‟ the elevation will remain at the set angle when the pause is pressed.
          vi. Beep – Turns the speaker (beep sound) on or off.
         vii. Service Mode:

                            motor stops when key is released. The motor is allowed to move until limit switch activated.

             off the brake coil is actually energized and there will be 18vdc at the two brake wires. When ON there is no power to the coil.

     4.2.3 Error Codes: Messages, Cause and Solution

           Error Codes
           E1 Over Current: The Inverter detects an abnormal increase in output current.
                   1) Check wiring connections to motor for possible short circuit.
                   2) Check the deck/belt for high friction or worn out.
                   3) Check that the Brake is released when Motor is moving.
                  4) Replace Inverter or Motor.
           E2 Over-Voltage: The DC voltage inside Inverter exceeded the maximum allowable value.
                   1) Check the AC line voltage.
                   2) Replace Inverter.
          E3 Over-Voltage, Decel: The DC voltage inside Inverter exceeded the maximum allowable value during deceleration.
                 1) Check the AC line voltage.
                   2) Replace Inverter.
           E4 Ground Fault: The output terminal(s) of Inverter is grounded.
                  1) Check the motor wire connections between the Inverter and Motor for possible short circuits.
                      Also check if wires are shorted to ground.
                   2) Replace Inverter.
           E5 IGBT Fault: IGBT module of Inverter failure.
                   1) Check the wiring connections between the Inverter and Motor.
                   2) Disconnect the cables between the Inverter and Motor, and run again. Replace the Inverter if the error code is still displayed.
           E6 Drive Overload: The Inverter detects excessive output current.
                   1) Check the deck/belt for high friction or worn out.
                   2) Check that the Brake is released when Motor is moving.
                   3) Replace Inverter.
                   4) Replace Motor.
           E7 Thermal Overload: Motor overloaded.

                   5. Troubleshooting and Problem solving (See wiring diagram in the back of this manual for detailed wiring information)

1    No power, console doesn’t light.
     1.1 Make sure there is no problem with AC Power.




     1.2 Check the switch and both circuit breakers (one located on the back panel, the other is inside motor cover). Press the circuit breaker back if it popped
          out and make sure the power cord is plugged in properly. Go to next step if there is still no power on the treadmill.
17
     1.3 Make sure AC power goes into the Motor Drive. The red light on the Drive lights up when there is AC power and use the meter to check the voltage is
         correct. Replace the Drive if the input voltage is correct and the red LED doesn't light up. If there is no AC power at the motor drive, check voltage at
          both sides of the AC filter. If no AC at the input of the filter then the circuit breakers or AC input module may be bad. Go to next step if everything is
          normal but console still doesn't turn on.

     1.4 Measure between pin 4 (Vin) and pin 12 (Gnd.) of the 12 pin connecter at the back of the console (measure with the console disconnected from the 12
         pin connector). Replace the console if 12V DC was measured. Go to next step if there is no voltage.




     1.5 Measure the red 12 pin connector on the low control board between pin 4 and pin 12 as below. Replace the 12 pin cable from low control to the console
          if there is 12V DC measured here but not at the console. Replace the Drive if there is no voltage here but the AC voltage to the drive is ok.
