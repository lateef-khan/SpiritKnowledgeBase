Problem       1. Slippage and falling off of Belt          Rev
Solution：
1. If Belt (40) slips, follow procedure 3 to move

   Idler Axle (74)   downward by turning 1/4" ×

   3"L Hex Head Bolt (69) counterclockwise and

   tighten the Belt (40) until belt tension reads

   700~750 Newton.

2. If Belt (40) falls off, move Idler Axle (74)

   upward by turning 1/4" × 3"L Hex Head Bolt

   (69) clockwise and resume Belt (40) an adjust

   Belt tension. While adjusting, make sure 6203

   Bearing (65), Drive Pulley (41) and Hub

   Pulley (35) align well in a straight line. Run

   the belt for 5 minutes and resume Outer Chain

   Cover (60) when there is no problem.

Problem         4.      Display Blank or No Speed Displayed   Rev
Solution：
1. Make sure there is power for the unit.

2. Make sure Speed Sensor and magnet are well

   installed.

3. Verify input/output of transmitter signal.

4. If everything is normal, change the transmitter

   position. Some location may cause the signal

   harder to receive.
