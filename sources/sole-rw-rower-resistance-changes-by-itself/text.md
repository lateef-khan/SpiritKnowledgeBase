       Rower Resistance Changes by Itself
(If machine has been recently (re)assembled, replace Computer Cable)

This could be caused by stuck buttons, a computer error, or by the brake mechanism malfunctioning. Check the following:

Ask if machine has been recently assembled, disassembled or moved
If answer is Yes, replace Computer Cable
If answer is No, move on to step 2
Ask if level changes on console when it physically changes
If answer is Yes, remove battery from handle switch and try machine again
If machine works, replace Handle Assembly
If machine does not work, replace Console
If answer is No, replace Gear Motor
