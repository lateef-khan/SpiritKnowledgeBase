No Resistance or Too Much Resistance on Ellipticals, Bikes or Rowers

No Resistance
Ask if they are getting an E2 Error code
If answer is Yes, check E2 Error guide for Ellipticals, Bikes or Rowers
If answer is No, move onto next step
Ask if machine has been assembled, disassembled or moved
If answer is Yes, replaced Computer Cable (If it is an Elliptical, also replace Upper Resistance Wire and Lower Resistance/Incline Wire)
If answer is No, move onto next step
Ask if level changes on Console
If answer is Yes, replace Gear Motor
If answer is No, replace Console Assembly (If machine is an Elliptical, disconnect Level handle wire from Console and try again. If machine works, replace Upper Resistance Wire, Lower Resistance/Incline Wire, Handpulse Thin Film Label and Level Label. If machine does not work, replace Console Assembly

Resistance is too high and doesn’t change
Ask if level on console changes when they press the buttons
If answer is Yes, replace Steel Cable
If answer is No, replace Console Assembly (If machine is an Elliptical, disconnect Level handle wire from Console and try again. If machine works, replace Upper Resistance Wire, Lower Resistance/Incline Wire, Handpulse Thin Film Label and Level Label. If machine does not work, replace Console Assembly
