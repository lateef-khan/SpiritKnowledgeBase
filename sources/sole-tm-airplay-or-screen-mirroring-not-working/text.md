# Airplay or Screen Mirroring Not Working

The touchscreen machines can allow a modern enough mobile device to share its screen using Airplay on Apple devices or through the SOLE Mirroring app on Android devices. Perform the following if screen mirroring is not working for the respective device types:

Note: Copyright protected content will not be able to be mirrored and may display a black, green, or garbled screen or may refuse to even try to screen mirror.

## Apple Devices

1. Make sure both the machine and the Apple device are connected to the same network.
2. Ensure that both the Apple device and machine are fully up to date with no pending software updates.
3. Open the Control Center by swiping down from the top-right corner of the screen.
4. Find and tap the AirPlay screen mirror icon. [screenshot in original]
5. Select the machine's name in the list that pops up.
6. The device should now be screen mirroring to the machine.

If the Apple device wants a pin to input when connecting, you may need to go to the device's settings, set 'Automatically AirPlay' to 'Never,' and turn off 'AirPlay Receiver' in the AirPlay & Continuity section as seen in the picture below. [screenshot in original]

Note: If the Apple device asks for a passcode and the above does not fix, the device will not be able to connect. This is likely because the phone is being managed by a Mobile Device Management (MDM) app required by their workplace which ends up enforcing stronger security practices. Our machines do not take this into account and will not display a pin to input on the Apple device and there is no workaround besides using a different device not managed by an MDM.

## Android Devices

1. Install the SOLE Mirroring app made by Sunrise Technology Co. from the Google Play Store (Not to be confused with the SOLE+ app).
2. Make sure that the machine and the Android device are connected to the same network.
3. Make sure the machine and app is fully up to date with no pending software updates.
4. Grant the location permission if prompted. Precise location must be used instead of approximate location as this is how Android lets the app see the wifi network name and nearby devices.
5. Tap the "Start Searching" button in the app and select the machine's name.
6. The device should now be screen mirroring to the machine.

## If customer using mesh router

- Turn on 802.11r fast roam (Google nest has this on by default)
- Disable AP Isolation
