              XTERRA APP Q & A
Compatibility
iPhone 4S, 5, 5C, 5S,6 / 6 plus,6s / 6s plus,7 /7 plus above. iPad 3 above. iTouch 5th
gen above. iOS 7.0 above.
Android 4.3+ with Bluetooth 4.0 BLE required. The device uses BLE Bluetooth
technology.


Connect issue：can’t connect, search no device list,
break connect
Please make sure the following points:
     1. System JB (Jailbreaking) from your phones/tablets?
     2. Check the Bluetooth is ON from your phones/tablets?
     3. By interference from a lot of Wi-Fi environment use.
     4. Have opened more than one device with a Bluetooth device?
     5. The Bluetooth device is damaged.


UI font exception
1. Is there a set font increase from system?
2. Make sure that your device’s software is update.


Calendar week display non-set language from app
Calendar week of the visit is mainly to system language, if set to English, appear in
English, set language different from app.


First user can be connected, but the second user
is disconnected.
1. Please first user connect app Bluetooth disconnection, the second user can use.
   If not connect, please power off the equipment to reopen.
2. Please reboot your phones/tablets.
No record in the calendar data when finish
workout
1. When workout and connect app, whether the Bluetooth symbol always show on
   the console. Power outage?
2. Continuous press STOP button too fast, cause data loss transmitting to
   phones/tablets from the console. Make sure your phones/tablets shows
   ‘’Congratulations, you have completed your workout. Press STOP to exit the
   program.’’ Which mean your phones/tablets has received the data from console.




No synced on the INCLINE function (number) on
the app
1. Machine need re-calibration.
2. The incline motor failure.


App is connect, app does no function when you
press START of the console, the machine doesn’t
run
The machine issue, please provide error code from the console and connect service
unit.
