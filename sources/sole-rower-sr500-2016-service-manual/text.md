1. stroke/min:
     s/m value shows the equivalent strokes per minute.


  2. Time:
     2.1 It shows the time.
     2.2 Range of time: 00：00~99：59(minute: second)。
     2.3 The time is accumulated for each workout mode.
     2.4 When time is set to count down, it shows the time remaining.

  3. Distance：
     3.1 The distance range is 0~9999 and switches to the format of 1X.XX when the value is over 9999.
     3.2 The distance will be accumulated for each workout mode.
     3.3 When the distance is set to count down, it shows the remaining distance.
  4. Heart Rate:
     4.1 The heart rate range is 40~220 bpm。
     4.2 When the heart rate signal is detected, the small dot at lower right corner of the heart rate window will be blinking together with heart rate value
showing.
     4.3 When there is no heart rate signal detected, the heart rate window shows nothing.


  5. Calories:
     5.1 The calorie window shows the value of calorie dissipated.
     5.1 The calorie range is 0~999.
  6. Watts: The Watts window shows Watt value for each stroke.
     6.1 The Watt range is 0~2000
     6.2 When the numbers over 999 to four digits, the display would use point to show digit in thousands. E.g. 1000 shows 1.00, 1009 shows 1.01, 1240 shows
       1.20, 1250 shows 1.25, 2000 shows 2.00, etc.
  7. LEVEL:
     7.1 The level window shows the current resistance level.
     7.2 The level range is 1~16
     7.3 Level 1 and 2 would light the first dot, level 3 and 4 would light the second dot, etc.

III. Key button Function:
    1.1 Any valid key button pressed will generate a beep sound.
    1.2 When in power off mode, pressing any key button turns on the console.


  2. MODE Key：
    2.1 Under idle mode, pressing “MODE” key each time switches the workout mode with the following sequence:
       MANUAL →DISTANCE         →TIME →CALORIES →20/10 INTERVAL →10/20 INTERVAL→CUSTOM INTERVAL→
        Fat Burn → Cardio → Strength → Game
     2.2 The default workout mode after turning on the unit is Manual mode.
     2.3 To choose the target workout mode, when the matrix window shows the desired workout pattern and parameter window value to be set will be
blinking each
     second.
3. Up Key：
 3.1 Under the setting mode of the target workout, the parameter is will be counted up.
 3.2 The value increases one increment when “UP” key is pressed once.


4. Down Key：
 4.1 Under the setting mode of the target workout, the parameter is will be counted down.
 4.2 The value decreases one increment when “DOWN” key is pressed once.


5. Start/Stop Key：
 5.1 Under idle mode, pressing Start/Stop key button enters Manual workout mode.
 5.2 To confirm the value the window is showing when setting the parameter under each target workout mode and to start the workout mode.
 5.3 Press to end the current workout mode and all message windows stop counting.


6. Reset Key：
 6.1 Pressing this key button under stopping mode, the image switches to the idle mode.
 6.2 The reset key button is valid only in stopping mode.
 6.3 Under any mode, pressing this key button for 3 seconds turns on the console again.
