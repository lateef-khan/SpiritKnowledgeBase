How to Install Motor Controller 

MAKE SURE MACHINE IS TURNED OFF AND UNPLUGGED BEFORE BEGINNING
Loosen 5 screws from Motor Top Cover. Screws do not have to be fully removed. There are 3 screws along the front and 1 screw on each side. For the screws on the side, you may have to put the deck in the folded position to reach them.
Remove Motor Top Cover.
Take a picture of the old Motor Controller board. This will help with the next steps.
Disconnect all wires from the original Motor Controller. Some wires may have hot glue on them. The hot glue can be peeled away, or use a q-tip dipped in rubbing alcohol along the edges of the glue to help it let go. NOTE: You do not have to reapply glue to the new controller board.
Remove 2 screws holding the Motor Controller to the frame of the machine. These screws can be tough to get out by hand with a manual Phillips head screwdriver. You may want to use a power drill.
Remove old Motor Controller
Install new Motor Controller with the 2 screws.
Install 2 Drive Motor wires in bottom left hand corner of the Motor Controller. Red wire will got spot labeled “M+”. Black wire (depending on model, could be White wire) will go to spot labeled “M-”
Install 3 Incline Motor wires to the top right hand of the Motor Controller. Red wire will go to a spot labeled “UP”. White wire will go to a spot labeled “COM”. Black wire will go to spot labeled “DOWN”
Install Incline Motor potentiometer wire to 3 pin connector. Depending on model this will either be on the left side middle of the Motor Controller or below the Main Computer Cable pin connector.
Install Main Computer Cable to the biggest pin connector (amount of pins varies on model). This connector is typically located at the top of the Motor Controller, more to the left hand side.
Install Speed Sensor to 2 pin connector in the top left hand corner of the Motor Controller.
 (This step is only for older machines) If the Motor Controller also has a separate Transformer beside it with 3 connectors (Red wire, Blue wire and Black Wire), connect those to the pin connector near the bottom center of the controller.
Install 2 wires for On/Off Switch or Filter to the bottom right hand corner of the Motor Controller. These spots can be labeled differently depending on the model, but for the most part they should be labeled “ACN” and “ACL”. Black wire will go to “ACN”. White wire will go to “ACL”.
Put the Motor Top Cover back on the machine.
Retighten 5 screws to hold the Motor Top Cover in place.
Plug up the machine and turn it on.
Run a calibration on the machine to make sure everything runs properly. The calibration process changes if the machine is a touchscreen or non touch screen. 
For Treadmills with Physical Buttons:

Clear Error Codes (if present):
Power the treadmill off, wait a few seconds, then power it back on to clear any error codes.

Enter Factory Settings Mode:
With the machine on, remove the safety key.
Press and hold the Start and Speed Up (Fast) buttons on the main console (the one directly under the screen, not on the handrails).
While holding the buttons, insert the safety key and keep holding the buttons for about 10 seconds.
The screen should display “Factory Settings.” If it doesn't, repeat the steps.

Navigate to Calibration:
Press the Enter button repeatedly to navigate the menu until the screen no longer changes.
The display should then prompt you to press Start to begin calibration.

Start Calibration:
Step off the treadmill before starting—it will move on its own.
Press Start to begin. The treadmill will automatically move the speed and incline from their lowest to highest settings.

After Calibration:
If successful, the treadmill will reboot to the home screen.
Please note any error codes that appear during the process and observe the machine’s behavior (e.g., if it stops early, doesn't incline, etc.)

For Treadmills with a Touchscreen:

Clear Error Codes (if present):
Power the treadmill off, wait a few seconds, then power it back on.

Login to a Profile:
Login to either a personal account or use the Guest profile.

Open the Engineering Menu:
Tap the gear icon in the top left corner of the screen to open Settings.
At the top of the Settings screen, you'll see the word “Settings” (it doesn’t look like a button, but it is!).
Rapidly tap the word “Settings” several times until the Engineering Menu appears.

Start Calibration:
Tap “Engineering Mode”.
Step off the treadmill before starting—it will move on its own.
Then press the calibration button located in the bottom-right corner of the screen.
The treadmill will automatically run through the speed and incline ranges.

After Calibration:
The machine should reboot back to the login screen once everything has stopped moving. If it doesn’t, press the home button at the top to return to the settings menu once complete.
