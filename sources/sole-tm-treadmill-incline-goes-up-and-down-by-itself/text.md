Treadmill Incline Goes Up and Down by Itself
(If machine has been recently assembled, replace Computer Cables)

This can be caused by the machine thinking buttons are being pressed or by a malfunctioning motor controller. Check the following to determine if a button might be stuck and causing the problem, or if the motor controller is acting on its own and needs to be replaced:

Ask if machine has been recently assembled, disassembled or moved
If answer is Yes, replaced Computer Cables (if machine is older than 2020, replace Computer Cables, Upper Incline Cable and Incline Adjustment Switch)
If answer is No, move on to Step 2
Ask if Incline number on console changes when the speed physically changes
If answer is Yes, something in the console is telling it to change the incline, replace Console Assembly
If machine is older than 2020, disconnect Incline Adjustment Switch and run machine again
If machine works, replace Incline Adjustment Switch
If machine does not work, replace Console Assembly
If answer is No, replace Motor Controller
If replacing the motor controller, ask about Lubrication (Question: How often do you lubricate?)
Whether the machine has been properly lubricated or not, check Running Belt and Running Deck have been worn or damaged (Slide hand between running belt and deck palm up first. See if texture of running belt is gone in the middle. Palm down, see if running deck is damaged.)
If Running Belt and Running Deck are in good condition, move on to Step 3
If Running Belt or Running Deck are worn or damaged, replace Running Belt, Running Deck (Running Deck only has to be replaced if it is worn or damaged), move on to step 3
If replacing the motor controller, ask if they have squeaking or knocking noises coming from the machine.
If the answer is yes, ask if noise is coming from the front or rear of the machine. Depending on the answer, replace the Front Roller or Rear Roller (possibly both)
