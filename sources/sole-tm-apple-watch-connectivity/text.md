# Apple Watch Connectivity

The Apple watch is only able to sync live heart rate data through the Sole+ app to the treadmill and is only supported on machines manufactured in August 2021 or later.

Prerequisites:

- The SOLE+ Watch App must be installed on the Apple Watch
- SOLE+ must be installed on an iPhone (will not work with Android phones)
- The Apple Watch must be paired with the iPhone

If all the prerequisites are met, connect the SOLE+ app on the iPhone to the machine over bluetooth. This requires signing into the SOLE+ app on the iPhone, tapping the arrow next to Connect on the main screen, tap Add Device in the bottom-left, tap Pair via Bluetooth, and selecting Pair for the machine once it's discovered while the machine is turned on. Once connected, the Apple Watch will send the current heart rate to the machine through the SOLE+ app during any workouts. This wireless heart rate is the only functionality provided and allows the use of the heart rate programs built into the machine if present that require a wireless heart rate monitor and for displaying during any workout.
